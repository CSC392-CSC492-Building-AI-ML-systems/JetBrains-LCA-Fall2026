Using Lists
===========

Lists are a fundamental data structure in Python that allow you to store and manage ordered collections of items. They are versatile and widely used for various tasks such as storing sequences of elements, iterating over data, and managing collections dynamically.

Creating Lists
--------------

You can create a list by enclosing a comma-separated sequence of items in square brackets:

.. code-block:: python

    my_list = [1, 2, 3, 4, 5]
    names = ['Alice', 'Bob', 'Charlie']

Lists can contain elements of different types:

.. code-block:: python

    mixed_list = [1, 'two', 3.0, True]

Accessing List Elements
-----------------------

List elements are accessed by their index, starting at zero:

.. code-block:: python

    first_item = my_list[0]  # 1
    last_item = my_list[-1]  # 5

You can also slice lists to obtain sublists:

.. code-block:: python

    sublist = my_list[1:4]  # [2, 3, 4]

Modifying Lists
---------------

Lists are mutable, meaning you can change their contents after creation:

.. code-block:: python

    my_list[0] = 10
    my_list.append(6)
    my_list.extend([7, 8])
    my_list.insert(2, 15)
    my_list.remove(3)
    popped_item = my_list.pop()

Iterating Over Lists
--------------------

You can iterate over the elements of a list using a for loop:

.. code-block:: python

    for item in my_list:
        print(item)

Common List Operations
----------------------

- **Length**: Use `len()` to get the number of elements.

  .. code-block:: python

      length = len(my_list)

- **Sorting**: Use `sorted()` to get a sorted copy or `list.sort()` to sort in place.

  .. code-block:: python

      sorted_list = sorted(my_list)
      my_list.sort()

- **Checking membership**: Use the `in` keyword.

  .. code-block:: python

      if 10 in my_list:
          print('Found 10')

List Comprehensions
-------------------

List comprehensions provide a concise way to create lists:

.. code-block:: python

    squares = [x**2 for x in range(10)]

They can include conditions:

.. code-block:: python

    even_squares = [x**2 for x in range(10) if x % 2 == 0]

Using Lists with ftrack_api
---------------------------

In the context of the ftrack_api, lists are often used to manage collections of entities, operations, or cached data. For example, the session's local cache stores entities in a list-like structure, allowing you to access created, modified, or deleted entities as lists:

- **Created Entities**: Accessed via the `created` property, returning a list of newly created entities.

- **Modified Entities**: Accessed via the `modified` property, returning a list of locally modified entities.

- **Deleted Entities**: Accessed via the `deleted` property, returning a list of deleted entities.

These lists can be iterated over or manipulated as needed to manage the state of your session effectively.

Summary
-------

Lists are a powerful and flexible tool for managing ordered collections of items in Python. Understanding how to create, access, modify, and iterate over lists is essential for effective programming, including when working with APIs such as ftrack_api.
