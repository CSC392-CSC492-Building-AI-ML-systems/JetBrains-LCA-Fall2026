GILDAS CLASS File Reader
=======================

Overview
--------

This module provides functionality to read GILDAS CLASS files and convert them into `pyspeckit.spectrum.ObsBlock` objects for further analysis. CLASS files are a standard format used in radio astronomy for storing spectral data and associated metadata.

The module supports multiple CLASS file versions and formats, including IEEE and VAX byte orders, and handles various header sections and data blocks.

Key Features
------------

- Reading CLASS files of different types and versions, including:
  - Multiple spectra files (IEEE, VAX, EEEI formats)
  - Single spectrum files
  - Version 1 and Version 2 CLASS files

- Parsing and interpreting header sections such as:
  - USER CODE
  - COMMENT
  - GENERAL observation metadata
  - POSITION coordinates
  - SPECTRO spectral setup
  - BASELINE fitting parameters
  - HISTORY and calibration data

- Handling different data types and units, including integer, float, and string fields.

- Utilities for reading binary data with correct alignment and endianness.

- Timing decorator to measure and log the execution time of functions, useful for monitoring performance when reading large CLASS files.

Data Structures and Constants
-----------------------------

- `filetype_dict` and `fileversion_dict`: Dictionaries mapping CLASS file type codes to descriptive strings and version identifiers.

- `record_lengths`: Defines the byte length of records for different CLASS file versions.

- `header_id_numbers`: Maps header section IDs to their descriptive names.

- `header_id_lengths`: Specifies the expected lengths of certain header sections.

- `keys_lengths`: Defines the structure of various header sections, listing the keys, their counts, and data types. For example:
  - `GENERAL` section includes UT, LST, Azimuth, Elevation, Opacity, System temperature, and Integration time.
  - `POSITION` section includes source name, epoch, coordinates, and projection system.
  - `SPECTRO` section includes line name, rest frequency, number of channels, frequency resolution, velocity resolution, and Doppler factor.
  - `CALIBRATION` section includes beam efficiency, ambient temperature, opacity, receiver temperature, and calibration mode.
  - `BASELINE` section includes baseline degree, sigma, area under windows, and line window limits.

Functions
---------

- `_read_bytes(f, n)`: Reads `n` bytes from a file-like object `f`.

- `_read_byte(f)`, `_read_int16(f)`, `_read_int32(f)`, `_read_int64(f)`, `_read_float32(f)`: Functions to read specific binary data types from the file, ensuring correct byte alignment and endianness.

- `_align_32(f)`: Aligns the file pointer to the next 32-bit boundary.

- `_read_word(f, length)`: Reads a word of given length from the file, aligning afterward.

- `_read_int(f)`: Reads a 4-byte integer from the file.

- `is_ascii(s)`: Checks if a given string contains only ASCII characters.

- `is_all_null(s)`: Checks if a string consists entirely of null bytes.

- `print_timing(func)`: Decorator to measure and log the execution time of functions.

Usage Notes
-----------

- The module uses `numpy` and `astropy` for numerical operations and logging.

- It supports Python 2 and 3 compatibility via the `six` library.

- The reading functions assume native endianness but include careful handling to ensure correct interpretation of binary data.

- The module includes detailed comments and references to the CLASS file format specification:
  http://iram.fr/IRAMFR/GILDAS/doc/html/class-html/node58.html

- Some header sections and fields are marked as "private" or "untested" and may require caution when used.
