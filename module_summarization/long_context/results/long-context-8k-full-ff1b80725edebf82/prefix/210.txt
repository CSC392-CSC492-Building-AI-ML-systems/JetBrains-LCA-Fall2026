Empirical Likelihood Inference on Descriptive Statistics
=========================================================

Overview
--------
This module provides tools for conducting empirical likelihood inference on descriptive statistics such as the mean, variance, skewness, kurtosis, and correlation. Empirical likelihood is a nonparametric method of statistical inference that combines the flexibility of nonparametric methods with the likelihood-based inference framework.

The module supports hypothesis testing and confidence interval construction for these statistics. Additionally, if matplotlib is installed, it can generate multivariate confidence region plots and mean-variance contour plots.

References
----------
Owen, A. (2001). *Empirical Likelihood*. Chapman and Hall.

Key Features
------------
- Hypothesis tests and confidence intervals for:
  - Mean
  - Variance
  - Skewness
  - Kurtosis
  - Correlation

- Support for both univariate and multivariate data.

- Visualization capabilities for multivariate confidence regions and mean-variance contours (requires matplotlib).

Main Components
---------------

DescStat Function
~~~~~~~~~~~~~~~~~
The `DescStat` function is the entry point to empirical likelihood inference on descriptive statistics. It accepts data as input and returns an appropriate instance for univariate or multivariate analysis.

**Parameters:**

- `endog` : ndarray  
  Input data array. If the data is univariate (one-dimensional), a univariate analysis instance is returned. For multivariate data (more than one dimension), a multivariate analysis instance is returned.

**Returns:**

- An instance of `DescStatUV` for univariate data or `DescStatMV` for multivariate data.

_OptFuncts Class
~~~~~~~~~~~~~~~~
This internal class encapsulates the core optimization functions used in empirical likelihood calculations. It defines methods for:

- Constructing estimating equations.
- Solving for Lagrange multipliers in the profile likelihood maximization.
- Computing gradients and Hessians for optimization.
- Calculating log-likelihood ratios and confidence interval limits.
- Profiling over nuisance parameters when necessary.

Key methods include:

- `_modif_newton`: Modified Newton's method to maximize the empirical likelihood.
- `_find_eta`: Root-finding for Lagrange multipliers in mean testing.
- `_opt_var`, `_opt_skew`, `_opt_kurt`, `_opt_correl`: Optimization routines for variance, skewness, kurtosis, and correlation tests respectively.
- `_ci_limits_*`: Functions to compute confidence interval limits for various statistics.

DescStatUV Class
----------------
The `DescStatUV` class extends `_OptFuncts` and provides empirical likelihood inference tools specifically for univariate data.

**Parameters:**

- `endog` : 1-dimensional ndarray  
  The univariate data to analyze.

**Attributes:**

- `endog` : ndarray  
  The data array.
- `nobs` : int  
  Number of observations.

**Methods:**

- `test_mean(mu0, return_weights=False)`:  
  Performs a hypothesis test for the mean equal to `mu0`. Returns the log-likelihood ratio statistic, p-value, and optionally the observation weights under the null hypothesis.

- Additional methods (not fully shown) provide similar functionality for variance, skewness, kurtosis, and correlation.

Usage Example
-------------
```python
import numpy as np
from emplike import DescStat

data = np.random.randn(100)
desc_stat = DescStat(data)

# Test hypothesis that mean equals 0
llr, pvalue = desc_stat.test_mean(0)
print(f"Log-likelihood ratio: {llr}, p-value: {pvalue}")
```

Notes
-----
- The empirical likelihood approach does not require specifying a parametric distribution for the data.
- The optimization routines internally solve for Lagrange multipliers that maximize the empirical likelihood under constraints defined by the estimating equations.
- Confidence intervals are constructed by inverting the empirical likelihood ratio tests.
- Multivariate extensions allow joint inference on vectors of descriptive statistics.

Technical Details
-----------------
The empirical likelihood is maximized subject to constraints imposed by the estimating equations for the statistics of interest. The Lagrange multipliers associated with these constraints are found by solving nonlinear equations using modified Newton methods. The log-likelihood ratio statistics are computed from the optimized empirical likelihood weights.

The module uses weighted versions of the estimating equations and applies profiling over nuisance parameters when testing statistics like variance, skewness, and kurtosis.

Visualization
-------------
If matplotlib is available, the module can generate:

- Multivariate confidence region plots.
- Mean-variance contour plots.

These visualizations aid in understanding the joint uncertainty in multiple descriptive statistics.

Summary
-------
This module offers a comprehensive framework for empirical likelihood inference on common descriptive statistics, providing both hypothesis testing and confidence interval estimation in a flexible, nonparametric likelihood setting.
