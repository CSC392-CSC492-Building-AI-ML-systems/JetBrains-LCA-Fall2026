Plothist Command
================

The `plothist` command provides tools for plotting probability distributions (histograms) stored in HDF5 files, typically generated by weighted ensemble (WE) simulations. It supports plotting 1D and 2D histograms, with options for scaling, labeling, and output formats.

Overview
--------

The `plothist` command reads histogram data from an HDF5 file and generates plots of the probability distributions. It supports plotting distributions for single iterations or averages over iteration ranges. The command can output plots in various formats (default PDF), save plot data in HDF5 or text formats, and customize plot appearance.

Key Features
------------

- Plot 1D or 2D histograms from WE simulation data.
- Support for multiple plot scales: linear, logarithmic (base 10), and energy scale (inverted natural log).
- Specify plot ranges and axis labels.
- Output plots to files or suppress plotting.
- Save plot data in HDF5 or text formats.
- Superimpose contour plots on 2D heatmaps.
- Post-process plots with user-defined functions.

Usage
-----

The command accepts the following main arguments and options:

### Input Options

- `input`  
  Path to the HDF5 file containing histogram data.

- `firstdim` (optional)  
  Specifies the primary dimension to plot. Format: `INT[:[LB,UB]:LABEL]`  
  - `INT`: zero-based dimension index  
  - `LB`, `UB`: optional lower and upper bounds for plotting  
  - `LABEL`: optional axis label  
  Default: dimension 0, full range.

- `seconddim` (optional, for 2D plots)  
  Specifies an additional dimension for 2D color map plots.

### Output Options

- `-o, --output, --plot-output`  
  Filename for saving the plot (default: `hist.pdf`). Set to empty string to suppress plotting.

- `--hdf5-output`  
  Save plot data in an HDF5 file.

- `--text-output` (1D histograms only)  
  Save plot data in a text file.

- `--plot-contour`  
  Overlay contour lines on 2D heatmaps.

### Plot Options

- `--title`  
  Title for the plot.

- Plot scale options (mutually exclusive):  
  - `--linear` : linear scale  
  - `--energy` : energy scale (default), plots `-ln P(x)`  
  - `--log10` : base-10 logarithmic scale

- `--zero-energy E`  
  Set zero of energy scale to `E`, or `"min"`/`"max"` (default `"min"`).

- `--range LB,UB`  
  Set the range for the plot ordinate (Y axis for 1D, colorbar for 2D).

- `--postprocess-function MODULE.FUNCTION`  
  Specify a function to modify the plot just before saving. The function is called as  
  `postprocess(hist, midpoints, binbounds)` where:  
  - `hist`: histogram data plotted  
  - `midpoints`: bin midpoints for each dimension  
  - `binbounds`: bin boundaries for each dimension (2D only), or `None` for 1D

Subcommands
-----------

### instant

Plot the probability distribution for a single WE iteration.

**Options:**

- `--iter N_ITER`  
  Plot distribution for iteration `N_ITER` (default: last completed iteration).

Description
-----------

The `plothist` command is designed to visualize histograms stored in HDF5 files generated by WE simulations or compatible tools. It supports flexible dimension selection and range specification, allowing detailed inspection of probability distributions.

Plotting scales include:

- **Energy scale**: plots the negative natural logarithm of the probability, corresponding to free energy profiles.
- **Linear scale**: plots raw probabilities.
- **Log10 scale**: plots base-10 logarithm of probabilities.

For 2D histograms, the command produces color maps with optional contour overlays.

Output data can be saved in HDF5 or plain text formats for further analysis or record-keeping.

Examples
--------

Plot the histogram for dimension 0 from `data.h5` with default settings:

```
plothist data.h5
```

Plot dimension 1 with bounds 0.0 to 10.0 and label "Distance":

```
plothist data.h5 1:0.0,10.0:Distance
```

Plot a 2D histogram using dimensions 0 and 1, save plot as PNG, and overlay contours:

```
plothist data.h5 0 --seconddim 1 -o hist.png --plot-contour
```

Plot iteration 5 distribution on a linear scale with a custom title:

```
plothist instant data.h5 --iter 5 --linear --title "Iteration 5 Distribution"
```

Save plot data in HDF5 and text formats:

```
plothist data.h5 --text-output hist.txt --hdf5-output histdata.h5
```

Advanced Usage
--------------

Users can specify a post-processing function to customize the plot before saving. The function should accept three arguments: the histogram array, midpoints, and bin boundaries, and modify the plot using matplotlib's pyplot interface.

Energy zero can be set to a specific value or to the minimum or maximum histogram value to adjust the energy scale baseline.

Logging
-------

The command logs information about the input file, including the range and step of iterations available in the histogram data.

Dependencies
------------

- Python packages: `h5py`, `numpy`, `matplotlib`
- WESTPA modules: `westpa.tools`, `westpa.core`, `westpa.fasthist`

Notes
-----

- The command assumes histogram data is stored in a compatible HDF5 format with datasets such as `histograms`, `midpoints_<dim>`, and `binbounds_<dim>`.
- For 2D plots, the first dimension is plotted along the X axis and the second along the Y axis.
- When plotting on the energy scale, zeroing is applied by subtracting the specified zero energy value from `-ln P`.
