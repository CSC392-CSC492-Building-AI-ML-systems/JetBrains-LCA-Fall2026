Isotonic Regression
====================

The :mod:`isotonic` module provides tools for performing isotonic regression, a non-parametric approach to fitting a monotonic function to data. This module includes a function to solve the isotonic regression problem, a utility to check monotonicity, and an estimator class implementing isotonic regression with additional features.

Contents
--------

- :func:`check_increasing`
- :func:`isotonic_regression`

Functions
---------

check_increasing(x, y)
~~~~~~~~~~~~~~~~~~~~~~

Determine whether the target values `y` are monotonically correlated with the input `x`.

Parameters
----------
x : array-like of shape (n_samples,)
    Input data.

y : array-like of shape (n_samples,)
    Target values.

Returns
-------
increasing_bool : bool
    True if `y` is increasing with respect to `x`, False if decreasing.

Notes
-----
The function uses the Spearman correlation coefficient to assess monotonicity. A warning is issued if the 95% confidence interval of the correlation spans zero, indicating uncertainty in the monotonicity direction.

References
----------
- Fisher transformation. Wikipedia.
  https://en.wikipedia.org/wiki/Fisher_transformation


isotonic_regression(y, *, sample_weight=None, y_min=None, y_max=None, increasing=True)
--------------------------------------------------------------------------------------

Solve the isotonic regression problem on the data `y`.

Parameters
----------
y : array-like of shape (n_samples,)
    The data to fit.

sample_weight : array-like of shape (n_samples,), default=None
    Weights for each data point. If None, equal weights are assumed.

y_min : float, default=None
    Lower bound on the minimum predicted value.

y_max : float, default=None
    Upper bound on the maximum predicted value.

increasing : bool, default=True
    Whether to fit an increasing or decreasing isotonic regression.

Returns
-------
y_ : ndarray of shape (n_samples,)
    The isotonic regression fit of `y`.

References
----------
- Best, M. J., & Chakravarti, N. (1990). Active set algorithms for isotonic regression; A unifying framework.


Classes
-------

IsotonicRegression
~~~~~~~~~~~~~~~~~~

Isotonic regression estimator that fits a monotonic function to data.

.. versionadded:: 0.13

Parameters
----------
y_min : float, default=None
    Lower bound on the minimum predicted value.

y_max : float, default=None
    Upper bound on the maximum predicted value.

increasing : bool or {'auto'}, default=True
    Whether to fit an increasing or decreasing function. If 'auto', the direction is inferred from the data.

out_of_bounds : {'nan', 'clip', 'raise'}, default='nan'
    How to handle input values outside the training data range during prediction:
    
    - 'nan': return NaN for out-of-bounds inputs.
    - 'clip': clip inputs to the nearest training data boundary.
    - 'raise': raise a ValueError.

Attributes
----------
X_min_ : float
    Minimum value of the training input data.

X_max_ : float
    Maximum value of the training input data.

X_thresholds_ : ndarray of shape (n_thresholds,)
    Unique sorted input values used for interpolation.

y_thresholds_ : ndarray of shape (n_thresholds,)
    Corresponding isotonic regression values for `X_thresholds_`.

f_ : callable
    Interpolation function used for prediction.

increasing_ : bool
    Direction of monotonicity inferred or set during fitting.

Methods
-------
fit(X, y, sample_weight=None)
    Fit the isotonic regression model.

transform(T)
    Transform new data by linear interpolation.

predict(T)
    Predict new data by linear interpolation.

get_feature_names_out(input_features=None)
    Get output feature names for transformation.

Notes
-----
- The estimator supports 1D input arrays or 2D arrays with a single feature.
- Ties in the data are handled using the method described by de Leeuw (1977).
- The interpolation function is rebuilt upon unpickling to ensure persistence.

References
----------
- Chakravarti, N. (1989). Isotonic Median Regression: A Linear Programming Approach. Mathematics of Operations Research, 14(2), 303-308.
- de Leeuw, J., Hornik, K., & Mair, P. (2009). Isotone Optimization in R: Pool-Adjacent-Violators Algorithm (PAVA) and Active Set Methods. Journal of Statistical Software.
- de Leeuw, J. (1977). Correctness of Kruskal's algorithms for monotone regression with ties. Psychometrika.

Examples
--------
>>> from sklearn.datasets import make_regression
>>> from sklearn.isotonic import IsotonicRegression
>>> X, y = make_regression(n_samples=10, n_features=1, random_state=41)
>>> iso_reg = IsotonicRegression().fit(X, y)
>>> iso_reg.predict([0.1, 0.2])
array([1.8628..., 3.7256...])
