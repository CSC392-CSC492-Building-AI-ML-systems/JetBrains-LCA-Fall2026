Imputation of Missing Values
============================

Imputation is a common technique used to handle missing data in datasets by replacing missing values with substituted values. This process is essential for preparing data for machine learning models, which typically require complete datasets without missing entries.

SimpleImputer
-------------

The `SimpleImputer` class provides a straightforward univariate imputation approach to complete missing values using simple strategies. It replaces missing values in each feature column with a descriptive statistic or a constant value.

### Features

- Supports multiple imputation strategies:
  - **mean**: Replace missing values using the mean of the column (numeric data only).
  - **median**: Replace missing values using the median of the column (numeric data only).
  - **most_frequent**: Replace missing values using the most frequent value in the column (numeric or string data).
  - **constant**: Replace missing values with a constant fill value (numeric or string data).

- Handles missing values represented by various placeholders, including `np.nan`, `None`, strings, or pandas' `pd.NA`.

- Supports sparse and dense input data.

- Optionally adds a missing indicator feature to the output, which flags the locations of missing values in the original data.

- Allows keeping features that consist exclusively of missing values during fitting.

### Parameters

- **missing_values** : int, float, str, np.nan, None or pandas.NA, default=np.nan  
  The placeholder for the missing values. All occurrences of `missing_values` will be imputed.

- **strategy** : {'mean', 'median', 'most_frequent', 'constant'}, default='mean'  
  The imputation strategy to use.

- **fill_value** : str or numerical value, default=None  
  When `strategy='constant'`, this value is used to replace missing values. If `None`, defaults to 0 for numeric data and "missing_value" for strings or objects.

- **copy** : bool, default=True  
  Whether to create a copy of the input data or perform imputation in-place when possible.

- **add_indicator** : bool, default=False  
  If True, a binary indicator for missing values is added to the output.

- **keep_empty_features** : bool, default=False  
  If True, features that contain only missing values during fitting are retained during transformation.

### Attributes

- **statistics_** : ndarray of shape (n_features,)  
  The computed imputation values for each feature.

- **indicator_** : `MissingIndicator` or None  
  The missing indicator transformer if `add_indicator=True`.

- **n_features_in_** : int  
  Number of features seen during fit.

- **feature_names_in_** : ndarray of shape (n_features_in_,)  
  Names of features seen during fit, if available.

### Usage Example

```python
import numpy as np
from sklearn.impute import SimpleImputer

# Create an imputer object with mean strategy
imp_mean = SimpleImputer(missing_values=np.nan, strategy='mean')

# Fit the imputer on training data
imp_mean.fit([[7, 2, 3], [4, np.nan, 6], [10, 5, 9]])

# Transform new data with missing values
X = [[np.nan, 2, 3], [4, np.nan, 6], [10, np.nan, 9]]
print(imp_mean.transform(X))
```

Output:

```
[[ 7.   2.   3. ]
 [ 4.   3.5  6. ]
 [10.   3.5  9. ]]
```

### Notes

- Columns containing only missing values during fitting are discarded during transformation unless `strategy='constant'` or `keep_empty_features=True`.

- Simple imputation is often less effective with weak learners but can perform comparably or better than complex imputation methods when combined with powerful learners.

- The imputer supports both dense and sparse input formats but does not allow `missing_values=0` for sparse inputs due to densification issues.

Additional Utilities
--------------------

- `_BaseImputer` is a base class that provides common functionality for imputers, including support for missing value indicators.

- The imputation process internally handles different data types and missing value representations, ensuring compatibility with numerical and categorical data.

- Efficient computation of statistics such as mean, median, and most frequent values is implemented, including special handling for sparse matrices.

Summary
-------

Imputation is a vital preprocessing step to handle missing data effectively. The `SimpleImputer` class offers a flexible and easy-to-use interface for univariate imputation strategies, supporting various data types and missing value representations. It also provides options to enhance the imputation process by adding missing indicators and preserving features with only missing values.
