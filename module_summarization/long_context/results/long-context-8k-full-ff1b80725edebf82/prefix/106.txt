Hyperexpand Module
==================

Overview
--------

The `hyperexpand` module provides functionality to expand hypergeometric functions (including Meijer G functions) into named special functions. This expansion is achieved through a collection of lookup tables and properties of hypergeometric functions, enabling the transformation of many hypergeometric functions into expressions involving well-known special functions.

The methodology implemented in this module is based on the paper:

- Kelly B. Roach, *Meijer G Function Representations*, Proceedings of the 1997 International Symposium on Symbolic and Algebraic Computation, pages 205-211, New York, 1997. ACM.

Further details and explanations are available in the Sphinx documentation accompanying this module.

Key Concepts and Features
-------------------------

- **Meijer G Function Extensions**:  
  The module supports various extensions and transformations of Meijer G functions, including parameter shifts and order reductions. Important properties include:
  
  - The effect of multiplying by powers of \( z \) on the parameters of the G function.
  - Definition and use of differential operators \( D = z \frac{d}{dz} \) and four shift operators \( A_J, B_J, C_J, D_J \) that increment or decrement parameters under certain conditions.
  - Order reduction techniques when parameters differ by integers, allowing simplification to lower-order G functions.
  - The concept of "suitable" index quadruples and reachability between them via shift operators.
  
- **Lookup Tables and Formulae**:  
  The module maintains a comprehensive knowledge base of formulae that relate hypergeometric functions to special functions. These formulae are organized and added programmatically, covering a wide range of hypergeometric functions such as:
  
  - \( {}_0F_0 \), \( {}_1F_0 \), \( {}_2F_1 \), \( {}_3F_2 \), \( {}_1F_1 \), \( {}_0F_1 \), \( {}_0F_3 \), \( {}_1F_2 \), and others.
  - Special cases involving elliptic integrals, Fresnel integrals, Bessel functions, and exponential integrals.
  
- **Symbolic Representations**:  
  The expansions use symbolic expressions involving special functions like exponential, logarithm, Bessel functions, Fresnel integrals, elliptic integrals, and gamma functions. These are represented using SymPy's symbolic classes and functions.

- **Formula Collection and Documentation Generation**:  
  Upon import, the module automatically generates a collection of formulae and produces LaTeX-formatted documentation strings for these expansions. This documentation is integrated into the Sphinx documentation system, providing clear mathematical representations of the expansions.

Usage
-----

The primary interface involves the `FormulaCollection` class, which aggregates known expansions. Each formula relates a hypergeometric function with specific parameters to its closed-form expression in terms of special functions.

Example snippet of formula addition:

```python
add((), (), exp(z))  # 0F0 hypergeometric function equals exp(z)

add((a,), (), HyperRep_power1(-a, z))  # 1F0 expansion

addb((a, a - 1/2), (2*a,), 
     Matrix([HyperRep_power2(a, z), HyperRep_power2(a + 1/2, z)/2]),
     Matrix([[1, 0]]),
     Matrix([[ (a - 1/2)*z/(1 - z), (1/2 - a)*z/(1 - z)],
             [a/(1 - z), a*(z - 2)/(1 - z)]]))
```

These formulae enable symbolic manipulation and simplification of hypergeometric functions into more elementary or special functions.

Dependencies
------------

The module relies on various components from the SymPy library, including:

- Core symbolic classes and utilities (`Add`, `Mul`, `Dummy`, `symbols`, etc.)
- Special functions (`gamma`, `besselj`, `besseli`, `elliptic_k`, `elliptic_e`, `fresnels`, `fresnelc`, etc.)
- Hypergeometric function representations and utilities (`hyper`, `meijerg`, `HyperRep_*` classes)
- Polynomial and matrix operations
- Printing utilities for LaTeX output
