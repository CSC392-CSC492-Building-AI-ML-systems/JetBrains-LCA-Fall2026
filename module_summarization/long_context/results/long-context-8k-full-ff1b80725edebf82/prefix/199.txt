Neural Network Models (Supervised)
==================================

Overview
--------

This section documents the supervised neural network models implemented, focusing on multi-layer perceptrons (MLPs) for classification and regression tasks. The models utilize various activation functions, loss functions, and stochastic optimization methods to train neural networks effectively.

Activation Functions
--------------------

Neural networks use activation functions to introduce non-linearity into the model. The following activation functions are supported and can be applied inplace to the input data:

- **Identity**: Leaves the input unchanged.
- **Logistic (Sigmoid)**: Applies the logistic sigmoid function.
- **Tanh**: Applies the hyperbolic tangent function.
- **ReLU (Rectified Linear Unit)**: Applies the ReLU function, setting negative values to zero.
- **Softmax**: Applies the K-way softmax function for multi-class classification.

Each activation function has a corresponding derivative function used during backpropagation to compute gradients efficiently.

Loss Functions
--------------

Loss functions measure the discrepancy between the predicted outputs and the true targets. The following loss functions are implemented:

- **Squared Loss**: Used for regression tasks, computes the mean squared error divided by two.
- **Log Loss**: Also known as logistic loss or cross-entropy loss, used for multi-class classification.
- **Binary Log Loss**: Specialized log loss for binary classification and multilabel cases.

These loss functions are essential for guiding the optimization process during training.

Stochastic Optimization Methods
-------------------------------

Training neural networks involves minimizing the loss function using optimization algorithms. Two stochastic optimizers are provided:

1. **SGDOptimizer (Stochastic Gradient Descent with Momentum)**
   - Supports learning rate schedules: constant, invscaling, and adaptive.
   - Momentum helps accelerate gradients vectors in the right directions.
   - Optionally uses Nesterov momentum for improved convergence.
   - Parameters:
     - `learning_rate_init`: Initial learning rate.
     - `momentum`: Momentum factor.
     - `nesterov`: Boolean flag to enable Nesterov momentum.
     - `lr_schedule`: Learning rate schedule type.
     - `power_t`: Exponent for inverse scaling learning rate.

2. **AdamOptimizer**
   - Adaptive Moment Estimation optimizer combining advantages of RMSProp and momentum.
   - Parameters:
     - `learning_rate_init`: Initial learning rate.
     - `beta_1`: Exponential decay rate for first moment estimates.
     - `beta_2`: Exponential decay rate for second moment estimates.
     - `epsilon`: Small constant for numerical stability.

Both optimizers update model parameters based on gradients computed during backpropagation and support learning rate adjustments during training.

Multi-layer Perceptron (MLP)
----------------------------

The MLP implementation supports both classification and regression tasks through derived classes. It is a feedforward artificial neural network model that maps sets of input data onto appropriate outputs.

Key Features:

- **Hidden Layers**: Configurable number and size of hidden layers.
- **Activation Functions**: Choice among identity, logistic, tanh, and ReLU.
- **Solvers**: Supports 'lbfgs' (quasi-Newton optimizer), 'sgd' (stochastic gradient descent), and 'adam' optimizers.
- **Regularization**: L2 penalty (alpha) to prevent overfitting.
- **Batch Size**: Controls the number of samples per gradient update.
- **Learning Rate**: Various schedules and initial learning rate settings.
- **Early Stopping**: Option to terminate training when validation score is not improving.
- **Shuffle**: Option to shuffle samples in each iteration.
- **Random State**: Seed for reproducibility.
- **Verbose**: Controls the verbosity of output during training.
- **Warm Start**: Reuse solution of the previous call to fit as initialization.

The base class `BaseMultilayerPerceptron` is abstract and should not be used directly. Instead, use the derived classes for classification or regression tasks.

Parameter Constraints
---------------------

The MLP model enforces constraints on its parameters to ensure valid configurations:

- `hidden_layer_sizes`: Sequence of integers, each >= 1.
- `activation`: One of {"identity", "logistic", "tanh", "relu"}.
- `solver`: One of {"lbfgs", "sgd", "adam"}.
- `alpha`: Non-negative float for L2 regularization.
- `batch_size`: Positive integer or "auto".
- `learning_rate`: One of {"constant", "invscaling", "adaptive"}.
- `learning_rate_init`: Positive float.
- `power_t`: Non-negative float.
- `max_iter`: Positive integer.
- `shuffle`: Boolean.
- `random_state`: Random seed or state.
- `tol`: Non-negative float for tolerance to declare convergence.
- `verbose`: Verbosity level.
- `warm_start`: Boolean.
- `momentum`: Float in [0, 1].
- `nesterovs_momentum`: Boolean.
- `early_stopping`: Boolean.
- `validation_fraction`: Float in [0, 1).
- `beta_1`, `beta_2`: Floats in [0, 1).
- `epsilon`: Positive float.
- `n_iter_no_change`: Positive integer or infinity.
- `max_fun`: Positive integer.

Usage Notes
-----------

- Activation functions and their derivatives are applied inplace for memory efficiency.
- Loss functions are used to evaluate model performance and guide optimization.
- Optimizers update model parameters iteratively based on computed gradients.
- The MLP model supports flexible configurations to adapt to various supervised learning problems.
- Early stopping and learning rate schedules help prevent overfitting and improve convergence.
