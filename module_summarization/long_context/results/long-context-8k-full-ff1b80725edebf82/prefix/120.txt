Channel Options
===============

In Vega-Lite and Altair, **channels** are the visual encoding channels that map data fields or values to visual properties of marks in a chart. These channels define how data is represented visually, such as position, color, size, shape, and more.

This document provides an overview of the available channel options and their usage.

Common Channel Options
----------------------

- **field**  
  The name of the data field to encode.

- **type**  
  The type of the encoded field. Common types include:
  - `quantitative` (continuous numeric data)
  - `ordinal` (ordered discrete values)
  - `nominal` (unordered discrete values)
  - `temporal` (time or date values)

- **aggregate**  
  An aggregation function to apply to the field, such as `mean`, `sum`, `count`, `min`, `max`, etc.

- **bin**  
  Whether to bin quantitative data into discrete bins. Can be a boolean or an object specifying bin parameters.

- **timeUnit**  
  Time unit to apply to temporal fields, such as `year`, `month`, `day`, `hours`, etc.

- **title**  
  Custom axis or legend title for the channel.

- **scale**  
  Scale properties for the channel, such as type of scale (`linear`, `log`, `ordinal`, etc.), domain, range, and other scale parameters.

- **axis**  
  Axis configuration options when the channel is positional (e.g., `x`, `y`). Includes properties like labels, ticks, grid lines, and orientation.

- **legend**  
  Legend configuration options when the channel is non-positional and uses a legend (e.g., `color`, `shape`, `size`).

- **sort**  
  Sorting order for ordinal or nominal fields.

- **condition**  
  Conditional encoding for interactive or conditional visual properties.

Channels Overview
-----------------

### Position Channels

- **x, y**  
  Map data to horizontal and vertical positions.

- **x2, y2**  
  Secondary position channels for ranged marks (e.g., bars, areas).

- **longitude, latitude**  
  Geographic position channels for maps.

### Mark Property Channels

- **color**  
  Encodes data using color.

- **fill, stroke**  
  Fill and stroke colors for marks.

- **size**  
  Size of marks (e.g., point size, bar thickness).

- **shape**  
  Shape of marks (e.g., circle, square, triangle).

- **opacity**  
  Transparency level of marks.

- **strokeWidth, strokeDash, strokeOpacity**  
  Stroke width, dash pattern, and opacity.

### Text and Tooltip Channels

- **text**  
  Text to display on marks.

- **tooltip**  
  Tooltip content shown on hover.

### Detail and Order Channels

- **detail**  
  Additional fields to group data without visual encoding.

- **order**  
  Order of marks for layered or stacked charts.

### Key Channels

- **key**  
  Unique key for data points, useful for selections and interactions.

Binding Channels
----------------

Channels can also be bound to interactive widgets for dynamic filtering or parameter control:

- **BindCheckbox**  
- **BindInput**  
- **BindRadioSelect**  
- **BindRange**  

These bindings allow users to interactively manipulate channel values.

Usage in Altair
---------------

In Altair, channels are specified as keyword arguments in encoding methods, for example:

```python
import altair as alt
from vega_datasets import data

source = data.cars()

chart = alt.Chart(source).mark_point().encode(
    x='Horsepower:Q',
    y='Miles_per_Gallon:Q',
    color='Origin:N',
    size='Acceleration:Q',
    tooltip=['Name:N', 'Year:O']
)
```

Here, `x`, `y`, `color`, `size`, and `tooltip` are channels with their respective field names and types.

Advanced Channel Options
------------------------

Channels support complex definitions including conditional encodings, value definitions, and field definitions with additional properties such as formatting and custom scales.

For detailed channel options and their schema, refer to the Vega-Lite [encoding documentation](https://vega.github.io/vega-lite/docs/encoding.html).

Deprecated and Legacy Notes
---------------------------

Some older datasets and functions related to channel options may be deprecated in favor of newer packages such as `vega_datasets`. It is recommended to use the latest Vega-Lite and Altair APIs for channel encoding.

Summary
-------

Channels are fundamental to creating effective visualizations in Vega-Lite and Altair. Understanding the available channel options and their configurations enables precise control over how data is visually represented.

For comprehensive details, consult the Vega-Lite schema and Altair API references.
