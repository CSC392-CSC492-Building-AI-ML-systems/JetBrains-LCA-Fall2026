Miner
=====

The `Miner` class provides an interface to interact with the Ethereum miner through the Web3.py library. It allows querying miner status and controlling mining operations via JSON-RPC calls.

Initialization
--------------

`Miner(web3)`

Creates a new `Miner` instance.

- **web3** (`Web3`): An instance of the Web3 class used to send requests.

Properties
----------

hashrate
~~~~~~~~

The current mining hashrate.

:type: int

This property returns the miner's current hashrate as a decimal integer by calling the `eth_hashrate` JSON-RPC method.

Methods
-------

makeDAG(number)
~~~~~~~~~~~~~~

Generate a DAG (Directed Acyclic Graph) for the specified block number.

:param number: The block number for which to generate the DAG.
:type number: int
:return: Result of the DAG generation request.
:rtype: varies

This method calls the `miner_makeDag` JSON-RPC method with the given block number.

setExtra(extra)
~~~~~~~~~~~~~~

Set the extra data field for the miner.

:param extra: Extra data to include in mined blocks.
:type extra: hex str or bytes
:return: Result of the extra data setting request.
:rtype: varies

This method calls the `miner_setExtra` JSON-RPC method with the provided extra data.

setEtherBase(etherbase)
~~~~~~~~~~~~~~~~~~~~~~

Set the etherbase (coinbase) address for mining rewards.

:param etherbase: The address to receive mining rewards.
:type etherbase: hex str
:return: Result of the etherbase setting request.
:rtype: varies

This method calls the `miner_setEtherbase` JSON-RPC method with the specified address.

setGasPrice(gas_price)
~~~~~~~~~~~~~~~~~~~~~~

Set the gas price for mining transactions.

:param gas_price: The gas price to use.
:type gas_price: int or hex str
:return: Result of the gas price setting request.
:rtype: varies

This method calls the `miner_setGasPrice` JSON-RPC method with the specified gas price.

start(num_threads)
~~~~~~~~~~~~~~~~~~

Start the miner with the specified number of threads.

:param num_threads: Number of threads to use for mining.
:type num_threads: int
:return: Result of the start mining request.
:rtype: varies

This method calls the `miner_start` JSON-RPC method with the number of threads.

stop()
~~~~~~

Stop the miner.

:return: Result of the stop mining request.
:rtype: varies

This method calls the `miner_stop` JSON-RPC method.

startAutoDAG()
~~~~~~~~~~~~~

Enable automatic DAG generation.

:return: Result of the start auto DAG request.
:rtype: varies

This method calls the `miner_startAutoDag` JSON-RPC method.

stopAutoDAG()
~~~~~~~~~~~~

Disable automatic DAG generation.

:return: Result of the stop auto DAG request.
:rtype: varies

This method calls the `miner_stopAutoDag` JSON-RPC method.
