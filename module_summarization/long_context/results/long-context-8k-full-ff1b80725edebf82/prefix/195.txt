Learn Gaussian Mixture Models
=============================

Overview
--------

Gaussian Mixture Models (GMMs) are probabilistic models that assume all the data points are generated from a mixture of a finite number of Gaussian distributions with unknown parameters. GMMs are widely used for clustering, density estimation, and as generative models.

This documentation describes the base class for mixture models, which provides a common interface and shared functionality for Gaussian Mixture Models and other mixture models.

BaseMixture Class
-----------------

The `BaseMixture` class is an abstract base class for mixture models. It specifies the interface and provides common methods used by all mixture models, including Gaussian Mixture Models.

### Initialization Parameters

- **n_components** : int  
  The number of mixture components.

- **tol** : float  
  The convergence threshold. EM iterations will stop when the lower bound average gain is below this threshold.

- **reg_covar** : float  
  Non-negative regularization added to the diagonal of covariance matrices to ensure they are positive definite.

- **max_iter** : int  
  The maximum number of EM iterations to perform.

- **n_init** : int  
  The number of initializations to perform. The best results are kept.

- **init_params** : {'kmeans', 'random', 'random_from_data', 'k-means++'}  
  The method used to initialize the weights, the means and the precisions.

- **random_state** : int, RandomState instance or None  
  Controls the random seed given to the initialization.

- **warm_start** : bool  
  When set to True, reuse the solution of the last fitting to initialize and add more iterations to the EM algorithm.

- **verbose** : bool  
  Enable verbose output.

- **verbose_interval** : int  
  Number of iterations done before the next verbose output.

### Key Methods

- **fit(X)**  
  Estimate model parameters with the EM algorithm. The method fits the model `n_init` times and selects the best fit based on the likelihood.

- **fit_predict(X)**  
  Fit the model and predict the labels for the data points in `X`.

- **predict(X)**  
  Predict the labels for the data samples in `X` using the trained model.

- **predict_proba(X)**  
  Evaluate the density of each mixture component for each sample in `X`.

- **score_samples(X)**  
  Compute the log-likelihood of each sample under the current model.

- **score(X)**  
  Compute the average log-likelihood of the given data `X`.

- **sample(n_samples=1)**  
  Generate random samples from the fitted Gaussian mixture model.

### EM Algorithm

The Expectation-Maximization (EM) algorithm is used to estimate the parameters of the mixture model:

- **E-step**: Compute the responsibilities (posterior probabilities) for each data point belonging to each component.

- **M-step**: Update the parameters (weights, means, covariances) to maximize the expected complete-data log-likelihood.

The algorithm iterates between these two steps until convergence, which is determined by the change in log-likelihood being less than `tol` or reaching `max_iter` iterations.

### Initialization Methods

- **kmeans**: Initialize responsibilities using KMeans clustering.

- **random**: Initialize responsibilities randomly.

- **random_from_data**: Initialize responsibilities by randomly assigning data points to components.

- **k-means++**: Initialize responsibilities using the k-means++ algorithm for better initial cluster centers.

### Model Parameters

- **weights_** : array-like, shape (n_components,)  
  The weights of each mixture component.

- **means_** : array-like, shape (n_components, n_features)  
  The mean of each mixture component.

- **covariances_** : array-like  
  The covariance of each mixture component. The shape depends on the covariance type.

- **converged_** : bool  
  Whether the algorithm has converged.

- **n_iter_** : int  
  Number of iterations run.

- **lower_bound_** : float  
  Log-likelihood of the fitted model.

Usage Example
-------------

```python
from sklearn.mixture import GaussianMixture

# Create a Gaussian Mixture Model with 3 components
gmm = GaussianMixture(n_components=3, covariance_type='full', random_state=42)

# Fit the model to data X
gmm.fit(X)

# Predict the labels for data points
labels = gmm.predict(X)

# Generate new samples from the fitted model
samples, sample_labels = gmm.sample(n_samples=100)
```

Notes
-----

- The `BaseMixture` class is abstract and cannot be used directly. Use derived classes such as `GaussianMixture` which implement the abstract methods.

- The model supports different covariance types (`full`, `tied`, `diag`, `spherical`) which affect the shape and flexibility of the covariance matrices.

- The `warm_start` option allows incremental fitting by continuing from the last solution.

- The model raises a `ConvergenceWarning` if the EM algorithm does not converge within the specified number of iterations.
