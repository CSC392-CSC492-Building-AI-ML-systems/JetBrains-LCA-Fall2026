Compatibility Policy
====================

This module provides a collection of random number generation components, including the `SFC64` bit generator and various distributions implemented in C and Cython. The compatibility policy for this module is designed to ensure reproducibility, stability, and clarity for users relying on its random number generation capabilities.

Deterministic Output Guarantee
-------------------------------

The `SFC64` bit generator guarantees that a fixed seed will always produce the same sequence of random integers. This deterministic behavior is critical for reproducible scientific computations and simulations. Users can rely on the fact that:

- Initializing `SFC64` with the same seed will yield identical random streams.
- The internal state of the generator can be saved and restored exactly via the `state` property, preserving the sequence continuity.

API Stability
-------------

- The public API for bit generators, including `SFC64`, follows a consistent interface modeled after NumPy’s `BitGenerator` class.
- The state dictionary format for bit generators is stable and includes all necessary information to fully capture and restore the generator’s state.
- The module exposes a comprehensive set of random distributions implemented in C for performance, accessible through the bit generator interface.

Source and Binary Compatibility
-------------------------------

- The module is built as a static library (`npyrandom`) and Cython extensions, ensuring consistent compilation and linking across supported platforms.
- Compiler flags and build configurations are set to maintain compatibility with various systems, including special handling for Cygwin environments.
- The module’s source code and build system are designed to maintain backward compatibility with existing seeds and state representations.

Summary
-------

Users can depend on this module to provide stable, reproducible random number generation with a clear compatibility policy:

- Fixed seeds produce consistent random streams.
