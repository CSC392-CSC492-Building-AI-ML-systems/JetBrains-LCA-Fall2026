Nextcord
=======

Introduction
------------

Nextcord is a modern, easy-to-use, feature-rich, and async-ready Python library for interacting with the Discord API. It is designed to help developers create Discord bots and applications with minimal effort while providing powerful tools and abstractions.

Key Features
------------

- **Asynchronous**: Built on Python's `asyncio` library, Nextcord allows for efficient and scalable asynchronous programming.
- **Comprehensive API Coverage**: Supports a wide range of Discord features including guilds, channels, members, messages, reactions, voice, and more.
- **Intuitive Object Model**: Provides Pythonic classes and methods that represent Discord entities such as users, channels, guilds, and widgets.
- **Extensible**: Easily extendable with custom commands, events, and plugins.
- **Type Hinting and Documentation**: Fully typed with detailed docstrings to improve developer experience and IDE support.

Core Components
---------------

- **Widgets**: Nextcord supports Discord Guild Widgets, which provide a snapshot of a guild's online members and voice channels. The `Widget` class represents a guild widget, containing information such as the guild's ID, name, accessible voice channels (`WidgetChannel`), and online members (`WidgetMember`). Widgets also provide convenient properties like `json_url` for accessing the widget's JSON data and methods to fetch invites.

- **WidgetChannel**: Represents a partial voice channel in a guild widget, including attributes like `id`, `name`, and `position`. It supports operations such as equality checks and string representation returning the channel's name.

- **WidgetMember**: Represents a partial member in a guild widget, including attributes like `id`, `name`, `discriminator`, `bot` status, presence `status`, nickname, avatar, activity, and voice state (deafened, muted, suppressed). It provides a `display_name` property that returns the member's nickname if available, otherwise their username.

- **Colour**: The `Colour` class represents Discord role colors as integer values, with convenient methods to create colors from RGB or HSV values, generate random colors, and access predefined color constants (e.g., `teal`, `dark_teal`, `brand_green`, `blurple`, `dark_theme`). It supports standard operations such as equality, hashing, and conversion to string (hex format) or integer.

Getting Started
---------------

To start using Nextcord, install it via pip:

.. code-block:: bash

    pip install nextcord

Then, import and create a bot instance:

.. code-block:: python

    import nextcord
    from nextcord.ext import commands

    bot = commands.Bot(command_prefix='!')

    @bot.event
    async def on_ready():
        print(f'Logged in as {bot.user}!')

    bot.run('your_token_here')
