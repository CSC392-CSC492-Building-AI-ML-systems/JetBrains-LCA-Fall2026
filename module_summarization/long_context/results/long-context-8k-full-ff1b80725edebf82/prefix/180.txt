Cross-validation: Evaluating Estimator Performance
====================================================

Cross-validation is a robust statistical method used to estimate the skill of machine learning models. It is primarily used to assess how the results of a predictive model will generalize to an independent dataset. This technique is essential for evaluating estimator performance, tuning model parameters, and selecting the best model.

Overview
--------

Cross-validation involves partitioning the original dataset into a training set to train the model, and a test set to evaluate it. The most common form is *k*-fold cross-validation, where the data is split into *k* subsets (folds). The model is trained on *k-1* folds and tested on the remaining fold. This process is repeated *k* times, with each fold used exactly once as the test set. The results are then averaged to produce a single estimation.

Key Concepts
------------

- **Estimator**: An object implementing the methods `fit` and `predict`. It can be a classifier, regressor, or any predictive model.
- **Training set**: The subset of data used to fit the model.
- **Test set**: The subset of data used to evaluate the model's performance.
- **Cross-validation splitter**: A strategy or generator that defines how to split the data into training and test sets. Examples include `KFold`, `StratifiedKFold`, and `GroupKFold`.
- **Scoring**: A metric or function used to evaluate the predictions of the model. It can be a string identifier or a callable.

Using Cross-validation in scikit-learn
--------------------------------------

Scikit-learn provides utilities to perform cross-validation and evaluate estimator performance efficiently. The `model_selection` module includes functions and classes such as `cross_val_score`, `cross_validate`, and various cross-validation splitters.

### Learning Curves

Learning curves are a visualization tool to understand the performance of an estimator with varying sizes of the training dataset. They plot the training and validation scores against the number of training samples, helping to diagnose whether a model suffers from bias or variance issues.

The `LearningCurveDisplay` class in scikit-learn facilitates the visualization of learning curves. It can be created directly from training scores or from an estimator using the `from_estimator` class method.

Example usage:

```python
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.model_selection import LearningCurveDisplay, learning_curve
from sklearn.tree import DecisionTreeClassifier

X, y = load_iris(return_X_y=True)
tree = DecisionTreeClassifier(random_state=0)

train_sizes, train_scores, test_scores = learning_curve(tree, X, y)
display = LearningCurveDisplay(train_sizes=train_sizes,
                               train_scores=train_scores,
                               test_scores=test_scores,
                               score_name="Accuracy")
display.plot()
plt.show()
```

Parameters for `LearningCurveDisplay.from_estimator` include:

- `estimator`: The model to evaluate.
- `X`, `y`: Input data and target labels.
- `train_sizes`: Relative or absolute numbers of training examples to use.
- `cv`: Cross-validation splitting strategy.
- `scoring`: Scoring metric or callable.
- `shuffle`: Whether to shuffle data before splitting.
- `random_state`: Seed for reproducibility.
- `n_jobs`: Number of parallel jobs.
- `error_score`: Value to assign if an error occurs during fitting.

Plot Customization
------------------

The learning curve plot can be customized with parameters such as:

- `negate_score`: Whether to negate the scores (useful for metrics where lower is better).
- `score_type`: Which scores to plot (`"train"`, `"test"`, or `"both"`).
- `std_display_style`: Style to display the standard deviation around the mean score (`"fill_between"`, `"errorbar"`, or `None`).
- `line_kw`, `fill_between_kw`, `errorbar_kw`: Additional keyword arguments passed to matplotlib plotting functions.

Interpreting Learning Curves
----------------------------

- **High training score and low validation score**: Indicates overfitting.
- **Low training and validation scores**: Indicates underfitting.
- **Converging training and validation scores with increasing training size**: Suggests a good fit.

Additional Cross-validation Strategies
--------------------------------------

Scikit-learn supports various cross-validation strategies to suit different data scenarios:

- **KFold**: Basic *k*-fold cross-validation.
- **StratifiedKFold**: Preserves class distribution in each fold, useful for classification.
- **GroupKFold**: Ensures that the same group is not represented in both training and test sets.
- **LeaveOneOut**: Uses a single observation as the test set, and the rest as training.

These strategies can be passed to cross-validation functions via the `cv` parameter.

Summary
-------

Cross-validation is a fundamental technique for evaluating the generalization performance of machine learning estimators. It helps in model selection, hyperparameter tuning, and understanding model behavior. Visualization tools like learning curves provide intuitive insights into model performance across varying training set sizes, aiding in diagnosing bias and variance issues.
