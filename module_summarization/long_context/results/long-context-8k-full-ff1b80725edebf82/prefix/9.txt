Using Timers
============

The ftrack API provides support for working with timers to measure and manage time intervals within your applications. Timers can be useful for profiling code execution, scheduling tasks, or tracking durations of operations.

Creating a Timer
----------------

To create a timer, you typically instantiate a timer object associated with your session or operation context. The timer can then be started, stopped, and queried for elapsed time.

Starting and Stopping a Timer
-----------------------------

Once a timer is created, you can start it to begin measuring time. When the operation or code section you want to time completes, stop the timer to record the elapsed duration.

Example::

    timer = session.create_timer()
    timer.start()
    # Perform some operations
    timer.stop()
    print('Elapsed time:', timer.elapsed)

Accessing Timer Information
---------------------------

Timers provide properties and methods to access timing information such as:

- **elapsed**: The total time elapsed between start and stop.
- **running**: Boolean indicating if the timer is currently running.
- **reset()**: Method to reset the timer to zero.

Using Timers with Context Managers
----------------------------------

Timers can be used conveniently with Python's context manager protocol to automatically start and stop timing around a block of code.

Example::

    with session.timer('operation_name') as timer:
        # Code to time
        perform_operation()
    print('Operation took:', timer.elapsed)

Integration with Event System
-----------------------------

Timers can be integrated with the ftrack event system to emit timing events or trigger actions based on timer completion. This allows for automated workflows and monitoring within the ftrack environment.

Best Practices
--------------

- Use timers to profile critical sections of your code to identify performance bottlenecks.
- Employ context managers for clean and readable timing code.
- Reset timers when reusing them for multiple measurements.
- Combine timers with logging to record timing information for audit and debugging purposes.

Note
----

The timer functionality depends on the session being active and connected. Ensure your session is properly initialized and not closed before using timers.

For detailed usage and advanced timer features, refer to the API reference and examples provided with the ftrack Python API.
