Generate Example for Generalized Additive Model (GAM) Smoothers
=================================================================

This example demonstrates how to generate and use spline basis functions and smoothers for Generalized Additive Models (GAM) using the provided classes and functions. The code includes utilities for B-splines, polynomial smoothers, and generic smoothers, as well as methods for knot selection and basis evaluation.

Overview
--------

The module provides several classes and functions to create smooth basis functions for GAMs:

- **UnivariateBSplines**: Creates B-spline basis functions for a single explanatory variable.
- **UnivariatePolynomialSmoother**: Creates polynomial basis functions.
- **UnivariateGenericSmoother**: Allows using custom basis functions.
- Utility functions for knot selection and basis evaluation, such as `get_knots_bsplines`, `_eval_bspline_basis`, and `make_bsplines_basis`.

Example: Creating and Using a B-Spline Smoother
-----------------------------------------------

```python
import numpy as np
import matplotlib.pyplot as plt
from smooth_basis import UnivariateBSplines

# Generate sample data
x = np.linspace(0, 10, 100)

# Create a B-spline smoother with 10 degrees of freedom and cubic splines (degree=3)
bspline_smoother = UnivariateBSplines(x, df=10, degree=3, include_intercept=False,
                                     constraints='center', variable_name='x')

# Access the spline basis matrix for the original data
basis = bspline_smoother.basis

# Plot the basis functions
plt.figure(figsize=(10, 6))
for i in range(basis.shape[1]):
    plt.plot(x, basis[:, i], label=f'Basis {i}')
plt.title('B-Spline Basis Functions')
plt.xlabel('x')
plt.ylabel('Basis function value')
plt.legend()
plt.show()

# Transform new data points using the spline basis
x_new = np.linspace(0, 10, 50)
basis_new = bspline_smoother.transform(x_new)

# basis_new can be used for prediction or further modeling
```

Example: Creating a Polynomial Smoother
--------------------------------------

```python
from smooth_basis import UnivariatePolynomialSmoother

# Generate sample data
x = np.linspace(0, 5, 50)

# Create a polynomial smoother of degree 4
poly_smoother = UnivariatePolynomialSmoother(x, degree=4, variable_name='x')

# Access the polynomial basis matrix
basis_poly = poly_smoother.basis

# Plot polynomial basis functions
import matplotlib.pyplot as plt

plt.figure(figsize=(8, 5))
for i in range(basis_poly.shape[1]):
    plt.plot(x, basis_poly[:, i], label=f'Degree {i+1}')
plt.title('Polynomial Basis Functions')
plt.xlabel('x')
plt.ylabel('Basis function value')
plt.legend()
plt.show()
```

Example: Using Generic Smoother with Custom Basis
-------------------------------------------------

```python
import numpy as np
from smooth_basis import UnivariateGenericSmoother

# Suppose you have custom basis matrices computed externally
x = np.linspace(0, 1, 100)
custom_basis = np.column_stack([np.sin(2 * np.pi * x), np.cos(2 * np.pi * x)])
custom_der_basis = np.gradient(custom_basis, axis=0)
custom_der2_basis = np.gradient(custom_der_basis, axis=0)
cov_der2 = np.dot(custom_der2_basis.T, custom_der2_basis)

# Create a generic smoother using the custom basis
generic_smoother = UnivariateGenericSmoother(x, custom_basis, custom_der_basis,
                                             custom_der2_basis, cov_der2,
                                             variable_name='x')

# Use the basis for modeling or prediction
basis_generic = generic_smoother.basis
```

Knot Selection and Basis Evaluation
-----------------------------------

The module provides functions to select knots and evaluate B-spline basis functions:

- `get_knots_bsplines(x, df, degree, spacing='quantile', ...)`  
  Returns knots for B-splines based on quantile or equal spacing.

- `_eval_bspline_basis(x, knots, degree, deriv='all', include_intercept=True)`  
  Evaluates the B-spline basis and its derivatives at points `x`.

These utilities allow flexible construction of spline bases tailored to the data and modeling needs.

Penalty Matrix Computation
--------------------------

The smoothers compute a penalty matrix based on the integral of the cross product of the second derivatives of the basis functions. This is used for regularization in GAM fitting.

```python
cov_der2 = get_covder2(smoother)
```

This integral is approximated using numerical integration over knots and additional points.

Summary
-------

This module facilitates the creation of smooth basis functions for GAMs, supporting B-splines, polynomial bases, and custom bases. It includes tools for knot selection, basis evaluation, and penalty matrix computation, enabling flexible and efficient modeling of smooth effects in regression models.
