w_multi_west Command
====================

Overview
--------
`w_multi_west` is a command-line tool designed to combine multiple WESTPA simulations into a single consolidated dataset while properly accounting for reweighting. This tool facilitates the aggregation of simulation data, including auxiliary datasets and optionally ibstates, enabling streamlined analysis across multiple simulation runs.

Key Features
------------
- Combines multiple WESTPA simulation outputs (`west.h5` files) into one unified HDF5 file.
- Supports reweighting of trajectories to maintain statistical consistency.
- Allows inclusion of additional auxiliary datasets.
- Optionally combines `ibstates` datasets if they are consistent across simulations.
- Provides progress indication during processing.
- Handles source and sink states for recycling targets across simulations.

Usage
-----
```
w_multi_west [OPTIONS]
```

Command-Line Options
--------------------
The following options are available for `w_multi_west`:

Input/Output Options
~~~~~~~~~~~~~~~~~~~
- `-o`, `--output-file`  
  Specify the name of the output file to store the combined results.  
  Default: `multi.h5`

- `-W`, `--west`, `--WEST_H5FILE`  
  Specify the name of the main WESTPA HDF5 file inside each simulation directory.  
  Default: `west.h5`

Auxiliary Data Options
~~~~~~~~~~~~~~~~~~~~~~
- `-a`, `--aux`  
  Names of additional auxiliary datasets to be combined. Can be specified multiple times.

- `-aa`, `--auxall`  
  Combine all auxiliary datasets found in the simulations.  
  Default: False

Reweighting and Dataset Options
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
- `-nr`, `--no-reweight`  
  Disable reweighting of trajectories during combination.  
  Default: False

- `-ib`, `--ibstates`  
  Attempt to combine `ibstates` datasets from the simulations. This requires that the `ibstates` datasets are identical across all input files.  
  Default: False

Functionality Details
---------------------
- The tool reads multiple WESTPA simulation files and extracts iteration data, including segment indices, progress coordinates, weight graphs, and optionally auxiliary data.
- It verifies consistency of `ibstates` datasets if the `--ibstates` option is used, and combines them if consistent.
- Source and sink states are identified and tracked to manage recycling targets across simulations.
- Segment indices and parent IDs are adjusted to maintain correct references after concatenation.
- The combined data is saved into a new WESTPA HDF5 file, compatible with existing WESTPA analysis tools.
- Progress is reported throughout the operation to inform the user of the current processing stage.

Example
-------
To combine multiple simulations stored in directories with default `west.h5` files, including all auxiliary datasets and combining `ibstates`, run:

```
w_multi_west -o combined_multi.h5 -aa --ibstates
```

This will produce a file named `combined_multi.h5` containing the merged simulation data.

Notes
-----
- The tool assumes that the `ibstates` datasets are identical across all input simulations when combining them; otherwise, it will skip exporting the `ibstates` dataset.
- Reweighting is enabled by default to ensure statistical correctness; disable it only if you have a specific reason.
- Auxiliary datasets can be selectively included or all combined using the provided options.

Logging and Debugging
---------------------
The tool uses Python's logging module to provide debug information, including details about bin mappers loaded from the input files. This can assist in troubleshooting issues related to binning and data consistency.

For further assistance or to report issues, please refer to the WESTPA documentation or contact the WESTPA development team.
