Metadata Routing API
====================

The Metadata Routing API provides a flexible mechanism to route metadata parameters through meta-estimators to their underlying base estimators. This is particularly useful in complex estimator compositions such as multi-output regressors and classifiers, where parameters need to be passed down to individual sub-estimators in a structured and controlled manner.

Overview
--------

Meta-estimators often wrap one or more base estimators to extend their functionality. When fitting or partially fitting these meta-estimators, it is sometimes necessary to pass additional parameters to the underlying estimators' methods (`fit`, `partial_fit`, etc.). The Metadata Routing API enables this by encapsulating routing information and processing parameter dispatching automatically.

Key Components
--------------

- **MetadataRouter**  
  A central class that encapsulates routing information for an estimator. It defines how parameters should be routed from the meta-estimator to its sub-estimators.

- **MethodMapping**  
  Defines mappings between the caller method names on the meta-estimator and the callee method names on the underlying estimators. This allows flexible routing of parameters for different methods such as `fit` and `partial_fit`.

- **process_routing**  
  A utility function that processes the routing of parameters based on the routing information defined in the `MetadataRouter`. It ensures that parameters are correctly dispatched to the appropriate sub-estimators.

- **_routing_enabled**  
  A function that checks whether metadata routing is enabled in the current context, allowing conditional routing behavior.

- **_raise_for_params**  
  A helper function that raises errors if unexpected parameters are passed, ensuring strict parameter validation when routing is enabled.

Usage in MultiOutput Estimators
-------------------------------

The multi-output meta-estimators such as `MultiOutputRegressor` and `MultiOutputClassifier` utilize the Metadata Routing API to handle parameters passed to their `fit` and `partial_fit` methods.

For example, in the `partial_fit` method of `_MultiOutputEstimator`:

- When metadata routing is enabled (`_routing_enabled()` returns `True`), the method calls `process_routing` to route parameters like `sample_weight` and any additional `partial_fit_params` to the corresponding sub-estimators.

- When routing is disabled, parameters are manually checked and passed to the underlying estimators.

This design allows users to pass parameters in a flexible way, supporting advanced use cases such as passing different parameters to different sub-estimators in a multi-output setting.

Example
-------

```python
multi_output_regressor = MultiOutputRegressor(estimator)
multi_output_regressor.partial_fit(X, y, sample_weight=weights, custom_param=value)
```

If metadata routing is enabled, `custom_param` will be routed appropriately to each underlying estimator's `partial_fit` method according to the routing rules defined in the `MetadataRouter`.

Getting Metadata Routing Information
------------------------------------

Each meta-estimator implementing metadata routing exposes a method:

```python
get_metadata_routing()
```

which returns a `MetadataRouter` instance describing how parameters are routed. For example, the `_MultiOutputEstimator` defines:

```python
def get_metadata_routing(self):
    router = MetadataRouter(owner=self.__class__.__name__).add(
        estimator=self.estimator,
        method_mapping=MethodMapping()
        .add(callee="partial_fit", caller="partial_fit")
        .add(callee="fit", caller="fit"),
    )
    return router
```

This indicates that parameters passed to the meta-estimator's `fit` and `partial_fit` methods are routed to the corresponding methods of the underlying `estimator`.

Version Information
-------------------

The Metadata Routing API was introduced in version 1.3 of the library. Parameters passed via metadata routing are supported in methods such as `fit` and `partial_fit` starting from this version.

Summary
-------

The Metadata Routing API enhances meta-estimators by providing a structured and extensible way to route parameters to underlying estimators. This facilitates advanced parameter passing scenarios, improves code maintainability, and supports complex estimator compositions such as multi-output models.
