Working with Assignments and Allocations
========================================

In ftrack, assignments and allocations are key concepts used to manage the relationship between tasks and resources such as users or assets. This documentation provides an overview of how to work with assignments and allocations within the ftrack API.

Assignments
-----------

An **assignment** represents the association of a resource (typically a user) to a task or other assignable entity. Assignments are used to indicate responsibility or involvement in a particular piece of work.

### Creating Assignments

To create an assignment, you typically create an entity of type `Assignment` and associate it with the relevant task and user. This can be done using the `Session.create()` method:

```python
assignment = session.create('Assignment', {
    'task': task_entity,
    'resource': user_entity
})
```

Here, `task_entity` is the task to which the user is being assigned, and `user_entity` is the user resource.

### Accessing Assignments

Assignments can be accessed via the task or resource entities. For example, to get all assignments for a task:

```python
assignments = task_entity['assignments']
```

Similarly, to get all tasks assigned to a user:

```python
assignments = user_entity['assignments']
```

### Modifying Assignments

Assignments can be modified by updating their attributes and then committing the changes:

```python
assignment['some_attribute'] = new_value
session.commit()
```

### Deleting Assignments

To remove an assignment, delete the assignment entity:

```python
session.delete(assignment)
session.commit()
```

Allocations
-----------

An **allocation** represents the allocation of a resource to a task or other entity, often with additional metadata such as time or effort estimates. Allocations are used to plan and track resource usage.

### Creating Allocations

Allocations are created similarly to assignments, by creating an entity of type `Allocation` and associating it with the relevant task and resource:

```python
allocation = session.create('Allocation', {
    'task': task_entity,
    'resource': user_entity,
    'time_estimate': 8.0  # hours
})
```

### Accessing Allocations

Allocations can be accessed through the task or resource entities:

```python
allocations = task_entity['allocations']
```

or

```python
allocations = user_entity['allocations']
```

### Modifying Allocations

Modify allocation attributes as needed and commit the changes:

```python
allocation['time_estimate'] = 10.0
session.commit()
```

### Deleting Allocations

Delete an allocation entity to remove it:

```python
session.delete(allocation)
session.commit()
```

Working with Assignments and Allocations in Sessions
---------------------------------------------------

The `Session` object manages entities including assignments and allocations. It provides methods to create, modify, and delete these entities, as well as to query and cache them efficiently.

- Use `Session.create()` to create new assignment or allocation entities.
- Use entity attributes to access related assignments or allocations.
- Use `Session.commit()` to persist changes to the server.
- Use `Session.delete()` to remove assignments or allocations.

Example workflow:

```python
with ftrack_api.Session() as session:
    # Retrieve a task and user
    task = session.query('Task where name is "Example Task"').one()
    user = session.query('User where username is "jdoe"').one()

    # Create an assignment
    assignment = session.create('Assignment', {
        'task': task,
        'resource': user
    })

    # Create an allocation with time estimate
    allocation = session.create('Allocation', {
        'task': task,
        'resource': user,
        'time_estimate': 8.0
    })

    # Commit changes
    session.commit()
```

Best Practices
--------------

- Always commit your session after creating or modifying assignments and allocations to persist changes.
- Use the session’s caching and auto-populate features to efficiently manage entity state.
- Use context managers (`with` statement) to ensure sessions are properly closed.
- Handle exceptions such as `ftrack_api.exception.UnrecognisedEntityTypeError` when creating entities.
- Use the session’s event hub to listen for changes to assignments and allocations if real-time updates are needed.

Summary
-------

Assignments and allocations are fundamental to managing task-resource relationships in ftrack. The ftrack API provides a flexible and powerful interface to create, access, modify, and delete these entities within a session context, enabling effective resource management and planning.
