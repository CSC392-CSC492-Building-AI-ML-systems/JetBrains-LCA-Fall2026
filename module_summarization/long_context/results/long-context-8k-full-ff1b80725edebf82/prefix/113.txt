Plans
=====

This module provides a collection of experimental plans for controlling and scanning hardware devices (motors, detectors, etc.) in scientific experiments. These plans are designed to be used with Bluesky, a framework for experiment control and data acquisition.

Functions
---------

count(detectors, num=1, delay=None, *, per_shot=None, md=None)
    Take one or more readings from detectors.

    Parameters
    ----------
    detectors : list
        List of 'readable' detector objects.
    num : int or None, optional
        Number of readings to take; default is 1. If None, capture data until canceled.
    delay : scalar or iterable, optional
        Time delay in seconds between successive readings; default is 0.
    per_shot : callable, optional
        Hook for customizing action of inner loop (messages per step).
        Expected signature:
            def f(detectors: Iterable[OphydObj]) -> Generator[Msg]
    md : dict, optional
        Metadata dictionary.

list_scan(detectors, *args, per_step=None, md=None)
    Scan over one or more variables in steps simultaneously (inner product).

    Parameters
    ----------
    detectors : list
        List of 'readable' detector objects.
    *args :
        Motor and position list pairs, e.g.:
            motor1, [point1, point2, ...],
            motor2, [point1, point2, ...],
            ...
    per_step : callable, optional
        Hook for customizing action of inner loop (messages per step).
        Expected signature:
            f(detectors, motor, step) -> plan (a generator)
    md : dict, optional
        Metadata dictionary.

list_grid_scan(detectors, *args, snake_axes=False, per_step=None, md=None)
    Scan over a mesh grid; each motor moves independently.

    Parameters
    ----------
    detectors : list
        List of 'readable' detector objects.
    *args :
        Motor and position list pairs, e.g.:
            motor1, [pos1, pos2, ...],
            motor2, [pos1, pos2, ...],
            ...
    snake_axes : bool or iterable, optional
        Which axes to snake (winding trajectory instead of simple left-to-right).
        Can be False (no snaking), True (snake all axes), or list of motors to snake.
    per_step : callable, optional
        Hook for customizing action of inner loop (messages per step).
    md : dict, optional
        Metadata dictionary.

Notes
-----

- All scanning functions accept a list of detectors to read data from.
- The `per_step` or `per_shot` callable parameters allow customization of the actions performed at each step or shot.
- Metadata dictionaries (`md`) can be passed to provide additional context or information about the scan.
- Relative scans automatically handle resetting and relative positioning of motors.
- The `snake_axes` parameter in grid scans allows for more efficient scanning patterns by snaking certain axes.
- The plans use decorators from the `preprocessors` module to stage devices and manage run lifecycles.
