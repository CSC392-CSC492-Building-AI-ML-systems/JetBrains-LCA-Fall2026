Generate Documentation for G-Functions
======================================

This module dynamically generates documentation for a collection of special functions and their associated formulas. Its primary purpose is to produce well-formatted mathematical expressions suitable for inclusion in Sphinx-generated documentation.

Overview
--------

Upon import, the module constructs a comprehensive docstring that categorizes and presents various functions and their defining equations. The documentation is organized into sections based on the types of functions involved:

- **Elementary functions:** Functions that do not involve any special function arguments.
- **Functions involving special functions:** Grouped by the specific special functions they include.

Function Categories and Presentation
------------------------------------

The module uses a lookup table to gather formulas and related information, which it then sorts and formats. Each category is introduced with a heading indicating the functions involved, using LaTeX-rendered names for clarity.

For each formula in a category, the documentation includes:

- The formula itself, expressed as a mathematical equation.
- The generated function or expression it corresponds to.
- Any conditions under which the formula holds, clearly indicated alongside the equation.

Mathematical Formatting
-----------------------

All mathematical content is rendered using LaTeX syntax to ensure high-quality typesetting in the final documentation. Equations are presented using the `.. math::` directive, enabling Sphinx to display them properly.

Example Output Structure
------------------------

The generated documentation follows a structure similar to the example below:

Elementary functions:

.. math::
  <formula_1> = <generated_expression_1>

.. math::
  <formula_2> = <generated_expression_2>, \text{ if } <condition>

Functions involving `\operatorname{func1}`, `\operatorname{func2}`:

.. math::
  <formula_3> = <generated_expression_3>

.. math::
  <formula_4> = <generated_expression_4>, \text{ if } <condition>

Usage
-----

This module is intended to be imported as part of the documentation build process. It does not provide runtime functionality beyond generating its own docstring, which is then incorporated into the Sphinx documentation.

Dependencies
------------

The module relies on several internal components:

- Core symbolic constructs (`Add`, `Eq`, `Symbol`)
- LaTeX printing utilities
- A lookup table creation function from the `meijerint` package
- Utility functions for sorting and organizing the documentation entries

Summary
-------

By automating the generation of detailed, well-formatted documentation for special functions and their formulas, this module facilitates maintaining accurate and readable mathematical references within the project’s documentation.
