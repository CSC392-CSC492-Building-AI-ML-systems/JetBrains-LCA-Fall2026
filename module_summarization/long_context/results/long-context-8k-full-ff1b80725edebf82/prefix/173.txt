SESANS Data Fitting
===================

Overview
--------

Spin-Echo Small Angle Neutron Scattering (SESANS) is a powerful technique used to probe the structure of materials at the nanoscale. Fitting SESANS data involves modeling the scattering behavior to extract meaningful physical parameters.

This documentation provides an overview of the fitting process, the parameters involved, and the conversion between different model formats, including compatibility with SasView models.

Parameters and Models
---------------------

The fitting process relies on a variety of parameters that describe the physical and geometrical properties of the sample. These parameters are used within different models to simulate the SESANS data.

- Parameters can be categorized by their type, such as volume, orientation, scattering length density (SLD), or others.
- Each parameter may be used in one or more models.
- Some parameters represent magnetic magnitudes or SLD values, which require special handling during conversion and scaling.

Listing Parameters
------------------

To list all parameters used across available models, a utility script is provided:

```bash
python -m sasmodels.list_pars [-v] [kind]
```

- The `-v` or `--verbose` flag lists the models that use each parameter.
- The optional `kind` argument filters parameters by type: `volume`, `orientation`, `sld`, `none`, or `any`.
- Without `-v`, only parameter names are listed.

This helps in identifying which parameters are relevant for a particular fitting scenario.

Model Conversion and Compatibility
----------------------------------

SESANS fitting models can be converted to and from SasView formats to ensure compatibility and reuse of existing models.

- Some models in SasView do not explicitly include parameters such as `scale` or `background`. These models are tracked in lists to handle conversions correctly.
- Magnetic models have specific considerations due to magnetic SLD parameters.
- Polydispersity information is translated between new and old style naming conventions to maintain consistency.

Scaling of Parameters
---------------------

Parameters representing scattering length densities (SLD) or magnetic magnitudes often require rescaling during conversion:

- Forward conversion typically scales SLD parameters by \(10^{6}\).
- Backward conversion scales by \(10^{-6}\).
- This ensures numerical stability and consistency across different software versions.

Mathematical Foundations
------------------------

The fitting process and model transformations rely on advanced mathematical functions, including elliptic integrals and special functions:

- Elliptic functions such as \( \text{sn}, \text{cn}, \text{dn} \) are used to describe complex transformations.
- The Guyou projection is implemented to convert between latitude-longitude coordinates and planar coordinates, which can be useful in certain model visualizations or transformations.
- These mathematical tools ensure accurate representation of the scattering phenomena and support complex model geometries.

Usage Example
-------------

To perform SESANS data fitting:

1. Identify the appropriate model and parameters for your sample.
2. Use the parameter listing utility to understand parameter usage.
3. Convert models if necessary to ensure compatibility with your fitting software.
4. Apply scaling to SLD or magnetic parameters as required.
5. Fit the SESANS data using the chosen model and extract physical parameters.
