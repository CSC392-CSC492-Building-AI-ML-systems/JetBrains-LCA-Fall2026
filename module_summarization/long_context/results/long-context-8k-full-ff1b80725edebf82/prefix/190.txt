Linear and Quadratic Discriminant Analysis
============================================

Linear Discriminant Analysis (LDA)
----------------------------------

Linear Discriminant Analysis is a classification method used in statistics, pattern recognition, and machine learning to find a linear combination of features that best separates two or more classes of objects or events. The resulting combination may be used as a linear classifier or, more commonly, for dimensionality reduction before classification.

LDA assumes that the different classes generate data based on Gaussian distributions with the same covariance matrix but different means. It models the posterior probabilities of the classes given the data by assuming class-conditional densities are normally distributed with a shared covariance matrix.

Key characteristics of LDA:

- Assumes normally distributed classes.
- Assumes equal covariance matrices for all classes.
- Finds a linear decision boundary between classes.
- Can be used for both classification and dimensionality reduction.
- Works well when the assumptions of normality and equal covariance hold.

Quadratic Discriminant Analysis (QDA)
-------------------------------------

Quadratic Discriminant Analysis is a generalization of Linear Discriminant Analysis that allows each class to have its own covariance matrix. This relaxation leads to quadratic decision boundaries, which can better model more complex class distributions.

QDA assumes that the data from each class are drawn from a Gaussian distribution with its own mean vector and covariance matrix. By estimating these parameters from the training data, QDA models the posterior probabilities of the classes given the data.

Key characteristics of QDA:

- Assumes normally distributed classes.
- Allows different covariance matrices for each class.
- Results in quadratic decision boundaries.
- More flexible than LDA but requires more parameters to be estimated.
- Can perform better than LDA when class covariances differ significantly.

Comparison and Usage
-------------------

| Feature                     | Linear Discriminant Analysis (LDA) | Quadratic Discriminant Analysis (QDA) |
|-----------------------------|-----------------------------------|---------------------------------------|
| Covariance assumption        | Shared covariance matrix           | Class-specific covariance matrices    |
| Decision boundary            | Linear                           | Quadratic                            |
| Number of parameters         | Fewer (simpler model)             | More (complex model)                  |
| Flexibility                 | Less flexible                    | More flexible                        |
| Sample size requirement      | Lower (due to fewer parameters)   | Higher (needs more data to estimate covariances) |
| Performance                 | Better when covariance matrices are similar | Better when covariance matrices differ |

Both LDA and QDA are widely used in classification problems where the classes are assumed to be normally distributed. The choice between LDA and QDA depends on the nature of the data and the trade-off between bias and variance.

Examples
--------

Using Linear Discriminant Analysis:

```python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=0)

lda = LinearDiscriminantAnalysis()
lda.fit(X_train, y_train)
y_pred = lda.predict(X_test)
```

Using Quadratic Discriminant Analysis:

```python
from sklearn.discriminant_analysis import QuadraticDiscriminantAnalysis
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=0)

qda = QuadraticDiscriminantAnalysis()
qda.fit(X_train, y_train)
y_pred = qda.predict(X_test)
```
