Permutation Feature Importance
==============================

Permutation feature importance is a model inspection technique that measures the importance of features by evaluating the increase in the prediction error of a model after permuting the feature’s values. This method provides insight into how much each feature contributes to the predictive performance of a fitted estimator.

Overview
--------

Given a fitted estimator and a dataset (which can be the training set or a separate validation set), the permutation importance of a feature is computed as follows:

1. Compute a baseline score of the estimator on the dataset using a specified scoring metric.
2. Permute the values of a single feature column in the dataset, breaking the relationship between that feature and the target.
3. Compute the score of the estimator on the permuted dataset.
4. The importance of the feature is defined as the difference between the baseline score and the score after permutation.

This process is repeated multiple times (controlled by `n_repeats`) to obtain a distribution of importance scores, allowing estimation of the mean importance and its variability.

Parameters
----------

- **estimator** : object  
  A fitted estimator compatible with the scoring function. The estimator must implement a `fit` method and be already trained.

- **X** : array-like or DataFrame of shape (n_samples, n_features)  
  The data on which permutation importance will be computed.

- **y** : array-like or None of shape (n_samples,) or (n_samples, n_classes)  
  Target values for supervised learning or `None` for unsupervised tasks.

- **scoring** : str, callable, list, tuple, dict, or None, default=None  
  The scoring metric(s) to evaluate the estimator. Can be a single string, a callable, or multiple scorers. If `None`, the estimator’s default scorer is used.

- **n_repeats** : int, default=5  
  Number of times to permute each feature to obtain a reliable estimate of importance.

- **n_jobs** : int or None, default=None  
  Number of parallel jobs to run for computing permutation scores. `None` means 1, `-1` uses all processors.

- **random_state** : int, RandomState instance, or None, default=None  
  Controls the randomness of feature permutations for reproducibility.

- **sample_weight** : array-like of shape (n_samples,), default=None  
  Sample weights used in scoring.

- **max_samples** : int or float, default=1.0  
  Number or fraction of samples to draw from `X` to compute feature importance in each repeat. Helps control computational cost on large datasets.

Returns
-------

- **result** : `sklearn.utils.Bunch` or dict of such instances  
  A dictionary-like object containing:

  - `importances_mean` : ndarray of shape (n_features,)  
    Mean importance of each feature over `n_repeats`.

  - `importances_std` : ndarray of shape (n_features,)  
    Standard deviation of importance scores over `n_repeats`.

  - `importances` : ndarray of shape (n_features, n_repeats)  
    Raw permutation importance scores for each repeat.

  If multiple scoring metrics are used, the result is a dictionary mapping scorer names to `Bunch` objects.

Usage Example
-------------

```python
from sklearn.linear_model import LogisticRegression
from sklearn.inspection import permutation_importance

X = [[1, 9, 9], [1, 9, 9], [1, 9, 9],
     [0, 9, 9], [0, 9, 9], [0, 9, 9]]
y = [1, 1, 1, 0, 0, 0]

clf = LogisticRegression().fit(X, y)
result = permutation_importance(clf, X, y, n_repeats=10, random_state=0)

print(result.importances_mean)
# array([0.4666..., 0.       , 0.       ])

print(result.importances_std)
# array([0.2211..., 0.       , 0.       ])
```

Notes
-----

- Permutation importance can be computed on the training data or on a separate validation set.
- The method is model-agnostic and works with any fitted estimator.
- Using `max_samples` less than the full dataset size can speed up computation at the cost of some accuracy.
- When multiple scoring metrics are provided, permutation importance is computed efficiently by reusing predictions.
