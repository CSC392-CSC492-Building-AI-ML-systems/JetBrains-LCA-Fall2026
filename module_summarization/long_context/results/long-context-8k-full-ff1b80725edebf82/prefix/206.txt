Support Vector Machines
=======================

Support Vector Machines (SVMs) are a set of supervised learning methods used for classification, regression, and outlier detection. They are powerful tools for both linear and non-linear data analysis, capable of handling high-dimensional spaces efficiently.

LinearSVC
---------

The `LinearSVC` class implements linear Support Vector Classification using the `liblinear` library. It is similar to the `SVC` class with a linear kernel but offers more flexibility in the choice of penalties and loss functions, and generally scales better to large datasets.

Key features of `LinearSVC` include:

- Supports both dense and sparse input data.
- Handles multiclass classification using a one-vs-the-rest scheme.
- Provides options for different penalties (`l1` or `l2`) and loss functions (`hinge` or `squared_hinge`).
- Allows automatic selection of the dual or primal optimization problem solver via the `dual` parameter.
- Supports fitting an intercept with customizable scaling.
- Offers class weighting to handle imbalanced datasets.
- Includes verbose output and random state control for reproducibility.
- Efficient implementation suitable for large-scale problems.

Parameters
~~~~~~~~~~

- **penalty** : {'l1', 'l2'}, default='l2'  
  Specifies the norm used in the penalization. The 'l2' penalty is standard, while 'l1' leads to sparse coefficient vectors.

- **loss** : {'hinge', 'squared_hinge'}, default='squared_hinge'  
  Specifies the loss function. 'hinge' is the classic SVM loss; 'squared_hinge' is its squared variant.

- **dual** : "auto" or bool, default=True  
  Selects whether to solve the dual or primal optimization problem. The `"auto"` option chooses based on data shape and parameters.

- **tol** : float, default=1e-4  
  Tolerance for stopping criteria.

- **C** : float, default=1.0  
  Regularization parameter; the inverse of regularization strength.

- **multi_class** : {'ovr', 'crammer_singer'}, default='ovr'  
  Strategy for multiclass classification. `"ovr"` trains one-vs-rest classifiers; `"crammer_singer"` optimizes a joint objective.

- **fit_intercept** : bool, default=True  
  Whether to fit an intercept term.

- **intercept_scaling** : float, default=1.0  
  Scaling of the synthetic feature appended for the intercept.

- **class_weight** : dict or 'balanced', default=None  
  Weights associated with classes to handle class imbalance.

- **verbose** : int, default=0  
  Enables verbose output.

- **random_state** : int, RandomState instance or None, default=None  
  Controls randomness for shuffling during optimization.

- **max_iter** : int, default=1000  
  Maximum number of iterations.

Attributes
~~~~~~~~~~

- **coef_** : ndarray of shape (n_classes, n_features) or (1, n_features)  
  Weights assigned to the features.

- **intercept_** : ndarray of shape (n_classes,) or (1,)  
  Intercept terms.

- **classes_** : ndarray of shape (n_classes,)  
  Unique class labels.

- **n_iter_** : int  
  Number of iterations run.

Usage Example
~~~~~~~~~~~~~

```python
from sklearn.svm import LinearSVC
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import make_classification

X, y = make_classification(n_features=4, random_state=0)
clf = make_pipeline(StandardScaler(),
                    LinearSVC(dual="auto", random_state=0, tol=1e-5))
clf.fit(X, y)

print(clf.named_steps['linearsvc'].coef_)
print(clf.named_steps['linearsvc'].intercept_)
print(clf.predict([[0, 0, 0, 0]]))
```

LinearSVR
---------

The `LinearSVR` class implements linear Support Vector Regression using `liblinear`. It is similar to `SVR` with a linear kernel but offers more flexibility and better scalability for large datasets.

Key features of `LinearSVR` include:

- Supports both dense and sparse input data.
- Provides options for different loss functions (`epsilon_insensitive` and `squared_epsilon_insensitive`).
- Allows automatic selection of the dual or primal optimization problem solver.
- Supports fitting an intercept with customizable scaling.
- Includes verbose output and random state control for reproducibility.

Parameters
~~~~~~~~~~

- **epsilon** : float, default=0.0  
  Epsilon parameter in the epsilon-insensitive loss function.

- **tol** : float, default=1e-4  
  Tolerance for stopping criteria.

- **C** : float, default=1.0  
  Regularization parameter.

- **loss** : {'epsilon_insensitive', 'squared_epsilon_insensitive'}, default='epsilon_insensitive'  
  Specifies the loss function.

- **fit_intercept** : bool, default=True  
  Whether to fit an intercept term.

- **intercept_scaling** : float, default=1.0  
  Scaling of the synthetic feature appended for the intercept.

- **dual** : "auto" or bool, default=True  
  Selects whether to solve the dual or primal optimization problem.

- **verbose** : int, default=0  
  Enables verbose output.

- **random_state** : int, RandomState instance or None, default=None  
  Controls randomness for shuffling during optimization.

- **max_iter** : int, default=1000  
  Maximum number of iterations.

Attributes
~~~~~~~~~~

- **coef_** : ndarray of shape (n_features,)  
  Weights assigned to the features.

- **intercept_** : float  
  Intercept term.

Notes
-----

- `LinearSVC` and `LinearSVR` use `liblinear` internally, which is optimized for linear problems and large datasets.
- The choice between `dual=True` or `dual=False` depends on the shape of the data and the loss function.
- The intercept term is handled by appending a synthetic feature scaled by `intercept_scaling`.
- Results may vary slightly due to the use of random number generators in the optimization process.

For more detailed information, refer to the User Guide sections on SVM classification and regression.
