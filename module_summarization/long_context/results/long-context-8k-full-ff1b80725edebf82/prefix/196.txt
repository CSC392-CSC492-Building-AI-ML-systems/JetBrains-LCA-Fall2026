Multi-class and Multi-output Algorithms
=======================================

Overview
--------

Scikit-learn provides meta-estimators to extend single-output estimators to handle multi-output regression and classification problems. These meta-estimators fit one estimator per target variable, enabling support for multi-target tasks even when the base estimator does not natively support them.

The main meta-estimators for multi-output tasks are:

- **MultiOutputRegressor**: Extends regressors to multi-output regression.
- **MultiOutputClassifier**: Extends classifiers to multi-output classification.
- **RegressorChain** and **ClassifierChain**: Chain models that arrange regressions or classifications into a sequence, where each model in the chain uses the predictions of previous models as additional features.

MultiOutputRegressor
--------------------

`MultiOutputRegressor` is a simple strategy for multi-target regression. It fits one regressor per target variable independently.

**Parameters**

- `estimator` : estimator object  
  An estimator implementing `fit` and `predict`.

- `n_jobs` : int or None, default=None  
  The number of jobs to run in parallel for fitting and predicting each target.  
  - `None` means 1 unless in a `joblib.parallel_backend` context.  
  - `-1` means using all available processors.

**Attributes**

- `estimators_` : list of estimators  
  The list of fitted estimators, one per output.

- `n_features_in_` : int  
  Number of features seen during fit (if supported by the base estimator).

- `feature_names_in_` : ndarray of shape (`n_features_in_`,)  
  Names of features seen during fit (if supported by the base estimator).

**Methods**

- `fit(X, y, sample_weight=None, **fit_params)`  
  Fit the model to data, separately for each output variable.

- `partial_fit(X, y, sample_weight=None, **partial_fit_params)`  
  Incrementally fit the model to data for each output variable (if supported by the base estimator).

- `predict(X)`  
  Predict multi-output targets using the fitted models.

**Example**

```python
from sklearn.datasets import load_linnerud
from sklearn.multioutput import MultiOutputRegressor
from sklearn.linear_model import Ridge

X, y = load_linnerud(return_X_y=True)
regr = MultiOutputRegressor(Ridge(random_state=123)).fit(X, y)
print(regr.predict(X[[0]]))
```

MultiOutputClassifier
---------------------

`MultiOutputClassifier` extends classifiers to multi-output classification by fitting one classifier per target variable independently.

**Parameters**

- `estimator` : estimator object  
  An estimator implementing `fit` and `predict`.  
  A `predict_proba` method will be exposed only if the base estimator implements it.

- `n_jobs` : int or None, default=None  
  The number of jobs to run in parallel for fitting and predicting each target.

**Attributes**

- `classes_` : ndarray of shape (n_classes,)  
  Class labels.

- `estimators_` : list of estimators  
  The list of fitted estimators, one per output.

- `n_features_in_` : int  
  Number of features seen during fit (if supported by the base estimator).

- `feature_names_in_` : ndarray of shape (`n_features_in_`,)  
  Names of features seen during fit (if supported by the base estimator).

**Methods**

- `fit(X, y, sample_weight=None, **fit_params)`  
  Fit the model to data, separately for each output variable.

- `partial_fit(X, y, sample_weight=None, **partial_fit_params)`  
  Incrementally fit the model to data for each output variable (if supported by the base estimator).

- `predict(X)`  
  Predict multi-output targets using the fitted models.

MultiOutput Estimators: Common Characteristics
----------------------------------------------

- These meta-estimators require a base estimator that implements `fit` and `predict`.
- They fit one estimator per output variable independently.
- Parallelization is supported via the `n_jobs` parameter to speed up fitting and prediction.
- Support for incremental learning via `partial_fit` is available if the base estimator supports it.
- Sample weights can be passed to the base estimators if supported.
- The output of `predict` is an array of shape `(n_samples, n_outputs)`.

Metadata Routing
----------------

Starting from version 1.3, multi-output estimators support metadata routing, allowing parameters to be passed selectively to the underlying estimators' methods such as `fit` and `partial_fit`. This advanced feature enables fine-grained control over the fitting process.

See the :ref:`User Guide <metadata_routing>` for more details.
