Tuning the hyper-parameters of an estimator
============================================

When building predictive models, selecting the right hyper-parameters for an estimator is crucial to achieve optimal performance. Hyper-parameter tuning involves searching for the best combination of parameters that maximize the model’s predictive accuracy on unseen data.

Grid Search
-----------

Grid search is a widely used method for hyper-parameter tuning. It exhaustively considers all parameter combinations specified in a grid and evaluates each using cross-validation. This approach ensures that the best performing parameters are found within the predefined search space.

Key Concepts
~~~~~~~~~~~~

- **Estimator**: The machine learning model whose hyper-parameters are to be tuned.
- **Parameter Grid**: A dictionary specifying the hyper-parameters and the list of values to try for each.
- **Cross-validation**: A technique to assess the generalization performance of the model by splitting the data into training and validation sets multiple times.
- **Scoring**: The metric used to evaluate the performance of the model on the validation sets.

Using Grid Search
~~~~~~~~~~~~~~~~~

The typical workflow for tuning hyper-parameters using grid search involves:

1. **Defining the parameter grid**: Specify the hyper-parameters and their candidate values.
2. **Selecting the estimator**: Choose the model to tune.
3. **Performing grid search with cross-validation**: Evaluate each parameter combination using cross-validation.
4. **Selecting the best parameters**: Identify the combination that yields the highest cross-validation score.
5. **Refitting the estimator**: Train the model on the entire training set using the best parameters.

Visualization of Model Performance
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Visual tools such as learning curves and validation curves can help understand how the model performance varies with different training set sizes or hyper-parameter values.

- **Learning Curve**: Shows the training and validation scores as a function of the number of training samples. It helps diagnose whether the model suffers from high bias or variance.
- **Validation Curve**: Displays the training and validation scores as a function of a hyper-parameter value, helping to identify underfitting or overfitting.

Example: Learning Curve Visualization
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The `LearningCurveDisplay` class provides a convenient way to visualize learning curves. It can be created from an estimator and dataset, and supports customization of the plot appearance.

```python
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.model_selection import LearningCurveDisplay, learning_curve
from sklearn.tree import DecisionTreeClassifier

X, y = load_iris(return_X_y=True)
tree = DecisionTreeClassifier(random_state=0)

train_sizes, train_scores, test_scores = learning_curve(tree, X, y)

display = LearningCurveDisplay(
    train_sizes=train_sizes,
    train_scores=train_scores,
    test_scores=test_scores,
    score_name="Accuracy"
)
display.plot()
plt.show()
```

Parameters of `LearningCurveDisplay.plot` include options to control the score negation (useful for error metrics), the type of scores to plot (training, test, or both), and the style for displaying standard deviation (error bars or shaded regions).

Best Practices
~~~~~~~~~~~~~~

- Use cross-validation to reliably estimate model performance.
- Define a reasonable parameter grid to balance thoroughness and computational cost.
- Visualize learning and validation curves to gain insights into model behavior.
- Consider incremental learning or parallel processing to speed up grid search when supported by the estimator.

By systematically tuning hyper-parameters and analyzing model performance, grid search helps in building robust and accurate predictive models.
