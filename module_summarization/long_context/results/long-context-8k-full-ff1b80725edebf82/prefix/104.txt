Diophantine Equations Module
=============================

Overview
--------

This module provides tools for solving Diophantine equations, which are polynomial equations where integer solutions are sought. It includes functions to classify Diophantine equations by type, solve various classes of these equations, and handle equations involving multiple variables and factors.

Key Features
------------

- Classification of Diophantine equations into known types such as linear, binary quadratic, homogeneous ternary quadratic, general Pythagorean, and more.
- Solvers for linear Diophantine equations, quadratic equations, ternary quadratic forms, and sums of squares.
- Ability to handle factored equations by solving each factor independently and merging solutions.
- Support for parametric solutions using integer parameters.
- Utilities for simplifying and manipulating polynomial expressions relevant to Diophantine problems.

diophantine(eq, param=symbols('t', integer=True), syms=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Simplify and solve a Diophantine equation by factoring it into terms and solving each term independently.

Parameters
^^^^^^^^^^

- eq : Relational or Expr  
  The Diophantine equation to solve.
- param : Symbol, optional  
  The parameter symbol to use in parametric solutions (default is an integer symbol 't').
- syms : list of Symbol, optional  
  Specifies the order of variables in the returned solution tuples.

Returns
^^^^^^^

A set of tuples representing solutions. Each tuple contains solutions for the variables in alphabetical order or as specified by `syms`.

Examples
^^^^^^^^

>>> diophantine(x**2 - y**2)
{(t_0, -t_0), (t_0, t_0)}

>>> diophantine(x*(2*x + 3*y - z))
{(0, n1, n2), (t_0, t_1, 2*t_0 + 3*t_1)}

diop_solve(eq, param=symbols('t', integer=True))
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Solve a Diophantine equation without factoring, by classifying the equation type and applying the appropriate solver.

Parameters
^^^^^^^^^^

- eq : Expr  
  The Diophantine equation assumed to be zero.
- param : Symbol, optional  
  Parameter symbol for parametric solutions.

Returns
^^^^^^^

A solution or set of solutions depending on the equation type.

Examples
^^^^^^^^

>>> diop_solve(2*x + 3*y - 5)
(3*t_0 - 5, -2*t_0 + 5)

>>> diop_solve(x**2 + y**2 - 5)
{(-2, -1), (-2, 1), (-1, -2), (-1, 2), (1, -2), (1, 2), (2, -1), (2, 1)}

classify_diop(eq, _dict=True)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Classify a Diophantine equation by its type, variables, and coefficients.

Parameters
^^^^^^^^^^

- eq : Expr  
  The Diophantine equation assumed to be zero.

Returns
^^^^^^^

A tuple `(variables, coefficients, diophantine_type)` where:

- `variables` is a list of free symbols sorted alphabetically.
- `coefficients` is a dictionary mapping terms to integer coefficients.
- `diophantine_type` is a string indicating the type of the equation.

Known types include:

- binary_quadratic
- cubic_thue
- general_pythagorean
- general_sum_of_even_powers
- general_sum_of_squares
- homogeneous_general_quadratic
- homogeneous_ternary_quadratic
- homogeneous_ternary_quadratic_normal
- inhomogeneous_general_quadratic
- inhomogeneous_ternary_quadratic
- linear
- univariate

Examples
^^^^^^^^

>>> classify_diop(4*x + 6*y - 4)
([x, y], {1: -4, x: 4, y: 6}, 'linear')

>>> classify_diop(x**2 + y**2 - x*y + x + 5)
([x, y], {1: 5, x: 1, x**2: 1, y**2: 1, x*y: -1}, 'binary_quadratic')


diop_linear(eq, param=symbols('t', integer=True))
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Solve linear Diophantine equations of the form:

.. math::

    a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = 0

Parameters
^^^^^^^^^^

- eq : Expr  
  A linear Diophantine equation assumed to be zero.
- param : Symbol, optional  
  Parameter symbol for parametric solutions.

Returns
^^^^^^^

A tuple representing the parametric solution for the variables.

Examples
^^^^^^^^

>>> diop_linear(2*x - 3*y - 5)
(3*t_0 - 5, 2*t_0 - 5)

>>> diop_linear(2*x - 3*y - 4*z - 3)
(t_0, 2*t_0 + 4*t_1 + 3, -t_0 - 3*t_1 - 3)

Internal Utilities
------------------

- `_is_int(i)`  
  Checks if `i` can be interpreted as an integer.

- `_sorted_tuple(*i)`  
  Returns a sorted tuple of the inputs.

- `_remove_gcd(*x)`  
  Removes the greatest common divisor from a tuple of integers.

- `_rational_pq(a, b)`  
  Returns a tuple `(numerator, denominator)` for the rational number `a/b` with sign in numerator and gcd removed.

- `_nint_or_floor(p, q)`  
  Returns the nearest integer to `p/q`, breaking ties by flooring.

- `_odd(i)` and `_even(i)`  
  Check if an integer is odd or even.

- `merge_solution(var, var_t, solution)`  
  Merges partial solutions from factored equations into a full solution tuple, introducing new integer parameters as needed.

Known Diophantine Equation Types
-------------------------------

The module recognizes and handles the following types of Diophantine equations:

- binary_quadratic  
- cubic_thue  
- general_pythagorean  
- general_sum_of_even_powers  
- general_sum_of_squares  
- homogeneous_general_quadratic  
- homogeneous_ternary_quadratic  
- homogeneous_ternary_quadratic_normal  
- inhomogeneous_general_quadratic  
- inhomogeneous_ternary_quadratic  
- linear  
- univariate

Notes
-----

- The module assumes all coefficients in the equations are integers.
- Parametric solutions use integer parameters by default.
- Some equation types may not yet have implemented solvers and will raise `NotImplementedError`.
- Factoring is attempted in `diophantine()` to simplify solving, but `diop_solve()` works on unfactored equations.

Examples
--------

>>> from diofant.abc import x, y, z
>>> diophantine(x**2 + y**2 - z**2)
{(t_0**2 - t_1**2, 2*t_0*t_1, t_0**2 + t_1**2)}

>>> diop_solve(2*x + 3*y - 5)
(3*t_0 - 5, -2*t_0 + 5)

>>> classify_diop(x**2 + y**2 - 1)
([x, y], {1: -1, x**2: 1, y**2: 1}, 'binary_quadratic')
