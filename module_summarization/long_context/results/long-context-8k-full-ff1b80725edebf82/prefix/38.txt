Examples and Usage
==================

This section provides examples and usage guidelines for the various field types available in Tortoise ORM. Fields define the schema of your models and map Python types to database column types.

Basic Field Usage
-----------------

All fields inherit from the base `Field` class and share common parameters:

- `source_field`: Specify a custom database column name.
- `generated`: Indicates if the field is generated by the database.
- `pk`: Marks the field as a Primary Key.
- `null`: Allows the field to be nullable.
- `default`: Default value or callable for dynamic defaults.
- `unique`: Enforces uniqueness on the field.
- `index`: Adds an index on the field.
- `description`: Optional description for the field.

Example:

```python
from tortoise import fields
from tortoise.models import Model

class User(Model):
    id = fields.IntField(pk=True)
    username = fields.CharField(max_length=50, unique=True)
    email = fields.CharField(max_length=255, null=True)
    is_active = fields.BooleanField(default=True)
```

Integer Fields
--------------

- `IntField`: 32-bit signed integer.
- `BigIntField`: 64-bit signed integer.
- `SmallIntField`: 16-bit signed integer.

Primary keys can be auto-generated by setting `pk=True`. These fields support database-generated values and have constraints on their value ranges.

Example:

```python
class Product(Model):
    id = fields.BigIntField(pk=True)
    stock = fields.IntField(default=0)
    rating = fields.SmallIntField(null=True)
```

Character Fields
----------------

- `CharField`: Fixed-length character field. Requires `max_length`.
- `TextField`: Large text field, not indexable or unique.

Example:

```python
class Article(Model):
    title = fields.CharField(max_length=200)
    content = fields.TextField()
```

Boolean Field
-------------

- `BooleanField`: Stores boolean values.

Example:

```python
class FeatureToggle(Model):
    name = fields.CharField(max_length=100)
    enabled = fields.BooleanField(default=False)
```

Decimal Field
-------------

- `DecimalField`: Stores decimal numbers with precision. Requires `max_digits` and `decimal_places`.

Example:

```python
class Invoice(Model):
    amount = fields.DecimalField(max_digits=10, decimal_places=2)
```

Field Constraints and Validation
--------------------------------

Fields provide constraints that can be used for validation or schema generation. For example, integer fields specify minimum and maximum values, and character fields specify maximum length.

Example:

```python
field = fields.IntField()
print(field.constraints)  # {'ge': -2147483648, 'le': 2147483647}
```

Database Dialect Overrides
--------------------------

Fields support per-database dialect overrides for SQL types and generation SQL. You can customize behavior for specific databases by defining inner classes named `_db_{dialect}`.

Example:

```python
class CustomIntField(fields.IntField):
    class _db_sqlite:
        SQL_TYPE = "INTEGER"
```

Serialization and Description
-----------------------------

Fields provide a `describe()` method that returns a dictionary describing the field, useful for introspection or generating JSON schemas.

Example:

```python
field = fields.CharField(max_length=100, null=True, default="N/A")
description = field.describe(serializable=True)
print(description)
```

This will output a dictionary with keys such as `name`, `field_type`, `db_column`, `python_type`, `nullable`, `default`, and more.

Advanced Usage
--------------

- Use `default` with a callable for dynamic default values.
- Use `unique=True` to enforce uniqueness.
- Use `index=True` to add database indexes.
- Use `pk=True` to designate primary keys.
- Use `null=True` to allow nullable fields.

Example with dynamic default:

```python
import datetime

class Event(Model):
    created_at = fields.DatetimeField(default=datetime.datetime.utcnow)
```

Summary
-------

Tortoise ORM fields provide a rich set of options to define your model schema with support for various data types, constraints, and database-specific customizations. Use the appropriate field type and parameters to model your data accurately and efficiently.
