cubes Module Documentation
==========================

Overview
--------

The `cubes` module provides interactive plotting capabilities for spectral data cubes, enabling users to visualize maps and spectra in an integrated and user-friendly manner. It is designed primarily for exploratory data analysis rather than publication-quality figures, although it leverages the `APLpy` package to allow for high-quality plotting when desired.

Key Features
------------

- Interactive map plotting of spectral cubes with mouse and keyboard controls.
- Integration with spectrum plotting, allowing users to click on map pixels to view corresponding spectra.
- Support for various map projections and plotting conventions.
- Ability to average spectra over circular apertures defined interactively.
- Overplotting multiple spectra with customizable colors and styles.
- Compatibility with FITS headers and World Coordinate System (WCS) information.
- Optional use of `APLpy` for enhanced plotting features.

Dependencies
------------

- `numpy`
- `matplotlib`
- `astropy` (for WCS and FITS handling, if available)
- `aplpy` (optional, for advanced plotting)
- `six` (for Python 2 and 3 compatibility)

Main Classes and Functions
--------------------------

### MapPlotter

The primary class in the module, `MapPlotter`, manages the creation and interactive display of maps derived from spectral cubes. It connects map visualization with spectrum plotting, allowing users to explore data intuitively.

#### Initialization

```python
MapPlotter(Cube=None, figure=None, doplot=False, **kwargs)
```

- `Cube`: A spectral cube object containing the data and metadata.
- `figure`: A `matplotlib.figure.Figure` instance or an integer figure number where the map will be plotted.
- `doplot`: If `True`, automatically generates the map plot upon initialization.
- Additional keyword arguments are passed to the plotting methods.

#### Methods

- `mapplot(convention='calabretta', colorbar=True, useaplpy=True, vmin=None, vmax=None, cmap=None, plotkwargs={}, **kwargs)`

  Generates the map plot from the cube data. Supports customization of color scales, colormaps, and plotting conventions.

- `makeplane(estimator=np.nanmean)`

  Creates a 2D map ("plane") from the 3D cube data by applying an estimator function along the spectral axis. Supports various estimators including maximum, integration, slicing, or loading from external FITS files.

- `click(event)`

  Records the location of mouse clicks on the map for interactive operations.

- `plot_spectrum(event, plot_fit=True)`

  Handles mouse and keyboard events to plot spectra corresponding to selected map pixels or regions. Supports overplotting and interactive aperture definition.

- `circle(x1, y1, x2, y2, **kwargs)`

  Plots the spectrum averaged over a circular aperture defined by two points.

- `copy(parent=None)`

  Creates a shallow copy of the `MapPlotter` instance with uninitialized plotting axes and figure, optionally associating it with a new cube parent.

Interactive Controls
--------------------

- **Left Mouse Button (Button 1) or '1' key**: Plot the spectrum at the clicked pixel, marking the location with an 'x'.
- **Middle Mouse Button (Button 2) or 'o' key**: Overplot additional spectra from selected pixels.
- **Right Mouse Button (Button 3)**: Disconnect the interactive viewer.
- **'c' key**: Set the center of a circular aperture.
- **'r' key**: Set the radius of the circular aperture and plot the averaged spectrum.

Usage Notes
-----------

- The module attempts to use `astropy.wcs` and `astropy.io.fits` for WCS and FITS file handling; if unavailable, it falls back to older `pywcs` and `pyfits` packages.
- If `aplpy` is installed and enabled, it is used for map plotting to provide enhanced visualization features including colorbars and coordinate overlays.
- The module is intended for interactive data exploration and may not produce publication-ready figures without further customization.
- The `Cube` object passed to `MapPlotter` is expected to have attributes such as `cube` (the data array), `header` (FITS header), `xarr` (spectral axis), and optionally `parcube` (parameter cube).
