Regression Models
=================

This module provides implementations of several standard regression models including:

- Generalized Least Squares (GLS)
- Ordinary Least Squares (OLS)
- Weighted Least Squares (WLS)
- Generalized Least Squares with autoregressive error terms (GLSAR)

These models are specified with an endogenous response variable and an exogenous design matrix, and are fit using their `fit` method. Subclasses that require more complex covariance structures can override the `whiten` method, as the `fit` method prewhitens the response by calling `whiten`.

General references for regression models include:

- Montgomery, D. C. and E. A. Peck. *Introduction to Linear Regression Analysis*, 2nd Ed., Wiley, 1992.
- Davidson, R. and J. G. MacKinnon. *Econometric Theory and Methods*, Oxford, 2004.
- Green, W. *Econometric Analysis*, 5th Ed., Pearson, 2003.

Quantile Regression
-------------------

The module also includes an implementation of Quantile Regression via the `QuantReg` class. Quantile regression estimates conditional quantiles of the response variable, providing a more complete view of possible causal relationships between variables than mean regression.

### QuantReg Class

The `QuantReg` class estimates a quantile regression model using iterative reweighted least squares (IRLS). Model parameters are estimated by minimizing the weighted sum of absolute residuals, allowing for robust estimation of conditional quantiles.

#### Parameters

- `endog` : array-like or DataFrame  
  The endogenous or response variable.
  
- `exog` : array-like or DataFrame  
  The exogenous or explanatory variables.

#### Notes

- The Least Absolute Deviation (LAD) estimator is a special case of quantile regression where the quantile `q` is set to 0.5.
- The asymptotic covariance matrix of the parameter estimates is computed using kernel density estimation, with options for different kernels and bandwidth selection methods.

#### Fit Method

The `fit` method solves the quantile regression problem using iterative weighted least squares.

##### Parameters

- `q` : float, default 0.5  
  The quantile to be estimated, must be between 0 and 1.
  
- `vcov` : str, default 'robust'  
  Method to calculate the variance-covariance matrix of the parameters. Options:
  - `'robust'`: heteroskedasticity robust standard errors (recommended).
  - `'iid'`: assumes independent and identically distributed errors.
  
- `kernel` : str, default 'epa'  
  Kernel function used in kernel density estimation for the asymptotic covariance matrix. Options include:
  - `'epa'`: Epanechnikov kernel
  - `'cos'`: Cosine kernel
  - `'gau'`: Gaussian kernel
  - `'par'`: Parzen kernel
  
- `bandwidth` : str, default 'hsheather'  
  Bandwidth selection method for kernel density estimation. Options:
  - `'hsheather'`: Hall-Sheather method
  - `'bofinger'`: Bofinger method
  - `'chamberlain'`: Chamberlain method
  
- `max_iter` : int, default 1000  
  Maximum number of iterations for the IRLS algorithm.
  
- `p_tol` : float, default 1e-6  
  Convergence tolerance for parameter estimates.

##### Returns

A `RegressionResultsWrapper` instance containing the fitted model results.

#### References

- Birkes, D. and Y. Dodge (1993). *Alternative Methods of Regression*, John Wiley and Sons.
- Greene, W. H. (2008). *Econometric Analysis*, 6th Edition.
- Koenker, R. (2005). *Quantile Regression*, Cambridge University Press.
- LeSage, J. P. (1999). *Applied Econometrics Using MATLAB*.
- Bofinger, E. (1975). Estimation of a density function using order statistics. *Australian Journal of Statistics*, 17: 1-17.
- Chamberlain, G. (1994). Quantile regression, censoring, and the structure of wages. In *Advances in Econometrics*, Vol. 1: Sixth World Congress.
- Hall, P., and S. Sheather (1988). On the distribution of the Studentized quantile. *Journal of the Royal Statistical Society*, Series B, 50: 381-391.

### QuantRegResults Class

The `QuantRegResults` class encapsulates the results of a quantile regression fit. It provides methods and properties such as:

- `prsquared`: Pseudo R-squared measure for quantile regression.
- `summary()`: Generates a detailed summary of the regression results including parameter estimates, standard errors, and diagnostic information.

Note that traditional statistics such as AIC, BIC, log-likelihood, and R-squared are not defined for quantile regression and return `NaN`.

Kernel Functions and Bandwidth Selection
---------------------------------------

Several kernel functions are implemented for use in kernel density estimation of the asymptotic covariance matrix:

- Biweight (biw)
- Cosine (cos)
- Epanechnikov (epa)
- Gaussian (gau)
- Parzen (par)

Bandwidth selection methods include:

- Hall-Sheather (hsheather)
- Bofinger (bofinger)
- Chamberlain (chamberlain)

These kernels and bandwidth selectors are used internally by the `QuantReg.fit` method.

Warnings and Convergence
------------------------

The iterative weighted least squares algorithm includes checks for convergence and may issue warnings if:

- The maximum number of iterations is reached without convergence.
- A convergence cycle is detected, indicating potential numerical issues.

Summary
-------

This module provides robust and flexible tools for regression analysis, including classical linear regression models and advanced quantile regression techniques. It supports heteroskedasticity-robust inference and offers detailed result summaries to facilitate econometric analysis and interpretation.
