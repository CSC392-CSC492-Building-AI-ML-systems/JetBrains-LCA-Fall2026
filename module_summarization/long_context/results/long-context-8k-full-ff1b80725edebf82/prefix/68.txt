Gaussian Process Kernels
========================

This module provides a collection of kernels for Gaussian process regression and classification. The kernels support kernel engineering, allowing them to be combined using addition ("+") and multiplication ("*") operators, as well as exponentiation with a scalar ("**"). Scalar values in these expressions are automatically converted to constant kernels.

All kernels support analytic gradient-based hyperparameter optimization. The hyperparameter search space is rectangular and can be specified by providing lower and upper bounds for each hyperparameter. Alternatively, hyperparameters can be fixed to exclude them from optimization.

Kernel Hyperparameters
----------------------

Hyperparameters are specified using the `Hyperparameter` class, which encapsulates the name, type, bounds, number of elements, and whether the hyperparameter is fixed. This allows flexible specification of scalar or vector-valued hyperparameters with bounds or fixed values.

Base Kernel Class
-----------------

The `Kernel` class is the abstract base class for all kernels. It provides:

- Parameter management via `get_params` and `set_params`.
- Cloning with specified hyperparameters.
- Properties for the number of non-fixed hyperparameters (`n_dims`), the list of hyperparameter specifications (`hyperparameters`), the flattened and log-transformed hyperparameters (`theta`), and their bounds (`bounds`).
- Operator overloading to combine kernels using addition, multiplication, and exponentiation.
- Abstract methods to evaluate the kernel, compute the diagonal of the kernel matrix, and check if the kernel is stationary.
- Support for nested kernels and hyperparameter optimization warnings.

Kernel Mixins
-------------

Several mixin classes provide additional kernel behaviors:

- `NormalizedKernelMixin`: For kernels normalized such that k(X, X) = 1.
- `StationaryKernelMixin`: For stationary kernels where k(X, Y) depends only on X - Y.
- `GenericKernelMixin`: For kernels operating on generic objects (e.g., sequences, trees, graphs) rather than fixed-length feature vectors.

Compound Kernels
----------------

The `CompoundKernel` class allows composition of multiple kernels into a single kernel. This enables building complex kernels by combining simpler ones.

Usage Example
-------------

```python
from sklearn.gaussian_process.kernels import ConstantKernel, RBF, CompoundKernel

# Define individual kernels
constant_kernel = ConstantKernel(constant_value=1.0, constant_value_bounds=(0.0, 10.0))
rbf_kernel = RBF(length_scale=1.0)

# Combine kernels
compound_kernel = CompoundKernel([constant_kernel, rbf_kernel])

# Access hyperparameters
for hyperparameter in compound_kernel.hyperparameters:
    print(hyperparameter)

# Get kernel parameters
params = compound_kernel.get_params()
print(params)
```

Summary
-------

This module provides a flexible and extensible framework for defining kernels used in Gaussian process models. It supports kernel composition, hyperparameter optimization, and customization for various data types and kernel properties.
