w_bins Command
==============

Overview
--------
The `w_bins` command is a tool for displaying information and statistics about binning in a WEST simulation, as well as modifying the binning for the current iteration of a WEST simulation.

This command provides two primary subcommands:

- `info`: Display information about the current binning.
- `rebin`: Rebuild the current iteration with new binning.

Usage
-----

```
w_bins <subcommand> [options]
```

Subcommands
-----------

### info

Display information about binning for a specified iteration.

**Options:**

- `-n`, `--n-iter` *N_ITER*  
  Consider initial points of segment *N_ITER*. Defaults to the current iteration if not specified.

- `--detail`  
  Display detailed per-bin information in addition to summary information.

- Binning options inherited from the binning component (e.g., specifying bin definitions).

This command prints bin information including bin counts and weights for the specified iteration.

### rebin

Rebuild the current iteration with new binning.

**Options:**

- `--confirm`  
  Commit the revised iteration to the HDF5 file. Without this option, the effects of the new binning are only calculated and printed but not saved.

- `--detail`  
  Display detailed per-bin information in addition to summary information.

- `-n`, `--n-iter` *N_ITER*  
  Consider initial points of segment *N_ITER*. Defaults to the current iteration if not specified.

- Binning options inherited from the binning component, except `--bins-from-file` is suppressed.

- Target count options for specifying desired bin target counts.

**Notes:**

- Rebinning is not supported for the first iteration. Attempting to rebin iteration 1 will result in an error message advising to reinitialize with `w_init` instead.

- When confirmed, the new binning is saved to the simulation data, and the iteration is rebuilt accordingly.

Description
-----------

The `w_bins` tool interacts with WESTPA simulation data to provide insights into the binning scheme used to categorize simulation segments. It can display summary and detailed statistics about bins, including counts and weights of segments assigned to each bin.

The `info` subcommand reads the binning information for a specified iteration and outputs bin assignments and statistics.

The `rebin` subcommand allows users to apply a new binning scheme to the current iteration, recalculating segment assignments and optionally committing these changes to the simulation data. This is useful for adjusting bin definitions dynamically during a simulation.

Examples
--------

Display bin information for the current iteration with summary statistics:

```
w_bins info
```

Display detailed bin information for iteration 10:

```
w_bins info -n 10 --detail
```

Rebin the current iteration with new bin definitions, showing detailed bin statistics but not saving changes:

```
w_bins rebin --detail --bins <binning options>
```

Rebin iteration 15 and commit the changes:

```
w_bins rebin -n 15 --confirm --bins <binning options> --target-counts <counts>
```

Logging
-------

The tool logs messages under the logger name `w_bins`, which can be configured for debugging or informational output.

Exit Codes
----------

- Exits with status code 1 if rebinning is attempted on the first iteration.

Dependencies
------------

- Requires access to WESTPA simulation data files.
- Utilizes WESTPA Python API components such as `WESTTool`, `WESTDataReader`, and `BinMappingComponent`.

See Also
--------

- `w_init` — for initializing simulations and binning.
- WESTPA documentation on binning and iteration management.
