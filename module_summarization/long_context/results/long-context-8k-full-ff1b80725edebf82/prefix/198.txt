Nearest Neighbors
=================

The Nearest Neighbors module provides efficient data structures and algorithms for nearest neighbor searches in high-dimensional spaces. It includes implementations of two primary tree-based data structures: the Ball Tree and the KD Tree. These trees enable fast querying of nearest neighbors by organizing data points in a way that allows pruning large portions of the search space.

Ball Tree
---------

The Ball Tree is a binary tree data structure where each node represents a hypersphere ("ball") containing a subset of the data points. Each node stores:

- A centroid representing the center of the ball.
- A radius defining the size of the ball.
- Indices of the data points contained within the node.

The Ball Tree supports a variety of distance metrics, including but not limited to:

- Bray-Curtis Distance
- Canberra Distance
- Chebyshev Distance
- Dice Distance
- Euclidean Distance
- Hamming Distance
- Haversine Distance
- Jaccard Distance
- Mahalanobis Distance
- Manhattan Distance
- Minkowski Distance
- Rogers-Tanimoto Distance
- Russell-Rao Distance
- Squared Euclidean Distance
- Sokal-Michener Distance
- Sokal-Sneath Distance
- Weighted Minkowski Distance

The Ball Tree uses the concept of "reduced distance" to optimize computations. The reduced distance is a metric-specific transformation of the true distance that preserves relative rankings but is cheaper to compute. For example, the reduced distance for the Euclidean metric is the squared Euclidean distance.

Key operations in the Ball Tree include:

- Allocation of node data arrays.
- Initialization of nodes by computing centroids and radii based on contained points.
- Computation of minimum and maximum distances (and reduced distances) between points and nodes.
- Computation of minimum and maximum distances between pairs of nodes.

These operations enable efficient pruning during nearest neighbor queries by quickly estimating bounds on distances.

KD Tree
-------

The KD Tree is another binary tree data structure optimized for nearest neighbor searches, particularly in spaces with moderate dimensionality. Each node in the KD Tree represents a hyperrectangle bounding a subset of the data points. The node stores:

- Lower and upper bounds for each feature dimension.
- Indices of the data points contained within the node.
- A radius representing the size of the circumscribed hypersphere around the node's bounding box.

The KD Tree supports a smaller set of distance metrics, including:

- Euclidean Distance
- Manhattan Distance
- Chebyshev Distance
- Minkowski Distance

Similar to the Ball Tree, the KD Tree uses reduced distances to optimize computations. The radius of each node is computed based on the bounding box and the chosen metric, which helps in pruning during queries.

Key operations in the KD Tree include:

- Allocation of node bounds arrays.
- Initialization of nodes by computing bounding boxes and radii.
- Computation of minimum and maximum distances (and reduced distances) between points and nodes.
- Computation of minimum and maximum distances between pairs of nodes.

Usage
-----

Both Ball Tree and KD Tree classes are available in two precision variants:

- 64-bit floating point (BallTree64, KDTree64)
- 32-bit floating point (BallTree32, KDTree32)

The default classes `BallTree` and `KDTree` correspond to the 64-bit implementations.

These trees can be used to perform efficient nearest neighbor searches, radius searches, and other proximity queries in various machine learning and data analysis tasks.

Summary
-------

- **Ball Tree**: Organizes data in hyperspheres; supports many distance metrics; uses reduced distances for efficiency.
- **KD Tree**: Organizes data in axis-aligned bounding boxes; supports common Minkowski metrics; uses reduced distances.
- Both trees provide fast nearest neighbor queries by pruning search space using bounding information.
- Implementations support both 32-bit and 64-bit floating point precision.
