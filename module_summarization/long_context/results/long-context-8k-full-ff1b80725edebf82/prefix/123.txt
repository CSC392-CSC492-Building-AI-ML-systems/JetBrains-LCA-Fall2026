DeleteViewMixin and WithinRoleDeleteView
=========================================

Implements the preview + confirm + delete workflow for Django views.

Overview
--------

This module provides a mixin and a concrete view class to facilitate a common pattern in web applications where a user is presented with a preview of an object, asked to confirm deletion, and then the object is deleted upon confirmation.

DeleteViewMixin
---------------

`DeleteViewMixin` is a mixin class designed to be used with Django's generic `DeleteView` or similar views. It encapsulates the logic and user interface elements needed for a preview-confirm-delete workflow.

Key Features:

- **Page Title and Labels**  
  - `get_pagetitle()`  
    Returns the page title, defaulting to "Confirm delete".  
  - `get_action_label()`  
    Returns the action label, defaulting to "Delete". Used as a prefix for the page title and as the default label for the delete button.  
  - `get_delete_button_label()`  
    Returns the label for the delete button, defaulting to the action label.  
  - `get_cancel_button_label()`  
    Returns the label for the cancel button, defaulting to "Cancel".

- **Object Preview and Confirmation Message**  
  - `get_object_preview()`  
    Returns a string representation of the object to be deleted, used to preview the object in the confirmation prompt.  
  - `get_confirm_message()`  
    Returns a confirmation message asking the user if they are sure they want to delete the object, including the object preview.

- **Success Handling**  
  - `get_success_url()`  
    Returns the URL to redirect to after successful deletion. Defaults to the index view of the current app.  
  - `get_success_message(object_preview)`  
    Returns a success message after deletion, including the object preview.  
  - `add_success_messages(object_preview)`  
    Adds success messages to the Django messages framework after deletion. Can be overridden to customize messaging behavior.

- **Context Data**  
  - `add_delete_view_mixin_context_data(context)`  
    Adds relevant context variables to the template context, including model verbose name, success URL, object preview, page title, confirmation message, and button labels.

- **Delete Operation**  
  - Overrides the `delete()` method to add success messages after the object has been deleted.

Usage Note:

You should import this class via:

```python
from django_cradmin import viewhelpers
```

and refer to it as `viewhelpers.formview.DeleteViewMixin`.

WithinRoleDeleteView
--------------------

`WithinRoleDeleteView` is a concrete view class that combines `DeleteViewMixin` with other mixins to provide a complete delete view implementation for applications using django_cradmin roles.

Features:

- Inherits from:
  - `QuerysetForRoleMixin` — to restrict the queryset based on the current role.
  - `DeleteViewMixin` — to provide the preview-confirm-delete workflow.
  - Django's generic `DeleteView`.
  - `CommonCradminViewMixin` — for common cradmin view functionality.
  - `javascriptregistry.viewmixin.WithinRoleViewMixin` — for JavaScript component integration within roles.

- Uses the template:  
  `'django_cradmin/viewhelpers/formview/within_role_delete_view.django.html'`

- Context Data:  
  Extends the context with JavaScript component IDs, common view mixin data, and delete view mixin context data.

Usage Note:

You should import this class via:

```python
from django_cradmin import viewhelpers
```

and refer to it as `viewhelpers.formview.WithinRoleDeleteView`.

Example Workflow
----------------

1. **Preview**  
   The user is shown a preview of the object to be deleted, including a confirmation message.

2. **Confirm**  
   The user confirms the deletion by clicking the delete button, or cancels the operation.

3. **Delete**  
   Upon confirmation, the object is deleted, success messages are added, and the user is redirected to the success URL.

Customization
-------------

You can override any of the following methods to customize behavior and appearance:

- `get_pagetitle()`  
- `get_action_label()`  
- `get_delete_button_label()`  
- `get_cancel_button_label()`  
- `get_object_preview()`  
- `get_confirm_message()`  
- `get_success_url()`  
- `get_success_message(object_preview)`  
- `add_success_messages(object_preview)`  
- `add_delete_view_mixin_context_data(context)`

This allows you to tailor the delete workflow to your application's needs.

Internationalization
--------------------

All user-facing strings are wrapped with Django's `gettext_lazy` for translation support.

Summary
-------

The `DeleteViewMixin` and `WithinRoleDeleteView` provide a robust and reusable implementation of the preview + confirm + delete workflow, integrating seamlessly with django_cradmin's role-based permissions and JavaScript registry system. They simplify the creation of consistent and user-friendly delete views in Django applications.
