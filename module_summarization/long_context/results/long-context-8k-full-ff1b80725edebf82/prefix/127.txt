Convolution Module Built-in Kernels
===================================

The `astropy.convolution` module provides a comprehensive set of tools for performing convolution operations on N-dimensional arrays. Central to this module are the built-in kernel classes that represent convolution kernels of various dimensions and shapes. These kernels can be used directly or combined to create complex convolution operations.

Kernel Classes
--------------

The module defines several kernel classes that serve as the basis for convolution operations:

- **Kernel**: The base class for all kernels. It provides common functionality and interface for kernel objects.
- **Kernel1D**: A subclass of `Kernel` representing one-dimensional kernels.
- **Kernel2D**: A subclass of `Kernel` representing two-dimensional kernels.

These kernel classes encapsulate the kernel data and provide methods for normalization, validation, and manipulation.

Kernel Properties and Constraints
---------------------------------

- Kernels must have an odd number of elements along each axis. This ensures a well-defined center pixel for the convolution operation.
- Kernels can be normalized to have a sum of one, which is often desirable for smoothing operations.
- Kernels may be masked arrays, where masked values are replaced by a specified fill value during convolution.

Convolution Functionality
-------------------------

The primary function for convolution in this module is `convolve`, which supports 1D, 2D, and 3D arrays. It accepts either raw `numpy.ndarray` objects or instances of the kernel classes.

Key features of the `convolve` function include:

- **NaN Handling**: Special treatment of `NaN` values in the input array. Instead of propagating `NaN`s through the convolution, the function can interpolate over them using the kernel as an interpolation function or fill them with a specified value.
- **Boundary Conditions**: Several options for handling array boundaries during convolution:
  - `None`: Values outside the array are treated as zero, and the result is zeroed where the kernel extends beyond the array edges.
  - `'fill'`: Values outside the array are set to a specified fill value.
  - `'wrap'`: Periodic boundary conditions, wrapping around the array edges.
  - `'extend'`: Values outside the array are set to the nearest edge value.
- **Normalization**: Optionally normalize the kernel before convolution.
- **Masking**: Support for masking input arrays, treating masked pixels as `NaN`.
- **Preservation of NaNs**: Optionally preserve `NaN` values in the output where they existed in the input.

Performance Considerations
--------------------------

- The convolution operation is implemented in C for performance, with support for multi-threading (though OpenMP support is currently disabled).
- The function attempts to optimize FFT sizes for efficient computation when applicable.
- Copying and data type conversions are handled internally to ensure compatibility and avoid side effects on input data.

Usage Notes
-----------

- The kernel and input array must have the same number of dimensions.
- Kernels with sums close to zero cannot be normalized and cannot be used with `nan_treatment='interpolate'`.
- When both the input array and kernel are instances of `Kernel`, certain parameters are hardwired for consistency.
- The function supports arrays up to three dimensions.
- For boundary handling with `None`, the kernel size must be smaller than the array size in all dimensions.

Example
-------

```python
from astropy.convolution import convolve, Gaussian2DKernel
import numpy as np

# Create a 2D Gaussian kernel
kernel = Gaussian2DKernel(x_stddev=1)

# Create a 2D array with some NaN values
array = np.ones((10, 10))
array[4:6, 4:6] = np.nan

# Convolve the array with the kernel, interpolating over NaNs
result = convolve(array, kernel, nan_treatment='interpolate')
```

This example demonstrates how to use a built-in Gaussian kernel to smooth an array containing `NaN` values, with the convolution function interpolating over the missing data.

Summary
-------

The built-in kernels in the `astropy.convolution` module provide flexible and efficient tools for convolution operations on N-dimensional data. With support for masking, NaN handling, and various boundary conditions, these kernels enable robust image and signal processing workflows within the Astropy ecosystem.
