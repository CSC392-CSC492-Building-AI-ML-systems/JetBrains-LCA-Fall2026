Resources
=========

Support for plugins that provide access to resources such as schemas.

Classes
-------

DirectoryResourceMapping
~~~~~~~~~~~~~~~~~~~~~~~~

A resource mapping that reads resource content from a directory or directory tree.

See :class:`~asdf_standard.resource.DirectoryResourceMapping` for details.

ResourceMappingProxy
~~~~~~~~~~~~~~~~~~~~

Wrapper around a resource mapping that carries additional information on the package that provided the mapping.

Methods and Properties:

- `maybe_wrap(delegate)` (class method)  
  Wraps the given delegate in a ResourceMappingProxy if it is not already one.

- `__init__(delegate, package_name=None, package_version=None)`  
  Initialize the proxy with a resource mapping delegate and optional package metadata.

- `__getitem__(uri)`  
  Retrieve the resource content for the given URI from the delegate.

- `__len__()`  
  Return the number of resources in the delegate.

- `__iter__()`  
  Iterate over the URIs in the delegate.

- `delegate` (property)  
  Returns the wrapped mapping instance.

- `package_name` (property)  
  Returns the name of the Python package that provided this mapping, or None if added at runtime.

- `package_version` (property)  
  Returns the version of the Python package that provided this mapping, or None if added at runtime.

- `class_name` (property)  
  Returns the fully qualified class name of the mapping.

- `__eq__(other)`  
  Equality comparison based on the wrapped delegate.

- `__hash__()`  
  Hash based on the identity of the delegate.

- `__repr__()`  
  String representation including class name, package info, and length.

ResourceManager
~~~~~~~~~~~~~~~

Wraps multiple resource mappings into a single interface with friendlier error handling.

Parameters
----------
- `resource_mappings` : iterable of collections.abc.Mapping  
  Underlying resource mappings. In case of duplicate URIs, the first mapping takes precedence.

Methods:

- `__getitem__(uri)`  
  Retrieve the resource content for the given URI from the first mapping that contains it. Raises KeyError if unavailable. Returns bytes (encoding strings as UTF-8).

- `__len__()`  
  Returns the total number of unique URIs across all mappings.

- `__iter__()`  
  Iterate over all unique URIs.

- `__contains__(uri)`  
  Check if a URI is available in any of the mappings.

- `__repr__()`  
  String representation showing the number of resources managed.

JsonschemaResourceMapping
~~~~~~~~~~~~~~~~~~~~~~~~~

Resource mapping that fetches metaschemas from the `jsonschema` package.

Methods:

- `__getitem__(uri)`  
  Returns the content of the metaschema corresponding to the given URI by loading it from the `jsonschema` package data.

- `__len__()`  
  Returns the number of known metaschema URIs.

- `__iter__()`  
  Iterate over the known metaschema URIs.

- `__repr__()`  
  String representation of the instance.

Functions
---------

get_json_schema_resource_mappings()
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Returns a list containing an instance of `JsonschemaResourceMapping`.

Usage
-----

This module provides abstractions to manage and access resource mappings, such as JSON schemas or other resource files, potentially contributed by different Python packages or loaded from directories.

- Use `DirectoryResourceMapping` to create resource mappings from directory trees.
- Use `ResourceMappingProxy` to wrap resource mappings with metadata about their source package.
- Use `ResourceManager` to combine multiple resource mappings into a single interface.
- Use `JsonschemaResourceMapping` to access JSON Schema metaschemas provided by the `jsonschema` package.
- Use `get_json_schema_resource_mappings()` to obtain default JSON Schema resource mappings.

This infrastructure facilitates plugin-based access to resources identified by URIs, with support for package metadata and error handling.
