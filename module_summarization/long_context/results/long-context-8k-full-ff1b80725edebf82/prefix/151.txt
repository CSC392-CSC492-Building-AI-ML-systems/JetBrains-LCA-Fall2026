# General Plotting Routines

This document provides an overview of the general plotting routines available in the Masci-tools package for creating interactive plots using the Bokeh backend. These routines facilitate the visualization of scientific data with customizable options and interactive features.

---

## Overview

The plotting routines are built on top of the `BokehPlotter` class and provide convenient functions to create common plot types such as scatter plots, multi-scatter plots, line plots, and density of states (DOS) plots. They support flexible data input formats, including array-like objects, pandas DataFrames, and Bokeh ColumnDataSource objects.

---

## Setting and Managing Plot Defaults

The plotting routines use a shared `BokehPlotter` instance (`plot_params`) to manage default plotting parameters. You can customize and control these defaults using the following helper functions:

- **`set_bokeh_plot_defaults(**kwargs)`**  
  Set or update default parameters for the Bokeh plotting backend.  
  Available defaults and their descriptions can be found in the `BokehPlotter` class.

- **`reset_bokeh_plot_defaults()`**  
  Reset all Bokeh plotting defaults to the original hardcoded values.

- **`show_bokeh_plot_defaults()`**  
  Display the currently set default parameters for the Bokeh backend.

- **`get_bokeh_help(key)`**  
  Print the description of a specific default parameter key.

- **`load_bokeh_defaults(filename='plot_bokeh_defaults.json')`**  
  Load default plotting parameters from a JSON file.

- **`save_bokeh_defaults(filename='plot_bokeh_defaults.json', save_complete=False)`**  
  Save the current default parameters to a JSON file.  
  If `save_complete` is `True`, both user-overwritten and hardcoded defaults are saved.

## Plotting Functions

### 1. `bokeh_scatter`

Create an interactive scatter plot.

**Signature:**
```python
bokeh_scatter(x, y=None, *, xlabel='x', ylabel='y', title='', figure=None, data=None, saveas='scatter', copy_data=False, **kwargs)
```

**Parameters:**
- `x`, `y`: Array-like or keys for data columns for the x and y axes.
- `data`: Optional data source (e.g., pandas DataFrame).
- `xlabel`, `ylabel`: Axis labels.
- `title`: Plot title.
- `figure`: Optional existing Bokeh figure to add the plot to.
- `saveas`: Filename prefix for saving the plot.
- `copy_data`: If `True`, the data source is copied before plotting.
- `**kwargs`: Additional parameters passed to `BokehPlotter` or Bokeh's `scatter` function.

**Description:**  
Creates a single scatter plot with interactive tooltips and customizable styling.

---

### 2. `bokeh_multi_scatter`

Create an interactive scatter plot with multiple datasets.

**Signature:**
```python
bokeh_multi_scatter(x, y=None, *, data=None, figure=None, xlabel='x', ylabel='y', title='', saveas='scatter', copy_data=False, set_default_legend=True, **kwargs)
```

**Parameters:**  
Same as `bokeh_scatter`, with the addition of:
- `set_default_legend`: If `True`, automatically generates legend labels from data names.

**Description:**  
Plots multiple scatter datasets on the same figure, each with its own styling and tooltips. Supports automatic legend generation.

---

### 3. `bokeh_line`

Create an interactive multi-line plot.

**Signature:**
```python
bokeh_line(x, y=None, *, data=None, figure=None, xlabel='x', ylabel='y', title='', saveas='line', plot_points=False, area_curve=0, copy_data=False, set_default_legend=True, **kwargs)
```

**Parameters:**
- `plot_points`: If `True`, overlays scatter points on the lines.
- `area_curve`: Numeric value to shift the baseline for area plots.
- Other parameters as in `bokeh_multi_scatter`.

**Description:**  
Creates one or more line plots with optional scatter points and area fills. Supports legends, tooltips, and customizable colors.

---

### 4. `bokeh_dos`

Create an interactive density of states (DOS) plot (non-spin-polarized).

**Signature:**
```python
bokeh_dos(energy_grid, dos_data=None, *, data=None, energy_label='$$E-E_F [eV]$$', dos_label='DOS [1/eV]', title='Density of states', xyswitch=False, e_fermi=0, saveas='dos_plot', copy_data=False, **kwargs)
```

**Parameters:**
- `energy_grid`: Energy values or key for energy data.
- `dos_data`: DOS values or keys for DOS data columns.
- `data`: Optional data source.
- `energy_label`, `dos_label`: Axis labels.
- `title`: Plot title.
- `xyswitch`: If `True`, swaps x and y axes (energy plotted vertically).
- `e_fermi`: Fermi energy value; a vertical or horizontal line is drawn at this energy.
- `saveas`: Filename prefix for saving the plot.
- `copy_data`: If `True`, copies the data source.
- `**kwargs`: Additional parameters passed to `bokeh_line`.

**Description:**  
Plots the density of states with options for orientation and marking the Fermi energy. Supports multiple DOS datasets.

---

## Data Handling

All plotting functions accept data in flexible formats:

- Direct array-like inputs for x and y data.
- Data keys referencing columns in a pandas DataFrame or similar data source.
- Bokeh `ColumnDataSource` objects.

The helper function `process_data_arguments` is used internally to standardize and prepare data for plotting, ensuring consistent length and format.

---

## Customization and Extensibility

- Plot defaults can be customized globally or per function call.
- Additional keyword arguments are passed to the underlying Bokeh plotting functions, allowing fine control over plot appearance.
- Tooltips and interactive features are automatically added based on the data.
- Legends and color palettes are managed automatically for multi-dataset plots.

---

## Example Usage

```python
import pandas as pd
from masci_tools.vis.plotting import bokeh_scatter, set_bokeh_plot_defaults

# Set global defaults
set_bokeh_plot_defaults(width=800, height=600)

# Prepare data
df = pd.DataFrame({'x': [1, 2, 3], 'y': [4, 5, 6]})

# Create scatter plot
p = bokeh_scatter('x', 'y', data=df, title='Example Scatter Plot')

# Show or save plot as needed
```

---

## Notes

- Passing the data source as the first positional argument is deprecated; use keyword arguments `data`, `x`, and `y` instead.
- The plotting routines are designed to integrate seamlessly with the Masci-tools visualization framework and can be extended or customized by modifying the `BokehPlotter` defaults.

---

This set of general plotting routines provides a powerful and flexible foundation for interactive scientific visualization using Bokeh within the Masci-tools package.
