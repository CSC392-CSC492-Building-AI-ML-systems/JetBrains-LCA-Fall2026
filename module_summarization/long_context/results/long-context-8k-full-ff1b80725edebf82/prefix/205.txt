Stochastic Gradient Descent (SGD)
=================================

Overview
--------

Stochastic Gradient Descent (SGD) is an iterative optimization algorithm used for minimizing an objective function that is typically a sum of differentiable functions. It is widely used in machine learning for training models such as linear regression, logistic regression, and neural networks.

The implementation provided here focuses on advanced variants of SGD, specifically the Stochastic Average Gradient (SAG) and SAGA algorithms, which improve convergence rates by incorporating variance reduction techniques.

Key Features
------------

- **SAG and SAGA Solvers**: These are incremental gradient methods designed to minimize finite sums efficiently. They maintain an average of gradients computed on individual samples to reduce variance and accelerate convergence.

- **Just-in-Time (JIT) Updates**: To optimize performance, especially with sparse data, the algorithm applies gradient updates only when necessary. This avoids redundant computations by scaling gradient steps according to the number of iterations since the last update for each feature.

- **Weight Scaling for L2 Regularization**: Instead of updating all weights at every iteration, a scaling factor is maintained and applied lazily to weights. This improves computational efficiency and numerical stability.

- **Support for Proximal Operators**: The implementation supports L1 regularization through proximal operators, enabling sparse solutions when using the SAGA variant.

- **Multinomial and Binary Loss Functions**: The solver supports multiple loss functions including logistic loss, squared loss, and multinomial logistic loss for multi-class classification.

Algorithm Details
-----------------

### Loss Functions

- **Logistic Loss**: Used for binary classification problems.
- **Squared Loss**: Used for regression problems.
- **Multinomial Logistic Loss**: Used for multi-class classification problems. The loss for a single sample is computed as:

  .. math::

     \text{loss} = \text{sample_weight} \times \left( \log \sum_c \exp(\text{prediction}_c) - \text{prediction}_y \right)

  where :math:`\text{prediction}` is the vector of class scores for the sample, and :math:`y` is the true class label.

### Gradient Computation

The gradient of the multinomial logistic loss with respect to class :math:`c` is:

.. math::

   \text{grad}_c = \text{sample_weight} \times \left( p_c - \delta_{y,c} \right)

where :math:`p_c` is the predicted probability for class :math:`c`, and :math:`\delta_{y,c}` is the Kronecker delta.

### Update Rules

- **Weight Updates**: Weights are updated using the average of gradients stored in memory, scaled by the step size and regularization parameters.
- **Intercept Updates**: If fitting an intercept, it is updated separately with its own gradient and decay factor.
- **Proximal Operator**: When L1 regularization is enabled (in SAGA), a soft-thresholding proximal operator is applied to encourage sparsity.

Implementation Notes
--------------------

- The implementation is templated for both 32-bit and 64-bit floating point precision.
- It uses efficient memory layouts and low-level optimizations for speed.
- The algorithm maintains arrays for gradient memory, sum of gradients, and feature update history to enable efficient incremental updates.
- Numerical stability is ensured by periodically resetting scaling factors and applying all pending updates.
- The solver supports verbose output and convergence tolerance parameters.

Usage
-----

The solver is typically used internally by higher-level estimators such as Ridge regression and Logistic Regression implementations. It requires:

- A dataset in a sequential format.
- Initial weights and intercepts.
- Parameters such as step size, regularization strengths (alpha for L2, beta for L1), maximum iterations, and tolerance.
- Choice of loss function: `"log"`, `"squared"`, or `"multinomial"`.

The solver iteratively updates weights and intercepts until convergence criteria are met or the maximum number of iterations is reached.

Summary
-------

This implementation of Stochastic Gradient Descent leverages advanced techniques like SAG and SAGA to provide efficient and scalable optimization for large-scale machine learning problems. Its support for multiple loss functions, regularization types, and sparse data makes it a versatile tool for training linear models.
