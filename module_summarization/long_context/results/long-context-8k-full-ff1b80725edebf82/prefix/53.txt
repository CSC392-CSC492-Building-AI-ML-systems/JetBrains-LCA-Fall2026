Multiple Imputation through Chained Equations (MICE) Module
=============================================================

Overview
--------

This module provides an implementation of the Multiple Imputation through Chained Equations (MICE) methodology for handling missing data in statistical analyses. The MICE approach iteratively imputes missing values by modeling each variable with missing data conditional on other variables in the dataset. The key steps in the MICE procedure are:

1. Initial imputation of missing values using the mean of observed values for each variable.
2. For each variable with missing data (the "focus variable"):
   - Fit an imputation model regressing the focus variable on other variables.
   - Impute missing values using predictive mean matching (PMM).
3. Fit the analysis model to the fully imputed dataset.
4. Repeat the imputation and analysis steps multiple times and combine results to obtain parameter estimates and standard errors.

The module supports specifying custom imputation models and formulas for each variable, with ordinary least squares (OLS) regression as the default model. It also supports perturbation methods to reflect uncertainty in parameter estimates, including Gaussian draws and bootstrap resampling.

Usage Modes
-----------

- **MICEData Class**: Wraps a Pandas DataFrame to perform multiple imputations. It allows customization of imputation models per variable, supports iterative updates, and provides visualization tools for missing data patterns and imputation diagnostics. This class is suitable when the goal is to generate imputed datasets for further analysis or sharing.

- **MICE Class**: Combines a `MICEData` object with an analysis model specification. It runs the full multiple imputation process, fits the analysis models on imputed datasets, and combines results to produce inference summaries.

Terminology
-----------

- **Analysis Model**: The statistical model of interest to be fit after imputation.
- **Imputation Model**: A regression model used to impute missing values for a particular variable, conditional on other variables.
- **Perturbation Method**: The technique used to introduce variability in imputation model parameters to reflect uncertainty. Supported methods include:
  - *Gaussian*: Parameters are drawn from a Gaussian approximation to the sampling distribution.
  - *Bootstrap*: Parameters are estimated from bootstrapped samples of the data.

Class Structure
---------------

### MICEData

- Wraps a Pandas DataFrame and manages imputation models for variables with missing data.
- Supports setting custom imputation formulas, model classes, and fitting options per variable.
- Implements predictive mean matching for imputations.
- Provides methods to update imputations iteratively (`update_all`), access imputed datasets, and visualize missing data patterns.
- Allows a `history_callback` function to save or analyze intermediate imputed datasets during the iterative process.

### PatsyFormula

- A helper class to wrap strings as Patsy formulas for use in model specification.

Key Features
------------

- Initial imputation uses a PMM-like approach by imputing missing values with observed values closest to the mean.
- Imputation order is determined by the number of missing values per variable, imputing variables with fewer missing values first.
- Flexible specification of imputation models, including support for regularized fitting methods.
- Integration with Patsy for formula parsing and design matrix construction.
- Facilities to handle and visualize missing data patterns.
- Support for perturbation methods to incorporate parameter uncertainty in imputations.

Examples
--------

Impute missing values in variable `x1` using a model including `x2`, `x2^2`, and `x3`, and save 20 imputed datasets:

    >>> imp = mice.MICEData(data)
    >>> imp.set_imputer('x1', formula='x2 + np.square(x2) + x3')
    >>> for j in range(20):
    ...     imp.update_all()
    ...     imp.data.to_csv('data%02d.csv' % j)

Iterate over imputed datasets using default models:

    >>> imp = mice.MICEData(data)
    >>> j = 0
    >>> for data in imp:
    ...     imp.data.to_csv('data%02d.csv' % j)
    ...     j += 1

Notes
-----

- The module assumes column names in the input DataFrame are strings.
- Observations with all variables missing are dropped during initialization.
- By default, minimal information is stored between iterations to conserve memory.
- When using regularized fitting methods, the perturbation method must be set to bootstrap.
- The `history_callback` function can be used to save or analyze intermediate imputed datasets during the iterative process.
- Predictive mean matching uses a default of 20 nearest neighbors, adjustable per variable.

This module provides a comprehensive and flexible framework for multiple imputation using chained equations, facilitating robust handling of missing data in statistical workflows.
