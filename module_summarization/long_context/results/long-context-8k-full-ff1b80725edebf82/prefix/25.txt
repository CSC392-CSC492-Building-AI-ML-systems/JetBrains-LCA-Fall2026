w_ipa — WESTPA Interactive Python Analysis Tool
===============================================

Overview
--------

`w_ipa` (WESTPA Interactive Python Analysis) is an interactive, stateful analysis tool designed for exploring WESTPA simulation data. It allows users to run traces, examine weights, progress coordinates, and other relevant information from the current analysis scheme and iteration. By default, `w_ipa` uses the first analysis scheme defined in the `west.cfg` configuration file and starts at iteration 1.

Key Features
------------

- Stateful interaction with WESTPA data, always reflecting the current analysis scheme and iteration.
- Access to detailed iteration data including walkers, summary statistics, states, segment IDs, weights, parents, kinetics averages, progress coordinates, bins, populations, and auxiliary data.
- Ability to run traces on specific segment IDs to retrieve their full history.
- Supports multiple analysis schemes and easy switching between them.
- Automatic management and generation of analysis files based on configuration.
- Integration with WESTPA’s parallel work manager for efficient data processing.
- Configurable runtime options for analysis mode, reanalysis, debugging, and plotting.

Usage
-----

### Starting `w_ipa`

Launch the tool from the command line to enter an interactive Python environment tailored for WESTPA data analysis.

### Accessing Properties

All properties and methods are accessed via the `w` or `west` object.

- **Current iteration:**

  ```python
  w.iteration
  # or
  west.iteration
  ```

- **Setting the iteration:**

  ```python
  w.iteration = 100
  ```

- **Listing and changing analysis schemes:**

  ```python
  w.list_schemes
  w.scheme = 'scheme_name'  # Replace 'scheme_name' with a valid scheme from the list
  ```

- **Viewing states and bins in the current scheme:**

  ```python
  w.states
  w.bin_labels
  ```

- **Accessing current iteration data:**

  ```python
  w.current
  ```

  The `current` object contains detailed information such as walkers, summary, states, segment IDs, weights, parents, kinetics averages, progress coordinates, bins, populations, and auxiliary data if available.

### Running a Trace

To retrieve the history of a specific segment ID in the current iteration:

```python
trace_data = w.trace(seg_id)
```

This returns a dictionary with all pertinent information about the segment’s history. Since tracing can be computationally expensive, it is recommended to store the result for repeated use.

Runtime Options
---------------

`w_ipa` supports several command-line options to customize its behavior:

- `--analysis-only`, `-ao`  
  Run the analysis and return to the terminal without entering the interactive environment.

- `--reanalyze`, `-ra`  
  Delete existing analysis files and reanalyze from scratch.

- `--ignore-hash`, `-ih`  
  Ignore stored argument hashes and do not regenerate files.

- `--debug`, `-d`  
  Enable debug output intended primarily for development purposes.

- `--terminal`, `-t`  
  Plot output directly in the terminal.

Configuration and Analysis Schemes
----------------------------------

`w_ipa` automatically parses the WESTPA configuration file (`west.cfg`) to identify analysis schemes and their settings. It manages the creation and loading of analysis files (`assign.h5`, `direct.h5`, `reweight.h5`) for each enabled scheme, regenerating them as needed based on argument hashes and user options.

Analysis schemes can be customized in the configuration file under the `west.analysis` section. For example, to specify options for `w_direct`:

```yaml
west:
  analysis:
    w_direct:
      evolution: cumulative
      step_iter: 1
      extra: ['disable-correl']
```

If the same options apply to both `w_direct` and `w_reweight`, the key `w_direct` can be replaced with `kinetics` to apply settings to both tools.

Internals and Extensibility
---------------------------

- `w_ipa` inherits from `WESTParallelTool` and uses `WESTDataReader` for data access.
- It integrates with WESTPA’s parallel work manager for efficient computation.
- The tool maintains internal hashes of arguments and data to avoid unnecessary recomputation.
- Users can extend or customize analysis behavior by modifying configuration files or by interacting with the tool’s Python interface.

Getting Help
------------

Within the interactive environment, use Python’s built-in `help()` function to learn more about any function or property:

```python
help(w.trace)
help(w.current)
```

This provides detailed information on usage and available attributes.

Summary
-------

`w_ipa` is a powerful and flexible interactive tool for analyzing WESTPA simulation data. It streamlines access to complex datasets, supports multiple analysis schemes, and provides a rich Python interface for custom exploration and visualization.

Happy analyzing!
