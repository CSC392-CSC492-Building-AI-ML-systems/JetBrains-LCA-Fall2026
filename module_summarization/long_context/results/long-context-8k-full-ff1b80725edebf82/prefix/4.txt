Sync Users with LDAP
====================

Overview
--------

This module provides functionality to synchronize users between an LDAP directory and the ftrack server. It enables automated management of user accounts by importing user information from LDAP, ensuring that the ftrack user database is consistent with the organization's directory service.

Key Features
------------

- Connect to an LDAP server using provided credentials.
- Query and retrieve user entries from LDAP.
- Create new users in ftrack based on LDAP entries.
- Update existing ftrack users to reflect changes in LDAP.
- Deactivate or remove ftrack users that no longer exist in LDAP.
- Support for configurable LDAP filters and attribute mappings.
- Logging and error handling for synchronization operations.

Usage
-----

To synchronize users with LDAP, establish a session with the ftrack server and configure the LDAP connection parameters. The synchronization process typically involves the following steps:

1. **Establish ftrack Session**

   Create a session object to interact with the ftrack server. This session handles authentication, caching, and event management.

2. **Configure LDAP Connection**

   Specify the LDAP server URL, bind DN, password, and search base. Optionally, define filters to select which users to synchronize.

3. **Fetch LDAP Users**

   Query the LDAP directory to retrieve user entries. Extract relevant attributes such as username, email, and full name.

4. **Synchronize Users**

   For each LDAP user entry:

   - Check if the user exists in ftrack.
   - If the user does not exist, create a new user entity.
   - If the user exists, update user attributes as necessary.
   - Handle user deactivation or removal if the LDAP entry is no longer present.

5. **Commit Changes**

   Persist any created or modified user entities to the ftrack server.

Configuration
-------------

- **LDAP Server URL**: The address of the LDAP server to connect to.
- **Bind DN and Password**: Credentials used to authenticate against the LDAP server.
- **Search Base**: The LDAP directory subtree to search for user entries.
- **User Filter**: LDAP filter expression to select user entries.
- **Attribute Mapping**: Mapping between LDAP attributes and ftrack user fields.

Example
-------

```python
from ftrack_api import Session

# Establish session with ftrack server
session = Session(
    server_url='https://ftrack.example.com',
    api_user='api_user',
    api_key='api_key'
)

# LDAP connection parameters
ldap_url = 'ldap://ldap.example.com'
bind_dn = 'cn=admin,dc=example,dc=com'
bind_password = 'password'
search_base = 'ou=users,dc=example,dc=com'
user_filter = '(objectClass=person)'

# Synchronize users
synchronize_ldap_users(
    session,
    ldap_url,
    bind_dn,
    bind_password,
    search_base,
    user_filter
)
```

Notes
-----

- Ensure that the LDAP credentials have sufficient permissions to read user entries.
- The synchronization process may be scheduled to run periodically to keep user data up to date.
- Proper error handling and logging are recommended to monitor synchronization status.
- The synchronization respects the ftrack API's caching and session management to optimize performance.
