Camera Geometry and Subarray Description
========================================

Overview
--------

This module provides tools to work with images or data cubes related to Cherenkov Cameras, focusing on the geometric and positional description of telescopes within an array or subarray. It enables the management of telescope configurations, their positions on the ground, and their associated camera and optics descriptions.

SubarrayDescription
-------------------

The `SubarrayDescription` class collects and manages the descriptions of all telescopes in a Cherenkov telescope array or subarray, including their positions on the ground and their individual telescope characteristics.

### Key Features

- **Telescope Positions and Coordinates**  
  Stores telescope positions as 3D coordinates on the ground, internally represented using `astropy.coordinates.SkyCoord` in the `GroundFrame`. This allows precise spatial referencing and transformations.

- **Telescope Descriptions**  
  Maintains a dictionary of `TelescopeDescription` objects, each describing the optics, camera, and other properties of a telescope.

- **Reference Location**  
  Supports an Earth-based reference location (`astropy.coordinates.EarthLocation`) that defines the origin (0,0,0) of the coordinate system for telescope positions.

- **Telescope Identification and Indexing**  
  Provides mappings between telescope IDs and zero-based indices, facilitating efficient data handling and indexing in arrays or data cubes.

- **Subarray Footprint**  
  Computes the ground footprint of the array as the area of the smallest circle containing all telescopes.

- **Table Export**  
  Exports subarray information as `astropy.table.Table` objects, supporting different views such as the full subarray or optics-specific tables. This is useful for serialization, inspection, or interfacing with other software components.

- **Subarray Selection**  
  Allows creation of new subarrays by selecting subsets of telescopes, enabling flexible analysis of parts of the array.

- **Multiplicity Calculation**  
  Computes the multiplicity (number of triggered telescopes) from boolean masks, optionally filtered by telescope type.

- **Visualization**  
  Provides a quick plotting method to visualize the array layout using matplotlib.

### Attributes

- `name` (str): Name of the subarray.
- `positions` (Dict[int, np.ndarray]): Dictionary mapping telescope IDs to their ground positions (x, y, z).
- `tels` (Dict[int, TelescopeDescription]): Dictionary mapping telescope IDs to their descriptions.
- `reference_location` (`EarthLocation`): Earth location defining the coordinate origin.
- `tel_coords` (`SkyCoord`): Telescope positions as astropy SkyCoord objects.
- `tel_ids` (np.ndarray): Array of telescope IDs.
- `tel_indices` (Dict[int, int]): Mapping from telescope ID to zero-based index.
- `footprint` (`astropy.units.Quantity`): Ground area covered by the array.

### Methods

- `info(printer=print)`  
  Prints a summary of the subarray, including the number of telescopes, footprint, and counts per telescope type.

- `to_table(kind='subarray')`  
  Returns an `astropy.table.Table` representing the subarray or optics information.

- `select_subarray(tel_ids, name=None)`  
  Creates a new `SubarrayDescription` containing only the specified telescopes.

- `tel_ids_to_indices(tel_ids)`  
  Converts telescope IDs to their corresponding zero-based indices.

- `tel_ids_to_mask(tel_ids)`  
  Converts a list of telescope IDs to a boolean mask array.

- `tel_mask_to_tel_ids(tel_mask)`  
  Converts a boolean mask back to a list of telescope IDs.

- `multiplicity(tel_mask, tel_type=None)`  
  Computes the number of triggered telescopes from a boolean mask, optionally filtered by telescope type.

- `peek()`  
  Displays a quick matplotlib plot of the array layout.

### Telescope and Camera Types

- `telescope_types`  
  Tuple of unique telescope types present in the subarray.

- `camera_types`  
  Tuple of unique camera types present in the subarray.

- `optics_types`  
  Tuple of unique optics types present in the subarray.

Usage Example
-------------

```python
from ctapipe.instrument import SubarrayDescription

# Create a subarray description with telescope positions and descriptions
subarray = SubarrayDescription(
    name="ExampleArray",
    tel_positions={1: [0, 0, 0] * u.m, 2: [100, 0, 0] * u.m},
    tel_descriptions={1: telescope_desc1, 2: telescope_desc2},
    reference_location=earth_location
)

# Print information about the subarray
subarray.info()

# Get telescope coordinates
coords = subarray.tel_coords

# Select a subset of telescopes
sub_subarray = subarray.select_subarray([1])

# Export subarray info as a table
table = subarray.to_table()

# Visualize the array layout
subarray.peek()
```

Summary
-------

The `SubarrayDescription` class and related tools provide a comprehensive framework for managing and working with Cherenkov telescope arrays, their cameras, and optics. This facilitates the handling of images and data cubes by providing consistent geometric and positional context essential for data analysis and visualization.
