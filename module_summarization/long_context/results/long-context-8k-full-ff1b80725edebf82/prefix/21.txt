w_eddist — Calculate time-resolved transition-event duration distributions
=============================================================================

Description
-----------

The `w_eddist` tool calculates time-resolved transition-event duration distributions from kinetics results generated by weighted ensemble simulations.

This tool processes source data collected from the results of the `w_kinetics trace` command (see `w_kinetics trace --help` for more information on generating this dataset).

Histogram binning is performed on the transition-event durations to produce normalized histograms that describe the distribution of event durations over time.

Source Data
-----------

Input data is obtained from the kinetics trace file, which contains populations, transition rates, and transition-event durations. This file is typically generated by the `w_kinetics trace` command.

By default, `w_eddist` reads from a kinetics trace file named `kintrace.h5`, but this can be changed via command-line options.

Histogram Binning
-----------------

Histograms are constructed to represent the distribution of transition-event durations. By default, 100 bins are used in each dimension.

The binning scheme can be customized using the `-b` or `--bins` option, which accepts several formats:

- **Single integer N**: Use N uniformly spaced bins in each dimension.
- **Sequence of integers N1,N2,...**: Use N1 bins for the first dimension, N2 for the second, and so forth.
- **List of lists of bin boundaries**: Specify explicit bin boundaries for each dimension, e.g., `[[b11, b12, ...], [b21, b22, ...], ...]`. These boundaries need not be uniformly spaced and are evaluated as Python expressions with `np` (NumPy) available.

Note that the first two forms require scanning the data to determine minimum and maximum values in each dimension, which may be computationally expensive for large datasets. Providing explicit bin boundaries avoids this scan.

The bins used here are independent of the bins used to drive weighted ensemble sampling.

Output Format
-------------

The output is stored in an HDF5 file (default: `eddist.h5`), which contains the following datasets:

- **histograms**: A time series of normalized histograms. The first axis corresponds to iteration number, and subsequent axes correspond to the dimensions of the input data.
- **binbounds_0, binbounds_1, ...**: Arrays of bin boundaries for each dimension.
- **midpoints_0, midpoints_1, ...**: Arrays of bin midpoints for each dimension.
- **n_iter**: Vector of iteration numbers corresponding to the histograms.

Attributes `iter_start` and `iter_stop` are stored with the histograms dataset to indicate the iteration range analyzed.

Subsequent Processing
---------------------

The output file can be visualized or further analyzed using the `plothist` tool or other compatible programs.

Parallelization
---------------

`w_eddist` supports parallelized binning and data reading by default, which can significantly speed up processing for large datasets. For simpler cases or smaller datasets, serial processing can be enabled with the `--serial` option.

Command-Line Options
--------------------

```
-b, --bins BINEXPR
    Specify binning scheme for histograms. BINEXPR can be:
      - An integer N: use N bins in each dimension.
      - A list of integers [N1,N2,...]: use N1 bins for dimension 1, N2 for dimension 2, etc.
      - A list of lists of bin boundaries [[b11,b12,...],[b21,b22,...],...]: explicit bin boundaries per dimension.
    Default: 100 bins per dimension.

-C, --compress
    Compress histograms in the output file. This can reduce file size but may increase analysis time.
    Default: no compression.

--loose
    Ignore data points that fall outside the specified bin boundaries. Use with caution as this may mask binning errors.

--istate ISTATE
    (Required) Initial state defining the transition event.

--fstate FSTATE
    (Required) Final state defining the transition event.

--first-iter ITER
    Iteration to begin analysis (default: 1).

--last-iter ITER
    Iteration to end analysis.

-k, --kinetics FILE
    Input kinetics trace file containing populations, transition rates, and durations.
    Default: kintrace.h5

-o, --output FILE
    Output file to store results.
    Default: eddist.h5

--serial
    Disable parallel processing and run in serial mode.

Progress Indicator
------------------

`w_eddist` provides a progress indicator to monitor the status of data scanning and histogram construction.

Examples
--------

Calculate the transition-event duration distribution for transitions from state 1 to state 2, using default bins and input file:

```
w_eddist --istate 1 --fstate 2
```

Specify custom bins and output file:

```
w_eddist --istate 1 --fstate 2 -b "[[0,1,2,3,4,5]]" -o my_eddist.h5
```

Use 50 bins in each dimension and compress the output:

```
w_eddist --istate 1 --fstate 2 -b 50 -C
```

Notes
-----

- The tool assumes that the kinetics trace file contains datasets named `durations/duration` and `durations/weight` with appropriate structure.
- The iteration range defaults to the full range available in the kinetics file but can be restricted with `--first-iter` and `--last-iter`.
- The output histograms are normalized so that each histogram sums to 1.
- The tool is designed to work with weighted ensemble simulation data processed by WESTPA.
