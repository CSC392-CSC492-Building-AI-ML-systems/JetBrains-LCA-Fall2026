Cross Decomposition
===================

The `cross_decomposition` module in scikit-learn implements Partial Least Squares (PLS) methods, which are a family of techniques for modeling relations between sets of observed variables by means of latent variables. These methods are particularly useful when the predictor variables are many and highly collinear.

Overview
--------

Partial Least Squares (PLS) is a statistical method that finds a linear regression model by projecting the predicted variables and the observable variables to a new space. The main goal of PLS is to predict a set of dependent variables from a set of independent variables or predictors.

The `cross_decomposition` module provides implementations of several PLS algorithms, including:

- PLSRegression
- PLSCanonical
- PLSSVD

These algorithms are based on the decomposition of the data matrices into latent structures that capture the covariance between the predictors and the responses.

Key Concepts
------------

- **Latent Variables**: New variables constructed as linear combinations of the original variables, capturing the directions of maximum covariance between the predictor and response variables.
- **Deflation**: The process of removing the information explained by the extracted latent variables from the original data matrices to extract subsequent components.
- **Modes**: Different algorithmic modes ("A" and "B") that define how weights and scores are computed.
- **Algorithms**: Two main algorithms are implemented:
  - **NIPALS** (Nonlinear Iterative Partial Least Squares): An iterative method to extract singular vectors.
  - **SVD** (Singular Value Decomposition): A direct method using matrix factorization.

Main Class: `_PLS`
------------------

The `_PLS` class is an abstract base class implementing the generic PLS algorithm. It provides the core functionality used by specific PLS variants.

### Parameters

- `n_components` : int, default=2  
  Number of components to keep.

- `scale` : bool, default=True  
  Whether to scale the data to unit variance before applying the algorithm.

- `deflation_mode` : {'regression', 'canonical'}, default='regression'  
  Deflation mode to use.  
  - `'regression'`: Deflate X and regress Y on X scores.  
  - `'canonical'`: Deflate both X and Y.

- `mode` : {'A', 'B'}, default='A'  
  Algorithmic mode for weight computation.

- `algorithm` : {'nipals', 'svd'}, default='nipals'  
  Algorithm to use for extracting components.

- `max_iter` : int, default=500  
  Maximum number of iterations for the NIPALS algorithm.

- `tol` : float, default=1e-06  
  Tolerance for convergence in the NIPALS algorithm.

- `copy` : bool, default=True  
  Whether to copy the input data.

### Attributes

- `x_weights_` : ndarray of shape (n_features, n_components)  
  Weights of X.

- `y_weights_` : ndarray of shape (n_targets, n_components)  
  Weights of Y.

- `x_loadings_` : ndarray of shape (n_features, n_components)  
  Loadings of X.

- `y_loadings_` : ndarray of shape (n_targets, n_components)  
  Loadings of Y.

- `x_rotations_` : ndarray of shape (n_features, n_components)  
  Transformation matrix for X.

- `y_rotations_` : ndarray of shape (n_targets, n_components)  
  Transformation matrix for Y.

- `coef_` : ndarray of shape (n_targets, n_features)  
  Regression coefficients.

- `intercept_` : ndarray of shape (n_targets,)  
  Intercept term.

- `n_iter_` : list  
  Number of iterations run for each component (only for NIPALS algorithm).

### Methods

- `fit(X, Y)`  
  Fit the PLS model to the data.

- `transform(X, Y=None, copy=True)`  
  Apply dimensionality reduction to X (and optionally Y).

- `inverse_transform(X, Y=None)`  
  Transform data back to its original space.

- `predict(X, copy=True)`  
  Predict target values for given samples.

- `fit_transform(X, y=None)`  
  Fit the model and apply the dimensionality reduction on X.

Usage Notes
-----------

- The number of components `n_components` must be less than or equal to the rank of the data matrices, depending on the deflation mode.
- Scaling is recommended to ensure that variables with larger scales do not dominate the analysis.
- The NIPALS algorithm is iterative and may require tuning of `max_iter` and `tol` parameters.
- The SVD algorithm computes the full singular value decomposition and may be more stable but computationally more expensive.
