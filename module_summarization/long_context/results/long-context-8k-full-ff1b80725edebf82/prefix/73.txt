Naive Bayes
===========

The `sklearn.naive_bayes` module implements Naive Bayes algorithms. These are supervised learning methods based on applying Bayes' theorem with strong (naive) feature independence assumptions.

Overview
--------

Naive Bayes classifiers are a family of simple probabilistic classifiers based on applying Bayes' theorem with strong independence assumptions between the features. Despite their simplicity, Naive Bayes classifiers have worked well in many complex real-world situations.

This module provides several variants of Naive Bayes classifiers suitable for different types of data:

- **GaussianNB**: Gaussian Naive Bayes for continuous data assuming features follow a normal distribution.
- **BernoulliNB**: Naive Bayes classifier for multivariate Bernoulli models.
- **MultinomialNB**: Naive Bayes classifier for multinomial models, typically used for discrete counts.
- **ComplementNB**: A variant of MultinomialNB designed to correct the "severe assumptions" made by the standard multinomial naive Bayes.
- **CategoricalNB**: Naive Bayes classifier for categorical features.

Base Classes
------------

### _BaseNB

An abstract base class for Naive Bayes estimators. It defines the core interface and common methods used by all Naive Bayes classifiers:

- `_joint_log_likelihood(X)`: Abstract method to compute the unnormalized posterior log probability of input samples.
- `_check_X(X)`: Abstract method to validate input data, used in prediction methods.
- `predict_joint_log_proba(X)`: Returns joint log probability estimates for the test vectors.
- `predict(X)`: Predicts the class labels for the input samples.
- `predict_log_proba(X)`: Returns log-probability estimates for the test vectors.
- `predict_proba(X)`: Returns probability estimates for the test vectors.

Gaussian Naive Bayes
-------------------

### GaussianNB

Gaussian Naive Bayes implements the Naive Bayes algorithm for continuous data assuming that the likelihood of the features is Gaussian.

Key features:

- Supports online updates to model parameters via `partial_fit`.
- Uses an efficient algorithm for updating means and variances incrementally.
- Includes smoothing of variance for numerical stability.

Parameters
~~~~~~~~~~

- `priors` : array-like of shape (n_classes,), default=None  
  Prior probabilities of the classes. If specified, these priors are not adjusted according to the data.

- `var_smoothing` : float, default=1e-9  
  Portion of the largest variance of all features added to variances for calculation stability.

Attributes
~~~~~~~~~~

- `class_count_` : ndarray of shape (n_classes,)  
  Number of training samples observed in each class.

- `class_prior_` : ndarray of shape (n_classes,)  
  Probability of each class.

- `classes_` : ndarray of shape (n_classes,)  
  Class labels known to the classifier.

- `epsilon_` : float  
  Absolute additive value to variances for numerical stability.

- `n_features_in_` : int  
  Number of features seen during fitting.

- `feature_names_in_` : ndarray of shape (n_features_in_,)  
  Names of features seen during fitting (if available).

- `var_` : ndarray of shape (n_classes, n_features)  
  Variance of each feature per class.

- `theta_` : ndarray of shape (n_classes, n_features)  
  Mean of each feature per class.

Methods
~~~~~~~

- `fit(X, y, sample_weight=None)`  
  Fit Gaussian Naive Bayes according to training data.

- `partial_fit(X, y, classes=None, sample_weight=None)`  
  Incremental fit on a batch of samples. Useful for online learning or out-of-core learning.

- `predict(X)`  
  Perform classification on an array of test vectors.

- `predict_proba(X)`  
  Return probability estimates for the test vectors.

- `predict_log_proba(X)`  
  Return log-probability estimates for the test vectors.

- `predict_joint_log_proba(X)`  
  Return joint log probability estimates for the test vectors.

Example
~~~~~~~

```python
import numpy as np
from sklearn.naive_bayes import GaussianNB

X = np.array([[-1, -1], [-2, -1], [-3, -2], [1, 1], [2, 1], [3, 2]])
y = np.array([1, 1, 1, 2, 2, 2])

clf = GaussianNB()
clf.fit(X, y)
print(clf.predict([[-0.8, -1]]))  # Output: [1]

clf_pf = GaussianNB()
clf_pf.partial_fit(X, y, np.unique(y))
print(clf_pf.predict([[-0.8, -1]]))  # Output: [1]
```

Additional Naive Bayes Variants
-------------------------------

- **BernoulliNB**: Suitable for binary/boolean features.
- **MultinomialNB**: Suitable for discrete count features such as word counts in text classification.
- **ComplementNB**: Designed to improve performance on imbalanced datasets.
- **CategoricalNB**: Designed for categorical features.
