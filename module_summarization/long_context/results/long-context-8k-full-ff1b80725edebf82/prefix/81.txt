====================
SimpleFitter wrapper
====================

Adds a variable height (background) component to any model.

Module API
^^^^^^^^^^

The module provides a simple wrapper class and utility function to enhance spectral models by adding a variable height (background) component.

Classes
-------

SimpleFitter
~~~~~~~~~~~~

A basic fitter class that can be extended for spectral fitting purposes.

Methods:

- __init__():
  Initializes the SimpleFitter instance.

- moments(*args, **kwargs):
  Get the spectral moments from the `moments` package.

Functions
---------

vheightmodel(zeroheightmodel)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Wrapper function to add a variable height component to an existing model function.

Parameters:
- zeroheightmodel : function
  The original model function without a height parameter.

Returns:
- vhm : function
  A wrapped model function that includes a variable height parameter as the first parameter.

Description:
The wrapped function `vhm` takes the x-axis and parameters, where the first parameter is interpreted as the height (background) level added to the output of the original model function. If the keyword argument `vheight` is set to False, the height parameter is ignored.

Example parameter order: height, amplitude, shift, width.

=============================
Generic SpectralModel wrapper
=============================

.. moduleauthor:: Adam Ginsburg <adam.g.ginsburg@gmail.com>

Module API
^^^^^^^^^^

This module provides a comprehensive wrapper class for spectral models, enabling multi-component modeling, parameter management, annotations, integrals, and individual component handling. It supports complex model declarations including parameter naming, limits, units, and annotations.

Classes
-------

SpectralModel
~~~~~~~~~~~~~

A wrapper class for spectral models that extends SimpleFitter.

Description:
This class facilitates the creation and fitting of spectral models with multiple components. It supports detailed parameter management, including naming, limits, fixing, tying, and units. It also supports analytic integral functions and full-width half-maximum (FWHM) calculations.

Initialization Parameters:
- modelfunc : function
  The model function to be fitted. It should accept an X-axis (spectroscopic axis) and model parameters, returning an array of the same shape as the input X-axis.

- npars : int
  Number of parameters required by the model.

- shortvarnames : tuple, optional
  TeX names of the variables used for annotation (default: ("A","\\Delta x","\\sigma")).

- fitunit : str, optional
  Units to convert the X-axis to before passing to the model.

- centroid_par : int or None, optional
  Index of the parameter representing the profile centroid.

- fwhm_func : function or None, optional
  Function to calculate the full-width half-maximum (FWHM).

- fwhm_pars : list or None, optional
  Parameters for the FWHM function.

- integral_func : function or None, optional
  Analytic integral function for the model.

- use_lmfit : bool, optional
  Whether to use lmfit instead of mpfit for fitting (default: False).

- guess_types : tuple, optional
  Types of parameters for initial guesses; valid values include 'amplitude', 'center', and 'width'.

Key Methods:
- __call__(*args, **kwargs):
  Calls the fitter using either lmfit or mpfit depending on the `use_lmfit` flag.

- make_parinfo(**kwargs):
  Generates a ParinfoList object describing the parameters.

- _make_parinfo(...):
  Internal method to generate a ParinfoList from various parameter inputs, handling parameter names, values, limits, fixing, tying, and other attributes. Supports multiple peaks and variable height parameters.

- n_modelfunc(pars=None, debug=False, **kwargs):
  Wrapper to handle multiple independent peaks for the spectral model.

Properties:
- npeaks:
  Number of peaks in the model (integer).

Attributes:
- modelfunc:
  The model function.

- npars:
  Number of parameters per peak.

- parinfo:
  List of parameter information objects.

- vheight:
  Boolean indicating if variable height is included.

Notes:
- The class supports complex parameter management including fixed parameters, tied parameters, limits, and error estimates.
- Supports scaling of amplitude parameters.
- Designed to be extensible for various spectral line models, including hyperfine structure.

Dependencies
------------

- numpy
- pyspeckit.mpfit
- pyspeckit.spectrum.moments
- pyspeckit.spectrum.parinfo
- astropy.log
- matplotlib.cbook
- six
- collections.OrderedDict (or ordereddict for Python <2.7)

Warnings
--------

- OrderedDict is required for modeling. For Python versions earlier than 2.7, the `ordereddict` module must be installed.

Summary
-------

This module provides foundational classes and utilities for spectral model fitting, including a simple fitter with background height adjustment and a comprehensive spectral model wrapper supporting multi-component fitting, parameter management, and integration with fitting libraries such as mpfit and lmfit.
