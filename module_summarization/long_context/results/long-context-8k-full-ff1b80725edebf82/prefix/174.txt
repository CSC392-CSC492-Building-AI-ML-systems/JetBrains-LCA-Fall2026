Array API Support
=================

Scikit-learn aims to provide compatibility with the emerging Array API standard to facilitate interoperability across different array computing libraries. This support enables users to leverage scikit-learn estimators seamlessly with array types that conform to the Array API specification.

Overview
--------

The Array API standard defines a common set of array operations and behaviors, allowing libraries to operate on arrays from various backends (e.g., NumPy, CuPy, Dask) without modification. Scikit-learn's support for the Array API ensures that its estimators and utilities can accept and process array-like inputs adhering to this specification.

Key Features
------------

- **Input Compatibility**: Estimators in scikit-learn accept inputs that implement the Array API, enabling the use of alternative array libraries without explicit conversion to NumPy arrays.

- **Multioutput Estimators**: Meta-estimators such as `MultiOutputRegressor` and `MultiOutputClassifier` support multi-output tasks with Array API-compatible inputs, allowing parallel fitting and prediction across multiple targets.

- **Metadata Routing**: Advanced features like metadata routing (introduced in version 1.3) facilitate passing additional parameters during fitting and partial fitting, enhancing flexibility when working with array types supporting metadata.

Usage Notes
-----------

- When using multi-output meta-estimators, inputs `X` and targets `y` should be array-like objects conforming to the Array API specification, with appropriate shapes:

  - `X`: shape `(n_samples, n_features)`
  - `y`: shape `(n_samples, n_outputs)`

- Sample weights and additional fit parameters can be passed as usual, provided the underlying estimators support them.

- Parallelization via the `n_jobs` parameter in multi-output estimators is supported and can be leveraged to speed up computations when working with large datasets or multiple outputs.

Example
-------

```python
import numpy as np
from sklearn.multioutput import MultiOutputRegressor
from sklearn.linear_model import Ridge

# Assume `X` and `y` are Array API-compatible arrays
X = np.array([[0.1, 1.2], [1.3, 3.4], [2.1, 0.4]])
y = np.array([[1.0, 2.0], [2.0, 3.0], [3.0, 4.0]])

regressor = MultiOutputRegressor(Ridge())
regressor.fit(X, y)
predictions = regressor.predict(X)
```

This example demonstrates fitting a multi-output regressor on Array API-compatible arrays and obtaining predictions.

Additional Information
----------------------

- Scikit-learn's Array API support is continuously evolving to align with updates in the Array API specification and to improve compatibility with various array computing backends.

- For detailed information on metadata routing and advanced parameter passing, refer to the :ref:`User Guide <metadata_routing>`.

- The multi-output estimators provide attributes such as `estimators_`, `n_features_in_`, and `feature_names_in_` to inspect fitted models and feature information, supporting introspection when using Array API arrays.
