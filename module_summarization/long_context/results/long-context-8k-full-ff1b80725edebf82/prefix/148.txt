# General HDF5 File Reader

This document provides an overview of the general HDF5 file reader functionality implemented in the Masci-tools package, focusing on the `HDF5Reader` class and its associated transformation utilities.

---

## Overview

The `HDF5Reader` class is designed to facilitate reading and processing of HDF5 files, a widely used file format for storing large numerical datasets. To enhance flexibility and usability, a collection of predefined transformation functions is provided. These transformations allow users to manipulate datasets extracted from HDF5 files in various ways, such as slicing, reshaping, arithmetic operations, and attribute extraction.

All transformation functions are designed to handle three primary cases gracefully:

1. The dataset is an `h5py.Dataset` object and may need conversion to a NumPy array.
2. The dataset is already a NumPy array.
3. The dataset is a dictionary of datasets or arrays, allowing transformations to be applied to arbitrary child datasets where not all keys are known in advance.

---

## Transformation Functions

Transformation functions are registered via a decorator and can be applied to datasets read by the `HDF5Reader`. Each transformation handles input datasets flexibly and raises clear errors if processing fails.

### Key Transformations

- **Indexing and Slicing**
  - `get_first_element(dataset)`: Returns the first element of the dataset.
  - `index_dataset(dataset, index)`: Returns the element at the specified index.
  - `slice_dataset(dataset, slice_arg)`: Returns a slice of the dataset.

- **Shape and Naming**
  - `get_shape(dataset)`: Returns the shape of the dataset.
  - `get_name(dataset, full_path=False)`: Returns the dataset's name or full path.

- **Array Manipulations**
  - `tile_array(dataset, n_repeats)`: Repeats the dataset `n_repeats` times using `numpy.tile`.
  - `repeat_array(dataset, n_repeats)`: Repeats each element in the dataset `n_repeats` times using `numpy.repeat`.
  - `flatten_array(dataset, order='C')`: Flattens the dataset into a one-dimensional array.
  - `split_array(dataset, suffixes=None, name=None)`: Splits arrays in a dataset into multiple entries by their first index.

- **Arithmetic Operations**
  - `shift_dataset(dataset, scalar_value, negative=False)`: Shifts dataset values by adding or subtracting a scalar.
  - `multiply_scalar(dataset, scalar_value)`: Multiplies dataset values by a scalar.
  - `multiply_array(dataset, matrix, transpose=False)`: Multiplies dataset by a matrix, optionally transposed.

- **Complex Number Handling**
  - `convert_to_complex_array(dataset)`: Converts real-valued datasets into complex arrays following the convention where the last index 0 is the real part and 1 is the imaginary part.

- **Norm and Summation**
  - `calculate_norm(dataset, between_neighbours=False)`: Calculates the norm of dataset entries or distances between neighbors.
  - `cumulative_sum(dataset, beginning_zero=True)`: Computes the cumulative sum of the dataset.
  - `sum_over_dict_entries(dataset, overwrite_dict=False, entries=None, dict_entry='sum', entry_format=None)`: Sums datasets contained in a dictionary.

- **Dataset Extraction and Group Handling**
  - `get_all_child_datasets(group, ignore=None, contains=None)`: Retrieves all datasets contained in a given HDF5 group, with optional filtering.
  - `merge_subgroup_datasets(group, ignore=None, contains=None, ignore_group=None, contains_group=None, stack_results=True, sort_key=None)`: Merges datasets from subgroups within a group, with filtering and optional stacking.

- **Attribute Handling**
  - `get_attribute(dataset, attribute_name)`: Extracts a specified attribute from a dataset.
  - `attributes(dataset)`: Extracts all attributes from a dataset.

- **Memory and Data Conversion**
  - `move_to_memory(dataset)`: Converts datasets to in-memory NumPy arrays.
  - `convert_to_str(dataset, join=False)`: Converts datasets to NumPy arrays of strings, optionally joining them.
  - `apply_lambda(dataset, lambda_func)`: Applies a user-provided lambda function to the dataset.
  - `periodic_elements(dataset)`: Converts atomic numbers to their corresponding chemical element symbols.

- **Stacking and Sorting**
  - `stack_datasets(dataset, axis=0, sort_key=None)`: Stacks entries in a dictionary dataset along a specified axis.

---

## Error Handling

All transformation functions are wrapped to catch exceptions and raise a `HDF5TransformationError` with a clear message indicating which transformation failed and why. This ensures that errors during dataset processing are informative and easy to debug.

---

## Usage Notes

- Transformations can be applied to datasets directly or to dictionaries of datasets, enabling flexible handling of complex HDF5 file structures.
- Some transformations require the dataset to be an `h5py.Dataset` and will raise `NotImplementedError` if applied to unsupported types.
- Filtering options such as `ignore` and `contains` allow selective processing of datasets or groups based on their names.
- The transformations support both simple numerical operations and more complex manipulations like converting to complex arrays or extracting chemical element symbols.
