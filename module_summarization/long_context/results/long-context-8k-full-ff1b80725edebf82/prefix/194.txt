Pairwise Metrics, Affinities and Kernels
========================================

This section covers functions and utilities for computing pairwise metrics, affinities, and kernels between samples in datasets. These computations are fundamental in many machine learning algorithms, including clustering, classification, and dimensionality reduction.

Pairwise Metrics
----------------

Pairwise metrics compute distances or similarities between pairs of samples. The most common pairwise metric is the Euclidean distance, which measures the straight-line distance between two points in a feature space.

### Euclidean Distances

The `euclidean_distances` function computes the distance matrix between each pair of samples from two arrays `X` and `Y`. For efficiency, the Euclidean distance between vectors `x` and `y` is computed using the formula:

.. math::

    dist(x, y) = \sqrt{\|x\|^2 - 2 \langle x, y \rangle + \|y\|^2}

This approach is computationally efficient, especially for sparse data, and allows pre-computation of norms when one argument remains fixed.

**Parameters:**

- `X` : array-like or sparse matrix of shape (n_samples_X, n_features)  
  Input data where each row corresponds to a sample.

- `Y` : array-like or sparse matrix of shape (n_samples_Y, n_features), default=None  
  Input data where each row corresponds to a sample. If `None`, `Y` is set to `X`.

- `Y_norm_squared` : array-like, optional  
  Precomputed squared norms of `Y` samples.

- `squared` : bool, default=False  
  If True, returns squared Euclidean distances.

- `X_norm_squared` : array-like, optional  
  Precomputed squared norms of `X` samples.

**Returns:**

- `distances` : ndarray of shape (n_samples_X, n_samples_Y)  
  Matrix of distances between samples in `X` and `Y`.

**Notes:**

- The distance matrix may not be exactly symmetric due to floating point rounding.
- Precomputed norms can improve accuracy and efficiency.
- For float32 inputs, computations are internally upcast to float64 to reduce precision errors.

**Example:**

```python
from sklearn.metrics.pairwise import euclidean_distances
X = [[0, 1], [1, 1]]
euclidean_distances(X, X)
# Output:
# array([[0., 1.],
#        [1., 0.]])
```

### Euclidean Distances with Missing Values

The `nan_euclidean_distances` function computes Euclidean distances while handling missing values (e.g., `np.nan`). It ignores missing coordinates when computing distances and scales the result to account for the reduced number of features considered.

**Key points:**

- Missing values are ignored in distance computation.
- Distances are scaled by the ratio of total features to present features.
- Returns `NaN` if no common present features exist between samples.

**Parameters:**

- `X` : array-like of shape (n_samples_X, n_features)  
- `Y` : array-like of shape (n_samples_Y, n_features), default=None  
- `squared` : bool, default=False  
- `missing_values` : scalar, default=np.nan  
- `copy` : bool, default=True  

**Returns:**

- `distances` : ndarray of shape (n_samples_X, n_samples_Y)

**Example:**

```python
from sklearn.metrics.pairwise import nan_euclidean_distances
import numpy as np
nan = float("NaN")
X = [[0, 1], [1, nan]]
nan_euclidean_distances(X, X)
# Output:
# array([[0.        , 1.41421356],
#        [1.41421356, 0.        ]])
```

Utilities for Input Validation
------------------------------

Functions such as `check_pairwise_arrays` and `check_paired_arrays` ensure that input arrays are valid for pairwise computations. They verify dimensionality, data types, and compatibility between `X` and `Y`.

- `check_pairwise_arrays` prepares and validates inputs for general pairwise metrics.
- `check_paired_arrays` validates inputs for paired distances where `X` and `Y` must have the same shape.

These utilities help maintain consistency and prevent errors during metric computations.

Affinities and Kernels
----------------------

Beyond distances, affinity and kernel functions measure similarity between samples. Kernels are functions that implicitly map data into higher-dimensional spaces, enabling algorithms like Support Vector Machines and Kernel PCA.

While this document focuses on pairwise distances, the module also includes implementations of various affinity and kernel functions, such as:

- Chi-squared kernel
- Sparse Manhattan kernel

These functions leverage efficient computations and support sparse data formats.

Summary
-------

The pairwise metrics module provides robust and efficient implementations for computing distances and similarities between samples, including support for missing data and sparse inputs. Proper input validation ensures reliable usage across various machine learning tasks.

For more detailed usage and examples, refer to the User Guide section on metrics.
