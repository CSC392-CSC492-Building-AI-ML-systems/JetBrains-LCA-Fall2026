Utilities for Developers
========================

This section documents various utility functions and compatibility fixes provided to assist developers working with scikit-learn. These utilities cover compatibility across different versions of Python, NumPy, SciPy, and threadpoolctl, as well as enhancements to parallel processing, input validation, metadata routing, and mathematical functions.

Compatibility Fixes
------------------

The utilities include compatibility fixes for older versions of Python, NumPy, and SciPy. These fixes ensure consistent behavior across different environments by adapting to API changes and deprecations. For example:

- Sparse matrix container lists are extended to include sparse arrays introduced in SciPy 1.8.
- Functions like `line_search_wolfe1` and `line_search_wolfe2` are imported conditionally depending on SciPy version.
- The `percentile` function adapts to changes in NumPy's API regarding the `method` and `interpolation` keyword arguments.
- Backports of Python 3.9's `importlib.resources` functions are provided for compatibility with earlier Python versions.
- Warnings and exceptions from NumPy are imported conditionally based on the NumPy version.
- The `trapezoid` integration function is backported for SciPy versions prior to 1.6.

Threadpool Control Utilities
----------------------------

Utilities are provided to manage threadpool limits and information, abstracting differences in the `threadpoolctl` package versions:

- `threadpool_limits(limits=None, user_api=None)`: Context manager to limit the number of threads used in thread pools.
- `threadpool_info()`: Returns information about thread pools currently in use.

These functions internally manage a global threadpool controller to optimize performance.

Parallel Processing Enhancements
-------------------------------

A customized `Parallel` class extends `joblib.Parallel` to propagate scikit-learn's thread-local configuration to parallel workers. This ensures that configuration settings are consistently applied during parallel execution.

- `Parallel`: Subclass of `joblib.Parallel` that captures and propagates scikit-learn configuration.
- `delayed(function)`: Decorator to capture function arguments and propagate configuration when used with the customized `Parallel`.

These tools facilitate safe and consistent parallel computation within scikit-learn workflows.

Mathematical Utilities
----------------------

- `_log_logistic_sigmoid`: Efficient Cython-implemented function to compute the logarithm of the logistic sigmoid function element-wise on arrays.
- `_mode`: Compatibility wrapper around `scipy.stats.mode` to handle API changes across SciPy versions.
- `_sparse_linalg_cg`: Compatibility wrapper for the conjugate gradient solver in `scipy.sparse.linalg` to handle parameter changes.

Metadata Routing
----------------

The metadata routing utilities provide a framework for managing metadata requests and routing within scikit-learn objects. This includes classes and functions such as:

- `MetadataRouter`
- `MetadataRequest`
- `MethodMapping`
- `get_routing_for_object`
- `process_routing`

These utilities support advanced internal mechanisms for metadata handling and are primarily intended for developers extending scikit-learn's core functionality.

Input Validation Utilities
--------------------------

Robust input validation functions ensure data integrity and provide informative error messages:

- `assert_all_finite(X, *, allow_nan=False, estimator_name=None, input_name="")`: Checks that input data contains no NaN or infinite values, with options to allow NaNs and customize error messages.
- `_assert_all_finite`: Internal function specialized for ndarray inputs.
- `_assert_all_finite_element_wise`: Performs element-wise finiteness checks, optionally using optimized Cython implementations.
- `_deprecate_positional_args(func=None, *, version="1.3")`: Decorator to warn about deprecated positional arguments in function calls.

These utilities help maintain data quality and guide users towards best practices when preparing data for machine learning.

Additional Utilities
--------------------

- `_object_dtype_isnan(X)`: Detects NaN values in object-dtype arrays.
- Backports and fixes for various functions and warnings to maintain compatibility across dependencies.
- Helper functions for resource file handling compatible with multiple Python versions.

Summary
-------

The utilities provided serve as foundational tools for scikit-learn developers, ensuring compatibility, enhancing parallel processing, validating inputs, and supporting internal metadata management. They abstract away many complexities arising from dependency version differences and provide a consistent development experience.
