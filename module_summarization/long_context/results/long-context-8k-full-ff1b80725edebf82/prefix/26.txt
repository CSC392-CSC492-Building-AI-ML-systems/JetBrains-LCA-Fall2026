w_kinavg — Average rates and confidence intervals for path-tracing kinetics analysis
======================================================================================

Description
-----------

The `w_kinavg` command calculates average rates and associated confidence intervals (CIs) from weighted ensemble kinetics data. It processes bin assignments (typically stored in `assignments.h5`) and kinetics data files (such as `kintrace.h5` or `kinmat.h5`) that must have been generated previously using tools like `w_assign` and `w_kinetics`.

This command supports the **trace** subcommand, which performs path-tracing kinetics analysis to compute averages and confidence intervals over specified iteration windows.

Output Format
-------------

The output file (specified with `-o` or `--output`, defaulting to `kinavg.h5`) contains datasets with the following structure:

- **/avg_rates** `[state,state]`  
  Structured dataset containing state-to-state rates averaged over the entire selected iteration window.

In **trace** mode, additional datasets are generated:

- **/avg_total_fluxes** `[state]`  
  Structured dataset of total fluxes into each state averaged over the selected iteration window.

- **/avg_conditional_fluxes** `[state,state]`  
  Structured dataset of state-to-state fluxes averaged over the selected iteration window.

If the `--evolution-mode` option is specified, the following datasets are also available:

- **/rate_evolution** `[window][state][state]`  
  Structured dataset of state-to-state rates computed over windows of iterations with varying widths.  
  - If `--evolution-mode=cumulative`, windows start at `--start-iter` and grow by `--step-iter` for each successive element.  
  - If `--evolution-mode=blocked`, windows have fixed width `--step-iter` (except possibly the last), starting at `--start-iter`.

In **trace** mode with `--evolution-mode`, these additional datasets are provided:

- **/target_flux_evolution** `[window,state]`  
  Structured dataset of total flux into each macro state over iteration windows as described above.

- **/conditional_flux_evolution** `[window,state,state]`  
  Structured dataset of state-to-state fluxes over iteration windows as described above.

Dataset Structure
-----------------

Each dataset contains the following fields:

- **iter_start**  
  Integer indicating the iteration at which the averaging window begins (inclusive).

- **iter_stop**  
  Integer indicating the iteration at which the averaging window ends (exclusive).

- **expected**  
  Floating-point value representing the expected (mean) rate within the window, in units of inverse tau.

- **ci_lbound**  
  Floating-point value for the lower bound of the confidence interval on the rate, in units of inverse tau.

- **ci_ubound**  
  Floating-point value for the upper bound of the confidence interval on the rate, in units of inverse tau.

- **corr_len**  
  Integer representing the correlation length of the rate within the window, in units of tau.

Each dataset is also annotated with the following attributes:

- **mcbs_alpha**  
  Floating-point alpha value used for confidence intervals (e.g., `0.05` corresponds to a 95% confidence interval).

- **mcbs_nsets**  
  Integer number of bootstrap data sets used to generate confidence intervals.

- **mcbs_acalpha**  
  Floating-point alpha value used to determine correlation lengths.

Command-Line Options
--------------------

Run `w_kinavg trace --help` to see detailed command-line options for the trace subcommand.

Deprecation Notice
------------------

The `w_kinavg` command is deprecated. Users are encouraged to use the `w_direct` command instead for direct kinetics analysis. The `w_kinavg` command remains available for backward compatibility but may be removed in future releases.
