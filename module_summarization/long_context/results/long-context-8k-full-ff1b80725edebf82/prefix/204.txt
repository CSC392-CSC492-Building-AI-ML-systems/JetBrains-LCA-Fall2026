Random Projection
=================

Random Projections provide a simple and computationally efficient method to reduce the dimensionality of data. This technique achieves dimensionality reduction by projecting the original high-dimensional data onto a lower-dimensional subspace using a random matrix. The key idea is to trade a controlled amount of accuracy—manifested as additional variance—for faster processing times and smaller model sizes.

Theoretical Background
----------------------

The effectiveness of random projections is underpinned by the Johnson-Lindenstrauss lemma, which guarantees that a small set of points in a high-dimensional Euclidean space can be embedded into a space of much lower dimension such that the pairwise distances between points are approximately preserved. Formally, for any two points \( u \) and \( v \), the random projection \( p \) satisfies:

\[
(1 - \varepsilon) \|u - v\|^2 < \|p(u) - p(v)\|^2 < (1 + \varepsilon) \|u - v\|^2
\]

with high probability, where \( \varepsilon \in (0,1) \) controls the distortion level.

The minimal number of components \( n_{\text{components}} \) required to guarantee this embedding with distortion \( \varepsilon \) for a dataset with \( n_{\text{samples}} \) points is given by:

\[
n_{\text{components}} \geq \frac{4 \log(n_{\text{samples}})}{\varepsilon^2 / 2 - \varepsilon^3 / 3}
\]

This bound is independent of the original number of features and depends only on the number of samples and the desired distortion level.

Key Features
------------

- **Dimensionality Reduction:** Efficiently reduces the number of features while approximately preserving distances.
- **Computational Efficiency:** Random projection matrices can be generated quickly and applied efficiently.
- **Flexibility:** Supports both dense Gaussian random matrices and sparse random matrices.
- **Theoretical Guarantees:** Provides probabilistic guarantees on distance preservation via the Johnson-Lindenstrauss lemma.

Available Transformers
----------------------

### GaussianRandomProjection

Projects data using a dense Gaussian random matrix whose components are drawn from a normal distribution \( \mathcal{N}(0, 1 / n_{\text{components}}) \).

- Suitable for dense data.
- Automatically determines the number of components based on the Johnson-Lindenstrauss lemma if `n_components='auto'`.
- Allows control over the embedding quality via the `eps` parameter.
- Optionally computes the pseudo-inverse of the projection matrix for inverse transformations.

### SparseRandomProjection

Projects data using a sparse random matrix, which can be more efficient for high-dimensional sparse data.

- The sparsity level can be controlled via the `density` parameter.
- Supports the Achlioptas matrix and its generalizations.
- Provides similar theoretical guarantees as Gaussian random projections.

Usage Example
-------------

```python
import numpy as np
from sklearn.random_projection import GaussianRandomProjection

rng = np.random.RandomState(42)
X = rng.rand(25, 3000)  # Original high-dimensional data

transformer = GaussianRandomProjection(random_state=rng)
X_new = transformer.fit_transform(X)

print(X_new.shape)  # Output: (25, n_components)
```

Parameters
----------

- **n_components** : int or 'auto', default='auto'  
  Dimensionality of the target projection space. If set to 'auto', the number of components is determined based on the Johnson-Lindenstrauss lemma and the number of samples.

- **eps** : float, default=0.1  
  Controls the quality of the embedding when `n_components='auto'`. Smaller values lead to better embeddings but higher dimensionality.

- **compute_inverse_components** : bool, default=False  
  Whether to compute the pseudo-inverse of the projection matrix to enable inverse transformations.

- **random_state** : int, RandomState instance or None, default=None  
  Controls the random number generator for reproducibility.

Notes
-----

Random projections are particularly useful when dealing with very high-dimensional data where traditional dimensionality reduction techniques like PCA become computationally expensive. While random projections do not guarantee optimal embeddings for all datasets, they provide a fast and scalable alternative with strong theoretical backing.
