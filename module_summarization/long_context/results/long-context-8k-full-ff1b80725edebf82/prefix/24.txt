w_init Command
==============

Overview
--------

The `w_init` command initializes a new WEST simulation by creating the WEST HDF5 file and preparing the first iteration's segments. It sets up the initial states from which the simulation will begin, including basis states, start states, and optionally target states for steady-state simulations.

Initial States
--------------

Initial states are generated from one or more **basis states**, which can be specified in two ways:

- From a file using the `--bstates-from` (or `--bstate-file`) option.
- By providing one or more `--bstate` arguments directly on the command line.

If neither `--bstates-from` nor at least one `--bstate` argument is provided, a default basis state with probability one, identified by state ID zero and label `"basis"`, will be created. A warning will be printed in this case to remind you of this default behavior.

Start states can also be specified similarly using:

- The `--sstates-from` (or `--sstate-file`) option to read from a file.
- One or more `--sstate` arguments on the command line.

Target States
-------------

Target states are used for non-equilibrium steady-state simulations and define recycling sinks in the simulation. They can be specified by:

- A file using the `--tstates-from` (or `--tstate-file`) option.
- One or more `--tstate` arguments on the command line.

If neither `--tstates-from` nor any `--tstate` arguments are provided, the simulation will run as an equilibrium simulation without any sinks.

Command-Line Options
--------------------

- `--force`  
  Overwrite any existing simulation data.

- `--bstates-from BSTATE_FILE`, `--bstate-file BSTATE_FILE`  
  Read basis state names, probabilities, and optionally data references from the specified file.

- `--bstate 'label,probability[,auxref]'`  
  Add a basis state with the given label, probability, and optional auxiliary reference. This option can be specified multiple times to add multiple basis states.

- `--tstates-from TSTATE_FILE`, `--tstate-file TSTATE_FILE`  
  Read target state names and representative progress coordinates from the specified file. The entire bin containing the representative progress coordinate is converted into a recycling sink.

- `--tstate 'label,pcoord0[,pcoord1[,...]]'`  
  Add a target state with the given label and progress coordinate(s). This option can be specified multiple times.

- `--sstates-from SSTATE_FILE`, `--sstate-file SSTATE_FILE`  
  Read start state names, probabilities, and optionally data references from the specified file.

- `--sstate 'label,probability[,auxref]'`  
  Add a start state with the given label, probability, and optional auxiliary reference. This option can be specified multiple times.

- `--segs-per-state N`  
  Initialize `N` segments from each basis state. Default is 1.

- `--no-we`, `--shotgun`  
  Do not run the weighted ensemble bin/split/merge algorithm on newly-created segments.

Additional Options
------------------

The command also supports additional options related to the work manager environment, which can be viewed by running `w_init --help`.

Behavior and Notes
------------------

- The total probability of all basis and start states is checked and, if it does not sum to unity within numerical precision, the probabilities are rescaled accordingly. A warning is issued if rescaling occurs.

- If no basis states are provided, the command will exit with an error.

- Target states define recycling sinks by converting the entire bin containing the target state's representative progress coordinate into a sink.

- The `--no-we` or `--shotgun` option disables the weighted ensemble algorithm on the initial segments, which can be useful for certain simulation setups.

Example Usage
-------------

Initialize a simulation with basis states specified in a file and 5 segments per state:

```
w_init --bstates-from basis_states.txt --segs-per-state 5
```

Initialize a simulation with explicit basis states and target states:

```
w_init --bstate "stateA,0.6" --bstate "stateB,0.4" --tstate "sink,1.0"
```

Initialize a simulation without weighted ensemble resampling on initial segments:

```
w_init --bstates-from basis_states.txt --no-we
```

Summary
-------

The `w_init` command is the first step in setting up a WEST simulation, defining the initial and target states, and preparing the simulation environment. Proper specification of basis states and target states is essential for accurate simulation initialization.
