Contributing to Qiskit Metal
=============================

Welcome to the Qiskit Metal contributor guide! This document provides an overview of how to contribute to the Qiskit Metal project, including coding standards, licensing, and best practices to ensure a smooth collaboration.

Coding Standards and Documentation
----------------------------------

- All source files should begin with the standard Qiskit copyright and license header as shown above.
- Use UTF-8 encoding for all source files.
- Include module-level docstrings that describe the purpose of the module, authorship, and date.
- Use clear and descriptive docstrings for all functions and classes, including descriptions of arguments, return values, and exceptions.
- Follow PEP 8 style guidelines for Python code.
- Use meaningful variable and function names to improve readability.
- Include examples and usage notes in docstrings where appropriate.

Project Structure and Modules
-----------------------------

Qiskit Metal is organized into several modules and submodules, including but not limited to:

- `qiskit_metal.analyses`: Contains all Qiskit Metal analyses, including electromagnetic and Hamiltonian analyses.
- `qiskit_metal.analyses.em`: Electromagnetic analyses.
- `qiskit_metal.analyses.hamiltonian`: Hamiltonian-only analyses.
- `qiskit_metal.analyses.cp_calculations`: Tools for coplanar waveguide (CPW) parameter calculations.
- `qiskit_metal.analyses.lumped_capacitive`: Lumped element equivalent calculations for CPW transmission lines.

When contributing new features or fixes, please place your code in the appropriate module and ensure it is well documented.

Testing and Validation
----------------------

- Write unit tests for new features and bug fixes.
- Ensure that all tests pass before submitting a pull request.
- Use existing test frameworks and follow the style of current tests.
- Validate numerical calculations and physical models carefully, especially for analyses involving electromagnetic properties and Hamiltonian parameters.

Submitting Contributions
------------------------

- Fork the repository and create a feature branch for your work.
- Commit changes with clear, concise commit messages.
- Push your branch and submit a pull request describing your changes.
- Engage with code reviewers and address feedback promptly.
- Ensure your pull request passes all continuous integration checks.

Acknowledgments and Authorship
------------------------------

- Include your name and the date in module docstrings when adding new modules or significant features.
- Acknowledge prior authors and contributors in the docstrings where applicable.
- Maintain clear authorship information to facilitate collaboration and credit.

Additional Notes
----------------

- When modifying existing files, add a notice in the file indicating that it has been altered from the original.
- For complex calculations or algorithms, provide references to relevant literature or sources in the docstrings.
- Use consistent units and clearly document them in function arguments and return values.
- When handling physical constants or parameters, define them clearly and use standard scientific notation.

Thank you for contributing to Qiskit Metal! Your efforts help advance quantum hardware design and simulation tools for the community.
