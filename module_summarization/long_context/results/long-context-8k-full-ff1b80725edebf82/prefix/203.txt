Transforming the Prediction Target
==================================

In many machine learning workflows, it is often necessary to transform the prediction target (also known as the response variable or label) before fitting a model. This transformation can help in encoding categorical targets, handling missing values, or grouping infrequent categories to improve model performance and robustness.

Base Encoder for Target Transformation
--------------------------------------

The `_BaseEncoder` class serves as a foundational transformer for encoding categorical targets. It provides functionality to:

- Validate and preprocess input target data.
- Identify unique categories and their counts.
- Handle unknown categories during transformation.
- Map infrequent categories to a single category to reduce noise and improve generalization.

Key Features
------------

### Input Validation and Preprocessing

- Supports input as arrays or pandas DataFrames.
- Preserves data types of individual features to maintain category integrity.
- Checks for missing values and handles them appropriately.
- Converts string categories to object dtype to avoid truncation issues.

### Category Handling

- Automatically determines categories if not provided.
- Validates predefined categories for consistency and sorting.
- Raises errors or handles unknown categories gracefully during transformation.
- Supports returning category counts for further analysis.

### Infrequent Category Mapping

- Enables grouping of infrequent categories based on minimum frequency or maximum number of categories.
- Provides a mapping from original categories to frequent and infrequent groups.
- Missing values can be excluded from infrequent category consideration.
- Supports ignoring specific category indices during infrequent category mapping.

### Transformation Process

- Encodes categories into integer labels.
- Marks unknown categories and optionally warns the user.
- Maps infrequent categories to a single integer label.
- Returns encoded integer arrays along with masks indicating valid entries.

Usage Notes
-----------

- The encoder must be fitted on the training target data to learn categories and infrequent mappings.
- During transformation, unknown categories can either raise errors or be encoded as zeros.
- The `infrequent_categories_` property provides access to the grouped infrequent categories for each feature.
- Parameters such as `max_categories` and `min_frequency` control the behavior of infrequent category grouping.

Example Workflow
----------------

1. Initialize the encoder with desired parameters (e.g., `max_categories`, `min_frequency`).
2. Fit the encoder on the training target data using the `_fit` method.
3. Transform new target data using the `_transform` method to obtain encoded labels.
4. Use the encoded labels for model training or evaluation.

This approach ensures that the prediction target is consistently encoded, handles rare categories effectively, and is robust to unknown or missing values during prediction.
