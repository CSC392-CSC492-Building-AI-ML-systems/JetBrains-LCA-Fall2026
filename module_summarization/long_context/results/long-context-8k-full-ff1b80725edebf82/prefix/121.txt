Create Cradmin Menu System
==========================

The Cradmin menu system provides a flexible and extensible way to create navigation menus in your Django application using renderable components. This documentation describes the core classes and functions used to build menus with Cradmin.

Overview
--------

Cradmin menus are composed of renderable items such as links, buttons, separators, and expandable menus. These items are subclasses of `django_cradmin.renderable.AbstractRenderable` and are designed to be easily customized and extended.

The menu system supports both large screen (desktop) menus and small screen (mobile) expandable menus, with default implementations provided.

Getting the Default Expandable Menu Renderable
----------------------------------------------

You can retrieve the default expandable menu renderable using the function:

```python
get_default_expandable_menu_renderable(**kwargs)
```

This function returns an instance of the class specified by the Django setting `DJANGO_CRADMIN_DEFAULT_EXPANDABLE_MENU_CLASS`, or `None` if no such setting is defined.

Menu Item Renderables
---------------------

### BaseMenuLinkRenderable

Base class for menu link items. It renders a link with a label and URL, and supports an active state for styling.

**Constructor parameters:**

- `label`: The text label shown in the menu.
- `url`: The URL to navigate to when clicked.
- `is_active`: Boolean indicating if the link should be styled as active.
- `bem_variant_list`: Optional list of BEM CSS variants.
- `parent_bem_block`: Optional BEM block name for CSS styling.

### NavLinkItemRenderable

Subclass of `BaseMenuLinkRenderable` used to add standard links to the main menu.

### NavLinkButtonItemRenderable

Subclass of `NavLinkItemRenderable` used to add links styled as buttons to the main menu.

### ExpandableMenuItem

Subclass of `BaseMenuLinkRenderable` used to add links to expandable menus (typically for mobile views). It uses a different template and BEM block.

### ExpandableMenuSeparator

Renderable used to add separators between items in expandable menus.

### MenuToggleItemItemRenderable

Renderable used to add a toggle button for expandable menus, typically shown on small screens to open or close the menu.

Menu Renderables
----------------

### AbstractMenuRenderable

Base class for rendering menus. It manages a list of renderable menu items and provides methods to create and manipulate links, buttons, and separators.

Key features:

- Configurable renderable classes for links, buttons, and separators.
- Methods to append, prepend, or insert menu items.
- Supports BEM CSS naming conventions.
- Abstract methods to define BEM blocks and parent blocks for child renderables.
- Can be subclassed to create fully custom menus with custom templates.

### DefaultMainMenuRenderable

The default menu renderable for large screens (desktop). It uses:

- `NavLinkItemRenderable` for links.
- `NavLinkButtonItemRenderable` for buttons.
- `MenuToggleItemItemRenderable` for the menu toggle button.

It supports integration with an expandable menu renderable for small screens and manages the visibility of the menu toggle button accordingly.

### DefaultExpandableMenuRenderable

The default menu renderable for small screens (mobile). It uses:

- `ExpandableMenuItem` for links.
- `ExpandableMenuSeparator` for separators.

It does not support buttons by default.

Usage Notes
-----------

- Menus are composed by creating instances of menu renderables and adding child renderables using methods like `append_link()`, `prepend_button()`, or `append_separator()`.
- The BEM (Block Element Modifier) methodology is used for CSS class naming to ensure consistent styling.
- The menu toggle button is automatically shown if an expandable menu is available.
- You can customize the menu appearance by subclassing the renderables and providing your own templates.

Example
-------

Here is a brief example of creating a main menu with links and a button:

```python
menu = DefaultMainMenuRenderable(request)
menu.append_link(label='Home', url='/')
menu.append_link(label='Profile', url='/profile/', is_active=True)
menu.append_button(label='Logout', url='/logout/')
```

This will render a desktop menu with two links and a logout button, highlighting the active "Profile" link.

Templates
---------

Each renderable uses a specific Django template for rendering:

- `BaseMenuLinkRenderable`: `'django_cradmin/crmenu/menuitem/link.django.html'`
- `ExpandableMenuItem`: `'django_cradmin/crmenu/menuitem/expandable-menu-item.django.html'`
- `ExpandableMenuSeparator`: `'django_cradmin/crmenu/menuitem/expandable-menu-separator.django.html'`
- `MenuToggleItemItemRenderable`: `'django_cradmin/crmenu/menuitem/menutoggle.django.html'`
- `DefaultMainMenuRenderable`: `'django_cradmin/crmenu/menu/default-main.django.html'`
- `DefaultExpandableMenuRenderable`: `'django_cradmin/crmenu/menu/default-expandable.django.html'`

You can override these templates to customize the HTML output.

Settings
--------

- `DJANGO_CRADMIN_DEFAULT_EXPANDABLE_MENU_CLASS`: Specifies the class used for the default expandable menu renderable.

Summary
-------

The Cradmin menu system provides a modular and extensible framework for building navigation menus in Django applications. By leveraging renderable components and BEM CSS conventions, it supports both desktop and mobile-friendly menus with customizable appearance and behavior.
