How to Generate Schema
======================

This module provides functionality to generate and apply SQL schemas for a given database client.

Functions
---------

get_schema_sql(client: BaseDBAsyncClient, safe: bool) -> str
    Generates the SQL schema for the specified database client.

    :param client: The database client for which to generate the schema SQL.
    :param safe: If set to True, the generated SQL will create tables only if they do not already exist.
    :return: A string containing the SQL schema.

generate_schema_for_client(client: BaseDBAsyncClient, safe: bool) -> None
    Asynchronously generates and applies the SQL schema directly to the specified database client.

    :param client: The database client to which the schema will be applied.
    :param safe: If set to True, tables will be created only if they do not already exist.
    :return: None

Usage
-----

1. Use `get_schema_sql` to generate the SQL schema as a string. This can be useful if you want to inspect or modify the schema SQL before applying it.

2. Use `generate_schema_for_client` to generate and apply the schema directly to the database client asynchronously. This function logs the generated schema at the debug level before applying it.

Notes
-----

- The `safe` parameter in both functions controls whether the schema creation commands include checks to avoid overwriting existing tables.
- The functions expect a database client instance that implements the `BaseDBAsyncClient` interface and provides a `schema_generator` method.
- Logging is performed using the "tortoise" logger to provide debug information about schema creation.
