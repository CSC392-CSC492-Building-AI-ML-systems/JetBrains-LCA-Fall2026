Array Best Practices
====================

This document outlines best practices for working with arrays in Dask, focusing on efficient usage, interoperability with NumPy masked arrays, image processing, and percentile computations.

1. Working with Masked Arrays
-----------------------------

Dask provides support for NumPy masked arrays (`numpy.ma`) with many familiar functions adapted to work efficiently on Dask arrays. When working with masked arrays, consider the following:

- Use `dask.array.ma.masked_array` to create masked arrays from Dask arrays. This function supports broadcasting and chunk-wise operations.
- Functions such as `filled`, `masked_equal`, `masked_invalid`, `masked_inside`, `masked_outside`, `masked_where`, `masked_values`, `fix_invalid`, `getdata`, and `getmaskarray` are available and operate lazily on Dask arrays.
- Reduction operations like `count` and `average` are implemented to work efficiently with masked arrays.
- Use `set_fill_value` to set the fill value for masked arrays.
- Element-wise operations such as `masked_greater`, `masked_less_equal`, and `masked_not_equal` are wrapped to work with Dask arrays.
- Use `nonzero` and `where` for conditional indexing and selection on masked arrays.
- When creating masked arrays, ensure that the mask shape is compatible with the data shape to avoid errors.
- Avoid passing non-scalar `fill_value` or `value` arguments to masked array functions, as these are not supported.

Example:

```python
import dask.array as da
import numpy as np

x = da.from_array(np.arange(10), chunks=5)
mask = x > 5
mx = da.ma.masked_array(x, mask=mask)
filled_x = da.ma.filled(mx, fill_value=0)
```

2. Image Processing with Dask Arrays
------------------------------------

Dask supports reading and processing stacks of images efficiently using lazy evaluation and chunking:

- Use `dask.array.image.imread` to read multiple image files matching a glob pattern into a single Dask array.
- Each image file is treated as an individual chunk, enabling parallel and out-of-core processing.
- You can provide a custom `imread` function or a preprocessing function to customize image loading and transformation.
- The resulting array stacks images along the first dimension.

Example:

```python
from dask.array.image import imread

images = imread('images/*.png')
print(images.shape)  # e.g., (number_of_images, height, width, channels)
```

3. Percentile Computations on Dask Arrays
-----------------------------------------

Dask provides an approximate percentile function for 1-dimensional arrays with several internal methods:

- Use `dask.array.percentile` to compute approximate percentiles on large arrays.
- Supported internal methods include:
  - `"dask"`: Dask's internal custom algorithm.
  - `"tdigest"`: Uses the t-digest algorithm for floating-point and integer data (requires the `crick` package).
  - `"default"`: Alias for `"dask"`.
- The function supports various interpolation methods: `'linear'`, `'lower'`, `'higher'`, `'midpoint'`, and `'nearest'`.
- Percentile computations are currently implemented only for 1-D arrays.
- The function automatically handles categorical and datetime data types.
- The percentile computation is performed in two stages: chunk-wise percentile calculation followed by merging results.
- Use `merge_percentiles` to combine percentile results from multiple chunks if needed.

Example:

```python
import dask.array as da

x = da.random.random(10000, chunks=1000)
p = da.percentile(x, [25, 50, 75], method='linear', internal_method='tdigest')
print(p.compute())
```

4. General Best Practices
-------------------------

- Always use Dask array functions (`map_blocks`, `blockwise`, `elemwise`, `reduction`) to ensure operations are performed lazily and in parallel.
- When working with masked arrays, convert inputs to Dask arrays using `asanyarray` to maintain compatibility.
- Avoid passing arrays as scalar parameters (e.g., `fill_value`, `value`) to masked array functions.
- Use `tokenize` to generate unique keys for Dask graphs when implementing custom functions.
- When reading large datasets (e.g., images), leverage chunking to enable out-of-core computation.
- Be mindful of the dimensionality requirements of functions (e.g., percentile requires 1-D arrays).
- Use `derived_from` decorator to maintain API consistency with NumPy functions.
- Handle exceptions and input validation carefully to avoid runtime errors in distributed computations.
