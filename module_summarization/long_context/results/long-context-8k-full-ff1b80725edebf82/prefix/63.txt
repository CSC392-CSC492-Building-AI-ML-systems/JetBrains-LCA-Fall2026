Commands Module
===============

This module provides a set of functions to manage database schema migrations using Alembic. It includes commands to initialize migration environments, create and manage revisions, upgrade and downgrade database schemas, and inspect migration history.

Functions
---------

list_templates(config)
    List available migration environment templates.

    :param config: a :class:`.Config` object.

init(config, directory, template='generic', package=False)
    Initialize a new scripts directory for migrations.

    :param config: a :class:`.Config` object.
    :param directory: string path of the target directory.
    :param template: string name of the migration environment template to use.
    :param package: if True, write ``__init__.py`` files into the environment and versions directories.

revision(config, message=None, autogenerate=False, sql=False, head='head', splice=False, branch_label=None, version_path=None, rev_id=None, depends_on=None, process_revision_directives=None)
    Create a new revision file.

    :param config: a :class:`.Config` object.
    :param message: string message to apply to the revision.
    :param autogenerate: whether to autogenerate the script from the database.
    :param sql: whether to dump the script as a SQL string.
    :param head: head revision to build the new revision upon.
    :param splice: whether the new revision should be made into a new head.
    :param branch_label: string label to apply to the branch.
    :param version_path: string symbol identifying a specific version path.
    :param rev_id: optional revision identifier to use instead of generating one.
    :param depends_on: optional list of "depends on" identifiers.
    :param process_revision_directives: callable to programmatically alter the revision process.

check(config)
    Check if a revision command with autogenerate has pending upgrade operations.

    :param config: a :class:`.Config` object.

merge(config, revisions, message=None, branch_label=None, rev_id=None)
    Merge two revisions together by creating a new migration file.

    :param config: a :class:`.Config` instance.
    :param revisions: string of revisions to merge.
    :param message: string message to apply to the revision.
    :param branch_label: string label name to apply to the new revision.
    :param rev_id: hardcoded revision identifier instead of generating a new one.

upgrade(config, revision, sql=False, tag=None)
    Upgrade the database schema to a later version.

    :param config: a :class:`.Config` instance.
    :param revision: string revision target or range for --sql mode.
    :param sql: if True, use ``--sql`` mode.
    :param tag: arbitrary tag for custom env.py scripts.

downgrade(config, revision, sql=False, tag=None)
    Revert the database schema to a previous version.

    :param config: a :class:`.Config` instance.
    :param revision: string revision target or range for --sql mode.
    :param sql: if True, use ``--sql`` mode.
    :param tag: arbitrary tag for custom env.py scripts.

show(config, rev)
    Show the revision(s) denoted by the given symbol.

    :param config: a :class:`.Config` instance.
    :param rev: string revision target.

history(config, rev_range=None, verbose=False, indicate_current=False)
    List changeset scripts in chronological order.

    :param config: a :class:`.Config` instance.
    :param rev_range: string revision range.
    :param verbose: output in verbose mode.
    :param indicate_current: indicate current revision.

heads(config, verbose=False, resolve_dependencies=False)
    Show current available heads in the script directory.

    :param config: a :class:`.Config` instance.
    :param verbose: output in verbose mode.
    :param resolve_dependencies: treat dependency version as down revisions.

branches(config, verbose=False)
    Show current branch points in the migration history.

    :param config: a :class:`.Config` instance.
    :param verbose: output in verbose mode.

current(config, verbose=False)
    Display the current revision for a database.

    :param config: a :class:`.Config` instance.
    :param verbose: output in verbose mode.

stamp(config, revision, sql=False, tag=None, purge=False)
    'Stamp' the revision table with the given revision without running migrations.

    :param config: a :class:`.Config` instance.
    :param revision: target revision or list of revisions to stamp.
    :param sql: use ``--sql`` mode.
    :param tag: arbitrary tag for custom env.py scripts.
    :param purge: delete all entries in the version table before stamping.

Overview
--------

These commands interact with Alembic's migration environment and script directory to facilitate database schema version control. They support operations such as:

- Initializing migration environments with templates.
- Creating new migration revisions, optionally autogenerating changes from the database schema.
- Merging multiple revisions.
- Upgrading and downgrading the database schema.
- Displaying migration history, current revisions, heads, and branches.
- Stamping the database schema version without applying migrations.

The commands leverage Alembic's `EnvironmentContext` and `ScriptDirectory` to manage migration scripts and database connections, providing a programmatic interface for migration operations.
