Markov Chain Monte Carlo (MCMC) Framework
=========================================

Overview
--------

This module provides a comprehensive framework for performing equilibrium sampling of biomolecular systems using Markov chain Monte Carlo (MCMC) methods. It supports a variety of MCMC moves including Langevin dynamics, hybrid Monte Carlo (HMC), generalized hybrid Monte Carlo (GHMC), and Monte Carlo barostat moves. These moves can be combined flexibly using container classes such as `SequenceMove` and `WeightedMove` to create complex sampling schemes.

The framework leverages OpenMM for molecular simulation and uses a shared global `ContextCache` to optimize performance by minimizing the number of OpenMM Context creations. Users can customize the platform used for simulations and manage context caching strategies to balance speed and memory usage.

Key Features
------------

- **Flexible MCMC Move Abstraction**: Define new MCMC moves by implementing the `MCMCMove` abstract base class.
- **Move Containers**: Combine multiple moves in sequence (`SequenceMove`) or select moves probabilistically (`WeightedMove`).
- **Sampler Class**: The `MCMCSampler` class manages the thermodynamic and sampler states and applies moves iteratively.
- **Context Caching**: Efficient reuse of OpenMM Contexts via `ContextCache` to accelerate simulations.
- **Minimization Support**: Built-in energy minimization of configurations before sampling.
- **Error Handling**: Specialized exceptions (`IntegratorMoveError`) capture and serialize simulation states when numerical instabilities occur.

Core Classes and Usage
----------------------

### MCMCMove

An abstract base class representing a single MCMC move. To implement a new move, subclass `MCMCMove` and define the `apply` method, which modifies the thermodynamic and sampler states.

```python
class MCMCMove(SubhookedABCMeta):
    def apply(self, thermodynamic_state, sampler_state):
        """Apply the MCMC move to the given states."""
        pass
```

### MCMCSampler

Manages the MCMC simulation by applying a specified move or move set repeatedly.

**Initialization:**

```python
sampler = MCMCSampler(thermodynamic_state, sampler_state, move)
```

- `thermodynamic_state`: The initial thermodynamic state (e.g., temperature, pressure).
- `sampler_state`: The initial microscopic state (e.g., atomic positions).
- `move`: An `MCMCMove` instance or a container of moves.

**Running the sampler:**

```python
sampler.run(n_iterations=100)
```

Runs the sampler for the specified number of iterations, applying the move(s) at each iteration.

**Energy Minimization:**

```python
sampler.minimize(tolerance=1.0*unit.kilocalories_per_mole/unit.angstroms,
                 max_iterations=100)
```

Minimizes the current configuration to remove high-energy clashes before sampling.

### Move Containers

#### SequenceMove

Applies a sequence of moves in order at each iteration.

```python
sequence_move = SequenceMove([move1, move2, move3])
```

#### WeightedMove

Selects one move from a set probabilistically at each iteration.

```python
weighted_move = WeightedMove([(move1, 0.5), (move2, 0.5)])
```

Examples
--------

### Alanine Dipeptide Vacuum Simulation

```python
from simtk import unit
from openmmtools import testsystems
from openmmtools.states import ThermodynamicState, SamplerState

# Create test system and initial states
test = testsystems.AlanineDipeptideVacuum()
thermodynamic_state = ThermodynamicState(system=test.system, temperature=298*unit.kelvin)
sampler_state = SamplerState(positions=test.positions)

# Define moves
ghmc_move = GHMCMove(timestep=1.0*unit.femtosecond, n_steps=50)
langevin_move = LangevinDynamicsMove(n_steps=10)

# Create sampler with a weighted move
weighted_move = WeightedMove([(ghmc_move, 0.5), (langevin_move, 0.5)])
sampler = MCMCSampler(thermodynamic_state, sampler_state, move=weighted_move)

# Minimize and run
sampler.minimize()
sampler.run(n_iterations=100)
```

### Lennard-Jones Fluid NPT Simulation

```python
from simtk import unit
from openmmtools import testsystems
from openmmtools.states import ThermodynamicState, SamplerState

test = testsystems.LennardJonesFluid(nparticles=200)
thermodynamic_state = ThermodynamicState(system=test.system, temperature=298*unit.kelvin,
                                         pressure=1*unit.atmospheres)
sampler_state = SamplerState(positions=test.positions)

# Sequence of moves including barostat
move = SequenceMove([GHMCMove(n_steps=50), MonteCarloBarostatMove(n_attempts=5)])
sampler = MCMCSampler(thermodynamic_state, sampler_state, move=move)

sampler.run(n_iterations=100)
```

Context Caching and Platform Configuration
------------------------------------------

By default, the framework uses a global `ContextCache` that creates OpenMM Contexts on the fastest available platform. Users can customize the platform and cache behavior:

```python
import openmm
from openmmtools import cache

# Select Reference platform
reference_platform = openmm.Platform.getPlatformByName('Reference')

# Configure global context cache
cache.global_context_cache.platform = reference_platform
cache.global_context_cache.time_to_live = 10  # Number of read/write operations before context is discarded
```

Alternatively, local caches can be created and assigned to moves:

```python
local_cache1 = cache.ContextCache(capacity=5, time_to_live=50)
local_cache2 = cache.ContextCache(platform=reference_platform, capacity=1)

sequence_move = SequenceMove([HMCMove(), LangevinDynamicsMove()], context_cache=local_cache1)
ghmc_move = GHMCMove(context_cache=local_cache2)
```

For scenarios where context caching is not desired, a `DummyContextCache` can be used to create a new Context every time:

```python
dummy_cache = cache.DummyContextCache(platform=reference_platform)
ghmc_move = GHMCMove(context_cache=dummy_cache)
```

Error Handling
--------------

The framework defines an `IntegratorMoveError` exception that is raised when numerical instabilities (e.g., NaNs) are detected after applying a move. This exception captures the state of the simulation and can serialize it to disk for debugging:

```python
try:
    move.apply(thermodynamic_state, sampler_state)
except IntegratorMoveError as e:
    e.serialize_error('error_output/prefix')
```

This creates files containing serialized representations of the move, system, integrator, and state at the time of the error.
