distutils module
================

This module provides utility functions and classes to assist with building,
installing, and configuring Python extensions and libraries, particularly
in the context of NumPy and scientific computing packages. It includes
tools for handling source files, managing temporary directories, detecting
build environments, and supporting colored terminal output.

Key Components
--------------

InstallableLib
~~~~~~~~~~~~~~

A container class to hold information about an installable library.

Parameters
----------
- name : str
    Name of the installed library.
- build_info : dict
    Dictionary holding build information.
- target_dir : str
    Absolute path specifying where to install the library.

Attributes
----------
- name
- build_info
- target_dir

See Also
--------
Configuration.add_installed_library

Functions
---------

get_num_build_jobs()
~~~~~~~~~~~~~~~~~~~~
Returns the number of parallel build jobs to run, based on the
`--parallel` command line argument, the environment variable
`NPY_NUM_BUILD_JOBS`, or the number of CPUs available (capped at 8).

Returns
-------
int
    Number of parallel build jobs.

quote_args(args)
~~~~~~~~~~~~~~~~
(Deprecated) Quotes a list of command-line arguments.

allpath(name)
~~~~~~~~~~~~~
Converts a '/'-separated pathname to one using the OS's path separator.

rel_path(path, parent_path)
~~~~~~~~~~~~~~~~~~~~~~~~~~~
Returns the relative path of `path` with respect to `parent_path`.

get_path_from_frame(frame, parent_path=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Returns the path of the module given a frame object from the call stack.
If `parent_path` is provided, the returned path is relative to it;
otherwise, it is absolute.

njoin(*path)
~~~~~~~~~~~~
Joins two or more pathname components, converting '/' separators to the
OS's path separator and resolving '.' and '..' components.

get_mathlibs(path=None)
~~~~~~~~~~~~~~~~~~~~~~~
Returns the list of math libraries defined in the `_numpyconfig.h` file
located in the given path or in the NumPy include directories.

minrelpath(path)
~~~~~~~~~~~~~~~~
Resolves '.' and '..' components from a path string.

sorted_glob(fileglob)
~~~~~~~~~~~~~~~~~~~~~
Returns a sorted list of files matching the given glob pattern.

gpaths(paths, local_path='', include_non_existing=True)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Applies glob patterns to paths and prepends `local_path` if needed.

make_temp_file(suffix='', prefix='', text=True)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Creates and returns a temporary file object and its name, ensuring one
temporary directory per thread.

terminal_has_colors()
~~~~~~~~~~~~~~~~~~~~~
Detects if the terminal supports colored output.

red_text(s), green_text(s), yellow_text(s), blue_text(s), cyan_text(s), default_text(s)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Return the input string wrapped in terminal color codes if supported.

cyg2win32(path)
~~~~~~~~~~~~~~~
Converts a Cygwin-native path to a Windows-native path using the `cygpath`
utility. Returns the original path if not on Cygwin.

mingw32()
~~~~~~~~~
Returns True if the environment is MinGW32 on Windows.

msvc_runtime_version()
~~~~~~~~~~~~~~~~~~~~~~
Returns the version of the MSVC runtime library used to build Python.

msvc_runtime_library()
~~~~~~~~~~~~~~~~~~~~~~
Returns the name of the MSVC runtime library if Python was built with MSVC >= 7.

msvc_runtime_major()
~~~~~~~~~~~~~~~~~~~~
Returns the major version of the MSVC runtime.

_get_f90_modules(source)
~~~~~~~~~~~~~~~~~~~~~~~~
Returns a list of Fortran 90 module names defined in the given source file.

is_string(s)
~~~~~~~~~~~~
Returns True if `s` is a string.

all_strings(lst)
~~~~~~~~~~~~~~~~
Returns True if all items in the list are strings.

is_sequence(seq)
~~~~~~~~~~~~~~~~
Returns True if `seq` is a sequence but not a string.

is_glob_pattern(s)
~~~~~~~~~~~~~~~~~~
Returns True if `s` is a string containing glob pattern characters '*' or '?'.

as_list(seq)
~~~~~~~~~~~~
Converts the input to a list if it is a sequence; otherwise returns a list
containing the input as its only element.

get_language(sources)
~~~~~~~~~~~~~~~~~~~~~
Determines the programming language ('c', 'f77', 'f90') from a list of source files.

has_f_sources(sources)
~~~~~~~~~~~~~~~~~~~~~~
Returns True if the list of sources contains Fortran files.

has_cxx_sources(sources)
~~~~~~~~~~~~~~~~~~~~~~~~
Returns True if the list of sources contains C++ files.

filter_sources(sources)
~~~~~~~~~~~~~~~~~~~~~~~
(Partial implementation in the provided code) Intended to filter source files
into categories such as C, C++, and Fortran.

Temporary Directory Management
------------------------------

The module manages temporary directories on a per-thread basis to avoid
creating multiple temporary directories unnecessarily. All temporary
directories created are tracked and cleaned up automatically upon program
exit.

Colored Terminal Output
-----------------------

Functions are provided to output colored text in terminals that support it,
including red, green, yellow, blue, cyan, and default colors. Detection
of terminal color support is performed automatically.

Platform-Specific Utilities
---------------------------

- `cyg2win32`: Converts Cygwin paths to Windows paths.
- `mingw32`: Detects if running in a MinGW32 environment.
- MSVC runtime version and library detection functions.

Notes
-----

This module is designed to support building and installing Python extensions,
particularly in scientific computing contexts such as NumPy. It provides
utilities for handling source files, paths, build jobs, and environment
detection to facilitate robust and portable build processes.
