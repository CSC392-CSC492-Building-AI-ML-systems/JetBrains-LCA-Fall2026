Migrating to nextcord
=====================

nextcord is a modern, actively maintained fork of discord.py that provides additional features, improvements, and ongoing support. This guide will help you migrate your existing discord.py codebase to nextcord with minimal effort.

Key Changes and Migration Notes
-------------------------------

1. **Installation**

   Replace your discord.py installation with nextcord:

   ```bash
   pip uninstall discord.py
   pip install nextcord
   ```

2. **Import Statements**

   Change your imports from `discord` to `nextcord`. For example:

   ```python
   import nextcord
   from nextcord.ext import commands
   ```

3. **Colour Class**

   The `Colour` class in nextcord is similar to discord.py but includes additional factory methods and improvements:

   - Aliased as `Color` for convenience.
   - Supports creation from RGB and HSV tuples.
   - Provides many predefined colours such as `Colour.teal()`, `Colour.dark_teal()`, `Colour.brand_green()`, `Colour.blue()`, `Colour.purple()`, `Colour.gold()`, `Colour.orange()`, `Colour.brand_red()`, `Colour.lighter_grey()`, `Colour.dark_grey()`, `Colour.light_grey()`, `Colour.darker_grey()`, `Colour.og_blurple()`, `Colour.blurple()`, `Colour.greyple()`, `Colour.dark_theme()`, and `Colour.fuchsia()`.
   - Supports generating random colours with optional seeding.
   - Colour instances behave like integers representing the raw colour value and support equality, hashing, and string conversion to hex format.

   Example usage:

   ```python
   colour = nextcord.Colour.blue()
   print(str(colour))  # Outputs: #3498db
   ```

4. **Widget Support**

   nextcord includes support for Guild Widgets, which are partial representations of guilds, channels, and members accessible via the widget API:

   - `WidgetChannel`: Represents a partial widget channel with attributes like `id`, `name`, and `position`.
   - `WidgetMember`: Represents a partial member in the widget with attributes such as `id`, `name`, `discriminator`, `bot`, `status`, `nick`, `avatar`, `activity`, and voice state flags (`deafened`, `muted`, `suppress`).
   - `Widget`: Represents the guild widget itself, containing lists of `WidgetChannel` and `WidgetMember` instances, the guild's ID and name, and the invite URL.

   These classes provide properties and methods to access widget data, including:

   - `Widget.json_url`: The URL to the widget's JSON data.
   - `Widget.invite_url`: The invite URL for the guild, if available.
   - `Widget.fetch_invite()`: Coroutine to fetch an `Invite` object from the widget's invite URL.

   Example usage:

   ```python
   widget = await client.fetch_guild_widget(guild_id)
   print(widget.name)
   for member in widget.members:
       print(member.display_name, member.status)
   ```

5. **Activity and Status**

   Widget members support activity and status information similar to regular members, including support for Spotify activities.

6. **Backward Compatibility**

   nextcord aims to maintain compatibility with discord.py's API where possible. However, some internal improvements and additional features may require minor code adjustments.

Summary
-------

Migrating to nextcord primarily involves updating your imports and dependencies. You gain access to enhanced features such as improved colour handling and widget support. The API remains familiar, making the transition straightforward.

For detailed API documentation and examples, please refer to the official nextcord documentation.
