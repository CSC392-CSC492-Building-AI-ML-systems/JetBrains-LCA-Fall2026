w_stateprobs Command
====================

Overview
--------

The `w_stateprobs` command calculates average populations and associated confidence intervals (CIs) for state populations from weighted ensemble data. This analysis requires bin assignments, including macrostate definitions (see `w_assign --help` for more information).

This tool performs path-tracing kinetics analysis by averaging state populations over specified iteration windows, providing insights into the kinetics of state-to-state transitions.

Output Format
-------------

The output file (specified with `-o` or `--output`, default: `stateprobs.h5`) contains the following datasets:

- **/avg_state_pops [state]**  
  A structured dataset representing the population of each state averaged across the entire specified iteration range.

If the `--evolution-mode` option is used, an additional dataset is included:

- **/state_pop_evolution [window][state]**  
  A structured dataset representing state populations calculated over windows of iterations. The windows can be defined in two modes:
  
  - **cumulative**: Windows start at the iteration specified by `--start-iter` and grow in length by `--step-iter` for each successive element.
  - **blocked**: Windows have a fixed width of `--step-iter` (except possibly the last window), starting at `--start-iter`.

Dataset Structure
-----------------

Each dataset contains the following fields:

- **iter_start**  
  Integer. The iteration at which the averaging window begins (inclusive).

- **iter_stop**  
  Integer. The iteration at which the averaging window ends (exclusive).

- **expected**  
  Floating-point. The expected (mean) value of the state population within this window.

- **ci_lbound**  
  Floating-point. The lower bound of the confidence interval on the state population within this window.

- **ci_ubound**  
  Floating-point. The upper bound of the confidence interval on the state population within this window.

- **corr_len**  
  Integer. The correlation length of the state population within this window, measured in units of tau.

Each dataset is also annotated with the following attributes:

- **mcbs_alpha**  
  Floating-point. The alpha value used for confidence intervals (e.g., `alpha=0.05` corresponds to a 95% confidence interval).

- **mcbs_nsets**  
  Integer. The number of bootstrap data sets used to generate confidence intervals.

- **mcbs_acalpha**  
  Floating-point. The alpha value used for determining correlation lengths.

Command-Line Options
--------------------

The `w_stateprobs` command supports various options to control the analysis, including specifying input files, iteration ranges, and output settings. For detailed usage and options, run:

```
w_stateprobs --help
```

Deprecation Notice
------------------

Please note that `w_stateprobs` is deprecated and users are encouraged to use the `w_direct` command instead for state-to-state kinetics analysis.

Summary
-------

`w_stateprobs` provides a robust method for calculating average state populations and their confidence intervals from weighted ensemble simulations, facilitating detailed kinetic analyses through path-tracing of trajectories.
