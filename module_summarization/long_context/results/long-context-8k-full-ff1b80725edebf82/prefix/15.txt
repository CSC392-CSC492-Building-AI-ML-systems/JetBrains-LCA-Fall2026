Ploterr Command
===============

The `ploterr` command provides a suite of subcommands for plotting error bars, kinetics, and state probabilities from WESTPA simulation data. It supports plotting from generic HDF5 datasets as well as specialized outputs from `w_direct` and `w_kinavg` tools.

Subcommands
-----------

generic
~~~~~~~

Plot generic expectation and confidence interval (CI) data from an arbitrary HDF5 file and dataset.

**Usage:**

```
ploterr generic [OPTIONS] DSSPEC
```

- `DSSPEC` must be formatted as `FILENAME/PATH[SLICE]`, where:
  - `FILENAME` is the HDF5 file to read.
  - `PATH` is the HDF5 path to the dataset.
  - `SLICE` (optional) is a NumPy-style slice selecting a vector of data.

The dataset must be one-dimensional and contain the following fields:

- `iter_start`
- `iter_stop`
- `expected`
- `ci_lbound`
- `ci_ubound`

**Options:**

- `-o, --output OUTPUT`  
  Write plot to `OUTPUT` (default: `errbars.pdf`). The output format is inferred from the filename extension.

- Plot options:
  - `--xscale {linear,log,symlog}`  
    Scaling for the x-axis (default: linear).
  - `--yscale {linear,log,symlog}`  
    Scaling for the y-axis (default: linear).
  - `--xrange XRANGE`  
    Restrict x-axis range to `xmin,xmax`.
  - `--yrange YRANGE`  
    Restrict y-axis range to `ymin,ymax`.
  - `--xlabel XLABEL`  
    Label for the x-axis.
  - `--ylabel YLABEL`  
    Label for the y-axis.
  - `--title TITLE`  
    Title of the plot.
  - `--terminal, -t`  
    Plot output in terminal (text interface).

---

d.kinetics
~~~~~~~~~~

Plot evolution of state-to-state rates and total flux into states as generated by `w_direct` or `w_reweight` kinetics tools (when used with the `--evolution-mode` option).

Plots are generated for all rates and fluxes calculated.

**Usage:**

```
ploterr d.kinetics [OPTIONS]
```

**Options:**

- `-i, --input INPUT`  
  Read kinetics results from `INPUT` (default: `direct.h5`).

- `--rate-output FILENAME_PATTERN`  
  Filename pattern for rate evolution output (default: `rate_evolution_d_{istate_label}_{fstate_label}.pdf`).

- `--flux-output FILENAME_PATTERN`  
  Filename pattern for flux evolution output (default: `flux_evolution_d_{state_label}.pdf`).

**Filename Pattern Fields:**

- `istate_label`, `fstate_label` (string)  
  Names of the initial and final states.

- `istate_index`, `fstate_index` (integer)  
  Indices of the initial and final states.

- `state_label` (string)  
  Name of the state (for fluxes).

- `state_index` (integer)  
  Index of the state (for fluxes).

**Plot Details:**

- Rate plots show the rate from one state to another.
- Flux plots show the total flux into a state.
- Default y-axis labels are `Rate (τ⁻¹)` for rates and `Flux (τ⁻¹)` for fluxes.
- Titles and axis labels support substitution based on the state labels and indices.

---

d.probs
~~~~~~~

Plot evolution of macrostate populations and associated uncertainties as output by `w_direct probs`.

Plots are generated for all states calculated.

**Usage:**

```
ploterr d.probs [OPTIONS]
```

**Options:**

- `-i, --input INPUT`  
  Read `w_kinavg` results from `INPUT` (default: `direct.h5`).

- `--population-output FILENAME_PATTERN`  
  Filename pattern for population evolution output (default: `pop_evolution_d_{state_label}.pdf`).

- `--color-output FILENAME_PATTERN`  
  Filename pattern for ensemble evolution output (default: `color_evolution_d_{state_label}.pdf`).

**Filename Pattern Fields:**

- `state_label` (string)  
  Name of the state.

- `state_index` (integer)  
  Index of the state.

**Plot Details:**

- Population plots show the population in each state.
- Color plots show the population in ensembles.
- Default y-axis label is `Population`.
- Titles and axis labels support substitution based on the state labels and indices.

---

Common Plot Options
-------------------

All subcommands support the following plot options:

- `--xscale {linear,log,symlog}`  
  Set the x-axis scale (default: linear).

- `--yscale {linear,log,symlog}`  
  Set the y-axis scale (default: linear).

- `--xrange xmin,xmax`  
  Restrict the x-axis range.

- `--yrange ymin,ymax`  
  Restrict the y-axis range.

- `--xlabel XLABEL`  
  Label for the x-axis.

- `--ylabel YLABEL`  
  Label for the y-axis.

- `--title TITLE`  
  Title of the plot.

- `--terminal, -t`  
  Plot output in terminal (text interface) instead of graphical output.

---

Plotting Interface
------------------

- If the `DISPLAY` environment variable is set and `--terminal` is not specified, plots are generated using Matplotlib and saved to files.
- If `DISPLAY` is not set or `--terminal` is specified, plots are rendered as text in the terminal.

---

Examples
--------

Plot generic error bars from a dataset:

```
ploterr generic data.h5/mydataset[0:100] --output myplot.pdf --xscale log --xlabel "Iteration"
```

Plot kinetics rate evolution with custom output filenames:

```
ploterr d.kinetics -i kinetics.h5 --rate-output "rates_{istate_label}_to_{fstate_label}.pdf"
```

Plot state populations from direct probabilities output:

```
ploterr d.probs -i direct.h5 --population-output "pop_{state_label}.pdf"
```

---

Logging and Progress
--------------------

The command provides progress indicators during data loading and plotting operations. Logging is available under the `ploterrs` logger name.

---

Dependencies
------------

- Requires `h5py` and `numpy` for data handling.
- Requires `matplotlib` for graphical plotting (if available and `DISPLAY` is set).
- Uses WESTPA internal modules for command infrastructure.

---

This command is part of the WESTPA toolkit for weighted ensemble simulations and analysis.
