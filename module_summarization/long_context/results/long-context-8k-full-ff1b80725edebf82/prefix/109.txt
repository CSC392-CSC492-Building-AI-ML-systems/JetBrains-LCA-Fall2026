async module
============

This module provides asynchronous scanning plans for data acquisition using detectors and motors. These plans support various scanning patterns including linear, relative, logarithmic, list-based, and grid scans. They are designed to be used with Bluesky or similar experimental control frameworks.

Functions
---------

count(detectors, num=1, delay=None, *, per_shot=None, md=None)
    Take one or more readings from detectors.

    Parameters
    ----------
    detectors : list
        List of 'readable' detector objects.
    num : int or None, optional
        Number of readings to take; default is 1. If None, capture data until canceled.
    delay : iterable or scalar, optional
        Time delay in seconds between successive readings; default is 0.
    per_shot : callable, optional
        Hook for customizing action of inner loop (messages per step).
        Expected signature:
            def f(detectors: Iterable[OphydObj]) -> Generator[Msg]
    md : dict, optional
        Metadata dictionary.

list_scan(detectors, *args, per_step=None, md=None)
    Scan over one or more variables in steps simultaneously (inner product).

    Parameters
    ----------
    detectors : list
        List of 'readable' detector objects.
    *args :
        For one dimension, provide motor and list of points:
            motor, [point1, point2, ...]
        For multiple dimensions, provide pairs of motors and point lists:
            motor1, [points...], motor2, [points...], ..., motorN, [points...]
    per_step : callable, optional
        Hook for customizing action of inner loop (messages per step).
        Signature: f(detectors, motor, step) -> plan (generator)
    md : dict, optional
        Metadata dictionary.

list_grid_scan(detectors, *args, snake_axes=False, per_step=None, md=None)
    Scan over a mesh grid; each motor moves independently.

    Parameters
    ----------
    detectors : list
        List of 'readable' detector objects.
    *args :
        Patterned as motor and list of positions:
            motor1, [points...], motor2, [points...], ..., motorN, [points...]
    snake_axes : bool or iterable, optional
        Specifies which axes to snake (winding trajectory).
        False (default) means no snaking.
        True means snake all axes except the slowest.
        Iterable specifies which motors to snake.
    per_step : callable, optional
        Hook for customizing action of inner loop (messages per step).
    md : dict, optional
        Metadata dictionary.

Notes
-----

- All scanning functions accept a list of detectors and one or more motors or variables to scan.
- The `per_step` or `per_shot` callable parameters allow customization of the actions performed at each step or shot.
- Metadata dictionaries (`md`) can be passed to enrich the scan with additional information.
- Relative scans automatically reset motor positions after completion.
- Snaking axes in grid scans optimize scanning trajectories by alternating direction on specified axes.
- The module uses decorators from `preprocessors` to stage devices and manage run lifecycles.
- The scanning patterns leverage numpy functions such as `linspace` and `logspace` for step generation.
- The module attempts to use `cytools` for performance but falls back to `toolz` if unavailable.
