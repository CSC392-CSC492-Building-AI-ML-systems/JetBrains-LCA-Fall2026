Manifold Learning — Non-linear Dimensionality Reduction
=======================================================

Manifold learning is a class of algorithms for non-linear dimensionality reduction. Unlike linear methods such as Principal Component Analysis (PCA), manifold learning techniques aim to uncover the low-dimensional structure embedded in high-dimensional data by assuming that the data lies on or near a manifold of much lower dimensionality than the ambient space.

Overview
--------

High-dimensional data often lies on a manifold with intrinsic dimensionality much smaller than the observed dimensionality. Manifold learning algorithms seek to find a meaningful low-dimensional embedding that preserves certain properties of the original data, such as distances or neighborhood relationships.

These methods are particularly useful for visualization, noise reduction, and as a preprocessing step for other machine learning tasks.

Multidimensional Scaling (MDS)
------------------------------

Multidimensional Scaling (MDS) is a classical manifold learning technique that aims to place each object in a low-dimensional space such that the between-object distances are preserved as well as possible. The goal is to find an embedding where the pairwise distances correspond closely to the original dissimilarities.

### SMACOF Algorithm

The SMACOF (Scaling by MAjorizing a COmplicated Function) algorithm is an iterative majorization technique used to minimize the *stress* function, which measures the discrepancy between the distances in the embedding space and the original dissimilarities.

The algorithm proceeds as follows:

1. Initialize the configuration of points in the embedding space, either randomly or using a provided initial configuration.
2. Compute the stress, which quantifies the difference between the distances in the embedding and the original dissimilarities.
3. Update the configuration using the Guttman transform to reduce the stress.
4. Repeat steps 2 and 3 until convergence or a maximum number of iterations is reached.

The SMACOF algorithm supports both metric and nonmetric MDS:

- **Metric MDS** attempts to preserve the actual dissimilarities.
- **Nonmetric MDS** preserves the rank order of dissimilarities by applying a monotonic regression step before stress computation.

### Parameters and Usage

- **dissimilarities**: Pairwise dissimilarities between points, which must be symmetric.
- **metric**: Boolean flag to choose between metric and nonmetric MDS.
- **n_components**: Number of dimensions for the embedding space.
- **init**: Optional initial configuration for the embedding.
- **n_init**: Number of times the algorithm is run with different initializations to avoid local minima.
- **max_iter**: Maximum number of iterations per run.
- **eps**: Convergence tolerance based on relative change in stress.
- **random_state**: Seed or random state for reproducibility.
- **normalized_stress**: Option to use normalized stress (Stress-1) instead of raw stress, supported only for nonmetric MDS.

### Interpretation of Stress

The stress value indicates the quality of the embedding:

- 0: Perfect fit
- 0.025: Excellent fit
- 0.05: Good fit
- 0.1: Fair fit
- 0.2: Poor fit

Applications
------------

Manifold learning techniques like MDS are widely used for:

- Visualizing high-dimensional data in 2D or 3D.
- Discovering intrinsic geometric structures.
- Preprocessing for clustering or classification.
- Noise reduction by projecting data onto a lower-dimensional manifold.

Related Methods
---------------

Other manifold learning and non-linear dimensionality reduction methods include:

- **Isomap**: Combines MDS with geodesic distances computed on a neighborhood graph.
- **Locally Linear Embedding (LLE)**: Preserves local neighborhood relationships.
- **Spectral Embedding**: Uses spectral decomposition of affinity matrices.
- **t-SNE**: Focuses on preserving local structure for visualization.

Example
-------

The following example demonstrates the use of MDS for embedding the digits dataset into two dimensions:

.. code-block:: python

    from sklearn.datasets import load_digits
    from sklearn.manifold import MDS

    X, _ = load_digits(return_X_y=True)
    embedding = MDS(n_components=2, normalized_stress='auto')
    X_transformed = embedding.fit_transform(X[:100])

    print(X_transformed.shape)  # Output: (100, 2)

This embedding can then be used for visualization or further analysis.

Summary
-------

Manifold learning provides powerful tools for uncovering the underlying low-dimensional structure of complex datasets. Multidimensional Scaling, particularly via the SMACOF algorithm, offers a flexible and interpretable approach to non-linear dimensionality reduction by preserving dissimilarities or their rank order in a low-dimensional embedding.
