Feature Extraction — Text Processing Utilities
==============================================

The `sklearn.feature_extraction.text` submodule provides a collection of utilities to transform text documents into numerical feature vectors suitable for machine learning models. This module includes various vectorizers, transformers, and helper functions designed to preprocess, tokenize, and extract meaningful features from raw text data.

Overview
--------

Text data requires specialized processing to convert unstructured strings into structured numerical representations. This submodule offers tools to handle common text preprocessing tasks such as accent stripping, tokenization, stop word filtering, and n-gram extraction. It supports multiple tokenization schemes and customizable analyzers to adapt to diverse text processing needs.

Key Components
--------------

### Vectorizers

- **CountVectorizer**  
  Converts a collection of text documents to a matrix of token counts. It supports tokenization, stop word filtering, and n-gram extraction.

- **HashingVectorizer**  
  Transforms text documents into a matrix of token occurrences using a hashing trick, which is memory efficient and suitable for large datasets.

- **TfidfVectorizer**  
  Extends `CountVectorizer` by applying Term Frequency-Inverse Document Frequency (TF-IDF) weighting to the token counts.

### Transformers

- **TfidfTransformer**  
  Converts a count matrix to a normalized TF-IDF representation.

### Utilities

- **ENGLISH_STOP_WORDS**  
  A built-in set of English stop words for filtering common words during tokenization.

- **strip_accents_unicode(s)**  
  Removes accentuated unicode characters by decomposing them into their base characters. Suitable for languages with accented characters.

- **strip_accents_ascii(s)**  
  Removes accentuated characters by transliterating them to ASCII equivalents. Faster but only suitable for languages with direct ASCII transliterations.

- **strip_tags(s)**  
  Removes HTML/XML tags from strings using a basic regular expression. For more robust HTML parsing, external libraries are recommended.

Core Functionalities
--------------------

### Text Preprocessing

- `_preprocess(doc, accent_function=None, lower=False)`  
  Applies optional accent stripping and lowercasing to a document string.

- `build_preprocessor()`  
  Constructs a preprocessing function based on parameters such as accent stripping and lowercasing.

### Tokenization and Analysis

- `build_tokenizer()`  
  Returns a tokenizer function that splits text into tokens based on a regular expression pattern or a custom tokenizer.

- `build_analyzer()`  
  Creates an analyzer callable that chains preprocessing, tokenization, and n-gram generation. Supports different analyzers such as "word", "char", and "char_wb".

- `_word_ngrams(tokens, stop_words=None)`  
  Generates word n-grams from tokens, optionally filtering out stop words.

- `_char_ngrams(text_document)`  
  Generates character n-grams from a text document.

- `_char_wb_ngrams(text_document)`  
  Generates whitespace-boundary aware character n-grams, padding edges of words with spaces.

### Stop Words Handling

- `get_stop_words()`  
  Retrieves the effective stop words list, supporting built-in lists or user-provided collections.

- `_check_stop_list(stop)`  
  Validates and converts stop word inputs.

- `_check_stop_words_consistency(stop_words, preprocess, tokenize)`  
  Checks if the stop words are consistent with the preprocessing and tokenization steps, issuing warnings if inconsistencies are detected.

### Vocabulary and Parameter Validation

- `_validate_vocabulary()`  
  Validates and processes the vocabulary input, ensuring uniqueness and proper indexing.

- `_check_vocabulary()`  
  Ensures that the vocabulary is fitted and non-empty before use.

- `_validate_ngram_range()`  
  Validates the n-gram range parameter to ensure logical boundaries.

- `_warn_for_unused_params()`  
  Issues warnings when certain parameters are ignored due to the presence of custom analyzers or tokenizers.

Usage Notes
-----------

- The module supports flexible customization of text processing pipelines through parameters such as `analyzer`, `tokenizer`, `preprocessor`, `stop_words`, and `ngram_range`.

- Accent stripping can be performed using either Unicode normalization or ASCII transliteration, depending on language requirements and performance considerations.

- Stop word lists can be customized or replaced with built-in sets like `ENGLISH_STOP_WORDS`.

- The vectorizers support input as raw text, filenames, or file-like objects, with automatic decoding based on specified encoding parameters.

- For HTML or XML content, `strip_tags` provides a simple tag removal method, but for complex documents, dedicated parsers are recommended.
