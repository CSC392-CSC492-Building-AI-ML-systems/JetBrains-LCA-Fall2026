Conditions in PyTables
======================

PyTables provides a powerful and flexible way to query tables using *conditions*. Conditions allow you to filter rows in a table based on logical expressions involving the columns of the table. This document describes the syntax and usage of conditions in PyTables.

Overview
--------

A *condition* in PyTables is a logical expression that evaluates to `True` or `False` for each row in a table. When you apply a condition to a table, only the rows for which the condition evaluates to `True` are selected.

Conditions can be simple comparisons, such as equality or inequality tests, or more complex expressions combining multiple comparisons with logical operators.

Basic Syntax
------------

Conditions are expressed as strings that resemble Python expressions, but with some restrictions and extensions to work efficiently with table columns.

### Column Names

Column names are used as variables in the condition expression. For example, if your table has columns named `age` and `weight`, you can write conditions like:

```python
"age > 30"
"weight <= 70"
```

### Comparison Operators

The following comparison operators are supported:

- `==` : equal to
- `!=` : not equal to
- `<`  : less than
- `<=` : less than or equal to
- `>`  : greater than
- `>=` : greater than or equal to

Example:

```python
"age >= 18"
"weight != 0"
```

### Logical Operators

You can combine multiple conditions using logical operators:

- `&` : logical AND
- `|` : logical OR
- `~` : logical NOT

Parentheses `()` can be used to group expressions and control precedence.

Example:

```python
"(age >= 18) & (weight < 70)"
"~(age < 18) | (weight > 100)"
```

### Membership Operators

You can test if a column value is in a list of values using the `in` operator:

```python
"gender in ['M', 'F']"
```

### String Operations

String columns can be compared using equality and inequality operators. Some string methods may also be supported depending on the PyTables version.

Example:

```python
"name == 'John'"
```

Advanced Usage
--------------

### Using NumPy Functions

Some NumPy functions can be used inside conditions for more complex queries, such as `numpy.isnan()` to check for NaN values.

Example:

```python
"numpy.isnan(weight)"
```

### Using Indexes for Faster Queries

PyTables supports indexing on columns to speed up condition queries. When a column is indexed, queries involving that column can be executed more efficiently.

To create an index on a column:

```python
table.cols.column_name.create_index()
```

Once indexed, conditions involving that column will benefit from faster lookups.

### Conditions with Multiple Columns

You can write conditions involving multiple columns combined with logical operators.

Example:

```python
"(age > 30) & (weight < 70) & (gender == 'F')"
```

Examples
--------

Suppose you have a table `table` with columns `age`, `weight`, and `gender`.

- Select rows where age is greater than 25:

  ```python
  condition = "age > 25"
  rows = [row for row in table.where(condition)]
  ```

- Select rows where weight is between 50 and 80:

  ```python
  condition = "(weight >= 50) & (weight <= 80)"
  rows = [row for row in table.where(condition)]
  ```

- Select rows where gender is male and age is less than 40:

  ```python
  condition = "(gender == 'M') & (age < 40)"
  rows = [row for row in table.where(condition)]
  ```

Notes and Limitations
---------------------

- Conditions are evaluated on the server side (inside PyTables) for efficiency.
- Not all Python expressions are supported; only a subset of operators and functions are allowed.
- When using string comparisons, be mindful of case sensitivity.
- Complex conditions may require indexing columns for acceptable performance.
- Conditions involving floating-point comparisons should consider precision issues.
