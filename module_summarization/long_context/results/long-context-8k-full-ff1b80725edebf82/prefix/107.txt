Iterables Utilities
===================

This module provides a collection of utility functions for working with iterables, sequences, and multisets. It includes functions for flattening nested iterables, grouping elements, generating subsets and permutations, and more.

Functions
---------

flatten(iterable, levels=None, cls=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Recursively denest iterable containers.

- If `levels` is specified, only that many levels of nesting are flattened.
- If `cls` is specified, only instances of that class are flattened.

Examples:

>>> flatten([1, 2, [3]])
[1, 2, 3]

>>> flatten([[(-2, -1), (1, 2)], [(0, 0)]], levels=1)
[(-2, -1), (1, 2), (0, 0)]

unflatten(iter, n=2)
~~~~~~~~~~~~~~~~~~~~
Group an iterable into tuples of length `n`. Raises an error if the length of the iterable is not a multiple of `n`.

group(seq, multiple=True)
~~~~~~~~~~~~~~~~~~~~~~~~~
Splits a sequence into a list of lists of equal, adjacent elements.

- If `multiple` is False, returns a list of tuples `(element, count)`.

Examples:

>>> group([1, 1, 1, 2, 2, 3])
[[1, 1, 1], [2, 2], [3]]

>>> group([1, 1, 1, 2, 2, 3], multiple=False)
[(1, 3), (2, 2), (3, 1)]

multiset(seq)
~~~~~~~~~~~~
Returns a dictionary representing the multiset of the sequence, where keys are elements and values are their multiplicities.

Example:

>>> multiset('mississippi')
{'m': 1, 'i': 4, 's': 4, 'p': 2}

postorder_traversal(node, keys=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Generator that yields nodes of a tree in postorder traversal.

- `node`: the root node to traverse.
- `keys`: optional sorting keys for ordering children.

Example:

>>> list(postorder_traversal(w + (x + y)*z, keys=True))
[w, z, x, y, x + y, z*(x + y), w + z*(x + y)]

subsets(seq, k=None, repetition=False)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Generates all k-subsets (combinations) from the sequence `seq`.

- If `k` is None, generates all subsets.
- If `repetition` is True, combinations with repetition are generated.

Examples:

>>> list(subsets([1, 2], 2))
[(1, 2)]

>>> list(subsets([1, 2], 2, repetition=True))
[(1, 1), (1, 2), (2, 2)]

filter_symbols(iterator, exclude)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Yields elements from `iterator` that are not in `exclude`.

numbered_symbols(prefix='x', cls=None, start=0, exclude=[], **assumptions)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Generates an infinite stream of symbols with a given prefix and increasing subscripts, excluding any in `exclude`.

sift(seq, keyfunc)
~~~~~~~~~~~~~~~~~~
Partitions the sequence `seq` into a dictionary keyed by the result of `keyfunc` applied to each element.

Example:

>>> sift(range(5), lambda x: x % 2)
defaultdict(<class 'list'>, {0: [0, 2, 4], 1: [1, 3]})

common_prefix(*seqs)
~~~~~~~~~~~~~~~~~~~
Returns the longest common starting subsequence of the given sequences.

common_suffix(*seqs)
~~~~~~~~~~~~~~~~~~~
Returns the longest common ending subsequence of the given sequences.

rotate_left(x, y)
~~~~~~~~~~~~~~~~~
Left rotates the list `x` by `y` steps.

rotate_right(x, y)
~~~~~~~~~~~~~~~~~~
Right rotates the list `x` by `y` steps.

multiset_combinations(m, n, g=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Yields unique combinations of size `n` from the multiset `m`.

multiset_permutations(m, size=None, g=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Yields unique permutations of the multiset `m`.

_partition(seq, vector, m=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Partitions the sequence `seq` according to the partition vector `vector`.

_set_partitions(n)
~~~~~~~~~~~~~~~~~~
Generator that yields all partitions of `n` elements as a tuple `(m, q)` where `m` is the number of parts and `q` is the partition vector.

multiset_partitions(multiset, m=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Yields unique partitions of the given multiset.

- If `m` is None, yields all partitions.
- If `m` is specified, yields only partitions with `m` parts.

Counting the number of partitions corresponds to Bell numbers.
