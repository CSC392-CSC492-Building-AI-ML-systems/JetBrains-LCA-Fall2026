Miscellaneous Models
====================

This module provides implementations of several statistical models using generic maximum likelihood estimation (MLE) techniques. These models extend classical approaches by incorporating alternative error distributions, offsets, and zero-inflation to better handle real-world data complexities.

Linear Model with Student-t Distributed Errors
----------------------------------------------

The `TLinearModel` class implements a linear regression model assuming errors follow a Student's t-distribution rather than the normal distribution. The t-distribution's heavier tails make this model more robust to outliers and observations with heavier tails. The degrees of freedom and scale parameters of the t-distribution can be estimated or fixed.

Key features:
- Maximum likelihood estimation using generic MLE framework.
- Numerical gradients and Hessians for inference.
- Starting values can be initialized from ordinary least squares (OLS) estimates.
- The model uses the standard (non-standardized) t-distribution, where the scale parameter is not equal to the standard deviation.

Reference:
Kenneth L. Lange, Roderick J. A. Little, Jeremy M. G. Taylor (1989).  
"Robust Statistical Modeling Using the t Distribution",  
Journal of the American Statistical Association, Vol. 84, No. 408, pp. 881-896.

Univariate ARMA Model with Student-t Distributed Errors
-------------------------------------------------------

The `TArma` class extends the classical ARMA model by assuming that the innovations (errors) follow a Student's t-distribution. This allows for modeling time series data with heavier-tailed noise, providing robustness against outliers.

Key points:
- Inherits most functionality from `statsmodels.tsa.arma_mle.Arma`.
- Uses the standard t-distribution; the error variance is given by \( \frac{df}{df-2} \times scale^2 \).
- Supports maximum likelihood estimation with numerical optimization.
- Includes methods for log-likelihood and numerical derivatives.

Poisson Models with Generic MLE
-------------------------------

Several Poisson regression models are implemented using the generic MLE framework, allowing for flexible extensions beyond the classical Poisson model.

1. **PoissonGMLE**  
   Implements a standard Poisson regression model. The log-likelihood is based on the Poisson probability mass function. This model serves as an example of generic MLE applied to count data.

2. **PoissonOffsetGMLE**  
   Extends the Poisson model by including an offset term, which can be used to model exposure or other known multiplicative effects. The offset is incorporated additively on the log scale.

3. **PoissonZiGMLE**  
   Implements a zero-inflated Poisson model that accounts for excess zeros in count data. This model combines a Poisson count component with a zero-inflation component modeled via a logistic function.  
   Notes:
   - Numerical issues may arise when there is no zero-inflation present.
   - The zero-inflation probability is modeled as a logistic transformation of an additional parameter.
   - Supports offsets and flexible specification of regressors.

Additional Utilities
--------------------

- **NonlinearDeltaCov**:  
  A utility class for computing asymptotic covariance matrices of nonlinear functions of parameters using the delta method. It approximates gradients numerically and calculates covariance matrices and Wald statistics for hypothesis testing.

General Notes
-------------

- All models rely on numerical differentiation for gradients and Hessians, enabling flexible specification of likelihood functions.
- Starting values for parameters are often initialized using simpler models (e.g., OLS for linear models).
- The models are designed for experimentation and extension, with some TODOs and known issues noted in the source code.
- The module demonstrates the use of generic MLE for robust and flexible modeling beyond standard assumptions.
