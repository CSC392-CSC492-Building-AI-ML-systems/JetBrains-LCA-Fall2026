Feature Selection and Dimensionality Reduction
==============================================

Feature selection and dimensionality reduction are essential techniques in machine learning to improve model performance, reduce overfitting, and decrease computational cost by selecting or transforming input features.

Overview
--------

Feature selection involves selecting a subset of relevant features for use in model construction. Dimensionality reduction transforms the feature space into a lower-dimensional space, often by combining features.

These techniques are particularly useful when working with high-dimensional data, where many features may be redundant or irrelevant.

Multi-Output Estimators
-----------------------

In scenarios involving multiple output variables, such as multi-target regression or multi-label classification, it is often necessary to extend single-output estimators to handle multiple outputs. The multi-output estimators provided here facilitate this by fitting one estimator per output variable.

### MultiOutputRegressor

`MultiOutputRegressor` is a meta-estimator that fits one regressor per target variable. This approach allows extending regressors that do not natively support multi-target regression.

**Parameters**

- `estimator` : estimator object  
  An estimator implementing `fit` and `predict`.

- `n_jobs` : int or None, default=None  
  The number of jobs to run in parallel for fitting and predicting each target.  
  - `None` means 1 unless in a `joblib.parallel_backend` context.  
  - `-1` means using all available processors.

**Attributes**

- `estimators_` : list of estimators  
  The list of fitted estimators, one per output.

- `n_features_in_` : int  
  Number of features seen during fit (if supported by the underlying estimator).

- `feature_names_in_` : ndarray of shape (`n_features_in_`,)  
  Names of features seen during fit (if supported).

**Example**

```python
from sklearn.datasets import load_linnerud
from sklearn.linear_model import Ridge
from sklearn.multioutput import MultiOutputRegressor

X, y = load_linnerud(return_X_y=True)
regr = MultiOutputRegressor(Ridge(random_state=123)).fit(X, y)
predictions = regr.predict(X[[0]])
```

### MultiOutputClassifier

`MultiOutputClassifier` is a meta-estimator that fits one classifier per target variable. It extends classifiers that do not natively support multi-target classification.

**Parameters**

- `estimator` : estimator object  
  An estimator implementing `fit` and `predict`.  
  A `predict_proba` method will be exposed only if the base estimator implements it.

- `n_jobs` : int or None, default=None  
  The number of jobs to run in parallel for fitting and predicting each target.

**Attributes**

- `classes_` : ndarray of shape (n_classes,)  
  Class labels.

- `estimators_` : list of estimators  
  The list of fitted estimators, one per output.

- `n_features_in_` : int  
  Number of features seen during fit (if supported).

- `feature_names_in_` : ndarray of shape (`n_features_in_`,)  
  Names of features seen during fit (if supported).

Incremental Learning
--------------------

Both `MultiOutputRegressor` and `MultiOutputClassifier` support incremental learning via the `partial_fit` method if the underlying estimator supports it. This allows fitting models on batches of data or streaming data.

Usage of `partial_fit` requires providing the classes for classification tasks during the first call.

Parallelization
---------------

The `n_jobs` parameter controls parallelization of fitting and prediction across multiple outputs. Parallel execution can speed up training and prediction when individual estimators are computationally expensive.

Metadata Routing
----------------

These multi-output estimators support metadata routing, allowing parameters to be passed selectively to the underlying estimators' methods such as `fit` and `partial_fit`. This advanced feature enables fine-grained control over the fitting process.

Summary
-------

Feature selection and dimensionality reduction techniques, combined with multi-output estimators, provide powerful tools for handling complex datasets with multiple targets. By fitting separate models per output and enabling parallel and incremental learning, these estimators facilitate scalable and flexible modeling in multi-target scenarios.
