Configurations
==============

The `ConfigurationsOptions` class provides a comprehensive set of options to control the import and export behavior of various components within a project configuration. This allows users to selectively enable or disable the import/export of variables, setups, optimizations, parametrics, boundaries, mesh operations, coordinate systems, materials, object properties, and datasets.

Options
-------

- **object_mapping_tolerance** (`float`):  
  Tolerance value used in object mapping operations, such as for boundaries. Default is `1e-9`.

- **export_variables** (`bool`):  
  Enable or disable exporting variables to a JSON file. Default is `True`.

- **export_setups** (`bool`):  
  Enable or disable exporting setups to a JSON file. Default is `True`.

- **export_optimizations** (`bool`):  
  Enable or disable exporting optimizations to a JSON file. Default is `True`.

- **export_parametrics** (`bool`):  
  Enable or disable exporting parametrics to a JSON file. Default is `True`.

- **export_boundaries** (`bool`):  
  Enable or disable exporting boundaries to a JSON file. Default is `True`.

- **export_mesh_operations** (`bool`):  
  Enable or disable exporting mesh operations to a JSON file. Default is `True`.

- **export_coordinate_systems** (`bool`):  
  Enable or disable exporting coordinate systems to a JSON file. Default is `True`.

- **export_materials** (`bool`):  
  Enable or disable exporting materials to a JSON file. Default is `True`.

- **export_object_properties** (`bool`):  
  Enable or disable exporting object properties to a JSON file. Default is `True`.

- **export_datasets** (`bool`):  
  Enable or disable exporting datasets to a JSON file. Default is `True`.

- **import_variables** (`bool`):  
  Enable or disable importing/creating variables from a JSON file. Default is `True`.

- **import_setups** (`bool`):  
  Enable or disable importing/creating setups from a JSON file. Default is `True`.

- **import_optimizations** (`bool`):  
  Enable or disable importing/creating optimizations from a JSON file. Default is `True`.

- **import_parametrics** (`bool`):  
  Enable or disable importing/creating parametrics from a JSON file. Default is `True`.

- **import_boundaries** (`bool`):  
  Enable or disable importing/creating boundaries from a JSON file. Default is `True`.

- **import_mesh_operations** (`bool`):  
  Enable or disable importing/creating mesh operations from a JSON file. Default is `True`.

- **import_coordinate_systems** (`bool`):  
  Enable or disable importing/creating coordinate systems from a JSON file. Default is `True`.

- **import_materials** (`bool`):  
  Enable or disable importing/creating materials from a JSON file. Default is `True`.

- **import_object_properties** (`bool`):  
  Enable or disable importing/creating object properties from a JSON file. Default is `True`.

- **import_datasets** (`bool`):  
  Enable or disable importing datasets from a JSON file. Default is `True`.

- **skip_import_if_exists** (`bool`):  
  Defines whether existing boundaries or properties should be updated during import. Default is `False`.

Methods
-------

- **unset_all_export()**  
  Sets all export-related options to `False`.

- **set_all_export()**  
  Sets all export-related options to `True`.

- **unset_all_import()**  
  Sets all import-related options to `False`.

- **set_all_import()**  
  Sets all import-related options to `True`.

- **_is_any_import_set** (`bool` property)  
  Returns `True` if any import option is enabled, otherwise `False`.

Usage Examples
--------------

```python
from pyaedt import Hfss

hfss = Hfss()

# Disable exporting variables
hfss.configurations.options.export_variables = False

# Enable importing setups
hfss.configurations.options.import_setups = True

# Disable all exports
hfss.configurations.options.unset_all_export()

# Enable all imports
hfss.configurations.options.set_all_import()
```

ImportResults
-------------

The `ImportResults` class encapsulates the results of import operations. Each attribute corresponds to a specific import category and holds a boolean value indicating success (`True`) or failure (`False`) of that import.

Attributes include:

- `import_units`
- `import_variables`
- `import_postprocessing_variables`
- `import_setup`
- `import_optimizations`
- `import_parametrics`
- `import_boundaries`
- `import_mesh_operations`
- `import_coordinate_systems`
- `import_face_coordinate_systems`
- `import_material_datasets`
- `import_materials`
- `import_object_properties`
- `import_monitor`
- `import_datasets`

The class provides a method to reset all results:

- **_reset_results()**  
  Resets all import results to their initial state (`None`).

The property:

- **global_import_success** (`bool`)  
  Returns `True` if all import operations were successful, otherwise `False`.

Summary
-------

This configuration module provides fine-grained control over the import and export processes of various simulation components, enabling users to customize their workflow and data management effectively. The `ConfigurationsOptions` class is central to managing these settings, while the `ImportResults` class tracks the success of import operations.
