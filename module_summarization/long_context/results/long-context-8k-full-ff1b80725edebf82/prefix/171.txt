Calculator Interface
====================

Overview
--------

The Calculator Interface provides a standardized way to interact with various scattering models, enabling the listing and management of model parameters, conversion between different model formats, and mathematical transformations relevant to scattering calculations.

Parameter Listing Utility
-------------------------

A utility is provided to list all parameters used across available models, along with the models that utilize them. This is useful for understanding parameter usage and for model comparison.

Usage
~~~~~

Run the following command to list parameters:

```
python -m sasmodels.list_pars [-v] [kind]
```

Options:

- `-v`, `--verbose`  
  When specified, the output includes the models that use each parameter, not just the parameter names.

- `kind`  
  Optional positional argument to filter parameters by their kind. Possible values are:  
  - `volume`  
  - `orientation`  
  - `sld` (scattering length density)  
  - `none`  
  - `any` (default)  

If `kind` is omitted or set to `any`, all parameters are listed.

Functionality
~~~~~~~~~~~~~

- `find_pars(kind=None)`  
  Returns a dictionary mapping parameter names to a list of models that use them. If `kind` is specified, only parameters of that kind are included.

- `list_pars(names_only=True, kind=None)`  
  Prints the parameters. If `names_only` is `True`, only parameter names are printed; otherwise, the models using each parameter are also listed.

Model Conversion
----------------

The interface supports conversion of models to and from SasView format, handling differences in parameter naming and scaling conventions.

Key Points:

- Some models do not include explicit `scale` or `background` parameters in SasView versions. These models are tracked in lists such as `MODELS_WITHOUT_SCALE` and `MODELS_WITHOUT_BACKGROUND`.

- Magnetic models supported by SasView are listed in `MAGNETIC_SASVIEW_MODELS`.

- Polydispersity parameters use a translation scheme to convert between new-style and old-style naming conventions.

- Functions `_rescale` and `_rescale_sld` handle scaling of parameters, particularly scattering length density (SLD) parameters, to maintain consistency between different unit conventions.

- The `_get_translation_table` function generates a mapping between new and old parameter names for a given model and SasView version, facilitating backward compatibility.

Mathematical Transformations
----------------------------

The interface includes implementations of advanced mathematical functions and coordinate transformations relevant to scattering calculations:

- Elliptic functions (`ellipticJ`, `ellipticFi`, `ellipticF`) are implemented using SciPy special functions, with support for complex arguments.

- The Guyou map projection is implemented via `guyou` and `guyou_invert` functions, which convert between latitude-longitude coordinates and Guyou map coordinates. This is useful for visualizing spherical data on a plane.

- A plotting utility `plot_grid` demonstrates the Guyou transformation by plotting latitude-longitude grids before and after transformation.

Example Usage of Guyou Transformation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

```python
import matplotlib.pyplot as plt

# Plot the Guyou transformation grid
plot_grid()
plt.show()
```

This will display the forward and inverse Guyou map projections of latitude-longitude grids.

Summary
-------

The Calculator Interface provides comprehensive tools for:

- Enumerating and managing model parameters across multiple scattering models.

- Converting models between different formats, especially SasView compatibility.

- Performing specialized mathematical transformations necessary for scattering data analysis.

These capabilities facilitate flexible and consistent use of scattering models in computational workflows.
