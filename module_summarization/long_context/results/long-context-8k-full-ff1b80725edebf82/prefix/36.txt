w_succ — List Successful (Recycled) Segments
=============================================

Synopsis
--------

.. code-block:: console

    w_succ [OPTIONS]

Description
-----------

The `w_succ` command lists segments from WESTPA simulations that have successfully reached a target state, i.e., segments that were recycled during the simulation. This tool outputs information about these successful segments, including their iteration number, segment ID, weight, and final progress coordinate values.

Output Format
-------------

The output consists of columns with the following information:

- **Column 0:** Iteration number  
- **Column 1:** Segment ID  
- **Column 2:** Weight of the segment  
- **Columns >2:** Final progress coordinate values for the segment  

The output begins with header lines describing the columns, unless header suppression is enabled.

Options
-------

- `-o, --output OUTPUT_FILE`  
  Write the output to the specified file instead of standard output.

Additional options may be available through WESTPA configuration and analysis tool arguments.

Usage Example
-------------

.. code-block:: console

    w_succ -o successful_segments.txt

This command writes the list of successful (recycled) segments to the file `successful_segments.txt`.

Details
-------

The command processes all iterations up to the current iteration in the WESTPA data manager. For each iteration, it identifies segments marked as recycled (successful) and retrieves their final progress coordinate values. The output is formatted with fixed-width fields for readability.

If no recycled segments are found in an iteration, that iteration is skipped.

Logging
-------

The tool uses the logger named `w_succ` for internal logging purposes.
