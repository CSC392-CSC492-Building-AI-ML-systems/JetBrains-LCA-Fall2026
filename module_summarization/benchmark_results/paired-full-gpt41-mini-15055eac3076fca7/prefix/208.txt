Utilities for Developers
========================

This module provides a collection of compatibility fixes and utility functions designed to support developers working with different versions of Python, NumPy, SciPy, and related libraries. These utilities ensure consistent behavior across various environments and simplify the handling of version-dependent features.

Compatibility Fixes
------------------

- **Sparse Matrix Containers**  
  Defines lists of sparse matrix container types (`CSR_CONTAINERS`, `CSC_CONTAINERS`, `COO_CONTAINERS`, `LIL_CONTAINERS`, `DOK_CONTAINERS`, `BSR_CONTAINERS`) that include both classic sparse matrix classes and, when available (SciPy >= 1.8), sparse array classes. This facilitates uniform handling of sparse data structures regardless of the SciPy version.

- **Line Search Functions**  
  Imports `line_search_wolfe1` and `line_search_wolfe2` from the appropriate SciPy submodules depending on the installed SciPy version, maintaining compatibility with versions before and after SciPy 1.8.

- **Percentile Function**  
  Provides a wrapper around NumPy's `percentile` function to handle the renaming of the `interpolation` keyword argument to `method` introduced in NumPy 1.22. For NumPy versions earlier than 1.22, the wrapper translates the `method` argument to `interpolation` to maintain backward compatibility.

- **Threadpool Control Utilities**  
  Implements `threadpool_limits` and `threadpool_info` functions that abstract over different versions of the `threadpoolctl` library. These functions manage threadpool limits and provide information about threadpool usage, using a global controller when supported (threadpoolctl >= 3.0.0) to optimize performance.

- **Deprecated Utilities**  
  Includes a deprecated `delayed` function that issues a warning and redirects to the new location in `sklearn.utils.parallel`. This helps developers transition their code smoothly before the removal of the old import path.

- **Mode Function Compatibility**  
  Defines a `_mode` function that wraps `scipy.stats.mode` to handle changes in the function's behavior and return types across SciPy versions, ensuring consistent results.

- **Conjugate Gradient Solver Wrapper**  
  Provides a compatibility wrapper `_sparse_linalg_cg` around `scipy.sparse.linalg.cg` to accommodate changes in keyword arguments and default behaviors introduced in SciPy versions prior to 1.12.

Backports
---------

- **Importlib.resources Backport**  
  Contains a backport of Python 3.9's `importlib.resources` functionality to support older Python versions. This includes a utility function `_open_text` that opens text files from package resources in a version-compatible manner.

Utility Functions
-----------------

- **_object_dtype_isnan(X)**  
  A helper function to detect NaN values in arrays with object dtype by leveraging the property that NaN is not equal to itself.

Usage Notes
-----------

These utilities are primarily intended for internal use within the library to smooth over differences between dependency versions and Python releases. They help maintain consistent behavior and reduce the need for version-specific code scattered throughout the codebase.

Developers extending or maintaining the library should refer to these utilities when dealing with compatibility issues or when adding support for new versions of dependencies. Deprecated functions are clearly marked and accompanied by guidance on their future removal to facilitate code modernization.
