Isotonic Regression
====================

The :mod:`isotonic` module provides tools for performing isotonic regression, a type of regression that fits a non-decreasing (or non-increasing) function to data. This module includes functions to check monotonic relationships, perform isotonic regression, and a scikit-learn compatible estimator for isotonic regression.

Functions
---------

check_increasing(x, y)
    Determine whether the target values `y` are monotonically correlated with the input `x`.

    This function uses the Spearman correlation coefficient to assess whether `y` is increasing or decreasing with respect to `x`. It returns a boolean indicating if the relationship is increasing. A warning is issued if the 95% confidence interval of the Spearman correlation spans zero, indicating uncertainty in the monotonicity direction.

    Parameters
    ----------
    x : array-like of shape (n_samples,)
        Input data.

    y : array-like of shape (n_samples,)
        Target values.

    Returns
    -------
    increasing_bool : bool
        True if `y` is monotonically increasing with `x`, False otherwise.

    Notes
    -----
    The Spearman correlation coefficient is estimated from the data, and its sign determines the monotonicity. The confidence interval is computed using the Fisher transformation.

isotonic_regression(y, *, sample_weight=None, y_min=None, y_max=None, increasing=True)
    Solve the isotonic regression problem on the data `y`.

    This function fits an isotonic regression model to the data, optionally weighted by `sample_weight`. The fit can be constrained to be increasing or decreasing, and bounds can be set on the predicted values.

    Parameters
    ----------
    y : array-like of shape (n_samples,)
        The data to fit.

    sample_weight : array-like of shape (n_samples,), default=None
        Weights for each data point. If None, equal weights are assumed.

    y_min : float or None, default=None
        Lower bound on the predicted values. If None, no lower bound is applied.

    y_max : float or None, default=None
        Upper bound on the predicted values. If None, no upper bound is applied.

    increasing : bool, default=True
        If True, fit an increasing isotonic regression; if False, fit a decreasing one.

    Returns
    -------
    y_ : ndarray of shape (n_samples,)
        The isotonic regression fit of `y`.

    References
    ----------
    Best, M. J., & Chakravarti, N. (1990). Active set algorithms for isotonic regression; A unifying framework.

Classes
-------

IsotonicRegression
    Isotonic regression estimator compatible with scikit-learn API.

    This class fits an isotonic regression model to data, supporting both increasing and decreasing fits, optional bounds on predictions, and sample weights. It can be used as a regressor or transformer within scikit-learn pipelines.

    .. versionadded:: 0.13

    Parameters
    ----------
    y_min : float or None, default=None
        Lower bound on the predicted values.

    y_max : float or None, default=None
        Upper bound on the predicted values.

    increasing : bool, default=True
        Whether to fit an increasing or decreasing isotonic regression.

    out_of_bounds : {'clip', 'nan', 'raise'}, default='nan'
        Defines the behavior when predicting values outside the training data range.

    increasing : bool, default=True
        Whether to fit an increasing or decreasing isotonic regression.

    Attributes
    ----------
    X_thresholds_ : ndarray of shape (n_thresholds,)
        The unique sorted input data points used for fitting.

    y_thresholds_ : ndarray of shape (n_thresholds,)
        The isotonic regression values corresponding to `X_thresholds_`.

    References
    ----------
    See the :ref:`User Guide <isotonic>` for detailed usage examples and explanations.

Notes
-----
Isotonic regression is useful when the relationship between variables is assumed to be monotonic but not necessarily linear. This module leverages efficient algorithms for isotonic regression and integrates with the scikit-learn ecosystem for ease of use in machine learning workflows.
