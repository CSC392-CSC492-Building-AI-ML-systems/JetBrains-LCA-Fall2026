Best Effort Callback
====================

The `BestEffortCallback` class provides a flexible and user-friendly callback for live data visualization and tabular display during data acquisition runs. It is designed to work with streaming data, automatically handling plotting, tabular display, and baseline data presentation with minimal configuration.

Overview
--------

`BestEffortCallback` inherits from `QtAwareCallback` and is decorated with `make_class_safe` to ensure safe execution with logging support. It supports live plotting of data streams, live tabular display of hinted readings, and baseline data printing. The callback attempts to intelligently guess the structure of the data and dimensions if not explicitly provided.

Usage
-----

The callback can be instantiated with optional parameters such as a figure factory for plot creation and a flag to enable or disable the live table display.

```python
callback = BestEffortCallback(fig_factory=my_fig_factory, table_enabled=True)
```

Features
--------

- **Live Plotting:** Automatically plots hinted fields from all streams except those listed in `noplot_streams` (default includes `'baseline'`).
- **Live Table:** Displays a live-updating table of hinted readings from the primary data stream.
- **Baseline Display:** Prints fields from the `'baseline'` stream if enabled.
- **Configurable Display Options:** Enable or disable heading, table, baseline, and plots independently.
- **Automatic Dimension Guessing:** Attempts to infer independent variables (dimensions) from the plan document or falls back to a heuristic guess.
- **Peak Detection:** Maintains peak statistics for live plots.
- **Thread-Safe and Qt-Aware:** Designed to work smoothly in GUI applications using Qt.

Public Methods
--------------

- `enable_heading()`: Enable printing of timestamp and scan IDs at the start of a run.
- `disable_heading()`: Disable the heading printout.
- `enable_table()`: Enable live table display of primary stream readings.
- `disable_table()`: Disable the live table display.
- `enable_baseline()`: Enable printing of baseline stream fields.
- `disable_baseline()`: Disable baseline printing.
- `enable_plots()`: Enable live plotting of data streams.
- `disable_plots()`: Disable all plotting.

Callback Invocation
-------------------

The callback is designed to be called with the signature:

```python
callback(name, doc, *args, **kwargs)
```

where `name` is the event name, and `doc` is the document dictionary containing data and metadata. The callback will process the document and update plots, tables, and baseline displays accordingly, depending on the enabled features.

Internal Behavior
-----------------

- On `start(doc)`, the callback clears previous state, stores the start document, and extracts hints and dimensions.
- It attempts to unify dimensions to a single stream for plotting; if multiple streams are involved, it falls back to a heuristic guess and issues a warning.
- The callback maintains internal mappings from descriptor unique IDs to live plot, grid, and scatter instances.
- It tracks streams seen and manages plotting options such as overplotting and omission of single-point plots.
- Peak statistics are collected and updated for relevant data streams.

Notes
-----

- The callback is intended for interactive use and may require a Qt event loop for full functionality.
- It is designed to be robust and to provide a "best effort" visualization experience without extensive user configuration.
- The class uses internal buffering and heuristics to manage display formatting and updates.

Logging
-------

The callback uses the standard Python `logging` module to report warnings and internal state changes, facilitating debugging and monitoring.
