Publishing for Web Review
=========================

The ftrack API provides a robust mechanism for publishing content for web review, enabling seamless collaboration and feedback through the web interface. This documentation outlines the key concepts and usage patterns related to publishing for web review within the ftrack ecosystem.

Session and Authentication
--------------------------

Interaction with the ftrack server, including publishing operations, is managed through an isolated `Session` object. The session handles authentication, caching, event management, and plugin integration.

- **Authentication**: The `SessionAuthentication` class attaches ftrack session authentication information to HTTP requests, ensuring secure communication with the server using an API key and user credentials.

- **Session Initialization**: When creating a `Session`, you specify the server URL, API key, and user. The session supports automatic attribute population, plugin loading, caching, and event hub connection, all of which facilitate efficient publishing workflows.

Publishing Workflow
-------------------

Publishing for web review typically involves the following steps:

1. **Prepare Content**: Organize and prepare the media or assets to be published. This may include encoding, packaging, or generating reviewable formats.

2. **Create or Update Entities**: Use the session to create or update entities within the ftrack server that represent the published content. Entities can include tasks, versions, or review sessions.

3. **Attach Reviewable Media**: Link the prepared media files to the corresponding entities. This enables the web review interface to access and display the content.

4. **Notify Reviewers**: Optionally, trigger notifications or events to inform reviewers that new content is available for review.

Event Hub and Plugins
---------------------

The session optionally connects to an embedded event hub, which facilitates publishing and subscribing to events related to web review publishing.

- **Event Hub Connection**: If enabled, the event hub connects in a background thread, allowing asynchronous event handling without blocking session startup.

- **Plugins**: Plugins can extend publishing capabilities, automate workflows, or integrate with external systems. Plugin paths and arguments can be configured during session initialization.

Caching and Performance
-----------------------

To optimize performance during publishing operations, the session supports caching mechanisms:

- **Schema Caching**: Enables caching of schema information to reduce server queries.

- **Layered Cache**: Combines memory and persistent caches to improve data retrieval speed.

These caching strategies ensure that publishing workflows remain responsive and efficient, even with large datasets.

Summary
-------

Publishing for web review in ftrack is facilitated through a well-structured API that manages authentication, session state, event handling, and caching. By leveraging these components, users can automate and streamline the process of making content available for collaborative review via the web interface.
