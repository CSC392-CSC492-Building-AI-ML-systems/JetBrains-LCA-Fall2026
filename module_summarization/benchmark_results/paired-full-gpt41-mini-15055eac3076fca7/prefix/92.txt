distutils module
================

The `distutils` module provides utilities and classes to facilitate the building, installation, and distribution of Python modules and extensions. It includes functionality for managing build configurations, handling source files, and supporting parallel build jobs, among other features.

Key Components
--------------

### InstallableLib

A container class to hold information about an installable library.

**Parameters:**

- `name` (str): Name of the installed library.
- `build_info` (dict): Dictionary holding build information.
- `target_dir` (str): Absolute path specifying where to install the library.

**Attributes:**

- `name`
- `build_info`
- `target_dir`

**See Also:**

- `Configuration.add_installed_library`

### get_num_build_jobs()

Determines the number of parallel build jobs to run during the build process.

- Checks the `--parallel` command line argument of `setup.py`.
- If not set, checks the environment variable `NPY_NUM_BUILD_JOBS`.
- Defaults to the number of processors on the system, capped at 8 to avoid overloading.
- Returns the maximum parallel jobs specified among build commands if set.

**Returns:**

- `int`: Number of parallel jobs that can be run.

### quote_args(args)

Quotes a list of command-line arguments.

**Deprecated:** Since version 1.22.

**Parameters:**

- `args` (list): List of argument strings.

**Returns:**

- `list`: List of quoted argument strings.

### allpath(name)

Converts a forward-slash (`/`) separated pathname to one using the operating system's path separator.

**Parameters:**

- `name` (str): Pathname with `/` separators.

**Returns:**

- `str`: Pathname with OS-specific separators.

### rel_path(path, parent_path)

Returns the relative path of `path` with respect to `parent_path`.

- Uses real paths to avoid issues with symbolic links.

**Parameters:**

- `path` (str): Target path.
- `parent_path` (str): Reference parent path.

**Returns:**

- `str`: Relative path from `parent_path` to `path`.

### get_path_from_frame(frame, parent_path=None)

Returns the path of the module given a frame object from the call stack.

- If `parent_path` is provided, returns the path relative to it.
- Otherwise, returns the absolute path.

**Parameters:**

- `frame` (frame object): Frame object from the call stack.
- `parent_path` (str, optional): Reference path to which the returned path is relative.

**Returns:**

- `str`: Path of the module corresponding to the frame.

Module Variables and Utilities
------------------------------

- `_tdata`: Thread-local storage for temporary directories.
- `_tmpdirs`: List of all created temporary directories to be cleaned up at exit.
- `clean_up_temporary_directory()`: Function registered with `atexit` to remove temporary directories.
- Various utility functions and constants for path manipulation, source file filtering, color terminal output, and build configuration management.

Usage Notes
-----------

This module is designed to support complex build and installation workflows, particularly for packages that include compiled extensions or require custom build steps. It integrates with the standard `distutils` and `numpy.distutils` infrastructure to provide enhanced functionality such as parallel builds and detailed configuration management.

The module exposes a comprehensive API for managing build information, source files, and installation targets, making it suitable for use in sophisticated Python package build systems.
