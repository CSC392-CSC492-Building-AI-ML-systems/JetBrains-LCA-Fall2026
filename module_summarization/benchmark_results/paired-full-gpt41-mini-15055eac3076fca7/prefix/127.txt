Convolution Module Built-in Kernels
===================================

The `astropy.convolution` module provides a collection of built-in kernel classes designed for use with convolution operations. These kernels are fundamental components for smoothing, filtering, and other image processing tasks within the Astropy framework.

Kernel Classes
--------------

The module includes several kernel base classes and specialized kernels:

- **Kernel**: The base class for all kernels. It provides the core functionality and interface for kernel objects.

- **Kernel1D**: A subclass of `Kernel` designed for one-dimensional kernels. Useful for 1D convolution operations.

- **Kernel2D**: A subclass of `Kernel` designed for two-dimensional kernels. Commonly used for image convolution.

Kernel Properties
-----------------

Kernels in this module are typically represented as arrays with specific shapes and normalization properties. They can be used directly with convolution functions to apply smoothing or filtering effects to data arrays.

Normalization and Size Constraints
----------------------------------

Kernels often require normalization to ensure that the convolution operation preserves the overall flux or intensity of the data. The module defines constants such as `MAX_NORMALIZATION` to control normalization behavior.

Kernel sizes are subject to constraints to optimize performance, especially when using FFT-based convolution methods. The module maintains a list of "good" sizes (`_good_sizes`) that are optimal for FFT computations. Functions like `_next_fast_lengths` help determine the best padding sizes for input arrays to improve FFT efficiency.

Boundary Conditions
-------------------

When performing convolution, handling of array boundaries is important. The module supports several boundary options:

- `None`: No special boundary handling.
- `"fill"`: Pad input arrays with a constant fill value.
- `"wrap"`: Wrap around the array edges.
- `"extend"`: Extend the edge values.

These options can be specified to control how convolution behaves near the edges of the input data.

Usage Notes
-----------

- Kernels can be created and manipulated as `Kernel`, `Kernel1D`, or `Kernel2D` objects.
- When convolving data, care should be taken to handle masked arrays and NaN values appropriately. The module includes utility functions to copy and prepare input arrays for convolution, ensuring that masked or invalid data is treated correctly.
- FFT-based convolution methods benefit from input arrays padded to sizes that are efficient for FFT algorithms. The module provides mechanisms to compute these optimal sizes.

Exceptions and Warnings
-----------------------

The module defines exceptions such as `KernelSizeError` to handle invalid kernel sizes, and warnings like `AstropyUserWarning` to alert users about potential issues during convolution operations.

Summary
-------

The built-in kernels in the `astropy.convolution` module provide flexible and efficient tools for convolution operations in one or two dimensions. They are designed to integrate seamlessly with Astropy's modeling and NDData frameworks, supporting advanced image processing workflows with attention to performance and data integrity.
