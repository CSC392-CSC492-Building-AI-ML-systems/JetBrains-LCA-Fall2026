MapPlot Module
==============

Overview
--------

The `MapPlot` module provides interactive plotting capabilities for data cubes, allowing users to visualize maps and connect them interactively to spectrum plotting. It is designed primarily as an interactive analysis tool rather than for producing publication-quality plots. However, it leverages the `APLpy` package, enabling the creation of high-quality plots if desired.

This module is particularly useful for exploring spectral data cubes by plotting maps and enabling interactive selection of pixels or regions to examine their spectra.

Dependencies
------------

- `matplotlib` for plotting figures and handling interactive events.
- `numpy` for numerical operations.
- `astropy.wcs` and `astropy.io.fits` (or legacy `pywcs` and `pyfits`) for handling FITS headers and World Coordinate System (WCS) transformations.
- `aplpy` (optional) for advanced FITS image plotting and color scaling.

Key Classes and Functions
-------------------------

### MapPlotter

The primary class in this module, `MapPlotter`, facilitates the creation of interactive map plots from data cubes.

#### Initialization

```python
MapPlotter(Cube=None, figure=None, doplot=False, **kwargs)
```

- **Cube**: The data cube object containing the spectral data and header information.
- **figure**: A `matplotlib.figure.Figure` instance, an integer figure number, or `None`. Determines where the plot will be drawn.
- **doplot**: If `True`, automatically generates the map plot upon initialization.
- **kwargs**: Additional keyword arguments passed to plotting methods.

The constructor sets up the plotting figure, initializes internal state variables, and prepares the WCS transformation if a valid FITS header is available.

#### Methods

- `__call__(**kwargs)`: Alias for `mapplot()`, allowing the instance to be called directly to generate plots.
  
- `mapplot(convention='calabretta', colorbar=True, useaplpy=True, vmin=None, vmax=None, cmap=None, plotkwargs={}, **kwargs)`

  Generates an interactive map plot from the data cube.

  Parameters:
  
  - **convention** (`str`): Projection convention for Galactic data, either `'calabretta'` or `'griesen'`. Default is `'calabretta'`.
  - **colorbar** (`bool`): Whether to display a colorbar alongside the map.
  - **useaplpy** (`bool`): Use `aplpy` for plotting if a FITS header is available.
  - **vmin**, **vmax** (`float` or `None`): Minimum and maximum values for the color scale. Automatically determined if `None`.
  - **cmap**: Colormap to use for the plot.
  - **plotkwargs** (`dict`): Additional keyword arguments passed to the plotting functions (`aplpy.show_colorscale` or `matplotlib.pyplot.imshow`).
  - **kwargs**: Additional parameters passed to internal methods such as `makeplane`.

  Interactive Features:
  
  - **Left mouse button (or keyboard '1')**: Plot the spectrum of the selected pixel in a separate window and mark the pixel with an 'x'.
  - **Middle mouse button (or keyboard 'o')**: Overplot additional spectra on the existing spectrum plot.
  - **Right mouse button**: Disconnect the interactive viewer.
  - **Click-and-drag with left mouse button**: Average over a circular region.
  - Keyboard shortcuts 'c' and 'r' allow setting the center and radius of a circular region for averaging.

Usage Notes
-----------

- The module is intended for interactive data exploration rather than final figure production.
- When `aplpy` is available and enabled, it provides enhanced plotting capabilities, including FITS header-aware coordinate handling.
- The `makeplane` method (not shown here) is responsible for selecting the map slice from the cube to be plotted.
- The module handles WCS transformations to correctly display celestial coordinates.

Example
-------

```python
from mapplot import MapPlotter
import some_cube_module

cube = some_cube_module.load_cube('data.fits')
plotter = MapPlotter(Cube=cube, doplot=True)
plotter.mapplot()
```

This will open an interactive map window where users can click on pixels to view their spectra.

Notes
-----

- The module attempts to import `astropy.wcs` and `astropy.io.fits` but falls back to legacy `pywcs` and `pyfits` if necessary.
- If neither WCS package is available, WCS-related features will be disabled.
- The module cycles through a set of colors when overplotting multiple spectra.
