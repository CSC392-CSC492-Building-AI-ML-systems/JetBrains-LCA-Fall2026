Geometric Image Transformations
===============================

This module provides tools and classes for performing geometric image transformations, with a focus on camera modeling and coordinate transformations in computer vision applications.

PinholeCamera
-------------

The `PinholeCamera` class represents a pinhole camera model, encapsulating the intrinsic and extrinsic parameters of the camera in a batched format to leverage PyTorch's parallel computation capabilities.

Class Signature:
```python
class PinholeCamera:
```

### Initialization

```python
PinholeCamera(intrinsics: torch.Tensor, extrinsics: torch.Tensor, height: torch.Tensor, width: torch.Tensor) -> None
```

- **intrinsics** (`torch.Tensor`): A tensor of shape `(B, 4, 4)` containing the full 4x4 camera calibration matrices for a batch of cameras.
- **extrinsics** (`torch.Tensor`): A tensor of shape `(B, 4, 4)` containing the full 4x4 rotation-translation matrices for the batch.
- **height** (`torch.Tensor`): A tensor of shape `(B,)` containing the image heights for each camera in the batch.
- **width** (`torch.Tensor`): A tensor of shape `(B,)` containing the image widths for each camera in the batch.

**Note:** The class assumes batched inputs to optimize performance using PyTorch's parallelism.

### Properties

- **intrinsics** (`torch.Tensor`): Returns the full 4x4 intrinsic matrices of shape `(B, 4, 4)`.
- **extrinsics** (`torch.Tensor`): Returns the full 4x4 extrinsic matrices of shape `(B, 4, 4)`.
- **batch_size** (`int`): Returns the batch size, i.e., the number of cameras stored.
- **fx** (`torch.Tensor`): Returns the focal length in the x-direction for each camera, shape `(B,)`.
- **fy** (`torch.Tensor`): Returns the focal length in the y-direction for each camera, shape `(B,)`.
- **cx** (`torch.Tensor`): Returns the x-coordinate of the principal point for each camera, shape `(B,)`.
- **cy** (`torch.Tensor`): Returns the y-coordinate of the principal point for each camera, shape `(B,)`.
- **tx** (`torch.Tensor`): Returns the x-coordinate of the translation vector for each camera, shape `(B,)`.

### Methods

- **tx.setter**: Allows setting the x-coordinate of the translation vector for the extrinsic matrix.

### Usage Example

```python
import torch
from kornia.geometry.subpix import PinholeCamera

# Example batch size
B = 2

# Define intrinsics and extrinsics for batch of cameras
intrinsics = torch.eye(4).unsqueeze(0).repeat(B, 1, 1)  # (B, 4, 4)
extrinsics = torch.eye(4).unsqueeze(0).repeat(B, 1, 1)  # (B, 4, 4)
height = torch.tensor([480, 640])
width = torch.tensor([640, 480])

camera = PinholeCamera(intrinsics, extrinsics, height, width)

print(camera.fx)  # Focal lengths in x-direction
print(camera.cy)  # Principal point y-coordinates
```
