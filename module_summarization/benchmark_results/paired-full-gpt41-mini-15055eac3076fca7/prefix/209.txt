Analyzing a Collection of Text Documents
========================================

The `sklearn.feature_extraction.text` submodule provides utilities to build feature vectors from text documents. This is a crucial step in many natural language processing (NLP) and machine learning workflows, where raw text data must be transformed into numerical representations that algorithms can process.

Text Preprocessing and Analysis Pipeline
----------------------------------------

Analyzing a collection of text documents typically involves a sequence of preprocessing and tokenization steps. The submodule offers flexible components that can be chained together to customize this process according to the needs of your application.

### Preprocessing

Preprocessing involves cleaning and normalizing the raw text. Common preprocessing steps include:

- Lowercasing text to ensure uniformity.
- Removing or normalizing accented characters.
- Stripping HTML or XML tags.

The function `_preprocess` applies these steps in a customizable manner:

```python
def _preprocess(doc, accent_function=None, lower=False):
    """
    Chain together an optional series of text preprocessing steps to apply to a document.

    Parameters
    ----------
    doc : str
        The string to preprocess.
    accent_function : callable, default=None
        Function for handling accented characters, such as normalization or removal.
    lower : bool, default=False
        Whether to convert all text to lowercase.

    Returns
    -------
    doc : str
        The preprocessed string.
    """
```

Two common functions for handling accented characters are:

- `strip_accents_unicode(s)`: Transforms accented Unicode symbols into their simple counterparts by decomposing Unicode characters. This method preserves most characters but is slower.
- `strip_accents_ascii(s)`: Transforms accented Unicode symbols into ASCII equivalents or removes them. This method is faster but only suitable for languages with direct ASCII transliterations.

Example usage:

```python
from sklearn.feature_extraction.text import strip_accents_ascii

clean_text = strip_accents_ascii("Café")
# clean_text == "Cafe"
```

Additionally, `strip_tags(s)` can be used to remove HTML or XML tags from text using a basic regular expression.

### Tokenization and N-grams

After preprocessing, the text is typically tokenized into words or tokens. Tokenization can be customized by providing a callable tokenizer function.

N-grams (contiguous sequences of n tokens) can also be generated to capture context beyond single words.

### Analysis Function

The `_analyze` function orchestrates the entire process of converting a raw document into a sequence of tokens or n-grams:

```python
def _analyze(
    doc,
    analyzer=None,
    tokenizer=None,
    ngrams=None,
    preprocessor=None,
    decoder=None,
    stop_words=None,
):
    """
    Chain together an optional series of text processing steps to go from a single document to ngrams.

    Parameters
    ----------
    doc : str
        The raw document string.
    analyzer : callable, default=None
        A callable that replaces the preprocessor, tokenizer, and ngrams steps.
    tokenizer : callable, default=None
        Function to split the document into tokens.
    ngrams : callable, default=None
        Function to generate n-grams from tokens.
    preprocessor : callable, default=None
        Function to preprocess the document.
    decoder : callable, default=None
        Function to decode the document (e.g., from bytes to string).
    stop_words : list, default=None
        List of stop words to remove from tokens.

    Returns
    -------
    ngrams : list
        A sequence of tokens or n-grams extracted from the document.
    """
```

If an `analyzer` is provided, it replaces the other steps except for decoding. Otherwise, the document is decoded, preprocessed, tokenized, and transformed into n-grams, optionally removing stop words.

### Stop Words

Stop words are common words that are often removed from text to reduce noise. The submodule provides a built-in English stop word list `ENGLISH_STOP_WORDS`. You can specify `"english"` to use this list or provide your own list of stop words.

### Summary

By combining these utilities, you can build a robust pipeline to analyze and transform a collection of text documents into feature vectors suitable for machine learning models. The modular design allows you to customize each step — from preprocessing and tokenization to n-gram extraction and stop word removal — to best fit your specific text analysis task.
