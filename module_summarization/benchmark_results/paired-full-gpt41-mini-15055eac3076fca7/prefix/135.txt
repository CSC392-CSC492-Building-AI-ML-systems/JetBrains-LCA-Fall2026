Work with Images and Data Cubes Related to Cherenkov Cameras
=============================================================

This module provides tools and classes to work with images and data cubes associated with Cherenkov cameras, focusing on the geometry and description of telescope arrays and their components.

SubarrayDescription
-------------------

The `SubarrayDescription` class is a central component for managing collections of telescopes in a Cherenkov telescope array. It aggregates the descriptions of individual telescopes along with their positions on the ground, enabling users to handle the array as a whole.

### Overview

- **Purpose**: To collect and organize `TelescopeDescription` instances for all telescopes in a subarray, along with their spatial coordinates.
- **Key Attributes**:
  - `name` (str): The name of the subarray.
  - `positions` (Dict[int, np.ndarray]): A dictionary mapping telescope IDs to their 3D positions on the ground.
  - `tels` (Dict[int, TelescopeDescription]): A dictionary mapping telescope IDs to their descriptions.
  - `reference_location` (`astropy.coordinates.EarthLocation`): The Earth location used as the reference point for the coordinate system.

### Features

- **Coordinate Handling**: Telescope positions are internally converted to `astropy.coordinates.SkyCoord` objects in the `GroundFrame`, facilitating accurate spatial computations.
- **Validation**: Ensures that the telescope IDs in the positions and descriptions dictionaries match, preventing inconsistencies.
- **Information Display**: The `info()` method prints a summary of the subarray, including the number of telescopes, footprint size, and a breakdown of telescope types with their IDs.
- **Lazy Properties**: Uses `lazyproperty` to efficiently compute and cache telescope coordinates.

### Usage Example

```python
from ctapipe.instrument import SubarrayDescription, TelescopeDescription
from astropy.coordinates import EarthLocation
import astropy.units as u
import numpy as np

# Define telescope positions (in meters)
positions = {
    1: np.array([0, 0, 0]) * u.m,
    2: np.array([100, 0, 0]) * u.m,
}

# Define telescope descriptions
telescope_descriptions = {
    1: TelescopeDescription(name="Telescope1", ...),
    2: TelescopeDescription(name="Telescope2", ...),
}

# Define reference location on Earth
reference_location = EarthLocation(lat=28.76, lon=-17.89, height=2200 * u.m)

# Create subarray description
subarray = SubarrayDescription(
    name="ExampleSubarray",
    tel_positions=positions,
    tel_descriptions=telescope_descriptions,
    reference_location=reference_location,
)

# Print subarray info
subarray.info()
```

### Additional Utilities

- **Range Extraction**: Internal helper functions such as `_group_consecutives` and `_range_extraction` are used to format lists of telescope IDs into concise ranges for display purposes.
- **Exception Handling**: The `UnknownTelescopeID` exception is defined to handle cases where an invalid telescope ID is referenced.

Summary
-------

This module is essential for managing the spatial and descriptive metadata of Cherenkov telescope arrays, enabling downstream processing of camera images and data cubes with accurate geometric context. By organizing telescope descriptions and positions, it supports calibration, image reconstruction, and analysis workflows that depend on precise knowledge of the camera geometry and array layout.
