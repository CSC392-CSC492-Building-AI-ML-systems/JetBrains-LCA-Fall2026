Conditions in PyTables
======================

PyTables provides a powerful and flexible way to query and filter data stored in tables using *conditions*. Conditions allow you to specify criteria that rows must meet to be selected or processed. This document describes the syntax and usage of conditions in PyTables.

Overview
--------

A *condition* in PyTables is an expression that evaluates to a boolean value for each row in a table. Conditions are used in methods such as `Table.read_where()`, `Table.where()`, and `Table.remove_rows_where()` to filter rows based on column values.

Conditions can be simple comparisons, logical combinations of comparisons, or more complex expressions involving arithmetic operations and functions.

Basic Syntax
------------

Conditions are typically specified as strings using a subset of Python expressions. The syntax supports:

- **Comparison operators**: `==`, `!=`, `<`, `<=`, `>`, `>=`
- **Logical operators**: `&` (and), `|` (or), `~` (not)
- **Arithmetic operators**: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- **Parentheses** for grouping expressions
- **Column names** as variables
- **Constants** such as numbers and strings

Examples:

- Select rows where the column `age` is greater than 30:

  ```python
  condition = 'age > 30'
  ```

- Select rows where `weight` is between 50 and 80:

  ```python
  condition = '(weight >= 50) & (weight <= 80)'
  ```

- Select rows where `name` is not equal to `'John'`:

  ```python
  condition = 'name != "John"'
  ```

Logical Operators
-----------------

Logical operators combine multiple conditions:

- **AND**: Use `&` to combine conditions that must all be true.

- **OR**: Use `|` to combine conditions where at least one must be true.

- **NOT**: Use `~` to negate a condition.

Note that when combining conditions, parentheses are required to ensure correct precedence. For example:

```python
condition = '(age > 30) & ((weight < 70) | (height > 180))'
```

Column Names and Data Types
---------------------------

Column names used in conditions correspond to the fields defined in the table's description. PyTables supports various data types, including integers, floats, strings, and enumerations.

When referencing string columns, string literals in conditions must be enclosed in quotes (`'` or `"`).

Example:

```python
condition = 'city == "New York"'
```

Functions and Expressions
-------------------------

PyTables supports a limited set of functions and expressions in conditions, primarily arithmetic operations and comparisons. Complex functions or user-defined functions are not supported directly in condition strings.

For more advanced filtering, consider reading the entire table and applying Python functions on the resulting data.

Performance Considerations
--------------------------

Using conditions in PyTables queries is efficient because PyTables can use indexes on columns to speed up searches. Indexes are automatically created for columns when requested, and they significantly improve the performance of queries with conditions.

However, complex conditions or conditions on non-indexed columns may result in slower queries.

Examples of Using Conditions
----------------------------

1. **Reading rows with a condition:**

   ```python
   for row in table.where('age > 25'):
       print(row['name'], row['age'])
   ```

2. **Removing rows matching a condition:**

   ```python
   table.remove_rows_where('score < 50')
   ```

3. **Reading data into an array with a condition:**

   ```python
   data = table.read_where('height >= 170')
   ```

Notes
-----

- Conditions are evaluated in the context of the table's columns.

- Use parentheses to clarify complex logical expressions.

- String comparisons are case-sensitive.

- Conditions must be valid Python expressions using the supported syntax.

Summary
-------

Conditions in PyTables provide a concise and expressive way to filter and query table data. By leveraging comparison and logical operators, users can specify precise criteria to select rows of interest efficiently.

For more information, see the PyTables User Guide and API documentation related to the `Table` class and its methods that accept conditions.
