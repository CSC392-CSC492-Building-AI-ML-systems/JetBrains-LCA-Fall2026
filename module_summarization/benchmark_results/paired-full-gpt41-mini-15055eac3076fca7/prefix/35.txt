w_states command
================

Overview
--------

The `w_states` command is used to display or manipulate basis (initial) or target (recycling) states for a WEST simulation. By default, it displays the current states or dumps them to files. It also supports replacing or appending states for the next iteration of the simulation.

Modes of Operation
------------------

The command supports three mutually exclusive modes of operation:

- **--show**  
  Display the current basis and target states, or dump them to specified files.

- **--replace**  
  Replace the current basis or target states with those specified by the user for the next iteration.

- **--append**  
  Append the given target states to the existing list of target states for the next iteration.

Note: Appending basis states is not permitted due to the complexity of renormalizing basis state probabilities. To modify basis states, use the `--show` mode to export the current basis states to a file, edit the file as needed, and then use `--replace` with the updated file.

Arguments
---------

- **--bstate-file BSTATE_FILE**  
  Specify a file to read basis state names, probabilities, and data references from (when using `--append` or `--replace`), or to write them to (when using `--show`).

- **--bstate 'label,probability[,auxref]'**  
  Add a basis state directly via the command line. This option can be specified multiple times to add multiple basis states. These states are appended after those specified in `--bstate-file`, if any.

- **--tstate-file TSTATE_FILE**  
  Specify a file to read target state names and representative progress coordinates from (when using `--append` or `--replace`), or to write them to (when using `--show`).

- **--tstate 'label,pcoord0[,pcoord1[,...]]'**  
  Add a target state directly via the command line. This option can be specified multiple times to add multiple target states. These states are appended after those specified in `--tstate-file`, if any.

Additional Options
------------------

- The command integrates with WESTPA's runtime configuration and work manager environment, allowing specification of work manager options and other runtime parameters.

Usage Examples
--------------

- Display current basis and target states on the console:

  ```
  w_states --show
  ```

- Dump basis states to a file:

  ```
  w_states --show --bstate-file bstates.txt
  ```

- Replace basis states from a file:

  ```
  w_states --replace --bstate-file bstates.txt
  ```

- Append target states from the command line:

  ```
  w_states --append --tstate 'state1,0.1,0.2' --tstate 'state2,0.3,0.4'
  ```

Notes
-----

- When modifying basis states, it is recommended to export the current states to a file, edit the file manually, and then replace the states using the updated file. This avoids errors related to probability normalization.

- The command requires access to the WESTPA simulation environment and data files, and should be run in the context of an initialized WESTPA simulation.

Logging
-------

The command uses the logger named `w_states` for logging messages and diagnostics.

---

This command is a useful tool for managing the initial and recycling states in WEST simulations, facilitating inspection and modification of these states to control simulation behavior.
