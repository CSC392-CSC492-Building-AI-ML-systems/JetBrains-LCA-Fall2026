w_bins — Display and Modify WESTPA Binning Information
======================================================

Synopsis
--------

```
w_bins <command> [options]
```

Description
-----------

The `w_bins` command provides tools to display information and statistics about binning in a WEST simulation, as well as to modify the binning for the current iteration of a WEST simulation.

Binning is a key component in WESTPA simulations, defining how the configuration space is partitioned for weighted ensemble sampling. This tool helps users inspect and adjust binning schemes to optimize their simulations.

Commands
--------

### info

Display information about the binning used in a specified iteration of a WEST simulation.

**Usage:**

```
w_bins info [options]
```

**Options:**

- `-n`, `--n-iter` *N_ITER*  
  Consider initial points of segment *N_ITER*. Defaults to the current iteration if not specified.

- `--detail`  
  Display detailed per-bin information in addition to summary information.

- Binning-related options inherited from the binning component (e.g., specifying binning schemes).

**Description:**

This command prints bin information for the specified iteration, including bin assignments and weights. It also reports on target states and their assignments. When the `--detail` flag is used, detailed statistics for each bin are displayed.

---

### rebin

Rebuild the current iteration with a new binning scheme.

**Usage:**

```
w_bins rebin [options]
```

**Options:**

- `--confirm`  
  Commit the revised iteration to the HDF5 file. Without this option, the effects of the new binning are only calculated and printed, but not saved.

- `--detail`  
  Display detailed per-bin information in addition to summary information.

- `-n`, `--n-iter` *N_ITER*  
  Consider initial points of segment *N_ITER*. Defaults to the current iteration if not specified.

- Binning-related options for specifying the new binning scheme and target counts. Note that the option `--bins-from-file` is suppressed in this command.

**Description:**

This command allows users to modify the binning for the current iteration by rebuilding it with a new binning scheme. It reads the segments from the specified iteration and reassigns them according to the new binning. The `--confirm` flag must be used to save changes to the simulation data; otherwise, the command only simulates the rebinning and outputs the results.

**Important:** Rebinning is not supported for the first iteration. Attempting to rebin iteration 1 will result in an error message advising to reinitialize with `w_init` instead.

---

General Options
---------------

The `w_bins` tool accepts additional options related to data reading and binning configuration, inherited from the WESTPA tools framework. These include options to specify the WESTPA data file, iteration number, and binning parameters.

Examples
--------

- Display binning information for the current iteration with summary statistics:

  ```
  w_bins info
  ```

- Display detailed binning information for iteration 10:

  ```
  w_bins info -n 10 --detail
  ```

- Simulate rebinning of the current iteration with a new binning scheme, showing detailed bin statistics without saving:

  ```
  w_bins rebin --detail --bins <binning options>
  ```

- Commit the rebinning changes to iteration 15:

  ```
  w_bins rebin -n 15 --confirm --bins <binning options>
  ```

Logging
-------

The `w_bins` tool uses logging under the logger name `w_bins` to report informational messages and errors.
