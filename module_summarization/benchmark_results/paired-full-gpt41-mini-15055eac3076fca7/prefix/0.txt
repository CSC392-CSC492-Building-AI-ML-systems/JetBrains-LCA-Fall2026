Working with Assignments and Allocations
========================================

In ftrack, assignments and allocations are fundamental concepts used to manage the distribution of work and resources across tasks and users. This documentation provides an overview of how to work with assignments and allocations within the ftrack API.

Assignments
-----------

An *assignment* represents the relationship between a task and a user or group responsible for completing that task. Assignments are used to specify who is assigned to perform a particular task within a project.

### Creating Assignments

To create an assignment, you typically associate a user or group with a task entity. This can be done by creating an assignment entity and linking it to the relevant task and user.

Example:

```python
# Assume 'session' is an active ftrack_api.Session instance
task = session.query('Task where name is "Animation"').one()
user = session.query('User where username is "jdoe"').one()

assignment = session.create('Assignment', {
    'task': task,
    'resource': user
})
session.commit()
```

### Querying Assignments

You can query assignments to find out which users are assigned to which tasks, or to retrieve all assignments for a particular user or task.

Example:

```python
assignments = session.query('Assignment where resource.username is "jdoe"').all()
for assignment in assignments:
    print(f'Task: {assignment["task"].name}, Assigned to: {assignment["resource"].username}')
```

Allocations
-----------

An *allocation* represents the allocation of a resource (usually a user) to a project or a broader scope, often with a specified time period or capacity. Allocations help manage resource availability and planning.

### Creating Allocations

Allocations are created by associating a resource with a project or other entity, optionally specifying start and end dates or other constraints.

Example:

```python
project = session.query('Project where name is "Feature Film"').one()
user = session.query('User where username is "jdoe"').one()

allocation = session.create('Allocation', {
    'project': project,
    'resource': user,
    'start_date': '2024-01-01T00:00:00Z',
    'end_date': '2024-06-30T23:59:59Z'
})
session.commit()
```

### Querying Allocations

You can query allocations to determine resource availability or to review how resources are distributed across projects.

Example:

```python
allocations = session.query('Allocation where resource.username is "jdoe"').all()
for allocation in allocations:
    print(f'Project: {allocation["project"].name}, From: {allocation["start_date"]}, To: {allocation["end_date"]}')
```

Best Practices
--------------

- Always commit your session after creating or modifying assignments and allocations to persist changes.
- Use queries to validate existing assignments and allocations before creating new ones to avoid duplicates.
- Utilize allocations to manage resource availability effectively, especially when planning across multiple projects.
- Leverage the ftrack API’s event system to listen for changes in assignments and allocations to keep your application state synchronized.

Summary
-------

Assignments link tasks to the users or groups responsible for them, while allocations manage the availability and capacity of resources across projects. Together, they provide a powerful mechanism for resource and task management within ftrack. Using the ftrack API, you can create, query, and manage assignments and allocations programmatically to integrate with your production workflows.
