====================
SimpleFitter wrapper
====================

This module provides a wrapper class and utility functions to add a variable height (background) component to any spectral model.

Module API
^^^^^^^^^^

The module includes the following key components:

SimpleFitter Class
------------------

A basic wrapper class intended to be extended by more complex spectral fitting classes.

Methods:

- __init__():  
  Initializes the SimpleFitter instance. Currently a placeholder with no implementation.

- moments(*args, **kwargs):  
  Computes spectral moments using the `moments` function from the `pyspeckit.spectrum.moments` package.  
  Returns the spectral moments for the given input data.

vheightmodel(zeroheightmodel)
-----------------------------

A function decorator that wraps an existing model function to add a variable height (background) parameter.

Parameters:
- zeroheightmodel (function):  
  The original model function without a height parameter.

Returns:
- vhm (function):  
  A new model function that includes an additional height parameter as the first parameter.  
  The parameter order for the wrapped function is: height, amplitude, shift, width.

Behavior:
- If the keyword argument `vheight` is True (default), the returned model value is the original model plus the height parameter.
- If `vheight` is False, the height parameter is ignored and the original model is returned unchanged.

The wrapper function `vhm` inherits the documentation string from the original `zeroheightmodel` function.

=============================
Generic SpectralModel wrapper
=============================

.. moduleauthor:: Adam Ginsburg <adam.g.ginsburg@gmail.com>

This module provides a comprehensive wrapper class for spectral models, enabling multi-component modeling, parameter management, annotations, and integration. It supports complex model declarations with named parameters, limits, units, and annotations.

Module API
^^^^^^^^^^

SpectralModel Class
-------------------

A subclass of `SimpleFitter` designed for flexible spectral modeling and fitting.

Description:
- Facilitates the creation of multi-component spectral models.
- Supports parameter naming, limits, units, and annotations.
- Provides internal functions for generating model components, annotations, and integrals.
- Suitable for complex spectral line fitting, including hyperfine structure models.

Constructor (__init__) Parameters:

- modelfunc (function):  
  The model function to be fitted. It should accept a spectroscopic X-axis and model parameters, returning an array of model values.

- npars (int):  
  Number of parameters required by the model.

- shortvarnames (tuple, optional):  
  TeX-formatted short variable names for parameters, used in annotations. Default is ("A", "\\Delta x", "\\sigma").

- fitunit (str, optional):  
  Units to convert the X-axis into before passing to the model function.

- centroid_par (int or None, optional):  
  Index of the parameter representing the centroid (center) of the model.

- fwhm_func (function or None, optional):  
  Function to compute the full width at half maximum (FWHM) from model parameters.

- fwhm_pars (list or None, optional):  
  Parameters to be passed to the FWHM function.

- integral_func (function or None, optional):  
  Function to compute the integral of the model.

- use_lmfit (bool, optional):  
  If True, use the `lmfit` package for fitting instead of `mpfit`.

- guess_types (tuple, optional):  
  Tuple specifying the types of parameters for initial guesses. Valid types are 'amplitude', 'center', and 'width'. Default is ('amplitude', 'center', 'width').

- **kwargs:  
  Additional keyword arguments for extended functionality.

Description of Parameter Guess Types:
- 'amplitude': Parameter representing the amplitude of the spectral feature.
- 'center': Parameter representing the center or position of the spectral feature.
- 'width': Parameter representing the width or dispersion of the spectral feature.

Notes:
- The class supports parameter limits, fixing parameters, tying parameters together, and specifying step sizes.
- It is designed to handle complex models with multiple components and parameters.
- Examples of usage include hyperfine structure fitting for molecules such as HCN and N2H+.

Exceptions:
- Raises warnings if required dependencies such as `OrderedDict` are not available.

Additional Module Details
-------------------------

- Imports and dependencies include numpy, mpfit, astropy logging, matplotlib utilities, and pyspeckit internal modules.
- Provides compatibility handling for Python versions lacking `OrderedDict`.
- Defines a tuple `valid_guess_types` listing allowed guess parameter types.

Summary
-------

This module offers foundational classes and utilities for spectral model fitting, emphasizing flexibility and extensibility. It enables users to define complex spectral models with variable background components, manage parameter properties, and perform robust fitting using either `mpfit` or `lmfit`. The included `SpectralModel` class is a powerful tool for astronomers and spectroscopists working with spectral line data.
