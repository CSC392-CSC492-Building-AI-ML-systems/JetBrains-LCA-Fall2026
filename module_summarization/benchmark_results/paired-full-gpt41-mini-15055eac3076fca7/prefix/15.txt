Ploterr Command
===============

The `ploterr` command provides functionality for plotting data with error bounds, typically used to visualize expected values along with confidence intervals over iterations. It supports flexible customization of plot appearance and output formats.

Overview
--------

The `ploterr` command is implemented as a subcommand within the WESTPA framework, inheriting from `WESTSubcommand`. It offers options to control plot scaling, axis ranges, labels, titles, and output interfaces.

Features
--------

- Plot expected values with confidence interval bounds.
- Support for linear, logarithmic, and symmetric logarithmic scales on both axes.
- Customizable axis ranges and labels.
- Ability to specify plot titles.
- Output plots either as graphical images (using Matplotlib) or as terminal-based plots.
- Progress indication during plotting operations.

Usage
-----

The command accepts the following options related to plotting:

**Plot Options**

- `--xscale {linear,log,symlog}`  
  Specify the scaling for the x-axis. Default is `linear`.

- `--yscale {linear,log,symlog}`  
  Specify the scaling for the y-axis. Default is `linear`.

- `--xrange XRANGE`  
  Restrict the x-axis range to `XRANGE`, which must be formatted as `"xmin,xmax"`.  
  If not specified, the range is determined automatically from the input data.

- `--yrange YRANGE`  
  Restrict the y-axis range to `YRANGE`, which must be formatted as `"ymin,ymax"`.  
  If not specified, the range is determined automatically from the input data.

- `--xlabel XLABEL`  
  Use `XLABEL` as the label for the x-axis. Default is `"Iteration"`.

- `--ylabel YLABEL`  
  Use `YLABEL` as the label for the y-axis. Default varies depending on the data.

- `--title TITLE`  
  Use `TITLE` as the plot title. Default varies depending on the data.

- `--terminal`, `-t`  
  Plot output in the terminal instead of generating a graphical plot. This is useful when no graphical display is available.

Behavior
--------

- The command automatically detects whether a graphical display is available by checking the `DISPLAY` environment variable. If no display is found or the `--terminal` option is specified, the plot is rendered in the terminal.

- When generating graphical plots, the command uses Matplotlib to create figures showing the expected values and confidence interval bounds over iterations.

- The x-axis typically represents iteration numbers, while the y-axis shows the expected values and their confidence intervals.

- The plot includes three lines:
  - Expected values (black line)
  - Lower confidence interval bound (gray line)
  - Upper confidence interval bound (gray line)

Examples
--------

Plot with default linear scales and automatic axis ranges:

```
ploterr data.h5 output.png
```

Plot with logarithmic y-axis and custom x-axis range:

```
ploterr --yscale log --xrange 0,100 data.h5 output.png
```

Plot with custom axis labels and title:

```
ploterr --xlabel "Time (ps)" --ylabel "Probability" --title "Progress Over Time" data.h5 output.png
```

Plot output in terminal (no graphical display):

```
ploterr --terminal data.h5
```

Notes
-----

- The `XRANGE` and `YRANGE` options require a comma-separated pair of numeric values specifying the minimum and maximum axis limits.

- If invalid range specifications are provided, the command will raise an error indicating the invalid input.

- The command relies on Matplotlib for graphical output; ensure Matplotlib is installed and a display is available for graphical plots.

- Progress indicators are shown during plotting operations to provide feedback on command execution.

Logging
-------

The command uses a logger named `ploterrs` to record informational and error messages during execution.

Dependencies
------------

- Python packages: `numpy`, `h5py`, `matplotlib` (optional, for graphical output)
- WESTPA framework components: `WESTMasterCommand`, `WESTSubcommand`, `ProgressIndicatorComponent`, `Plotter`
