Calculator Interface
====================

Overview
--------

The Calculator Interface provides functionality to list and inspect parameters used across various models. It allows users to identify all parameters, filter them by type, and see which models utilize each parameter.

Usage
-----

The primary utility is accessible via the command line as follows:

```
python -m sasmodels.list_pars [-v] [kind]
```

- `-v`, `--verbose`: When specified, the output includes the models that use each parameter.
- `kind`: Optional positional argument to filter parameters by their kind. Possible values are:
  - `volume`
  - `orientation`
  - `sld`
  - `none`
  - `any` (default)

If `kind` is omitted or set to `any`, all parameters are listed regardless of type.

Functionality
-------------

### find_pars(kind=None)

Scans all available models and collects parameters used by them.

- **Parameters:**
  - `kind` (optional): Filter parameters by their type (e.g., volume, orientation, sld). If `None`, all parameters are included.

- **Returns:**
  - A dictionary mapping parameter names to a list of model names that use them:
    ```python
    {parameter_name: [model1, model2, ...], ...}
    ```

### list_pars(names_only=True, kind=None)

Prints the list of parameters found across all models.

- **Parameters:**
  - `names_only` (bool): If `True`, only parameter names are printed. If `False`, each parameter is followed by the models that use it.
  - `kind` (optional): Filter parameters by type, passed to `find_pars`.

- **Behavior:**
  - When `names_only` is `True`, the parameter names are printed in a columnized format.
  - When `names_only` is `False`, each parameter is printed along with the comma-separated list of models that use it.

### main()

Entry point for the command line interface.

- Parses command line arguments.
- Calls `list_pars` with appropriate options based on user input.

Examples
--------

- List all parameter names:

  ```
  python -m sasmodels.list_pars
  ```

- List all parameters along with the models that use them:

  ```
  python -m sasmodels.list_pars -v
  ```

- List only parameters of kind `volume`:

  ```
  python -m sasmodels.list_pars volume
  ```

- List parameters of kind `sld` with verbose output:

  ```
  python -m sasmodels.list_pars -v sld
  ```

Notes
-----

- The interface relies on the internal model registry and parameter metadata.
- Parameter kinds correspond to categories such as volume-related parameters, orientation parameters, scattering length density (sld), or none.
- The tool is useful for developers and users who want to understand parameter usage across models or to find parameters of a specific type.
