Support Vector Machines (SVM)
==============================

Support Vector Machines (SVM) are a set of supervised learning methods used for classification, regression, and outliers detection. They are particularly well-suited for classification of complex but small- or medium-sized datasets.

LinearSVC
---------

The `LinearSVC` class implements linear Support Vector Classification. It is similar to the `SVC` class with `kernel='linear'`, but it is implemented using the `liblinear` library rather than `libsvm`. This implementation provides more flexibility in the choice of penalties and loss functions and generally scales better to large numbers of samples.

Key Features:
- Supports both dense and sparse input.
- Handles multiclass classification using a one-vs-the-rest scheme.
- Offers different penalties and loss functions for customization.
- More scalable to large datasets compared to kernel-based SVMs.

Parameters
----------

- **penalty** : {'l1', 'l2'}, default='l2'  
  Specifies the norm used in the penalization. The 'l2' penalty is the standard used in SVC. The 'l1' penalty leads to sparse coefficient vectors (`coef_`).

- **loss** : {'hinge', 'squared_hinge'}, default='squared_hinge'  
  Specifies the loss function. 'hinge' is the standard SVM loss (used by `SVC`), while 'squared_hinge' is the square of the hinge loss. Note that the combination of `penalty='l1'` and `loss='hinge'` is not supported.

- **dual** : {"auto", bool}, default=True  
  Selects whether to solve the dual or primal optimization problem. It is recommended to set `dual=False` when the number of samples exceeds the number of features. The `"auto"` option (introduced in version 1.3 and becoming the default in version 1.5) automatically chooses the appropriate setting based on the dataset and parameters.

- **tol** : float, default=1e-4  
  Tolerance for stopping criteria.

Usage Notes
-----------

- `LinearSVC` differs from `SVC(kernel='linear')` primarily in the loss function used by default and in the handling of intercept regularization.
- The class supports both dense and sparse input formats.
- Multiclass classification is handled via a one-vs-the-rest approach.
- The choice between solving the dual or primal problem can significantly affect performance and is automatically determined when using `dual="auto"`.
