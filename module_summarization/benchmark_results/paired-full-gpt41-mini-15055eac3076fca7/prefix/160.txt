Compatibility Policy
====================

The `numpy.random` module, including its underlying C libraries and Cython extensions, follows a compatibility policy designed to balance stability for users with the ability to improve and optimize the implementation.

Source Compatibility
--------------------

- The core random number generation functionality is implemented in C source files located under `src/` directories, such as `src/distributions/`, `src/mt19937/`, `src/philox/`, `src/pcg64/`, and `src/sfc64/`.
- These source files are compiled into a static library `npyrandom` which is linked into the Python extension modules.
- The C API exposed by these sources is considered internal and subject to change; direct usage outside of the `numpy.random` module is not guaranteed to be stable.

Python API Compatibility
------------------------

- The Python interface is provided through Cython extension modules, each corresponding to different bit generators and distributions.
- The extensions are built from `.pyx` files and associated C sources, with generated `.pxd` files installed alongside for Cython users.
- The public Python API, including modules such as `_mt19937`, `_philox`, `_pcg64`, `_sfc64`, `bit_generator`, and `mtrand`, is maintained with backward compatibility in mind.
- Deprecated APIs are still supported where necessary, as indicated by compilation flags such as `-DNPY_NO_DEPRECATED_API=0`, to ensure existing codebases continue to function.

Binary Compatibility
--------------------

- The compiled extension modules link against the `npyrandom` static library and other internal dependencies.
- Compilation flags and platform-specific linker options (e.g., `-Wl,--export-all-symbols` on Cygwin) are used to ensure compatibility across supported platforms.
- Users should rely on the provided Python packages and avoid linking directly against internal static libraries to maintain compatibility.

Installation and Distribution
-----------------------------

- All source files, headers (`.pxd`), Python modules, tests, examples, and license files are installed into the `numpy/random` subdirectory within the NumPy installation.
- This consistent installation layout supports compatibility with tools and workflows that depend on the presence of these files.

Testing and Validation
----------------------

- A comprehensive suite of tests is included and installed under `numpy/random/tests` to verify the correctness and stability of the random number generation implementations.
- Test data sets for various bit generators are also installed to support regression testing and validation.

Summary
-------

Users of `numpy.random` can expect a stable and consistent API for random number generation across NumPy releases. While internal implementation details and C APIs may evolve, the public Python interface and installed files maintain backward compatibility to support existing codebases and extensions.
