GILDAS CLASS File Reader
=======================

Overview
--------

This module provides functionality to read GILDAS CLASS files and convert them into `pyspeckit.spectrum.ObsBlock` objects for further analysis. CLASS files are a standard format used in radio astronomy for storing spectral data.

Features
--------

- Supports multiple CLASS file types and versions, including IEEE and VAX formats.
- Handles different record lengths and header types as specified by the CLASS file format.
- Includes utilities for timing function execution to monitor performance during file reading.
- Provides compatibility with both Python 2 and 3 using the `six` library.
- Uses `astropy` for logging and unit handling.

Key Components
--------------

- **filetype_dict**: Maps CLASS file type codes to descriptive strings indicating the file format variant.
- **fileversion_dict**: Maps file type codes to version identifiers.
- **record_lengths**: Defines the byte length of records for different CLASS file versions.
- **header_id_numbers**: Associates header ID numbers with their corresponding section names in the CLASS file.
- **header_id_lengths**: Specifies the expected lengths of various header sections.
- **print_timing(func)**: A decorator function that logs the execution time of the decorated function, useful for monitoring performance when reading large CLASS files.
- **ensure_bytes(string)**: Utility function to ensure that strings are in byte format, supporting compatibility across Python versions.

Usage
-----

The module is designed to be imported and used within the `pyspeckit` framework or other Python scripts that require reading and processing CLASS files. It abstracts the complexities of the CLASS file format, allowing users to focus on data analysis.

References
----------

- CLASS file format specification: http://iram.fr/IRAMFR/GILDAS/doc/html/class-html/node58.html
- `pyspeckit` spectrum analysis package

Dependencies
------------

- Python 2.7 or 3.x
- `six` for Python 2/3 compatibility
- `numpy`
- `astropy` (for logging, units, and FITS file handling)
- `pyspeckit`

Notes
-----

- Some header sections are marked as "private" and correspond to specialized fits or calibration data.
- The module includes placeholders for progress bars during file reading, which can be enabled if `astropy.utils.console.ProgressBar` is available.
- The code includes partial definitions and comments related to the CLASS file structure, indicating ongoing development or extension.

This module is essential for astronomers and data scientists working with spectral data stored in CLASS files, facilitating efficient data ingestion and preparation for analysis.
