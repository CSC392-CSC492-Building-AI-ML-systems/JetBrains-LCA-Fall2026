Feature Extraction from Text
============================

The `sklearn.feature_extraction.text` submodule provides utilities to build feature vectors from text documents. It includes various classes and functions to preprocess text, tokenize, remove accents, strip HTML tags, and convert text into numerical feature representations suitable for machine learning models.

Submodule Overview
------------------

This submodule contains the following key components:

- **Vectorizers**:
  - `CountVectorizer`: Converts a collection of text documents to a matrix of token counts.
  - `HashingVectorizer`: Uses the hashing trick to convert text documents to a matrix of token occurrences.
  - `TfidfVectorizer`: Converts a collection of raw documents to a matrix of TF-IDF features.

- **Transformers**:
  - `TfidfTransformer`: Transforms a count matrix to a normalized TF-IDF representation.

- **Stop Words**:
  - `ENGLISH_STOP_WORDS`: A built-in set of English stop words for filtering common words.

- **Text Preprocessing Utilities**:
  - `strip_accents_unicode(s)`: Removes accentuated unicode symbols by decomposing them into their base characters.
  - `strip_accents_ascii(s)`: Removes accentuated unicode symbols by transliterating them into ASCII characters.
  - `strip_tags(s)`: Removes HTML/XML tags from a string using a basic regular expression.

Text Processing Functions
-------------------------

- `_preprocess(doc, accent_function=None, lower=False)`: Applies a sequence of preprocessing steps to a document string, including optional accent stripping and lowercasing.

- `_analyze(doc, analyzer=None, tokenizer=None, ngrams=None, preprocessor=None, decoder=None, stop_words=None)`: Processes a document through a customizable pipeline of decoding, analyzing, tokenizing, n-gram extraction, and stop word filtering to produce a sequence of tokens or n-grams.

Accent Stripping
----------------

Two functions are provided to handle accented characters in text:

- `strip_accents_unicode(s)`: Uses Unicode normalization to decompose accented characters and removes combining marks. This method preserves the original characters as much as possible but is slower due to Python-level processing.

- `strip_accents_ascii(s)`: Transliterates accented characters to their closest ASCII equivalents by encoding to ASCII and ignoring errors. This method is faster but only suitable for languages with direct ASCII transliterations.

HTML Tag Stripping
------------------

- `strip_tags(s)`: Removes HTML or XML tags from a string using a regular expression. For more robust HTML parsing, external libraries such as `lxml` or `BeautifulSoup` are recommended.

Stop Words Handling
-------------------

- The submodule supports stop word filtering with a built-in English stop word list (`ENGLISH_STOP_WORDS`). Custom stop word lists can also be provided.

Usage Notes
-----------

- The vectorizers and transformers in this submodule are designed to integrate seamlessly with scikit-learn's estimator API, supporting methods like `fit`, `transform`, and `fit_transform`.

- Preprocessing functions can be customized or extended to suit specific text processing needs.

- When working with accented characters or HTML content, appropriate preprocessing steps should be applied to ensure clean and consistent input for feature extraction.
