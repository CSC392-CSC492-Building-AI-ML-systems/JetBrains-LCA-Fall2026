Nearest Neighbors
=================

The Nearest Neighbors module provides efficient data structures and algorithms to perform nearest neighbor searches in high-dimensional spaces. One of the key data structures implemented is the **Ball Tree**, which is a binary tree specialized for spatial partitioning and fast nearest neighbor queries.

Ball Tree
---------

A Ball Tree is a binary tree where each node represents a "ball" or hypersphere containing a subset of the data points. The tree recursively partitions the data into nested hyperspheres, allowing efficient pruning of search space during nearest neighbor queries.

### Implementation Details

- The Ball Tree is implemented as a specialization of a generic binary tree structure.
- Each node stores a centroid and a radius defining the hypersphere that encloses all points in that node.
- The centroid is computed as the weighted or unweighted mean of the points in the node.
- The radius is the maximum reduced distance from the centroid to any point in the node.
- The concept of **reduced distance** is used for efficiency: it is a metric-dependent quantity that preserves the relative ranking of distances but is cheaper to compute. For example, for Euclidean distance, the reduced distance is the squared Euclidean distance.

### Supported Data Types

The Ball Tree implementation supports multiple floating-point precisions:

- `BallTree64` for 64-bit floating point data (`float64`)
- `BallTree32` for 32-bit floating point data (`float32`)

### Supported Distance Metrics

The Ball Tree supports a variety of distance metrics, including but not limited to:

- Bray-Curtis Distance
- Canberra Distance
- Chebyshev Distance
- Dice Distance
- Euclidean Distance
- Hamming Distance
- Haversine Distance
- Jaccard Distance
- Mahalanobis Distance
- Manhattan Distance
- Minkowski Distance
- Rogers-Tanimoto Distance
- Russell-Rao Distance
- Squared Euclidean Distance
- Sokal-Michener Distance
- Sokal-Sneath Distance
- Weighted Minkowski Distance
- User-defined Python function distance

### Node Initialization

When building the Ball Tree, each node is initialized by:

1. Computing the centroid of the points in the node, optionally weighted by sample weights.
2. Computing the radius as the maximum reduced distance from the centroid to any point in the node.
3. Storing the start and end indices of the points contained in the node.

This initialization allows efficient pruning during nearest neighbor searches by comparing distances to node radii.

Summary
-------

The Ball Tree data structure provides an efficient way to organize data points for nearest neighbor queries, especially in high-dimensional spaces. By leveraging reduced distances and hierarchical partitioning into hyperspheres, it enables fast and scalable nearest neighbor searches with support for a wide range of distance metrics and data types.
