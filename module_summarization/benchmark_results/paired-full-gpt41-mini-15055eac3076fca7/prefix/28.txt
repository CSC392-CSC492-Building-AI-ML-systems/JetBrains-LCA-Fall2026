w_multi_west Command
====================

Overview
--------
`w_multi_west` is a command-line tool designed to combine multiple WESTPA simulations into a single dataset while properly accounting for reweighting. This tool facilitates the aggregation of simulation data, including auxiliary datasets, enabling comprehensive analysis across multiple simulation runs.

Features
--------
- Combines multiple WESTPA simulation results.
- Supports reweighting of combined data to maintain statistical accuracy.
- Allows inclusion of additional auxiliary datasets.
- Optionally combines all auxiliary datasets automatically.
- Supports combining the `ibstates` dataset.
- Provides progress indication during processing.

Usage
-----
```
w_multi_west [OPTIONS]
```

Command-Line Options
--------------------

Input/Output Options
~~~~~~~~~~~~~~~~~~~

- `-o`, `--output-file`  
  Specify the name of the output file to store the combined results.  
  **Default:** `multi.h5`

- `-W`, `--west`, `--WEST_H5FILE`  
  Specify the name of the main WESTPA HDF5 file inside each simulation directory.  
  **Default:** `west.h5`

- `-a`, `--aux`  
  Names of additional auxiliary datasets to be combined. This option can be specified multiple times to include multiple auxiliary datasets.

- `-aa`, `--auxall`  
  Combine all auxiliary datasets found in the simulations.  
  **Default:** False

- `-nr`, `--no-reweight`  
  Disable reweighting of the combined data.  
  **Default:** False

- `-ib`, `--ibstates`  
  Attempt to combine the `ibstates` dataset.  
  **Default:** False

Description
-----------
The `w_multi_west` tool reads multiple WESTPA simulation directories, each containing a `west.h5` file (or a specified alternative), and merges their data into a single HDF5 file. It handles the complexities of reweighting to ensure that the combined dataset accurately reflects the underlying statistical ensemble.

Auxiliary datasets, which may contain additional simulation data, can be selectively included or all combined automatically. The tool also supports combining the `ibstates` dataset, which may be relevant for certain analyses.

Internally, the tool manages progress reporting to keep users informed during potentially long-running operations.

Example
-------
To combine simulations located in multiple directories, producing an output file named `combined.h5` and including all auxiliary datasets, run:

```
w_multi_west -o combined.h5 -aa /path/to/sim1/west.h5 /path/to/sim2/west.h5 /path/to/sim3/west.h5
```

To combine simulations without reweighting and include a specific auxiliary dataset named `aux_data`:

```
w_multi_west -nr -a aux_data /path/to/sim1/west.h5 /path/to/sim2/west.h5
```

Notes
-----
- The tool expects the input simulation directories to contain valid WESTPA HDF5 files.
- Reweighting is enabled by default to maintain statistical correctness.
- Combining all auxiliary datasets (`--auxall`) overrides specifying individual auxiliary datasets.
- The `ibstates` dataset combination is experimental and may not be supported in all cases.

Logging and Debugging
---------------------
The tool uses Python's logging module to provide debug information, including details about binning data loading and hash value lookups. This can be helpful for troubleshooting issues related to data consistency or file access.
