Tuning the hyper-parameters of an estimator
============================================

When building machine learning models, selecting the right hyper-parameters is crucial for achieving optimal performance. Hyper-parameters are parameters that are not learned from the data during training but are set prior to the learning process. Examples include the regularization strength in linear models, the number of neighbors in k-nearest neighbors, or the depth of a decision tree.

Grid Search
-----------

Grid search is a systematic way of working through multiple combinations of parameter tunes, cross-validating as it goes to determine which tune gives the best performance. The process involves specifying a set of hyper-parameters and their possible values, then exhaustively evaluating the model performance for each combination.

The typical workflow for grid search includes:

1. **Defining the parameter grid**: Specify the hyper-parameters and the range of values to explore.

2. **Cross-validation**: For each combination of parameters, the model is trained and evaluated using cross-validation to estimate its generalization performance.

3. **Selecting the best parameters**: The combination of hyper-parameters that yields the best cross-validation score is selected.

4. **Refitting the model**: The model is retrained on the entire training set using the best found parameters.

Visualization of Hyper-parameter Tuning Results
----------------------------------------------

Visual tools can help understand how different hyper-parameter values affect model performance. For example, plotting validation curves or learning curves can provide insights into underfitting or overfitting behaviors.

The `_BaseCurveDisplay` class provides utilities to plot such curves, showing training and validation scores along with their variability. It supports different styles for displaying the standard deviation, such as shaded regions (`fill_between`) or error bars (`errorbar`).

Key features include:

- Plotting mean training and validation scores against hyper-parameter values.
- Displaying variability in scores to assess stability.
- Customizable plot styles and labels.
- Support for logarithmic scales and different score types (train, test, or both).

By leveraging these visualization tools, practitioners can make informed decisions about hyper-parameter settings and better understand the model's learning dynamics.

Best Practices
--------------

- Use cross-validation to reliably estimate model performance for each hyper-parameter setting.
- Consider the computational cost of exhaustive grid search; for large parameter spaces, randomized search or Bayesian optimization may be more efficient.
- Visualize the results to detect patterns such as overfitting or underfitting.
- Always validate the final model on a separate test set to assess its generalization ability.

In summary, tuning hyper-parameters through grid search combined with visualization techniques is a powerful approach to optimize estimator performance and gain deeper insights into model behavior.
