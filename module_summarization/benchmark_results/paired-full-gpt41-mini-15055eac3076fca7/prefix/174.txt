Array API Support
=================

Scikit-learn aims to provide compatibility with the Array API standard, enabling interoperability with array libraries that implement this specification. This support facilitates the use of scikit-learn estimators and utilities with a variety of array types beyond NumPy arrays, such as those from libraries like CuPy, Dask, or others adhering to the Array API.

Overview
--------

The Array API standard defines a common set of array operations and behaviors, allowing libraries to work seamlessly with different array implementations. Scikit-learn's support for the Array API ensures that its core functionalities, including estimators, transformers, and utilities, can operate on any compliant array type without requiring conversion to NumPy arrays.

Supported Features
------------------

- **Estimator Compatibility**: Most scikit-learn estimators accept inputs that implement the Array API, enabling training and prediction on arrays from supported libraries.
- **Meta-Estimators**: Meta-estimators such as `MultiOutputRegressor`, `MultiOutputClassifier`, `ClassifierChain`, and `RegressorChain` are designed to work with base estimators that support the Array API, thus extending multioutput capabilities to compliant array types.
- **Utilities and Validation**: Internal utilities for validation, cloning, and parameter checking have been adapted to recognize and handle Array API arrays appropriately.
- **Parallel and Sparse Support**: Parallel processing utilities and sparse matrix support are maintained alongside Array API compatibility, ensuring efficient computation.

Usage Notes
-----------

- When using array types other than NumPy, ensure that the array library fully implements the Array API specification to avoid unexpected behavior.
- Some scikit-learn features or third-party extensions may not yet support the Array API; consult the relevant documentation for compatibility details.
- Performance characteristics may vary depending on the underlying array library and its implementation of the Array API.

Example
-------

```python
import numpy as np
from sklearn.multioutput import MultiOutputRegressor
from sklearn.linear_model import LinearRegression

# Using a NumPy array (Array API compliant)
X = np.array([[1, 2], [3, 4], [5, 6]])
y = np.array([[1, 2], [3, 4], [5, 6]])

regressor = MultiOutputRegressor(LinearRegression())
regressor.fit(X, y)
predictions = regressor.predict(X)
```

In this example, replacing `np.array` with an array from another Array API-compliant library should work seamlessly with scikit-learn estimators.
