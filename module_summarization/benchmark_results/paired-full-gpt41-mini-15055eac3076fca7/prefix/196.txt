Multiclass and Multioutput Algorithms
=====================================

Scikit-learn provides a set of meta-estimators that extend single-output estimators to handle multioutput regression and classification problems. These meta-estimators require a base estimator to be provided during their construction and enable the application of single-output algorithms to problems with multiple outputs.

Overview
--------

Multioutput problems involve predicting multiple target variables simultaneously. These targets can be either continuous (regression) or categorical (classification). The estimators in this module facilitate handling such problems by wrapping around existing single-output estimators.

Key Meta-Estimators
-------------------

- **MultiOutputRegressor**  
  Extends a single-output regressor to support multioutput regression by fitting one regressor per target variable independently.

- **MultiOutputClassifier**  
  Extends a single-output classifier to support multioutput classification by fitting one classifier per target variable independently.

- **ClassifierChain**  
  Implements a chain of classifiers where each classifier deals with one target variable and the predictions of previous classifiers in the chain are used as additional features for subsequent classifiers. This approach models dependencies between target variables.

- **RegressorChain**  
  Similar to `ClassifierChain`, but for regression problems. It models dependencies between multiple continuous target variables by chaining regressors.

Usage
-----

These meta-estimators require a base estimator that supports either regression or classification. For example, to use `MultiOutputRegressor` with a decision tree regressor:

```python
from sklearn.tree import DecisionTreeRegressor
from sklearn.multioutput import MultiOutputRegressor

base_regressor = DecisionTreeRegressor()
multioutput_regressor = MultiOutputRegressor(base_regressor)
multioutput_regressor.fit(X_train, y_train)
y_pred = multioutput_regressor.predict(X_test)
```

Similarly, for multioutput classification:

```python
from sklearn.linear_model import LogisticRegression
from sklearn.multioutput import MultiOutputClassifier

base_classifier = LogisticRegression()
multioutput_classifier = MultiOutputClassifier(base_classifier)
multioutput_classifier.fit(X_train, y_train)
y_pred = multioutput_classifier.predict(X_test)
```

Advantages
----------

- **Flexibility:** Allows any single-output estimator to be extended to multioutput problems without modifying the underlying estimator.
- **Modularity:** Each target variable is modeled independently (except in chain methods), enabling parallel fitting and prediction.
- **Modeling Dependencies:** Chain methods capture dependencies between target variables, potentially improving predictive performance.

Implementation Details
----------------------

- The meta-estimators clone the base estimator for each target variable.
- They support fitting with or without sample weights.
- Partial fitting is supported if the base estimator implements `partial_fit`.
- Chain methods use the predictions of previous estimators in the chain as additional features for subsequent estimators.
- Utilities are provided to check classification targets and validate estimators.
