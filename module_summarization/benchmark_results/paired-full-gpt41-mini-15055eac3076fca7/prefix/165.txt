PyTables File Format
====================

Overview
--------

PyTables is a package for managing hierarchical datasets and designed to efficiently and easily cope with extremely large amounts of data. It is built on top of the HDF5 library and NumPy package, providing a high-level interface to HDF5 files.

The PyTables file format is based on HDF5, which organizes data in a hierarchical structure similar to a file system, with groups and datasets. PyTables extends this structure by adding indexing capabilities to speed up data retrieval, especially for large tables.

Indexing in PyTables
--------------------

Indexes in PyTables are used to accelerate queries on table columns. Each index corresponds to a column in a table and maintains auxiliary data structures that allow fast searching and sorting operations.

### Index Class

The `Index` class represents the index of a column in a table. It is a specialized group node that stores indexing information and metadata related to the indexed column.

Key features of the `Index` class:

- **Association with a single column:** Each `Index` instance is linked to exactly one column in a table.
- **Index kinds:** Different kinds of indexes are supported, which vary in the granularity and size of the indexing information:
  - `ultralight` (8-bit)
  - `light` (16-bit)
  - `medium` (32-bit)
  - `full` (64-bit)
- **Optimization levels:** Indexes can be created with different optimization levels to balance between speed and storage requirements.
- **Filters:** Compression and other I/O filters can be applied to indexes to reduce disk space usage and improve performance.
- **Automatic updating:** Indexes can be automatically updated when the underlying table data changes, ensuring consistency.

### Index Storage and Structure

Indexes are stored as groups within the HDF5 file hierarchy, with datasets representing the index arrays. The index data is organized in chunks and may be compressed using filters such as zlib.

The index datasets store information about the positions of rows in the table, enabling efficient searching and retrieval. Depending on the index kind, the size and detail of this information vary.

### Default Settings

- **Default index kind:** The default kind of index created is `full`, which tracks row positions using 64-bit integers.
- **Default filters:** By default, indexes use compression filters with level 1 compression using zlib, shuffle enabled, and no Fletcher32 checksum.
- **Automatic indexing:** By default, indexes are automatically updated after table append operations or other modifications that invalidate the index.

### Supported Data Types for Optimized Search

PyTables implements optimized search algorithms for the following data types:

- Signed integers: int8, int16, int32, int64
- Unsigned integers: uint8, uint16, uint32, uint64
- Floating point numbers: float32, float64

These optimizations leverage C and Cython implementations for improved performance.

Index Pathnames
---------------

Indexes are stored in the file hierarchy with pathnames that reflect their association with table columns. The pathname of an index typically includes a prefix `_i_` followed by the column name.

For example, given an index pathname:

```
/group/subgroup/_i_columnname/...
```

- The table pathname is `/group/subgroup/columnname`
- The column pathname is the remainder after the index prefix

This structure allows PyTables to efficiently locate the table and column associated with a given index.

Performance and Debugging
------------------------

PyTables includes options for debugging and profiling index operations. These can be enabled to print size information or gather performance statistics during index creation and updates.

Sorting Method
--------------

The default sorting algorithm used in indexes is `mergesort`, chosen for its stability and performance characteristics.

Deprecated API
--------------

Some older API names are deprecated but still available for backward compatibility:

- `defaultAutoIndex` (use `default_auto_index` instead)
- `defaultIndexFilters` (use `default_index_filters` instead)

Summary
-------

The PyTables file format extends HDF5 by adding indexing capabilities that enable fast and efficient querying of large tabular datasets. The `Index` class encapsulates the indexing logic, supporting multiple index kinds, compression filters, and automatic maintenance. This design allows PyTables to handle large-scale data analysis tasks with high performance and flexibility.
