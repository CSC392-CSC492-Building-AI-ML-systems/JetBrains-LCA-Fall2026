Migrating to nextcord
=====================

nextcord is a maintained fork of discord.py designed to provide continued support and new features for Discord bot development. If you are migrating your project from discord.py or another library to nextcord, this guide will help you understand the key changes and how to adapt your code.

Key Changes and Migration Notes
-------------------------------

1. **Package and Import Names**

   The primary change when migrating to nextcord is updating your imports. Instead of importing from `discord`, you will import from `nextcord`.

   ```python
   # Before (discord.py)
   import discord
   from discord.ext import commands

   # After (nextcord)
   import nextcord
   from nextcord.ext import commands
   ```

2. **Widget Support**

   nextcord includes support for Discord widgets, which allow you to retrieve partial information about guilds, channels, and members.

   - `WidgetChannel` represents a partial widget channel with attributes such as `id`, `name`, and `position`.
   - `WidgetMember` represents a partial member of the widget's guild, including attributes like `id`, `name`, `discriminator`, `status`, `nick`, `avatar`, and voice state flags (`deafened`, `muted`, `suppress`).
   - `Widget` provides access to the widget data itself.

   These classes provide useful properties such as:

   - `WidgetChannel.mention`: Returns a string that mentions the channel.
   - `WidgetChannel.created_at`: Returns the channel's creation time as a UTC datetime.
   - `WidgetMember.activity`: The member's current activity, which can be a base activity or Spotify activity.
   - `WidgetMember.connected_channel`: The voice channel the member is connected to, if any.

3. **Enums and Status**

   nextcord uses enums such as `Status` to represent user presence states. When migrating, ensure you update any status checks to use nextcord's enums.

   ```python
   from nextcord.enums import Status

   if member.status == Status.online:
       # do something
   ```

4. **Activity Handling**

   nextcord supports various activity types, including Spotify integration. Activities can be accessed and created using nextcord's activity classes and helper functions.

5. **Type Hinting and Forward Compatibility**

   nextcord uses modern Python typing features, including `from __future__ import annotations` for postponed evaluation of annotations. This improves type hinting and compatibility with static type checkers.

6. **Maintained and Updated Codebase**

   nextcord continues to maintain and update the codebase originally developed by Rapptz for discord.py, including bug fixes, new Discord API features, and improvements.

Summary
-------

Migrating to nextcord primarily involves changing your imports and updating references to nextcord-specific classes and enums. The library maintains a similar API to discord.py, making migration straightforward. Additionally, nextcord offers extended features such as widget support and enhanced activity handling.

For detailed usage and API references, consult the nextcord documentation and examples.
