Generate Documentation for G-Functions
======================================

This module dynamically generates documentation for a collection of mathematical functions, particularly focusing on elementary functions and those involving special functions represented by Meijer G-functions.

Overview
--------

Upon import, the module constructs a comprehensive docstring intended for display in Sphinx-generated documentation. It organizes functions into categories based on the types of special functions they involve and presents their defining formulas along with any associated conditions.

Key Components
--------------

- **Function Categorization**  
  Functions are grouped into categories determined by the types of special functions they involve. Elementary functions (those without special function involvement) are listed separately.

- **Lookup Table Creation**  
  The module utilizes a lookup table created by the `_create_lookup_table` function from the `meijerint` submodule. This table maps tuples of function types to lists of formulas and related data.

- **Formula Representation**  
  Each formula is represented as an equation using symbolic expressions (`Eq`) involving sums of terms (`Add`) and symbols (`Symbol`). The LaTeX representation of these equations is generated for inclusion in the documentation.

- **Conditional Display**  
  Conditions under which each formula holds are displayed alongside the formulas, formatted appropriately in LaTeX.

Documentation Structure
-----------------------

The generated documentation is structured as follows:

1. **Elementary Functions**  
   A section listing formulas for elementary functions without involvement of special functions.

2. **Functions Involving Special Functions**  
   Subsequent sections categorize functions by the special functions they involve. Each category is introduced by listing the involved special functions in LaTeX format.

3. **Formulas and Conditions**  
   Within each category, formulas are presented as LaTeX-rendered mathematical equations. If a formula is subject to specific conditions, these are displayed alongside the equation.

Example Output Snippet
----------------------

Elementary functions:

.. math::
  f(x) = g(x)

Functions involving `\mathrm{G}_{p,q}^{m,n}`:

.. math::
  F(x) = \sum_i a_i G_i(x), \quad \text{if } x > 0

Usage
-----

This module is intended to be imported as part of the documentation build process. Its primary role is to provide a dynamically generated docstring that can be rendered by Sphinx to produce up-to-date and well-organized documentation of the mathematical functions and their properties.

Dependencies
------------

- `collections` and `typing` for data structures and type annotations.
- Internal modules:
  - `core` for symbolic expressions and equations.
  - `printing` for LaTeX rendering.
  - `utilities` for sorting keys.
  - `meijerint` for generating the lookup table of functions.

Summary
-------

By automating the generation of documentation for a wide range of functions involving Meijer G-functions and elementary functions, this module ensures that the documentation remains consistent, comprehensive, and easy to maintain.
