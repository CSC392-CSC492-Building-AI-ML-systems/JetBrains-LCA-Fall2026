Pairwise Metrics, Affinities and Kernels
========================================

This module provides utilities and functions to compute pairwise metrics, affinities, and kernels between samples in datasets. These computations are fundamental in many machine learning algorithms, including clustering, classification, and dimensionality reduction.

Overview
--------

Pairwise metrics measure the distance or similarity between pairs of samples. Affinities and kernels are specific types of similarity measures that can be used to capture relationships between data points in various feature spaces.

Key Concepts
------------

- **Pairwise Metrics**: Functions that compute a distance or dissimilarity measure between pairs of samples. Examples include Euclidean distance, Manhattan distance, and cosine distance.

- **Affinities**: Measures of similarity between samples, often derived from distances. Affinities are typically non-negative and higher values indicate greater similarity.

- **Kernels**: Functions that compute inner products in transformed feature spaces, enabling algorithms to operate in high-dimensional or infinite-dimensional spaces implicitly. Common kernels include linear, polynomial, and Gaussian (RBF) kernels.

Utility Functions
-----------------

### `_return_float_dtype(X, Y)`

Determines the appropriate floating-point data type for input arrays `X` and `Y`. If both inputs are of type `float32`, the function returns `float32`; otherwise, it returns the default floating-point type (`float64`). This ensures consistency in computations involving pairwise metrics.

### `check_pairwise_arrays(X, Y, *, precomputed=False, dtype=None, accept_sparse='csr', force_all_finite=True, copy=False)`

Validates and prepares input arrays `X` and `Y` for pairwise computations. This function performs the following checks and transformations:

- Converts inputs to arrays or sparse matrices as needed.
- Ensures inputs are at least two-dimensional.
- Validates that the number of features (columns) in `X` and `Y` match.
- Handles the case where `Y` is `None` by setting it to reference `X`.
- Supports precomputed distance matrices when `precomputed=True`.
- Allows specification of data types and sparse matrix formats.
- Enforces or relaxes checks for finite values, including support for missing values (`np.nan`, `pd.NA`).

Parameters
----------

- `X` : array-like or sparse matrix of shape (n_samples_X, n_features)  
  Input data.

- `Y` : array-like or sparse matrix of shape (n_samples_Y, n_features) or None  
  Input data or None. If None, `Y` is set to `X`.

- `precomputed` : bool, default=False  
  If True, `X` is treated as a precomputed distance matrix.

- `dtype` : type or list of types, default=None  
  Desired data type for the arrays. If None, an appropriate float type is selected.

- `accept_sparse` : str, bool, or list/tuple of str, default='csr'  
  Allowed sparse matrix formats.

- `force_all_finite` : bool or 'allow-nan', default=True  
  Whether to raise an error on infinite or missing values.

- `copy` : bool, default=False  
  Whether to force a copy of the input arrays.

Returns
-------

- `safe_X` : array-like or sparse matrix  
  Validated and possibly converted version of `X`.

- `safe_Y` : array-like or sparse matrix  
  Validated and possibly converted version of `Y`. If `Y` was None, this is a reference to `X`.

Usage Notes
-----------

All pairwise metric functions should use `check_pairwise_arrays` to validate inputs before computation. This ensures consistency and robustness across different metric implementations.
