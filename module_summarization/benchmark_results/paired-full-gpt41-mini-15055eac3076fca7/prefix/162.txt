Parallel Random Number Generation
=================================

Overview
--------

The `numpy.random` module provides a suite of parallel-capable random number generators (RNGs) designed for high-performance and reproducible stochastic simulations. These generators leverage modern algorithms and C implementations to enable efficient generation of random variates in parallel computing environments.

Core Components
---------------

### Bit Generators

At the heart of the parallel random number generation infrastructure are several bit generators implemented in C and exposed to Python via Cython extensions. These bit generators serve as the fundamental sources of randomness and include:

- **MT19937**: The widely used Mersenne Twister algorithm, implemented with support for jump-ahead functionality to enable parallel streams.
- **Philox**: A counter-based RNG suitable for parallel computations, providing statistically robust random numbers.
- **PCG64**: Permuted Congruential Generator with 64-bit state, designed for fast and statistically sound random number generation.
- **SFC64**: Small Fast Counting RNG with 64-bit state, optimized for speed and quality.

Each bit generator is implemented as a Cython extension module combining Python interface code with performant C source files.

### Parallel Stream Support

To facilitate parallel random number generation, the bit generators support features such as:

- **Jumping Ahead**: Algorithms like MT19937 include jump functions (`mt19937-jump.c`) that allow the RNG state to advance by large steps, enabling the creation of independent random streams for parallel tasks.
- **Counter-Based Generators**: Philox uses a counter-based approach that naturally supports parallelism by associating counters with parallel threads or processes.

### Distributions and Sampling

The `npyrandom` C library provides efficient implementations of various probability distributions and sampling algorithms, including hypergeometric and multivariate hypergeometric distributions. These are used internally by the random number generators to produce samples from complex distributions in parallel contexts.

Build and Installation
----------------------

The parallel random number generation components are built as part of the `npyrandom` static library, which compiles multiple C source files related to distributions and random number generation algorithms.

Cython extensions wrapping the bit generators and distribution functions are compiled with appropriate compiler flags to ensure compatibility and performance, including large file support and handling of deprecated NumPy C API usage.

The build system installs the compiled libraries, Python source files, stub files, tests, and example scripts into the `numpy/random` subdirectory, ensuring that all components required for parallel random number generation are available.

Usage
-----

Users can access the parallel-capable random number generators through the `numpy.random` namespace. Each bit generator can be instantiated and used to generate random numbers independently, allowing for parallel computations with reproducible and statistically sound random streams.

Examples and tests included in the installation demonstrate how to extend and utilize these generators in parallel workflows, including CFFI and Cython examples.

Summary
-------

The parallel random number generation infrastructure in `numpy.random` combines state-of-the-art algorithms, efficient C implementations, and flexible Python interfaces to provide robust and scalable random number generation suitable for parallel and high-performance computing applications.
