Stochastic Gradient Descent (SGD)
=================================

Overview
--------

Stochastic Gradient Descent (SGD) is an iterative optimization algorithm used for minimizing an objective function that is typically a sum of differentiable functions. It is widely used in machine learning for training models such as linear classifiers, logistic regression, and neural networks.

Unlike traditional gradient descent which computes the gradient using the entire dataset, SGD approximates the gradient by using a single or a small batch of samples at each iteration. This makes SGD computationally efficient and suitable for large-scale and online learning scenarios.

Loss Functions
--------------

The implementation includes support for various loss functions, including the Multinomial Logistic Loss, which is commonly used for multi-class classification problems.

### Multinomial Logistic Loss

The multinomial logistic loss for a single sample is defined as:

.. math::

    \text{loss} = - w_s \sum_c \delta_{y,c} \left( \text{prediction}[c] - \log \sum_{c'} \exp(\text{prediction}[c']) \right)
               = w_s \left( \log \sum_{c'} \exp(\text{prediction}[c']) - \text{prediction}[y] \right)

where:

- :math:`\text{prediction}` is the vector of predicted scores for each class, computed as the dot product of the sample features and the model weights plus an intercept.
- :math:`y` is the true class label index.
- :math:`\delta_{y,c}` is the Kronecker delta, equal to 1 if :math:`y = c` and 0 otherwise.
- :math:`w_s` is the sample weight.

This loss measures how well the predicted probabilities match the true class labels.

Gradient Computation
--------------------

The gradient of the multinomial logistic loss with respect to the prediction for class :math:`c` is:

.. math::

    \text{grad}_c = - w_s \left( p_c - \delta_{y,c} \right)

where:

- :math:`p_c = \frac{\exp(\text{prediction}[c])}{\sum_{c'} \exp(\text{prediction}[c'])}` is the predicted probability for class :math:`c`.
- Other terms are as defined above.

This gradient is used to update the model parameters during training. Note that the gradient with respect to the model weights is obtained by multiplying this value by the feature vector of the sample.

Numerical Stability
-------------------

To ensure numerical stability when computing the log-sum-exp term, the implementation uses a normalization trick by subtracting the maximum value in the prediction vector before exponentiation. This reduces the risk of overflow or underflow during computation.

Usage Notes
-----------

- The implementation supports both 32-bit and 64-bit floating point precision.
- Sample weights can be used to give different importance to samples during training.
- The code is optimized for performance using Cython and low-level C functions.
