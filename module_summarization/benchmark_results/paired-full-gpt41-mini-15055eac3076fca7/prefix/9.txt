Using Timers
============

Timers provide a convenient way to measure the duration of code execution within your ftrack API sessions or plugins. They can be used to profile performance, debug slow operations, or simply log elapsed time for various tasks.

Basic Usage
-----------

To use a timer, you typically start it before the code block you want to measure and stop it afterward. The timer will then provide the elapsed time between these two points.

Example:

.. code-block:: python

    import time
    from ftrack_api import Timer

    timer = Timer()
    timer.start()

    # Code block to measure
    time.sleep(2)

    timer.stop()
    print('Elapsed time:', timer.elapsed)

Context Manager Usage
---------------------

Timers can also be used as context managers to automatically measure the duration of a code block without explicitly starting and stopping the timer.

Example:

.. code-block:: python

    from ftrack_api import Timer

    with Timer() as timer:
        # Code block to measure
        perform_task()

    print('Elapsed time:', timer.elapsed)

Logging with Timers
------------------

Timers can be integrated with the ftrack logging system to log elapsed time messages conveniently.

Example:

.. code-block:: python

    import logging
    from ftrack_api import Timer

    logger = logging.getLogger('ftrack.timer')

    with Timer() as timer:
        perform_task()

    logger.info('Task completed in {:.2f} seconds'.format(timer.elapsed))

Advanced Usage
--------------

Timers can be nested or used in combination with other profiling tools to gain detailed insights into your application's performance.

Consider using timers in plugins or event handlers to monitor execution time and optimize accordingly.

Notes
-----

- Timers measure wall-clock time and are suitable for measuring elapsed real time.
- For CPU time measurement, consider using other profiling tools.
- Ensure timers are stopped properly to get accurate measurements.
- Using timers as context managers is recommended for cleaner and safer code.

By incorporating timers into your ftrack API workflows, you can effectively monitor and optimize the performance of your integrations and customizations.
