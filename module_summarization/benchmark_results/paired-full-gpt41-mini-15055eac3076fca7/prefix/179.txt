Cross decomposition
===================

The `sklearn.cross_decomposition` module provides tools for cross decomposition methods, which are techniques used to model relationships between two datasets by extracting latent variables that capture the covariance structure between them. These methods are particularly useful when dealing with multivariate data where the goal is to find components that explain the shared information between two sets of variables.

Overview
--------

Cross decomposition methods aim to find linear combinations of variables in two datasets, typically denoted as `X` and `Y`, such that these combinations have maximal covariance. This approach is widely used in chemometrics, genomics, and other fields where the relationship between two sets of variables is of interest.

Key classes in this module include:

- **PLSRegression**: Implements Partial Least Squares regression, which models the relationship between `X` and `Y` by projecting both onto a new space formed by latent variables. It is particularly effective when the predictors are highly collinear or when the number of predictors exceeds the number of observations.

- **PLSCanonical**: Implements Canonical Partial Least Squares, which finds latent variables that maximize the covariance between `X` and `Y` without focusing on prediction but rather on the correlation structure.

- **PLSSVD**: Implements Partial Least Squares using Singular Value Decomposition (SVD), providing a decomposition of the cross-covariance matrix between `X` and `Y`.

Functionality
-------------

The module provides several utility functions and classes to facilitate the computation of cross decomposition:

- **_get_first_singular_vectors_power_method**: Computes the first left and right singular vectors of the cross-covariance matrix `X'Y` using the power method. This iterative approach is an alternative to full SVD and can be more efficient in certain scenarios.

- **_get_first_singular_vectors_svd**: Computes the first singular vectors of `X'Y` using a full SVD decomposition.

- **_center_scale_xy**: Centers and optionally scales the input matrices `X` and `Y`. Centering is essential for cross decomposition methods to ensure that the latent variables capture covariance rather than mean differences.

Usage Notes
-----------

- The methods in this module assume that the input data matrices `X` and `Y` are numeric and appropriately preprocessed (e.g., centered and scaled).

- The power method used in `_get_first_singular_vectors_power_method` includes convergence checks and warnings if the maximum number of iterations is reached without convergence.

- The module handles numerical stability and edge cases, such as constant residuals in `Y`, by raising appropriate exceptions or warnings.

- Depending on the version of SciPy installed, the module adapts the computation of pseudo-inverses to maintain consistent behavior.
