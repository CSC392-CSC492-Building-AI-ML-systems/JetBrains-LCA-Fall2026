FileNode Module
===============

Overview
--------

The `filenode` module provides a file-like interface to nodes within PyTables databases. It allows users to create and manipulate file nodes inside PyTables HDF5 files as if they were ordinary Python files. This module supports binary I/O operations on these file nodes, enabling reading and appending data.

Key Features
------------

- Creation of new file nodes using the `new_node()` function.
- Opening existing file nodes with `open_node()` for read-only or read-write (append) access.
- Read access is always available; write access is limited to appending data.
- Full compliance with Python's `io` module interfaces since version 3.0.
- Currently supports only binary I/O.

Usage
-----

To create a new file node, use the `new_node()` function. This creates a brand new file node that can be read from and written to like a standard Python file.

To open an existing file node, use the `open_node()` function. This allows read-only or append-mode access to the node.

Note that write access is restricted to appending data; rewriting or deleting existing data is not supported.

For detailed instructions and examples, see the :ref:`filenode_usersguide`.

Version Information
-------------------

- The module was completely rewritten in version 3.0 to align with the interfaces defined in Python's `io` module.
- Supported node type versions are 1 and 2.

Constants
---------

- `NodeType`  
  A string constant `'file'` representing the node system attribute `NODE_TYPE`.

- `NodeTypeVersions`  
  A list `[1, 2]` indicating the supported values for the `NODE_TYPE_VERSION` node system attribute.

Classes
-------

### RawPyTablesIO

`RawPyTablesIO` is the base class for raw binary I/O operations on HDF5 files using PyTables. It inherits from `io.RawIOBase` and implements the necessary methods to provide a file-like interface.

#### Initialization

```python
RawPyTablesIO(node, mode=None)
```

- `node`: The PyTables node to interface with.
- `mode`: Optional file mode. If not specified, the mode of the underlying PyTables file is used.

#### Attributes

- `mode` (read-only): Returns the file mode as a string.

#### Methods

- `tell()`  
  Returns the current stream position as an integer.

- `seek(pos, whence=0)`  
  Changes the stream position.  
  - `pos`: The offset to seek to.  
  - `whence`: Optional; defaults to 0.  
    - `0`: Seek from the start of the stream.  
    - `1`: Seek relative to the current position.  
    - `2`: Seek relative to the end of the stream.  
  Returns the new absolute position.

- `seekable()`  
  Returns `True` indicating that random access is supported.

- `fileno()`  
  Returns the underlying file descriptor of the PyTables file. Raises `IOError` if no file descriptor exists.

- `close()`  
  Flushes and closes the IO object. Has no effect if already closed. Warns if the host PyTables file is already closed.

- `flush()`  
  Flushes write buffers if applicable. Not implemented for read-only or non-blocking streams.

- `truncate(pos=None)`  
  Truncates the file to the specified size in bytes. If `pos` is `None`, truncates to the current position.  
  Note: This method currently only supports growing the file node, as rewriting or deleting data is not supported.

Additional Information
----------------------

- The module uses internal mechanisms to verify node attributes and modes to ensure consistency and correctness.
- The file interface supports only binary mode operations.
- The module is designed to integrate seamlessly with PyTables and HDF5 file structures.
