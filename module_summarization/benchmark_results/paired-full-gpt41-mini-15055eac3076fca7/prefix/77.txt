Transforms Module
=================

This module provides utilities and functions for image transformations, including interpolation modes, image dimension and size retrieval, and conversion between image formats and tensors. It supports images represented as PIL Images, NumPy arrays, and PyTorch tensors.

Interpolation Modes
-------------------

The module defines an `InterpolationMode` enumeration that specifies the available interpolation methods for image transformations:

- `NEAREST`: Nearest neighbor interpolation.
- `NEAREST_EXACT`: Exact nearest neighbor interpolation.
- `BILINEAR`: Bilinear interpolation.
- `BICUBIC`: Bicubic interpolation.
- `BOX`: Box filter interpolation (for PIL compatibility).
- `HAMMING`: Hamming filter interpolation.
- `LANCZOS`: Lanczos filter interpolation.

These modes can be used to specify the interpolation method when resizing or transforming images.

Image Dimension and Size Utilities
----------------------------------

The module provides functions to retrieve image dimensions and size, supporting both PIL Images and PyTorch tensors:

- `get_dimensions(img: Tensor) -> List[int]`  
  Returns the dimensions of an image as `[channels, height, width]`.  
  **Args:**  
  &nbsp;&nbsp;&nbsp;&nbsp;`img` (PIL Image or Tensor): The image to be checked.  
  **Returns:**  
  &nbsp;&nbsp;&nbsp;&nbsp;List of integers representing the image dimensions.

- `get_image_size(img: Tensor) -> List[int]`  
  Returns the size of an image as `[width, height]`.  
  **Args:**  
  &nbsp;&nbsp;&nbsp;&nbsp;`img` (PIL Image or Tensor): The image to be checked.  
  **Returns:**  
  &nbsp;&nbsp;&nbsp;&nbsp;List of integers representing the image size.

- `get_image_num_channels(img: Tensor) -> int`  
  Returns the number of channels in the image.  
  **Args:**  
  &nbsp;&nbsp;&nbsp;&nbsp;`img` (PIL Image or Tensor): The image to be checked.  
  **Returns:**  
  &nbsp;&nbsp;&nbsp;&nbsp;Integer number of channels.

Conversion to Tensor
--------------------

- `to_tensor(pic) -> Tensor`  
  Converts a PIL Image or NumPy ndarray to a PyTorch tensor. This function does not support TorchScript.  
  **Args:**  
  &nbsp;&nbsp;&nbsp;&nbsp;`pic` (PIL Image or numpy.ndarray): Image to be converted to tensor.  
  **Returns:**  
  &nbsp;&nbsp;&nbsp;&nbsp;Tensor representation of the image with shape `[channels, height, width]` and normalized pixel values if applicable.

  The function supports:
  - PIL Images
  - NumPy arrays with 2 or 3 dimensions (grayscale or color images)
  - AccImage objects (if available)

  The output tensor will have pixel values normalized to the range [0, 1] if the input is a byte tensor.

Examples
--------

Converting a PIL Image to a tensor:

```python
from PIL import Image
from torchvision.transforms import to_tensor

img = Image.open("path/to/image.jpg")
tensor_img = to_tensor(img)
print(tensor_img.shape)  # e.g., torch.Size([3, height, width])
```

Getting image dimensions and size:

```python
from torchvision.transforms import get_dimensions, get_image_size, get_image_num_channels
from PIL import Image

img = Image.open("path/to/image.jpg")

dims = get_dimensions(img)
print(f"Dimensions (C, H, W): {dims}")

size = get_image_size(img)
print(f"Size (W, H): {size}")

channels = get_image_num_channels(img)
print(f"Number of channels: {channels}")
```

Using interpolation modes:

```python
from torchvision.transforms import InterpolationMode

mode = InterpolationMode.BILINEAR
print(f"Selected interpolation mode: {mode.value}")
```

Notes
-----

- The module internally distinguishes between PIL Images and tensors to apply appropriate processing.
- Some functions log API usage for telemetry purposes when not running under TorchScript.
- The module attempts to import `accimage` for optimized image loading; if unavailable, it falls back to PIL.
- The `_interpolation_modes_from_int` function maps integer codes to interpolation modes, useful for internal compatibility.

This module is a foundational component for image preprocessing and augmentation pipelines in computer vision tasks using PyTorch.
