Optimization Utilities for Model Fitting
========================================

This module provides general-purpose optimization functions designed to be used for fitting a wide range of models. The core idea is to separate these utilities from any specific model class, such as `LikelihoodModel`, to enable their reuse across different modeling contexts.

Overview
--------

The module includes an `Optimizer` class that implements a flexible `_fit` method capable of optimizing an objective function using various numerical optimization algorithms. This method supports multiple optimization techniques and provides extensive options for controlling the fitting process.

Key Features
------------

- **Flexible Optimization Methods**  
  Supports a variety of optimization algorithms including:
  - Newton-Raphson (`newton`)
  - Nelder-Mead simplex (`nm`)
  - Broyden-Fletcher-Goldfarb-Shanno (`bfgs`)
  - Powell’s method (`powell`)
  - Conjugate Gradient (`cg`)
  - Newton-Conjugate Gradient (`ncg`)
  - Basin-hopping global optimization (`basinhopping`)
  - Generic minimization wrapper (`minimize`) using `scipy.optimize.minimize`

- **Customizable Parameters**  
  Allows specification of:
  - Initial parameter guesses (`start_params`)
  - Maximum number of iterations (`maxiter`)
  - Whether to display convergence messages (`disp`)
  - Callback functions to monitor progress (`callback`)
  - Additional arguments passed to the objective function (`fargs`)
  - Option to return all intermediate solutions (`retall`)
  - Full output including solver-specific return values (`full_output`)

- **Error Handling**  
  Includes utility functions such as `_check_method` to validate the chosen optimization method and provide informative error messages.

Usage
-----

The `_fit` method is designed to be called internally by model fitting routines. It requires:

- An objective function to minimize (or maximize, depending on context)
- Optionally, a gradient function and Hessian matrix for methods that use derivative information
- Starting parameter values
- Additional arguments and keyword arguments for fine-tuning the optimization process

Returns
-------

- `xopt` : ndarray  
  The optimized parameter values that minimize (or maximize) the objective function.

- `retvals` : dict or None  
  Detailed information returned by the optimizer if `full_output` is set to True; otherwise, None.

- `optim_settings` : dict  
  A dictionary containing the parameters and settings used during optimization.

Notes
-----

- The basin-hopping solver ignores some parameters such as `maxiter`, `retall`, and `full_output`.
- Each optimization method supports additional optional arguments specific to the underlying algorithm. These are accessible via the `mle_settings` attribute in the results object when used in a broader modeling framework.
- The module relies on `numpy` for numerical operations and `scipy.optimize` for the optimization algorithms.

This modular and extensible design facilitates robust and reusable optimization routines suitable for a variety of statistical and machine learning models.
