w_ipa — WESTPA Interactive Python Analysis
===========================================

Overview
--------

`w_ipa` (WESTPA Interactive Python Analysis) is a powerful, stateful command-line tool designed for interactive analysis of WESTPA simulation data. It allows users to explore trajectories, weights, progress coordinates, and other relevant information from WESTPA simulations in an interactive Python environment.

This tool is intended to provide seamless access to the current analysis scheme and iteration, enabling detailed inspection and manipulation of simulation data.

Key Features
------------

- **Stateful Analysis**  
  The tool maintains state with respect to the current analysis scheme and iteration. By default, it uses the first analysis scheme defined in `west.cfg` and starts at iteration 1.

- **Interactive Access to Data**  
  All properties and methods are accessed via the `w` or `west` object, providing a consistent interface for querying and modifying analysis parameters.

- **Trace Functionality**  
  The `w.trace(seg_id)` function allows users to retrieve the full history of a specific segment ID (`seg_id`) within the current iteration, returning a dictionary with all pertinent information about that segment’s trajectory.

Usage
-----

### Accessing and Setting the Current Iteration

To view the current iteration:

```python
w.iteration
# or
west.iteration
```

To set the iteration to a new value:

```python
w.iteration = 100
```

### Managing Analysis Schemes

To list available analysis schemes:

```python
w.list_schemes
```

To change the current analysis scheme:

```python
w.scheme = 'scheme_name'  # Replace 'scheme_name' with the desired scheme
```

### Viewing States and Bins

To see the states and bins defined in the current analysis scheme:

```python
w.states
w.bin_labels
```

### Accessing Current Iteration Data

All information about the current iteration is available through the `current` object:

```python
w.current
```

This object contains data such as:

- walkers
- summary
- states
- seg_id
- weights
- parents
- kinavg
- pcoord (progress coordinates)
- bins
- populations
- auxdata (if available)

### Running a Trace on a Segment

To run a trace over a specific segment ID in the current iteration:

```python
trace_data = w.trace(seg_id)
```

This returns a dictionary containing the full history and relevant data for the specified segment. It is recommended to store this output as the trace operation can be computationally expensive.

Command-Line Options
--------------------

`w_ipa` supports several runtime options to customize its behavior:

- `--analysis-only`, `-ao`  
  Run the analysis and return to the terminal without launching the interactive interface.

- `--reanalyze`, `-ra`  
  Delete existing analysis files and reanalyze from scratch.

- `--ignore-hash`, `-ih`  
  Ignore hash checks and do not regenerate files, useful for forcing reuse of existing data.

- `--debug`, `-d`  
  Enable debug output primarily intended for development and troubleshooting.

- `--terminal`, `-t`  
  Plot output directly in the terminal instead of using graphical interfaces.

Additional options related to progress indicators and data reading are also available and can be viewed by running:

```bash
w_ipa --help
```

Getting Help
------------

Within the interactive environment, you can use Python’s built-in `help()` function to get more information about any function or property. For example:

```python
help(w.trace)
help(w.current)
```

This will provide detailed documentation and usage examples.

Notes
-----

- The tool uses the first enabled analysis scheme by default but allows switching between schemes interactively.
- The interface defaults to using matplotlib for plotting, but terminal-based plotting is available via the `--terminal` option.
- Warnings related to deprecated or runtime issues are suppressed to provide a cleaner user experience.

Happy analyzing with `w_ipa`!
