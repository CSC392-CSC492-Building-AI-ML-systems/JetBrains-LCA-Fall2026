Cross-validation: Evaluating Estimator Performance
====================================================

Cross-validation is a robust statistical method used to estimate the skill of machine learning models. It is primarily employed to assess how the results of a predictive model will generalize to an independent dataset. This technique is essential for evaluating estimator performance, helping to prevent issues such as overfitting and providing insight into the model's ability to perform on unseen data.

Overview
--------

Cross-validation involves partitioning the original dataset into complementary subsets, performing the analysis on one subset (called the training set), and validating the analysis on the other subset (called the validation or test set). The most common form is *k*-fold cross-validation, where the data is divided into *k* subsets, and the model is trained and evaluated *k* times, each time using a different subset as the test set and the remaining subsets as the training set.

Key Components
--------------

- **Training Scores and Test Scores**: During cross-validation, the estimator is trained on the training folds and evaluated on the test fold. Scores from both training and test sets are collected to analyze the model's performance and potential overfitting.

- **Score Types**: Scores can be categorized as:
  - *Train*: Performance on the training data.
  - *Test*: Performance on the validation/test data.
  - *Both*: Evaluation on both training and test data for comprehensive analysis.

- **Score Metrics**: Various scoring metrics can be used depending on the problem type (e.g., accuracy, precision, recall, R²). It is important to validate the score name to ensure compatibility with the estimator and task.

Visualization of Cross-validation Results
----------------------------------------

Visualizing cross-validation results aids in understanding the estimator's behavior across different training set sizes or parameter values. The `_BaseCurveDisplay` class provides a foundation for plotting learning curves and validation curves, which are common tools for evaluating estimator performance.

### Plotting Curves

The `_plot_curve` method supports plotting training and test scores against a range of values (e.g., training set sizes or hyperparameter values). Key features include:

- **Axes Handling**: If no matplotlib axes object is provided, a new figure and axes are created.

- **Score Negation**: Optionally negate scores when lower values indicate better performance (e.g., loss functions).

- **Standard Deviation Display Styles**:
  - *fill_between* (default): Displays the variability of scores as a shaded region around the mean.
  - *errorbar*: Displays error bars representing the standard deviation.
  - *None*: No variability display.

- **Score Type Selection**: Choose to plot training scores, test scores, or both.

- **Customization**: Line properties, fill properties, and error bar properties can be customized via keyword arguments.

### Interpretation

- **Mean Scores**: The mean score across cross-validation folds is plotted to represent average performance.

- **Variability**: The standard deviation indicates the variability of the estimator's performance across different folds, highlighting stability or sensitivity.

- **Legends and Labels**: Plots include legends distinguishing training and test scores for clarity.

Best Practices
--------------

- Use cross-validation to obtain a reliable estimate of model performance, especially when the dataset is limited.

- Analyze both training and test scores to detect overfitting or underfitting.

- Visualize learning curves to understand how increasing training data affects performance.

- Choose appropriate scoring metrics aligned with the problem domain.

- Customize plots to enhance interpretability and presentation quality.

Conclusion
----------

Cross-validation is a fundamental technique for evaluating the performance of machine learning estimators. By systematically training and testing across multiple data splits, it provides a comprehensive assessment of model generalization. Visualization tools built upon cross-validation results, such as learning and validation curves, offer valuable insights into model behavior, guiding model selection and tuning decisions.
