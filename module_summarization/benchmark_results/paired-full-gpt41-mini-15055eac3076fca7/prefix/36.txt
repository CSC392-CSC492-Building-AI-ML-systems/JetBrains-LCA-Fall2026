w_succ — List Successful (Recycled) Segments
=============================================

Synopsis
--------

.. code-block:: console

    w_succ [OPTIONS]

Description
-----------

The `w_succ` command lists segments from WESTPA simulations that have successfully reached a target state, specifically those segments that have been recycled. Recycling in WESTPA refers to segments that have reached a defined target state and are restarted from a previous state to enhance sampling efficiency.

The output includes information about each successful segment, such as the iteration number, segment ID, statistical weight, and the final progress coordinate values.

Output Format
-------------

The output is a plain text table with the following columns:

- **Column 0:** Iteration number  
- **Column 1:** Segment ID  
- **Column 2:** Weight of the segment  
- **Columns >2:** Final progress coordinate values for the segment

The output begins with header lines describing the columns, unless header suppression is enabled.

Options
-------

The command supports standard WESTPA configuration options as well as:

- `-o, --output OUTPUT_FILE`  
  Write the output to the specified file instead of standard output.

Examples
--------

List successful segments and print to standard output:

.. code-block:: console

    w_succ

Save the output to a file named `successful_segments.txt`:

.. code-block:: console

    w_succ -o successful_segments.txt

Details
-------

`w_succ` processes all completed iterations up to the current iteration in the WESTPA simulation data. For each iteration, it identifies segments marked as recycled (i.e., those that have reached the target state and are restarted). It then extracts the final progress coordinate values for these segments and outputs the relevant information.

The progress coordinate values are formatted according to their data types for readability.

Logging
-------

The command uses the logger named `w_succ` for internal logging and debugging purposes.
