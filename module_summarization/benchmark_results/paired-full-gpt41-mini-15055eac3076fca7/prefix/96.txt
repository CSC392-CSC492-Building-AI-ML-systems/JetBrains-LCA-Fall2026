Getting Started with Mitogen Core
==================================

Introduction
------------

Mitogen is a Python library designed to simplify the creation of distributed and parallel applications by providing a transparent and efficient way to manage child processes and inter-process communication. This module contains core functionality shared between master and parent processes, enabling recursive connections and child context management.

This tutorial will guide you through the basic concepts and usage of the Mitogen core module to help you get started quickly.

Key Concepts
------------

- **Master and Parent Processes**: Mitogen distinguishes between master processes, which control the overall execution, and parent processes, which may spawn child contexts recursively.
- **Child Contexts**: These are subprocesses or remote processes managed by Mitogen, which can themselves become parents to further child contexts.
- **Broker**: The communication hub that manages connections between contexts.
- **PTY Management**: Mitogen handles pseudo-terminal (PTY) allocation and locking, which is essential for managing interactive subprocesses.
- **Signal Handling**: The module maps signal numbers to names for easier debugging and management.
- **Cross-Platform Compatibility**: Special handling is included for Linux and BSD/Darwin systems, as well as Python 2 and 3 compatibility.

Prerequisites
-------------

- Python 2.7 or later (Python 3.x recommended)
- Basic understanding of Python subprocesses and inter-process communication
- Familiarity with Unix-like operating systems is helpful for understanding PTY and signal handling

Basic Usage
-----------

1. **Importing the Core Module**

   Begin by importing the core module from Mitogen:

   ```python
   import mitogen.core
   ```

2. **Obtaining the Python Executable**

   Mitogen attempts to use the current Python interpreter for child processes. You can retrieve the executable path safely using:

   ```python
   python_executable = mitogen.core.get_sys_executable()
   ```

   This function returns `sys.executable` if set, or defaults to `/usr/bin/python` with a warning logged.

3. **Handling PTYs**

   Mitogen includes utilities to allocate and lock PTYs, which are necessary for interactive subprocesses. If PTY allocation fails, Mitogen provides informative error messages suggesting system configuration adjustments.

4. **Signal Mapping**

   The module provides a dictionary mapping signal numbers to their names for easier debugging:

   ```python
   signal_name = mitogen.core.SIGNAL_BY_NUM.get(signal_number)
   ```

5. **Logging**

   Mitogen uses Python’s standard logging module. You can check the current log level with:

   ```python
   log_level = mitogen.core.get_log_level()
   ```

Advanced Features
-----------------

- **Recursive Connections**

  Mitogen supports recursive connections where child contexts can themselves become parents to further child contexts. This is managed transparently by the core module.

- **SELinux Compatibility**

  The module detects if SELinux is enabled and avoids using socketpairs in such environments to maintain compatibility.

- **Cross-Version Compatibility**

  Mitogen handles differences between Python 2 and 3, including differences in iteration methods and attribute names.

Troubleshooting
---------------

- **PTY Allocation Failures**

  If you encounter errors related to PTY allocation, consider increasing system limits such as `kern.tty.ptmx_max` on macOS or `kernel.pty.max` on Linux.

- **Missing sys.executable**

  If `sys.executable` is unset, Mitogen will default to `/usr/bin/python`. Ensure your Python environment is correctly configured to avoid this fallback.

- **SELinux Restrictions**

  On systems with SELinux enabled, some socket operations may be restricted. Mitogen detects this and adjusts behavior accordingly.

Conclusion
----------

This tutorial introduced the core concepts and basic usage of the Mitogen core module. By leveraging Mitogen, you can efficiently manage complex process hierarchies and inter-process communication in your Python applications.

For more detailed examples and advanced usage, please refer to the full Mitogen documentation and source code.
