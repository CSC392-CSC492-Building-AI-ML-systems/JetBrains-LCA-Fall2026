Gaussian Processes
==================

Overview
--------

Gaussian Processes (GPs) are a powerful, non-parametric Bayesian approach to regression and classification problems. They provide a flexible framework for modeling distributions over functions and allow for principled uncertainty quantification in predictions.

Kernels
-------

At the core of Gaussian Processes lies the kernel (or covariance) function, which encodes assumptions about the function to be learned, such as smoothness, periodicity, and amplitude. The choice of kernel critically influences the behavior and performance of the GP model.

The kernels provided in this module support kernel engineering, enabling users to combine kernels using addition ("+") and multiplication ("*") operators, as well as exponentiation with scalars ("**"). This compositional approach allows the construction of complex kernels tailored to specific problems.

Kernel Hyperparameters
----------------------

Each kernel has hyperparameters that control its behavior, such as length scales and variance parameters. These hyperparameters can be optimized by maximizing the marginal likelihood of the data, typically using gradient-based methods.

Hyperparameters can be specified with bounds that define the search space for optimization. Alternatively, hyperparameters can be fixed to constant values to exclude them from optimization. This flexibility allows fine control over the model fitting process.

The `Hyperparameter` class encapsulates the specification of kernel hyperparameters, including:

- **name**: The identifier of the hyperparameter.
- **value_type**: The type of the hyperparameter (currently only "numeric" is supported).
- **bounds**: The lower and upper bounds for the hyperparameter values or the string `"fixed"` if the hyperparameter is not to be optimized.
- **n_elements**: The number of elements in the hyperparameter value (scalar or vector-valued).
- **fixed**: A boolean indicating whether the hyperparameter is fixed during optimization.

Example usage of hyperparameters:

```python
from sklearn.gaussian_process.kernels import ConstantKernel, Hyperparameter

kernel = ConstantKernel(constant_value=1.0, constant_value_bounds=(0.0, 10.0))

for hyperparameter in kernel.hyperparameters:
    print(hyperparameter)
```

This will output:

```
Hyperparameter(name='constant_value', value_type='numeric',
bounds=array([[ 0., 10.]]), n_elements=1, fixed=False)
```

Kernel Engineering
------------------

Kernels can be combined to create new kernels that capture more complex patterns:

- **Addition (`+`)**: Combines kernels by summing their covariance functions, modeling functions as sums of independent components.
- **Multiplication (`*`)**: Combines kernels by multiplying their covariance functions, modeling interactions between components.
- **Exponentiation (`**`)**: Raises a kernel to a scalar power, allowing for flexible scaling of kernel effects.

These operations support scalar values as well, which are automatically converted to constant kernels.

Gradient-Based Optimization
---------------------------

All kernels support analytic gradients with respect to their hyperparameters, enabling efficient gradient-based optimization of the marginal likelihood. This facilitates automatic tuning of kernel parameters to best fit the data.

Anisotropic Kernels
-------------------

Kernels can be isotropic (single length scale for all input dimensions) or anisotropic (different length scales per dimension). When specifying anisotropic kernels, the length scale parameter must match the number of input features.

Validation utilities ensure that length scales are correctly specified and consistent with the input data dimensionality.
