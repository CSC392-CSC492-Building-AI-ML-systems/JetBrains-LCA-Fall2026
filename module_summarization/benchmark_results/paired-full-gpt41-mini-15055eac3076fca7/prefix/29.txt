w_ntop — Select walkers from bins based on weight or randomly
==============================================================

Description
-----------

The ``w_ntop`` command selects walkers from bins using an assignment file that maps walkers to bins at each timepoint. This assignment file is required and can be generated using the ``w_assign`` command (see ``w_assign --help`` for details).

By default, ``w_ntop`` selects the top N walkers with the highest weights from each bin (hence the name "w_ntop"). Alternatively, it can select the N walkers with the lowest weights or select walkers randomly.

Output Format
-------------

The output file (specified with ``-o`` or ``--output``, default: ``ntop.h5``) contains the following datasets:

- ``/n_iter`` [iteration]  
  *(Integer)* Iteration numbers for each entry in other datasets.

- ``/n_segs`` [iteration][bin]  
  *(Integer)* Number of segments in each bin/state in the given iteration.  
  This is generally the same as the number requested with ``--count`` but may be smaller if fewer walkers exist.

- ``/seg_ids`` [iteration][bin][segment]  
  *(Integer)* Segment IDs matching each bin in each iteration.  
  For iteration ``n_iter``, only the first ``n_segs[n_iter]`` entries are valid.  
  For example, the list of matching segment IDs in bin 0 in the first stored iteration is ``seg_ids[0][0][:n_segs[0][0]]``.

- ``/weights`` [iteration][bin][segment]  
  *(Floating-point)* Weights corresponding to each segment in ``/seg_ids``.

Command-line Arguments
----------------------

Input Options
~~~~~~~~~~~~~

- ``-a``, ``--assignments``  
  Use assignments from the given ASSIGNMENTS file (default: ``assign.h5``).

Selection Options
~~~~~~~~~~~~~~~~~

- ``-n``, ``--count``  
  Select COUNT walkers from each iteration for each bin (default: 1).

- ``-t``, ``--timepoint``  
  Base selection on the given TIMEPOINT within each iteration. Default is ``-1``, which corresponds to the last timepoint.

Selection Mode (mutually exclusive)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``--highweight``  
  Select COUNT highest-weight walkers from each bin (default).

- ``--lowweight``  
  Select COUNT lowest-weight walkers from each bin.

- ``--random``  
  Select COUNT walkers randomly from each bin.

Output Options
~~~~~~~~~~~~~~

- ``-o``, ``--output``  
  Write output to OUTPUT file (default: ``ntop.h5``).

Progress Indicator
------------------

Options to control progress reporting are also available.

Usage Notes
-----------

- The assignment file must be generated prior to running ``w_ntop`` and should contain the mapping of walkers to bins at each timepoint.

- The selection is performed per iteration and per bin, based on the specified timepoint within each iteration.

- The output file can be used for further analysis or as input to other WESTPA tools.

For more information on generating assignment files, see the documentation for ``w_assign``.
