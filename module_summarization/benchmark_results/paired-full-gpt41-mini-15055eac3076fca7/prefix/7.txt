Using Lists
===========

Lists are a fundamental data structure in Python that allow you to store an ordered collection of items. They are mutable, meaning you can change their content after creation by adding, removing, or modifying elements.

Creating Lists
--------------

You can create a list by placing comma-separated values inside square brackets:

.. code-block:: python

    my_list = [1, 2, 3, 4]
    fruits = ['apple', 'banana', 'cherry']

Accessing Elements
------------------

List elements can be accessed by their index, starting at 0 for the first element:

.. code-block:: python

    first_fruit = fruits[0]  # 'apple'
    last_fruit = fruits[-1]  # 'cherry'

Modifying Lists
---------------

Lists can be modified by assigning new values to specific indices:

.. code-block:: python

    fruits[1] = 'blueberry'  # fruits is now ['apple', 'blueberry', 'cherry']

Adding Elements
---------------

You can add elements to a list using methods such as `append()`, `extend()`, or `insert()`:

.. code-block:: python

    fruits.append('date')          # Adds 'date' to the end
    fruits.extend(['elderberry'])  # Adds multiple elements
    fruits.insert(1, 'banana')     # Inserts 'banana' at index 1

Removing Elements
-----------------

Elements can be removed using `remove()`, `pop()`, or `del`:

.. code-block:: python

    fruits.remove('banana')  # Removes first occurrence of 'banana'
    last = fruits.pop()      # Removes and returns the last element
    del fruits[0]            # Deletes element at index 0

Iterating Over Lists
--------------------

You can iterate over the elements of a list using a for loop:

.. code-block:: python

    for fruit in fruits:
        print(fruit)

List Comprehensions
-------------------

List comprehensions provide a concise way to create lists:

.. code-block:: python

    squares = [x**2 for x in range(10)]

Common List Operations
----------------------

- `len(list)` returns the number of elements.
- `list.sort()` sorts the list in place.
- `sorted(list)` returns a new sorted list.
- `list.reverse()` reverses the list in place.
- `list.index(value)` returns the index of the first occurrence of value.
- `value in list` checks if value is in the list.

Example
-------

.. code-block:: python

    numbers = [1, 2, 3, 4, 5]
    even_numbers = [n for n in numbers if n % 2 == 0]
    print(even_numbers)  # Output: [2, 4]

Lists are versatile and widely used in Python programming for managing collections of data efficiently.
