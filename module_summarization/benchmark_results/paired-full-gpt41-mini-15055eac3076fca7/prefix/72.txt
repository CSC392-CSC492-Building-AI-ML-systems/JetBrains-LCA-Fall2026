Metrics Module
==============

This module provides utility functions and validation routines primarily used for pairwise distance computations and related metrics. It includes functions to check and prepare input arrays, handle sparse and dense data formats, and ensure data consistency and correctness before metric calculations.

Functions
---------

_return_float_dtype(X, Y)
    Determines the appropriate floating-point data type for the input arrays `X` and `Y`.
    
    - If both `X` and `Y` have dtype `float32`, returns `float32`.
    - Otherwise, returns the default Python float type.
    
    Parameters
    ----------
    X : array-like or sparse matrix
        First input array.
    Y : array-like or sparse matrix or None
        Second input array or None.
    
    Returns
    -------
    X : ndarray or sparse matrix
        Converted input array `X`.
    Y : ndarray or sparse matrix or None
        Converted input array `Y`.
    dtype : dtype
        The determined floating-point data type.

check_pairwise_arrays(X, Y, *, precomputed=False, dtype=None, accept_sparse='csr', force_all_finite=True, copy=False)
    Validates and prepares input arrays `X` and `Y` for pairwise distance computations.
    
    This function ensures that:
    
    - Both `X` and `Y` are converted to arrays or sparse matrices as appropriate.
    - They have compatible shapes for pairwise operations.
    - Their data types are floats or as specified.
    - Sparse matrix formats are accepted or converted as needed.
    - All values are finite unless specified otherwise.
    
    Parameters
    ----------
    X : array-like or sparse matrix of shape (n_samples_X, n_features)
        Input data.
    Y : array-like or sparse matrix of shape (n_samples_Y, n_features) or None
        Input data or None. If None, `Y` is set to `X`.
    precomputed : bool, default=False
        If True, `X` is treated as a precomputed distance matrix.
    dtype : str, type, list of types, or None, default=None
        Desired data type for the arrays. If None, an appropriate float type is selected.
    accept_sparse : str, bool, or list/tuple of str, default='csr'
        Allowed sparse matrix formats. If input is sparse but not in allowed format, it will be converted.
    force_all_finite : bool or 'allow-nan', default=True
        Whether to raise an error on np.inf, np.nan, or pd.NA in the arrays.
        - True: all values must be finite.
        - False: allows np.inf, np.nan, pd.NA.
        - 'allow-nan': allows only np.nan and pd.NA, but no infinite values.
    copy : bool, default=False
        Whether to force a copy of the input arrays.
    
    Returns
    -------
    safe_X : ndarray or sparse matrix of shape (n_samples_X, n_features)
        Validated and possibly converted version of `X`.
    safe_Y : ndarray or sparse matrix of shape (n_samples_Y, n_features)
        Validated and possibly converted version of `Y`. If `Y` was None, this is a reference to `X`.

Notes
-----
This module is intended for internal use within the metrics subpackage and supports the implementation of various distance and similarity measures by ensuring input data integrity and compatibility.
