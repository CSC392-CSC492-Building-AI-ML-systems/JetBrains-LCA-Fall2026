Partial Dependence and Individual Conditional Expectation Plots
================================================================

Overview
--------

Partial Dependence (PD) and Individual Conditional Expectation (ICE) plots are powerful tools for interpreting machine learning models. They help visualize the relationship between one or more features and the predicted outcome of a model, marginalizing over the values of all other features.

Partial Dependence Plots
------------------------

Partial Dependence plots show the average effect of a feature (or a set of features) on the predicted outcome of a model. By marginalizing over the distribution of the other features, PD plots provide insight into how the target response changes as the feature(s) of interest vary.

Key points about Partial Dependence plots:

- They display the marginal effect of one or two features on the predicted outcome.
- They are computed by averaging the predictions of the model over the joint distribution of the other features.
- PD plots are useful for understanding global model behavior.

Individual Conditional Expectation Plots
----------------------------------------

Individual Conditional Expectation plots complement PD plots by showing the dependence of the prediction on a feature for individual instances rather than averaging over the dataset.

Key points about ICE plots:

- They display one curve per instance, showing how the prediction changes as the feature varies.
- ICE plots reveal heterogeneity in the feature effect that may be masked by PD plots.
- They are useful for detecting interactions and identifying subgroups with different feature effects.

Usage and Interpretation
------------------------

- Use PD plots to understand the average effect of features on the model prediction.
- Use ICE plots to explore variation in feature effects across individual samples.
- Together, PD and ICE plots provide a comprehensive view of feature influence.

Feature Names Handling
----------------------

When generating PD or ICE plots, it is important to correctly handle feature names:

- If feature names are not provided, generic names such as `"x0"`, `"x1"`, ... are assigned based on the input data shape.
- For pandas DataFrames, column names are used as feature names.
- Feature names should be unique; duplicates will raise an error.
- Features can be specified by name or index when selecting features for plotting.

Example Workflow
----------------

1. Validate or generate feature names from the input data.
2. Select the feature(s) of interest by name or index.
3. Compute partial dependence values by marginalizing over other features.
4. Plot the average partial dependence curve (PD plot).
5. Optionally, plot individual conditional expectation curves (ICE plots) for detailed instance-level insights.

By leveraging Partial Dependence and Individual Conditional Expectation plots, practitioners can gain interpretable insights into complex machine learning models, facilitating better understanding and trust in model predictions.
