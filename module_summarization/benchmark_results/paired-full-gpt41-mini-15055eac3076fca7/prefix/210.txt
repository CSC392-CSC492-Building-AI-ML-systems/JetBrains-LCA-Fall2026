Empirical Likelihood Inference on Descriptive Statistics
=========================================================

Overview
--------
This module provides tools for conducting empirical likelihood inference on descriptive statistics such as the mean, variance, skewness, kurtosis, and correlation. Empirical likelihood methods enable hypothesis testing and the construction of confidence intervals without relying on parametric assumptions.

Key Features
------------
- Hypothesis tests and confidence intervals for:
  - Mean
  - Variance
  - Skewness
  - Kurtosis
  - Correlation

- Support for both univariate and multivariate data.

- Visualization capabilities (if matplotlib is installed), including:
  - Multivariate confidence region plots
  - Mean-variance contour plots

Empirical Likelihood Methodology
-------------------------------
Empirical likelihood is a nonparametric method of statistical inference that combines the flexibility of nonparametric methods with the likelihood-based inference framework. It constructs likelihood ratios directly from the data without specifying a parametric family, allowing for robust inference on parameters defined by estimating equations.

The approach involves solving for observation weights that maximize the empirical likelihood subject to constraints imposed by the estimating equations. Lagrange multipliers are used to enforce these constraints, and optimization routines are employed to find the maximum empirical likelihood estimates.

Classes and Functions
---------------------

DescStat(endog)
^^^^^^^^^^^^^^^
Returns an instance for conducting empirical likelihood inference on descriptive statistics.

Parameters
~~~~~~~~~~
- endog : ndarray
  Input data array. Can be univariate or multivariate.

Returns
~~~~~~~
- DescStat instance:
  - If the data is univariate (one-dimensional), returns a `DescStatUV` instance.
  - If the data is multivariate (more than one dimension), returns a `DescStatMV` instance.

_OptFuncts
^^^^^^^^^^
A helper class encapsulating functions used in the optimization and solving of empirical likelihood problems.

Key Methods
~~~~~~~~~~~
- _log_star(eta, est_vect, weights, nobs)
  Computes a transformed log of observation probabilities in terms of the Lagrange multiplier. This transformation aids in the optimization process.

- _hess(eta, est_vect, weights, nobs)
  Calculates the Hessian matrix of the weighted empirical likelihood problem, which is essential for Newton-type optimization methods.

- _grad(eta, est_vect, weights, nobs)
  Computes the gradient vector of the weighted empirical likelihood problem.

Technical Details
-----------------
The empirical likelihood inference is formulated by defining estimating equations for the parameters of interest. The optimization problem involves maximizing the empirical likelihood subject to these estimating equations, which is solved by profiling out nuisance parameters when present.

The optimization uses modified Newton methods to solve for the Lagrange multipliers that enforce the constraints. The module leverages numerical optimization routines from SciPy and Statsmodels to perform these calculations efficiently.
