Kernel Approximation Module
===========================

The :mod:`sklearn.kernel_approximation` module implements several approximate kernel feature maps based on Fourier transforms and Count Sketches. These methods provide efficient ways to approximate kernel functions, enabling scalable kernel methods for large datasets.

Overview
--------

Kernel methods often rely on computing the kernel function between pairs of samples, which can be computationally expensive for large datasets. Kernel approximation techniques aim to approximate the feature map induced by a kernel function, allowing the use of linear methods in the transformed feature space.

This module includes implementations of approximate kernel feature maps such as:

- Polynomial kernel approximation via Tensor Sketch.
- Other approximate feature maps based on Fourier transforms and Count Sketches.

Classes
-------

PolynomialCountSketch
~~~~~~~~~~~~~~~~~~~~~

Approximate the polynomial kernel feature map using Tensor Sketch.

The polynomial kernel is defined as:

.. math::

    K(X, Y) = (\gamma \langle X, Y \rangle + \text{coef0})^{\text{degree}}

PolynomialCountSketch efficiently approximates this kernel by computing a Count Sketch of the outer product of a vector with itself using Fast Fourier Transforms (FFT).

**Parameters**

- **gamma** : float, default=1.0  
  Parameter of the polynomial kernel whose feature map will be approximated.

- **degree** : int, default=2  
  Degree of the polynomial kernel.

- **coef0** : int, default=0  
  Constant term in the polynomial kernel.

- **n_components** : int, default=100  
  Dimensionality of the output feature space. Typically, a larger number of components leads to better approximation.

- **random_state** : int, RandomState instance or None, default=None  
  Controls the randomness of the hash functions used in the sketch.

**Attributes**

- **indexHash_** : ndarray of shape (degree, n_features), dtype=int64  
  Indexes used for the 2-wise independent hash functions in Count Sketch.

- **bitHash_** : ndarray of shape (degree, n_features), dtype=float32  
  Random entries in {+1, -1} used for the 2-wise independent hash functions.

- **n_features_in_** : int  
  Number of features seen during fit.

- **feature_names_in_** : ndarray of shape (n_features_in_,), optional  
  Names of features seen during fit, if available.

**Example**

.. code-block:: python

    from sklearn.kernel_approximation import PolynomialCountSketch
    from sklearn.linear_model import SGDClassifier

    X = [[0, 0], [1, 1], [1, 0], [0, 1]]
    y = [0, 0, 1, 1]

    ps = PolynomialCountSketch(degree=3, random_state=1)
    X_features = ps.fit_transform(X)

    clf = SGDClassifier(max_iter=10, tol=1e-3)
    clf.fit(X_features, y)
    print(clf.score(X_features, y))
    # Output: 1.0

See Also
--------

- :class:`sklearn.kernel_approximation.AdditiveChi2Sampler`  
  Approximate feature map for additive chi-squared kernel.

- :class:`sklearn.kernel_approximation.Nystroem`  
  Approximate a kernel map using a subset of the training data.

- :class:`sklearn.kernel_approximation.RBFSampler`  
  Approximate a RBF kernel feature map using random Fourier features.

- :class:`sklearn.kernel_approximation.SkewedChi2Sampler`  
  Approximate feature map for "skewed chi-squared" kernel.

- :mod:`sklearn.metrics.pairwise.kernel_metrics`  
  List of built-in kernels.
