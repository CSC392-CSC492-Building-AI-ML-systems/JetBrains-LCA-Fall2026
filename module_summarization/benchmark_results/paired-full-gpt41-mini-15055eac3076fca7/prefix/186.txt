Imputation of Missing Values
============================

Imputation is a common preprocessing step in data analysis and machine learning, where missing values in datasets are filled in with substituted values. This process allows models to be trained on complete datasets without discarding samples or features that contain missing data.

Overview
--------

The imputation module provides base classes and utilities to handle missing values in numerical and categorical data. It supports various strategies for imputing missing values and can optionally add indicators to mark the locations of missing data.

Key Features
------------

- **Flexible Missing Value Definitions**  
  Missing values can be specified using various markers, including `np.nan`, `pd.NA`, or any other user-defined sentinel value.

- **Support for Numerical and Categorical Data**  
  The imputers handle different data types and ensure that the missing values and input data types are compatible.

- **Missing Indicator Support**  
  Optionally, an indicator matrix can be added to the output to flag the positions of missing values in the original data.

- **Sparse and Dense Data Compatibility**  
  The imputation utilities work seamlessly with both dense NumPy arrays and sparse matrix formats.

Base Imputer Class
------------------

The `_BaseImputer` class serves as the foundational class for all imputation transformers. It inherits from `TransformerMixin` and `BaseEstimator`, providing a consistent interface and integration with scikit-learn pipelines.

### Parameters

- `missing_values` : scalar or "NaN", default=`np.nan`  
  The placeholder for the missing values. All occurrences of this value will be imputed.

- `add_indicator` : bool, default=False  
  If True, a `MissingIndicator` is added to the output to mark missing values.

- `keep_empty_features` : bool, default=False  
  Whether to keep features that are entirely missing after imputation.

### Methods

- `_fit_indicator(X)`  
  Fits a `MissingIndicator` on the dataset `X` if `add_indicator` is True.

- `_transform_indicator(X)`  
  Transforms the dataset `X` to produce the missing indicator mask.

- `_concatenate_indicator(X_imputed, X_indicator)`  
  Concatenates the imputed data with the missing indicator mask.

- `_concatenate_indicator_feature_names_out(names, input_features)`  
  Extends feature names to include indicator feature names when `add_indicator` is True.

Utility Functions
-----------------

- `_check_inputs_dtype(X, missing_values)`  
  Validates that the data type of `X` and the `missing_values` parameter are compatible, especially for numerical data.

- `_most_frequent(array, extra_value, n_repeat)`  
  Computes the most frequent value in a 1D array, considering an additional repeated value. This is useful for imputing categorical features with the most frequent category.

Usage Notes
-----------

- When using pandas data structures, the imputation utilities recognize `pd.NA` as a missing value marker.

- The imputation process can be performed inplace for efficiency, but care must be taken when using missing indicators to ensure the original missing data mask is preserved.

- Tie-breaking in the computation of the most frequent value is handled consistently to ensure deterministic results.
