Nextcord
=======

Nextcord is an easy-to-use, feature-rich, and modern Python library designed for interacting with the Discord API. It allows developers to create Discord bots and automate tasks within Discord servers with simplicity and efficiency.

Introduction
------------

Nextcord provides a comprehensive interface to Discord's features, including user management, channels, guilds, activities, invites, and widgets. It is built with type hinting and asynchronous programming in mind, making it suitable for modern Python applications.

Key Features
------------

- **Widget Support**: Nextcord includes support for Discord widgets, allowing you to access partial information about guilds, channels, and members through widget data.
- **Rich Object Models**: The library models Discord entities such as users, members, channels, and activities with detailed classes that provide useful attributes and methods.
- **Activity and Status Handling**: Nextcord supports various activity types, including Spotify listening status, and provides enums for user status.
- **Type Safety and Introspection**: With extensive use of type annotations and enums, Nextcord helps catch errors early and improves code readability.
- **Asynchronous Design**: Built on Python's `asyncio`, Nextcord enables efficient handling of multiple Discord events and API calls concurrently.

Widget Classes Overview
-----------------------

Nextcord includes classes to represent partial data from Discord widgets:

- **WidgetChannel**  
  Represents a partial channel from a Discord widget.  
  Attributes:  
  - `id` (int): The channel's unique identifier.  
  - `name` (str): The channel's name.  
  - `position` (int): The channel's position in the channel list.  
  Properties:  
  - `mention` (str): A string to mention the channel in Discord.  
  - `created_at` (datetime): The UTC timestamp when the channel was created.

- **WidgetMember**  
  Represents a partial member of a guild obtained from a widget.  
  Inherits from `BaseUser`.  
  Attributes include:  
  - `id` (int): The member's unique identifier.  
  - `name` (str): The member's username.  
  - `discriminator` (str): The member's discriminator tag.  
  - `bot` (bool): Whether the member is a bot.  
  - `status` (Status): The member's current status (online, offline, etc.).  
  - `nick` (Optional[str]): The member's nickname in the guild.  
  - `avatar` (Optional[str]): The member's avatar hash.  
  - `activity` (Optional[BaseActivity or Spotify]): The member's current activity.  
  - `deafened`, `muted`, `suppress` (Optional[bool]): Voice state flags.  
  - `connected_channel` (Optional[WidgetChannel]): The voice channel the member is connected to.
