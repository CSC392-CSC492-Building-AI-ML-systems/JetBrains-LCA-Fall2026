Miscellaneous Models
====================

Linear Model with Student-t Distributed Errors
----------------------------------------------

This module implements a linear regression model where the errors are assumed to follow a Student's t-distribution rather than a normal distribution. The Student's t-distribution has heavier tails compared to the normal distribution, making this model more robust to outliers and observations with heavier tails.

The model is estimated using Maximum Likelihood Estimation (MLE) via the generic likelihood framework provided by `statsmodels`. The key feature of this model is the incorporation of the degrees of freedom parameter (`df`) of the t-distribution, which controls the heaviness of the tails. When `df` is large, the t-distribution approaches the normal distribution, while smaller values of `df` allow for heavier tails.

Key Features
~~~~~~~~~~~~

- **Robustness to Outliers:** The t-distributed errors provide robustness against outliers in the data, as the heavier tails reduce the influence of extreme observations on parameter estimates.
- **Flexible Tail Behavior:** The degrees of freedom parameter can be estimated from the data or fixed by the user, allowing flexibility in modeling tail behavior.
- **Generic MLE Framework:** The model leverages the generic likelihood model interface, requiring only the specification of the negative log-likelihood function. Gradients and Hessians are computed numerically.
- **Starting Values:** Starting values for the optimization can be based on ordinary least squares (OLS) estimates, with optional adjustments based on residual kurtosis.

Model Details
~~~~~~~~~~~~~

The model assumes the following form:

.. math::

    y_i = x_i^{\\prime} \\beta + \\varepsilon_i, \\quad \\varepsilon_i \\sim t_{\\nu}(0, \\sigma^2)

where :math:`t_{\\nu}` denotes the Student's t-distribution with degrees of freedom :math:`\\nu`, location zero, and scale parameter :math:`\\sigma`.

The log-likelihood for observation :math:`i` is given by the t-distribution log-density evaluated at the residuals scaled by the scale parameter.

Parameters
~~~~~~~~~~

- **Regression coefficients (beta):** Coefficients for the explanatory variables.
- **Degrees of freedom (df):** Controls the heaviness of the tails of the error distribution. Can be fixed or estimated.
- **Scale:** Scale parameter of the t-distribution, related to the dispersion of the errors.

Usage Notes
~~~~~~~~~~~

- The scale parameter is not the standard deviation of the errors since the t-distribution is not standardized.
- The model supports fixing the degrees of freedom parameter to a specified value or estimating it from the data.
- Numerical differentiation is used for gradients and Hessians, which may affect performance and precision.
- Starting values for parameters are important for convergence; by default, OLS estimates are used for regression coefficients, and default values are set for degrees of freedom and scale.
- Some features such as parameter restrictions and debugging utilities are noted as TODO or experimental.
