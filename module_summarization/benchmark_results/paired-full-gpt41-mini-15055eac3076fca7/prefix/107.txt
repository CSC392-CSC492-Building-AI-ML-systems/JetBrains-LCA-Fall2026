Iterables Module
================

This module provides utility functions for working with iterable data structures, including flattening nested iterables, grouping elements, and traversing tree-like structures.

Functions
---------

flatten(iterable, levels=None, cls=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Recursively denest iterable containers.

- Parameters:
  - iterable: The iterable to flatten.
  - levels (optional): The number of levels to flatten. If None, flattens all levels.
  - cls (optional): If specified, only instances of this class will be flattened.

- Returns: A list with the nested iterables flattened.

- Examples:

  >>> flatten([1, 2, 3])
  [1, 2, 3]

  >>> flatten([1, 2, [3]])
  [1, 2, 3]

  >>> flatten([1, 2, [3, [4, 5]]], levels=1)
  [1, 2, 3, [4, 5]]

  >>> class MyOp(Basic):
  ...     pass
  ...
  >>> flatten([MyOp(1, MyOp(2, 3))], cls=MyOp)
  [1, 2, 3]

unflatten(iter, n=2)
~~~~~~~~~~~~~~~~~~~~
Group an iterable into tuples of length `n`.

- Parameters:
  - iter: The iterable to group.
  - n: The size of each group (default is 2).

- Returns: A list of tuples, each of length `n`.

- Raises: ValueError if the length of `iter` is not a multiple of `n`.

- Example:

  >>> unflatten([1, 2, 3, 4], 2)
  [(1, 2), (3, 4)]

group(seq, multiple=True)
~~~~~~~~~~~~~~~~~~~~~~~~~
Splits a sequence into a list of lists of equal, adjacent elements.

- Parameters:
  - seq: The sequence to group.
  - multiple: If True (default), returns groups as lists of elements.
              If False, returns a list of tuples (element, count).

- Returns: A list of grouped elements or tuples of (element, count).

- Examples:

  >>> group([1, 1, 1, 2, 2, 3])
  [[1, 1, 1], [2, 2], [3]]

  >>> group([1, 1, 1, 2, 2, 3], multiple=False)
  [(1, 3), (2, 2), (3, 1)]

  >>> group([1, 1, 3, 2, 2, 1], multiple=False)
  [(1, 2), (3, 1), (2, 2), (1, 1)]

multiset(seq)
~~~~~~~~~~~~
Return the hashable sequence in multiset form with values being the multiplicity of the item in the sequence.

- Parameters:
  - seq: The sequence to convert to a multiset.

- Returns: A dictionary mapping elements to their multiplicities.

- Example:

  >>> multiset('mississippi')
  {'m': 1, 'i': 4, 's': 4, 'p': 2}

postorder_traversal(node, keys=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Perform a postorder traversal of a tree-like structure.

- Parameters:
  - node: The root node of the tree to traverse.
  - keys (optional): Sorting key(s) for ordering children nodes. If None, children are processed in arbitrary order. If True, default ordering keys are used.

- Yields: Each subtree in postorder (children before parent).

- Example:

  >>> from diofant.abc import w, x, y, z
  >>> list(postorder_traversal(w + (x + y)*z, keys=True))
  [w, z, x, y, x + y, z*(x + y), w + z*(x + y)]

Notes
-----
- The `flatten` function can handle arbitrary nesting and can be restricted to flatten only specific container types.
- The `group` function is useful for run-length encoding or summarizing sequences.
- The `multiset` function provides a convenient way to count occurrences of elements.
- The `postorder_traversal` function is designed for traversing expression trees or similar structures in a depth-first manner.

See Also
--------
- `multiset` and `group` are related in that they both summarize sequences by element counts.
- `postorder_traversal` is useful in symbolic computation and tree processing contexts.
