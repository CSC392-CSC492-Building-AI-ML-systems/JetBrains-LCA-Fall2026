Generate Documentation for ASDF Tree Search Utilities
======================================================

Overview
--------
This module provides utilities for searching and inspecting ASDF (Advanced Scientific Data Format) trees. It includes the `AsdfSearchResult` class, which encapsulates the results of a search operation on an ASDF file tree and provides methods to refine and format these results.

Features
--------

AsdfSearchResult Class
----------------------

The `AsdfSearchResult` class represents the outcome of a search performed on an ASDF tree. It allows users to filter nodes based on keys, types, and values, and to customize the display of the search results.

### Initialization

- **Parameters:**
  - `identifiers`: Identifiers related to the search result.
  - `node`: The node in the ASDF tree that matches the search.
  - `filters` (optional): List of filters applied to the search.
  - `parent_node` (optional): The parent node of the matched node.
  - `max_rows` (optional): Maximum number of rows to display in the formatted output.
  - `max_cols` (optional): Maximum number of columns (line length) to display.
  - `show_values` (optional): Boolean flag to indicate whether to show primitive values in the output.

### Formatting Search Results

- **Method:** `format(max_rows=NotSet, max_cols=NotSet, show_values=NotSet)`
  
  Allows customization of the formatting parameters for the rendered tree output.
  
  - **Parameters:**
    - `max_rows`: Controls the maximum number of lines to print. Can be an integer, tuple, `None`, or `NotSet`.
      - If an integer, limits the total number of displayed lines.
      - If a tuple, limits lines per node at corresponding depths.
      - If `None`, all lines are displayed.
      - If `NotSet`, retains the existing value.
    - `max_cols`: Controls the maximum length of each line. Can be an integer, `None`, or `NotSet`.
      - If an integer, limits the length of displayed lines.
      - If `None`, line length is unconstrained.
      - If `NotSet`, retains the existing value.
    - `show_values`: Boolean or `NotSet`.
      - If `False`, disables display of primitive values.
      - If `NotSet`, retains the existing value.
  
  - **Returns:** A new `AsdfSearchResult` instance with updated formatting parameters.

### Searching Within Results

- **Method:** `search(key=NotSet, type=NotSet, value=NotSet, filter=None)`
  
  Enables further narrowing of the search results based on node key, type, or value.
  
  - **Parameters:**
    - `key`: Search query to select nodes by dictionary key or list index.
      - If `NotSet`, no constraint on node key.
      - If `str`, interpreted as a regular expression pattern to match keys or indexes.
      - Otherwise, nodes must have keys or indexes equal to this value.
    - `type`: Search query to select nodes by type.
      - If `NotSet`, no constraint on node type.
      - If `str`, interpreted as a regular expression pattern matching fully qualified node type names.
      - If a Python type, nodes must be instances of this type.
    - `value`: Search query to select nodes by value.
      - If `NotSet`, no constraint on node value.
      - If `str`, interpreted as a regular expression pattern matching node values.
      - Otherwise, nodes must have values equal to this value.
    - `filter`: Additional custom filter function (optional).
  
  - **Returns:** A new `AsdfSearchResult` instance representing the filtered search results.

Internal Utilities
------------------

- `_maybe_compile_pattern(query)`: Compiles a string query into a regular expression pattern if necessary.
- `_safe_equals(a, b)`: Safely compares two values for equality, returning `False` if comparison raises an exception.
- `_get_fully_qualified_type(value)`: Returns the fully qualified type name of a value, including its module.

Usage
-----

The `AsdfSearchResult` class is typically obtained by calling the `search` method on an `AsdfFile` object (not shown here). Users can chain calls to `search` to refine results and use `format` to customize the display of the matched nodes.

Example:

```python
result = asdf_file.search(key=".*temperature.*")
filtered_result = result.search(type="float")
formatted_result = filtered_result.format(max_rows=20, show_values=False)
print(formatted_result)
```

This example searches for nodes with keys matching "temperature", filters those nodes to only include floats, formats the output to show up to 20 lines without primitive values, and prints the result.

Summary
-------

This module provides a flexible and powerful interface for querying and displaying nodes within ASDF trees, facilitating detailed inspection and analysis of complex hierarchical data structures.
