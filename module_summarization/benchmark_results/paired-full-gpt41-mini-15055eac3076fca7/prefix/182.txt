Developing scikit-learn Estimators
==================================

This document provides guidance and an overview for developers interested in creating or extending estimators within the scikit-learn ecosystem. It covers the design principles, base classes, and utilities available to facilitate the development of robust, consistent, and interoperable estimators.

Estimator Design Principles
---------------------------

Scikit-learn estimators follow a consistent interface and design pattern to ensure compatibility with the broader ecosystem. Key principles include:

- **Fit / Predict Paradigm**: Estimators implement a `fit` method to learn from data, and one or more prediction methods such as `predict`, `predict_proba`, or `transform`.
- **Meta-Estimators**: Some estimators act as wrappers or meta-estimators that extend the functionality of base estimators, for example, enabling multioutput regression or classification.
- **Cloning and Immutability**: Estimators should be cloneable via the `clone` utility to ensure reproducibility and safe parameter tuning.
- **Parameter Validation**: Parameters should be validated and documented clearly, using utilities such as `_param_validation` to enforce correct types and values.
- **Support for Sample Weights**: When applicable, estimators should support sample weights during fitting.
- **Partial Fit Support**: For incremental learning, estimators may implement `partial_fit` to update the model with batches of data.

Base Classes and Mixins
-----------------------

Scikit-learn provides several base classes and mixins to simplify estimator development:

- `BaseEstimator`: The fundamental base class providing parameter management and cloning.
- `ClassifierMixin` and `RegressorMixin`: Provide default implementations for classification and regression metrics and checks.
- `MetaEstimatorMixin`: For meta-estimators that wrap other estimators.
- Utility functions such as `clone`, `check_is_fitted`, and `check_classification_targets` assist in estimator implementation and validation.

Multioutput Estimators
----------------------

The module includes meta-estimators that extend single-output estimators to handle multioutput tasks:

- `MultiOutputRegressor`: Extends regressors to multioutput regression.
- `MultiOutputClassifier`: Extends classifiers to multioutput classification.
- `ClassifierChain` and `RegressorChain`: Implement chained multioutput estimators where predictions of one estimator are used as features for the next.

These meta-estimators require a base estimator to be provided and handle fitting and prediction across multiple outputs.

Fitting and Partial Fitting
---------------------------

Helper functions such as `_fit_estimator` and `_partial_fit_estimator` are used internally to clone and fit estimators, optionally supporting sample weights and incremental learning parameters.

Metadata Routing and Conditional Availability
----------------------------------------------

Advanced utilities like `MetadataRouter` and decorators such as `available_if` enable conditional method availability based on the presence of attributes in sub-estimators, facilitating flexible meta-estimator implementations.

Dependencies and Environment
----------------------------

Developing scikit-learn estimators requires adherence to minimum dependency versions to ensure compatibility and stability. Key dependencies include:

- NumPy (minimum version varies by Python implementation)
- SciPy
- Joblib
- Threadpoolctl
- Cython (for build)

Additional dependencies support testing, documentation, benchmarking, and examples.

Testing and Validation
----------------------

Estimators should be thoroughly tested using the scikit-learn testing framework, which relies on `pytest` and related tools. Validation utilities help ensure estimators conform to scikit-learn standards and behave correctly across diverse datasets.

Summary
-------

Developing estimators in scikit-learn involves adhering to a well-defined interface and leveraging base classes and utilities provided by the library. By following these guidelines, developers can create estimators that integrate seamlessly with the scikit-learn ecosystem, benefiting from its rich functionality and community support.
