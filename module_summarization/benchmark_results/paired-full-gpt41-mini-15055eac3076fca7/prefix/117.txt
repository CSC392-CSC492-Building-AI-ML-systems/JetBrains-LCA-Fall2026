Resources
=========

Support for plugins that provide access to resources such as schemas.

Classes
-------

DirectoryResourceMapping
~~~~~~~~~~~~~~~~~~~~~~~~

A resource mapping that reads resource content from a directory or directory tree.

See :class:`~asdf_standard.resource.DirectoryResourceMapping` for details.

ResourceMappingProxy
~~~~~~~~~~~~~~~~~~~~

Wrapper around a resource mapping that carries additional information on the package that provided the mapping.

**Methods and Properties:**

- `maybe_wrap(delegate)`  
  Class method that returns a `ResourceMappingProxy` wrapping the given delegate mapping, or returns the delegate itself if it is already a `ResourceMappingProxy`.

- `__init__(delegate, package_name=None, package_version=None)`  
  Initialize the proxy with the given resource mapping delegate and optional package name and version.

- `__getitem__(uri)`  
  Retrieve the resource content for the given URI from the wrapped mapping.

- `__len__()`  
  Return the number of resources in the wrapped mapping.

- `__iter__()`  
  Iterate over the URIs in the wrapped mapping.

- `delegate` (property)  
  Get the wrapped mapping instance.  
  Returns: `collections.abc.Mapping`

- `package_name` (property)  
  Get the name of the Python package that provided this mapping.  
  Returns: `str` or `None` if the mapping was added at runtime.

- `package_version` (property)  
  Get the version of the Python package that provided this mapping.  
  Returns: `str` or `None` if the mapping was added at runtime.

- `class_name` (property)  
  Get the fully qualified class name of the mapping.  
  Returns: `str`

- `__eq__(other)`  
  Equality comparison based on the wrapped delegate.

- `__hash__()`  
  Hash based on the identity of the wrapped delegate.

- `__repr__()`  
  String representation including class name, package name and version, and number of resources.

ResourceManager
~~~~~~~~~~~~~~~

Wraps multiple resource mappings into a single interface with friendlier error handling.

**Parameters:**

- `resource_mappings` : iterable of `collections.abc.Mapping`  
  Underlying resource mappings. In the case of a duplicate URI, the first mapping takes precedence.

**Methods:**

- `__getitem__(uri)`  
  Retrieve the resource content for the given URI from the first mapping that contains it. Raises `KeyError` if unavailable. Returns bytes (encoding strings as UTF-8).

- `__len__()`  
  Return the total number of unique URIs across all mappings.

- `__iter__()`  
  Iterate over all unique URIs.

- `__contains__(uri)`  
  Check if the URI is available in any of the underlying mappings.

- `__repr__()`  
  String representation showing the number of resources managed.

JsonschemaResourceMapping
~~~~~~~~~~~~~~~~~~~~~~~~~

Resource mapping that fetches metaschemas from the `jsonschema` package.

**Methods:**

- `__getitem__(uri)`  
  Retrieve the metaschema content for the given JSON Schema URI. Supported URIs are mapped to filenames within the `jsonschema` package data.

Constants
---------

_JSONSCHEMA_URI_TO_FILENAME
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Dictionary mapping JSON Schema URIs to corresponding filenames in the `jsonschema` package.

Example:

- `"http://json-schema.org/draft-04/schema"` maps to `"draft4.json"`.

Summary
-------

This module provides a framework for managing resource mappings, which are abstractions for accessing resource content such as JSON schemas. It includes:

- `DirectoryResourceMapping` for loading resources from directories.
- `ResourceMappingProxy` for wrapping mappings with package metadata.
- `ResourceManager` for combining multiple mappings into a single interface.
- `JsonschemaResourceMapping` for accessing JSON Schema metaschemas from the `jsonschema` package.

These classes facilitate flexible and extensible access to resource content needed by plugins or other components.
