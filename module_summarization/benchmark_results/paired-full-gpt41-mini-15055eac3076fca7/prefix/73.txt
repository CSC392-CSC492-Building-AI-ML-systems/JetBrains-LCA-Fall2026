Naive Bayes (:mod:`sklearn.naive_bayes`)
=========================================

Overview
--------

The :mod:`sklearn.naive_bayes` module implements Naive Bayes algorithms, which are supervised learning methods based on applying Bayes' theorem with strong (naive) feature independence assumptions. These algorithms are widely used for classification tasks due to their simplicity, efficiency, and effectiveness in many practical applications.

Classes
-------

The module provides several Naive Bayes classifiers, each suited for different types of data and assumptions:

- **BernoulliNB**  
  Implements the Bernoulli Naive Bayes algorithm for binary/boolean features.

- **GaussianNB**  
  Implements the Gaussian Naive Bayes algorithm for continuous features assumed to follow a Gaussian distribution.

- **MultinomialNB**  
  Implements the Multinomial Naive Bayes algorithm for multinomially distributed data, commonly used for discrete counts such as word counts in text classification.

- **ComplementNB**  
  A variant of MultinomialNB designed to correct the "severe assumptions" made by the standard MultinomialNB, particularly useful for imbalanced datasets.

- **CategoricalNB**  
  Implements Naive Bayes for categorical features without requiring one-hot encoding.

Base Class: _BaseNB
-------------------

The abstract base class `_BaseNB` provides a common interface and shared functionality for all Naive Bayes classifiers in this module. It inherits from `BaseEstimator` and `ClassifierMixin` and uses the `ABCMeta` metaclass to enforce implementation of abstract methods in subclasses.

Key Methods:

- `_joint_log_likelihood(X)`  
  Abstract method to compute the unnormalized posterior log probability of the input samples `X`. It returns an array of shape `(n_samples, n_classes)` representing the log probabilities `log P(c) + log P(x|c)` for each class `c`.

- `_check_X(X)`  
  Abstract method intended to be overridden in subclasses to perform input validation and preprocessing on `X`. Used internally by prediction methods.

- `predict_joint_log_proba(X)`  
  Returns the joint log probability estimates for the input samples `X`. For each sample and class, it computes `log P(x, y) = log P(y) + log P(x|y)`.

- `predict(X)`  
  Performs classification on the input samples `X` by predicting the most likely class labels.

- `predict_log_proba(X)`  
  Returns the log-probability estimates for the input samples `X`. The probabilities are normalized over all classes.

- `predict_proba(X)`  
  Returns the probability estimates for the input samples `X` by exponentiating the log probabilities.

Usage
-----

Typical usage involves instantiating one of the Naive Bayes classifiers, fitting it to training data, and then using it to predict labels or probabilities for new data samples.

Example:

```python
from sklearn.naive_bayes import GaussianNB

# Create a Gaussian Naive Bayes classifier
gnb = GaussianNB()

# Fit the model
gnb.fit(X_train, y_train)

# Predict class labels
y_pred = gnb.predict(X_test)

# Predict class probabilities
y_proba = gnb.predict_proba(X_test)
```

Notes
-----

- All classifiers in this module assume feature independence given the class label.
- Input validation and preprocessing are handled internally by each classifier.
- The module supports multi-class classification problems.
- The `predict_log_proba` and `predict_proba` methods provide probabilistic outputs useful for downstream tasks requiring uncertainty estimates.
