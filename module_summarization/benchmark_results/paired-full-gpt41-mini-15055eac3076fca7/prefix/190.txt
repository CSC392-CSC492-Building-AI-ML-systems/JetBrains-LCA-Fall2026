Linear and Quadratic Discriminant Analysis
===========================================

Linear Discriminant Analysis (LDA) and Quadratic Discriminant Analysis (QDA) are classical methods used in statistics and machine learning for classification tasks. Both methods model the distribution of the predictors separately in each class and use Bayes’ theorem to estimate the posterior probabilities of the classes given the predictors.

Overview
--------

- **Linear Discriminant Analysis (LDA)** assumes that the different classes share the same covariance matrix but have different mean vectors. This assumption leads to linear decision boundaries between classes.
- **Quadratic Discriminant Analysis (QDA)** relaxes the assumption of shared covariance matrices and allows each class to have its own covariance matrix. This results in quadratic decision boundaries.

Both methods are generative classifiers, meaning they model the joint probability distribution \( p(X, Y) \) and use it to compute the posterior \( p(Y|X) \).

Mathematical Formulation
------------------------

Given a feature vector \( \mathbf{x} \in \mathbb{R}^d \) and a set of classes \( \{1, \ldots, K\} \), LDA and QDA model the class-conditional densities \( p(\mathbf{x} | y = k) \) as multivariate normal distributions:

\[
p(\mathbf{x} | y = k) = \frac{1}{(2\pi)^{d/2} |\Sigma_k|^{1/2}} \exp\left(-\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu}_k)^T \Sigma_k^{-1} (\mathbf{x} - \boldsymbol{\mu}_k)\right)
\]

- For **LDA**, the covariance matrices are assumed equal across classes: \( \Sigma_k = \Sigma \) for all \( k \).
- For **QDA**, each class has its own covariance matrix \( \Sigma_k \).

The prior probabilities \( \pi_k = P(y = k) \) are estimated from the training data.

Decision Rule
-------------

The classification rule assigns a sample \( \mathbf{x} \) to the class \( k \) that maximizes the posterior probability:

\[
\hat{y} = \arg\max_k \; p(y = k | \mathbf{x}) \propto \pi_k \, p(\mathbf{x} | y = k)
\]

- In **LDA**, this leads to a linear discriminant function:

\[
\delta_k(\mathbf{x}) = \mathbf{x}^T \Sigma^{-1} \boldsymbol{\mu}_k - \frac{1}{2} \boldsymbol{\mu}_k^T \Sigma^{-1} \boldsymbol{\mu}_k + \log \pi_k
\]

- In **QDA**, the discriminant function is quadratic in \( \mathbf{x} \):

\[
\delta_k(\mathbf{x}) = -\frac{1}{2} \log |\Sigma_k| - \frac{1}{2} (\mathbf{x} - \boldsymbol{\mu}_k)^T \Sigma_k^{-1} (\mathbf{x} - \boldsymbol{\mu}_k) + \log \pi_k
\]

Applications
------------

LDA and QDA are widely used in various domains including:

- Pattern recognition
- Medical diagnosis
- Finance for credit scoring
- Any classification problem where the class-conditional distributions can be reasonably approximated by Gaussian distributions

Advantages and Limitations
--------------------------

**Advantages:**

- Both methods are simple and computationally efficient.
- LDA performs well when the class covariances are similar and the data is approximately Gaussian.
- QDA is more flexible than LDA as it allows different covariance matrices for each class.

**Limitations:**

- Both methods assume normality of the predictors within each class.
- LDA’s assumption of equal covariance matrices may be too restrictive in some cases.
- QDA requires estimating more parameters (covariance matrices for each class), which can lead to overfitting especially with small sample sizes.

Implementation Notes
--------------------

- Prior probabilities \( \pi_k \) can be specified or estimated from the training data.
- Regularization techniques can be applied to covariance estimates to improve robustness.
- Feature scaling is generally not required as the methods are based on covariance estimates.
- Both LDA and QDA can be extended to multi-class classification problems naturally.

Example Usage
-------------

```python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis, QuadraticDiscriminantAnalysis

# Create LDA and QDA classifiers
lda = LinearDiscriminantAnalysis()
qda = QuadraticDiscriminantAnalysis()

# Fit the models
lda.fit(X_train, y_train)
qda.fit(X_train, y_train)

# Predict
y_pred_lda = lda.predict(X_test)
y_pred_qda = qda.predict(X_test)
```
