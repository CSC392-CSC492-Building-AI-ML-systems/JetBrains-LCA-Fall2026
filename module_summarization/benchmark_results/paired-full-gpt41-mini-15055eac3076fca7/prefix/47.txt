Contingency Tables Module
=========================

Overview
--------

This module provides methods for analyzing two-way contingency tables, which are frequency tables for observations cross-classified with respect to two categorical variables. It includes classes and functions designed to handle general two-way tables, square tables, 2x2 tables, and collections of 2x2 tables, as well as statistical tests commonly used in categorical data analysis.

Main Classes
------------

- **Table**

  Represents a general two-way contingency table. Provides methods applicable to any two-way table, including tests for nominal and ordinal association.

- **SquareTable**

  Extends functionality for square two-way contingency tables (where the number of rows equals the number of columns).

- **Table2x2**

  Specialized methods for 2x2 contingency tables.

- **StratifiedTable**

  Methods for analyzing collections of 2x2 contingency tables, useful for stratified analysis.

Functions
----------

- **McNemar's Test**

  Conducts McNemar's test for paired nominal data.

- **Cochran's Q Test**

  Performs Cochran's Q test for related samples.

Key Features and Notes
----------------------

- The module assumes that observed units are independent and identically distributed.

- Inference procedures depend on the sampling model and the nature of the data.

- The `Table` class supports construction from raw data or from existing frequency tables.

- Zero cell counts can be adjusted by adding 0.5 to all cells to avoid issues in statistical calculations.

- Provides methods for testing nominal association (chi-square test of independence) and ordinal association (linear-by-linear association test).

Detailed Description
---------------------

### Table Class

The `Table` class encapsulates a two-way contingency table and provides methods for statistical analysis.

**Initialization**

- `table` : array-like  
  The contingency table data.

- `shift_zeros` : bool, optional (default=True)  
  If True and any cell count is zero, adds 0.5 to all values in the table to avoid zero counts.

**Attributes**

- `table_orig` : array-like  
  The original input table before any modifications.

**Methods**

- `from_data(data, shift_zeros=True)`  
  Class method to create a `Table` instance from raw data. The first two columns of the data are used to construct the contingency table.

- `test_nominal_association()`  
  Performs a chi-square test of independence treating rows and columns as nominal (unordered) categorical variables. Returns a result object containing the test statistic, degrees of freedom, and p-value.

- `test_ordinal_association(row_scores=None, col_scores=None)`  
  Performs a test for association between two ordinal variables using the linear-by-linear association test. (Note: method implementation is partial in the provided code.)

Helper Functions and Classes
----------------------------

- `_make_df_square(table)`  
  Utility function to reindex a pandas DataFrame so that it becomes square, ensuring that row and column indices contain the same values in the same order.

- `_Bunch`  
  A simple container class used to store and display test results in an organized manner.

Usage Notes
-----------

- The module is designed for categorical data analysis where the data consist of independent observations classified by two categorical variables.

- When zero counts are present in the contingency table, adding 0.5 to all cells (continuity correction) can improve the stability of statistical tests.

- The inference methods assume a sampling model with independent and identically distributed units.

This module is a valuable tool for statisticians and data analysts working with categorical data, providing both general and specialized methods for contingency table analysis.
