SESANS Fitting Guide
====================

Overview
--------

Spin-Echo Small Angle Neutron Scattering (SESANS) is a powerful technique used to probe the structure of materials at the nanoscale. Fitting SESANS data involves modeling the scattering behavior to extract meaningful physical parameters.

This guide provides an introduction to fitting SESANS data using available models and parameters, along with tools to explore model parameters and their usage.

Listing Model Parameters
------------------------

To effectively fit SESANS data, it is important to understand the parameters involved in the scattering models. The `sasmodels` package provides utilities to list all parameters used across different models.

You can list all parameters and the models that use them by running:

```bash
python -m sasmodels.list_pars [-v] [kind]
```

- `-v` or `--verbose`: Lists the models that use each parameter.
- `kind`: Filters parameters by type. Possible values are:
  - `volume`
  - `orientation`
  - `sld` (scattering length density)
  - `none`
  - `any` (default, lists all parameters)

For example, to list all parameters related to volume:

```bash
python -m sasmodels.list_pars volume
```

This command helps identify which parameters are relevant for your fitting task.

Parameter Table
---------------

The utility internally builds a reference table mapping each parameter to the models that use it. This allows users to quickly find which parameters are available and applicable for their SESANS fitting.

Fitting Workflow
----------------

1. **Select a Model**: Choose a scattering model appropriate for your sample and experimental setup.

2. **Identify Parameters**: Use the parameter listing tool to understand the parameters involved in the model.

3. **Prepare Data**: Load your SESANS data ensuring it is properly formatted.

4. **Fit the Model**: Use fitting routines (not covered here) to adjust model parameters to best match your data.

5. **Analyze Results**: Interpret the fitted parameters to gain insights into the sample structure.

Additional Notes
----------------

- The parameter listing tool supports filtering by parameter kind, which can be useful to focus on specific physical aspects such as volume or orientation.

- The models and parameters are continuously updated; refer to the latest documentation and model lists for up-to-date information.

- The fitting process may require iterative refinement and consideration of parameter constraints to achieve meaningful results.
