Configurations Options
======================

The `ConfigurationsOptions` class provides a comprehensive set of options to control the import and export behavior of various components within a project configuration. This allows users to enable or disable the serialization and deserialization of specific elements such as variables, setups, optimizations, parametrics, boundaries, mesh operations, coordinate systems, materials, object properties, and datasets.

Class: ConfigurationsOptions
----------------------------

### Overview

This class encapsulates configuration options that govern how project data is exported to or imported from JSON files. It is designed to give fine-grained control over which components are included during these operations, facilitating customized workflows and data management.

### Properties

- **object_mapping_tolerance** (`float`)

  Specifies the tolerance value used in object mapping processes, such as when matching boundaries. This tolerance helps determine how closely objects must align to be considered equivalent during import/export operations.

  **Default:** `1e-9`

  **Example:**

  ```python
  config_options = ConfigurationsOptions()
  config_options.object_mapping_tolerance = 1e-6
  ```

- **export_variables** (`bool`)

  Determines whether variables are exported to the JSON configuration file.

  **Default:** `True`

  **Example:**

  ```python
  from pyaedt import Hfss
  hfss = Hfss()
  hfss.configurations.options.export_variables = False  # Disable variables export
  ```

- **export_setups** (`bool`)

  Controls whether setups are included in the exported JSON file.

  **Default:** `True`

  **Example:**

  ```python
  from pyaedt import Hfss
  hfss = Hfss()
  hfss.configurations.options.export_setups = False  # Disable setups export
  ```

- **export_optimizations** (`bool`)

  Enables or disables the export of optimization setups.

  **Default:** `True`

- **export_parametrics** (`bool`)

  Enables or disables the export of parametric setups.

  **Default:** `True`

- **export_boundaries** (`bool`)

  Controls the export of boundary conditions.

  **Default:** `True`

- **export_mesh_operations** (`bool`)

  Determines if mesh operations are exported.

  **Default:** `True`

- **export_coordinate_systems** (`bool`)

  Controls the export of coordinate systems.

  **Default:** `True`

- **export_materials** (`bool`)

  Enables or disables the export of material definitions.

  **Default:** `True`

- **export_object_properties** (`bool`)

  Controls whether object properties are exported.

  **Default:** `True`

- **export_datasets** (`bool`)

  Determines if datasets are included in the export.

  **Default:** `True`

- **import_datasets** (`bool`)

  Enables or disables the import of datasets from JSON files.

  **Default:** `True`

- **import_variables** (`bool`)

  Controls the import of variables.

  **Default:** `True`

- **import_setups** (`bool`)

  Enables or disables the import of setups.

  **Default:** `True`

- **import_optimizations** (`bool`)

  Controls the import of optimization setups.

  **Default:** `True`

- **import_parametrics** (`bool`)

  Enables or disables the import of parametric setups.

  **Default:** `True`

- **import_boundaries** (`bool`)

  Controls the import of boundary conditions.

  **Default:** `True`

- **import_mesh_operations** (`bool`)

  Enables or disables the import of mesh operations.

  **Default:** `True`

- **import_coordinate_systems** (`bool`)

  Controls the import of coordinate systems.

  **Default:** `True`

- **import_materials** (`bool`)

  Enables or disables the import of materials.

  **Default:** `True`

- **import_object_properties** (`bool`)

  Controls whether object properties are imported.

  **Default:** `True`

- **skip_import_if_exists** (`bool`)

  If set to `True`, existing objects will not be overwritten during import.

  **Default:** `False`

### Internal Function: _find_datasets

The `_find_datasets` function is a utility that recursively searches through nested dictionaries to identify dataset references, particularly those involving piecewise linear (PWL) data. It collects dataset identifiers found within the data structure, which can be used during export or import processes to manage dataset dependencies.

**Parameters:**

- `d` (`dict`): The dictionary to search through.
- `out_list` (`list`): A list to which found dataset identifiers are appended.

**Usage:**

This function is primarily used internally to extract dataset references from complex configuration data structures.
