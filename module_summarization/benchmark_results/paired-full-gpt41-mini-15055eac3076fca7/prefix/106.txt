Hyperexpand Module
==================

Overview
--------

The `hyperexpand` module provides functionality to expand hypergeometric functions, including Meijer G functions, into named special functions. This expansion is achieved through a collection of lookup tables and properties of hypergeometric functions, enabling the transformation of many hypergeometric functions into simpler or more recognizable special functions.

This module is based on the algorithm described in the paper:

- Kelly B. Roach. *Meijer G Function Representations*.  
  Proceedings of the 1997 International Symposium on Symbolic and Algebraic Computation, pages 205-211, New York, 1997. ACM.

The detailed explanation and usage of this module are further documented in the Sphinx documentation.

Key Concepts and Features
-------------------------

- **Expansion of Hypergeometric Functions:**  
  The module uses a knowledge base of formulas and properties to rewrite hypergeometric functions in terms of special functions.

- **Meijer G Function Extensions:**  
  The module supports various transformations and reductions of Meijer G functions, including:
  
  - Parameter shifts:  
    \( z^\rho G^{m,n}_{p,q}(\mathbf{a_p}; \mathbf{b_q}; z) = G^{m,n}_{p,q}(\mathbf{a_p} + \rho; \mathbf{b_q} + \rho; z) \)
  
  - Differential operators:  
    Using the operator \( D = z \frac{d}{dz} \), four shift operators are defined to increment or decrement parameters of the Meijer G function:
    
    - \( A_J = b_J - D \), for \( J = 1, \ldots, n \)
    - \( B_J = 1 - a_j + D \), for \( j = 1, \ldots, m \)
    - \( C_J = -b_J + D \), for \( J = m+1, \ldots, q \)
    - \( D_J = a_J - 1 - D \), for \( J = n+1, \ldots, p \)
  
  - Order reduction:  
    When certain parameter differences are non-negative integers, the order of the Meijer G function can be reduced, simplifying the expression.
  
  - Reachability and index quadruples:  
    The module considers sequences of shift operators to determine if one parameter set can be transformed into another, aiding in formula matching and instantiation.

- **Formula Collection:**  
  The module maintains a collection of formulas (`FormulaCollection`) that represent known expansions. These formulas are used to generate the documentation and to perform expansions programmatically.

Usage
-----

When imported, the module automatically generates a documentation string containing LaTeX-rendered formulas representing the expansions available in the knowledge base. This docstring is intended for display in Sphinx-generated documentation.

Implementation Details
----------------------

- The module imports core symbolic computation classes and functions such as `Eq`, `symbols`, and special functions like `hyper` and `meijerg`.
- It defines helper functions such as `_mod1` to handle modular arithmetic on parameters.
- The `add_formulae` function is used internally to populate the knowledge base with known expansions.
- The module relies on symbolic manipulation capabilities to rewrite hypergeometric functions into closed forms using the `rewrite` method.
- The code includes detailed comments summarizing the mathematical background and algorithmic approach for handling Meijer G functions.
