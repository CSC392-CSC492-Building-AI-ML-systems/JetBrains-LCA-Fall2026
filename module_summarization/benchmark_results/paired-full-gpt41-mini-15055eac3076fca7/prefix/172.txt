SANS to SESANS Conversion
=========================

This document provides an overview of the conversion between Small-Angle Neutron Scattering (SANS) and Spin-Echo Small-Angle Neutron Scattering (SESANS) techniques. The conversion involves mathematical transformations that relate the scattering intensity measured in SANS to the spin-echo polarization measured in SESANS.

Overview
--------

SANS measures the scattering intensity as a function of the scattering vector \( q \), providing information about the structure of materials on the nanoscale. SESANS, on the other hand, measures the spin-echo polarization as a function of the spin-echo length \( z \), which is related to the real-space correlation function of the sample.

The conversion between SANS and SESANS data requires the use of integral transforms involving special functions, particularly elliptic integrals and Jacobi elliptic functions. These mathematical tools enable the transformation of scattering data from reciprocal space (SANS) to real space (SESANS).

Mathematical Background
-----------------------

### Elliptic Functions and Integrals

The conversion relies on elliptic functions such as the Jacobi elliptic functions \(\mathrm{sn}(u|m)\), \(\mathrm{cn}(u|m)\), and \(\mathrm{dn}(u|m)\), and elliptic integrals of the first kind \( F(\phi|m) \). These functions are used to describe the mapping between angular coordinates and the spin-echo length.

The Jacobi elliptic functions are defined for complex arguments and parameter \( m \), and are computed using specialized numerical libraries such as SciPy's `scipy.special.ellipj` and `scipy.special.ellipkinc`.

### Conversion Functions

- **EllipticJi(u, v, m):**  
  Computes the Jacobi elliptic functions \(\mathrm{sn}\), \(\mathrm{cn}\), and \(\mathrm{dn}\) for a complex argument \( u + iv \) with parameter \( m \). This function handles real, imaginary, and mixed inputs efficiently by broadcasting arrays and applying appropriate sub-functions.

- **_ellipticJi_real(u, m):**  
  Computes the Jacobi elliptic functions for real arguments.

- **_ellipticJi_imag(v, m):**  
  Computes the Jacobi elliptic functions for purely imaginary arguments.

These functions form the mathematical core for transforming SANS intensity data into SESANS polarization data.

Usage
-----

The conversion process typically involves the following steps:

1. **Load SANS Model Parameters:**  
   Identify and load the parameters of the scattering model relevant to the sample under study. Parameters may include volume, orientation, and scattering length density (SLD).

2. **Compute Elliptic Functions:**  
   Use the elliptic function implementations to calculate the necessary transforms for the given parameters.

3. **Perform Integral Transforms:**  
   Apply the integral transforms that relate the SANS intensity \( I(q) \) to the SESANS polarization \( P(z) \). This often involves numerical integration and evaluation of special functions.

4. **Interpret SESANS Data:**  
   Analyze the resulting SESANS polarization to extract real-space structural information about the sample.

Command-Line Interface
----------------------

A utility is provided to list all parameters used across different scattering models, which can assist in selecting appropriate parameters for the conversion:

```bash
python -m sasmodels.list_pars [-v] [kind]
```

- `-v` or `--verbose`: Lists the models that use each parameter.
- `kind`: Filters parameters by type, such as `volume`, `orientation`, `sld`, or `none`.

Example:

```bash
python -m sasmodels.list_pars -v volume
```

This command lists all volume-related parameters along with the models that use them.
