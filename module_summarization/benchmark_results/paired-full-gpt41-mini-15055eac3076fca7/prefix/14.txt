Querying
========

The `Session` class in the ftrack API provides a powerful interface for interacting with an ftrack server, including the ability to query entities and their attributes efficiently.

Querying Entities
-----------------

Entities in ftrack represent the core objects such as projects, tasks, assets, and users. You can query these entities through the `Session` object, which acts as an isolated connection to the ftrack server.

### Basic Querying

To query entities, you typically use the `query()` method available on the `Session` instance. This method allows you to specify a query string using a simple query language to filter entities based on their attributes.

Example:

```python
session = ftrack_api.Session()
tasks = session.query('Task where status is "in progress"')
for task in tasks:
    print(task['name'], task['status'])
```

This example retrieves all tasks whose status is "in progress".

### Query Language

The query language supports filtering entities using conditions on their attributes. Common operators include:

- `is` — equality comparison
- `is not` — inequality comparison
- `in` — membership in a list or set
- `not in` — exclusion from a list or set
- Logical operators such as `and`, `or`, and `not`

You can combine multiple conditions to refine your queries.

### Lazy Loading and Auto-Populate

By default, the `Session` is configured with `auto_populate=True`. This means that when you access attributes of an entity that have not yet been fetched, the session will automatically retrieve them from the server. This behavior ensures that your queries and subsequent attribute accesses are efficient and transparent.

### Caching

The session supports caching of queried data to improve performance. You can provide a custom cache implementation or rely on the default layered cache, which includes an in-memory cache for fast access.

### Example: Querying Projects and Their Tasks

```python
session = ftrack_api.Session()

# Query all projects
projects = session.query('Project')

for project in projects:
    print('Project:', project['name'])
    # Query tasks related to the project
    tasks = session.query('Task where project.id is "{}"'.format(project['id']))
    for task in tasks:
        print('  Task:', task['name'], '-', task['status'])
```

### Notes

- Queries are executed against the server and return collections of entities matching the criteria.
- The `Session` class handles authentication and connection details transparently.
- You can extend querying capabilities by using plugins and custom attributes.

For more detailed information on querying syntax and advanced usage, refer to the ftrack API documentation and the `ftrack_api.query` module.
