==========================
Duration Analysis Utilities
==========================

This module provides functions for survival and incidence function estimation commonly used in duration or survival analysis. The implementations handle right-censored data and allow for weighted observations and delayed entry.

Functions
---------

_calc_survfunc_right(time, status, weights=None, entry=None, compress=True, retall=True)
    Calculate the survival function and its standard error for a single group.

    Parameters
    ----------
    time : array_like
        Event or censoring times.
    status : array_like
        Event indicator (1 if event occurred, 0 if censored).
    weights : array_like, optional
        Observation weights. Default is None.
    entry : array_like, optional
        Entry times for delayed entry (left truncation). Default is None.
    compress : bool, optional
        If True, only retain times where an event occurred. Default is True.
    retall : bool, optional
        If True, return additional intermediate results. Default is True.

    Returns
    -------
    sp : ndarray
        Estimated survival probabilities at unique event times.
    se : ndarray
        Standard errors of the survival probabilities.
    utime : ndarray
        Unique event times.
    rtime : ndarray
        Integer indices mapping original times to unique times.
    n : ndarray
        Risk set sizes just prior to each event time.
    d : ndarray
        Number of events at each unique time.

_calc_incidence_right(time, status, weights=None)
    Calculate the cumulative incidence function and its standard error for competing risks data.

    Parameters
    ----------
    time : array_like
        Event or censoring times.
    status : array_like
        Event type indicators (0 for censored, 1, 2, ... for different causes).
    weights : array_like, optional
        Observation weights. Default is None.

    Returns
    -------
    ip : list of ndarray
        List of cumulative incidence function estimates for each cause.
    se : list of ndarray or None
        Standard errors of the cumulative incidence functions for each cause.
        Returns None if weights are provided.
    utime : ndarray
        Unique event times.

Description
-----------

The survival function estimation (_calc_survfunc_right) uses the Kaplan-Meier estimator with Greenwood's formula for standard errors when no weights are provided. When weights are present, Tsiatis' formula is used for variance estimation. The function supports delayed entry (left truncation) and can compress the output to only event times.

The cumulative incidence function estimation (_calc_incidence_right) computes cause-specific cumulative incidence functions in the presence of competing risks. It internally calls the survival function estimator for the all-cause survival function and then calculates cause-specific event probabilities and their standard errors using established formulas.

These utilities are foundational for duration analysis, enabling estimation of survival probabilities and competing risks incidence in observational studies with censoring and truncation.
