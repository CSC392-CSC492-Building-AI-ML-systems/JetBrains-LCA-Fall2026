Generate Documentation for This Module
======================================

This module provides command functions for managing Alembic migration environments and revisions. The commands include listing available templates, initializing a new migration environment, and creating new revision files.

Functions
---------

list_templates(config: Config)  
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  
List available migration environment templates.

- **Parameters**:  
  - `config` (:class:`.Config`): The Alembic configuration object.

- **Description**:  
  Prints the list of available templates found in the template directory configured in `config`. For each template, it displays the template name and a brief synopsis extracted from the template's README file. Also provides an example of how to use templates with the `init` command.

init(config: Config, directory: str, template: str = "generic", package: bool = False) -> None  
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  
Initialize a new Alembic scripts directory.

- **Parameters**:  
  - `config` (:class:`.Config`): The Alembic configuration object.  
  - `directory` (str): The target directory path where the migration environment will be created.  
  - `template` (str, optional): The name of the migration environment template to use. Defaults to `"generic"`.  
  - `package` (bool, optional): If `True`, writes `__init__.py` files into the environment directory and the versions directory to make them Python packages. Defaults to `False`.

- **Description**:  
  Creates a new migration environment directory structure at the specified location. It verifies that the target directory does not already exist or is empty. It copies files from the specified template directory into the new environment directory, including generating the `alembic.ini` configuration file if it does not already exist. If `package` is `True`, it adds `__init__.py` files to the environment and versions directories. Finally, it prompts the user to edit the configuration file before proceeding.

revision(  
    config: Config,  
    message: Optional[str] = None,  
    autogenerate: bool = False,  
    sql: bool = False,  
    head: str = "head",  
    splice: bool = False,  
    branch_label: Optional[str] = None,  
    version_path: Optional[str] = None,  
    rev_id: Optional[str] = None,  
    depends_on: Optional[str] = None,  
    process_revision_directives: Optional[ProcessRevisionDirectiveFn] = None  
) -> Union[Optional[Script], List[Optional[Script]]]  
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  
Create a new Alembic revision file.

- **Parameters**:  
  - `config` (:class:`.Config`): The Alembic configuration object.  
  - `message` (Optional[str]): The message string to apply to the revision (corresponds to the `-m` option).  
  - `autogenerate` (bool): Whether to autogenerate the revision script from the database schema (corresponds to the `--autogenerate` option).  
  - `sql` (bool): Whether to output the revision script as SQL to stdout instead of writing a file (corresponds to the `--sql` option).  
  - `head` (str): The head revision identifier to build the new revision upon (corresponds to the `--head` option). Defaults to `"head"`.  
  - `splice` (bool): Whether to create the new revision as a new head, required if the specified `head` is not itself a head (corresponds to the `--splice` option).  
  - `branch_label` (Optional[str]): Label for the branch this revision belongs to.  
  - `version_path` (Optional[str]): Path to place the revision file within the versions directory.  
  - `rev_id` (Optional[str]): Explicit revision identifier to use for the new revision.  
  - `depends_on` (Optional[str]): Revision identifier that this revision depends on.  
  - `process_revision_directives` (Optional[ProcessRevisionDirectiveFn]): A callable to process revision directives during revision generation.

- **Returns**:  
  - A single `Script` object or a list of `Script` objects representing the created revision(s), or `None` if no revision was created.

- **Description**:  
  Generates a new migration revision file according to the specified parameters. Supports autogeneration of migration scripts, SQL output mode, branching, and revision dependencies. This function is the core of Alembic's revision creation command.

Usage Notes
-----------

- Templates listed by `list_templates` are used with the `init` command to create new migration environments.
- The `init` command ensures the target directory is suitable and copies necessary files from the chosen template.
- The `revision` command supports a variety of options to customize the creation of migration scripts, including autogeneration and SQL output.
- Proper configuration editing is recommended after initialization before running migrations.

This module is intended to be used as part of Alembic's command-line interface or programmatically to manage database schema migrations.
