Polynomial Factorization Routines
==================================

This module provides routines for factorization of polynomials over characteristic zero domains, with a focus on integer polynomials and algebraic number fields. It includes implementations of classical algorithms such as trial division, Zassenhaus factorization, and specialized methods for multivariate polynomials.

Overview
--------

The factorization routines are encapsulated in a mixin class `_Factor` which can be used to extend polynomial classes with factorization capabilities. The methods handle both univariate and multivariate polynomials, supporting factorization over integers (`Z[X]`) and algebraic number fields.

Key Classes and Methods
-----------------------

### Class `_Factor`

Mixin class providing factorization methods.

#### `_trial_division(self, f, factors)`

Performs trial division of polynomial `f` by a list of candidate `factors`. Returns a list of tuples `(factor, multiplicity)` representing the factorization of `f` with respect to the given factors.

#### `_aa_factor_trager(self, f)`

Factors multivariate polynomials over algebraic number fields using Trager's algorithm. The polynomial `f` is first made monic and square-free, then factored by norm computations and factor lifting. Returns the leading coefficient and a list of irreducible factors with their multiplicities.

#### `_zz_factor(self, f)`

Factors polynomials in `Z[X]`, including non-square-free polynomials. The method computes the complete factorization of a multivariate polynomial `f` into irreducibles over the integers:

.. math::

    f = \mathrm{content}(f) \cdot f_1^{k_1} \cdots f_n^{k_n}

The algorithm reduces the polynomial to a primitive square-free polynomial and factors it using Zassenhaus or Enhanced Extended Zassenhaus (EEZ) algorithms. Trial division is used to recover multiplicities.

Returns a tuple `(content(f), [(f_1, k_1), ..., (f_n, k_n)])`.

**Examples:**

```python
_, x = ring('x', ZZ)
(2*x**4 - 2).factor_list()
# Output: (2, [(x - 1, 1), (x + 1, 1), (x**2 + 1, 1)])

_, x, y = ring('x y', ZZ)
(2*x**2 - 2*y**2).factor_list()
# Output: (2, [(x - y, 1), (x + y, 1)])
```

**References:**

- Gathen, J. von zur, & Gerhard, J. (1999). *Modern Computer Algebra*. Cambridge University Press.

Additional Details
------------------

- The `_zz_factor` method handles both univariate and multivariate polynomials by recursively factoring after primitive part extraction and variable elimination.
- The method uses configurable queries such as `USE_IRREDUCIBLE_IN_FACTOR` and `USE_CYCLOTOMIC_FACTOR` to optimize factorization by checking irreducibility or factoring out cyclotomic polynomials.
- Trial division is extensively used to verify and extract multiplicities of factors.
- The factorization routines rely on auxiliary functions and classes imported from related modules such as `ntheory`, `polyerrors`, and `polyutils`.

Notes
-----

- The code assumes polynomials are defined over domains supporting arithmetic and factorization operations.
- The factorization methods are designed for characteristic zero fields and integer polynomial rings.
- Error handling is implemented via custom exceptions like `CoercionFailedError`, `DomainError`, and `ExtraneousFactorsError`.

This module forms a foundational component for symbolic polynomial manipulation and factorization in algebraic computation systems.
