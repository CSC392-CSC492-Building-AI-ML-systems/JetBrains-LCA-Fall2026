Contributing to Qiskit Metal
============================

Welcome to the Qiskit Metal contributor guide! We appreciate your interest in contributing to Qiskit Metal, an open-source framework for designing superconducting quantum devices.

Code Structure and Documentation
--------------------------------

Qiskit Metal is organized into several modules and submodules. For example, the `qiskit_metal.analyses` module contains analysis tools such as CPW (coplanar waveguide) calculations and lumped capacitive quantization.

Each module and function is documented with clear docstrings that describe their purpose, authorship, and usage. When contributing new code, please include comprehensive docstrings following the existing style to maintain consistency and clarity.

Example modules include:

- **Analyses** (`qiskit_metal.analyses`): Contains tools for electromagnetic and quantization analyses.
- **CPW Calculations** (`qiskit_metal.analyses.em.cpw_calculations`): Provides functions to calculate guided wavelengths and lumped element equivalents of CPW transmission lines, based on established scientific literature.
- **Lumped Capacitive Quantization** (`qiskit_metal.analyses.quantization.lumped_capacitive`): Tools for quantization analysis.

Coding Guidelines
-----------------

- Follow Python best practices and style guidelines (PEP 8).
- Include detailed docstrings for all public functions and classes.
- Write clear, maintainable, and well-tested code.
- Use meaningful variable and function names.
- Ensure that your code passes existing tests and add new tests for your contributions where applicable.

Submitting Contributions
------------------------

1. Fork the Qiskit Metal repository.
2. Create a feature branch for your changes.
3. Commit your changes with clear and descriptive commit messages.
4. Push your branch to your fork.
5. Open a pull request against the main Qiskit Metal repository.

Please describe the purpose of your changes and any relevant details in your pull request.

Testing
-------

Qiskit Metal includes automated tests to ensure code quality and correctness. Before submitting your contribution:

- Run all existing tests to verify that your changes do not break existing functionality.
- Add new tests to cover your changes.
- Ensure tests pass on supported platforms.

Support and Communication
-------------------------

For questions, discussions, or help with contributions, please use the Qiskit Metal community channels, such as the Qiskit Slack workspace or the GitHub issues page.
