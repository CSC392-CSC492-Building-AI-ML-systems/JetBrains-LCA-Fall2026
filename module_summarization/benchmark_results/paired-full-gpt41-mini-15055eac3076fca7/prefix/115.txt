Config Module
=============

This module provides methods for getting and setting global configuration options for ASDF (Advanced Scientific Data Format). It includes the `AsdfConfig` class, which acts as a container for ASDF configuration options, as well as utility functions to access and modify the global configuration.

AsdfConfig Class
----------------

The `AsdfConfig` class encapsulates configuration options for ASDF. Users typically do not instantiate this class directly; instead, they use the module-level functions `get_config` and `config_context` to access and modify the global configuration.

### Attributes and Properties

- **resource_mappings**  
  Returns the list of registered resource mapping instances. Unless overridden by user configuration, this list contains every mapping registered with an entry point.  
  **Type:** list of `asdf.resource.ResourceMappingProxy`

- **resource_manager**  
  Returns the `asdf.resource.ResourceManager` instance, which includes resources from registered resource mappings and any mappings added at runtime.  
  **Type:** `asdf.resource.ResourceManager`

- **extensions**  
  Returns the list of registered extensions.  
  **Type:** list of `asdf.extension.ExtensionProxy`

- **_validate_on_read**  
  Boolean flag indicating whether validation should be performed when reading ASDF files. Defaults to `True`.

- **_default_version**  
  The default ASDF version to use. Defaults to the version specified by `versioning.default_version`.

- **_legacy_fill_schema_defaults**  
  Boolean flag controlling legacy behavior for filling schema defaults. Defaults to `True`.

- **_io_block_size**  
  Integer specifying the block size for I/O operations. Defaults to `-1` (automatic).

- **_array_inline_threshold**  
  Threshold for inlining arrays. Defaults to `None`.

### Methods

- **add_resource_mapping(mapping)**  
  Registers a new resource mapping. The new mapping takes precedence over all previously registered mappings.  
  **Parameters:**  
  `mapping` : collections.abc.Mapping  
  A mapping of resource URI strings to bytes content.

- **remove_resource_mapping(mapping=None, *, package=None)**  
  Removes a registered resource mapping. At least one of `mapping` or `package` must be specified.  
  **Parameters:**  
  - `mapping` (optional): The mapping to remove.  
  - `package` (optional): Remove all mappings provided by this package if `mapping` is omitted.

- **reset_resources()**  
  Resets registered resource mappings to the default list provided as entry points.

Thread Safety
-------------

The `AsdfConfig` class uses a reentrant lock (`threading.RLock`) to ensure thread-safe access and modification of its internal state.

Usage Notes
-----------

- The global ASDF configuration should be accessed via the `get_config()` function.
- Temporary changes to the configuration can be made using the `config_context()` context manager.
- Resource mappings and extensions are automatically discovered via entry points but can be modified at runtime using the provided methods.

Constants
---------

- `DEFAULT_VALIDATE_ON_READ` : Default value for validation on read (True).
- `DEFAULT_DEFAULT_VERSION` : Default ASDF version string.
- `DEFAULT_LEGACY_FILL_SCHEMA_DEFAULTS` : Default flag for legacy schema defaults (True).
- `DEFAULT_IO_BLOCK_SIZE` : Default I/O block size (-1 for automatic).
- `DEFAULT_ARRAY_INLINE_THRESHOLD` : Default threshold for array inlining (None).

Summary
-------

This module centralizes configuration management for ASDF, allowing users to customize resource mappings, extensions, validation behavior, and other settings in a thread-safe manner. It supports dynamic modification of configuration options and integrates with ASDF's plugin system through entry points.
