Examples and Usage
==================

The `Field` class serves as the base type for all field definitions in Tortoise ORM models. It provides a flexible and extensible way to define database columns with various options and behaviors.

Basic Usage
-----------

When defining a model, you typically subclass `tortoise.models.Model` and declare fields as class attributes using subclasses of `Field`. Here is a simple example:

.. code-block:: python

    from tortoise import fields, models

    class User(models.Model):
        id = fields.IntField(pk=True)
        username = fields.CharField(max_length=50, unique=True)
        email = fields.CharField(max_length=255, null=True)
        is_active = fields.BooleanField(default=True)

Field Parameters
----------------

- **source_field**: Use this to specify a custom database column name if it differs from the attribute name.
- **generated**: Set to True if the field value is generated by the database (e.g., auto-increment).
- **pk**: Marks the field as the primary key. Only one primary key is allowed per model.
- **null**: Allows the field to be nullable in the database.
- **default**: Provides a default value or callable for the field if none is specified on model creation.
- **unique**: Enforces uniqueness on the field.
- **index**: Creates a database index on the field.
- **description**: Adds a description to the field, which appears in schema introspection and database comments.

Example with Various Field Options
----------------------------------

.. code-block:: python

    class Product(models.Model):
        sku = fields.CharField(max_length=20, unique=True, description="Stock Keeping Unit")
        name = fields.CharField(max_length=100, index=True)
        price = fields.DecimalField(max_digits=10, decimal_places=2, default=0.00)
        created_at = fields.DatetimeField(auto_now_add=True, generated=True)
        discontinued = fields.BooleanField(default=False, null=False)

Per-Database Customization
--------------------------

You can customize field behavior and SQL types for specific database backends by defining an inner class named `_db__{SQL_DIALECT}` inside your field subclass. For example:

.. code-block:: python

    class CustomCharField(fields.CharField):
        class _db__sqlite:
            SQL_TYPE = "VARCHAR(40)"
            skip_to_python_if_native = False

            def function_cast(self, term):
                from pypika import functions
                return functions.Cast(term, "NUMERIC")

This allows you to override SQL types, casting behavior, and other attributes on a per-database basis.

Field Meta-Class Behavior
-------------------------

The `_FieldMeta` metaclass automatically sets the `field_type` attribute based on mixin classes used when defining new field types. This helps with type inference and validation.

Error Handling
--------------

The `Field` constructor raises a `ConfigurationError` if incompatible options are provided, such as setting both `pk=True` and `null=True`, or attempting to index a non-indexable field.

Summary
-------

The `Field` base class is designed to be extended for specific field types (e.g., `IntField`, `CharField`, `BooleanField`) and provides a rich set of options for defining database columns with precise control over behavior, indexing, uniqueness, and database-specific customizations. Use it as the foundation for building your model schema in Tortoise ORM.
