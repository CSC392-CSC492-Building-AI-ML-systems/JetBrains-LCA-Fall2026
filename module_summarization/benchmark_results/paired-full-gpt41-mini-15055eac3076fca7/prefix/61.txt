Generate documentation for the `sqlalchemy.orm.instrumentation` module
=========================================================================

Overview
--------

The `instrumentation` module defines SQLAlchemy's system of class instrumentation, which is a core part of the ORM's interactivity and state tracking mechanism. Although this module is typically not directly accessed by user applications, it plays a crucial role in managing the lifecycle and behavior of ORM-mapped classes.

This module handles the registration of end-user classes for state tracking and works closely with related modules such as `state.py` and `attributes.py` to establish per-instance and per-class-attribute instrumentation respectively.

Key Concepts
------------

- **Class Instrumentation**: The process by which SQLAlchemy tracks and manages the state of ORM-mapped classes. This includes monitoring attribute changes, managing instance state, and coordinating with the session.

- **ClassManager**: The central class in this module responsible for tracking state information at the class level. It manages the instrumentation of a particular class, including its attributes and event dispatching.

- **Event Dispatching**: The `ClassManager` inherits from `EventTarget` and provides an event dispatch system that allows hooking into various lifecycle events of ORM classes.

- **Expired Attribute Loader**: A callable used to load expired or deferred attributes on instances, previously known as `deferred_scalar_loader`.

Customization
-------------

The class instrumentation system can be customized on a per-class or global basis using the `sqlalchemy.ext.instrumentation` extension module. This extension provides mechanisms to build and specify alternate instrumentation forms, allowing advanced users to tailor the ORM's behavior to their needs.

Version Changes
---------------

- Since version 0.8, the instrumentation extension system was moved out of the core ORM package into the external `sqlalchemy.ext.instrumentation` package. When this package is imported, it installs itself within `sqlalchemy.orm` to provide more comprehensive resolution mechanics.

Important Classes and Interfaces
-------------------------------

### ClassManager[_O]

- Tracks state information at the class level for ORM-mapped classes.
- Inherits from `HasMemoized`, `Dict[str, QueryableAttribute[Any]]`, `Generic[_O]`, and `EventTarget`.
- Manages event dispatching for class-level events.
- Maintains references to the managed class, its base class managers, and instrumentation-related metadata.
- Provides properties and methods to manage expired attribute loading and initialization hooks.
- Integrates with the event system to propagate events through the class hierarchy.

### _ExpiredAttributeLoaderProto

- A protocol defining the callable signature for expired attribute loaders.
- Responsible for loading expired attributes on instances when accessed.

Usage Notes
-----------

- The `ClassManager` is typically instantiated internally by SQLAlchemy when ORM classes are mapped.
- Users generally interact with instrumentation indirectly through the ORM's public API.
- Advanced customization and extension of instrumentation behavior should be done via the `sqlalchemy.ext.instrumentation` module.
