w_pdist — Calculate time-resolved, multi-dimensional probability distributions of WE datasets
===============================================================================================

Description
-----------

The `w_pdist` command calculates time-resolved, multi-dimensional probability distributions of Weighted Ensemble (WE) datasets.

Source data
-----------

Source data can be provided in one of the following ways:

- **User-specified function** (`--construct-dataset`):  
  Specify a Python function in `MODULE.FUNCTION` syntax that extracts or calculates the data whose probability distribution will be computed. The function is called as `function(n_iter, iter_group)`, where `n_iter` is the iteration number and `iter_group` is the corresponding group in the main WEST HDF5 file (`west.h5`). The function must return data indexable as `[segment][timepoint][dimension]`.

- **List of data set specifications** (`--dsspecs`):  
  Provide a list of dataset specifications formatted as `NAME[,file=FILENAME,slice=SLICE]`. This selects the dataset called `NAME` in the HDF5 file `FILENAME` (defaulting to the main WEST HDF5 file `west.h5`), optionally slicing it with the Python slice expression `SLICE` (e.g., `[0:2]` to select the first two elements along the first axis). This is useful for selecting specific columns from multi-column datasets, such as multi-dimensional progress coordinates.

- **Default dataset**:  
  If neither a custom function nor dataset specifications are provided, the default progress coordinate dataset `pcoord` is used.

Histogram binning
-----------------

Histograms are constructed by binning the data into discrete intervals. By default, 100 bins are used in each dimension. This can be customized with the `-b` or `--bins` option, which accepts several formats:

- **Single integer N**:  
  Use `N` uniformly spaced bins in each dimension.

- **Sequence of integers N1,N2,...**:  
  Use `N1` bins for the first dimension, `N2` for the second, and so on.

- **List of lists [[B11, B12, ...], [B21, B22, ...], ...]**:  
  Specify explicit bin boundaries for each dimension. These boundaries need not be uniformly spaced. The expressions are evaluated with Python's `eval` and have access to `np` (NumPy), allowing use of functions like `np.arange()`.

Note: The first two forms (integer or list of integers) require scanning all data to determine minimum and maximum values in each dimension, which can be computationally expensive for large datasets. Providing explicit bin boundaries avoids this overhead.

**Important:** These bins are unrelated to the bins used to drive WE sampling.

Output format
-------------

The output file (specified by `-o` or `--output`, default `"pdist.h5"`) contains the following datasets:

- **`histograms`**:  
  Normalized histograms with the first axis corresponding to iteration number and subsequent axes corresponding to data dimensions.

- **`/binbounds_0`, `/binbounds_1`, ...**:  
  Bin boundary vectors for each dimension.

- **`/midpoints_0`, `/midpoints_1`, ...**:  
  Bin midpoint vectors for each dimension.

- **`n_iter`**:  
  Vector of iteration numbers corresponding to the stored histograms.

This output can be used with the `plothist` program to generate plots or further processed as needed.

Subsequent processing
---------------------

The output file generated by `w_pdist` may be visualized using the `plothist` command. For more information, run:

```
plothist --help
```

Parallelization
---------------

`w_pdist` supports parallelized binning and input data reading. Parallel processing is enabled by default to improve performance on large datasets.

For simpler cases, such as reading pre-computed input data with a modest number of segments, serial processing can be enabled with the `--serial` option, which may be more efficient.

Command-line options
--------------------

Run `w_pdist --help` to see the full list of available command-line options and their descriptions.

Example usage
-------------

Calculate probability distributions using the default progress coordinate dataset and 50 bins per dimension, outputting to `my_pdist.h5`:

```
w_pdist -b 50 -o my_pdist.h5
```

Use a custom dataset construction function:

```
w_pdist --construct-dataset mymodule.myfunction -o custom_pdist.h5
```

Specify dataset specifications with slicing:

```
w_pdist --dsspecs pcoord,file=west.h5,slice=[0:2] -o sliced_pdist.h5
```
