# General Plotting Routines

This document provides an overview of the general plotting routines available in the Masci-tools package, focusing on interactive plotting using the Bokeh backend.

---

## Overview

The plotting routines utilize the `BokehPlotter` class to create interactive visualizations. The package provides functions to configure default plotting parameters, generate scatter plots, and manage plot appearance and behavior consistently.

---

## Setting and Managing Plot Defaults

The plotting routines allow customization of default plotting parameters for the Bokeh backend. These defaults control the appearance and behavior of plots and can be adjusted, reset, displayed, loaded from a file, or saved to a file.

### Functions

- **set_bokeh_plot_defaults(\*\*kwargs)**  
  Set default parameters for the Bokeh backend.  
  Parameters should correspond to those available in the `BokehPlotter` class.

- **reset_bokeh_plot_defaults()**  
  Reset all Bokeh plotting defaults to the original hardcoded values.

- **show_bokeh_plot_defaults()**  
  Display the currently set default parameters for the Bokeh backend.

- **get_bokeh_help(key)**  
  Print the description of a specific default parameter key in the Bokeh backend.

- **load_bokeh_defaults(filename='plot_bokeh_defaults.json')**  
  Load default plotting parameters from a JSON file.

- **save_bokeh_defaults(filename='plot_bokeh_defaults.json', save_complete=False)**  
  Save the current default plotting parameters to a JSON file.  
  If `save_complete` is `True`, both user-overwritten and hardcoded defaults are saved.

## General Plot Functions

### bokeh_scatter

```python
bokeh_scatter(x, y=None, *, xlabel='x', ylabel='y', title='', figure=None, data=None, saveas='scatter', copy_data=False, **kwargs)
```

Create an interactive scatter plot using Bokeh.

#### Parameters

- **x** (`array-like` or `str`): Data for the x-axis or key to extract from `data`.
- **y** (`array-like` or `str`, optional): Data for the y-axis or key to extract from `data`.
- **data** (`pandas.DataFrame` or similar, optional): Data source for the plot.
- **xlabel** (`str`, optional): Label for the x-axis. Default is `'x'`.
- **ylabel** (`str`, optional): Label for the y-axis. Default is `'y'`.
- **title** (`str`, optional): Title of the plot.
- **figure** (`bokeh.plotting.figure`, optional): If provided, the scatter plot will be added to this figure.
- **saveas** (`str`, optional): Filename prefix for saving the plot. Default is `'scatter'`.
- **copy_data** (`bool`, optional): If `True`, the data argument will be copied before plotting.
- **kwargs**: Additional keyword arguments passed to the `BokehPlotter` or directly to Bokeh's `scatter` function.

#### Notes

- The function supports passing data either directly as arrays or by specifying keys within a data source.
- Passing the data source as the first argument (`x`) is deprecated; instead, use the `data` keyword argument.
- Additional plotting options can be controlled via keyword arguments, allowing flexible customization.

## Additional Utilities

- **process_data_arguments**: Internal helper to process and validate data inputs for plotting.
- **ensure_plotter_consistency**: Decorator to ensure that plotting functions use consistent plot parameters.
