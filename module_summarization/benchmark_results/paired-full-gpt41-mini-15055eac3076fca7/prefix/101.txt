Miner
=====

The `Miner` class provides an interface to interact with the Ethereum miner through the Web3.py library. It allows querying miner status and controlling mining operations via JSON-RPC calls.

Initialization
--------------

`Miner(web3)`

Creates a new `Miner` instance.

- **web3** (`Web3`): An instance of the Web3 class used to send requests.

Properties
----------

hashrate
~~~~~~~~

The current mining hashrate.

:type: int

This property returns the current mining hashrate as a decimal integer by querying the `eth_hashrate` RPC method.

Methods
-------

makeDAG(number)
~~~~~~~~~~~~~~~

Generate a DAG (Directed Acyclic Graph) for the specified block number.

:param int number: The block number for which to generate the DAG.

:return: Result of the `miner_makeDag` RPC call.

setExtra(extra)
~~~~~~~~~~~~~~~

Set the extra data field for the miner.

:param str extra: The extra data to set.

:return: Result of the `miner_setExtra` RPC call.

setEtherBase(etherbase)
~~~~~~~~~~~~~~~~~~~~~~~

Set the etherbase (coinbase) address for mining rewards.

:param str etherbase: The address to set as the etherbase.

:return: Result of the `miner_setEtherbase` RPC call.

setGasPrice(gas_price)
~~~~~~~~~~~~~~~~~~~~~~

Set the gas price for mining transactions.

:param int gas_price: The gas price to set.

:return: Result of the `miner_setGasPrice` RPC call.

start(num_threads)
~~~~~~~~~~~~~~~~~~

Start the miner with the specified number of threads.

:param int num_threads: Number of threads to use for mining.

:return: Result of the `miner_start` RPC call.

stop()
~~~~~~

Stop the miner.

:return: Result of the `miner_stop` RPC call.

startAutoDAG()
~~~~~~~~~~~~~

Start automatic DAG generation.

:return: Result of the `miner_startAutoDag` RPC call.

stopAutoDAG()
~~~~~~~~~~~~

Stop automatic DAG generation.

:return: Result of the `miner_stopAutoDag` RPC call.
