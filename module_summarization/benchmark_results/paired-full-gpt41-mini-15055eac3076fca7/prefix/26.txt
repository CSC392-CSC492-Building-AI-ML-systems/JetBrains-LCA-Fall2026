w_kinavg — Average rates and confidence intervals for path-tracing kinetics analysis
======================================================================================

Description
-----------

The `w_kinavg` command calculates average rates and associated confidence intervals (CIs) from weighted ensemble kinetics data. It processes bin assignments (typically stored in `assignments.h5`) and kinetics data files (such as `kintrace.h5` or `kinmat.h5`) that must have been generated beforehand using related commands (`w_assign` and `w_kinetics`).

This tool supports the "trace" subcommand, which performs path-tracing kinetics analysis to compute averages and confidence intervals over specified iteration windows.

Output Format
-------------

The output is written to an HDF5 file (default: `kinavg.h5`), which contains datasets describing the computed rates and fluxes. The main datasets include:

- `/avg_rates` [state,state]  
  Structured dataset containing state-to-state average rates computed over the selected iteration window.

In trace mode, additional datasets are generated:

- `/avg_total_fluxes` [state]  
  Structured dataset of total fluxes into each state over the selected iteration window.

- `/avg_conditional_fluxes` [state,state]  
  Structured dataset of state-to-state fluxes over the selected iteration window.

If the `--evolution-mode` option is specified, the following datasets are also available:

- `/rate_evolution` [window,state,state]  
  Structured dataset showing state-to-state rates computed over windows of iterations with varying widths.  
  - For `--evolution-mode=cumulative`, windows start at `--start-iter` and grow by `--step-iter` for each successive element.  
  - For `--evolution-mode=blocked`, windows have fixed width `--step-iter` (except possibly the last), starting at `--start-iter`.

In trace mode with `--evolution-mode`, additional datasets include:

- `/target_flux_evolution` [window,state]  
  Structured dataset of total flux into each macro state over iteration windows as described above.

- `/conditional_flux_evolution` [window,state,state]  
  Structured dataset of state-to-state fluxes over iteration windows.

Dataset Structure
-----------------

Each dataset contains the following fields describing the statistics computed over the averaging window:

- `iter_start`  
  Integer indicating the first iteration included in the averaging window (inclusive).

- `iter_stop`  
  Integer indicating the iteration at which the averaging window ends (exclusive).

- `expected`  
  Floating-point value representing the expected (mean) rate or flux within the window, in units of inverse tau.

- `ci_lbound`  
  Floating-point value for the lower bound of the confidence interval on the rate or flux, in units of inverse tau.

- `ci_ubound`  
  Floating-point value for the upper bound of the confidence interval on the rate or flux, in units of inverse tau.

- `corr_len`  
  Integer representing the correlation length of the rate or flux within the window, measured in units of tau.

Each dataset is also annotated with the following attributes:

- `mcbs_alpha`  
  Floating-point alpha value used for confidence intervals (e.g., 0.05 corresponds to a 95% confidence interval).

- `mcbs_nsets`  
  Integer number of bootstrap data sets used to generate confidence intervals.

- `mcbs_acalpha`  
  Floating-point alpha value used for determining correlation lengths.

Command-Line Options
--------------------

Run `w_kinavg trace --help` for detailed information on available command-line options and usage.

Deprecation Notice
------------------

The `w_kinavg` command is deprecated. Users are encouraged to use the `w_direct` command instead for direct kinetics analysis. The `w_kinavg` command remains available for backward compatibility but may be removed in future releases.
