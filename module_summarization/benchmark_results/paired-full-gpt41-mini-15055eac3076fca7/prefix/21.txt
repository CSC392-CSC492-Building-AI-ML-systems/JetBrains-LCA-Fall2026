w_eddist — Calculate time-resolved transition-event duration distributions
=============================================================================

Description
-----------

The `w_eddist` tool calculates time-resolved transition-event duration distributions from kinetics results generated by weighted ensemble (WE) simulations.

This utility processes source data collected from the results of the `w_kinetics trace` command. For more information on generating this dataset, see the documentation for `w_kinetics trace` (`w_kinetics trace --help`).

Source Data
-----------

The input data for `w_eddist` is derived from the kinetics trace data produced by `w_kinetics trace`. This data contains information about transition events and their durations, which `w_eddist` uses to build histograms representing the distribution of event durations over time.

Histogram Binning
-----------------

By default, histograms are constructed with 100 bins in each dimension. This default can be overridden using the `-b` or `--bins` option, which accepts several types of arguments:

- **Single integer N**  
  Use `N` uniformly spaced bins in each dimension.

- **Sequence of integers N1,N2,... (comma-separated)**  
  Use `N1` bins for the first dimension, `N2` for the second, and so forth.

- **List of lists [[B11, B12, B13,...], [B21, B22, B23,...], ...]**  
  Specify explicit bin boundaries for each dimension. For example, the first dimension uses boundaries `B11, B12, B13, ...`, the second dimension uses `B21, B22, B23, ...`, etc. These boundaries need not be uniformly spaced. This argument is evaluated as a Python expression with `np` (NumPy) available, allowing use of functions like `np.arange()`.

**Important:**  
The first two forms (integer or list of integers) cause the program to scan all data in each dimension to determine minimum and maximum values, which can be computationally expensive for large datasets. Providing explicit bin boundaries (the third form) avoids this overhead.

Note that these histogram bins are unrelated to the bins used to drive WE sampling.

Output Format
-------------

The output file (specified by `-o` or `--output`, default: `pdist.h5`) contains the computed histograms and bin information. This file can be used with the `plothist` tool to generate plots or further process the data.

The output HDF5 file contains the following datasets:

- **`histograms`**  
  Normalized histograms with the first axis corresponding to iteration number and subsequent axes corresponding to the dimensions of the input data.

- **`/binbounds_0`, `/binbounds_1`, ...**  
  Bin boundary vectors for each dimension (index 0, 1, etc.).

- **`/midpoints_0`, `/midpoints_1`, ...**  
  Bin midpoint vectors for each dimension.

- **`n_iter`**  
  Vector of iteration numbers corresponding to the histograms stored along the first axis of the `histograms` dataset.

Subsequent Processing
---------------------

The output file generated by `w_eddist` can be visualized using the `plothist` program. For more details, see `plothist --help`.

Parallelization
---------------

`w_eddist` supports parallelized binning and input data reading. Parallel processing is enabled by default to improve performance on large datasets.

For simpler cases, such as reading pre-computed input data with a modest number of segments, serial processing can be enabled using the `--serial` option, which may be more efficient.

Command-Line Options
--------------------

Run `w_eddist --help` to see a full list of available command-line options and their descriptions.

Logging
-------

The tool logs its progress and any warnings or errors under the logger name `w_eddist`.

Examples
--------

Basic usage with default settings:

```
w_eddist -i kinetics_trace.h5 -o pdist.h5
```

Specify 50 bins in each dimension:

```
w_eddist -i kinetics_trace.h5 -o pdist.h5 -b 50
```

Specify different bin counts per dimension:

```
w_eddist -i kinetics_trace.h5 -o pdist.h5 -b 50,100
```

Specify explicit bin boundaries:

```
w_eddist -i kinetics_trace.h5 -o pdist.h5 -b "[np.linspace(0,10,51), np.linspace(-5,5,21)]"
```
