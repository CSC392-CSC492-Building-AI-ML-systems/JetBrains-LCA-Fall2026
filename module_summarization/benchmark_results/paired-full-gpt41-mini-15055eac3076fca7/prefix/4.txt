Sync Users with LDAP
====================

Overview
--------

This module provides functionality to synchronize users from an LDAP directory into the ftrack system. It enables automated management of user accounts by importing and updating user information based on LDAP data, ensuring that the ftrack user database remains consistent with the organization's directory services.

Key Features
------------

- Connect to an LDAP server to retrieve user information.
- Map LDAP user attributes to ftrack user attributes.
- Create new ftrack users based on LDAP entries.
- Update existing ftrack users with changes from LDAP.
- Handle user activation and deactivation according to LDAP status.
- Support for configurable LDAP queries and attribute mappings.
- Logging and error handling to track synchronization status.

Usage
-----

To synchronize users with LDAP, initialize a session with the ftrack server and configure the LDAP connection parameters. The synchronization process typically involves the following steps:

1. Establish a connection to the LDAP server using appropriate credentials.
2. Query the LDAP directory for user entries matching specified criteria.
3. For each LDAP user entry:
   - Check if the user exists in ftrack.
   - If the user does not exist, create a new user in ftrack with mapped attributes.
   - If the user exists, update the user attributes to reflect any changes.
4. Optionally deactivate or remove users in ftrack who no longer exist or are inactive in LDAP.
5. Log the results of the synchronization process for auditing and troubleshooting.

Configuration
-------------

The synchronization process can be customized through various configuration options:

- **LDAP Server URL**: The address of the LDAP server to connect to.
- **Bind DN and Password**: Credentials used to authenticate with the LDAP server.
- **Base DN**: The root distinguished name from which to search for user entries.
- **Search Filter**: LDAP filter expression to select user entries.
- **Attribute Mapping**: A mapping between LDAP attributes and ftrack user attributes.
- **User Activation Policy**: Rules to determine when users should be activated or deactivated.
- **Logging Level**: Controls the verbosity of synchronization logs.

Example
-------

```python
from ftrack_api import Session

# Initialize ftrack session
session = Session(
    server_url='https://ftrack.example.com',
    api_user='api_user',
    api_key='api_key'
)

# Configure LDAP synchronization parameters
ldap_config = {
    'server_url': 'ldap://ldap.example.com',
    'bind_dn': 'cn=admin,dc=example,dc=com',
    'password': 'secret',
    'base_dn': 'ou=users,dc=example,dc=com',
    'search_filter': '(objectClass=person)',
    'attribute_mapping': {
        'uid': 'username',
        'mail': 'email',
        'cn': 'full_name'
    }
}

# Perform synchronization
sync_ldap_users(session, ldap_config)
```

Logging and Monitoring
----------------------

The synchronization process emits detailed logs that include information about:

- Successful user creations and updates.
- Users skipped due to missing or invalid data.
- Errors encountered during LDAP queries or ftrack operations.
- Summary of synchronization results.

These logs can be used to monitor the health of the synchronization process and diagnose issues.

Best Practices
--------------

- Schedule regular synchronization intervals to keep user data up to date.
- Use secure connections (e.g., LDAPS) to protect LDAP credentials and data.
- Validate LDAP attribute mappings to ensure data consistency.
- Test synchronization in a staging environment before deploying to production.
- Monitor logs regularly to detect and resolve synchronization issues promptly.

Troubleshooting
---------------

- **Connection failures**: Verify LDAP server URL, network connectivity, and credentials.
- **Missing users**: Check LDAP search filters and base DN configuration.
- **Attribute mapping errors**: Ensure all required attributes are correctly mapped.
- **Permission issues**: Confirm that the API user has sufficient rights to create and update users in ftrack.

For further assistance, consult the ftrack API documentation or contact support.
