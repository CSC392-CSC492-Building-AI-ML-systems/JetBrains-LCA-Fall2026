Plothist Command
================

The `plothist` command is a versatile tool for visualizing histogram data stored in HDF5 files. It supports plotting histograms along specified dimensions, customizing plot appearance, and exporting plot data for further analysis.

Usage
-----

```bash
plothist [OPTIONS] INPUT [DIMENSION]
```

Arguments
---------

- **INPUT**  
  The HDF5 file containing the histogram data to be plotted.

- **DIMENSION** (optional)  
  Specifies the dimension of the histogram to plot. The dimension can be specified as:  
  ```
  INT[:[LB,UB]:LABEL]
  ```  
  where:  
  - `INT` is a zero-based integer identifying the dimension in the histogram.  
  - `LB` and `UB` are optional lower and upper bounds for plotting along that dimension.  
  - `LABEL` is an optional label for the plot axis.  
  If omitted, the default is dimension 0 with the full range.

Options
-------

### Input Options

- `INPUT`  
  The HDF5 file containing histogram data.

- `DIMENSION`  
  Dimension specification as described above.

### Output Options

- `-o`, `--output`, `--plot-output` PLOT_OUTPUT  
  Store the plot as the specified file. The output format is inferred from the filename extension (default is PDF).  
  To suppress plotting entirely, set this option to an empty string (`--plot-output=''`).  
  Default: `hist.pdf`

- `--hdf5-output` HDF5_OUTPUT  
  Store plot data in the specified HDF5 file.

- `--plot-contour`  
  Superimpose a contour plot over the heatmap for 2D histograms.

### Plot Options

- `--title` TITLE  
  Include the specified TITLE as the top-of-graph title.

- `--linear`  
  Plot the histogram on a linear scale.

- `--energy`  
  Plot the histogram on an inverted natural logarithm scale, corresponding to free energy (default).

- `--zero-energy`  
  Adjust the zero of energy for energy scale plots.

Functionality
-------------

The command supports plotting histograms along one or more dimensions, with options to specify ranges and labels for each dimension. It can handle 1D and 2D histograms, with the ability to overlay contour plots on 2D heatmaps.

Plot scales supported include linear and energy (inverted natural log) scales, allowing visualization of data in terms of free energy landscapes.

Plot data can be saved as graphical files (e.g., PDF) or exported back into HDF5 format for further processing.

Examples
--------

Plot the histogram along dimension 0 with default full range and save as PDF:

```bash
plothist data.h5
```

Plot dimension 1 with bounds 0 to 10 and label "Distance":

```bash
plothist data.h5 1:[0,10]:Distance
```

Plot with a linear scale and custom title, saving output as PNG:

```bash
plothist data.h5 --linear --title "Histogram Plot" -o hist.png
```

Plot a 2D histogram with contour overlay:

```bash
plothist data.h5 0 1 --plot-contour
```

Suppress plotting but save plot data to an HDF5 file:

```bash
plothist data.h5 --plot-output='' --hdf5-output plotdata.h5
```

Logging and Error Handling
--------------------------

The command uses logging to report progress and issues during execution. It suppresses divide-by-zero warnings during logarithmic transformations to ensure clean output.

Notes
-----

- The dimension specification allows flexible slicing and labeling of histogram data for tailored visualization.
- The output format depends on the file extension provided in the output filename.
- Contour plotting is only applicable for 2D histograms.
- Energy scale plotting uses an inverted natural logarithm to represent free energy landscapes.

For more detailed usage and advanced options, consult the command's help output:

```bash
plothist --help
```
