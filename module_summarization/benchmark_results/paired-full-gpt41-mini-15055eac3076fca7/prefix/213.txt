Nonparametric Methods
=====================

Univariate Kernel Density Estimators
------------------------------------

Kernel density estimation (KDE) is a fundamental nonparametric technique to estimate the probability density function of a random variable. Unlike parametric methods, KDE does not assume a specific functional form for the distribution, making it flexible for modeling complex data structures.

References
^^^^^^^^^^

- Racine, Jeff. (2008) "Nonparametric Econometrics: A Primer," Foundation and Trends in Econometrics: Vol 3: No 1, pp1-88.  
  http://dx.doi.org/10.1561/0800000009

Overview
^^^^^^^^

The `KDEUnivariate` class provides an efficient implementation of univariate kernel density estimation. It supports a variety of kernel functions and bandwidth selection methods, and can leverage FFT-based computation for improved performance with Gaussian kernels.

Key Features
^^^^^^^^^^^^

- Supports multiple kernel functions including Gaussian, Epanechnikov, Uniform, Triangular, Biweight, Triweight, and Cosine kernels.
- Bandwidth selection methods include Scott's rule, Silverman's rule, normal reference rule, user-specified floats, or custom callable functions.
- FFT-based density estimation for computational efficiency with Gaussian kernels.
- Provides estimates of the density, cumulative distribution function (CDF), survival function (SF), cumulative hazard, and entropy.
- Handles weighted data and allows grid size and bandwidth adjustment.

Usage
^^^^^

To use the `KDEUnivariate` estimator, initialize it with your data and call the `fit` method:

```python
import statsmodels.api as sm
import matplotlib.pyplot as plt
import numpy as np

nobs = 300
np.random.seed(1234)
data = np.random.normal(size=nobs)

dens = sm.nonparametric.KDEUnivariate(data)
dens.fit(kernel="gau", bw="normal_reference", fft=True)

plt.plot(dens.cdf)
plt.title("Estimated CDF using KDEUnivariate")
plt.show()
```

Parameters of `fit` method
^^^^^^^^^^^^^^^^^^^^^^^^^^

- **kernel** : str  
  Specifies the kernel function to use. Options include:  
  - `"gau"`: Gaussian  
  - `"epa"`: Epanechnikov  
  - `"uni"`: Uniform  
  - `"tri"`: Triangular  
  - `"biw"`: Biweight  
  - `"triw"`: Triweight  
  - `"cos"`: Cosine  

- **bw** : str, float, or callable  
  Bandwidth selection method or value. Options:  
  - `"scott"`: Scott's rule of thumb  
  - `"silverman"`: Silverman's rule of thumb  
  - `"normal_reference"`: Normal reference bandwidth based on kernel  
  - float: user-specified bandwidth  
  - callable: a function that takes data and kernel and returns bandwidth  

- **fft** : bool  
  Whether to use FFT-based computation (only available for Gaussian kernel). FFT improves computational speed.

- **gridsize** : int or None  
  Number of points on the grid where the density is estimated. Defaults to max(len(data), 50).

- **adjust** : float  
  Factor to adjust the bandwidth. The effective bandwidth is `bw * adjust`.

- **cut** : float  
  Extends the grid beyond the data range by `cut * bw` to ensure kernel tails are captured.

- **clip** : tuple  
  Tuple specifying lower and upper bounds to clip the data.

Notes
^^^^^

- When computing the CDF, survival function, cumulative hazard, or entropy, the calculations are based on the kernel's analytical definition rather than the FFT approximation, even if FFT is used for density estimation.
- `KDEUnivariate` is optimized for univariate continuous data and is significantly faster than multivariate KDE implementations.
- For multivariate or mixed data types, consider using `KDEMultivariate`.

See Also

This implementation provides a robust and flexible tool for nonparametric density estimation, suitable for exploratory data analysis, visualization, and as a building block for more complex statistical modeling.
