Neural Network Models (Supervised)
==================================

Overview
--------

This module provides utilities and functions to support the implementation of supervised neural network models. It includes activation functions, their derivatives, and loss functions commonly used in training neural networks for regression and classification tasks.

Activation Functions
--------------------

Activation functions introduce non-linearity into the neural network, enabling it to learn complex patterns. The module provides several inplace activation functions that modify the input data directly for efficiency.

- **Identity** (`inplace_identity`): Leaves the input unchanged.
- **Logistic Sigmoid** (`inplace_logistic`): Applies the logistic sigmoid function element-wise.
- **Hyperbolic Tangent (tanh)** (`inplace_tanh`): Applies the hyperbolic tangent function element-wise.
- **Rectified Linear Unit (ReLU)** (`inplace_relu`): Applies the ReLU function element-wise, setting negative values to zero.
- **Softmax** (`inplace_softmax`): Applies the softmax function across features for multi-class classification, converting raw scores into probabilities.

These functions accept input arrays of shape `(n_samples, n_features)` and modify them inplace for computational efficiency.

Activation Functions Dictionary
-------------------------------

The `ACTIVATIONS` dictionary maps string identifiers to the corresponding inplace activation functions:

- `"identity"`: `inplace_identity`
- `"tanh"`: `inplace_tanh`
- `"logistic"`: `inplace_logistic`
- `"relu"`: `inplace_relu`
- `"softmax"`: `inplace_softmax`

Derivatives of Activation Functions
-----------------------------------

During backpropagation, the derivatives of activation functions are used to propagate error gradients. The module provides inplace derivative functions that modify the backpropagated error signal (`delta`) based on the output of the activation function (`Z`).

- **Identity Derivative** (`inplace_identity_derivative`): No modification to `delta`.
- **Logistic Sigmoid Derivative** (`inplace_logistic_derivative`): Uses the property that the derivative is `Z * (1 - Z)`.
- **Hyperbolic Tangent Derivative** (`inplace_tanh_derivative`): Uses the property that the derivative is `1 - Z^2`.
- **ReLU Derivative** (`inplace_relu_derivative`): Sets `delta` to zero where the activation output `Z` is zero.

These derivative functions are designed to be efficient by modifying the error signal inplace.

Derivatives Dictionary
----------------------

The `DERIVATIVES` dictionary maps string identifiers to the corresponding inplace derivative functions:

- `"identity"`: `inplace_identity_derivative`
- `"tanh"`: `inplace_tanh_derivative`
- `"logistic"`: `inplace_logistic_derivative`
- `"relu"`: `inplace_relu_derivative`

Loss Functions
--------------

Loss functions quantify the difference between the predicted outputs of the neural network and the true target values. They are essential for guiding the optimization process during training.

- **Squared Loss** (`squared_loss`): Used for regression tasks, it computes the mean squared error divided by two:
  
  .. math::
  
     L = \\frac{1}{2} \\cdot \\text{mean}((y_{true} - y_{pred})^2)
  
- **Logistic Loss** (`log_loss`): Used for classification tasks, it computes the logistic loss (also known as cross-entropy loss) between true labels and predicted probabilities. It includes numerical stability measures such as clipping probabilities to avoid log(0).

Usage Notes
-----------

- Activation and derivative functions operate inplace on input arrays to optimize memory usage and computational speed.
- Input arrays are expected to have shape `(n_samples, n_features)`, where `n_samples` is the number of data points and `n_features` corresponds to features or output units.
- Loss functions expect ground truth and predicted values in compatible shapes and formats (e.g., label indicator matrices for classification).
- The softmax activation function is typically used in the output layer for multi-class classification problems to produce probability distributions over classes.
