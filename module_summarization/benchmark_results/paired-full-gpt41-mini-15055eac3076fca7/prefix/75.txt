Working with Text Data
======================

This tutorial provides an overview of how to work with text data using the utilities provided in the `sklearn.feature_extraction.text` submodule. This submodule offers tools to build feature vectors from text documents, which is a crucial step in many natural language processing (NLP) and machine learning workflows.

Overview
--------

The `sklearn.feature_extraction.text` submodule includes several classes and functions to preprocess, tokenize, and vectorize text data. Key components include:

- **Vectorizers**: Convert a collection of text documents to a matrix of token counts or TF-IDF features.
  - `CountVectorizer`
  - `TfidfVectorizer`
  - `HashingVectorizer`
- **Transformers**: Transform count matrices to normalized TF or TF-IDF representations.
  - `TfidfTransformer`
- **Stop Words**: Predefined lists of common stop words, such as `ENGLISH_STOP_WORDS`.
- **Text Preprocessing Utilities**: Functions to clean and normalize text data.
  - `strip_accents_ascii`
  - `strip_accents_unicode`
  - `strip_tags`

Preprocessing Text Data
-----------------------

Before converting text into numerical features, it is often necessary to preprocess the text. Preprocessing may include lowercasing, removing accents, stripping HTML tags, and removing stop words.

### Accent Stripping

Accented characters can be normalized or removed using:

- `strip_accents_unicode(s)`: Converts accented unicode characters into their closest simple unicode counterparts. This method is comprehensive but slower.
- `strip_accents_ascii(s)`: Converts accented unicode characters into ASCII equivalents or removes them. This method is faster but only suitable for languages with direct ASCII transliterations.

Example:

```python
from sklearn.feature_extraction.text import strip_accents_ascii

text = "Café"
clean_text = strip_accents_ascii(text)
print(clean_text)  # Output: Cafe
```

### HTML/XML Tag Stripping

To remove HTML or XML tags from text, use:

```python
from sklearn.feature_extraction.text import strip_tags

html_text = "<p>This is a <b>bold</b> paragraph.</p>"
clean_text = strip_tags(html_text)
print(clean_text)  # Output: " This is a  bold  paragraph. "
```

Note: For complex HTML/XML parsing, consider using dedicated libraries like BeautifulSoup or lxml.

Tokenization and Analysis
-------------------------

Text data is typically tokenized into words or n-grams before vectorization. The submodule provides flexible mechanisms to chain preprocessing, tokenization, and n-gram extraction.

The `_analyze` function (used internally) demonstrates this pipeline:

1. **Decoding**: Convert input to a standard format.
2. **Analyzing**: Apply a custom analyzer function if provided.
3. **Preprocessing**: Apply preprocessing such as lowercasing or accent stripping.
4. **Tokenizing**: Split text into tokens.
5. **N-gram Extraction**: Generate n-grams from tokens.
6. **Stop Word Removal**: Remove common stop words if specified.

This modular approach allows customization of each step.

Stop Words
----------

Stop words are common words that are often removed from text data to reduce noise. The submodule provides a built-in English stop word list accessible via `ENGLISH_STOP_WORDS`.

You can specify stop words when using vectorizers to automatically exclude them from the feature set.

Vectorizing Text Data
---------------------

The main goal of text feature extraction is to convert raw text into numerical feature vectors suitable for machine learning algorithms.

### CountVectorizer

Converts a collection of text documents to a matrix of token counts.

Example:

```python
from sklearn.feature_extraction.text import CountVectorizer

corpus = [
    "This is the first document.",
    "This document is the second document.",
    "And this is the third one.",
    "Is this the first document?",
]

vectorizer = CountVectorizer(stop_words='english')
X = vectorizer.fit_transform(corpus)
print(X.toarray())
print(vectorizer.get_feature_names_out())
```

### TfidfVectorizer

Converts a collection of raw documents to a matrix of TF-IDF features.

Example:

```python
from sklearn.feature_extraction.text import TfidfVectorizer

vectorizer = TfidfVectorizer(stop_words='english')
X = vectorizer.fit_transform(corpus)
print(X.toarray())
print(vectorizer.get_feature_names_out())
```

### HashingVectorizer

Uses a hashing trick to convert text to feature vectors without storing a vocabulary dictionary. Useful for large datasets or streaming data.

Example:

```python
from sklearn.feature_extraction.text import HashingVectorizer

vectorizer = HashingVectorizer(n_features=20, alternate_sign=False)
X = vectorizer.transform(corpus)
print(X.toarray())
```

Conclusion
----------

The `sklearn.feature_extraction.text` submodule provides a comprehensive set of tools to preprocess, tokenize, and vectorize text data efficiently. By combining preprocessing utilities with vectorizers, you can transform raw text into meaningful numerical features for machine learning models.

For advanced text processing, consider customizing analyzers, tokenizers, and preprocessing steps to suit your specific dataset and task requirements.
