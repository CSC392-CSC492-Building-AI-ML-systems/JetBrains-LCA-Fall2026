Quantile Regression Model
=========================

This module implements a Quantile Regression model using iterative reweighted least squares (IRLS) for parameter estimation. Quantile regression provides a comprehensive view of the conditional distribution of the response variable by estimating conditional quantiles, allowing for a more robust analysis compared to ordinary least squares regression.

Overview
--------

The model parameters are estimated via an iterative reweighted least squares algorithm. The asymptotic covariance matrix of the parameter estimates is computed using kernel density estimation techniques, providing robust standard errors that account for heteroskedasticity.

Key Features
------------

- **Quantile Regression Estimation**: Supports estimation of any quantile between 0 and 1, including the median regression (Least Absolute Deviation, LAD) as a special case when the quantile is set to 0.5.
- **Robust Covariance Estimation**: Offers heteroskedasticity-robust standard errors as well as iid error assumptions.
- **Kernel Density Estimation**: Implements several kernel functions (Epanechnikov, Cosine, Gaussian, Parzen) for estimating the asymptotic covariance matrix.
- **Bandwidth Selection Methods**: Provides multiple bandwidth selection methods for kernel density estimation, including Hall-Sheather, Bofinger, and Chamberlain methods.

Usage
-----

The primary class provided is `QuantReg`, which inherits from a general regression model base class. It requires endogenous (response) and exogenous (explanatory) variables as inputs.

```python
from statsmodels.regression.quantile_regression import QuantReg

model = QuantReg(endog, exog)
results = model.fit(q=0.5, vcov='robust', kernel='epa', bandwidth='hsheather')
```

Parameters for the `fit` method include:

- `q`: The quantile to estimate (float between 0 and 1).
- `vcov`: Method for variance-covariance matrix calculation (`'robust'` or `'iid'`).
- `kernel`: Kernel function for density estimation (`'epa'`, `'cos'`, `'gau'`, `'par'`).
- `bandwidth`: Bandwidth selection method (`'hsheather'`, `'bofinger'`, `'chamberlain'`).

Notes
-----

- The Least Absolute Deviation (LAD) estimator corresponds to the median regression (quantile = 0.5).
- The asymptotic covariance matrix estimation follows the procedure described in Greene (2008, pp. 407-408).
- The original IRLS algorithm was adapted from Matlab code by Shapour Mohammadi (University of Tehran, 2008) and translated to Python by Christian Prinoth.
