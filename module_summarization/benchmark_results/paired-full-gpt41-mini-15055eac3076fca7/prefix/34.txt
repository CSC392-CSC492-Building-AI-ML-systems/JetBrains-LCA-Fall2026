w_stateprobs Command
====================

Overview
--------

The `w_stateprobs` command calculates average populations and associated confidence intervals (CIs) for state populations from weighted ensemble data. This analysis requires bin assignments, including macrostate definitions (see `w_assign --help` for more information).

This tool performs path-tracing kinetics analysis by averaging state populations over specified iteration windows, providing insights into the kinetics of state-to-state transitions.

Output Format
-------------

The output is written to a file (specified with `-o` or `--output`, default is `stateprobs.h5`) containing the following datasets:

- **/avg_state_pops [state]**  
  A structured dataset representing the population of each state averaged across the entire specified iteration range.

If the `--evolution-mode` option is specified, an additional dataset is included:

- **/state_pop_evolution [window][state]**  
  A structured dataset representing state populations calculated over windows of iterations. The windows can be defined in two modes:

  - **cumulative**: Windows start at the iteration specified by `--start-iter` and grow in length by `--step-iter` for each successive element.
  - **blocked**: Windows are of fixed width `--step-iter` (except possibly the last window), starting at `--start-iter`.

Dataset Structure
-----------------

Each dataset contains the following fields:

- **iter_start**  
  Integer. The iteration at which the averaging window begins (inclusive).

- **iter_stop**  
  Integer. The iteration at which the averaging window ends (exclusive).

- **expected**  
  Floating-point. The expected (mean) value of the rate within this window, in units of inverse tau.

- **ci_lbound**  
  Floating-point. The lower bound of the confidence interval on the rate within this window, in units of inverse tau.

- **ci_ubound**  
  Floating-point. The upper bound of the confidence interval on the rate within this window, in units of inverse tau.

- **corr_len**  
  Integer. The correlation length of the rate within this window, in units of tau.

Each dataset is also annotated with the following attributes:

- **mcbs_alpha**  
  Floating-point. Alpha value of confidence intervals (e.g., `alpha=0.05` corresponds to a 95% confidence interval).

- **mcbs_nsets**  
  Integer. Number of bootstrap data sets used to generate confidence intervals.

- **mcbs_acalpha**  
  Floating-point. Alpha value used for determining correlation lengths.

Command-Line Options
--------------------

Run `w_stateprobs --help` to see all available command-line options. The command supports options to specify input files, output files, iteration ranges, and parameters controlling the calculation of confidence intervals and correlation lengths.

Deprecation Notice
------------------

**Note:** The `w_stateprobs` command is deprecated. Users are encouraged to use the `w_direct` command instead for state-to-state kinetics analysis.

Example Usage
-------------

```bash
w_stateprobs -o stateprobs.h5 --start-iter 0 --stop-iter 1000 --evolution-mode cumulative
```

This command calculates average state populations and confidence intervals over iterations 0 to 999, outputting results to `stateprobs.h5`, with cumulative evolution mode enabled.

Further Information
-------------------

For more details on bin assignments and macrostate definitions required for this analysis, see the documentation for the `w_assign` command:

```bash
w_assign --help
```
