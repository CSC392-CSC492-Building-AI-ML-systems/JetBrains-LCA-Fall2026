Decision Trees
==============

Decision Trees are a versatile and widely used class of supervised learning algorithms for classification and regression tasks. They work by recursively partitioning the input space into subsets based on feature values, aiming to create homogeneous subsets with respect to the target variable.

Overview
--------

A Decision Tree is constructed by splitting the dataset into subsets using feature thresholds that maximize some criterion of "purity" or "impurity" reduction. The process continues recursively, creating a tree structure where each internal node represents a decision rule on a feature, and each leaf node represents a predicted output value or class.

Impurity Criteria
-----------------

The quality of a split in a Decision Tree is evaluated using impurity criteria. These criteria measure how well a split separates the data into homogeneous groups. Common impurity measures include Gini impurity, entropy, and variance reduction.

The `Criterion` interface defines the methods required to calculate and update impurity measures efficiently during tree construction. It provides the following key functionalities:

- **Initialization**: Setting up the criterion with the target values, sample weights, and indices of samples considered at the current node.
- **Resetting**: Preparing the criterion to evaluate splits starting from either the beginning or the end of the sample indices.
- **Updating**: Efficiently updating the impurity statistics when samples are moved from one child node to another during split evaluation.
- **Impurity Calculation**: Computing the impurity of the current node and its children to assess the quality of potential splits.
- **Handling Missing Values**: Managing missing data by initializing statistics for samples with missing feature values.

These operations are designed to be performed with high efficiency, often implemented in low-level languages like Cython to optimize performance.

Tree Construction
-----------------

During tree construction, the algorithm iteratively selects the best split by evaluating all possible splits across all features using the impurity criteria. The split that results in the greatest reduction in impurity is chosen to partition the data at each node.

The process continues recursively until stopping conditions are met, such as reaching a maximum tree depth, having a minimum number of samples in a node, or when no further impurity reduction is possible.

Summary
-------

Decision Trees provide an interpretable and powerful method for both classification and regression. Their construction relies heavily on impurity criteria to guide the splitting process, ensuring that each split improves the homogeneity of the resulting subsets. Efficient implementations of these criteria are crucial for building scalable and performant tree-based models.
