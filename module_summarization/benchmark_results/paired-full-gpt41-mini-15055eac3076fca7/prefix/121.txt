Create Cradmin menu system
==========================

The Cradmin menu system provides a flexible and extensible way to create navigation menus in your Django application using the `django_cradmin` framework. This documentation describes the core components and how to use them to build menus.

Default Expandable Menu Renderable
----------------------------------

You can obtain the default expandable menu renderable by using the function:

```python
get_default_expandable_menu_renderable(**kwargs)
```

This function returns an instance of the expandable menu renderable class configured in the Django settings under the key `DJANGO_CRADMIN_DEFAULT_EXPANDABLE_MENU_CLASS`. If this setting is not defined, the function returns `None`.

**Parameters:**

- `**kwargs`: Keyword arguments passed to the constructor of the expandable menu class.

**Returns:**

- An instance of `AbstractMenuRenderable` or `None`.

Menu Link Renderables
---------------------

### BaseMenuLinkRenderable

This is the base class for menu link items. It renders a menu item with a label and a URL.

**Constructor parameters:**

- `label`: The text label displayed in the menu.
- `url`: The URL to navigate to when the menu item is clicked.
- `is_active`: Boolean indicating if the menu item should be styled as active.
- `bem_variant_list`: Optional list of BEM (Block Element Modifier) variants for styling.
- `parent_bem_block`: Optional BEM block name for CSS styling.

**Key methods:**

- `get_parent_bem_block()`: Returns the BEM block name used for styling.
- `get_bem_element()`: Returns the BEM element name for the menu link.
- `get_bem_variant_list()`: Returns the list of BEM variants, including 'active' if the item is active.

### NavLinkItemRenderable

A subclass of `BaseMenuLinkRenderable` used to add standard links to the main menu.

### NavLinkButtonItemRenderable

A subclass of `NavLinkItemRenderable` that styles the link as a button. It overrides the BEM variant list to include `'button'`.

Expandable Menu Items
---------------------

### ExpandableMenuItem

An expandable menu item that can contain nested menu items. It uses a different template and BEM elements for styling.

- Template: `'django_cradmin/crmenu/menuitem/expandable-menu-item.django.html'`
- BEM block fallback: `'expandable-menu'`
- BEM elements: link and list item elements for nested menus.

### ExpandableMenuSeparator

A visual separator used within expandable menus to group items.

- Template: `'django_cradmin/crmenu/menuitem/expandable-menu-separator.django.html'`
- BEM block fallback: `'expandable-menu'`
- BEM element: separator

Menu Toggle Item
----------------

### MenuToggleItemItemRenderable

This renderable adds a toggle button to the menu, typically used to expand or collapse the menu on smaller screens.

- Template: `'django_cradmin/crmenu/menuitem/menutoggle.django.html'`
- Label: Translatable label "Menu"
- BEM block fallback: `'adminui-page-header'`
- BEM elements: navmenutoggle, navmenutoggle-label, navmenutoggle-icon

Base Menu Renderable
--------------------

### AbstractMenuRenderable

This is the base class for rendering a complete menu. It extends `AbstractRenderableWithCss` and provides the foundation for creating custom menus.

To create a fully customized menu, you can subclass `AbstractMenuRenderable` and override the template by implementing the method `get_template_name()` to specify your own HTML structure.

Summary
-------

The Cradmin menu system is built around reusable renderable components that follow the BEM CSS methodology for styling. You can combine these components to create complex, accessible, and responsive menus tailored to your application's needs.

- Use `NavLinkItemRenderable` and `NavLinkButtonItemRenderable` for simple menu links.
- Use `ExpandableMenuItem` and `ExpandableMenuSeparator` to create nested, expandable menus.
- Use `MenuToggleItemItemRenderable` to add a menu toggle button for responsive designs.
- Extend `AbstractMenuRenderable` for full control over menu rendering.

By leveraging these components, you can build a consistent and maintainable menu system integrated with the Cradmin framework.
