Diophantine Equations Module
============================

Overview
--------

This module provides functionality for solving Diophantine equations, which are polynomial equations where integer solutions are sought. The main function `diophantine` simplifies the solution procedure by factoring the equation into terms and solving each independently.

Supported Equation Types
------------------------

The module recognizes several types of Diophantine equations, including but not limited to:

- Binary quadratic equations
- Cubic Thue equations
- General Pythagorean equations
- General sums of even powers
- General sums of squares
- Homogeneous general quadratic equations
- Homogeneous ternary quadratic equations (including normalized forms)
- Inhomogeneous general quadratic equations
- Inhomogeneous ternary quadratic equations
- Linear equations
- Univariate equations

Utility Functions
-----------------

Several internal utility functions assist in the processing and solving of equations:

- `_is_int(i)`: Checks if `i` can be interpreted as an integer.
- `_sorted_tuple(*i)`: Returns a tuple of the inputs sorted in ascending order.
- `_remove_gcd(*x)`: Removes the greatest common divisor from a tuple of integers.
- `_rational_pq(a, b)`: Returns a tuple `(numerator, denominator)` for the rational number `a/b` with sign normalized and gcd removed.
- `_nint_or_floor(p, q)`: Returns the nearest integer to the fraction `p/q`; in case of a tie, returns the floor.
- `_odd(i)`: Returns `True` if `i` is odd.
- `_even(i)`: Returns `True` if `i` is even.

Main Function: diophantine
--------------------------

```python
diophantine(eq, param=symbols('t', integer=True), syms=None)
```

Simplifies and solves the Diophantine equation `eq` by factoring it into terms that equal zero and solving each term independently.

Parameters
~~~~~~~~~~

- `eq` : `Relational` or `Expr`
  
  The Diophantine equation to be solved. It can be an equality or an expression assumed equal to zero.

- `param` : `Symbol`, optional
  
  The parameter symbol to be used in the parametric solutions. Defaults to an integer symbol `t`.

- `syms` : list of `Symbol`, optional
  
  Specifies the order of variables in the returned solution tuples. If not provided, variables are sorted alphabetically.

Returns
~~~~~~~

A set of tuples, each tuple representing a solution to the equation. The elements of the tuple correspond to the variables in the order specified by `syms` or by alphabetical order if `syms` is not provided.

Each solution tuple contains expressions in terms of the parameter symbol(s).

Examples
~~~~~~~~

Solve the equation \( x^2 - y^2 = 0 \):

```python
>>> diophantine(x**2 - y**2)
{(t_0, -t_0), (t_0, t_0)}
```

Solve the equation \( x(2x + 3y - z) = 0 \):

```python
>>> diophantine(x*(2*x + 3*y - z))
{(0, n1, n2), (t_0, t_1, 2*t_0 + 3*t_1)}
```

Solve the equation \( x^2 + 3xy + 4x = 0 \):

```python
>>> diophantine(x**2 + 3*x*y + 4*x)
{(0, n1), (3*t_0 - 4, -t_0)}
```

Notes
-----

- The function accepts equations expressed as equalities (`Eq`) or expressions assumed equal to zero.
- The equation is expanded and factored before solving.
- Only polynomial equations with rational coefficients are supported.
- If the equation is not polynomial or cannot be processed, a `TypeError` is raised.
