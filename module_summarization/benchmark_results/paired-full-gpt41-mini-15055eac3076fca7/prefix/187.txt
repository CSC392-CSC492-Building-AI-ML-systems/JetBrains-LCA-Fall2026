Isotonic Regression
===================

Isotonic regression is a non-parametric regression technique that fits a free-form line to a set of points while preserving the order of the dependent variable. It is particularly useful when the relationship between variables is assumed to be monotonic (either non-decreasing or non-increasing) but not necessarily linear.

Overview
--------

The isotonic regression model finds a monotonic function that best fits the data in a least squares sense. This method is widely used in statistics and machine learning when the underlying relationship is expected to be monotonic but the exact form is unknown.

Key Features
------------

- Fits a monotonic (increasing or decreasing) function to data.
- Supports weighted samples.
- Allows bounding the predicted values within specified minimum and maximum limits.
- Can be used both as a regressor and as a transformer.

Functions and Classes
---------------------

check_increasing(x, y)
~~~~~~~~~~~~~~~~~~~~~~

Determine whether the target variable `y` is monotonically correlated with the input `x`.

Parameters
^^^^^^^^^^

- **x** : array-like of shape (n_samples,)
  
  Training data.

- **y** : array-like of shape (n_samples,)
  
  Training target.

Returns
^^^^^^^

- **increasing_bool** : bool
  
  Returns `True` if `y` is monotonically increasing with respect to `x`, `False` otherwise.

Notes
^^^^^

The function uses the Spearman correlation coefficient to assess monotonicity. A warning is issued if the 95% confidence interval of the correlation coefficient spans zero, indicating uncertainty in the monotonicity determination.

References
^^^^^^^^^^

- Fisher transformation. Wikipedia. https://en.wikipedia.org/wiki/Fisher_transformation

isotonic_regression(y, *, sample_weight=None, y_min=None, y_max=None, increasing=True)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Solve the isotonic regression problem for a given set of data.

Parameters
^^^^^^^^^^

- **y** : array-like of shape (n_samples,)
  
  The data to fit.

- **sample_weight** : array-like of shape (n_samples,), default=None
  
  Weights applied to each data point. If `None`, all points are weighted equally.

- **y_min** : float, default=None
  
  Lower bound on the predicted values. If not specified, no lower bound is applied.

- **y_max** : float, default=None
  
  Upper bound on the predicted values. If not specified, no upper bound is applied.

- **increasing** : bool, default=True
  
  If `True`, fits an increasing isotonic regression; if `False`, fits a decreasing one.

Returns
^^^^^^^

- **y_** : ndarray of shape (n_samples,)
  
  The isotonic regression fit of the input data.

References
^^^^^^^^^^

- Best, M. J., & Chakravarti, N. (1990). Active set algorithms for isotonic regression; A unifying framework.

IsotonicRegression
~~~~~~~~~~~~~~~~~~

An estimator implementing isotonic regression as a scikit-learn compatible regressor and transformer.

.. versionadded:: 0.13

Parameters
^^^^^^^^^^

- **y_min** : float or None, default=None
  
  Lower bound on the predicted values.

- **y_max** : float or None, default=None
  
  Upper bound on the predicted values.

- **increasing** : bool, default=True
  
  Whether to fit an increasing or decreasing isotonic regression.

- **out_of_bounds** : {'clip', 'nan', 'raise'}, default='nan'
  
  Defines the behavior when transforming data outside the training range.

- **sample_weight** : array-like of shape (n_samples,), default=None
  
  Sample weights.

Attributes
^^^^^^^^^^

- **X_thresholds_** : ndarray of shape (n_thresholds,)
  
  The unique sorted training data points.

- **X_min_** : float
  
  Minimum value of the training data.

- **X_max_** : float
  
  Maximum value of the training data.

- **y_thresholds_** : ndarray of shape (n_thresholds,)
  
  The isotonic regression fit values at the thresholds.

- **increasing_** : bool
  
  Whether the fitted model is increasing.

Usage
-----

Isotonic regression can be used for calibration, smoothing, or any scenario where a monotonic relationship is expected but the exact functional form is unknown.

Example
-------

.. code-block:: python

    import numpy as np
    from sklearn.isotonic import IsotonicRegression

    x = np.array([0, 1, 2, 3, 4, 5])
    y = np.array([0, 0.8, 0.9, 1.2, 1.1, 1.3])

    ir = IsotonicRegression(increasing=True)
    y_ = ir.fit_transform(x, y)

    print(y_)

Notes
-----

Isotonic regression is a powerful tool when monotonicity is a reasonable assumption. It is less restrictive than parametric models and can adapt flexibly to the data shape while preserving order constraints.
