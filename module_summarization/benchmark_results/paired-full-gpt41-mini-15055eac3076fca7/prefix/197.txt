Naive Bayes Methods
===================

Overview
--------

The :mod:`sklearn.naive_bayes` module implements Naive Bayes algorithms, which are supervised learning methods based on applying Bayes' theorem with strong (naive) feature independence assumptions. These methods are particularly suited for classification tasks and are known for their simplicity, efficiency, and effectiveness in many practical applications.

Naive Bayes Estimators
----------------------

All Naive Bayes classifiers in this module inherit from the abstract base class :class:`_BaseNB`, which provides a common interface and shared functionality.

### _BaseNB Class

The :class:`_BaseNB` class is an abstract base class for Naive Bayes estimators. It defines the core methods that all Naive Bayes classifiers implement:

- **_joint_log_likelihood(X)**  
  Computes the unnormalized posterior log probability of the input samples `X`.  
  Specifically, it calculates:  
  ``log P(c) + log P(x|c)``  
  for each class `c` and each sample `x` in `X`.  
  This method returns an array of shape `(n_samples, n_classes)`.

- **_check_X(X)**  
  Performs input validation and preprocessing on `X`. This method is intended to be overridden in subclasses.

- **predict_joint_log_proba(X)**  
  Returns the joint log probability estimates for the test samples `X`.  
  For each sample `x` and class `y`, it computes:  
  ``log P(x, y) = log P(y) + log P(x|y)``  
  where `log P(y)` is the log prior probability of class `y` and `log P(x|y)` is the log likelihood of `x` given `y`.  
  Returns an array of shape `(n_samples, n_classes)`.

- **predict(X)**  
  Performs classification on the input samples `X`.  
  Returns the predicted class labels as an array of shape `(n_samples,)`.

- **predict_log_proba(X)**  
  Returns the log-probability estimates for the test samples `X`.  
  This is computed by normalizing the joint log likelihoods to obtain log probabilities.  
  Returns an array of shape `(n_samples, n_classes)`.

- **predict_proba(X)**  
  Returns the probability estimates for the test samples `X`.  
  This is the exponentiation of the log-probabilities returned by `predict_log_proba`.  
  Returns an array of shape `(n_samples, n_classes)`.

Usage
-----

The Naive Bayes classifiers can be used for classification tasks where the assumption of feature independence holds or is a reasonable approximation. They are particularly effective for high-dimensional data and text classification problems.

The typical workflow involves:

1. Instantiating a Naive Bayes classifier (e.g., `GaussianNB`, `MultinomialNB`, `BernoulliNB`, etc.).
2. Fitting the classifier to training data.
3. Using the `predict`, `predict_proba`, or `predict_log_proba` methods to make predictions on new data.

Summary
-------

Naive Bayes classifiers provide a fast and simple probabilistic approach to classification based on Bayes' theorem with the assumption of feature independence. The :mod:`sklearn.naive_bayes` module offers several variants of Naive Bayes classifiers suitable for different types of data and applications, all sharing a consistent interface and functionality.
