Discrete Models (:mod:`statsmodels.discrete.discretemod`)
============================================================

Overview
--------

This module provides implementations of zero-inflated count models, which are useful for modeling count data with an excess of zero counts. The zero-inflated models combine a count model with a binary model for the excess zeros, allowing for more flexible modeling of overdispersed count data.

Available Models
----------------

- **ZeroInflatedPoisson**  
  A zero-inflated Poisson model that accounts for excess zeros beyond what the standard Poisson distribution can model.

- **ZeroInflatedGeneralizedPoisson**  
  A zero-inflated generalized Poisson model that extends the Poisson model to allow for overdispersion and zero inflation.

- **ZeroInflatedNegativeBinomialP**  
  A zero-inflated Negative Binomial model parameterized with the probability parameterization, suitable for overdispersed count data with excess zeros.

GenericZeroInflated Class
-------------------------

The `GenericZeroInflated` class serves as a base for zero-inflated count models. It models count data with an additional binary inflation component to capture excess zeros.

Parameters
~~~~~~~~~~

- **endog** : array_like  
  The endogenous response variable (count data).

- **exog** : array_like  
  The exogenous design matrix for the count model.

- **exog_infl** : array_like or None  
  Explanatory variables for the binary inflation model (mixing probability model). If None, a constant term is used.

- **offset** : array_like  
  Offset added to the linear predictor with coefficient fixed at 1.

- **exposure** : array_like  
  Log(exposure) is added to the linear predictor with coefficient fixed at 1.

- **inflation** : string, 'logit' or 'probit'  
  Specifies the model for zero inflation. Can be either 'logit' (default) or 'probit'.

Attributes
~~~~~~~~~~

- **endog** : array  
  Reference to the endogenous response variable.

- **exog** : array  
  Reference to the exogenous design matrix for the count model.

- **exog_infl** : array  
  Reference to the exogenous design matrix for the zero-inflation model.

Details
-------

The zero-inflated models combine two components:

1. A count model (e.g., Poisson, Generalized Poisson, Negative Binomial) that models the count data.

2. A binary inflation model (logit or probit) that models the probability of excess zeros.

The inflation model uses its own set of explanatory variables (`exog_infl`). If none are provided, a constant term is used by default.

The `GenericZeroInflated` class initializes the inflation model based on the specified `inflation` parameter and sets up the corresponding Hessian function for optimization.

Notes
-----

- The number of observations in `exog` and `exog_infl` must be the same; missing data handling for differing lengths is not supported.

- The parameter names for the inflation model are prefixed with `inflate_` to distinguish them from the count model parameters.

- This module relies on components from `statsmodels.discrete.discrete_model` and `statsmodels.distributions` for underlying model implementations and distributions.

Warnings
--------

- Convergence warnings may be issued during model fitting if the optimization does not converge.

See Also

Examples
--------

```python
import statsmodels.api as sm
from statsmodels.discrete.discretemod import ZeroInflatedPoisson

# Example data
endog = [0, 1, 0, 2, 3, 0, 1]
exog = sm.add_constant(np.ones(len(endog)))  # intercept only

# Fit zero-inflated Poisson model
zip_model = ZeroInflatedPoisson(endog, exog, inflation='logit')
result = zip_model.fit()

print(result.summary())
```

This example fits a zero-inflated Poisson model with a logit inflation component to count data with excess zeros.
