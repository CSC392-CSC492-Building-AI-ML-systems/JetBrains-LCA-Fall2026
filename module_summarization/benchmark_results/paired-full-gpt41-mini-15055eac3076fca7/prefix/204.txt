Random Projection
=================

Random Projections provide a simple and computationally efficient method to reduce the dimensionality of data. This technique achieves dimensionality reduction by trading a controlled amount of accuracy—manifested as additional variance—for faster processing times and smaller model sizes.

Overview
--------

The core idea behind Random Projections is to project high-dimensional data into a lower-dimensional space using a random matrix, while approximately preserving the pairwise distances between samples. This is particularly useful in scenarios where the original feature space is very large, and computational efficiency is critical.

The theoretical foundation of Random Projections is the Johnson-Lindenstrauss lemma, which states that a small set of points in a high-dimensional Euclidean space can be embedded into a space of much lower dimension such that the distances between the points are nearly preserved. Formally, for any two points \( u \) and \( v \), the projection \( p \) satisfies:

\[
(1 - \varepsilon) \|u - v\|^2 < \|p(u) - p(v)\|^2 < (1 + \varepsilon) \|u - v\|^2
\]

where \( \varepsilon \in (0, 1) \) controls the distortion level.

Key Features
------------

- **Efficiency:** Random Projection matrices are designed to be computationally efficient to generate and apply.
- **Distance Preservation:** The projection approximately preserves pairwise distances between samples, ensuring that the structure of the data is maintained.
- **Dimensionality Independence:** The required number of components depends primarily on the number of samples and the desired distortion level, rather than the original number of features.
- **Flexibility:** Supports both dense Gaussian random matrices and sparse random matrices for different trade-offs between speed and accuracy.

Johnson-Lindenstrauss Minimum Dimension
---------------------------------------

The function `johnson_lindenstrauss_min_dim` computes a safe lower bound on the number of components needed to guarantee an \(\varepsilon\)-embedding with high probability. The minimum number of components \( n_{\text{components}} \) satisfies:

\[
n_{\text{components}} \geq \frac{4 \log(n_{\text{samples}})}{\varepsilon^2 / 2 - \varepsilon^3 / 3}
\]

where \( n_{\text{samples}} \) is the number of samples in the dataset and \( \varepsilon \) is the maximum allowable distortion.

This bound ensures that the random projection will preserve distances within the specified distortion level.

Usage Example
-------------

```python
from sklearn.random_projection import johnson_lindenstrauss_min_dim

# Compute minimal number of components for 1,000,000 samples with 50% distortion
n_components = johnson_lindenstrauss_min_dim(1_000_000, eps=0.5)
print(n_components)  # Output: 663

# Compute for multiple distortion levels
n_components_array = johnson_lindenstrauss_min_dim(1_000_000, eps=[0.5, 0.1, 0.01])
print(n_components_array)  # Output: array([    663,   11841, 1112658])
```
