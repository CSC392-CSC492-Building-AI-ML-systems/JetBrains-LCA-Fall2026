Getting Started with Mitogen
=============================

Overview
--------
Mitogen is a Python library designed to facilitate efficient and scalable remote code execution and orchestration. It provides core functionality common to master and parent processes and supports recursive connections to child contexts.

Key Features
------------
- Transparent remote execution with minimal overhead.
- Support for recursive parent-child process relationships.
- Compatibility with multiple Python versions, including legacy support for Python 2.4 and 2.5.
- Robust handling of system-level details such as PTY allocation and signal management.
- Awareness of SELinux environments to avoid socketpair usage when necessary.

Installation
------------
Mitogen can be installed via standard Python packaging tools. Ensure your environment meets the necessary system requirements, including Python and relevant system libraries.

Basic Usage
-----------
Mitogen’s core functionality is encapsulated in the `mitogen.core` module, which is automatically imported and used internally. The library manages child contexts and communication channels transparently.

To start using Mitogen in your project:

1. Import the necessary Mitogen modules:
   
   ```python
   import mitogen.core
   ```

2. Use Mitogen’s APIs to create and manage child contexts, execute remote code, and handle communication.

System Compatibility and Requirements
-------------------------------------
- Mitogen detects if SELinux is enabled on the system and adjusts its behavior to avoid socketpair usage, which may be restricted.
- On Linux systems, Mitogen uses ioctl calls to manage PTYs, with safeguards for maximum PTY limits.
- The library handles differences between Python versions, including differences in attribute names and built-in functions.
- If `sys.executable` is not set, Mitogen defaults to using `/usr/bin/python` for child processes and logs a warning.

Advanced Configuration
----------------------
- Mitogen allows setting a pre-execution hook (`_preexec_hook`) that runs before any new child process is exec’d. This can be used to customize process affinity or other settings.
- Logging is integrated and can be configured to adjust verbosity and capture warnings such as missing `sys.executable`.

Troubleshooting
---------------
- If you encounter errors related to PTY allocation, consider increasing system limits such as `kern.tty.ptmx_max` on macOS or `kernel.pty.max` on Linux.
- Warnings about `sys.executable` indicate that Python could not determine its original program name; Mitogen will fall back to a default interpreter path.
- SELinux-enabled systems may restrict certain socket operations; Mitogen detects this and adapts accordingly.

Further Information
-------------------
For detailed API documentation and advanced usage examples, please refer to the full Mitogen documentation and source code. The library is designed to be extensible and adaptable to a wide range of remote execution scenarios.
