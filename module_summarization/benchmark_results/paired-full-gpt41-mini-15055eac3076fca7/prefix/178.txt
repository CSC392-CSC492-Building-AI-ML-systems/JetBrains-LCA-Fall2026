Computational Performance
=========================

Overview
--------

The computational performance of scikit-learn estimators depends on several factors including the choice of the base estimator, the complexity of the model, the size and dimensionality of the dataset, and the efficiency of the underlying implementations.

Multioutput Estimators
----------------------

Scikit-learn provides meta-estimators such as `MultiOutputRegressor`, `MultiOutputClassifier`, `ClassifierChain`, and `RegressorChain` that extend single-output estimators to handle multioutput regression and classification problems. These meta-estimators internally clone and fit multiple copies of the base estimator, one for each output target.

Performance Considerations:
- **Parallelization**: The fitting of individual estimators for each output can be parallelized to improve computational efficiency.
- **Cloning Overhead**: Each output requires cloning the base estimator, which may add overhead depending on the complexity of the estimator.
- **Sample Weighting**: Support for sample weights during fitting can affect performance depending on the estimator’s implementation.

Dependency Versions and Performance
-----------------------------------

The performance of scikit-learn also relies on the versions of its dependencies, which are carefully chosen to balance compatibility and efficiency:

- **NumPy**: Minimum version 1.17.3 (or 1.19.2 for PyPy) ensures optimized numerical operations.
- **SciPy**: Minimum version 1.5.0 provides efficient scientific computations.
- **Joblib**: Minimum version 1.1.1 is used for lightweight pipelining and parallel computing.
- **Threadpoolctl**: Minimum version 2.0.0 manages thread pools for optimized parallelism.
- **Cython**: Minimum version 0.29.33 is used to compile C extensions for performance-critical code.

These dependencies enable scikit-learn to leverage optimized low-level implementations and parallel processing capabilities, which are critical for scaling to large datasets and complex models.

Best Practices for Performance
------------------------------

- **Use Efficient Base Estimators**: Choose base estimators that are optimized for speed and support parallelism when using meta-estimators.
- **Leverage Parallel Computing**: Utilize scikit-learn’s parallel utilities such as `joblib.Parallel` to distribute computations across multiple CPU cores.
- **Manage Sample Weights Carefully**: When using sample weights, ensure that the base estimator efficiently supports them to avoid unnecessary overhead.
- **Keep Dependencies Updated**: Use the recommended minimum versions of dependencies to benefit from performance improvements and bug fixes.

Summary
-------

Scikit-learn’s computational performance is enhanced through the use of meta-estimators that support multioutput tasks, efficient cloning and fitting strategies, and optimized dependencies. By following best practices and leveraging parallelism, users can achieve scalable and efficient machine learning workflows.
