How to Generate Pydantic Models from Tortoise Models
======================================================

This guide explains how to generate Pydantic models from Tortoise ORM models using the utilities provided by `tortoise.contrib.pydantic`. This integration allows you to easily serialize and validate data from your Tortoise models using Pydantic's powerful features.

PydanticMeta Configuration
--------------------------

To customize the generated Pydantic models, you can define an inner class `PydanticMeta` inside your Tortoise model. This class controls which fields are included, excluded, or computed in the resulting Pydantic model.

Example:

.. code-block:: python3

    class Foo(Model):
        foo: fields.CharField(...)
        baa: fields.IntField(...)
        count_peanuts: int

        class PydanticMeta:
            exclude = ("foo", "baa")       # Fields to exclude from the Pydantic model
            computed = ("count_peanuts",)  # Computed fields to include in the Pydantic model

Attributes:

- **include** (`Tuple[str, ...]`): If set, only the fields listed here will be included in the Pydantic model.
- **exclude** (`Tuple[str, ...]`): Fields listed here will be excluded from the Pydantic model.
- **computed** (`Tuple[str, ...]`): Computed fields to be included in the Pydantic model.

Generating Pydantic Models
--------------------------

Use the `pydantic_model_creator` function to generate a Pydantic model class from a Tortoise model.

Signature:

.. code-block:: python3

    def pydantic_model_creator(
        cls: Type[Model],
        *,
        name: Optional[str] = None,
        exclude: Optional[Tuple[str, ...]] = None,
        include: Optional[Tuple[str, ...]] = None,
        computed: Optional[Tuple[str, ...]] = None,
        allow_cycles: bool = False,
        sort_alphabetically: Optional[bool] = None,
        exclude_readonly: bool = False,
    ) -> Type[PydanticModel]:

Parameters:

- **cls**: The Tortoise model class to generate the Pydantic model from.
- **name**: Optional custom name for the generated Pydantic model class.
- **exclude**: Additional fields to exclude from the model.
- **include**: Additional fields to include in the model.
- **computed**: Additional computed fields to include.
- **allow_cycles**: Whether to allow cycles in the generated model (useful for recursive/self-referential models). Defaults to `False`.
- **sort_alphabetically**: If `True`, fields will be sorted alphabetically instead of by field definition order.
- **exclude_readonly**: If `True`, readonly fields will be excluded from the generated model.

Example:

.. code-block:: python3

    from tortoise.contrib.pydantic import pydantic_model_creator

    UserPydantic = pydantic_model_creator(User, name="User")

Using PydanticModel Methods
---------------------------

The generated Pydantic models inherit from `PydanticModel`, which extends Pydantic's `BaseModel` with additional methods tailored for Tortoise ORM.

### from_tortoise_orm

Asynchronously creates a Pydantic model instance from a Tortoise model instance, automatically prefetching all related fields.

.. code-block:: python3

    user_obj = await User.get(id=1)
    user_pydantic = await UserPydantic.from_tortoise_orm(user_obj)

**Note:**

- This method automatically prefetches all relations to avoid `OperationalError` exceptions caused by missing awaited I/O operations.
- If you want to manage prefetching yourself or require a synchronous method, consider using `.from_orm()` instead, but be cautious to exclude relational fields or handle prefetching manually.

### from_queryset

Asynchronously creates a list of Pydantic model instances from a Tortoise queryset, prefetching all relations automatically.

.. code-block:: python3

    users = await UserPydantic.from_queryset(User.all())

### from_queryset_single

Asynchronously creates a single Pydantic model instance from a Tortoise queryset, prefetching all relations automatically.

.. code-block:: python3

    user = await UserPydantic.from_queryset_single(User.filter(id=1))

Handling Relations and Computed Fields
--------------------------------------

- Many-to-many and reverse relations are automatically converted to lists in the Pydantic model.
- Computed fields defined in `PydanticMeta.computed` are included and can be used as regular fields in the Pydantic model.
- The internal validator `_tortoise_convert` ensures that callable values are executed and relation fields are properly converted.

Example of a computed field:

.. code-block:: python3

    class User(Model):
        ...

        @property
        def full_name(self) -> str:
            return f"{self.first_name} {self.last_name}"

        class PydanticMeta:
            computed = ("full_name",)

Summary
-------

- Define `PydanticMeta` inside your Tortoise models to control field inclusion/exclusion.
- Use `pydantic_model_creator` to generate Pydantic models from Tortoise models.
- Use asynchronous methods `.from_tortoise_orm()`, `.from_queryset()`, and `.from_queryset_single()` to create Pydantic model instances with automatic relation prefetching.
- Computed fields and relations are supported and handled automatically.

This integration simplifies serialization and validation of Tortoise ORM models using Pydantic, enabling robust data handling in your asynchronous Python applications.
