Dataset Loading Utilities
=========================

The `sklearn.datasets` module provides a variety of utilities to load and fetch popular reference datasets, as well as generate artificial datasets for experimentation and benchmarking. These utilities facilitate easy access to well-known datasets and simplify the process of preparing data for machine learning tasks.

Loading Reference Datasets
--------------------------

The module includes functions to load classic datasets such as:

- **Breast Cancer Wisconsin dataset**: `load_breast_cancer()`
- **Diabetes dataset**: `load_diabetes()`
- **Digits dataset**: `load_digits()`
- **Iris dataset**: `load_iris()`
- **Linnerud dataset**: `load_linnerud()`
- **Wine dataset**: `load_wine()`

These functions return a dictionary-like object (`Bunch`) containing the data, target labels, and metadata such as feature names and dataset description.

Fetching Larger Datasets
------------------------

For larger datasets that are not included by default, the module provides fetch functions that download the data from online repositories:

- **California Housing dataset**: `fetch_california_housing()`
- **Covertype dataset**: `fetch_covtype()`
- **KDD Cup 1999 dataset**: `fetch_kddcup99()`
- **Labeled Faces in the Wild (LFW) datasets**: `fetch_lfw_people()`, `fetch_lfw_pairs()`
- **Olivetti Faces dataset**: `fetch_olivetti_faces()`
- **OpenML datasets**: `fetch_openml()`
- **RCV1 dataset**: `fetch_rcv1()`

These functions download the datasets on demand and cache them locally for future use.

Example usage:

```python
from sklearn.datasets import fetch_california_housing
housing = fetch_california_housing()
```

or for the Ames housing dataset via OpenML:

```python
from sklearn.datasets import fetch_openml
housing = fetch_openml(name="house_prices", as_frame=True)
```

Note on Ethical Considerations
------------------------------

Some datasets, such as the Boston Housing dataset, have known ethical and fairness issues. The scikit-learn maintainers strongly discourage the use of such datasets except for educational purposes related to ethical issues in data science and machine learning.

If needed, the Boston Housing dataset can be fetched from the original source manually:

```python
import pandas as pd
import numpy as np

data_url = "http://lib.stat.cmu.edu/datasets/boston"
raw_df = pd.read_csv(data_url, sep="\s+", skiprows=22, header=None)
data = np.hstack([raw_df.values[::2, :], raw_df.values[1::2, :2]])
target = raw_df.values[1::2, 2]
```

Dataset Formats and Parsers
---------------------------

The module supports loading datasets in various formats, including the svmlight / libsvm format, which is a sparse text-based format commonly used for large sparse datasets.

### Loading svmlight / libsvm format

```python
from sklearn.datasets import load_svmlight_file

X, y = load_svmlight_file("dataset.svm")
```

- This format stores one sample per line and omits zero-valued features, making it efficient for sparse data.
- The first element of each line is typically the target variable.
- The loader returns a sparse CSR matrix for the features.
- Optional parameters allow control over the number of features, data type, multilabel targets, and handling of query IDs (pairwise preference constraints).

Performance Considerations
--------------------------

Parsing text-based dataset formats can be computationally expensive. To improve loading times when repeatedly working with the same dataset, it is recommended to cache the results using `joblib.Memory.cache`. This approach stores a memory-mapped backup of the processed data, enabling near-instantaneous loading on subsequent calls.

Artificial Dataset Generators
----------------------------

The module also includes functions to generate synthetic datasets for testing and benchmarking machine learning algorithms, such as:

- `make_blobs()`
- `make_classification()`
- `make_circles()`
- `make_checkerboard()`
- `make_friedman1()`, `make_friedman2()`, `make_friedman3()`
- `make_gaussian_quantiles()`
- `make_biclusters()`

These generators allow customization of dataset properties such as number of samples, features, clusters, and noise.

Summary
-------

The `sklearn.datasets` module is a comprehensive resource for accessing a wide range of datasets and generating synthetic data, facilitating experimentation and development in machine learning. It provides convenient functions to load, fetch, and generate datasets in various formats, with considerations for performance and ethical use.
