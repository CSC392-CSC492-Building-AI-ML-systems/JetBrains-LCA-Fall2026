Contributing to Qiskit Metal
============================

Welcome to the Qiskit Metal contributor guide! We appreciate your interest in contributing to Qiskit Metal, a framework designed to facilitate the design and analysis of quantum devices.

Code Structure and Modules
--------------------------

Qiskit Metal is organized into several modules, including but not limited to:

- **Analyses**: This module contains electromagnetic and Hamiltonian analyses tools, such as energy-participation analyses and impedance-based analyses.
- **Electromagnetic Analyses (`qiskit_metal.analyses.em`)**: Provides tools for electromagnetic simulations and calculations.
- **Hamiltonian Analyses (`qiskit_metal.analyses.hamiltonian`)**: Contains analyses focused on Hamiltonian computations.
- **Quantization Tools**: Includes lumped capacitive models and other quantization-related utilities.

Each module is documented with author and date information, and includes detailed descriptions of its purpose and functionality.

Contribution Guidelines
-----------------------

- **Code Quality**: Please ensure your code adheres to the existing style and conventions used throughout Qiskit Metal.
- **Documentation**: Contributions should include appropriate documentation strings and comments to maintain clarity and usability.
- **Testing**: Include tests for new features or bug fixes to ensure code reliability.
- **Copyright Notices**: Retain all existing copyright notices in modified files and add notices indicating your changes.
- **Licensing**: Contributions must comply with the Apache License, Version 2.0.

Getting Started
---------------

To contribute effectively:

1. Familiarize yourself with the Qiskit Metal codebase and its modules.
2. Follow the naming conventions and code organization patterns already established.
3. Use the provided analysis functions and utilities as references for your implementations.
4. When working with capacitance matrices or other data structures, ensure they follow the expected formats and ordering conventions.
