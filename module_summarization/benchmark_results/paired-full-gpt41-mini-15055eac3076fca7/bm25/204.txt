Random Projection Transformers
==============================

Random Projections provide a simple and computationally efficient method to reduce the dimensionality of data. By accepting a controlled amount of accuracy loss—manifested as additional variance—these techniques enable faster processing times and smaller model sizes without significantly compromising the quality of the data representation.

Overview
--------

The core idea behind Random Projections is to project high-dimensional data into a lower-dimensional space using a random matrix, while approximately preserving the pairwise distances between samples. This is grounded in the Johnson-Lindenstrauss lemma, which states that a small set of points in a high-dimensional space can be embedded into a space of much lower dimension such that distances between the points are nearly preserved. The embedding map can be chosen to be Lipschitz continuous and even orthogonal.

Key Concepts
------------

- **Dimensionality Reduction:** Random Projection reduces the number of features in the dataset by projecting data onto a randomly generated subspace.
- **Distance Preservation:** The random projection matrices are constructed to maintain the relative distances between data points, ensuring that the structure of the data is largely retained.
- **Computational Efficiency:** Compared to other dimensionality reduction techniques, Random Projections are faster and require less memory, making them suitable for large-scale data.

Types of Random Projection Transformers
---------------------------------------

### Gaussian Random Projection

This transformer uses a dense random matrix with entries drawn from a Gaussian distribution. It is suitable when a dense projection matrix is acceptable and can provide high-quality embeddings.

### Sparse Random Projection

Sparse Random Projection employs a sparse random matrix, which is more memory efficient and allows faster computation. The components of the sparse matrix are drawn from a distribution controlled by a density parameter, typically set to values like 1/3 or 1/√n_features, as recommended in the literature. The sparsity pattern helps in reducing computational overhead while maintaining embedding quality.

Parameters and Attributes
-------------------------

- **n_components:** Number of dimensions to project the data onto. Can be set to "auto" to determine the optimal number based on the Johnson-Lindenstrauss lemma.
- **density:** For sparse projections, controls the sparsity of the random matrix.
- **eps:** Controls the quality of the embedding when `n_components` is set to "auto". Smaller values lead to better embeddings but higher dimensionality.
- **dense_output:** Determines whether the output is a dense array or sparse matrix when the input is sparse.
- **compute_inverse_components:** If True, computes the pseudo-inverse of the projection matrix to enable inverse transformations.

Usage Example
-------------

```python
import numpy as np
from sklearn.random_projection import GaussianRandomProjection

rng = np.random.RandomState(42)
X = rng.rand(100, 1000)  # Original high-dimensional data

transformer = GaussianRandomProjection(n_components=100, random_state=rng)
X_new = transformer.fit_transform(X)
```

Advantages
----------

- **Scalability:** Efficient for large datasets due to low computational and memory requirements.
- **Simplicity:** Easy to implement and use without complex parameter tuning.
- **Theoretical Guarantees:** Backed by the Johnson-Lindenstrauss lemma ensuring distance preservation.
