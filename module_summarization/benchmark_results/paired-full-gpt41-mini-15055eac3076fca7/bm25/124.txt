Header Interface Transition Guide
=================================

This guide provides information on transitioning from the old `Header.update()` method to the new interface methods available in the `Header` class.

Overview
--------

The `Header` class represents a FITS header and provides both dictionary-like and list-like interfaces to manipulate header cards. In previous versions, the `Header.update()` method was commonly used to add or modify header cards. However, this method has been replaced with new methods that offer clearer and more flexible interfaces.

Transition from `Header.update()` to `Header.insert()`
-----------------------------------------------------

The old usage of `Header.update()` to insert or update header cards should be replaced with the `Header.insert()` method as follows:

- To insert a card before a specified keyword:

  .. code-block:: python

      # Old usage
      header.update(keyword, value, before=before_keyword)

      # New usage
      header.insert(before_keyword, (keyword, value))

- To insert a card after a specified keyword:

  .. code-block:: python

      # Old usage
      header.update(keyword, value, after=after_keyword)

      # New usage
      header.insert(after_keyword, (keyword, value), after=True)

Using `Header.set()` for Easier Transition
------------------------------------------

The `Header` class also provides a new method, `Header.set()`, which offers an interface similar to the old `Header.update()` method. This method may help ease the transition by allowing code to be updated incrementally without immediately switching to `insert()`.

Summary
-------

- Replace `header.update(keyword, value, before=before_keyword)` with `header.insert(before_keyword, (keyword, value))`.
- Replace `header.update(keyword, value, after=after_keyword)` with `header.insert(after_keyword, (keyword, value), after=True)`.
- Consider using `Header.set()` as a transitional method that mimics the old `update()` behavior.

This transition improves clarity and consistency in manipulating FITS headers and aligns with the evolving design of the `Header` class interface.
