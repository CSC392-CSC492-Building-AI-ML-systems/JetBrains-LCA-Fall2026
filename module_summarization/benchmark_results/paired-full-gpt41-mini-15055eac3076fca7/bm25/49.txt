Duration Module
===============

Overview
--------
This module provides implementations of proportional hazards regression models for duration data that may be censored, commonly known as Cox models. It includes functionality for estimating model parameters, obtaining distribution estimates, making predictions, and plotting survivor functions.

Key Features
------------

Proportional Hazards Regression Models
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
The module implements Cox proportional hazards models which are widely used in survival analysis and duration data modeling. These models handle censored data and estimate the effect of covariates on the hazard rate.

Parameter Estimation and Standard Errors
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
The module provides methods to obtain parameter estimates and their standard errors, facilitating inference about the effects of covariates on duration outcomes.

Distribution Estimation
~~~~~~~~~~~~~~~~~~~~~~~
Functions are available to return scipy distribution objects corresponding to the distribution of uncensored endogenous (duration) values for each case. These distributions are derived from discrete estimates of the survivor function, placing all mass on observed failure times within strata.

Prediction
~~~~~~~~~~
Prediction methods allow computation of various quantities such as log hazard ratios and survival probabilities based on the fitted model parameters and covariates. The prediction interface supports different prediction types and transformations.

Survivor Function Plotting
~~~~~~~~~~~~~~~~~~~~~~~~~~
The module includes utilities to plot one or more survivor functions, supporting visualization of survival probabilities over time. It handles multiple groups and censored data points, providing clear and informative plots.

Usage Examples
--------------

Plotting Survivor Functions
~~~~~~~~~~~~~~~~~~~~~~~~~~~
The `plot_survfunc` function can be used to plot survivor functions from one or more `SurvfuncRight` objects.

Example:

```python
import statsmodels.api as sm
from statsmodels.duration.survfunc import plot_survfunc

data = sm.datasets.get_rdataset("flchain", "survival").data
df = data.loc[data.sex == "F", :]
sf0 = sm.SurvfuncRight(df["futime"], df["death"])
sf1 = sm.SurvfuncRight(3.0 * df["futime"], df["death"])
fig = plot_survfunc([sf0, sf1])
ax = fig.get_axes()[0]
ax.set_position([0.1, 0.1, 0.64, 0.8])
ha, lb = ax.get_legend_handles_labels()
leg = fig.legend((ha[0], ha[1]), (lb[0], lb[1]), 'center right')

# Customize line colors
ha[0].set_color('purple')
ha[1].set_color('orange')
```

Notes
-----
- The distribution estimates are based on discrete survivor functions that assign probability mass to observed failure times within strata.
- The module supports weighted tests and Z-scale test statistics for model evaluation.
- The plotting utilities handle censored data points by marking them distinctly on survivor function plots.

This module is a valuable tool for survival analysis, providing robust methods for modeling, inference, prediction, and visualization of duration data with censoring.
