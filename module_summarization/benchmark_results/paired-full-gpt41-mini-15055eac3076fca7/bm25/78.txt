Generate documentation for this module
======================================

This module provides functionality to read from and write to filenodes within PyTables files. Filenodes allow storing file contents inside HDF5 files managed by PyTables, enabling seamless integration of external files into HDF5 datasets.

Functions
---------

read_from_filenode(h5file, filename, where, name=None, overwrite=False, create_target=False)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Read a filenode from a PyTables file and write its contents to a file.

.. versionadded:: 3.2

Parameters
----------
h5file : str or :class:`File`
    The PyTables file to be read from; can be either a string giving the file's location or a :class:`File` object.

filename : str
    Path of the file where the contents of the filenode shall be written to. If *filename* points to a directory or ends with a path separator (``/`` on Unix, ``\`` on Windows), the filename will be set to the *_filename* attribute of the read filenode if present; otherwise, the filenode's *name* attribute.

where : str or :class:`Group`
    Location of the filenode where the data shall be read from.

name : str, optional
    Name of the filenode to read. If no node with this name can be found at *where*, the first node at *where* whose *_filename* attribute matches *name* will be read.

overwrite : bool, optional
    Whether or not a possibly existing file at the specified *filename* shall be overwritten.

create_target : bool, optional
    Whether to create the target directory hierarchy if it does not exist.

Raises
------
OSError
    If the target file exists and *overwrite* is False, or if the file cannot be written to.

NodeError
    If the specified filenode cannot be found at the given location.

save_to_filenode(h5file, filename, where, name=None, overwrite=False, title="", filters=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Save a file's contents to a filenode inside a PyTables file.

.. versionadded:: 3.2

Parameters
----------
h5file : str or :class:`File`
    The PyTables file to be written to; can be either a string giving the file's location or a :class:`File` object. If a file with name *h5file* already exists, it will be opened in append mode (`a`).

filename : str
    Path of the file which shall be stored within the PyTables file.

where : str or :class:`Group`
    Location of the filenode where the data shall be stored.

name : str, optional
    Name of the filenode to create. If not given, and *where* is either a :class:`Group` object or a string ending with a path separator, the leaf name will be set to the file name of *filename*. The *name* will be modified to adhere to Python's natural naming conventions; the original filename will be preserved in the filenode's *_filename* attribute.

overwrite : bool, optional
    Whether or not a possibly existing filenode of the specified name shall be overwritten.

title : str, optional
    A description for this node (sets the ``TITLE`` HDF5 attribute on disk).

filters : :class:`Filters`, optional
    An instance of the :class:`Filters` class that provides information about the desired I/O filters to be applied during the life of this object.

Raises
------
OSError
    If the source file cannot be read, or if the PyTables file is opened read-only, or if the filenode already exists and *overwrite* is False.

Notes
-----
- When writing to a filenode, if a filenode with the specified name already exists and *overwrite* is True, the existing filenode will be removed before writing the new data.
- The original filename is stored in the filenode's *_filename* attribute to preserve the source file's name.
- The module ensures proper cleanup of file handles after operations.

Summary
-------
This module facilitates embedding external files into PyTables HDF5 files as filenodes, and extracting them back to the filesystem. It handles naming conventions, file overwriting policies, and directory creation to provide a robust interface for managing file contents within HDF5 containers.
