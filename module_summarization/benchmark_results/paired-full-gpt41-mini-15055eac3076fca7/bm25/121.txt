Create Cradmin Menu System
==========================

The Cradmin menu system provides a flexible and extensible way to create menus in your Django applications using the Cradmin framework. It is built around renderable components that can be combined to form complex menus with buttons, links, separators, and expandable menu items.

Key Components
--------------

### Menu Renderables

The menu system is composed of renderable objects that represent different menu elements:

- **Buttons**: Created using the `make_button_renderable` method and can be appended, prepended, or inserted into the menu.
- **Links**: Created using the `make_link_renderable` method and can be appended, prepended, or inserted similarly.
- **Separators**: Created using the `make_separator_renderable` method to visually separate menu items.
- **Expandable Menu Items**: Special menu items that can expand to show nested menu items.

### Adding Menu Items

You can add items to the menu using the following methods:

- `append_button(**kwargs)`: Creates a button renderable and appends it to the menu.
- `prepend_button(**kwargs)`: Creates a button renderable and prepends it to the menu.
- `insert_button(index, **kwargs)`: Inserts a button renderable at the specified index.
- `append_link(**kwargs)`: Creates a link renderable and appends it to the menu.
- `prepend_link(**kwargs)`: Creates a link renderable and prepends it to the menu.
- `insert_link(index, **kwargs)`: Inserts a link renderable at the specified index.
- `append_separator(**kwargs)`: Creates a separator renderable and appends it to the menu.
- `prepend_separator(**kwargs)`: Creates a separator renderable and prepends it to the menu.
- `insert_separator(index, **kwargs)`: Inserts a separator renderable at the specified index.

Each of these methods internally uses the corresponding `make_*_renderable` method to create the renderable object before adding it to the menu.

### Renderable Classes

- **BaseMenuLinkRenderable**  
  Represents a basic menu link item. It accepts parameters such as `label`, `url`, and `is_active` to indicate the link text, destination URL, and active state respectively. It supports BEM (Block Element Modifier) CSS methodology for styling through `bem_variant_list` and `parent_bem_block`.

- **ExpandableMenuSeparator**  
  Represents a separator within an expandable menu. It supports BEM styling and uses the template `'django_cradmin/crmenu/menuitem/expandable-menu-separator.django.html'`.

- **ExpandableMenuItem**  
  Represents an expandable menu item that can contain nested menu items. It uses the template `'django_cradmin/crmenu/menuitem/expandable-menu-item.django.html'` and supports BEM styling conventions.

### BEM Styling

The menu system uses BEM (Block Element Modifier) methodology for CSS class naming to ensure consistent and maintainable styling. Each renderable provides methods such as:

- `get_parent_bem_block()`
- `get_fallback_parent_bem_block()`
- `get_bem_element()`
- `get_list_element_bem_element()`

These methods help define the CSS classes applied to the menu elements.

### Default Expandable Menu Renderable

You can retrieve the default expandable menu renderable class configured in your Django settings via the `DJANGO_CRADMIN_DEFAULT_EXPANDABLE_MENU_CLASS` setting. Use the helper function:

```python
get_default_expandable_menu_renderable(**kwargs)
```

This function imports and instantiates the default expandable menu renderable class, passing any provided keyword arguments.

Usage Example
-------------

Here is a conceptual example of how to create a menu and add items:

```python
menu = SomeMenuRenderableClass()

# Add a button
menu.append_button(label='Save', url='/save/', is_active=True)

# Add a link
menu.append_link(label='Home', url='/home/')

# Add a separator
menu.append_separator()

# Insert a link at position 1
menu.insert_link(1, label='Settings', url='/settings/')
```

Templates
---------

The menu system uses Django templates to render the menu items. Some of the key templates include:

- `'django_cradmin/crmenu/menuitem/link.django.html'` for basic links.
- `'django_cradmin/crmenu/menuitem/expandable-menu-item.django.html'` for expandable menu items.
- `'django_cradmin/crmenu/menuitem/expandable-menu-separator.django.html'` for separators in expandable menus.

Customization
-------------

You can customize the menu by subclassing the renderable classes and overriding methods such as `get_wrapper_htmltag()` to change the HTML tag wrapping the menu, or by providing custom templates.

Summary
-------

The Cradmin menu system offers a structured and extensible approach to building menus in Django applications. By leveraging renderable components, BEM styling, and configurable templates, it allows developers to create rich and interactive menus tailored to their application's needs.
