Polys Module Documentation
==========================

Overview
--------
This module provides functionality for polynomial manipulation, factorization, and root isolation over various algebraic domains. It includes classes representing options and flags for polynomial operations, as well as methods for polynomial factorization, root isolation, and handling polynomials over different fields such as rational, real algebraic, and complex algebraic fields.

Key Features
------------
- Polynomial factorization and square-free decomposition.
- Isolation of real roots for polynomials over supported domains.
- Handling of polynomials over rational, real algebraic, and complex algebraic fields.
- Support for polynomial manipulation options via Boolean flags.
- Utilities for working with polynomial domains and extensions.

Classes
-------

BooleanOption (Flag)
~~~~~~~~~~~~~~~~~~~~
Base class for boolean options used in polynomial manipulation functions.

- `default()`  
  Returns the default value for the option.

- `postprocess(options)`  
  Adjusts options after initial parsing, e.g., disables automatic domain detection if domain or field is explicitly specified.

Frac (BooleanOption, Flag)
~~~~~~~~~~~~~~~~~~~~~~~~~~
Represents the ``frac`` option for polynomial manipulation functions.

- `option`  
  The option name: `'frac'`.

- `default()`  
  Returns `False` indicating that fractional mode is off by default.

Formal (BooleanOption, Flag)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Represents the ``formal`` flag for polynomial manipulation functions.

- `option`  
  The option name: `'formal'`.

- `default()`  
  Returns `False` indicating that formal mode is off by default.

Polys (BooleanOption, Flag)
~~~~~~~~~~~~~~~~~~~~~~~~~~~
Represents the ``polys`` flag for polynomial manipulation functions.

- `option`  
  The option name: `'polys'`.

Include (BooleanOption, Flag)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Represents the ``include`` flag for polynomial manipulation functions.

- `option`  
  The option name: `'include'`.

- `default()`  
  Returns `False` indicating that inclusion is off by default.

Gen (Flag)
~~~~~~~~~~
Represents the ``gen`` flag for polynomial manipulation functions.

Polynomial Factorization and Root Isolation
-------------------------------------------

The module supports polynomial factorization using square-free decomposition and trial division methods. It handles polynomials over various domains by setting and clearing denominators, computing greatest common divisors (GCD), and factoring polynomials into irreducible components.

Root isolation is supported for polynomials over rational fields and complex algebraic fields with real algebraic subfields. The isolation process involves:

- Checking domain compatibility for root isolation.
- Handling polynomials with zero roots based on interval bounds.
- Computing GCDs and factoring polynomials accordingly.
- Using Chebyshev polynomials for minimal polynomial computations related to roots of the form sin(πp/q).
- Returning isolated roots with multiplicities.

Example Usage
-------------

Factorization and root isolation typically involve:

1. Setting the polynomial domain appropriately.
2. Clearing denominators and computing GCDs.
3. Decomposing polynomials into square-free factors.
4. Isolating roots within specified intervals.
5. Handling special cases such as roots at zero or roots related to trigonometric minimal polynomials.

Error Handling
--------------

- Raises `DomainError` if root isolation is attempted over unsupported domains.
- Ensures that polynomial domains are compatible with the operations being performed.

Notes

- The module relies on underlying polynomial ring implementations and domain field properties.
- It supports advanced polynomial operations necessary for symbolic computation and algebraic number theory.
- The options classes provide a flexible interface for enabling or disabling features in polynomial manipulation functions.
