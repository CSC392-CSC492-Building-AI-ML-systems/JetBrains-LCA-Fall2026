Generate Documentation for This Module
======================================

This module provides command functions for managing Alembic migration environments and revisions. The commands include listing available templates, initializing a new migration environment, and creating new revision files.

Functions
---------

list_templates(config: Config)  
    List available migration environment templates.

    Parameters:
        config (Config): An Alembic configuration object.

    Description:
        Prints the list of available templates found in the template directory specified by the configuration. For each template, it displays the template name and a brief synopsis extracted from the template's README file. Also provides an example of how to use templates with the `init` command.

init(config: Config, directory: str, template: str = "generic", package: bool = False) -> None  
    Initialize a new Alembic scripts directory.

    Parameters:
        config (Config): An Alembic configuration object.
        directory (str): The target directory path where the migration environment will be created.
        template (str, optional): The name of the migration environment template to use. Defaults to "generic".
        package (bool, optional): If True, writes `__init__.py` files into the environment directory and the versions directory to make them Python packages. Defaults to False.

    Description:
        Creates a new migration environment directory structure at the specified location. It verifies that the target directory does not already exist or is empty. It copies files from the selected template directory into the target directory, including generating the `alembic.ini` configuration file if it does not already exist. If the `package` flag is set, it adds `__init__.py` files to the environment and versions directories. Finally, it prompts the user to edit the configuration file before proceeding.

revision(
    config: Config,
    message: Optional[str] = None,
    autogenerate: bool = False,
    sql: bool = False,
    head: str = "head",
    splice: bool = False,
    branch_label: Optional[str] = None,
    version_path: Optional[str] = None,
    rev_id: Optional[str] = None,
    depends_on: Optional[str] = None,
    process_revision_directives: Optional[ProcessRevisionDirectiveFn] = None
) -> Union[Optional[Script], List[Optional[Script]]]

    Create a new revision file.

    Parameters:
        config (Config): An Alembic configuration object.
        message (Optional[str]): The message string to apply to the revision (corresponds to the `-m` option).
        autogenerate (bool): Whether to autogenerate the revision script from the database schema (corresponds to the `--autogenerate` option).
        sql (bool): Whether to output the revision script as SQL to stdout instead of creating a file (corresponds to the `--sql` option).
        head (str): The head revision identifier to build the new revision upon (corresponds to the `--head` option).
        splice (bool): Whether to create the new revision as a new head, required if the specified head is not itself a head (corresponds to the `--splice` option).
        branch_label (Optional[str]): Label for the branch.
        version_path (Optional[str]): Path to place the revision file.
        rev_id (Optional[str]): Specific revision ID to use.
        depends_on (Optional[str]): Revision ID that this revision depends on.
        process_revision_directives (Optional[ProcessRevisionDirectiveFn]): A callback function to process revision directives.

    Returns:
        Union[Optional[Script], List[Optional[Script]]]: The created revision script(s), or None if outputting SQL.

    Description:
        Generates a new Alembic revision script file according to the specified parameters. Supports autogeneration of migration scripts based on database schema changes, outputting SQL scripts, branching, and revision dependencies. The function allows customization of the revision creation process through various options and a callback for processing revision directives.

Usage Notes
-----------

- The `list_templates` command helps users discover available migration environment templates.
- The `init` command sets up a new migration environment directory structure, copying template files and optionally making the directories Python packages.
- The `revision` command creates new migration scripts, supporting both manual and autogeneration workflows, as well as SQL output for review or manual application.

This module is intended to be used as part of Alembic's command-line interface or programmatically to manage database schema migrations efficiently.
