GILDAS CLASS File Reader
=======================

Overview
--------

This module provides functionality to read GILDAS CLASS files and convert them into `pyspeckit.spectrum.ObsBlock` objects for further analysis. CLASS files are a standard format used in radio astronomy for storing spectral data.

Features
--------

- Supports multiple CLASS file types and versions, including IEEE and VAX formats.
- Handles different record lengths and header types as specified by the CLASS file format.
- Includes utilities for timing function execution to monitor performance during file reading.
- Provides compatibility with both Python 2 and Python 3 using the `six` library.
- Uses `astropy` for logging and unit handling.
- Gracefully degrades progress bar functionality if `astropy.utils.console.ProgressBar` is unavailable.

Key Components
--------------

- **filetype_dict**: A dictionary mapping CLASS file type codes (both string and byte forms) to descriptive names indicating the file format variant.
- **fileversion_dict**: Maps file type codes to version identifiers.
- **record_lengths**: Defines the byte length of records for different CLASS file versions.
- **header_id_numbers**: Maps header ID numbers to their descriptive names, including standard and private headers.
- **header_id_lengths**: Specifies the expected length of certain header types.
- **print_timing(func)**: A decorator function that logs the execution time of the decorated function, useful for profiling file reading operations.
- **ensure_bytes(string)**: Utility function to ensure strings are in byte format, supporting compatibility across Python versions.

Usage
-----

The module is intended to be used as part of the `pyspeckit` package to load CLASS files into spectral observation blocks. It abstracts the complexities of the CLASS file format, allowing users to focus on data analysis.

References
----------

- CLASS file format specification: http://iram.fr/IRAMFR/GILDAS/doc/html/class-html/node58.html
- `pyspeckit` package: https://pyspeckit.readthedocs.io/

Notes
-----

- Some header types are marked as "private" and correspond to specialized fitting routines (e.g., GAUSSFIT, SHELLFIT).
- The module currently includes placeholders and partial implementations for certain CLASS file components.
- Progress bar functionality depends on `astropy.utils.console.ProgressBar` and falls back silently if unavailable.

This module is a foundational component for handling CLASS files within the `pyspeckit` ecosystem, facilitating the integration of CLASS spectral data into Python-based workflows.
