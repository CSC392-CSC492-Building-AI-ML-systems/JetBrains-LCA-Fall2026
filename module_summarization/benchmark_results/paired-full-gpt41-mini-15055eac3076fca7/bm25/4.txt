Sync Users with LDAP
====================

This document describes how to synchronize users with an LDAP directory using the available API functionality.

Overview
--------

The system supports executing a delayed job to synchronize users with LDAP. This operation is performed asynchronously on the server and returns a job entity representing the synchronization task.

Delayed Job for LDAP User Synchronization
-----------------------------------------

To initiate the synchronization of users with LDAP, use the `delayed_job` method on the session object with the job type `SYNC_USERS_LDAP`.

```python
job_data = session.delayed_job(ftrack_api.symbol.JOB_SYNC_USERS_LDAP)
```

- **job_type**: Must be `ftrack_api.symbol.JOB_SYNC_USERS_LDAP`.
- The method returns a `ftrack.entity.job.Job` instance representing the synchronization job.

If an invalid job type is provided, a `ValueError` will be raised.

Example Usage
-------------

```python
try:
    job = session.delayed_job(ftrack_api.symbol.JOB_SYNC_USERS_LDAP)
    print("LDAP user synchronization job started:", job)
except ValueError as e:
    print("Invalid job type:", e)
except ftrack_api.exception.ServerError as error:
    print("Server error occurred:", error)
```

Notes
-----

- The `delayed_job` method is deprecated in favor of `session.call`. Please refer to the latest release notes for updated usage.
- The synchronization job runs asynchronously on the server, allowing you to continue other operations while the sync is in progress.
- The returned job entity can be used to monitor the status of the synchronization.

User Invitation Methods
-----------------------

In addition to LDAP synchronization, the API provides methods to send invitations to users:

- `send_user_invite(user)`: Sends an invitation to a single user.
- `send_user_invites(users)`: Sends invitations to a list of users.

Both methods expect `User` instances as input.

Example:

```python
session.send_user_invite(user)
session.send_user_invites([user1, user2, user3])
```

These methods internally queue operations to send invitations to the specified users.

Summary
-------

- Use `session.delayed_job(ftrack_api.symbol.JOB_SYNC_USERS_LDAP)` to start LDAP user synchronization.
- Handle exceptions for invalid job types or server errors.
- Use user invitation methods to send invites to users as needed.

For more detailed information on session methods and job handling, refer to the API documentation.
