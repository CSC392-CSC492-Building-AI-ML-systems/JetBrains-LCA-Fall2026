Pairwise Metrics, Affinities and Kernels
========================================

Pairwise metrics, affinities, and kernels are fundamental tools in machine learning and data analysis for measuring similarity or dissimilarity between samples. This document provides an overview of the available pairwise metrics and kernels, their usage, and the functions they map to.

Pairwise Metrics
----------------

Pairwise metrics compute distances or dissimilarities between pairs of samples. They are often used in clustering, nearest neighbors search, and other algorithms that rely on distance computations.

Pairwise Kernels
----------------

Kernels are functions that compute a similarity measure between pairs of samples, often implicitly mapping data into higher-dimensional feature spaces. Kernels are widely used in kernel methods such as Support Vector Machines (SVMs) and kernel PCA.

The `pairwise_kernels` function computes the kernel between arrays `X` and an optional array `Y`. It accepts either feature arrays or precomputed kernel matrices as input and returns a kernel matrix.

Usage
-----

```python
pairwise_kernels(X, Y=None, metric='linear', *, filter_params=False, n_jobs=None, **kwds)
```

- **X** : array-like or sparse matrix, shape (n_samples_X, n_features) or (n_samples_X, n_samples_X)  
  Input data or kernel matrix. If `metric='precomputed'`, `X` should be a kernel matrix of shape (n_samples_X, n_samples_X). Otherwise, it should be a feature array.

- **Y** : array-like or sparse matrix, shape (n_samples_Y, n_features), default=None  
  Optional second feature array to compute pairwise kernels between `X` and `Y`.

- **metric** : str or callable, default='linear'  
  The kernel metric to use. Can be a string identifying a valid kernel or a callable function.

- **filter_params** : bool, default=False  
  Whether to filter the parameters passed to the kernel function.

- **n_jobs** : int or None, default=None  
  The number of jobs to run in parallel.

- **kwds** : additional keyword arguments  
  Additional parameters passed to the kernel function.

Valid Kernel Metrics
--------------------

The following kernel metrics are supported, along with their corresponding functions:

+==================+==============================================+
| Metric           | Function                                     |
+==================+==============================================+
| 'additive_chi2'  | `sklearn.pairwise.additive_chi2_kernel`     |
| 'chi2'           | `sklearn.pairwise.chi2_kernel`               |
| 'linear'         | `sklearn.pairwise.linear_kernel`             |
| 'poly'           | `sklearn.pairwise.polynomial_kernel`         |
| 'polynomial'     | `sklearn.pairwise.polynomial_kernel`         |
| 'rbf'            | `sklearn.pairwise.rbf_kernel`                 |
| 'laplacian'      | `sklearn.pairwise.laplacian_kernel`           |
| 'sigmoid'        | `sklearn.pairwise.sigmoid_kernel`             |
| 'cosine'         | `sklearn.pairwise.cosine_similarity`          |
+==================+==============================================+

Kernel Parameters
-----------------

Each kernel metric may accept specific parameters:

- **additive_chi2**: no parameters  
- **chi2**: `gamma`  
- **cosine**: no parameters  
- **linear**: no parameters  
- **poly**, **polynomial**: `gamma`, `degree`, `coef0`  
- **rbf**: `gamma`  
- **laplacian**: `gamma`  
- **sigmoid**: `gamma`, `coef0`  

These parameters can be passed as keyword arguments to `pairwise_kernels`.

Callable Metrics
----------------

In addition to string identifiers, a callable metric function can be provided. The callable should accept two 1-D arrays and return a float representing the similarity or distance between them.

When `X` and `Y` are the same object, the computation is optimized by calculating only the upper triangle of the output matrix and then symmetrizing it. The diagonal elements are also computed by applying the metric to each sample with itself.

Summary
-------

- Pairwise metrics measure distances or dissimilarities between samples.
- Kernels compute similarity measures and are used in kernel-based algorithms.
- The `pairwise_kernels` function supports a variety of kernel metrics and callable functions.
- Kernel parameters allow customization of kernel behavior.
- Efficient computation is implemented for callable metrics when inputs are identical.

This documentation provides a concise overview of pairwise metrics, affinities, and kernels to assist in selecting and using appropriate similarity measures in machine learning workflows.
