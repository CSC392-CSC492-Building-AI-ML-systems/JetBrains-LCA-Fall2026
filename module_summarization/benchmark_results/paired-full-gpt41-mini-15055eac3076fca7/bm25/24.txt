w_init — Initialize a new WEST simulation
==========================================

Synopsis
--------

```
w_init [OPTIONS]
```

Description
-----------

The `w_init` command initializes a new WEST simulation by creating the WEST HDF5 file and preparing the first iteration's segments.

Initial states for the simulation are generated from one or more *basis states*. These basis states can be specified either by providing a file with the `--bstates-from` option or by one or more `--bstate` arguments on the command line. If neither `--bstates-from` nor at least one `--bstate` argument is provided, a default basis state with probability one, identified by the state ID zero and label `"basis"`, will be created. A warning will be printed in this case to remind you of this default behavior.

For (non-equilibrium) steady-state simulations, *target states* can be specified either by providing a file with the `--tstates-from` option or by one or more `--tstate` arguments. If neither `--tstates-from` nor at least one `--tstate` argument is provided, an equilibrium simulation (without any sinks) will be performed.

Options
-------

- `--bstates-from BSTATE_FILE`, `--bstate-file BSTATE_FILE`  
  Read basis state names, probabilities, and optionally data references from the specified file.

- `--bstate 'label,probability[,auxref]'`  
  Add a basis state specified as a string to the list of basis states. This option may be specified multiple times to append multiple basis states in the order they appear on the command line.

- `--tstates-from TSTATE_FILE`, `--tstate-file TSTATE_FILE`  
  Read target state names and representative progress coordinates from the specified file. WESTPA uses the representative progress coordinate of a target state and converts the entire bin containing that progress coordinate into a recycling sink.

- `--tstate 'label,pcoord0[,pcoord1[,...]]'`  
  Add a target state specified as a string to the list of target states. This option may be specified multiple times to append multiple target states in the order they appear on the command line.

- `--sstates-from SSTATE_FILE`, `--sstate-file SSTATE_FILE`  
  Read start state names, probabilities, and optionally data references from the specified file.

- `--sstate 'label,probability[,auxref]'`  
  Add a start state specified as a string to the list of start states. This option may be specified multiple times to append multiple start states in the order they appear on the command line.

- `--segs-per-state N`  
  Initialize `N` segments from each basis state. Default is 1.

- `--no-we`, `--shotgun`  
  Do not run the weighted ensemble bin/split/merge algorithm on newly-created segments.

- `--force`  
  Overwrite any existing simulation data.

Additional options related to work managers and environment configuration may also be specified; these are handled internally by WESTPA.

Usage Notes
-----------

- If no basis states are specified, a default basis state with label `"basis"` and probability 1.0 will be created automatically.

- Target states define recycling sinks for steady-state simulations. If no target states are specified, the simulation will run as an equilibrium simulation without sinks.

- The `--no-we` option is useful for initializing segments without applying the weighted ensemble resampling algorithm, which can be helpful for certain types of simulations or debugging.

- The `--force` option allows overwriting existing simulation data files, which is useful when restarting or reinitializing a simulation.

Examples
--------

Initialize a simulation with basis states read from a file and 5 segments per basis state:

```
w_init --bstates-from basis_states.txt --segs-per-state 5
```

Initialize a simulation with two basis states specified on the command line and target states from a file:

```
w_init --bstate "stateA,0.6" --bstate "stateB,0.4" --tstates-from target_states.txt
```

Initialize a simulation without weighted ensemble resampling on new segments:

```
w_init --bstates-from basis_states.txt --no-we
```
