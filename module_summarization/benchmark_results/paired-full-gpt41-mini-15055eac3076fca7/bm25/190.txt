Linear and Quadratic Discriminant Analysis
===========================================

Linear Discriminant Analysis (LDA)
----------------------------------

Linear Discriminant Analysis is a classification method with a linear decision boundary, generated by fitting class conditional densities to the data and using Bayes' rule. It assumes that the different classes generate data based on Gaussian distributions with the same covariance matrix but different means.

The model fits a Gaussian density to each class and finds a linear combination of features that best separates the classes. LDA can also be used for dimensionality reduction by projecting the data onto a lower-dimensional space that maximizes class separability.

**Parameters**

- `priors` : array-like of shape (n_classes,), default=None  
  Class priors. By default, the class proportions are inferred from the training data.

- `solver` : {'svd', 'lsqr', 'eigen'}, default='svd'  
  Solver to use, depending on the data size and properties.

**Attributes**

- `priors_` : ndarray of shape (n_classes,)  
  Class priors estimated from the training data or set by the user.

- `coef_` : ndarray of shape (n_classes - 1, n_features)  
  Coefficients of the linear decision boundary.

- `intercept_` : ndarray of shape (n_classes - 1,)  
  Intercept term in the linear decision function.

**Notes**

- The priors are normalized to sum to 1. If the provided priors do not sum to 1, a warning is issued and they are normalized automatically.

- Different solvers (`svd`, `lsqr`, `eigen`) provide different computational approaches to fitting the model, with similar results in terms of coefficients.

Quadratic Discriminant Analysis (QDA)
-------------------------------------

Quadratic Discriminant Analysis is a classification method with a quadratic decision boundary, generated by fitting class conditional densities to the data and using Bayes' rule. Unlike LDA, QDA allows each class to have its own covariance matrix, resulting in a quadratic decision surface.

The model fits a Gaussian density to each class with its own covariance matrix, which allows for more flexible boundaries but requires more parameters to be estimated.

**Parameters**

- `priors` : array-like of shape (n_classes,), default=None  
  Class priors. By default, the class proportions are inferred from the training data.

- `store_covariance` : bool, default=False  
  If True, the covariance matrices of each class are computed and stored in the attribute `covariance_`.

**Attributes**

- `priors_` : ndarray of shape (n_classes,)  
  Class priors estimated from the training data or set by the user.

- `covariance_` : list of ndarray of shape (n_features, n_features)  
  Covariance matrices of each class. Present only if `store_covariance=True`.

**Notes**

- The priors are normalized to sum to 1. If the provided priors do not sum to 1, they are normalized automatically.

- QDA requires that each class has at least two samples to estimate the covariance matrix.

- Setting `store_covariance=True` allows access to the covariance matrices after fitting.

Usage and Additional Information
--------------------------------

Both LDA and QDA classifiers implement the standard scikit-learn estimator interface with `fit`, `predict`, and `decision_function` methods.

They support array-like inputs and can handle multi-class classification problems.

For more detailed information and examples, see the :ref:`User Guide <lda_qda>`.
