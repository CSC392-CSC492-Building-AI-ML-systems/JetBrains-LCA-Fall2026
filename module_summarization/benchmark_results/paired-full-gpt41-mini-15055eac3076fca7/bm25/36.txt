w_succ — List segments which successfully reach a target state
===============================================================

Description
-----------
The `w_succ` command lists segments from a WESTPA simulation that have successfully reached a specified target state. This tool is useful for analyzing trajectories that meet certain success criteria within weighted ensemble simulations.

Usage
-----
```
w_succ [OPTIONS]
```

Options
-------
- `-o, --output OUTPUT_FILE`  
  Store the output in the specified `OUTPUT_FILE`. If this option is not provided, the output will be written to standard output.

Additional options are available through WESTPA's runtime configuration and the tool's argument parser.

Functionality
-------------
The `w_succ` tool reads WESTPA simulation data and identifies segments that have successfully reached the target state defined in the simulation parameters. It formats and outputs information about these successful segments, including progress coordinate values, using appropriate formatting based on data types.

Output
------
The output consists of a list of segments that have reached the target state, with their associated progress coordinate values formatted for readability. By default, the output is sent to standard output but can be redirected to a file using the `-o` option.

Example
-------
To list successful segments and save the output to a file named `success_segments.txt`:

```
w_succ -o success_segments.txt
```

Logging
-------
The tool uses the logger named `w_succ` to report informational messages and errors during execution.

Dependencies
------------
- Python standard libraries: `argparse`, `sys`, `logging`
- Third-party libraries: `numpy`
- WESTPA modules: `westpa`, `westpa.core.segment`, `westpa.oldtools.aframe`
