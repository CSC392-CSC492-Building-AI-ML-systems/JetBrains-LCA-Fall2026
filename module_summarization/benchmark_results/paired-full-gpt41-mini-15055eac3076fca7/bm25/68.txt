Gaussian Process Module
=======================

Overview
--------
The Gaussian Process module provides tools for Gaussian Process (GP) regression and classification, along with a variety of kernel functions to define covariance structures. Gaussian Processes are powerful non-parametric models used for regression and classification tasks, offering probabilistic predictions and uncertainty estimates.

Key Components
--------------

GaussianProcessClassifier
~~~~~~~~~~~~~~~~~~~~~~~~~
A classifier based on Gaussian Processes. It uses kernels to define similarity between data points and can model complex decision boundaries with probabilistic outputs.

Example:
```python
from sklearn.datasets import load_iris
from sklearn.gaussian_process import GaussianProcessClassifier
from sklearn.gaussian_process.kernels import RBF

X, y = load_iris(return_X_y=True)
kernel = 1.0 * RBF(1.0)
gpc = GaussianProcessClassifier(kernel=kernel, random_state=0).fit(X, y)
print(gpc.score(X, y))
print(gpc.predict_proba(X[:2, :]))
```

GaussianProcessRegressor
~~~~~~~~~~~~~~~~~~~~~~~~
A regressor based on Gaussian Processes. It models the distribution over functions and provides mean predictions along with uncertainty estimates.

Kernel Functions
----------------

RBF (Radial Basis Function) Kernel
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
A widely used kernel that measures similarity based on the Euclidean distance between points, controlled by a length scale parameter.

RationalQuadratic Kernel
~~~~~~~~~~~~~~~~~~~~~~~
A kernel that can be seen as a scale mixture of RBF kernels with different length scales, controlled by parameters length_scale and alpha.

Exponentiation Kernel
~~~~~~~~~~~~~~~~~~~~~
This kernel raises a base kernel to a scalar exponent, allowing for flexible kernel shapes.

Mathematically:
.. math::
    k_{exp}(X, Y) = k(X, Y)^p

where :math:`k` is the base kernel and :math:`p` is the exponent.

Example:
```python
from sklearn.datasets import make_friedman2
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import RationalQuadratic, Exponentiation

X, y = make_friedman2(n_samples=500, noise=0, random_state=0)
kernel = Exponentiation(RationalQuadratic(), exponent=2)
gpr = GaussianProcessRegressor(kernel=kernel, alpha=5, random_state=0).fit(X, y)
print(gpr.score(X, y))
```

Product Kernel
~~~~~~~~~~~~~~
Combines two kernels by multiplying them, allowing for more complex covariance structures.

Example:
```python
from sklearn.datasets import make_friedman2
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import RBF, Product, ConstantKernel

X, y = make_friedman2(n_samples=500, noise=0, random_state=0)
kernel = Product(ConstantKernel(2), RBF())
gpr = GaussianProcessRegressor(kernel=kernel, random_state=0).fit(X, y)
print(gpr.score(X, y))
print(kernel)
```

Additional Information
----------------------
- The module supports hyperparameter tuning of kernels, including length scales and other kernel-specific parameters.
- Kernel objects support arithmetic operations such as exponentiation and multiplication to build complex kernels.
- For detailed usage and theory, refer to the User Guide section on Gaussian Processes.

Examples
--------
Classification with GaussianProcessClassifier:
```python
from sklearn.datasets import load_iris
from sklearn.gaussian_process import GaussianProcessClassifier
from sklearn.gaussian_process.kernels import RationalQuadratic

X, y = load_iris(return_X_y=True)
kernel = RationalQuadratic(length_scale=1.0, alpha=1.5)
gpc = GaussianProcessClassifier(kernel=kernel, random_state=0).fit(X, y)
print(gpc.score(X, y))
print(gpc.predict_proba(X[:2, :]))
```

Regression with GaussianProcessRegressor and custom kernels:
```python
from sklearn.datasets import make_friedman2
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import RBF, ConstantKernel, Product

X, y = make_friedman2(n_samples=500, noise=0, random_state=0)
kernel = Product(ConstantKernel(2), RBF())
gpr = GaussianProcessRegressor(kernel=kernel, random_state=0).fit(X, y)
print(gpr.score(X, y))
```

This module is part of scikit-learn and provides flexible and powerful tools for Gaussian Process modeling in Python.
