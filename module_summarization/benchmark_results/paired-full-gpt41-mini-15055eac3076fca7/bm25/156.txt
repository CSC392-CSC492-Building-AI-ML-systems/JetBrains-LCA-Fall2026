How Mitogen Works
=================

Mitogen is a Python library designed to facilitate efficient and transparent remote procedure calls and process management over various transport mechanisms such as SSH. It achieves this by establishing and managing multiplexed communication streams between processes, allowing complex orchestration and control with minimal overhead.

Core Concepts
-------------

### Streams and Protocols

At the heart of Mitogen's architecture is the concept of a **Stream**. A Stream represents one readable and optionally one writable file descriptor, encapsulated by `Side` objects that manage the receive and transmit ends respectively. Each Stream is associated with a **Protocol** object that defines how to handle I/O readiness events on these descriptors.

Streams are registered with a central event loop called the **Broker**, which monitors I/O activity and dispatches callbacks such as `on_receive`, `on_transmit`, `on_shutdown`, and `on_disconnect`. This design allows Mitogen to efficiently multiplex many streams over a small number of file descriptors.

### Protocol Lifecycle

The Protocol associated with a Stream is expected to change over the Stream's lifetime to reflect different phases of communication. For example, during connection setup, the initial Protocol might be `mitogen.parent.BootstrapProtocol`. This protocol handles entering SSH and sudo passwords and transmitting the core Mitogen source code to the target machine.

Once the target process is initialized, the Protocol switches to `MitogenProtocol`, which manages ongoing communication. This dynamic switching allows Mitogen to adapt to different stages of connection and communication seamlessly.

### Connections and Child Processes

Streams that connect to child processes are aggregated by a `mitogen.parent.Connection` object. This Connection manages the lifecycle and state of the child process, including any separate `stderr` Stream connected to it. This abstraction simplifies managing multiple child processes and their associated communication channels.

Message Routing and Error Handling
----------------------------------

Mitogen uses special sentinel values to manage message routing and error conditions. For example, the constant `IS_DEAD` (value 999) signals disconnection or the inability to route a message. When a message with `reply_to` set to `IS_DEAD` is received, it typically causes a `mitogen.core.ChannelError` to be raised.

This sentinel value indicates that the sender either did not know how to process the message or wishes to stop receiving further messages. It is used in scenarios such as:

- A remote receiver disconnecting or explicitly closing.
- Failure to deliver a message due to no existing route.
- Router teardown, signaling handlers to clean up.

Compatibility and Serialization
-------------------------------

Mitogen supports multiple Python versions, including legacy versions like Python 2.4. To handle serialization of exceptions and other objects consistently across versions, Mitogen includes a custom pickler (`Py24Pickler`) that works around limitations in older Python versions.

This pickler ensures that exceptions such as `CallError` are serialized in a way that preserves their structure and behavior, enabling robust remote exception handling.

Efficient Data Processing
-------------------------

Mitogen includes utility functions such as `iter_split` to efficiently process large buffers of data without incurring quadratic string operation costs or creating large intermediate lists. This function invokes a callback for each delimiter-separated chunk in a buffer, allowing streaming processing of data.

Summary
-------

Mitogen's design centers on multiplexed Streams managed by Protocols, coordinated by a Broker event loop. It dynamically adapts Protocols during connection setup and runtime, manages child processes through Connection objects, and handles message routing and errors with sentinel values. Compatibility across Python versions and efficient data processing utilities further enhance its robustness and performance.

This architecture enables Mitogen to provide transparent, efficient, and flexible remote execution and communication capabilities suitable for complex distributed Python applications.
