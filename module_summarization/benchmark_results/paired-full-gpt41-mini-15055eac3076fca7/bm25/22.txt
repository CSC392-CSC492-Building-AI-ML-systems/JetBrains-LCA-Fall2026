w_fluxanl Command
=================

Overview
--------

The `w_fluxanl` command is a tool for extracting fluxes into pre-defined target states from WEST simulation data. It performs averaging and constructs confidence intervals for the fluxes. The analysis accounts for correlated and potentially non-Gaussian statistical uncertainties by employing Monte Carlo bootstrapping techniques.

Note: `w_fluxanl` is deprecated. Users are encouraged to use the `w_assign` and `w_direct` commands instead.

Functionality
-------------

- Extract flux values from WEST HDF5 data files over a specified range of iterations.
- Support for different WEST HDF5 file versions (version 7 and above, and earlier versions).
- Calculation of flux averages and confidence intervals using Monte Carlo Block Bootstrapping.
- Handling of correlated data to improve statistical reliability.
- Storage of intermediate data and analysis results in an output HDF5 file.

Usage
-----

```bash
w_fluxanl [OPTIONS]
```

Options include:

- `-o, --output OUTPUT`  
  Specify the output file to store intermediate data and analysis results.  
  Default: `fluxanl.h5`

- `--disable-bootstrap, -db`  
  Disable the use of Monte Carlo Block Bootstrapping.

- `--disable-correl, -dc`  
  Disable correlation handling in the bootstrapping process.

- Iteration range specification options (to select the range of iterations over which fluxes are extracted and analyzed).

- Data reader options to specify the input WEST data files.

Function Details
----------------

### Flux Extraction

The command extracts flux data from the WEST HDF5 file for iterations greater than or equal to a specified start iteration and less than a specified stop iteration. If no data manager instance is provided, the global data manager from `westpa.rc.get_data_manager()` is used.

The extracted flux data is returned as a dictionary mapping target names (or target indices if names are unavailable) to one-dimensional arrays of flux entries. Each flux entry contains:

- Iteration number
- Flux value
- Count

### Monte Carlo Bootstrapping

Monte Carlo Block Bootstrapping is used to estimate confidence intervals for the fluxes, accounting for correlations and non-Gaussian statistics in the data. This method improves the robustness of the statistical analysis.

### Output

The results, including flux evolution data and bootstrapping parameters, are stored in the specified output HDF5 file. Attributes such as iteration step, bootstrapping alpha values, and the number of bootstrap sets are saved alongside the data.

Deprecation Notice
------------------

Users are warned that `w_fluxanl` is deprecated and should transition to using the `w_assign` and `w_direct` commands for flux analysis in WEST simulations.

Example
-------

```bash
w_fluxanl -o my_flux_analysis.h5 --disable-correl
```

This command runs the flux analysis, disables correlation handling in bootstrapping, and saves the results to `my_flux_analysis.h5`.

