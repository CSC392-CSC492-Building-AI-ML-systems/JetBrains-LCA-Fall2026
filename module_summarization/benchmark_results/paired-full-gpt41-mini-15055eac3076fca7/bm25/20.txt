w_direct Command
================

Overview
--------

The `w_direct` command is a comprehensive toolset for analyzing state-to-state kinetics, transition event durations, and state populations from weighted ensemble simulation data. It provides multiple subcommands to calculate and average kinetic rates, state probabilities, and fluxes, facilitating detailed kinetic modeling and statistical analysis.

Subcommands
-----------

- **init** (`w_direct init`)

  Calculate state-to-state rates and transition event durations by tracing trajectories.

  A bin assignment file (usually `assign.h5`) including trajectory labeling is required (see `w_assign --help` for information on generating this file).

  This subcommand is the foundation for all other `w_direct` analyses, producing normalized kinetics data from raw fluxes.

- **average** (`w_direct average`)

  A convenience function to average and return fluxes, rates, and color/state populations.

  Bin assignments, including macrostate definitions, are required (see `w_assign --help`).

  For more information on the individual subcommands this subs in for, run `w_direct {kinetics/probs} --help`.

- **kinavg** (`w_direct kinavg`)

  Computes averages of kinetic quantities.

- **stateprobs** (`w_direct stateprobs`)

  Calculates state populations over time.

- **all** (`w_direct all`)

  Runs the full suite, including initialization, kinetics calculation, and state probabilities.

  Bin assignments, including macrostate definitions, are required (see `w_assign --help`).

  For more information on the individual subcommands this subs in for, run `w_direct {init/kinetics/probs} --help`.

Description
-----------

The `w_direct` command suite is designed to process weighted ensemble simulation data to extract kinetic information such as state-to-state transition rates, event durations, and state populations. It requires bin assignment files that define trajectory labeling and macrostate definitions.

The kinetics calculations involve tracing trajectories to compute fluxes and transition event durations. Because raw fluxes are not normalized by initial macrostate populations, the `w_direct kinetics` subcommand performs this normalization while accounting for statistical fluctuations and correlations.

Event durations are stored in a structured format with the following fields:

- `istate` (Integer): Initial state of the transition event.
- `fstate` (Integer): Final state of the transition event.
- `duration` (Floating-point): Duration of the transition, in units of τ (tau).
- `weight` (Floating-point): Weight of the trajectory at the end of the transition, **not** normalized by initial state population.

Target fluxes (total flux into a given state) do not require normalization.

Usage Notes
-----------

- Bin assignments and macrostate definitions are mandatory for all subcommands. Refer to `w_assign --help` for details on generating these files.
- The `w_direct average` and `w_direct all` subcommands provide convenient wrappers to run multiple analyses in sequence.
- For detailed help on each subcommand, use `w_direct <subcommand> --help`.

Command-line Options
--------------------

Each subcommand provides its own set of command-line options. Run `w_direct <subcommand> --help` to see available options and usage details.

Examples
--------

Calculate kinetics by tracing trajectories:

```
w_direct init --assign-file assign.h5 --kinetics-file direct.h5
```

Average kinetic quantities and state populations:

```
w_direct average --kinetics-file direct.h5
```

Run the full suite of analyses:

```
w_direct all --assign-file assign.h5 --kinetics-file direct.h5
```

See Also
--------

- `w_assign` — for generating bin assignment files required by `w_direct`.
- `w_direct kinetics` — for detailed kinetics calculations.
- `w_direct stateprobs` — for state population calculations.
