Kernel Approximation Module
===========================

The `kernel_approximation` module provides tools for approximating kernel feature maps, enabling scalable kernel methods by transforming data into a feature space where linear methods can be applied efficiently. This module includes several classes that implement different kernel approximation techniques.

Classes
-------

AdditiveChi2Sampler
~~~~~~~~~~~~~~~~~~~
Approximate feature map for the additive chi-squared kernel.

PolynomialCountSketch
~~~~~~~~~~~~~~~~~~~~~
Polynomial kernel approximation via Tensor Sketch.

RBFSampler
~~~~~~~~~
Approximate a Radial Basis Function (RBF) kernel feature map using random Fourier features.

SkewedChi2Sampler
~~~~~~~~~~~~~~~~~
Approximate feature map for the "skewed chi-squared" kernel.

Usage Examples
--------------

AdditiveChi2Sampler
~~~~~~~~~~~~~~~~~~~
```python
from sklearn.kernel_approximation import AdditiveChi2Sampler
from sklearn.linear_model import SGDClassifier

X = [[0, 0], [1, 1], [1, 0], [0, 1]]
y = [0, 0, 1, 1]

chi2_feature = AdditiveChi2Sampler()
X_features = chi2_feature.fit_transform(X, y)

clf = SGDClassifier(max_iter=10, tol=1e-3)
clf.fit(X_features, y)
```

PolynomialCountSketch
~~~~~~~~~~~~~~~~~~~~~
```python
from sklearn.kernel_approximation import PolynomialCountSketch
from sklearn.linear_model import SGDClassifier

X = [[0, 0], [1, 1], [1, 0], [0, 1]]
y = [0, 0, 1, 1]

ps = PolynomialCountSketch(degree=3, random_state=1)
X_features = ps.fit_transform(X)

clf = SGDClassifier(max_iter=10, tol=1e-3)
clf.fit(X_features, y)
```

RBFSampler
~~~~~~~~~
```python
from sklearn.kernel_approximation import RBFSampler
from sklearn.linear_model import SGDClassifier

X = [[0, 0], [1, 1], [1, 0], [0, 1]]
y = [0, 0, 1, 1]

rbf_feature = RBFSampler(gamma=1, random_state=1)
X_features = rbf_feature.fit_transform(X)

clf = SGDClassifier(max_iter=5, tol=1e-3)
clf.fit(X_features, y)
print(clf.score(X_features, y))  # Output: 1.0
```

SkewedChi2Sampler
~~~~~~~~~~~~~~~~~
```python
from sklearn.kernel_approximation import SkewedChi2Sampler
from sklearn.linear_model import SGDClassifier

X = [[0, 0], [1, 1], [1, 0], [0, 1]]
y = [0, 0, 1, 1]

chi2_feature = SkewedChi2Sampler(skewedness=0.01, n_components=10, random_state=0)
X_features = chi2_feature.fit_transform(X, y)

clf = SGDClassifier(max_iter=10, tol=1e-3)
clf.fit(X_features, y)
```

Attributes
----------

feature_names_in_ : ndarray of shape (n_features_in_,)  
    Names of features seen during `fit`. Defined only when the input `X` has feature names that are all strings.  
    .. versionadded:: 1.0

Notes
-----
The kernel approximation methods implemented in this module are based on random feature maps that approximate kernel functions, allowing kernel methods to scale to large datasets by using linear algorithms on transformed features.

See Also
--------
- `sklearn.metrics.pairwise.kernel_metrics` : List of built-in kernels.
- `Nystroem` : Approximate a kernel map using a subset of the training data.

This module is part of scikit-learn’s kernel methods and provides efficient approximations for popular kernels to enable scalable machine learning.
