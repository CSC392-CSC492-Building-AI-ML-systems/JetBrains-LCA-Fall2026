w_eddist — Calculate time-resolved transition-event duration distribution
=============================================================================

Description
-----------

The `w_eddist` command calculates the time-resolved transition-event duration distribution from kinetics results obtained via WESTPA simulations.

This tool processes source data collected from the results of the `w_kinetics trace` command. For more information on generating this dataset, see the documentation for `w_kinetics trace --help`.

Source Data
-----------

The input data for `w_eddist` is derived from kinetics traces, which include populations and transition rates (including their evolution over iterations). This data is typically stored in an HDF5 file (default filename: `kintrace.h5`).

Histogram Binning
-----------------

By default, histograms are constructed with 100 bins in each dimension. This behavior can be customized using the `-b` or `--bins` option, which accepts several types of arguments:

- **Single integer N**  
  Use N uniformly spaced bins in each dimension.

- **Sequence of integers N1,N2,... (comma-separated)**  
  Use N1 bins for the first dimension, N2 for the second, and so forth.

- **List of lists [[B11, B12, B13,...], [B21, B22, B23,...], ...]**  
  Specify explicit bin boundaries for each dimension.

The output HDF5 file will contain datasets for the bin boundaries named `/binbounds_0`, `/binbounds_1`, etc., corresponding to each dimension.

Additional datasets include:

- `/midpoints_0`, `/midpoints_1`, ...  
  Vectors of bin midpoints for each dimension.

- `/n_iter`  
  Vector of iteration numbers corresponding to the stored histograms (the first axis of the `histograms` dataset).

Output and Subsequent Processing
--------------------------------

The results are stored in an output file (default: `eddist.h5`). This file contains the computed histograms representing the distribution of transition-event durations over time.

The output can be visualized using the `plothist` program. For more details on plotting, see `plothist --help`.

Parallelization
---------------

`w_eddist` supports parallelized binning and input data reading to improve performance on large datasets. Parallel processing is enabled by default.

For simpler cases, such as reading pre-computed input data or processing modest numbers of segments, serial processing can be enabled with the `--serial` option, which may be more efficient.

Command-Line Options
--------------------

The following are key command-line options available for `w_eddist`:

- `-k`, `--kinetics`  
  Specify the kinetics input file containing populations and transition rates.  
  Default: `kintrace.h5`

- `-o`, `--output`  
  Specify the output file to store results.  
  Default: `eddist.h5`

- `-b`, `--bins`  
  Specify the histogram binning scheme (see Histogram Binning section).

- `--last-iter`  
  Specify the iteration number at which to end the analysis.

- `--serial`  
  Disable parallel processing and run in serial mode.

- Progress indicator options are also available to monitor the progress of the computation.

Example Usage
-------------

```bash
w_eddist -k kintrace.h5 -o eddist.h5 --last-iter 100
```

This command computes the transition-event duration distribution using data from `kintrace.h5`, stores the results in `eddist.h5`, and stops analysis at iteration 100.

See Also
--------

- `w_kinetics trace` — Generate kinetics trace data used as input for `w_eddist`.
- `plothist` — Visualize histogram data produced by `w_eddist`.
