Nonparametric Methods
=====================

Overview
--------

Nonparametric methods provide flexible tools for estimating statistical functions without assuming a specific parametric form for the underlying population distribution. These methods are particularly useful when dealing with complex data structures, including mixed data types (continuous, ordered discrete, and unordered discrete variables), and when the functional form of relationships is unknown or difficult to specify.

Kernel Density Estimation (KDE)
-------------------------------

Kernel Density Estimation is a fundamental nonparametric technique used to estimate the probability density function of a random variable. The multivariate kernel density estimator extends this concept to multiple dimensions and can handle mixed data types.

### KDEMultivariate

The `KDEMultivariate` class implements a multivariate kernel density estimator capable of handling univariate and multivariate data, including mixed continuous, ordered discrete, and unordered discrete variables. It supports cross-validated bandwidth selection methods such as least squares and maximum likelihood to optimize the smoothing parameters.

**Parameters:**

- `data` : list of ndarray  
  Input data for density estimation. Each element corresponds to a variable and can be continuous or discrete.

- `var_type` : str  
  A string specifying the variable types for each dimension:  
  - 'c' for continuous  
  - 'o' for ordered discrete  
  - 'u' for unordered discrete

- `bw` : array_like or str, optional  
  Bandwidth parameters for the kernel. Can be specified manually or selected via cross-validation.

- `ckertype`, `ukertype`, `okertype` : str, optional  
  Kernel types for continuous, unordered discrete, and ordered discrete variables respectively.

**References:**

- Racine, J., Li, Q. *Nonparametric Econometrics: Theory and Practice*. Princeton University Press, 2007.
- Racine, J. "Nonparametric Econometrics: A Primer," *Foundations and Trends in Econometrics*, Vol. 3, No. 1, pp. 1-88, 2008.
- Li, Q., Racine, J. "Cross-validated local linear nonparametric regression," *Statistica Sinica*, 14(2004), pp. 485-512.

Multivariate Conditional Kernel Density Estimation
--------------------------------------------------

Conditional kernel density estimation extends KDE to estimate the conditional distribution of a dependent variable given one or more independent variables. This approach is useful for modeling complex relationships without specifying a parametric form.

The estimator can handle mixed data types and uses kernel functions tailored to each variable type. Bandwidth selection is critical and can be performed using cross-validation techniques.

Nonparametric Regression
------------------------

Nonparametric regression methods estimate the relationship between dependent and independent variables without assuming a predetermined functional form. Local linear regression and kernel regression are common approaches.

### Wang-Ryzin Kernel for Regression

A specialized kernel function, the Wang-Ryzin kernel, is used in nonparametric regression to handle certain data structures effectively. It is defined as:

```
WangRyzinReg(h, Xi, x) = h ** |Xi - x|
```

where `h` is the bandwidth parameter, `Xi` is the observed independent variable, and `x` is the point of evaluation.

Significance Testing in Nonparametric Regression
------------------------------------------------

Testing the significance of predictor variables in nonparametric regression models can be challenging due to the flexible nature of the models. Methods have been developed to perform consistent significance testing, including tests specifically designed for categorical predictor variables.

References for significance testing include:

- Racine, J. "Consistent Significance Testing for Nonparametric Regression," *Journal of Business & Economic Statistics*.
- Racine, J., Hart, J., Li, Q. "Testing the Significance of Categorical Predictor Variables in Nonparametric Regression Models," *Econometric Reviews*, 25(2006), pp. 523-544.

Applications and Use Cases
--------------------------

Nonparametric methods are widely used in econometrics, statistics, and machine learning for:

- Estimating multivariate cumulative distribution functions with mixed data types.
- Modeling complex relationships without specifying parametric forms.
- Performing regression analysis when the functional form is unknown.
- Conducting hypothesis testing in flexible modeling frameworks.
