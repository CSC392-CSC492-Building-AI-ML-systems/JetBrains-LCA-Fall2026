Support Vector Machines
=======================

Support Vector Machines (SVMs) are a set of supervised learning methods used for classification, regression, and outliers detection. They are implemented in scikit-learn primarily through the `svm` module, which interfaces with the LIBSVM and LIBLINEAR libraries.

Overview
--------

SVMs aim to find a hyperplane in an N-dimensional space (N — the number of features) that distinctly classifies the data points. The best hyperplane for an SVM means the one with the largest margin between the two classes. SVMs can efficiently perform a non-linear classification using what is called the kernel trick, implicitly mapping their inputs into high-dimensional feature spaces.

Key Implementations
-------------------

- **SVC**: Support Vector Classification implemented using LIBSVM. It supports multi-class classification and various kernels.
- **NuSVC**: Similar to SVC but uses a parameter `nu` to control the number of support vectors.
- **LinearSVC**: Scalable Linear Support Vector Machine for classification implemented using LIBLINEAR. It is optimized for large datasets.
- **SVR**: Support Vector Regression implemented using LIBSVM.
- **NuSVR**: Similar to SVR but uses a parameter `nu` to control the number of support vectors.

Probability Estimates
--------------------

SVMs can produce probability estimates using Platt scaling, which fits a logistic function to the decision values:

.. math::

    P(y=1 | x) = \frac{1}{1 + \exp(decision\_value \times probA\_ + probB\_)}

where ``probA_`` and ``probB_`` are parameters learned from the training data. If `probability=False`, the probability estimates are not computed and an empty array is returned.

Attributes
----------

- **support_** : ndarray of shape (n_SV,)
  
  Indices of support vectors.

- **support_vectors_** : ndarray of shape (n_SV, n_features)
  
  Support vectors.

- **n_support_** : ndarray of shape (1,), dtype=int32
  
  Number of support vectors.

- **shape_fit_** : tuple of int
  
  Array dimensions of the training vector ``X``.

- **feature_names_in_** : ndarray of shape (`n_features_in_`,)
  
  Names of features seen during :term:`fit`. Defined only when `X` has feature names that are all strings.
  
  .. versionadded:: 1.0

- **n_iter_** : int
  
  Number of iterations run by the optimization routine to fit the model.
  
  .. versionadded:: 1.1

Examples
--------

Classification with NuSVC:

>>> import numpy as np
>>> from sklearn.pipeline import make_pipeline
>>> from sklearn.preprocessing import StandardScaler
>>> from sklearn.svm import NuSVC
>>> X = np.array([[-1, -1], [-2, -1], [1, 1], [2, 1]])
>>> y = np.array([1, 1, 2, 2])
>>> clf = make_pipeline(StandardScaler(), NuSVC())
>>> clf.fit(X, y)
Pipeline(steps=[('standardscaler', StandardScaler()), ('nusvc', NuSVC())])
>>> clf.predict([[-0.8, -1]])
array([1])

Regression with SVR:

>>> import numpy as np
>>> from sklearn.pipeline import make_pipeline
>>> from sklearn.preprocessing import StandardScaler
>>> from sklearn.svm import SVR
>>> n_samples, n_features = 10, 5
>>> rng = np.random.RandomState(0)
>>> X = rng.randn(n_samples, n_features)
>>> y = rng.randn(n_samples)
>>> regr = make_pipeline(StandardScaler(), SVR(C=1.0, epsilon=0.2))
>>> regr.fit(X, y)
Pipeline(steps=[('standardscaler', StandardScaler()), ('svr', SVR(epsilon=0.2, C=1.0))])

Regression with NuSVR:

>>> import numpy as np
>>> from sklearn.pipeline import make_pipeline
>>> from sklearn.preprocessing import StandardScaler
>>> from sklearn.svm import NuSVR
>>> n_samples, n_features = 10, 5
>>> np.random.seed(0)
>>> X = np.random.randn(n_samples, n_features)
>>> y = np.random.randn(n_samples)
>>> regr = make_pipeline(StandardScaler(), NuSVR(C=1.0, nu=0.1))
>>> regr.fit(X, y)
Pipeline(steps=[('standardscaler', StandardScaler()), ('nusvr', NuSVR(C=1.0, nu=0.1))])
