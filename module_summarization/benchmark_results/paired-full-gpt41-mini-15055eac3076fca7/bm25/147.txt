# Fleur Input/Output Parsers

This module provides a collection of functions designed to extract and parse distinct parts of Fleur XML files. These parsers facilitate easy versioning, reuse, and manipulation of Fleur input and output data by converting XML content into structured Python dictionaries and other convenient formats.

## Overview

Fleur input and output files are XML-based and can vary depending on the version of the Fleur code used. The parsers in this module leverage schema dictionaries corresponding to specific Fleur versions to correctly interpret the XML structure and extract relevant information.

The main goals of these parsers are to:

- Extract parameters and settings from Fleur input XML files (`inp.xml`) to enable recreation or modification of inputs.
- Retrieve calculation modes and flags indicating which types of calculations are requested or performed.
- Obtain relaxation and k-point information from output XML files.
- Provide a unified interface that supports multiple versions of Fleur XML schemas.

## Key Functions

### `get_fleur_modes(xmltree, schema_dict, logger=None) -> dict[str, Any]`

Extracts calculation modes from a Fleur XML tree. This includes flags indicating whether specific calculations such as Green's function calculations or torque calculations are requested.

- **Parameters:**
  - `xmltree`: Parsed XML tree of the Fleur input or output file.
  - `schema_dict`: Schema dictionary corresponding to the XML file version.
  - `logger`: Optional logger for warnings or informational messages.

- **Returns:**  
  A dictionary with keys representing calculation modes (e.g., `'greensf'`, `'ldahia'`) and boolean values indicating whether the mode is active.

### `get_parameterdata(xmltree, schema_dict, inpgen_ready=True, write_ids=True, extract_econfig=False, allow_special_los=True, logger=None) -> dict[str, Any]`

Parses the Fleur input XML tree and returns a Python dictionary containing all parameters necessary to recreate the input file. This is particularly useful for generating new input files that reproduce the same calculation setup.

- **Parameters:**
  - `xmltree`: Parsed XML tree of the Fleur input file.
  - `schema_dict`: Schema dictionary corresponding to the XML file version.
  - `inpgen_ready`: If `True`, the output dictionary is formatted to be compatible with inpgen input generation.
  - `write_ids`: If `True`, includes IDs in the output dictionary.
  - `extract_econfig`: If `True`, extracts electronic configuration information.
  - `allow_special_los`: If `True`, allows special local orbital settings.
  - `logger`: Optional logger for warnings or informational messages.

- **Returns:**  
  A dictionary representing the input parameters extracted from the XML.

### `get_nkpts(xmltree, schema_dict, logger=None) -> int`

Retrieves the number of k-points used in the calculation from the Fleur input XML.

- **Parameters:**
  - `xmltree`: Parsed XML tree of the Fleur input file.
  - `schema_dict`: Schema dictionary corresponding to the XML file version.
  - `logger`: Optional logger for warnings or informational messages.

- **Returns:**  
  The number of k-points as an integer.

### `get_relaxation_information(xmltree, schema_dict, logger=None) -> dict[str, Any]`

Extracts relaxation-related information from a Fleur XML file, such as forces and energies during relaxation steps.

- **Parameters:**
  - `xmltree`: Parsed XML tree of the Fleur output file.
  - `schema_dict`: Schema dictionary corresponding to the XML file version.
  - `logger`: Optional logger for warnings or informational messages.

- **Returns:**  
  A dictionary containing relaxation data such as energies and forces.

## Version Dispatching

Many functions in this module use a version dispatching mechanism (`@schema_dict_version_dispatch`) to handle differences in XML schema versions. This ensures that the correct parsing logic is applied depending on the version of the Fleur input or output file.

## Dependencies

- `lxml.etree` for XML parsing.
- `masci_tools.io.parsers.fleur_schema` for schema dictionaries and version handling.
- `masci_tools.io.common_functions` for common parsing utilities.
- `logging.Logger` for optional logging support.

## Usage Example

```python
from lxml import etree
from masci_tools.io.parsers import fleur_parser
from masci_tools.io.parsers.fleur_schema import get_schema_dict

# Parse XML file
xmltree = etree.parse('inp.xml')

# Get schema dictionary for the input file version
schema_dict = get_schema_dict(xmltree)

# Extract calculation modes
modes = fleur_parser.get_fleur_modes(xmltree, schema_dict)

# Extract parameter data
params = fleur_parser.get_parameterdata(xmltree, schema_dict)

# Extract number of k-points
nkpts = fleur_parser.get_nkpts(xmltree, schema_dict)
```

## Notes

- The parsers are designed to be robust against changes in Fleur XML schema versions by using version-specific dispatching.
- Some functions may raise `NotImplementedError` if called with unsupported schema versions.
- Logging can be enabled by passing a `Logger` instance to the functions to capture warnings or errors during parsing.

This module is an essential tool for users and developers working with Fleur simulations who need to programmatically access and manipulate input and output data in a version-aware manner.
