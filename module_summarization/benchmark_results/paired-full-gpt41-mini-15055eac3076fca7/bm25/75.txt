Working with Text Data Tutorial
===============================

Introduction
------------

This tutorial provides an overview of how to work with text data using vectorization techniques such as term frequency (TF) and term frequency-inverse document frequency (TF-IDF). These methods are fundamental in natural language processing (NLP) and text mining to convert raw text into numerical feature vectors that machine learning algorithms can process.

Vectorization Overview
----------------------

Vectorization transforms text documents into numerical representations. Two common approaches are:

- **Term Frequency (TF):** Counts how often each term appears in a document.
- **TF-IDF:** Adjusts term frequency by the inverse document frequency, reducing the weight of common terms and highlighting important ones.

TF-IDF Calculation
------------------

The TF-IDF transformation involves the following steps:

1. **Term Frequency (TF):** Count the occurrences of each term in the document.
2. **Inverse Document Frequency (IDF):** Compute the logarithmically scaled inverse fraction of documents that contain the term, defined as:

   .. math::

      \text{idf}(t) = \log \frac{1 + n}{1 + \text{df}(t)} + 1

   where *n* is the total number of documents and *df(t)* is the number of documents containing term *t*.

3. **TF-IDF Weighting:** Multiply the TF by the IDF for each term.

Implementation Details
----------------------

### Data Validation and Input Format

- Input data should be provided as a sparse matrix of shape `(n_samples, n_features)`, where each row corresponds to a document and each column corresponds to a term/token.
- The matrix can be in Compressed Sparse Row (CSR) or Compressed Sparse Column (CSC) format.
- For large sparse datasets, 64-bit platforms are recommended due to limitations in certain numpy operations on 32-bit systems.

### Sublinear Term Frequency Scaling

- Optionally, sublinear scaling can be applied to term frequencies by replacing each term frequency *tf* with `1 + log(tf)`.
- This helps to dampen the effect of very frequent terms.

### IDF Vector Learning

- The IDF vector is learned from the training data by counting document frequencies.
- The learned IDF vector is stored as a property and used during transformation.
- If `use_idf` is set to `False`, the transformer behaves as a simple term frequency transformer.

### Normalization

- After TF-IDF weighting, vectors can be normalized using L1 or L2 norms.
- Normalization ensures that document vectors have comparable lengths, which is important for many machine learning algorithms.

### Stop Words Handling

- Stop words (common words like "the", "and", etc.) can be removed during preprocessing.
- It is important to ensure consistency between stop words and the tokenizer/preprocessor to avoid unexpected tokens.
- Warnings are issued if inconsistencies are detected.

Using the Transformer
---------------------

### Fitting the Transformer

- The `fit` method validates parameters and learns the IDF vector if `use_idf=True`.
- It accepts input data `X` as a sparse matrix of term counts.
- The target variable `y` is ignored and present only for API consistency.

### Transforming Data

- The `transform` method converts a count matrix into a TF or TF-IDF weighted matrix.
- It accepts the input matrix `X` and an optional `copy` parameter to specify whether to operate on a copy or in-place.
- The output is a sparse matrix of the same shape with weighted features.

### Analyzer Function

- The transformer provides a callable analyzer that handles preprocessing, tokenization, and n-gram generation.
- This callable can be used to process raw text input into tokens suitable for vectorization.

Example Workflow
----------------

1. **Prepare your text data** as a collection of documents.
2. **Tokenize and preprocess** the text using the analyzer callable.
3. **Convert tokens to a count matrix** representing term frequencies.
4. **Fit the transformer** on the training data to learn IDF weights.
5. **Transform the count matrix** to obtain TF-IDF weighted features.
6. **Normalize** the vectors if required.
7. **Use the resulting feature matrix** as input to machine learning models.

Conclusion
----------

TF and TF-IDF vectorization are powerful techniques for converting text data into numerical features. Proper handling of preprocessing, stop words, and normalization is essential for effective text representation. This tutorial outlines the key concepts and implementation details to help you work efficiently with text data in machine learning pipelines.
