Metrics Module
==============

This module provides functions and mappings for various distance and kernel metrics used in pairwise computations. It includes valid metrics for pairwise distances and pairwise kernels, along with their corresponding implementations.

Pairwise Distance Metrics
-------------------------

The module defines a set of valid metrics for computing pairwise distances between samples. These metrics can be specified as strings or callable functions. The available distance metrics and their corresponding functions are:

+----------------+------------------------------------------------------------+
| Metric         | Function                                                   |
+================+============================================================+
| 'cityblock'    | `metrics.pairwise.manhattan_distances`                     |
+----------------+------------------------------------------------------------+
| 'cosine'       | `metrics.pairwise.cosine_distances`                        |
+----------------+------------------------------------------------------------+
| 'euclidean'    | `metrics.pairwise.euclidean_distances`                     |
+----------------+------------------------------------------------------------+
| 'haversine'    | `metrics.pairwise.haversine_distances`                     |
+----------------+------------------------------------------------------------+
| 'l1'          | `metrics.pairwise.manhattan_distances`                     |
+----------------+------------------------------------------------------------+
| 'l2'          | `metrics.pairwise.euclidean_distances`                     |
+----------------+------------------------------------------------------------+
| 'manhattan'    | `metrics.pairwise.manhattan_distances`                     |
+----------------+------------------------------------------------------------+
| 'nan_euclidean'| `metrics.pairwise.nan_euclidean_distances`                 |
+----------------+------------------------------------------------------------+
| 'precomputed'  | Special case: distances are precomputed and passed directly|
+----------------+------------------------------------------------------------+

These metrics are used in functions such as `pairwise_distances_argmin_min` to compute distances between points or sets of points efficiently, including support for sparse matrices where applicable.

Functions
---------

- **distance_metrics()**

  Returns a dictionary of valid pairwise distance metrics mapping metric names (strings) to their corresponding functions. This function serves as a reference for the available distance metrics.

- **pairwise_distances_argmin_min(X, Y=None, *, axis=1, metric='euclidean', metric_kwargs=None)**

  Computes, for each row in `X`, the index of the closest row in `Y` according to the specified distance metric, along with the minimal distances. Supports various metrics and sparse input formats.

- **_dist_wrapper(dist_func, dist_matrix, slice_, *args, **kwargs)**

  Internal helper function that writes in-place to a slice of a distance matrix using the provided distance function.

- **_parallel_pairwise(X, Y, func, n_jobs, **kwds)**

  Internal helper function that breaks the pairwise distance matrix into `n_jobs` even slices and computes them in parallel for efficiency.

Kernel Metrics
--------------

The module also defines valid metrics for pairwise kernel computations. These kernels are used in similarity computations and machine learning algorithms. The available kernel metrics and their corresponding functions are:

+-------------------+------------------------------------------------------------+
| Metric            | Function                                                   |
+===================+============================================================+
| 'additive_chi2'   | `sklearn.pairwise.additive_chi2_kernel`                    |
+-------------------+------------------------------------------------------------+
| 'chi2'            | `sklearn.pairwise.chi2_kernel`                             |
+-------------------+------------------------------------------------------------+
| 'linear'          | `sklearn.pairwise.linear_kernel`                           |
+-------------------+------------------------------------------------------------+
| 'poly'            | `sklearn.pairwise.polynomial_kernel`                       |
+-------------------+------------------------------------------------------------+
| 'polynomial'      | `sklearn.pairwise.polynomial_kernel`                       |
+-------------------+------------------------------------------------------------+
| 'rbf'             | `sklearn.pairwise.rbf_kernel`                              |
+-------------------+------------------------------------------------------------+
| 'laplacian'       | `sklearn.pairwise.laplacian_kernel`                        |
+-------------------+------------------------------------------------------------+
| 'sigmoid'         | `sklearn.pairwise.sigmoid_kernel`                          |
+-------------------+------------------------------------------------------------+
| 'cosine'          | `sklearn.pairwise.cosine_similarity`                       |
+-------------------+------------------------------------------------------------+

Usage Notes
-----------

- For distance metrics such as 'cityblock', 'cosine', and 'euclidean' that are also available in SciPy, the scikit-learn implementations are preferred due to better performance and support for sparse matrices (except for 'cityblock').

- The 'precomputed' metric indicates that the distance matrix is provided directly and no computation is performed.

- The module supports validation of input parameters to ensure correct types and valid metric names.
