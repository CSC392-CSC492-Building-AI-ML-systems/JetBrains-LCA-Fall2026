Generate Documentation for ASDF Tree Search Utilities
======================================================

Overview
--------
This module provides utilities for searching and filtering nodes within ASDF (Advanced Scientific Data Format) trees. It includes the `AsdfSearchResult` class, which encapsulates the results of a search operation on an ASDF file and provides methods to refine and format these results.

AsdfSearchResult Class
----------------------

The `AsdfSearchResult` class represents the outcome of a search performed on an ASDF tree. It allows users to further narrow down search results based on keys, types, and values, and to customize the display format of the search output.

### Initialization

```python
AsdfSearchResult(
    identifiers,
    node,
    filters=[],
    parent_node=None,
    max_rows=DEFAULT_MAX_ROWS,
    max_cols=DEFAULT_MAX_COLS,
    show_values=DEFAULT_SHOW_VALUES,
)
```

- **identifiers**: Identifiers related to the search result.
- **node**: The node in the ASDF tree that matches the search.
- **filters**: Optional list of filters applied to the search.
- **parent_node**: Optional parent node of the current node.
- **max_rows**: Maximum number of rows to display in the formatted output.
- **max_cols**: Maximum number of columns (line length) to display.
- **show_values**: Boolean flag to indicate whether to show primitive values in the output.

### Methods

#### format(max_rows=NotSet, max_cols=NotSet, show_values=NotSet)

Adjusts the formatting parameters of the rendered tree output.

- **max_rows** (`int`, `tuple`, `None`, or `NotSet`, optional):  
  Controls the maximum number of lines to print.  
  - If `int`, limits the total number of displayed lines.  
  - If `tuple`, limits lines per node at corresponding depths.  
  - If `None`, displays all lines.  
  - If `NotSet`, retains the current setting.

- **max_cols** (`int`, `None`, or `NotSet`, optional):  
  Controls the maximum length of each line.  
  - If `int`, truncates lines exceeding this length.  
  - If `None`, lines are unconstrained in length.  
  - If `NotSet`, retains the current setting.

- **show_values** (`bool` or `NotSet`, optional):  
  Whether to display primitive values in the rendered tree.  
  - Set to `False` to hide values.  
  - Set to `NotSet` to retain the current setting.

Returns a new `AsdfSearchResult` instance with updated formatting parameters.

#### search(key=NotSet, type=NotSet, value=NotSet, filter=None)

Refines the search results by applying additional constraints on keys, types, and values.

- **key** (`NotSet`, `str`, or any object):  
  Filters nodes by dictionary key or list index.  
  - If `NotSet`, no constraint on the key.  
  - If `str`, interpreted as a regular expression pattern to match keys or indexes.  
  - Otherwise, nodes must have keys or indexes equal to this value.

- **type** (`NotSet`, `str`, or `builtins.type`):  
  Filters nodes by their type.  
  - If `NotSet`, no constraint on the type.  
  - If `str`, interpreted as a regular expression pattern matching fully qualified type names.  
  - If a type object, nodes must be instances of this type.

- **value** (`NotSet`, `str`, or any object):  
  Filters nodes by their value.  
  - If `NotSet`, no constraint on the value.  
  - If `str`, interpreted as a regular expression pattern matching node values.  
  - Otherwise, nodes must have values equal to this value.

- **filter** (optional):  
  Additional custom filter function to apply.

Internal Utility Methods
------------------------

- `_maybe_compile_pattern(query)`:  
  Compiles a string query into a regular expression pattern if necessary.

- `_safe_equals(a, b)`:  
  Safely compares two values for equality, returning `False` if comparison raises an exception or does not return a boolean.

- `_get_fully_qualified_type(value)`:  
  Returns the fully qualified type name of a value, including its module name unless it is a built-in type.

Usage
-----

The `AsdfSearchResult` class is typically obtained by calling the `search` method on an `AsdfFile` object (not shown here). Once obtained, users can refine the search results using the `search` method of `AsdfSearchResult` and customize the display using the `format` method.

Example:

```python
result = asdf_file.search(key="some_key")
refined_result = result.search(type="int").format(max_rows=20, show_values=False)
print(refined_result)
```

This module facilitates powerful and flexible querying of ASDF trees, enabling users to locate and inspect nodes based on keys, types, and values with fine-grained control over output formatting.
