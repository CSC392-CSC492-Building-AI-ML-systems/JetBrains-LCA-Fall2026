Querying
========

The querying functionality allows you to retrieve data by specifying query expressions. Queries can be customized with projections and pagination to efficiently access the desired information.

Basic Usage
-----------

When performing a query, you provide an expression that defines what data to retrieve. If the expression does not start with a `select` statement, the system automatically adds sensible default projections based on the entity type. This ensures that commonly used attributes are included in the query results without requiring explicit specification.

For example, if you provide an expression like:

```
Task where status = "in progress"
```

the system will transform it into:

```
select <default_projections> from Task where status = "in progress"
```

where `<default_projections>` are the default attributes defined for the `Task` entity.

Pagination
----------

The `page_size` parameter specifies the maximum number of results returned per page in the query result object. This allows you to control the size of each batch of results when iterating over large datasets.

Query Result Object
-------------------

The query returns a `QueryResult` object which can be iterated over to access individual records. This object handles pagination internally based on the specified `page_size`.

Logging
-------

Each query execution is logged for debugging purposes, showing the exact query expression being executed.
