Optimization Module
===================

This module provides functionality for performing numerical optimization, particularly focused on maximum likelihood estimation (MLE) problems. It includes routines to minimize objective functions such as negative log-likelihoods using gradient-based methods, with support for Hessian computations and convergence diagnostics.

Key Features
------------

- **Optimization with Gradient and Hessian Information**  
  The module supports optimization algorithms that utilize the function value, its gradient (score), and Hessian matrix to efficiently find parameter estimates that minimize the objective function.

- **Support for Ridge Regularization**  
  To improve numerical stability during Hessian inversion, a ridge factor can be added to the diagonal elements of the Hessian matrix.

- **Flexible Output Options**  
  Users can request full output including the optimized parameters, function value at optimum, number of iterations, gradient and Hessian at the optimum, convergence status, warning flags, and optionally the history of parameter vectors across iterations.

- **Callback Functionality**  
  A callback function can be specified to monitor or modify the optimization process at each iteration.

- **Convergence and Warning Handling**  
  The module detects convergence and warns if the maximum number of iterations is exceeded, printing informative messages when requested.

- **Support for Approximate Gradients**  
  When analytical gradients are not available, the module can approximate gradients numerically.

Usage Notes
-----------

- The primary function to be minimized is typically the negative log-likelihood function, which should accept parameters and additional arguments, returning a scalar value.

- The gradient function (score) should return the gradient vector of the negative log-likelihood with respect to the parameters. If approximate gradients are used, the score function can be omitted.

- Bounds on parameters can be specified to constrain the optimization.

- The module uses unconstrained optimization by default but allows passing options to underlying optimization routines such as `fmin_l_bfgs_b`.

- The sign conventions for the log-likelihood and its gradient may differ from standard notation within the MLE context of this module.

Example Workflow
----------------

1. Define the negative log-likelihood function `f(params, *args)`.
2. Define the gradient function `score(params)` if available.
3. Call the optimization routine with starting parameters, functions, and optional arguments.
4. Retrieve optimized parameters and diagnostic information.
5. Use callback functions or history tracking for monitoring progress.

This module is designed to be a robust and flexible tool for statistical model fitting and other optimization tasks requiring gradient-based methods with detailed output and control over the optimization process.
