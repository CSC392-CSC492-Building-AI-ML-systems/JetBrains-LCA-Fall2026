Contracts
=========

This module provides functionality to interact with Ethereum smart contracts using Python. It includes a base `Contract` class and utilities to create contract proxy classes from compiled contract definitions.

Overview
--------

The core concept is the `Contract` class, which acts as a Python proxy to interact with deployed smart contracts on the Ethereum blockchain. Contract classes are dynamically created using the `construct_contract_factory` function, which takes the contract's ABI and other metadata (such as bytecode and source code) typically generated by the Solidity compiler (`solc`) or frameworks like Populus.

Once a contract proxy class is created, you can instantiate it to interact with a specific deployed contract by providing its address, or deploy new contracts to the blockchain.

Key Components
--------------

### construct_contract_factory

Creates a new Contract class dynamically.

- **Parameters:**
  - `abi`: The contract ABI (Application Binary Interface), describing the contract's functions and events.
  - `code`: The contract bytecode for deployment.
  - `code_runtime`: The runtime bytecode of the contract.
  - `source`: The Solidity source code of the contract (optional).
  - `contract_name`: Name of the contract class to create (default: `'Contract'`).
  - `base_contract_factory_class`: Base class to inherit from (default: `Contract`).

- **Returns:**
  - A new Python class that acts as a proxy for the specified smart contract.

- **Usage Example:**

  .. code-block:: python

      # Assume we have a Token contract definition
      token_contract_data = {
          'abi': [...],
          'code': '0x...',
          'code_runtime': '0x...',
          'source': 'contract Token {.....}',
      }

      # Create a contract factory class for the Token contract
      TokenContract = construct_contract_factory(
          abi=token_contract_data['abi'],
          code=token_contract_data['code'],
          code_runtime=token_contract_data['code_runtime'],
          source=token_contract_data['source'],
          contract_name='Token'
      )

      # Instantiate a proxy for a deployed Token contract
      token = TokenContract(address='0x1234...')

### Contract Class

The base class for all contract proxy classes.

- **Attributes:**
  - `web3`: The Web3 instance used to interact with the Ethereum node.
  - `_abi`: The contract ABI.
  - `_code`: The contract bytecode.
  - `_code_runtime`: The runtime bytecode.
  - `_source`: The Solidity source code.
  - `address`: The Ethereum address of the deployed contract instance.

- **Initialization:**

  Create a contract proxy instance by providing the contract's address:

  .. code-block:: python

      contract_instance = ContractSubclass(address='0x1234...')

- **Methods:**

  - `transact_with_contract_function`: Call a contract function that modifies state (requires a transaction).
  - `call_contract_function`: Call a contract function that does not modify state (read-only call).
  - `deploy`: Deploy a new contract instance to the blockchain.

Usage
-----

1. Compile your Solidity contract using `solc` or a framework like Populus to obtain the ABI, bytecode, and optionally source code.

2. Use `construct_contract_factory` to create a Python contract proxy class.

3. Instantiate the contract proxy with the deployed contract address to interact with it.

4. Use the provided methods to call contract functions or deploy new contracts.

Dependencies
------------

This module depends on several packages from the Ethereum and Web3.py ecosystem:

- `eth_abi` for ABI encoding and decoding.
- `web3` for Ethereum node interaction.
- Utility modules for encoding, formatting, and event handling.

Error Handling
--------------

The module handles common errors such as encoding/decoding failures (`EncodingError`, `DecodingError`) and contract call errors (`BadFunctionCallOutput`), raising appropriate exceptions to aid debugging.

Summary
-------

This code provides a flexible and extensible framework for interacting with Ethereum smart contracts in Python. By dynamically generating contract proxy classes from ABI definitions, it simplifies contract interaction and deployment, integrating seamlessly with Web3.py and related Ethereum tooling.
