Working with Assignments and Allocations
========================================

In Ftrack, assignments and allocations are key concepts used to manage the relationship between users, tasks, and resources. This section provides an overview of how to work with assignments and allocations effectively.

Assignments
-----------

An *assignment* represents the relationship between a user and a task. Assignments are used to indicate which users are responsible for or involved in a particular task.

### Creating Assignments

To create an assignment, you typically associate a user with a task entity. This can be done by creating an assignment entity and linking it to the relevant user and task.

Example:

```python
assignment = session.create('Assignment')
assignment['user'] = user_entity
assignment['task'] = task_entity
session.commit()
```

### Querying Assignments

You can query assignments to find out which users are assigned to a task or which tasks a user is assigned to.

Example:

```python
assignments = session.query('Assignment where task.id is "{}"'.format(task_id)).all()
for assignment in assignments:
    print(assignment['user']['name'])
```

Allocations
-----------

An *allocation* represents the allocation of a resource (such as time or capacity) to a user or a task. Allocations help in planning and tracking resource usage.

### Creating Allocations

Allocations are created similarly to assignments but include additional information such as the amount of resource allocated.

Example:

```python
allocation = session.create('Allocation')
allocation['user'] = user_entity
allocation['task'] = task_entity
allocation['hours'] = 8  # Number of hours allocated
session.commit()
```

### Querying Allocations

You can query allocations to understand how resources are distributed across users and tasks.

Example:

```python
allocations = session.query('Allocation where user.id is "{}"'.format(user_id)).all()
for allocation in allocations:
    print(f"Task: {allocation['task']['name']}, Hours: {allocation['hours']}")
```

Best Practices
--------------

- Use assignments to manage responsibility and involvement of users in tasks.
- Use allocations to manage and track resource usage and availability.
- Always commit your session after creating or modifying assignments and allocations to persist changes.
- Utilize queries to retrieve and analyze assignment and allocation data for reporting and planning.

Notes
-----

- Assignments and allocations are linked to users and tasks via their respective entities.
- Proper management of assignments and allocations helps in efficient project tracking and resource management.
- The session cache and key maker mechanisms can optimize performance when working with large numbers of assignments and allocations.

By understanding and utilizing assignments and allocations, you can effectively manage user responsibilities and resource planning within your Ftrack projects.
