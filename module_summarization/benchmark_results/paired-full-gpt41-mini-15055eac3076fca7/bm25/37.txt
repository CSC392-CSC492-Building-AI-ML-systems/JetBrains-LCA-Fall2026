w_trace — Trace WEST trajectories and output segment data
==========================================================

Synopsis
--------

```
w_trace [OPTIONS] N_ITER:SEG_ID [N_ITER:SEG_ID ...]
```

Description
-----------

The `w_trace` command traces individual WEST (Weighted Ensemble Simulation Toolkit) trajectories and emits or calculates quantities along the trajectory.

Trajectories are specified as pairs of iteration number and segment ID (`N_ITER:SEG_ID`). Each segment is traced backward to its initial point, and various quantities—most notably `n_iter` (iteration number) and `seg_id` (segment ID)—are printed in order from the initial point up to the specified segment in the given iteration.

Output is stored in several files, all named according to the pattern given by the `-o` / `--output-pattern` parameter. The default output pattern is:

```
traj_%d_%d
```

where the printf-style format codes are replaced by the iteration number and segment ID of the terminal segment of the trajectory being traced.

Individual datasets can be selected for writing using the `-d` / `--dataset` option, which may be specified multiple times to include multiple datasets.

Options
-------

- `-d`, `--dataset` DSNAME  
  Include the dataset named `DSNAME` in the trace output. Extended forms allow specifying aliases, indices, files, or slices for datasets.

- `-o`, `--output-pattern` PATTERN  
  Specify the output filename pattern for trace files. The pattern should include two printf-style format specifiers for iteration number and segment ID, respectively. Default is `"traj_%d_%d"`.

- Other options may be available to configure data reading and output formats.

Output
------

The command produces output files containing trace data for each specified trajectory. Output includes:

- A text file (`*_trace.txt`) summarizing segment information along the trajectory, including iteration number, segment ID, weights, progress coordinates, and other relevant data.

- An HDF5 group containing datasets such as `basis_state`, `initial_state`, and `segments` that store detailed trajectory data in a structured format.

- Additional datasets specified via the `--dataset` option may be included in the output HDF5 files.

Usage Notes
-----------

- The trace starts from the specified segment and traces backward through parent segments until the initial segment is reached.

- The output text file columns are aligned and separated by spaces for readability.

- Weight vectors and other data are stored efficiently in HDF5 format to avoid duplication.

- The command supports reading data from WEST simulation data managers and can be integrated into workflows for analyzing WEST trajectories.

Example
-------

Trace a trajectory ending at iteration 10, segment 5, outputting default datasets:

```
w_trace 10:5
```

Trace multiple trajectories and include a specific dataset named `pcoord`:

```
w_trace -d pcoord 10:5 12:3 15:7
```

Specify a custom output filename pattern:

```
w_trace -o "mytrace_iter%d_seg%d" 10:5
```
