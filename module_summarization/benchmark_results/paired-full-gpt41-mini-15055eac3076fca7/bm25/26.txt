w_kinavg Command
================

Description
-----------

The `w_kinavg` command calculates average rates and associated confidence intervals (CIs) from weighted ensemble data. It is designed for path-tracing kinetics analysis and provides averaged kinetics information based on previously generated bin assignments and kinetics data files.

Input Requirements
------------------

Before running `w_kinavg`, the following data files must have been generated:

- **Bin assignments file** (usually named `assignments.h5`)
- **Kinetics data file** (usually named `kintrace.h5` or `kinmat.h5`)

For information on generating these files, see the documentation for the commands:

- `w_assign`
- `w_kinetics`

Usage
-----

The command is typically invoked as:

```
w_kinavg trace [OPTIONS]
```

where `trace` is the subcommand used for path-tracing kinetics analysis.

Output
------

The output file (specified with `-o` or `--output`, default is `kinavg.h5`) contains datasets with averaged kinetics information:

- **/avg_rates** `[state,state]`  
  A structured dataset representing state-to-state rates averaged over the entire window of selected iterations.

In trace mode, additional datasets are generated:

- **/avg_total_fluxes** `[state]`  
  Average total fluxes for each state.

- **ets**  
  Integer dataset indicating the number of bootstrap data sets used to generate confidence intervals.

- **mcbs_acalpha**  
  Floating-point value representing the alpha parameter used for determining correlation lengths.

Command-line Options
--------------------

Run `w_kinavg trace --help` to see all available command-line options for customizing the analysis.

Deprecation Notice
------------------

Note that `w_kinavg` is deprecated and users are encouraged to use the `w_direct` command instead for direct kinetics analysis. The `w_kinavg` command remains available for backward compatibility.

Summary
-------

- Calculates average rates and confidence intervals from weighted ensemble kinetics data.
- Requires prior generation of bin assignments and kinetics data files.
- Outputs averaged rates and related statistics in an HDF5 file.
- Deprecated in favor of the `w_direct` command.
