Nearest Neighbors
=================

The Nearest Neighbors algorithms provide functionality for unsupervised neighbor searches. These algorithms are fundamental in many machine learning tasks such as classification, regression, and clustering, where the proximity of data points is a key factor.

Overview
--------

The Nearest Neighbors methods allow you to find the closest points in a dataset to a given query point. The choice of algorithm and parameters such as `algorithm` and `leaf_size` can significantly affect the performance and accuracy of the neighbor searches.

For a detailed discussion on the choice of these parameters, see the :ref:`Nearest Neighbors <neighbors>` section in the online documentation.

More information about the underlying k-nearest neighbors algorithm can be found on the `Wikipedia page <https://en.wikipedia.org/wiki/K-nearest_neighbors_algorithm>`_.

Key Classes
-----------

- **NearestNeighbors**  
  An unsupervised learner for implementing neighbor searches. It supports different algorithms for neighbor searches and can be used to compute the k-nearest neighbors or neighbors within a fixed radius.

- **KNeighborsClassifier**  
  A classifier based on the k-nearest neighbors vote.

- **RadiusNeighborsClassifier**  
  A classifier based on neighbors within a given radius.

- **KNeighborsRegressor**  
  Regression based on k-nearest neighbors.

- **RadiusNeighborsRegressor**  
  Regression based on neighbors within a fixed radius.

- **BallTree**  
  A space partitioning data structure for organizing points in a multi-dimensional space, used for nearest neighbor search.

Parameters and Attributes
-------------------------

- `n_neighbors` : int, default=5  
  Number of neighbors to use by default for queries.

- `radius` : float, default=1.0  
  Range of parameter space to use by default for radius-based neighbors queries.

- `algorithm` : {'auto', 'ball_tree', 'kd_tree', 'brute'}, default='auto'  
  Algorithm used to compute the nearest neighbors.

- `leaf_size` : int, default=30  
  Leaf size passed to BallTree or KDTree. This can affect the speed of the construction and query, as well as the memory required to store the tree.

- `metric` : str or callable, default='minkowski'  
  The distance metric to use for the tree.

- `n_samples_fit_` : int  
  Number of samples in the fitted data.

- `n_features_in_` : int  
  Number of features seen during fit.

- `feature_names_in_` : ndarray of shape (`n_features_in_`,)  
  Names of features seen during fit. Defined only when input data has feature names that are all strings.

Usage Examples
--------------

Finding the k-nearest neighbors:

.. code-block:: python

    import numpy as np
    from sklearn.neighbors import NearestNeighbors

    samples = [[0, 0, 2], [1, 0, 0], [0, 0, 1]]
    neigh = NearestNeighbors(n_neighbors=2, radius=0.4)
    neigh.fit(samples)
    # NearestNeighbors(...)

    # Find the indices of the 2 nearest neighbors of the query point
    neigh.kneighbors([[0, 0, 1.3]], 2, return_distance=False)
    # array([[2, 0]]...)

    # Find neighbors within radius 0.4 of the query point
    nbrs = neigh.radius_neighbors([[0, 0, 1.3]], 0.4, return_distance=False)
    np.asarray(nbrs[0][0])
    # array(2)

Constructing a k-nearest neighbors graph:

.. code-block:: python

    X = [[0], [3], [1]]
    from sklearn.neighbors import NearestNeighbors
    neigh = NearestNeighbors(n_neighbors=2)
    neigh.fit(X)
    # NearestNeighbors(n_neighbors=2)

    A = neigh.kneighbors_graph(X)
    A.toarray()
    # array([[1., 0., 1.],
    #        [0., 1., 1.],
    #        [1., 0., 1.]])

Radius-based regression example:

.. code-block:: python

    X = [[0], [1], [2], [3]]
    y = [0, 0, 1, 1]
    from sklearn.neighbors import RadiusNeighborsRegressor
    neigh = RadiusNeighborsRegressor(radius=1.0)
    neigh.fit(X, y)
    # RadiusNeighborsRegressor(...)

    print(neigh.predict([[1.5]]))
    # [0.5]

Notes
-----

- The choice of `algorithm` and `leaf_size` can impact the efficiency of neighbor searches. Refer to the online documentation for guidance on selecting these parameters.

- When two neighbors have identical distances but different labels, the results may depend on the ordering of the training data.

- The Nearest Neighbors algorithms are versatile and can be used for classification, regression, and unsupervised learning tasks.
