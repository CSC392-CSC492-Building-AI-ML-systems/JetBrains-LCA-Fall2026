w_kinetics command
==================

Calculate state-to-state kinetics by tracing trajectories
---------------------------------------------------------

The `w_kinetics` command calculates state-to-state rates and transition event durations by tracing trajectories. It requires a bin assignment file (usually named `assign.h5`) that includes trajectory labeling. For information on generating this file, see the documentation for the `w_assign` command (`w_assign --help`).

The output generated by `w_kinetics` is intended to be used as input for the `w_kinavg` tool, which converts the flux data into average rates with confidence intervals. For more details, see `w_kinavg trace --help`.

Subcommands
-----------

trace
~~~~~

The `trace` subcommand computes averages and confidence intervals for path-tracing kinetics analysis.

- Default output file: `kintrace.h5`
- Description: Averages and confidence intervals for path-tracing kinetics analysis.

Output format
-------------

The output file (specified with `-o` or `--output`, defaulting to `kintrace.h5`) contains the following datasets:

- `/conditional_fluxes` [iteration][state][state]  
  *(Floating-point)* Macrostate-to-macrostate fluxes. These are **not** normalized.

- `/durations` [iteration][state][state]  
  *(Floating-point)* Duration of transition, in units of tau.

- `/weight`  
  *(Floating-point)* Weight of trajectory at end of transition, **not** normalized by initial state population.

Note that the state-to-state fluxes stored in this file are not normalized by the initial macrostate population and therefore cannot be used directly as rates. The `w_kinavg` command performs this normalization while accounting for statistical fluctuations and correlations. Target fluxes (total flux into a given state) do not require such normalization.

Usage notes
-----------

- The `w_kinetics` command is deprecated. Users are encouraged to use the `w_direct` command instead.
- When invoked, if no subcommand is specified, `trace` is used by default.

Example
-------

```bash
w_kinetics trace -o kintrace.h5 assign.h5
```

This command runs the path-tracing kinetics analysis on the assignment file `assign.h5` and writes the output to `kintrace.h5`.

See Also
--------

- `w_assign` — for generating bin assignment files.
- `w_kinavg` — for averaging flux data and computing confidence intervals.
- `w_direct` — recommended replacement for `w_kinetics`.
