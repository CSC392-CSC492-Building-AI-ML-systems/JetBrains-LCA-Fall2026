Iterables Module
================

This module provides various utilities for working with iterables, including generating partitions, subsets, runs, and performing breadth-first Cartesian products.

Particular functions documented here include:

partitions(n, k=None, m=None)
-----------------------------

Generate all partitions of the integer `n`.

A partition of `n` is a way of writing `n` as a sum of positive integers. Each partition is represented as a dictionary mapping an integer to the number of copies of that integer in the partition.

Parameters:
- `n` (int): The integer to partition.
- `k` (int, optional): Limits the numbers appearing in the partition (the keys of the returned dictionary) to be at most `k`.
- `m` (int, optional): Limits the maximum number of parts in the partition (the sum of the values in the returned dictionary) to be at most `m`.

Returns:
- Iterator[dict]: An iterator over partitions of `n` represented as dictionaries.

Examples:

>>> from diofant.utilities.iterables import partitions
>>> for p in partitions(6, k=2):
...     print(p)
{2: 3}
{2: 2, 1: 2}
{2: 1, 1: 4}
{1: 6}

>>> for p in partitions(6, m=2):
...     print(p)
{6: 1}
{5: 1, 1: 1}
{4: 1, 2: 1}
{3: 2}

Note:
The same dictionary object is returned each time for speed, so do not modify the returned dictionaries.

runs(seq, op=operator.ge)
-------------------------

Generate runs (consecutive subsequences) from the iterable `seq` where the binary operator `op` holds between consecutive elements.

Parameters:
- `seq` (iterable): The input sequence.
- `op` (callable, optional): A binary operator function that takes two arguments and returns a boolean. Defaults to `operator.ge` (greater than or equal).

Returns:
- List[List]: A list of runs, where each run is a list of elements from `seq` satisfying the operator condition consecutively.

Example:

>>> import operator
>>> from diofant.utilities.iterables import runs
>>> runs([0, 1, 2, 2, 1, 4, 3, 2, 2], op=operator.ge)
[[0, 1, 2, 2], [1, 4], [3], [2, 2]]

cantor_product(*args)
---------------------

Breadth-first (diagonal) Cartesian product of input iterables.

This function generates the Cartesian product of the input iterables in a breadth-first manner, advancing each iterable in turn in a round-robin fashion. This approach enumerates tuples in order of increasing sum of indices, which can be useful when dealing with infinite iterables.

Note:
Breadth-first traversal comes at the cost of increased memory consumption.

Example:

>>> from itertools import count, islice
>>> from diofant.utilities.iterables import cantor_product
>>> list(islice(cantor_product(count(), count()), 9))
[(0, 0), (1, 0), (0, 1), (2, 0), (1, 1), (0, 2), (3, 0), (2, 1), (1, 2)]

subsets(seq, k=None, repetition=False)
--------------------------------------

Generate all k-subsets (combinations) from an n-element set `seq`.

A k-subset of an n-element set is any subset of length exactly k. The number of k-subsets of an n-element set is given by the binomial coefficient C(n, k), whereas there are 2^n subsets in total. If `k` is None, then all 2^n subsets will be returned, ordered from shortest to longest.

Parameters:
- `seq` (iterable): The input sequence.
- `k` (int, optional): The size of subsets to generate. If None, generate all subsets.
- `repetition` (bool, optional): If True, subsets with repeated elements are allowed.

Returns:
- Iterator[tuple]: An iterator over subsets of `seq`.

Examples:

>>> from diofant.utilities.iterables import subsets
>>> list(subsets([1, 2], 2))
[(1, 2)]
>>> list(subsets([1, 2]))
[(), (1,), (2,), (1, 2)]
>>> list(subsets([1, 2, 3], 2))
[(1, 2), (1, 3), (2, 3)]

If `repetition` is True, elements can be repeated in subsets.

---

This module is useful for combinatorial tasks and working with sequences in a flexible and efficient manner.
