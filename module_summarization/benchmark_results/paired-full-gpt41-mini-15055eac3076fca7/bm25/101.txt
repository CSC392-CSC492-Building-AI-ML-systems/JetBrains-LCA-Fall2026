Miner
=====

The `Miner` class provides an interface to interact with the Ethereum miner through the Web3.py library. It allows querying mining-related information and controlling the miner's behavior via JSON-RPC calls.

Initialization
--------------

`Miner(web3)`

Creates a new `Miner` instance.

- **web3** (`Web3`): An instance of the Web3 class used to make JSON-RPC requests.

Properties
----------

hashrate
~~~~~~~~

The current mining hashrate.

:type: int

This property returns the miner's current hashrate as a decimal integer by calling the `eth_hashrate` JSON-RPC method.

Methods
-------

makeDAG(number)
~~~~~~~~~~~~~~

Generate the DAG (Directed Acyclic Graph) for a given epoch number.

:param int number: The epoch number for which to generate the DAG.

:return: Result of the `miner_makeDag` JSON-RPC call.

setExtra(extra)
~~~~~~~~~~~~~~

Set the extra data field for the miner.

:param str extra: The extra data to set.

:return: Result of the `miner_setExtra` JSON-RPC call.

setEtherBase(etherbase)
~~~~~~~~~~~~~~~~~~~~~~

Set the etherbase (coinbase) address for the miner.

:param str etherbase: The address to set as the etherbase.

:return: Result of the `miner_setEtherbase` JSON-RPC call.

setGasPrice(gas_price)
~~~~~~~~~~~~~~~~~~~~~~

Set the gas price for the miner.

:param int gas_price: The gas price to set.

:return: Result of the `miner_setGasPrice` JSON-RPC call.

start(num_threads)
~~~~~~~~~~~~~~~~~~

Start the miner with the specified number of threads.

:param int num_threads: Number of threads to use for mining.

:return: Result of the `miner_start` JSON-RPC call.

stop()
~~~~~~

Stop the miner.

:return: Result of the `miner_stop` JSON-RPC call.

startAutoDAG()
~~~~~~~~~~~~~

Enable automatic DAG generation.

:return: Result of the `miner_startAutoDag` JSON-RPC call.

stopAutoDAG()
~~~~~~~~~~~~

Disable automatic DAG generation.

:return: Result of the `miner_stopAutoDag` JSON-RPC call.
