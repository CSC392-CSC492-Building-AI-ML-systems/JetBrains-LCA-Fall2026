Decision Trees
==============

Decision trees are a non-parametric supervised learning method used for classification and regression tasks. The goal is to create a model that predicts the value of a target variable by learning simple decision rules inferred from the data features.

Overview
--------

The decision tree algorithms implemented include:

- **DecisionTreeClassifier**: A classifier based on decision trees.
- **ExtraTreeClassifier**: A variant of decision trees with randomized splits for classification.
- **DecisionTreeRegressor**: A regressor based on decision trees.
- **ExtraTreeRegressor**: A variant of decision trees with randomized splits for regression.

These estimators support various criteria for splitting nodes:

- Classification criteria: `"gini"`, `"log_loss"`
- Regression criteria: `"squared_error"`, `"absolute_error"`, `"friedman_mse"`, `"poisson"`

Key Features
------------

- Trees can handle both dense and sparse input data.
- The `apply` method returns the index of the leaf that each sample is predicted as.
- The `decision_path` method returns the decision path in the tree for each sample, indicating which nodes are visited.
- Supports sample weights to handle imbalanced datasets.
- Random state control for reproducibility.
- Parameters such as `max_depth`, `min_samples_leaf`, and others allow control over tree complexity and size to prevent overfitting.

Usage Example
-------------

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import load_iris

iris = load_iris()
X, y = iris.data, iris.target

clf = DecisionTreeClassifier(random_state=0, max_depth=3)
clf.fit(X, y)

# Predict class labels for samples
predictions = clf.predict(X)

# Get the index of the leaf node each sample ends up in
leaf_indices = clf.apply(X)

# Get the decision path for samples
decision_paths = clf.decision_path(X)
```

Attributes
----------

- `tree_`: The underlying Tree object that stores the tree structure.
- `classes_`: The class labels for classification tasks.
- `max_depth`: The maximum depth of the tree.
- `feature_importances_`: Importance of each feature in the decision making.

Notes
-----

- By default, trees are grown fully and unpruned, which can lead to very large trees and overfitting. It is recommended to control tree size using parameters like `max_depth` and `min_samples_leaf`.
- The `predict` method uses `numpy.argmax` on the output of `predict_proba`. In case of ties, the class with the lowest index in `classes_` is predicted.
- Decision trees can handle both dense and sparse input formats efficiently.

Testing and Validation
----------------------

The implementation includes comprehensive tests to ensure correctness of:

- The `apply` method on both dense and sparse data.
- The `decision_path` method, verifying the correctness of node indicators and leaf indices.
- Handling of explicit zeros in sparse matrices.
- Proper error raising on invalid input shapes.

These tests ensure the robustness and reliability of the decision tree estimators across different data formats and parameter settings.
