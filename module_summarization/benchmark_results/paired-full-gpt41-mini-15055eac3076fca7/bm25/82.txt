BaseUser Module
===============

Overview
--------
This module defines the `BaseUser` class, which provides a basic user model with authentication support. It is designed to be used within the Piccolo ORM framework and includes fields commonly required for user management, such as username, password, email, and permissions flags.

BaseUser Class
--------------

The `BaseUser` class inherits from `Table` and represents a user in the system. It is mapped to the database table named `piccolo_user`.

### Fields

- **id** (`Serial`):  
  The primary key for the user record.

- **username** (`Varchar(length=100, unique=True)`):  
  The unique username for the user.

- **password** (`Secret(length=255)`):  
  The user's password stored securely.

- **first_name** (`Varchar(null=True)`):  
  Optional first name of the user.

- **last_name** (`Varchar(null=True)`):  
  Optional last name of the user.

- **email** (`Varchar(length=255, unique=True)`):  
  The user's unique email address.

- **active** (`Boolean(default=False)`):  
  Indicates whether the user account is active.

- **admin** (`Boolean(default=False)`):  
  Indicates if the user has admin privileges to log into the Piccolo admin GUI.

- **superuser** (`Boolean(default=False)`):  
  Indicates if the user can manage other users' passwords in the Piccolo admin GUI.

- **last_login** (`Timestamp`):  
  Records the last login time of the user.

Class Methods
-------------

### `create_user`

```python
@classmethod
async def create_user(cls, username: str, password: str, **extra_params) -> BaseUser
```

Creates a new user and saves it to the database asynchronously.

- **Parameters:**
  - `username` (`str`): The username for the new user. Must be provided.
  - `password` (`str`): The password for the new user. Must be valid.
  - `**extra_params`: Additional fields to set on the user.

- **Returns:**  
  An instance of `BaseUser` representing the newly created user.

- **Raises:**  
  `ValueError` if the username or password is invalid.

- **Description:**  
  This method performs validation on the username and password before creating the user. It is recommended to use this method instead of directly instantiating and saving `BaseUser` objects to ensure proper validation.

### `create_user_sync`

```python
@classmethod
def create_user_sync(cls, username: str, password: str, **extra_params) -> BaseUser
```

A synchronous equivalent of `create_user`.

- **Parameters:**
  - `username` (`str`): The username for the new user.
  - `password` (`str`): The password for the new user.
  - `**extra_params`: Additional fields to set on the user.

- **Returns:**  
  An instance of `BaseUser` representing the newly created user.

- **Description:**  
  This method wraps the asynchronous `create_user` method to provide synchronous user creation support.

Usage Notes
-----------

- It is recommended to use the `create_user` or `create_user_sync` class methods to create new users to ensure that all necessary validation is performed.
- The `admin` and `superuser` flags control access to the Piccolo admin GUI and user management capabilities.
- Passwords are stored securely using the `Secret` column type.

Logging
-------

The module uses Python's standard `logging` library to log events, accessible via the `logger` object.

Imports
-------

The module imports several Piccolo ORM components such as `Table`, column types (`Varchar`, `Secret`, `Boolean`, `Timestamp`, `Serial`), and utility functions like `run_sync` for synchronous execution of asynchronous code.

Summary
-------

This module provides a foundational user model suitable for authentication and user management within applications using the Piccolo ORM. It includes essential fields and methods to create and manage users securely and efficiently.
