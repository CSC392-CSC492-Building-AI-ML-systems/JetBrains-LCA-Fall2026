SpectralModel Class
===================

A wrapper class for spectral models that includes internal functions to generate multi-component models, annotations, integrals, and individual components. This class supports complex model declarations where individual variables can be named, limits can be set, units for fitting can be specified, and annotations can be customized. Examples of usage can be found in hyperfine codes such as hcn and n2hp.

Constructor
-----------

SpectralModel(modelfunc, npars, shortvarnames=("A","\\Delta x","\\sigma"), fitunit=None, centroid_par=None, fwhm_func=None, fwhm_pars=None, integral_func=None, use_lmfit=False, guess_types=('amplitude', 'center', 'width'), **kwargs)

Parameters:

- **modelfunc** : callable  
  The model function to be wrapped.

- **npars** : int  
  Number of parameters in the model.

- **shortvarnames** : tuple of str, optional  
  Short variable names for parameters, default is ("A","\\Delta x","\\sigma").

- **fitunit** : optional  
  Unit in which the fit will be performed.

- **centroid_par** : str or None, optional  
  The name of the parameter representing the centroid. If unspecified, default centroid parameters of the model will be used.

- **fwhm_func** : callable, optional  
  Function to compute the full width at half maximum (FWHM).

- **fwhm_pars** : optional  
  Parameters for the FWHM function.

- **integral_func** : callable, optional  
  Function to compute the integral of the model.

- **use_lmfit** : bool, optional  
  Whether to use lmfit for fitting.

- **guess_types** : tuple of str, optional  
  Types of guesses for fitting parameters, default is ('amplitude', 'center', 'width').

- **kwargs** : additional keyword arguments  
  Additional arguments passed to the base class.

Methods
-------

fitter(xax, data, err=None, quiet=True, veryverbose=False, debug=False, parinfo=None, params=None, npeaks=None, **kwargs)  
    Fit the model to data using astropy models.  
    Parameters:  
    - **xax** : array-like  
      The x-axis data points.  
    - **data** : array-like  
      The data to fit.  
    - **err** : array-like or None, optional  
      Errors associated with the data points.  
    - **quiet** : bool, optional  
      Suppress output if True.  
    - **veryverbose** : bool, optional  
      Enable very verbose output if True.  
    - **debug** : bool, optional  
      Enable debug mode if True.  
    - **parinfo** : ParinfoList or None, optional  
      Parameter information for fitting.  
    - **params** : array-like or None, optional  
      Initial parameter values.  
    - **npeaks** : int or None, optional  
      Number of peaks to fit. Multiple peaks fitting is not supported with astropy models yet.  
    - **kwargs** : additional keyword arguments passed to the fitter.

_make_parinfo(model=None)  
    Create a ParinfoList from the model parameters.  
    Returns:  
    - parinfo : ParinfoList  
      List of parameter information objects.  
    - dict : empty dictionary (reserved for future use).

_parse_parinfo(parinfo)  
    Parse a ParinfoList into astropy.models parameters.  
    Raises ValueError if the number of parameters is not an integer multiple of the expected number.

computed_centroid(xarr=None)  
    Compute and return the centroid of the model.  
    Parameters:  
    - **xarr** : array-like or None, optional  
      The x coordinates over which to compute the centroid. If None, centroid is computed in pixel units.  
    Returns:  
    - list of centroid values.

Additional Attributes
---------------------

- **modelfunc** : astropy.modeling.Model  
  The underlying astropy model function.

- **parinfo** : ParinfoList  
  List of parameter information objects used for fitting.

- **npars** : int  
  Number of parameters in the model.

- **centroid_par** : str or None  
  Name of the centroid parameter.

- **astropy_fitter** : astropy fitting object  
  The fitter object used for fitting the model.

- **model** : callable  
  The fitted model evaluated at given x values.

Notes
-----

- The class currently does not support fitting multiple peaks simultaneously when using astropy models.

- The class integrates with astropy's NonLinearLSQFitter for fitting procedures.

- Error handling is implemented to ensure the parameter information matches the expected model parameters.

- The class is designed to be flexible and extensible for complex spectral modeling tasks.
