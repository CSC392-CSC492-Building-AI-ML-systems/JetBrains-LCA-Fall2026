w_ipa — WESTPA Interactive Python Analysis
===========================================

Overview
--------

`w_ipa` (WESTPA Interactive Python Analysis) is an interactive command-line tool designed to facilitate detailed analysis of WESTPA simulation data. It provides a stateful environment where users can explore trajectories, weights, progress coordinates, and other relevant data from WESTPA simulations. The tool operates based on the current analysis scheme and iteration, allowing dynamic and flexible data inspection.

Key Features
------------

- Interactive Python environment with tab completion and magic commands.
- Access to current iteration, schemes, and analysis data.
- Loading and running analyses automatically upon startup.
- Integration with IPython for enhanced interactivity.
- Support for multiple analysis schemes defined in `west.cfg`.
- Stateful interface: data reflects the current iteration and scheme.
- Tools to examine weights, progress coordinates, bin assignments, and trajectory labels.

Getting Started
---------------

To launch the tool, simply run:

```
w_ipa
```

Upon startup, you will see a welcome message indicating the version of `w_ipa` and instructions for further help:

```
Welcome to w_ipa (WESTPA Interactive Python Analysis) v. <version>!
Run w.introduction for a more thorough introduction, or w.help to see a list of options.
Running analysis & loading files.
```

The tool automatically loads the relevant data files and analysis structures for the current scheme and iteration.

Basic Usage
-----------

`w_ipa` exposes its properties and methods through the main interface object, typically referenced as `w` or `west`. You can inspect or modify the current iteration and scheme as follows:

```python
# Get current iteration
w.iteration

# Set current iteration
w.iteration = 5

# List available schemes
w.list_schemes
```

You can explore trajectory data, weights, and other analysis results using the provided attributes and methods.

Interactive Environment
-----------------------

`w_ipa` uses IPython to provide an enhanced interactive shell with features such as:

- Tab completion for dictionary keys and object attributes.
- Magic commands for quick access to common functions.
- Embedded help and introduction commands (`w.help`, `w.introduction`).

Exiting the Tool
----------------

To exit the interactive session, simply type `exit` or press `Ctrl-D`. Upon exit, you will see the message:

```
Leaving w_ipa... goodbye.
```

Advanced Usage
--------------

`w_ipa` is designed to be extensible and integrates with other WESTPA tools such as `w_assign`, `w_direct`, and `w_reweight`. It supports loading different analysis schemes and iterating through simulation data programmatically.

Warnings and Compatibility
--------------------------

The tool suppresses various warnings (DeprecationWarning, RuntimeWarning, FutureWarning, ImportWarning) to provide a cleaner user experience.

Requirements
------------

- Python environment with IPython installed.
- WESTPA simulation data and configuration files (`west.cfg`).
- Dependencies including `numpy` and `westpa` Python packages.

Summary
-------

`w_ipa` is a powerful and user-friendly interactive analysis tool for WESTPA simulations, enabling users to explore and analyze simulation data efficiently within a Python environment. It is ideal for users who want to perform custom analyses or inspect simulation results beyond standard command-line tools.
