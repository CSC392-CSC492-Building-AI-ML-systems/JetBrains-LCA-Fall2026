w_ntop Command
==============

Description
-----------

The `w_ntop` command selects walkers from bins based on their weights or randomly. It requires an assignment file that maps walkers to bins at each timepoint (see `w_assign --help` for information on generating this file). By default, `w_ntop` selects the top N highest-weight walkers from each bin (hence the name "w_ntop"). Alternatively, it can select the lowest-weight walkers or randomly-selected walkers from each bin.

This tool is useful for analyzing and extracting subsets of walkers from WESTPA simulations according to their weights or random selection criteria.

Output Format
-------------

The output file (specified with `-o` or `--output`, default: `ntop.h5`) contains the following datasets:

- **`/n_iter`** [iteration]  
  *(Integer)* Iteration numbers for each entry in other datasets.

- **`/n_segs`** [iteration][bin]  
  *(Integer)* Number of segments in each bin/state in the given iteration.  
  This number is generally the same as the number requested with `--n`/`--count` but may be smaller if the requested number of walkers does not exist.

- **`/seg_ids`** [iteration][bin][segment]  
  *(Integer)* Segment IDs matching the selected segments in each iteration for each bin.  
  For an iteration `n_iter`, only the first `n_segs[n_iter]` entries are valid. For example, the full list of matching segment IDs in bin 0 in the first stored iteration is `seg_ids[0][0][:n_segs[0]]`.

- **`/weights`** [iteration][bin][segment]  
  *(Floating-point)* Weights for each matching segment in `/seg_ids`.

Command-Line Arguments
----------------------

Selection Options
~~~~~~~~~~~~~~~~~

- `--lowweight`  
  Select the COUNT lowest-weight walkers from each bin.

- `--random`  
  Select COUNT walkers randomly from each bin.

By default, the command selects the COUNT highest-weight walkers from each bin.

Output Options
~~~~~~~~~~~~~~

- `-o`, `--output` OUTPUT  
  Write output to OUTPUT file (default: `ntop.h5`).

Other Options
~~~~~~~~~~~~~

- Iteration range selection options (see `w_assign` or related tools for details).

- Progress indicator options to monitor the progress of the command.

Usage Notes
-----------

- The assignment file mapping walkers to bins at each timepoint is required for this command to function correctly.

- The number of walkers selected per bin is controlled by the `--n` or `--count` argument (not shown here but typically available).

- The output file can be used for further analysis or visualization of walker distributions across bins and iterations.

For more detailed usage and examples, refer to the `w_assign` command documentation and WESTPA user guides.
