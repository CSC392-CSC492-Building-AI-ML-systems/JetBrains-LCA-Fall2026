RandAugment Module
==================

Overview
--------

The RandAugment module provides a flexible and extensible implementation of the RandAugment data augmentation technique, commonly used to improve the robustness and generalization of machine learning models, particularly in computer vision tasks. This module is part of the NVIDIA DALI library and leverages efficient GPU-accelerated operations.

Key Features
------------

- Supports a wide range of augmentation operations including brightness, contrast, color, sharpness, posterize, solarize, equalize, auto contrast, and identity transformations.
- Allows customization of augmentation suites with monotonic or non-monotonic magnitude ranges.
- Supports random negation of magnitudes for certain augmentations.
- Provides utilities to apply multiple augmentations sequentially with configurable magnitude bins.
- Enables exclusion of specific augmentations from the default suite.
- Integrates seamlessly with DALI's DataNode pipeline for efficient batch processing.

Functions
---------

rand_augment(data, n, m, num_magnitude_bins=31, shape=None, seed=None, monotonic_mag=True, excluded=None, **kwargs)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Apply RandAugment transformations to a batch of data.

Parameters
^^^^^^^^^^

- **data** (_DataNode_): Input batch of samples to be augmented.
- **n** (int): Number of augmentation transformations to apply sequentially.
- **m** (int): Magnitude for all augmentation operations, typically in the range [0, num_magnitude_bins - 1].
- **num_magnitude_bins** (int, optional): Number of discrete bins for magnitude levels. Default is 31.
- **shape** (Optional[Union[_DataNode, Tuple[int, ...]]]): Shape of the input data, used for spatial augmentations.
- **seed** (Optional[int]): Random seed for reproducibility.
- **monotonic_mag** (bool, optional): If True, use monotonic magnitude ranges; otherwise, use non-monotonic ranges. Default is True.
- **excluded** (Optional[List[str]]): List of augmentation operation names to exclude from the default suite.
- **kwargs**: Additional keyword arguments passed to augmentation operations.

Returns
^^^^^^^

_DataNode_: Batch of augmented samples.

Description
^^^^^^^^^^^

This function applies `n` augmentation operations sequentially to the input data, each with magnitude `m`. The augmentations are selected from a predefined suite, which can be customized or filtered by excluding certain operations. The magnitude bins control the strength of each augmentation. The function supports both monotonic and non-monotonic magnitude scaling, affecting how augmentation strength varies with magnitude.

get_rand_augment_suite(use_shape=False, max_translate_abs=None, max_translate_rel=None) -> List[_Augmentation]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Create a default list of RandAugment augmentations with monotonic magnitude ranges.

Parameters
^^^^^^^^^^

- **use_shape** (bool, optional): Whether to use the input shape for spatial augmentations. Default is False.
- **max_translate_abs** (Optional[int]): Maximum absolute translation for spatial augmentations.
- **max_translate_rel** (Optional[float]): Maximum relative translation for spatial augmentations.

Returns
^^^^^^^

List[_Augmentation]: List of augmentation operations forming the default monotonic RandAugment suite.

Description
^^^^^^^^^^^

This function returns a list of augmentation operations including brightness, contrast, color, sharpness, posterize, solarize, equalize, auto contrast, and identity. The magnitude ranges for these operations increase or decrease monotonically with the magnitude bin, providing predictable augmentation strength scaling.

get_rand_augment_non_monotonic_suite(use_shape=False, max_translate_abs=None, max_translate_rel=None) -> List[_Augmentation]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Create a list of RandAugment augmentations with non-monotonic magnitude ranges.

Parameters
^^^^^^^^^^

- **use_shape** (bool, optional): Whether to use the input shape for spatial augmentations. Default is False.
- **max_translate_abs** (Optional[int]): Maximum absolute translation for spatial augmentations.
- **max_translate_rel** (Optional[float]): Maximum relative translation for spatial augmentations.

Returns
^^^^^^^

List[_Augmentation]: List of augmentation operations forming the non-monotonic RandAugment suite.

Description
^^^^^^^^^^^

This variant of the augmentation suite differs from the monotonic version by using magnitude ranges where the strength of some color operations (brightness, contrast, color, sharpness) decreases as the magnitude approaches the center of the range. Posterize and solarize operations have strength inversely related to magnitude bins. This allows for more nuanced augmentation effects.

Usage Notes
-----------

- The module relies on NVIDIA DALI's DataNode abstraction for efficient data processing.
- Augmentation operations are implemented as instances of the internal `_Augmentation` class.
- Users can customize augmentation behavior by modifying the augmentation suites or by directly applying augmentations using `apply_rand_augment`.
- The module enforces that augmentation names are unique within a suite to avoid conflicts.
- Random negation of magnitudes is supported for augmentations that benefit from symmetric transformations.
