Manifold Learning for Non-Linear Dimensionality Reduction
=========================================================

Manifold learning is a class of algorithms for non-linear dimensionality reduction. Unlike linear methods such as Principal Component Analysis (PCA), manifold learning techniques aim to uncover the low-dimensional structure embedded in high-dimensional data by assuming that the data lies on or near a manifold of much lower dimensionality than the ambient space.

Overview
--------

Manifold learning methods seek to preserve certain geometric or topological properties of the data when mapping it to a lower-dimensional space. These methods are particularly useful for visualizing and understanding complex datasets where linear assumptions do not hold.

Common manifold learning algorithms include:

- **Multidimensional Scaling (MDS)**  
  A technique that aims to preserve pairwise distances between points in the low-dimensional embedding.  
  References:  
  [1] Kruskal, J. "Nonmetric multidimensional scaling: a numerical method." *Psychometrika*, 29 (1964).  
  [2] Kruskal, J. "Multidimensional scaling by optimizing goodness of fit to a nonmetric hypothesis." *Psychometrika*, 29 (1964).  
  [3] Borg, I.; Groenen, P. *Modern Multidimensional Scaling - Theory and Applications*.

- **Isometric Mapping (Isomap)**  
  Extends MDS by approximating the geodesic distances on the manifold using nearest neighbors graph, preserving the intrinsic geometry of the data.  
  Reference:  
  [1] Tenenbaum, J.B.; De Silva, V.; Langford, J.C. "A global geometric framework for nonlinear dimensionality reduction." *Science*, 290 (5500), 2000.

- **Locally Linear Embedding (LLE)**  
  Preserves local neighborhood relationships by reconstructing each data point from its neighbors and then finding a low-dimensional embedding that maintains these reconstruction weights.  
  References:  
  [1] Roweis, S.; Saul, L. "Nonlinear dimensionality reduction by locally linear embedding." *Science*, 290:2323 (2000).  
  [2] Donoho, D.; Grimes, C. "Hessian eigenmaps: Locally linear embedding techniques for high-dimensional data." *Proc Natl Acad Sci U S A.*, 100:5591 (2003).  
  [3] Zhang, Z.; Wang, J. "MLLE: Modified Locally Linear Embedding."

- **Spectral Embedding**  
  Uses spectral decomposition of the graph Laplacian constructed from the data to find a low-dimensional representation that preserves neighborhood information.

- **t-Distributed Stochastic Neighbor Embedding (t-SNE)**  
  A probabilistic technique that models pairwise similarities in high-dimensional space and attempts to preserve these similarities in a low-dimensional embedding, often used for visualization.  
  References:  
  [1] van der Maaten, L.J.P.; Hinton, G.E. "Visualizing High-Dimensional Data Using t-SNE." *Journal of Machine Learning Research*, 9:2579-2605, 2008.  
  [2] van der Maaten, L.J.P. "t-Distributed Stochastic Neighbor Embedding." https://lvdmaaten.github.io/tsne/  
  [3] van der Maaten, L.J.P. "Accelerating t-SNE using Tree-Based Algorithms." *Journal of Machine Learning Research*, 15(Oct):3221-3245, 2014.

Key Attributes and Parameters
-----------------------------

- **n_neighbors** : int  
  Number of neighbors to consider for each point when constructing the neighborhood graph. This parameter influences the balance between local and global structure preservation.

- **n_components** : int  
  The dimension of the projected subspace.

- **eigen_solver** : {'auto', 'arpack', 'dense'}  
  The algorithm to use for the eigenvalue decomposition step.  
  - *auto*: Automatically selects the best method based on the input data.  
  - *arpack*: Uses Arnoldi iteration in shift-invert mode, suitable for large sparse matrices.  
  - *dense*: Uses a dense eigenvalue solver.

- **n_iter_** : int  
  Number of iterations run during optimization (applicable to iterative methods like t-SNE).

- **nbrs_** : NearestNeighbors instance  
  Stores the nearest neighbors model used to compute neighborhood graphs.

- **dist_matrix_** : array-like, shape (n_samples, n_samples)  
  Stores the geodesic distance matrix computed from the training data (used in Isomap).

- **feature_names_in_** : ndarray of shape (`n_features_in_`,)  
  Names of features seen during fitting, if available.

Applications
------------

Manifold learning is widely used for:

- Visualization of high-dimensional data in 2D or 3D.
- Preprocessing step for clustering or classification.
- Discovering intrinsic data structure in fields such as image processing, bioinformatics, and speech recognition.

Example
--------

```python
from sklearn.datasets import load_digits
from sklearn.manifold import Isomap

X, _ = load_digits(return_X_y=True)
print(X.shape)  # (1797, 64)

embedding = Isomap(n_components=2)
X_transformed = embedding.fit_transform(X[:100])
print(X_transformed.shape)  # (100, 2)
```
