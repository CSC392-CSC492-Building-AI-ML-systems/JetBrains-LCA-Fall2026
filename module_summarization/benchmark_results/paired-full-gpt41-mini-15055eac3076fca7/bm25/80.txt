cubes Module
============

Overview
--------
The `cubes` module provides a collection of functions and classes designed to perform various transformations and manipulations on data cubes and their associated headers. It is primarily intended for use in astronomical data analysis, particularly with spectroscopic data cubes.

This module includes utilities for handling FITS headers, coordinate transformations, and interactive plotting of data cubes. It leverages several scientific Python libraries such as NumPy, Astropy, and optionally APLpy for enhanced plotting capabilities.

Key Features
------------

- **Data Cube Transformations:** Functions to manipulate and transform data cubes and their FITS headers.
- **Interactive Plotting:** Classes and methods to create interactive plots of data cubes, allowing users to explore spectroscopic data visually.
- **Coordinate Handling:** Integration with Astropy WCS for accurate world coordinate system transformations.
- **Aperture Spectra Extraction:** Tools to extract and plot spectra from circular apertures within the data cube.
- **Flexible Plot Customization:** Support for various plotting conventions, color maps, and interactive features.

Dependencies
------------
- Python standard libraries: `copy`, `itertools`, `os`, `tempfile`, `warnings`
- Third-party libraries: `numpy`, `astropy` (including `astropy.io.fits`, `astropy.wcs`, `astropy.coordinates`, `astropy.log`)
- Optional: `aplpy` for advanced plotting features
- Optional: `AG_fft_tools` for smoothing functions

Classes
-------

MapPlotter
----------
A class designed for interactive plotting of data cubes. It allows users to visualize maps derived from spectroscopic cubes and interactively connect these maps to spectrum plotting.

**Initialization:**
```python
MapPlotter(Cube=None, figure=None, doplot=True, **kwargs)
```
- `Cube`: The data cube object to be plotted.
- `figure`: A matplotlib figure instance to plot on.
- `doplot`: Boolean flag to trigger plotting upon initialization.

**Key Methods:**

- `mapplot(convention='calabretta', colorbar=True, useaplpy=True, vmin=None, vmax=None, cmap=None, plotkwargs={}, **kwargs)`

  Plots a map based on the input data cube. The map is selected using the `makeplane` method, with options to customize the plotting convention, color scale, and color map.

- `circle(x1, y1, x2, y2, **kwargs)`

  Plots the spectrum of a circular aperture defined by two points `(x1, y1)` and `(x2, y2)`. This method calculates the radius and extracts the aperture spectrum from the cube.

- `copy(parent=None)`

  Creates a copy of the current map plotter instance with blank (uninitialized) axis and figure. Optionally associates the copy with a new parent spectroscopic axis instance.

- `refresh()`

  Refreshes the plot display if the axis is initialized.

Usage Notes
-----------
- The plotting functionality is interactive, allowing users to click on the map with mouse buttons to explore data.
- The module attempts to use APLpy for enhanced plotting if available; otherwise, it falls back to matplotlib.
- The `Cube` object is expected to have a FITS header and data compatible with the module's functions.
- The module includes error handling for missing dependencies and provides fallbacks where possible.
