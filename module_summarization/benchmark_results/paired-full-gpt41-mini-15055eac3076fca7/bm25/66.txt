Generate Tutorial About Pipelines
=================================

This tutorial provides an overview of how to create and use pipelines in machine learning workflows using the `Pipeline` and `FeatureUnion` classes. Pipelines help streamline the process of applying a sequence of data transformations followed by an estimator, enabling cleaner code and easier parameter tuning.

Pipeline Overview
-----------------

A pipeline chains multiple steps together, where each step is a tuple consisting of a name and a transformer or estimator object implementing `fit` and `transform` methods. The steps are executed sequentially, and the final step must be an estimator (i.e., it implements `fit` and `predict`).

Each step's name is separated by a double underscore `'__'` when setting or accessing parameters, allowing you to modify parameters of individual steps within the pipeline easily.

Example usage of a pipeline combined with grid search can be found in the example :ref:`sphx_glr_auto_examples_compose_plot_digits_pipe.py`, which demonstrates how to perform hyperparameter tuning on pipeline components using the `'__'` syntax.

FeatureUnion Overview
---------------------

`FeatureUnion` allows you to combine several transformer objects into a new transformer that concatenates their outputs. This is useful when you want to apply different feature extraction methods in parallel and combine their results.

Example:

```python
from sklearn.decomposition import PCA, TruncatedSVD
from sklearn.pipeline import FeatureUnion

union = FeatureUnion([
    ("pca", PCA(n_components=2)),
    ("svd", TruncatedSVD(n_components=2))
])

X = [[0., 1., 3], [2., 2., 5]]
X_transformed = union.fit_transform(X)
print(X_transformed)
```

Output:

```
array([[ 1.5      ,  3.0...,  0.8...],
       [-1.5      ,  5.7..., -0.4...]])
```

You can also set parameters of individual transformers within the union using the `'__'` syntax:

```python
union.set_params(pca__n_components=1).fit_transform(X)
```

This will adjust the number of components in the PCA transformer before fitting and transforming the data.

Caching and Performance
-----------------------

The `Pipeline` class supports caching of fitted transformers using the `memory` parameter, which can be a string path or an object implementing the `joblib.Memory` interface. This can speed up repeated fitting by reusing previously computed results. Note that the last step of the pipeline is never cached, even if it is a transformer.

Parallel Processing
-------------------

`FeatureUnion` supports parallel execution of transformers via the `n_jobs` parameter, which specifies the number of jobs to run in parallel. This can improve performance when combining multiple feature extraction methods.

Summary
-------

Pipelines and feature unions provide a powerful and flexible way to build complex machine learning workflows by chaining and combining transformers and estimators. They facilitate cleaner code, easier parameter tuning, and improved performance through caching and parallelism.
