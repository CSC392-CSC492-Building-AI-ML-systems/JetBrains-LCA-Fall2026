w_red Command
=============

Description
-----------

The `w_red` command applies the RED (Rate Estimation from Data) scheme to estimate steady-state Weighted Ensemble (WE) fluxes from shorter trajectories. This method provides an approach to analyze WE simulation data to obtain more accurate flux estimates without requiring very long simulations.

Source Data
-----------

The source data for `w_red` is provided as a `w_ipa` "scheme," which is typically defined in the `west.cfg` configuration file. For example, if a user wishes to estimate RED fluxes for a scheme named `"DEFAULT"`, that scheme name would be provided to `w_red`. The tool then estimates RED fluxes based on the data contained in the `assign.h5` and `direct.h5` files located in the `ANALYSIS/DEFAULT` directory.

Configuration Requirements
--------------------------

The `w_red` command requires specific parameters to be set in the `west.cfg` file under the `[west.analysis.red]` section:

- `scheme` : The name of the scheme to analyze (e.g., `"DEFAULT"`).
- `istate_label` : The label of the initial state.
- `fstate_label` : The label of the final state.
- `nstiter` : Number of steps per iteration.
- `nstrep` : Number of steps per report.

Additionally, the kinetics evolution mode must be set to `"cumulative"` under `[west.analysis.kinetics]` for the RED estimation to proceed. Other evolution modes are not supported by `w_red`.

Usage
-----

Run the `w_red` command in the environment where your WE simulation data and configuration files are accessible. The command will:

1. Read the RED parameters and scheme information from `west.cfg`.
2. Load the relevant `assign.h5` and `direct.h5` files from the `ANALYSIS/<scheme>` directory.
3. Estimate the RED fluxes using the specified initial and final states.
4. Output the RED flux evolution data.

Output
------

The RED flux estimates are saved back into the `direct.h5` file under the dataset `red_flux_evolution` within the corresponding analysis directory. If the dataset already exists, the user is prompted whether to overwrite it. Alternatively, the flux data can be saved as a NumPy `.npy` file named `red.npy` in the analysis directory.

Example
-------

Assuming your `west.cfg` contains the appropriate RED configuration:

```ini
[west]
  [analysis]
    [red]
      scheme = DEFAULT
      istate_label = stateA
      fstate_label = stateB
      nstiter = 1000
      nstrep = 100
  [kinetics]
    evolution = cumulative
```

You would run:

```bash
w_red
```

This will process the data in `ANALYSIS/DEFAULT/assign.h5` and `ANALYSIS/DEFAULT/direct.h5` and produce RED flux estimates for the transition from `stateA` to `stateB`.

Notes
-----

- The RED scheme implemented by `w_red` currently supports only cumulative averaging for kinetics evolution.
- Proper configuration in `west.cfg` is essential for successful execution.
- The tool provides progress updates during the rate calculation iterations.

For more detailed information on the RED method and its theoretical background, please refer to the relevant literature or the WESTPA documentation.
