w_stateprobs — Calculate State-to-State Kinetics by Tracing Trajectories
=========================================================================

Description
-----------

The `w_stateprobs` command calculates average populations and associated confidence intervals (CIs) for state populations from weighted ensemble data. It requires bin assignments, including macrostate definitions, to perform the analysis. For more information on bin assignments, see the documentation for `w_assign`.

This tool performs path-tracing kinetics analysis to provide insights into state-to-state kinetics by tracing trajectories through the defined states.

Output Format
-------------

The output is written to a file (specified with the `-o` or `--output` option, defaulting to `stateprobs.h5`) containing datasets with the following structure:

- `/avg`  
  Floating-point dataset representing the average rate within each window, in units of inverse tau.

- `/ci_lbound`  
  Floating-point dataset representing the lower bound of the confidence interval on the rate within each window, in units of inverse tau.

- `/ci_ubound`  
  Floating-point dataset representing the upper bound of the confidence interval on the rate within each window, in units of inverse tau.

- `/corr_len`  
  Integer dataset representing the correlation length of the rate within each window, in units of tau.

Each dataset is annotated with the following attributes:

- `mcbs_alpha`  
  Floating-point value indicating the alpha level of the confidence intervals (e.g., `0.05` corresponds to a 95% confidence interval).

- `mcbs_nsets`  
  Integer indicating the number of bootstrap data sets used to generate the confidence intervals.

- `mcbs_acalpha`  
  Floating-point value used for determining correlation lengths.

Additional Datasets
-------------------

- `_state_pops[state]`  
  Structured dataset representing the population of each state across the entire specified range.

- `/state_pop_evolution[window][state]` (available if `--evolution-mode` is specified)  
  Structured dataset representing state populations based on windows of iterations of varying width.

  - If `--evolution-mode=cumulative`, windows begin at the iteration specified by `--start-iter` and grow in length by `--step-iter` for each successive element.
  - If `--evolution-mode=blocked`, windows are of width `--step-iter` (except possibly the last), starting at `--start-iter`.

Structure of Structured Datasets
--------------------------------

Each structured dataset contains the following fields:

- `iter_start`  
  Integer indicating the iteration at which the averaging window begins (inclusive).

- `iter_stop`  
  Integer indicating the iteration at which the averaging window ends (exclusive).

- `expected`  
  Floating-point value representing the expected (mean) value of the rate evaluated within this window, in units of inverse tau.

- `ci_lbound`  
  Floating-point value representing the lower bound of the confidence interval within this window.

- `ci_ubound`  
  Floating-point value representing the upper bound of the confidence interval within this window.

Command-Line Options
--------------------

Run `w_stateprobs --help` to see all available command-line options. Common options include:

- `-o`, `--output`  
  Specify the output file name (default: `stateprobs.h5`).

- `--evolution-mode`  
  Specify the mode for state population evolution analysis (`cumulative` or `blocked`).

- `--start-iter`  
  Specify the starting iteration for analysis windows.

- `--step-iter`  
  Specify the step size for iteration windows.

Deprecation Notice
------------------

**Note:** The `w_stateprobs` command is deprecated. Users are encouraged to use the `w_direct` command instead for state-to-state kinetics analysis.

For backward compatibility, `w_stateprobs` currently acts as a shim that invokes the `trace` subcommand of `w_direct`.
