PyTables File Format
====================

Overview
--------

PyTables is a package for managing hierarchical datasets and designed to efficiently and easily cope with extremely large amounts of data. It is built on top of the HDF5 library and supports a rich set of features for data storage and retrieval.

Format Versions
---------------

The PyTables file format has evolved through several versions, each introducing new features and improvements:

- **1.0**  
  Initial format.

- **1.1**  
  Changes in ucl compression.

- **1.2**  
  Support for enlargeable arrays and variable-length arrays (VLAs).  
  Introduced in PyTables 0.8.

- **1.3**  
  Support for indexes in Tables.  
  Introduced in PyTables 0.9.

- **1.4**  
  Support for multidimensional attributes.  
  Introduced in PyTables 1.1.

- **1.5**  
  Support for persistent defaults in tables.  
  Introduced in PyTables 1.2.

- **1.6**  
  Support for NumPy objects and new flavors for objects.  
  Introduced in PyTables 1.3.

- **2.0**  
  Pickles are no longer used in system attributes.  
  Introduced in PyTables 2.0.

- **2.1**  
  Numeric and numarray flavors have been removed.

Compatibility
-------------

PyTables supports reading old format versions, but the list of compatible formats is empty, which means that all old formats are supported unless otherwise specified.

File Structure and Components
-----------------------------

PyTables files are based on the HDF5 format and contain a hierarchical structure of nodes. Key components include:

- **Arrays**  
  Arrays are multidimensional datasets stored in the file. They can be created with attributes such as titles.

- **Tables**  
  Tables are structured datasets with columns, supporting indexing for efficient queries.

- **Links**  
  PyTables supports soft links and external links to reference nodes within or outside the file.

- **Attributes**  
  Nodes can have attributes, including multidimensional attributes supported since format version 1.4.

Indexes
-------

Tables can have indexed columns to speed up data retrieval. Indexes created with PyTables 1.x format are not supported in PyTables 2.x series. Users are advised to recreate indexes using the `ptrepack` utility if needed.

Data Types and Descriptions
---------------------------

- **Description**  
  Each table has a `Description` instance that reflects its structure, including column names and data types.

- **Column Data Types**  
  PyTables maps column names to their corresponding PyTables data types.

Threading and Performance
-------------------------

PyTables can detect the number of CPU cores on the machine and set parameters such as the maximum number of threads for operations like compression and expression evaluation accordingly.

File Extensions and Customizations
----------------------------------

PyTables supports extensions such as LRU cache extensions and link extensions to enhance functionality.

Version Detection
-----------------

PyTables provides functions to detect whether a file is a PyTables file and to determine its format version. The version string returned is always "1.0" or greater for valid PyTables files, and zero or a negative value otherwise.

Warnings
--------

Users may encounter warnings related to old index formats when opening tables created with older PyTables versions. These warnings inform about unsupported index formats and suggest using utilities to update them.

Summary
-------

The PyTables file format is a robust and evolving format designed to handle large and complex datasets efficiently. Its hierarchical structure, support for indexing, multidimensional attributes, and compatibility with NumPy make it a powerful tool for scientific data management.
