# General Plotting Routines

This module provides a collection of general plotting routines designed to facilitate the creation of common plot types with consistent styling and behavior. The routines dispatch plotting commands to different backends, currently supporting:

- **matplotlib** (`'mpl'`, `'matplotlib'`)
- **bokeh** (`'bokeh'`)

The goal is to provide a unified interface for plotting functions, where the core data arguments remain consistent across backends, while allowing backend-specific keyword arguments as needed.

---

## Overview

The general plotting routines are built around a set of configurable parameters managed by `plot_params`, which control aspects such as figure size, axis labels, titles, error bars, and saving options. These parameters can be set globally or overridden per plot call.

The module ensures consistency in plotting styles and parameters through decorators such as `@ensure_plotter_consistency`, which synchronize the plotting parameters before executing the plotting function.

---

## Key Functions

### `single_scatterplot`

Creates a scatter plot from provided x and y data arrays.

**Signature:**

```python
single_scatterplot(xdata,
                   ydata,
                   *,
                   xlabel='',
                   ylabel='',
                   title='',
                   data=None,
                   saveas='scatterplot',
                   axis=None,
                   xerr=None,
                   yerr=None,
                   area_curve=0,
                   ...)
```

**Parameters:**

- `xdata`, `ydata`: Arrays or sequences of data points to plot.
- `xlabel`, `ylabel`: Labels for the x and y axes.
- `title`: Title of the plot.
- `data`: Optional additional data context.
- `saveas`: Filename or identifier to save the plot.
- `axis`: Optional axis object to plot on.
- `xerr`, `yerr`: Optional error bars for x and y data.
- `area_curve`: Optional parameter to control area under curve plotting.
- Additional keyword arguments may be passed for backend-specific customization.

**Description:**

This function generates a scatter plot with optional error bars and customizable labels and titles. It supports saving the plot to a file and plotting on existing axes if provided.

---

## Plot Parameter Management

Plotting parameters such as figure size, axis labels, and saving options are managed through a centralized `plot_params` object. This allows:

- Setting global defaults for all plots.
- Overriding parameters on a per-call basis.
- Automatic scaling of figure size based on plot layout.
- Passing additional keyword arguments to underlying plotting functions.

---

## Plot Layout and Subplots

The routines support creating complex plot layouts with multiple subplots arranged in grids. Key features include:

- Automatic calculation of figure size based on the number of rows and columns.
- Support for specifying subplot locations and individual subplot parameters.
- Passing axis-specific keyword arguments to customize each subplot.
- Handling lists of labels and titles to assign them to corresponding subplots.

---

## Additional Features

- **Residual Plotting:** Functions support plotting residuals (difference between real data and fit data) with optional histograms.
- **Error Handling:** Error bars can be added to scatter plots to represent uncertainties.
- **Saving and Displaying:** Plots can be saved automatically with specified filenames and optionally displayed.
- **Backend Flexibility:** The plotting backend can be switched globally, allowing the same plotting calls to render with different libraries.

---

## Usage Notes

- The plotting routines expect data arrays to be compatible with NumPy or similar array-like structures.
- Keyword arguments not explicitly handled by the general routines are passed down to the specific plotting backend functions.
- The module is designed to be extensible, allowing additional backends or plot types to be integrated with minimal changes.
