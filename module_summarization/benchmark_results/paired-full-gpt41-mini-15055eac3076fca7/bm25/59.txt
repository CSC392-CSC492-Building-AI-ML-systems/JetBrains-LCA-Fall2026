Regression Module
=================

This module provides tools for performing regression analysis, including estimation of regression models, computation of robust covariance estimators, and diagnostic statistics for model evaluation.

Key Features
------------

- Estimation of regression parameters using various methods, including least squares and QR factorization.
- Support for different covariance estimators to obtain robust standard errors, including heteroscedasticity-consistent and HAC (Heteroskedasticity and Autocorrelation Consistent) estimators.
- Computation of p-values using Student's t distribution when appropriate.
- Diagnostic statistics such as cumulative sum (CUSUM) and cumulative sum of squares of standardized recursive residuals for testing the stability of regression relationships over time.

Covariance Estimators
---------------------

The module supports multiple covariance estimators, which can be specified via the `cov_type` parameter. Available covariance estimators include:

- Non-robust (default)
- Heteroscedasticity robust
- HAC (Heteroskedasticity and Autocorrelation Consistent)

Additional keyword arguments (`cov_kwds`) can be passed to customize the behavior of these estimators, such as specifying the number of lags or weighting functions for HAC estimators.

CUSUM and CUSUM of Squares Statistics
-------------------------------------

The module provides functions to compute the CUSUM and CUSUM of squares statistics based on standardized recursive residuals. These statistics are useful for detecting structural changes or instability in regression relationships over time.

- **CUSUM Statistic**:  
  The cumulative sum of standardized recursive residuals, defined as:

  .. math::

      W_t = \frac{1}{\hat \sigma} \sum_{j=k+1}^t w_j

  where :math:`w_j` is the recursive residual at time :math:`j`, :math:`\hat \sigma` is the estimated standard deviation from the full sample, and :math:`k` is the number of exogenous regressors. The first `k` observations are excluded from the calculation.

- **CUSUM of Squares Statistic**:  
  The cumulative sum of squares of standardized recursive residuals, providing an alternative test for parameter stability.

Returns
-------

Functions in this module typically return instances of the `RegressionResults` class, which encapsulate estimated parameters, covariance matrices, and diagnostic statistics.
