Contingency Tables Module
=========================

This module provides methods for analyzing two-way contingency tables, which are frequency tables for observations cross-classified with respect to two categorical variables. It includes classes and functions for a variety of table types and statistical tests commonly used in categorical data analysis.

Overview
--------

The main classes implemented in this module are:

- **Table**  
  Implements methods applicable to any two-way contingency table.

- **SquareTable**  
  Implements methods specific to square two-way contingency tables.

- **Table2x2**  
  Implements methods specific to 2x2 contingency tables.

- **StratifiedTable**  
  Implements methods for analyzing a collection of 2x2 contingency tables, often arising from stratifying a single 2x2 table by another factor.

Additionally, the module contains functions for conducting McNemar's test and Cochran's Q test.

Note that the inference procedures implemented here generally assume that the observed units are independent and identically distributed, and the sampling model may affect the interpretation of results.

Classes
-------

### StratifiedTable

The `StratifiedTable` class provides analyses for a collection of 2x2 contingency tables. Such collections typically arise by stratifying a single 2x2 table with respect to another factor. This class implements the Cochran-Mantel-Haenszel and Breslow-Day procedures for analyzing collections of 2x2 contingency tables.

#### Parameters

- **tables** : list or ndarray  
  Either a list containing several 2x2 contingency tables, or a 2x2xk ndarray where each slice along the third axis is a 2x2 contingency table.

- **shift_zeros** : bool, optional  
  If True, adds 0.5 to zero cells in the tables to avoid issues with zero counts.

#### Notes

The results are based on a sampling model in which the units are independent both within and between strata.

#### Methods

- **test_null_odds(correction=False)**  
  Tests the null hypothesis that all tables have an odds ratio equal to 1, using the Mantel-Haenszel test.  
  Parameters:  
  - `correction` (bool): If True, applies a continuity correction to the test statistic.  
  Returns:  
  - A result object containing the chi-square test statistic and p-value.

Functions
---------

### _make_df_square(table)

Reindexes a pandas DataFrame so that it becomes square, meaning the row and column indices contain the same values in the same order. If the table is not square, the row and column indices are extended to achieve this.

Parameters:  
- **table** : pandas.DataFrame  
  The contingency table to be reindexed.

Returns:  
- A square pandas DataFrame with matching row and column indices.

Statistical Tests
-----------------

- **McNemar's Test**  
  Used for paired nominal data to test marginal homogeneity. The module includes implementations that handle 2x2 tables and extensions to larger tables via homogeneity tests.

- **Cochran's Q Test**  
  A non-parametric test to assess differences between three or more matched groups.

Usage Notes
-----------

- The inference procedures implemented in this module depend on the sampling design and assumptions about independence.

- For 2x2 tables with zero counts, continuity corrections or zero-cell adjustments may be applied to improve test validity.

- The module follows conventions and methodologies consistent with established statistical software such as SAS and R.
