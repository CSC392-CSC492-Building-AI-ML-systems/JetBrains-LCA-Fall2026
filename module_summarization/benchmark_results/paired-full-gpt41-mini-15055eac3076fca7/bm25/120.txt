Channel Options
===============

The Channel Options provide a way to configure interactive input bindings for Vega visualizations. These options allow you to specify how signals in the visualization are bound to HTML input elements such as radio buttons or select dropdowns.

BindRadioSelect
---------------

The `BindRadioSelect` class is a schema wrapper that defines the configuration for binding a signal to either a radio button group or a select dropdown.

### Parameters

- **input** (`enum('radio', 'select')`):  
  Specifies the type of input element to use for the binding. Must be either `"radio"` or `"select"`.

- **options** (`List[Any]`):  
  An array of options to select from. These represent the possible values that the input element can take.

- **debounce** (`float`, optional):  
  If defined, delays event handling until the specified number of milliseconds have elapsed since the last event was fired. This can be used to reduce the frequency of updates.

- **element** (`Element`, optional):  
  An optional CSS selector string indicating the parent element to which the input element should be added. By default, all input elements are added within the parent container of the Vega view.

- **labels** (`List[string]`, optional):  
  An array of label strings to represent the `options` values. If unspecified, the `options` values will be coerced to strings and used as labels.

- **name** (`string`, optional):  
  By default, the signal name is used to label input elements. This `name` property can be used instead to specify a custom label for the bound signal.

Usage
-----

These options are typically passed as part of the binding configuration when creating interactive visualizations with Vega. They allow fine control over how users can interact with signals through standard HTML form elements.

Example
-------

```json
{
  "input": "radio",
  "options": [1, 2, 3],
  "labels": ["One", "Two", "Three"],
  "name": "Select Number"
}
```

This configuration binds a signal to a group of radio buttons labeled "One", "Two", and "Three", corresponding to the values 1, 2, and 3 respectively.

Additional Parameters
---------------------

Additional parameters can be passed as keyword arguments to customize the behavior further. For example, the `debounce` parameter can be used to delay event handling, and the `element` parameter can specify where in the DOM the input elements should be inserted.

Summary
-------

Channel Options provide a flexible way to bind Vega signals to HTML input elements, enabling interactive visualizations with customizable controls such as radio buttons and select dropdowns. The `BindRadioSelect` schema defines the structure and parameters for these bindings.
