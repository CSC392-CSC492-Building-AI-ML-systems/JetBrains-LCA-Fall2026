w_bins — Display and Modify Binning in WEST Simulations
=========================================================

Synopsis
--------

```
w_bins <command> [options]
```

Description
-----------

The `w_bins` command provides tools to display information and statistics about binning in a WEST simulation, as well as to modify the binning for the current iteration of a WEST simulation.

Binning is a key component in WEST simulations, organizing the state space into discrete regions (bins) to facilitate weighted ensemble sampling. This command helps users inspect the current binning scheme and adjust it as needed to optimize simulation performance.

Commands
--------

The `w_bins` tool supports the following subcommands:

### info

Display information about the current binning scheme.

Options:

- `-n`, `--n-iter` *N_ITER*

  Consider initial points of segment *N_ITER* (default: current iteration).

  This option allows you to specify the iteration number for which binning information is displayed.

### rebin

Modify the binning for the current iteration.

Options:

- `--detail`

  Display detailed per-bin information in addition to summary information.

- `-n`, `--n-iter` *N_ITER*

  Consider initial points of segment *N_ITER* (default: current iteration).

Additional options related to binning configuration and target counts can be specified with this command (see below).

Binning Configuration Options
-----------------------------

The `w_bins` command supports various options to configure binning, including specifying bin boundaries and target counts. These options are provided via the binning component and include:

- Defining bin edges or boundaries.
- Setting target counts for bins.

(For a full list of binning options, refer to the WESTPA documentation on binning components.)

Usage Examples
--------------

Display summary information about the binning at the current iteration:

```
w_bins info
```

Display detailed bin information for iteration 10:

```
w_bins info -n 10 --detail
```

Modify the binning for the current iteration with detailed output:

```
w_bins rebin --detail
```

Modify the binning for iteration 5:

```
w_bins rebin -n 5
```

Logging
-------

The `w_bins` tool logs messages under the logger name `w_bins`, which can be configured to adjust verbosity or redirect output.

Notes
-----

- The command requires access to the WEST simulation data files.
- Modifications to binning affect the current iteration and can influence subsequent simulation behavior.
