Connect to Remote Data
======================

This section describes how to connect to and interact with remote data sources using file-like interfaces. The examples and tests demonstrate reading, seeking, and handling remote files over HTTP and other protocols, including support for compression and text encoding.

Opening Remote Files
--------------------

Remote files can be opened using URL paths, for example HTTP URLs. The `open_files` function is used to open one or more remote files, returning file-like objects that support standard file operations such as reading and seeking.

Example:

.. code-block:: python

    root = "http://localhost:8999/"
    fn = "example.txt"
    f = open_files(root + fn)[0]
    with f as file:
        data = file.read()

Reading Data with Seek and Read Operations
------------------------------------------

The file-like objects support reading with specified lengths and seeking to arbitrary positions within the file.

Example:

.. code-block:: python

    with f as file:
        data = file.read(2)
        assert file.loc == 2
        file.seek(0)
        data = file.read(3)
        file.seek(1, 1)  # Seek forward 1 byte from current position
        assert file.loc == 4

Reading with Headers
--------------------

When connecting to HTTP resources, it is possible to specify HTTP headers to be sent with the request. This can be useful for caching, authentication, or other purposes.

Example:

.. code-block:: python

    headers = {"Date": "Wed, 21 Oct 2015 07:28:00 GMT"}
    f = open_files(root + fn, headers=headers)[0]
    with f as file:
        data = file.read(length=1) + file.read(length=-1)

Compression Support
-------------------

Remote files that are compressed can be transparently handled by specifying the compression format. The system supports multiple compression formats and will decompress data on the fly.

Example:

.. code-block:: python

    from fsspec.compression import compr
    from dask.bytes.utils import compress

    data = b"1234" * 1000
    compressed = compress["gzip"](data)

    b = BytesIO(compressed)
    g = compr["gzip"](b, mode="rb")
    data2 = g.read()
    g.close()
    assert data == data2

Text Mode and Encoding
----------------------

Files can be opened in text mode with a specified encoding. This allows reading remote text files as strings rather than bytes.

Example:

.. code-block:: python

    myfiles = open_files(".test.accounts.*", mode="rt", encoding="utf-8")
    for file in myfiles:
        with file as f:
            text = f.read()

Block Reading and Delimiters
----------------------------

The file-like objects support reading blocks of data and seeking to delimiters, which is useful for processing large files in chunks or reading line-by-line.

Example:

.. code-block:: python

    delimiter = b"\n"
    data = delimiter.join([b"123", b"456", b"789"])
    f = io.BytesIO(data)
    block = read_block(f, delimiter=delimiter)

Integration with Local Filesystem
---------------------------------

The interface is compatible with local filesystems as well, allowing seamless switching between local and remote data sources.

Example:

.. code-block:: python

    from fsspec.implementations.local import LocalFileSystem

    fs = LocalFileSystem()
    with fs.open("localfile.txt", "r") as f:
        content = f.read()

Use Cases and Testing
---------------------

The functionality has been tested with various scenarios including:

- Reading remote files over HTTP.
- Handling HTTP headers.
- Reading compressed files.
- Reading files in text and binary modes.
- Seeking and reading with offsets.
- Integration with local filesystems.

These tests ensure robust and consistent behavior when connecting to remote data sources.

Summary
-------

This interface provides a flexible and powerful way to connect to remote data sources, supporting standard file operations, compression, text encoding, and HTTP headers. It enables seamless data access whether files are local or remote, compressed or uncompressed, binary or text.
