Learn Gaussian Mixture Models
=============================

Gaussian Mixture Models (GMMs) are probabilistic models that assume all the data points are generated from a mixture of a finite number of Gaussian distributions with unknown parameters. They are widely used for clustering, density estimation, and as a generative model for data.

Overview
--------

A Gaussian Mixture Model represents a distribution as a weighted sum of Gaussian component densities. Each component is characterized by its mean and covariance, and the model parameters are typically estimated using the Expectation-Maximization (EM) algorithm.

The `GaussianMixture` class provides an implementation of GMMs with various options for initialization, covariance types, and convergence criteria.

Key Features
------------

- **Flexible covariance types**: spherical, diagonal, tied, and full covariance matrices.
- **Initialization methods**: including k-means++, random, and user-specified initial means.
- **Convergence monitoring**: tracks the lower bound of the log-likelihood to detect convergence or divergence.
- **Multiple initializations**: supports multiple runs (`n_init`) to avoid poor local optima.
- **Parameter constraints**: enforces valid ranges for parameters such as number of components, tolerance, and regularization.

Usage Example
-------------

```python
import numpy as np
from sklearn.mixture import GaussianMixture

# Generate sample data
rng = np.random.RandomState(0)
X = rng.uniform(size=(30, 3))

# Initialize GaussianMixture with 3 components
gmm = GaussianMixture(n_components=3, random_state=rng, max_iter=100, n_init=10)

# Fit the model to data
gmm.fit(X)

# Access the estimated means
print(gmm.means_)

# Predict cluster labels
labels = gmm.predict(X)
```

Initialization Details
----------------------

Proper initialization of the GMM parameters is crucial for convergence and avoiding divergence. The `means_init` parameter allows specifying initial means manually. For example:

```python
means_init = np.array([
    [0.67, 0.21, 0.13],
    [0.09, 0.58, 0.93],
    [0.50, 0.96, 0.09],
    [0.19, 0.55, 0.89]
])
gmm = GaussianMixture(n_components=4, means_init=means_init, random_state=rng)
gmm.fit(X)
```

Tests and Validation
--------------------

Several tests ensure the robustness of the `GaussianMixture` implementation:

- **Best parameters and convergence**: Tests verify that `best_parameters_`, `n_iter_`, and `lower_bound_` are set correctly, especially in cases where the EM algorithm might diverge.
- **Precision matrix initialization**: Checks that manually providing the precision matrix (`precision_cholesky_`) leads to consistent results compared to estimating it during fitting.
- **Non-regression tests**: Address known issues such as those reported in GitHub issues [#1821](https://github.com/scikit-learn/scikit-learn/issues/1821) and [#16944](https://github.com/scikit-learn/scikit-learn/issues/16944).

Additional Notes
----------------

The `BaseMixture` abstract class defines the interface and common functionality for mixture models, including parameter validation and fitting procedures. It ensures that subclasses like `GaussianMixture` adhere to a consistent API and behavior.

Warnings such as `ConvergenceWarning` are issued if the EM algorithm fails to converge within the specified number of iterations, helping users diagnose potential issues with model fitting.

For advanced usage, parameters like `tol` (tolerance for convergence), `reg_covar` (regularization added to covariance matrices), and `verbose` (verbosity level) can be adjusted to fine-tune the fitting process.
