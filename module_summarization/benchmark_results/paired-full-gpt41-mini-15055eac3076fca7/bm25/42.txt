How to Generate Schema
======================

This module provides functionality to generate and apply SQL schemas for a given database client.

Functions
---------

get_schema_sql(client, safe)
    Generates the SQL schema for the specified database client.

    Parameters:
    
    - client (`BaseDBAsyncClient`): The database client for which to generate the schema SQL.
    - safe (`bool`): If set to `True`, the generated SQL will create tables only if they do not already exist.
    
    Returns:
    
    - `str`: The SQL schema as a string.

generate_schema_for_client(client, safe)
    Asynchronously generates and applies the SQL schema directly to the specified database client.

    Parameters:
    
    - client (`BaseDBAsyncClient`): The database client to which the schema will be applied.
    - safe (`bool`): If set to `True`, tables will be created only if they do not already exist.
    
    This function logs the generated schema at the debug level before applying it. If the generated schema is not empty, it will be executed against the database client.

Usage
-----

To generate the schema SQL without applying it, use `get_schema_sql()`:

.. code-block:: python

    schema_sql = get_schema_sql(client, safe=True)

To generate and apply the schema asynchronously, use `generate_schema_for_client()`:

.. code-block:: python

    await generate_schema_for_client(client, safe=True)

Notes
-----

- The `safe` parameter helps prevent errors by ensuring that tables are only created if they do not already exist.
- The functions expect a database client that implements the `BaseDBAsyncClient` interface and provides a `schema_generator` method.
- Logging is performed using the "tortoise" logger to aid in debugging schema generation steps.
