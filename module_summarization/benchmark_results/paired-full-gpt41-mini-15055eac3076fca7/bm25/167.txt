Library Conventions
===================

This document summarizes the conventions and design choices used throughout the Python Control Systems Library to ensure consistency, MATLAB compatibility, and ease of use.

General Conventions
-------------------

- The library provides a comprehensive set of functions and classes for analyzing and designing feedback control systems.
- Functions and classes are organized into modules such as `statesp`, `iosys`, `xferfcn`, `lti`, `namedio`, `frdata`, `dtime`, and others.
- MATLAB-like functions are imported and adapted to provide a familiar interface for users coming from MATLAB.
- Some functions are renamed to match MATLAB conventions (e.g., `pole` and `zero` are aliases for `poles` and `zeros` respectively).

Configuration and Defaults
--------------------------

The library supports multiple configuration presets to match the conventions of different control system toolkits:

1. **MATLAB Defaults**

   - Bode plots display gain in decibels (dB), phase in degrees, and frequency in radians per second.
   - Plots include grids by default.
   - State-space classes and functions use NumPy matrix objects for compatibility.
   - These defaults can be enabled by calling `use_matlab_defaults()`.

2. **Feedback Systems (FBS) Defaults**

   - Bode plots display gain in powers of ten (linear scale), phase in degrees, and frequency in radians per second.
   - Plots do not include grids by default.
   - Nyquist plots use dashed lines for the mirror image of the Nyquist curve.
   - These defaults can be enabled by calling `use_fbs_defaults()`.

Plotting Conventions
--------------------

- Frequency plots (Bode, Nyquist, Nichols) follow the configuration settings for units and grid display.
- Gain units can be set to decibels or linear scale depending on the configuration.
- Phase is typically displayed in degrees.
- Frequency is expressed in radians per second by default.

Naming and Functionality
------------------------

- The library uses function names consistent with MATLAB where possible to ease transition.
- Some functions are imported directly from other libraries or modules until native implementations are complete.
- Functions for creating linear models include:
  - `tf` for transfer function models.
  - `ss` for state-space models.
  - `frd` for frequency response data models.
- Other model types such as zero/pole/gain (`zpk`), descriptor state-space (`dss`), and delayed state-space models (`delayss`) are planned or partially supported.

Time Handling
-------------

- The library supports both continuous-time and discrete-time systems.
- Functions like `c2d` are provided for converting continuous-time models to discrete-time.
- Time base compatibility is maintained across operations involving multiple systems.

Error Handling
--------------

- Custom exceptions such as `ControlArgument` are defined to handle control-specific argument errors.

Summary of Feature Implementation Status
----------------------------------------

The library uses symbols to indicate the implementation status of features:

- `*` : Feature is currently implemented.
- `-` : Feature is not planned for implementation.
- `s` : Feature is temporarily provided by importing from another library (e.g., SciPy).

This helps users understand which features are fully supported and which are under development or deferred.

---

This overview reflects the current state and conventions of the Python Control Systems Library and aims to provide a consistent and familiar experience for users, especially those with MATLAB background.
