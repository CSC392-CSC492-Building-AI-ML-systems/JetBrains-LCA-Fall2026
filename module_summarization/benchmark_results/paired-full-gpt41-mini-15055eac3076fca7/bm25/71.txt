Kernel Ridge Regression
========================

.. currentmodule:: sklearn.kernel_ridge

The :mod:`sklearn.kernel_ridge` module implements **Kernel Ridge Regression (KRR)**, a regression technique that combines ridge regression (linear least squares with L2-norm regularization) with the kernel trick. This allows learning a linear function in the space induced by the kernel and the data, which corresponds to a non-linear function in the original input space when using non-linear kernels.

Overview
--------

Kernel ridge regression learns a model similar in form to Support Vector Regression (SVR), but differs in the loss function used: KRR uses squared error loss, whereas SVR uses epsilon-insensitive loss. Unlike SVR, KRR fitting can be done in closed-form, making it typically faster for medium-sized datasets. However, the resulting model is non-sparse and may be slower at prediction time compared to SVR, which produces sparse models.

This estimator supports multi-output regression, allowing the target variable `y` to be a 2D array of shape `(n_samples, n_targets)`.

Features
--------

- Supports various kernels, including linear, polynomial, RBF, sigmoid, and precomputed kernels.
- Regularization parameter `alpha` controls the strength of the L2 penalty.
- Handles multi-target regression.
- Provides attributes such as `n_features_in_` and `feature_names_in_` to track input features.
- Compatible with scikit-learn’s estimator API.

Parameters
----------

- **alpha** : float or array-like of shape (n_targets,), default=1.0  
  Regularization strength; must be a positive float. Larger values specify stronger regularization. If an array is passed, penalties are target-specific.

- **kernel** : string, callable, or None, default='linear'  
  Kernel mapping used internally. Possible values include kernels from `PAIRWISE_KERNEL_FUNCTIONS` or `"precomputed"` for a precomputed kernel matrix.

- **gamma** : float, default=None  
  Kernel coefficient for ‘rbf’, ‘poly’, and ‘sigmoid’. If None, defaults to `1 / n_features`.

- **degree** : int, default=3  
  Degree for the polynomial kernel. Ignored by other kernels.

- **coef0** : float, default=1  
  Independent term in polynomial and sigmoid kernels.

- **kernel_params** : dict, default=None  
  Additional parameters (keyword arguments) for kernel function.

Attributes
----------

- **dual_coef_** : ndarray of shape (n_samples,) or (n_samples, n_targets)  
  Dual coefficients of the kernel ridge model.

- **X_fit_** : ndarray of shape (n_samples, n_features)  
  Training data used in fitting.

- **n_features_in_** : int  
  Number of features seen during fit.

- **feature_names_in_** : ndarray of shape (n_features_in_,)  
  Names of features seen during fit, if available.

Methods
-------

- **fit(X, y)**  
  Fit the Kernel Ridge model according to the given training data.

- **predict(X)**  
  Predict using the kernel ridge model. If `kernel="precomputed"`, `X` should be a precomputed kernel matrix.

Example
-------

>>> from sklearn.kernel_ridge import KernelRidge
>>> import numpy as np
>>> n_samples, n_features = 10, 5
>>> rng = np.random.RandomState(0)
>>> y = rng.randn(n_samples)
>>> X = rng.randn(n_samples, n_features)
>>> krr = KernelRidge(alpha=1.0)
>>> krr.fit(X, y)
KernelRidge(alpha=1.0)
>>> y_pred = krr.predict(X)
