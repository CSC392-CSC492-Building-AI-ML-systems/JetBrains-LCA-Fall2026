Feature Extraction Module
=========================

The `feature_extraction` module provides utilities to extract features from various types of data, primarily focusing on text and images. It includes classes and functions to convert raw data into numerical feature representations suitable for machine learning models.

Text Feature Extraction
-----------------------

This submodule offers several vectorizers to transform text documents into numerical feature vectors:

- **CountVectorizer**  
  Converts a collection of text documents to a matrix of token counts. It tokenizes the text, builds a vocabulary of known words, and encodes new documents using that vocabulary.  
  Example usage:
  ```python
  from sklearn.feature_extraction.text import CountVectorizer

  corpus = [
      'This is the first document.',
      'This document is the second document.',
      'And this is the third one.',
      'Is this the first document?',
  ]
  vectorizer = CountVectorizer()
  X = vectorizer.fit_transform(corpus)
  print(vectorizer.get_feature_names_out())
  print(X.toarray())
  ```

- **TfidfVectorizer**  
  Converts a collection of raw documents to a matrix of TF-IDF features, which reflect the importance of words in documents relative to the entire corpus.  
  Example usage:
  ```python
  from sklearn.feature_extraction.text import TfidfVectorizer

  corpus = [
      'this is the first document',
      'this document is the second document',
      'and this is the third one',
      'is this the first document',
  ]
  vectorizer = TfidfVectorizer()
  X = vectorizer.fit_transform(corpus)
  ```

- **HashingVectorizer**  
  Converts a collection of text documents to a matrix of token occurrences using a hashing trick. This vectorizer is stateless and does not require fitting.  
  Example usage:
  ```python
  from sklearn.feature_extraction.text import HashingVectorizer

  corpus = [
      'This is the first document.',
      'This document is the second document.',
      'And this is the third one.',
      'Is this the first document?',
  ]
  vectorizer = HashingVectorizer(n_features=2**4)
  X = vectorizer.fit_transform(corpus)
  print(X.shape)
  ```

Common Attributes and Parameters
--------------------------------

- `dtype` : data type of the matrix returned by `fit_transform()` or `transform()`.
- `vocabulary_` : dictionary mapping terms to feature indices.
- `fixed_vocabulary_` : boolean indicating if a fixed vocabulary was provided.
- `stop_words_` : set of terms ignored due to frequency thresholds or feature selection.

Notes
-----

- The `stop_words_` attribute can become large and increase model size when pickling.
- The `HashingVectorizer` is stateless and does not require fitting, but parameter validation is recommended during `fit_transform`.
- Feature names are available only when the input `X` has feature names that are all strings.

See Also
--------

- `CountVectorizer` : Transform text into a sparse matrix of n-gram counts.
- `TfidfVectorizer` : Convert raw documents to a matrix of TF-IDF features.
- `HashingVectorizer` : Convert text documents to a matrix of token occurrences using hashing.
