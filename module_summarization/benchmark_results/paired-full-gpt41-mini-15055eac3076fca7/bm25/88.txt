===============================
Using SQLite and asyncio Effectively
===============================

Overview
--------

This module provides utilities and classes to facilitate effective use of SQLite databases in asynchronous Python applications. It includes custom type converters and adapters for SQLite, as well as an asynchronous batch processing class to handle database queries efficiently with asyncio.

SQLite Type Converters and Adapters
------------------------------------

SQLite supports a limited set of data types natively. To work seamlessly with Python's rich data types, this module registers custom converters and adapters with the `sqlite3` module.

### Registered Converters

- **Numeric**: Converts SQLite numeric types to Python `Decimal`.
- **Integer**: Converts SQLite integer types to Python `int`.
- **UUID**: Converts SQLite UUID strings to Python `uuid.UUID` objects.
- **Date**: Converts SQLite date strings to Python `datetime.date`.
- **Time**: Converts SQLite time strings to Python `datetime.time`.
- **Seconds**: Converts seconds stored as integers or floats.
- **Boolean**: Converts SQLite boolean representations to Python `bool`.
- **Timestamp**: Converts SQLite timestamp strings to Python `datetime.datetime`.
- **Timestamptz**: Converts timestamp with timezone strings.
- **Array**: Deserializes JSON strings stored in SQLite array columns back into Python lists.
- **M2M**: Converts many-to-many relationship strings (comma-separated values) into Python lists.

### Registered Adapters

- **Decimal**: Converts Python `Decimal` to a format suitable for SQLite.
- **uuid.UUID**: Converts Python UUID objects to strings for SQLite storage.
- **datetime.time**: Converts Python time objects to strings.
- **datetime.date**: Converts Python date objects to strings.
- **datetime.datetime**: Converts Python datetime objects to strings.
- **datetime.timedelta**: Converts Python timedelta objects.
- **list**: Serializes Python lists into JSON strings for SQLite array columns.

These converters and adapters ensure that complex Python data types can be stored and retrieved from SQLite databases transparently.

AsyncBatch Class
----------------

The `AsyncBatch` class extends batch processing capabilities to asynchronous contexts, allowing efficient handling of large query result sets without blocking the event loop.

### Key Features

- **Connection and Query Management**: Holds references to the database connection and the query to be executed.
- **Batch Size Control**: Allows specifying the number of rows to fetch per batch.
- **Asynchronous Iteration**: Implements asynchronous iteration protocols (`__aiter__` and `__anext__`) to enable easy iteration over query results in an async context.
- **Cursor Management**: Manages an internal cursor for fetching data asynchronously.
- **Result Processing**: Processes raw query results into Python dictionaries or other desired formats asynchronously.

Example usage:

```python
async for row in async_batch_instance:
    # process each row
```

SQLite Connection Management
----------------------------

The module provides a connection management class that supports:

- **Database Path Configuration**: Specify relative or absolute paths to SQLite database files. The database file will be created if it does not exist.
- **Logging**: Optional logging of SQL queries and their raw responses for debugging purposes.
- **Connection Parameters**: Pass additional parameters directly to the SQLite adapter, such as `timeout` to handle concurrent writes.
- **Context Variable for Transactions**: Uses Python's `contextvars` to manage the current transaction context, enabling safe concurrent access patterns.
- **Version Checking**: Methods to retrieve the SQLite library version, both synchronously and asynchronously.
- **Database File Management**: Utility methods to create or remove the SQLite database file, useful for testing scenarios.

Example initialization:

```python
connection = SQLiteConnection(
    path="my_database.sqlite",
    log_queries=True,
    timeout=30,
)
```

Additional Notes
----------------

- The module leverages Python's built-in `sqlite3` library and extends it with custom converters and adapters to handle complex data types.
- It is designed to work efficiently with asynchronous Python code using `asyncio`, preventing blocking operations during database access.
- The batch processing and connection management classes are designed to be flexible and extensible for various application needs.
