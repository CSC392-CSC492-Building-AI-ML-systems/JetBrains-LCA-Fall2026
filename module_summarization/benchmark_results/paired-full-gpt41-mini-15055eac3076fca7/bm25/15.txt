Ploterr Command
===============

Overview
--------
The `ploterrs` command is a versatile tool designed to plot error ranges for weighted ensemble datasets. It supports multiple input formats and subcommands, allowing users to visualize various types of data related to weighted ensemble simulations, such as state probabilities, kinetics, and generic expectation/confidence interval data.

Subcommands
-----------
The `ploterrs` command includes the following subcommands, each tailored to specific data types and formats:

- **DirectKinetics**  
  Plots kinetics data directly from weighted ensemble simulations.  
  - Input filename: `reweight.h5`  
  - Output files:  
    - Flux evolution plots: `flux_evolution_rw_{state_label}.pdf`  
    - Rate evolution plots: `rate_evolution_rw_{istate_label}_{fstate_label}.pdf`  

- **DirectStateprobs**  
  Plots state probabilities directly from weighted ensemble simulations.  
  - Input filename: `reweight.h5`  
  - Output files:  
    - Population evolution plots: `pop_evolution_rw_{state_label}.pdf`  
    - Color evolution plots: `color_evolution_rw_{state_label}.pdf`  

- **ReweightStateprobs**  
  Plots reweighted state probabilities.  
  - Input filename: `reweight.h5`  
  - Output files:  
    - Population evolution plots: `pop_evolution_rw_{state_label}.pdf`  
    - Color evolution plots: `color_evolution_rw_{state_label}.pdf`  

- **ReweightKinetics**  
  Plots kinetics data obtained from reweighting procedures.  
  - Input filename: `reweight.h5`  
  - Output files:  
    - Flux evolution plots: `flux_evolution_rw_{state_label}.pdf`  
    - Rate evolution plots: `rate_evolution_rw_{istate_label}_{fstate_label}.pdf`  

- **GenericIntervalSubcommand**  
  Plots generic expectation or confidence interval data from arbitrary HDF5 files and datasets.  
  This subcommand requires the user to specify the path to the HDF5 file and the dataset within it, formatted as:  
  ```
  FILENAME/PATH[SLICE]
  ```  
  If the dataset is not one-dimensional, a slice must be provided to select the appropriate data subset.  
  For example, to plot the rate evolution from state 0 to state 1 calculated by `w_kinavg`, one might specify:  
  ```
  kinavg.h5/rate_evolution[:,0,1]
  ```  
  The default output filename is `errbars.pdf`, but this can be changed via command-line options.

Common Features and Options
---------------------------
All subcommands inherit common plotting options and features, including:

- **Input/Output Options**  
  - `-o, --output`  
    Specify the output filename for the plot. The file format is inferred from the filename extension. Default is `errbars.pdf` for generic plots.

- **Plot Options**  
  - `--xscale` and `--yscale`  
    Choose the scale for the x and y axes respectively. Supported scales include `linear`, `log`, and `symlog`.  
  - `--xrange` and `--yrange`  
    Set the limits for the x and y axes.  
  - `--xlabel` and `--ylabel`  
    Set labels for the x and y axes.  
  - `--title`  
    Set the plot title.

- **Progress Indicator**  
  A progress indicator is displayed during plotting to provide feedback on the operation status.

Usage Example
-------------
To plot error bars for a generic dataset stored in an HDF5 file, use the following command syntax:

```
ploterrs generic kinavg.h5/rate_evolution[:,0,1] -o rate_0_to_1.pdf --xscale log --yscale linear --xlabel "Time (ns)" --ylabel "Rate (1/ns)" --title "Rate Evolution from State 0 to 1"
```

This command will generate a plot of the rate evolution from state 0 to state 1, using logarithmic scaling on the x-axis and linear scaling on the y-axis, saving the output to `rate_0_to_1.pdf`.

Summary
-------
The `ploterrs` command is a powerful and flexible plotting utility for weighted ensemble simulation data, supporting multiple data formats and customizable plotting options. It facilitates the visualization of error ranges and confidence intervals, aiding in the analysis and interpretation of simulation results.
