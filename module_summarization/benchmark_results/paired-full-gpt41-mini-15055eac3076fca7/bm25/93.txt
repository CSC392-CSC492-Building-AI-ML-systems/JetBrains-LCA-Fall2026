Generate Documentation for Indexing Module
===========================================

This module provides utilities for handling and manipulating NumPy structured dtypes, particularly focusing on combining and indexing nested field structures within arrays.

Functions
---------

_zip_descr(seqarrays, flatten=False)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Combine the dtype description of a sequence of arrays.

Parameters
----------
seqarrays : sequence of arrays
    Sequence of arrays whose dtype descriptions are to be combined.
flatten : bool, optional
    Whether to collapse nested dtype descriptions into a flattened form. Default is False.

Returns
-------
list
    A combined dtype description list representing the merged structure of the input arrays.

Notes
-----
This function internally calls `_zip_dtype` to perform the combination and returns the `.descr` attribute of the resulting dtype.

get_fieldstructure(adtype, lastname=None, parents=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Generate a dictionary mapping field names to lists of their parent fields, facilitating access to nested fields within structured dtypes.

Parameters
----------
adtype : np.dtype
    The input NumPy dtype to analyze.
lastname : str, optional
    The name of the last field processed (used internally for recursion).
parents : list, optional
    List of parent field names leading to the current field (used internally for recursion).

Returns
-------
dict
    A dictionary where keys are field names and values are lists of parent field names, representing the nesting hierarchy.

Purpose
-------
This function simplifies access to nested fields by providing a clear indexing structure that relates each field to its parent fields, enabling easier manipulation and retrieval of nested data.

Overview
--------

When working with structured arrays in NumPy, fields can be nested within other fields, creating complex dtype hierarchies. This module aids in managing such structures by:

- Combining multiple dtype descriptions into a unified dtype description.
- Flattening nested dtype descriptions when needed.
- Providing a mapping from fields to their parent fields to simplify nested field access.

These utilities are particularly useful when dealing with complex data structures requiring precise indexing and manipulation of nested fields.
