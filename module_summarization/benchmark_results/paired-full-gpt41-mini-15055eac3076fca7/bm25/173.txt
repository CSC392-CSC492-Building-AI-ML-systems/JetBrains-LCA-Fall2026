Fitting SESANS Data
===================

This section describes the approach and tools used for fitting Spin-Echo Small Angle Neutron Scattering (SESANS) data within the modeling framework.

Overview
--------

SESANS data fitting involves interpreting the SESANS-specific data structures, calculating theoretical predictions using appropriate models, and applying transformations such as the Hankel transform to relate the model outputs to the measured SESANS signals.

Key Components
--------------

- **Data Interpretation**  
  The data is first interpreted to determine its type. SESANS data is identified by the presence of an `isSesans` attribute set to `True`. This triggers the use of SESANS-specific processing routines.

- **SESANS Transform Initialization**  
  A Hankel transform matrix is pre-computed to convert the scattering intensity data into the SESANS correlation function. This involves:
  
  - Converting the SESANS length scale (`SElength`) from the data's units to Angstroms.
  - Calculating the maximum scattering vector `q_max` based on the neutron wavelength and sample acceptance angle.
  - Defining the acceptance range `zaccept` for the SESANS measurement.
  - Creating a `SesansTransform` object that encapsulates the Hankel transform using these parameters.

- **Model Evaluation**  
  The model evaluation proceeds by:
  
  - Calculating the scattering intensity \( I(q) \) using the kernel calculator for the SESANS data.
  - Applying the Hankel transform to the calculated intensity to obtain the SESANS correlation function.
  - Incorporating resolution effects and other experimental factors to predict the measured SESANS signal.

- **DataMixin Class**  
  The `DataMixin` class manages the common aspects of evaluating a Small Angle Scattering (SAS) model for a given dataset. It handles:
  
  - Determining the data type (e.g., SESANS, 1D, 2D).
  - Preparing the data vectors and resolution functions.
  - Calling the appropriate kernel calculators and transformations.
  
  For SESANS data, `DataMixin` ensures that the SESANS transform is applied after the kernel calculation.

- **DirectModel and Bumps Integration**  
  - `DirectModel` is a callable object that accepts model parameters as keyword arguments and returns theoretical predictions for the data.
  - `bumps_model.Experiment` wraps the model and data to interface with the Bumps fitting engine, allowing parameter bounds and fitting ranges to be specified.
  
  Currently, SESANS fitting is supported through these mechanisms, while integration with other modeling frameworks (e.g., SasView) may require further development.

Usage Notes
-----------

- The SESANS fitting workflow requires careful construction of the \( q \)-vector used in calculations. This vector extends beyond the measured data range to accommodate resolution effects.
- The Hankel transform is a critical step unique to SESANS data, converting the scattering intensity into the real-space correlation function measured by SESANS.
- Resolution functions and experimental parameters such as detector geometry and neutron wavelength are incorporated to accurately model the SESANS signal.
- Simulated SESANS datasets can be generated by calculating theoretical intensities and adding random noise, facilitating testing and validation of fitting procedures.

Plotting SESANS Data
--------------------

SESANS data can be visualized using specialized plotting functions that handle the unique data structure and apply appropriate scaling (logarithmic or linear). Intensity limits can be set manually or inferred from the data.

Summary
-------

Fitting SESANS data involves a combination of:

- Data interpretation specific to SESANS,
- Kernel-based model evaluation,
- Application of the Hankel transform,
- Incorporation of resolution and experimental parameters,
- Integration with fitting engines such as Bumps.

This approach enables robust modeling and fitting of SESANS measurements, providing insights into the nanoscale structure probed by SESANS experiments.
