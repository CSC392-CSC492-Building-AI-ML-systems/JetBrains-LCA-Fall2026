Quick Start
===========

This documentation provides a quick overview of how to use the PolynomialPath class to represent and evaluate polynomial paths.

PolynomialPath Overview
-----------------------

The `PolynomialPath` class represents a polynomial path defined by its coefficients over a parameter interval \([s_{\text{start}}, s_{\text{end}}]\).

- If `coeff` is a 1D array, the polynomial path is defined as:

  .. math::

     p(s) = \text{coeff}[0] + \text{coeff}[1] s + \text{coeff}[2] s^2 + \cdots

- If `coeff` is a 2D array, the polynomial path represents multiple joint positions, where the \(i\)-th joint position is:

  .. math::

     p_i(s) = \text{coeff}[i, 0] + \text{coeff}[i, 1] s + \text{coeff}[i, 2] s^2 + \cdots

Initialization
--------------

To create a polynomial path, initialize the `PolynomialPath` class with the polynomial coefficients and optionally specify the start and end of the path parameter interval:

```python
path = PolynomialPath(coeff, s_start=0.0, s_end=1.0)
```

- `coeff` : array_like  
  Coefficients of the polynomial(s). Can be a 1D array for a single polynomial or a 2D array for multiple polynomials (e.g., joint positions).
- `s_start` : float, optional  
  Starting path position (default is 0.0).
- `s_end` : float, optional  
  Ending path position (default is 1.0).

Properties
----------

- `dof` : int  
  Returns the degrees of freedom (number of polynomials or joints).
  
- `duration` : float  
  Returns the duration of the path, calculated as `s_end - s_start`.
  
- `path_interval` : numpy.ndarray  
  Returns the start and end points of the path interval as a NumPy array: `[s_start, s_end]`.

Evaluating the Path
-------------------

The polynomial path can be evaluated at given path positions using the `__call__` method or the `eval` methods.

```python
positions = path(path_positions, order=0)
```

- `path_positions` : array_like  
  The parameter values at which to evaluate the polynomial path.
  
- `order` : int, optional  
  The order of the derivative to evaluate:
  - `0` : position (default)
  - `1` : first derivative (velocity)
  - `2` : second derivative (acceleration)

Alternatively, you can use:

- `eval(path_positions)` to get the position.
- `evald(path_positions)` to get the first derivative.
- `evaldd(path_positions)` to get the second derivative.

Waypoints
---------

The `waypoints` property returns a tuple containing:

- The path parameter values at the waypoints.
- The corresponding positions at those waypoints.

Example
-------

```python
import numpy as np

# Define polynomial coefficients for a single joint: p(s) = 1 + 2s + 3s^2
coeff = [1, 2, 3]

# Create a PolynomialPath instance
path = PolynomialPath(coeff, s_start=0.0, s_end=2.0)

# Evaluate position at s = 1.5
pos = path(1.5, order=0)

# Evaluate velocity at s = 1.5
vel = path(1.5, order=1)

print("Position:", pos)
print("Velocity:", vel)
```

This will output the position and velocity of the polynomial path at the parameter value \( s = 1.5 \).

Deprecated Methods
------------------

Some older methods are marked as deprecated but still available for backward compatibility:

- `get_duration()` — returns the path duration.
- `get_path_interval()` — returns the path interval.
- `get_dof()` — returns the degrees of freedom.

It is recommended to use the corresponding properties (`duration`, `path_interval`, `dof`) instead.
