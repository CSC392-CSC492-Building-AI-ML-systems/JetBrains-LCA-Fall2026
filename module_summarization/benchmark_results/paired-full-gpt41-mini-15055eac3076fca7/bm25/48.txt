Discrete Models (:mod:`statsmodels.discrete.discretemod`)
============================================================

Overview
--------

This module provides implementations of zero-inflated count models, which are useful for modeling count data with an excess of zero counts. The zero-inflated models combine a count model with a binary model for the excess zeros, allowing for more flexible modeling of overdispersed count data.

Available Models
----------------

- **ZeroInflatedPoisson**  
  A zero-inflated Poisson model that accounts for excess zeros by mixing a Poisson count model with a binary inflation model.

- **ZeroInflatedGeneralizedPoisson**  
  A zero-inflated generalized Poisson model that extends the Poisson model to allow for overdispersion and zero inflation.

- **ZeroInflatedNegativeBinomialP**  
  A zero-inflated Negative Binomial model parameterized with the probability parameterization, suitable for overdispersed count data with excess zeros.

Description
~~~~~~~~~~~

Generiz Zero Inflated model for count data.

Parameters
~~~~~~~~~~

- **endog** : array_like  
  The endogenous response variable (count data).

- **exog** : array_like  
  The exogenous design matrix for the count model.

- **exog_infl** : array_like or None  
  Explanatory variables for the binary inflation model (mixing probability model). If None, a constant is used.

- **offset** : array_like  
  Offset added to the linear prediction with coefficient equal to 1.

- **exposure** : array_like  
  Log(exposure) is added to the linear prediction with coefficient equal to 1.

- **inflation** : string, 'logit' or 'probit'  
  The model for zero inflation, either Logit (default) or Probit.

Attributes
~~~~~~~~~~

- **endog** : array  
  A reference to the endogenous response variable.

- **exog** : array  
  A reference to the exogenous design matrix.

- **exog_infl** : array  
  A reference to the zero-inflated exogenous design matrix.

Details
~~~~~~~

The zero-inflated models combine a count data model (such as Poisson, Generalized Poisson, or Negative Binomial) with a binary model (Logit or Probit) that models the probability of excess zeros. This allows the model to account for two separate data generating processes: one generating structural zeros and another generating counts including zeros.

The inflation model uses either a logistic or probit link function to model the probability of zero inflation. The exogenous variables for the inflation model can be specified separately from those of the count model.

Notes
~~~~~

- The number of observations in `exog` and `exog_infl` must be the same.

- If `exog_infl` is not provided, a constant term is used by default.

- The module uses numerical differentiation tools for gradient and Hessian approximations where necessary.

- Warnings such as `ConvergenceWarning` may be raised during model fitting if convergence issues occur.

Examples
--------

Basic usage of a zero-inflated Poisson model:

.. code-block:: python

    import statsmodels.api as sm
    from statsmodels.discrete.discretemod import ZeroInflatedPoisson

    # endog: count data
    # exog: explanatory variables for count model
    # exog_infl: explanatory variables for inflation model (optional)

    zip_model = ZeroInflatedPoisson(endog, exog, exog_infl=exog_infl, inflation='logit')
    zip_results = zip_model.fit()
    print(zip_results.summary())

This module is part of the `statsmodels` library and extends the discrete modeling capabilities to handle zero-inflated count data effectively.
