Configurations Module
=====================

Overview
--------
The `Configurations` module provides classes and methods to export and import configuration options for designs within the application. These configurations can be applied to new or existing designs, facilitating the management and replication of design settings.

Classes
-------

Configurations
--------------
The `Configurations` class enables exporting and importing configuration options to be applied on designs.

### Initialization
```python
Configurations(app)
```
- `app`: The application instance to which the configurations apply.

### Attributes
- `options`: An instance of `ConfigurationsOptions` that defines the sections to be applied during import/export.
- `results`: An instance of `ImportResults` that stores the results of import operations.

### Methods

#### import_config(config_file, *args)
Imports configuration settings from a JSON file and applies them to the current design.

```python
import_config(config_file, *args)
```

- **Parameters**
  - `config_file` (`str`): Full path to the JSON configuration file.
  - `*args` (optional): Names of objects to ignore for monitor assignment.

- **Returns**
  - `dict, bool`: The configuration dictionary and a boolean indicating success.

- **Description**
  This method reads configuration settings from the specified JSON file and applies them to the current design. The sections to be applied are defined by the `options` attribute. The results of the import operation are saved in the `results` attribute.

#### global_import_success
A property that returns `True` if all imports were successful, otherwise `False`.

```python
@property
def global_import_success(self) -> bool
```

ConfigurationsIcepak
-------------------
A subclass of `Configurations` tailored for Icepak designs.

### Initialization
```python
ConfigurationsIcepak(app)
```
- `app`: The Icepak application instance.

### Attributes
- `options`: An instance of `ConfigurationsOptionsIcepak` specific to Icepak.

### Methods

#### _update_object_properties(name, val)
Updates properties of objects within the Icepak design.

```python
_update_object_properties(name, val)
```

- **Parameters**
  - `name` (`str`): The name of the object.
  - `val`: The value to update.

Additional Features
-------------------
- Object mapping utilities to map dictionary values to configuration keys.
- Support for importing and exporting native components.
- Monitor export and import control via properties `export_monitor` and `import_native_components`.

Usage Example
-------------
```python
config = Configurations(app)
config_dict, success = config.import_config("path/to/config.json")
if config.global_import_success:
    print("Configuration imported successfully.")
else:
    print("Some imports failed.")
```

Summary
-------
The `Configurations` module simplifies the management of design configurations by providing structured import and export capabilities. It supports error handling, selective import options, and integration with application-specific features such as monitors and native components. The Icepak-specific subclass extends these capabilities for thermal simulation designs.
