w_run Command
=============

Overview
--------
The `w_run` command is used to start or continue a WEST simulation. It manages the execution of the simulation by coordinating the propagation of segments, handling work management, and interfacing with various WESTPA components such as the simulation manager, system driver, data manager, and propagator.

Usage
-----
```
w_run [OPTIONS]
```

Options
-------
- `--oneseg`  
  Only propagate one segment. This option is primarily useful for debugging propagators by limiting the simulation to a single segment propagation.

- Additional options are available through WESTPA's runtime configuration and work manager environment, which can be viewed by running `w_run --help`.

Functionality
-------------
When executed, `w_run` performs the following steps:

1. **Argument Parsing and Configuration**  
   Parses command-line arguments, including WESTPA runtime configuration options and work manager-specific arguments. These configurations are processed to set up the simulation environment.

2. **Work Manager Initialization**  
   Creates and initializes a work manager instance responsible for distributing and managing computational tasks during the simulation.

3. **Component Setup**  
   Loads and configures key simulation components:
   - Simulation Manager: Controls the overall simulation workflow.
   - System Driver: Interfaces with the underlying system being simulated.
   - Data Manager: Manages simulation data and I/O.
   - WESTPA Driver: Handles WESTPA-specific simulation logic.
   - Propagator: Advances the simulation segments forward in time.

   These components are interconnected to ensure proper data flow and control during the simulation.

4. **Simulation Execution**  
   Within the context of the work manager:
   - If running as the master process:
     - Installs signal handlers to gracefully handle interrupts.
     - Loads any simulation plugins.
     - Prepares the simulation run.
     - Executes the simulation run.
     - Finalizes the simulation after completion.
     - Handles keyboard interrupts and exceptions, logging errors and shutting down cleanly.
   - If running as a worker process:
     - Executes assigned work units as directed by the work manager.

Logging and Error Handling
--------------------------
The command uses Python's logging module to provide debug-level information about the simulation progress, including preparation, execution, and finalization stages. It also captures and logs exceptions and keyboard interrupts to ensure that the simulation shuts down gracefully in case of errors or user interruption.

Summary
-------
`w_run` is the primary command-line interface for running WEST simulations. It integrates configuration, work management, and simulation components to provide a robust and flexible environment for conducting weighted ensemble simulations. The command supports debugging options and ensures proper handling of runtime events and errors.
