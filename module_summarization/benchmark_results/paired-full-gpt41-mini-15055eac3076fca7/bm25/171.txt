Calculator Interface
====================

Overview
--------

The Calculator Interface provides a unified way to create and manipulate scattering model calculators, primarily for use with SAS (Small-Angle Scattering) models. It supports various shapes such as sphere, cylinder, ellipsoid, triaxial ellipsoid, parallelepiped, and bcc paracrystal, among others. The interface facilitates model building, parameter setting, and visualization using ipyvolume for 3D plotting.

Creating a Calculator
---------------------

Use the function `select_calculator(model_name, n=150, size=(10, 40, 100))` to create a model calculator for a given shape.

- **Parameters:**
  - `model_name` (str): Name of the model shape. Supported shapes include `'sphere'`, `'cylinder'`, `'ellipsoid'`, `'triaxial_ellipsoid'`, `'parallelepiped'`, `'bcc_paracrystal'`, and others.
  - `n` (int, optional): Number of points to use in the q range. Default is 150.
  - `size` (tuple, optional): Tuple `(a, b, c)` representing minor and major equatorial axes and polar axis respectively. Default is `(10, 40, 100)`.

- **Returns:**
  - `calculator`: A calculator object built using the SAS model.
  - `size`: Tuple `(a, b, c)` representing the size parameters used.

The function internally loads the model information, builds the SAS model, and prepares the calculator with default parameters and data axes. It also computes limits for visualization based on the intensity pattern.

Calculator Object
-----------------

The calculator object returned is an instance of `DirectModel` from the `sasmodels` package. It contains:

- `pars`: A dictionary of model parameters which can be modified to change the model.
- `qxqy`: Tuple of arrays representing the qx and qy axes used for calculations.
- `limits`: Tuple `(vmin, vmax)` representing the intensity range for plotting.

Example usage:

```python
calculator, size = select_calculator('sphere', n=200, size=(20, 20, 20))
calculator.pars['radius'] = 25.0
```

Visualization Interface
-----------------------

The interface includes matplotlib-style methods adapted for use with `ipyvolume` for 3D visualization:

- `set_xlim(limits)`: Set the x-axis limits.
- `set_ylim(limits)`: Set the y-axis limits.
- `set_zlim(limits)`: Set the z-axis limits.
- `set_axes_on()`: Turn axes on.
- `set_axes_off()`: Turn axes off.

These methods provide a familiar interface for users accustomed to matplotlib, but operate on `ipyvolume` plots.

Internal Plotting Function
--------------------------

The internal function `_ipv_plot(calculator, draw_shape, size, view, jitter, dist, mesh, projection)` handles the rendering of the model using `ipyvolume`. It sets up the 3D axes, camera, and draws the shape with specified parameters such as view angle and jitter.

Parameter Definitions
---------------------

Some common parameters used in the models include:

- `sld[n_shells]` (1e-6/Å²): Scattering length density of the shell.
- `thickness[n_shells]` (Å): Thickness of the shell.
- `interface[n_shells]` (Å): Thickness of the interface.
- `shape[n_shells]` (str): Shape of the interface.
- `nu[n_shells]` (float): Interface shape exponent.
- `n_steps` (int): Number of steps in each interface (must be an odd integer).

Command Line Interface
----------------------

A command line interface is provided via the `main()` function to compute multiple scattering:

- Options include:
  - `-p`, `--probability`: Scattering probability (default 0.1).
  - `-n`, `--nq`: Number of mesh points (default 1024).
  - `-q`, `--qmax`: Maximum q value (default 0.5).
  - `-w`, `--window`: Window factor for q calculation (default 2.0).

This CLI allows users to run scattering calculations directly from the command line with configurable parameters.

Notes
-----

- The calculator interface relies on the `sasmodels` package for model building and evaluation.
- Visualization uses `ipyvolume` for interactive 3D plotting within Jupyter notebooks.
- The interface is designed to be extensible for additional shapes and models.
