Hyperexpand Module
==================

Overview
--------

The `hyperexpand` module provides functionality to expand and simplify hypergeometric functions and related special functions such as Meijer G-functions. It attempts to find closed-form or more explicit expressions for these functions, especially in terms of elementary functions or simpler special functions, when possible.

Key Features
------------

- Expansion of generalized hypergeometric functions (`hyper`) into simpler expressions.
- Handling of Meijer G-functions (`meijerg`) with expansions at zero or infinity.
- Preservation of non-hypergeometric parts of expressions and unrecognized hypergeometric expressions.
- Support for rewriting results into various forms.
- Use of symbolic manipulation to apply operators and substitutions during expansions.

Functions
---------

### hyperexpand(f, rewrite='default', allow_hyper=True, place=None)

Expands hypergeometric functions within the expression `f`.

- **Parameters:**
  - `f` : expression containing hypergeometric functions.
  - `rewrite` : specifies the rewriting strategy for the output (default is `'default'` which corresponds to `'nonrepsmall'`).
  - `allow_hyper` : if `True`, allows hypergeometric functions in the output when no simpler form is found.
  - `place` : can be set to `0` or `zoo` to indicate the preferred expansion point (zero or infinity) when both expansions exist.

- **Returns:**
  - An expression where hypergeometric functions are expanded or rewritten if possible; otherwise, they remain unchanged.

- **Examples:**

  ```python
  >>> hyperexpand(hyper([], [], z))
  E**z
  ```

  Non-hypergeometric parts and unrecognized hypergeometric expressions remain unchanged:

  ```python
  >>> hyperexpand(1 + hyper([1, 1, 1], [], z))
  hyper((1, 1, 1), (), z) + 1
  ```

### _hyperexpand(func, z, ops0=[], z0=Dummy('z0'), premult=1, prem=0, rewrite='default')

Internal function that attempts to find an explicit expression for a hypergeometric function `func`.

- **Parameters:**
  - `func` : a hypergeometric function object.
  - `z` : the variable or expression in which to expand.
  - `ops0` : list of operators to apply after expansion.
  - `z0` : dummy variable used internally for substitution.
  - `premult` : a multiplier of the form `a*z**prem` applied to the result.
  - `prem` : exponent of `z` in the multiplier.
  - `rewrite` : rewriting strategy for the output.

- **Returns:**
  - An expression representing the expanded hypergeometric function, possibly involving substitutions and operator applications.

### _meijergexpand(func, z, allow_hyper, rewrite='default', place=None)

Attempts to expand Meijer G-functions into simpler expressions or hypergeometric functions.

- **Parameters:**
  - `func` : a Meijer G-function object.
  - `z` : the variable or expression in which to expand.
  - `allow_hyper` : whether to allow hypergeometric functions in the output.
  - `rewrite` : rewriting strategy.
  - `place` : preferred expansion point (`0` or `zoo`).

- **Returns:**
  - An expanded expression or the original Meijer G-function if no expansion is found.

Implementation Details
----------------------

- The module uses symbolic manipulation techniques such as substitution, application of derivative operators, and simplification.
- It handles expansions around different points, including zero and infinity, controlled by the `place` parameter.
- The expansions rely on known identities and transformations of hypergeometric and Meijer G-functions.
- When expansions are not possible, the original functions are preserved to maintain correctness.
- The module carefully manages branch cuts and singularities using polar lifting and gamma function identities.

Usage Notes
-----------

- The expansions are heuristic and depend on the availability of known formulas and rewrite rules.
- The `rewrite` parameter allows customization of the output form, which can be useful for further symbolic manipulation.
- The module is designed to integrate with symbolic computation libraries and can be used to simplify expressions involving special functions in mathematical analysis, physics, and engineering.

Examples
--------

```python
from sympy import hyper, hyperexpand, symbols

z = symbols('z')
expr = hyper([], [], z)
expanded_expr = hyperexpand(expr)
print(expanded_expr)  # Outputs: E**z
```

```python
expr = 1 + hyper([1, 1, 1], [], z)
expanded_expr = hyperexpand(expr)
print(expanded_expr)  # Outputs: hyper((1, 1, 1), (), z) + 1
```
