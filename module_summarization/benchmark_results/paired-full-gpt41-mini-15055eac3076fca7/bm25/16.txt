Plothist Command
================

The `plothist` command is a versatile tool for plotting probability density functions (histograms) generated by `w_pdist` or other programs that produce compatible output formats. It supports multiple plotting modes to visualize histogram data in different ways, leveraging the full capabilities of matplotlib for graphical output.

Modes of Operation
------------------

The program operates in one of three modes:

- **instant**

  Plot 1-D and 2-D histograms for an individual iteration. This mode is useful for examining the distribution at a specific point in time. For more details, run:

  ```
  plothist instant --help
  ```

- **average**

  Plot 1-D and 2-D histograms averaged over several iterations. This mode provides a smoothed view of the distribution over a range of iterations. For more information, run:

  ```
  plothist average --help
  ```

- **evolution**

  Plot the time evolution of 1-D histograms as waterfall (heat map) plots. This mode visualizes how the distribution changes over time. For additional details, run:

  ```
  plothist evolution --help
  ```

Input Data
----------

`plothist` takes as input the output files generated by `w_pdist`. These files contain histogram data in a format that `plothist` can interpret and visualize. For more information on generating compatible input data, see the `w_pdist` documentation:

```
w_pdist --help
```

Plotting Features
-----------------

- Supports 1-D and 2-D histograms.
- Can plot raw histograms, logarithmic scales, or energy scales (negative logarithm of the probability).
- Provides options to customize plot ranges, labels, and titles.
- Generates plots using matplotlib, allowing output in any supported graphical format.
- Includes colorbars and axis labels for clarity.
- Supports post-processing functions for advanced customization.

Usage Summary
-------------

The general usage pattern is:

```
plothist <mode> [options]
```

where `<mode>` is one of `instant`, `average`, or `evolution`.

Each mode has its own set of command-line options to tailor the plots to your needs. Use the `--help` option with any mode to see detailed usage instructions.

Example
-------

To plot an instantaneous 1-D histogram for a specific iteration:

```
plothist instant --iteration 100 --input-file pdist_output.h5 --output-file hist_plot.png
```

To plot the average histogram over iterations 50 to 150:

```
plothist average --start 50 --end 150 --input-file pdist_output.h5 --output-file avg_hist_plot.png
```

To visualize the evolution of a histogram over time:

```
plothist evolution --input-file pdist_output.h5 --output-file evolution_plot.png
```

Dependencies
------------

- Python packages: `numpy`, `matplotlib`, `h5py`
- WESTPA framework components

Logging and Error Handling
--------------------------

`plothist` uses Python's logging module to report status and errors. It suppresses divide-by-zero warnings during logarithmic transformations to avoid cluttering output with non-critical warnings.

Summary
-------

`plothist` is a powerful and flexible command-line tool for visualizing histogram data from weighted ensemble simulations or similar sources. Its multiple modes and extensive customization options make it suitable for detailed analysis and presentation of probability distributions over time.
