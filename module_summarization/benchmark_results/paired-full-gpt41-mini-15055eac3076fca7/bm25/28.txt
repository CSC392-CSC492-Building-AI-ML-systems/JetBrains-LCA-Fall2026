w_multi_west Command
====================

Overview
--------
`w_multi_west` is a command-line tool designed to combine multiple WESTPA simulations into a single dataset while properly accounting for reweighting. This tool facilitates the aggregation and analysis of simulation data from multiple independent WESTPA runs, enabling comprehensive post-processing and comparison.

Key Features
------------
- Combines multiple WESTPA simulation outputs.
- Supports reweighting to ensure accurate statistical representation.
- Allows inclusion of additional auxiliary datasets.
- Provides progress indication during processing.
- Outputs combined data into a single HDF5 file for easy access and further analysis.

Usage
-----
The `w_multi_west` tool is invoked from the command line. It accepts several options to customize input and output behavior.

Command-line Options
--------------------

Input/Output Options:
- `-o`, `--output-file`  
  Specify the name of the output file where combined results will be stored.  
  Default: `multi.h5`

- `-W`, `--west`, `--WEST_H5FILE`  
  Specify the name of the main WESTPA HDF5 file inside each simulation directory.  
  Default: `west.h5`

- `-a`, `--aux`  
  Names of additional auxiliary datasets to be combined. This option can be specified multiple times to include multiple auxiliary datasets.

- `-aa`, `--auxall`  
  Combine all auxiliary datasets found in the simulations. By default, this is set to False.

Progress Reporting:
- The tool includes a progress indicator component that provides feedback on the current operation status.

Functionality Details
---------------------
- The tool reads multiple WESTPA simulation directories, each containing a `west.h5` file (or the specified WESTPA HDF5 file).
- It extracts iteration data, bin mappings, and other relevant simulation metadata.
- Reweighting is applied to ensure that combined data accurately reflects the statistical ensemble.
- Auxiliary datasets can be selectively included or all combined, depending on user options.
- The combined data is written to an output HDF5 file with appropriate metadata attributes, including iteration precision and file format versions.

Output
------
The output is a single HDF5 file (default `multi.h5`) containing:
- Combined simulation data from all specified WESTPA runs.
- Auxiliary datasets as requested.
- Metadata attributes such as:
  - `west_current_iteration`
  - `west_file_format_version`
  - `west_iter_prec`
  - `westpa_fileformat_version`

Example
-------
```bash
w_multi_west -o combined_simulations.h5 -W west.h5 -a aux_dataset1 -a aux_dataset2
```
This command combines multiple WESTPA simulations, including two auxiliary datasets, and writes the output to `combined_simulations.h5`.

Notes
-----
- The tool is implemented as a subclass of `WESTMultiTool` and uses internal WESTPA data structures and dtypes.
- It handles complex data types such as iteration blocks and initial state arrays.
- Proper error handling is included for missing or incompatible data.
- Designed for advanced users familiar with WESTPA simulation data and HDF5 file structures.

For more detailed information on usage and options, please refer to the tool's help message:
```bash
w_multi_west --help
```
