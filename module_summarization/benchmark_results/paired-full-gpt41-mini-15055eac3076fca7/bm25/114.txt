Generate Documentation for Simulation Code
===========================================

This module provides utility functions to analyze and visualize scan plans typically used in experimental control and data acquisition workflows. The functions operate on iterable plans that yield `Msg` objects representing commands to devices or motors.

Functions
---------

plot_raster_path(plan, x_motor, y_motor, ax=None, probe_size=None, lw=2)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Plot the raster path for a given scan plan.

Parameters
^^^^^^^^^^
- **plan** : iterable  
  An iterable yielding `Msg` objects (not a coroutine). The plan should include commands that move motors and save positions.

- **x_motor, y_motor** : str  
  Names of the motors controlling the X and Y axes.

- **ax** : matplotlib.axes.Axes, optional  
  The matplotlib axes to plot on. If `None`, a new figure and axes are created.

- **probe_size** : float, optional  
  If provided, used as the radius of a circular probe marker at each saved position, in the same units as motor positions.

- **lw** : float, optional  
  Line width for the path connecting points.

Returns
^^^^^^^
A dictionary with keys:
- `'path'`: The matplotlib Line2D object representing the path.
- `'events'`: The matplotlib collection or scatter plot of the points.

Description
^^^^^^^^^^^
This function iterates through the plan, extracting motor positions for the specified x and y motors whenever a 'set' command is issued, and records positions when a 'save' command is encountered. It then plots the path connecting these points and optionally overlays circular markers representing the probe size.

summarize_plan(plan)
~~~~~~~~~~~~~~~~~~~~

Print a minimal summary of the plan, showing only moves and event creation points.

Parameters
^^^^^^^^^^
- **plan** : iterable  
  An iterable yielding `Msg` objects.

Description
^^^^^^^^^^^
This function wraps the plan with `print_summary_wrapper` from `bluesky.preprocessors` and prints a concise summary of the plan's commands. It is useful for quickly understanding the sequence of operations in a plan.

Note
^^^^
`summarize_plan` is also aliased as `print_summary` for backward compatibility.

check_limits(plan)
~~~~~~~~~~~~~~~~~~

Check that a plan will not move devices outside their allowed limits.

Parameters
^^^^^^^^^^
- **plan** : iterable  
  An iterable yielding `Msg` objects.

Description
^^^^^^^^^^^
This function iterates through the plan and for each 'set' command, it checks if the target device has a `check_value` method. If so, it calls this method with the proposed value to verify it is within limits. If the device lacks this method, a warning is issued, and the device is ignored for subsequent checks.

Warnings
^^^^^^^^
Devices without a `check_value()` method cannot be validated for limit violations, and a warning will be emitted for each such device encountered.

---

This module is intended to assist in the visualization, summarization, and validation of experimental scan plans before execution, helping users to verify correctness and safety of device movements.
