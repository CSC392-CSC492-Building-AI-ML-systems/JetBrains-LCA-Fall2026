distutils module
================

Overview
--------

This module provides utilities and classes to facilitate building and installing Python packages using the distutils framework. It includes functionality for managing configuration, extensions, libraries, and retrieving system information relevant to the build process.

Key Components
--------------

- **Configuration**  
  A central class to manage package configuration. It supports adding subpackages, extensions, and libraries, as well as handling build options and paths. It also provides methods to retrieve the associated distutils distribution object.

- **get_info(\*names)**  
  Retrieves system information for the specified names by aggregating data from `system_info.get_info`. Returns a single dictionary containing combined information for all requested components.

- **get_cmd(cmdname)**  
  Returns the distutils command object corresponding to the given command name. It caches command objects for efficiency and raises an error if the distribution instance is not initialized.

- **Temporary Directory Management**  
  The module manages temporary directories created during the build process, ensuring that each thread has its own temporary directory and that all temporary directories are cleaned up upon program exit.

- **Utility Functions and Variables**  
  Includes various helper functions and constants such as `dict_append`, `appendpath`, `generate_config_py`, `get_numpy_include_dirs`, `get_mathlibs`, and terminal color utilities (`red_text`, `green_text`, etc.) to assist with configuration and build customization.

Functionality Highlights
------------------------

- **Adding Extensions and Libraries**  
  Extensions can be added to the build configuration with detailed build information, including source files, macros, libraries, and other compiler/linker options. Libraries can similarly be added with their respective sources and build parameters.

- **Configuration Options Management**  
  The configuration object supports setting and validating build options, delegating options to subpackages, and managing quiet mode for less verbose output.

- **Subpackage Handling**  
  Supports wildcard retrieval of subpackages by name, facilitating modular package structures.

- **Integration with NumPy Distutils**  
  Utilizes components from `numpy.distutils` such as `Extension` and `get_distribution` to enhance build capabilities, especially for packages that depend on NumPy.

Error Handling
--------------

- Raises `DistutilsInternalError` if the distutils distribution instance is not initialized when attempting to retrieve command objects.
- Raises `ValueError` when unknown configuration options are set.
- Raises `PkgNotFound` if a required package is not found during configuration.

Usage Notes
-----------

- This module is intended to be used as part of a package's setup process, typically invoked by setup scripts to configure and build extensions and libraries.
- Temporary directories created during the build are managed automatically and cleaned up on exit.
- The module supports multi-threaded builds by maintaining thread-local temporary directories.
