w_assign Command
================

Overview
--------

The `w_assign` command assigns walkers to bins, producing an assignment file (by default named `assign.h5`) which can be used in subsequent analysis steps within the WESTPA framework.

For consistency in downstream analyses, the entire dataset must be assigned, even if only a subset of the data will be used. This ensures that analyses relying on tracing trajectory history or kinetic states remain accurate and consistent.

The assignment process also supports defining kinetic macrostates, which label each trajectory according to the macrostate it was most recently in at each timepoint. This labeling is essential for kinetic analyses such as `w_kintrace` and `w_kinmat`.

Parallelization
---------------

`w_assign` supports parallelized binning, including parallel reading and calculation of input data, to improve performance on large datasets.

Command-line Options
--------------------

The command-line interface provides several options to control the assignment process:

- **Data selection and slicing**:  
  You can specify Python slice expressions (e.g., `[0:2]`) to select specific portions of multi-dimensional progress coordinate datasets. This is useful when working with multi-column progress coordinates.

- **Specifying macrostates**:  
  Macrostates can be defined in three ways:

  1. **Single-bin states via `--states` option**:  
     Specify multiple states on the command line, each as a coordinate tuple with an optional label. For example:  
     ```
     --states bound:1.0 unbound:(2.5,2.5)
     ```  
     Unlabeled states are automatically named `stateN`, where `N` is the zero-based index.

  2. **Multi-bin states via YAML file with `--states-from-file`**:  
     Provide a YAML file defining a list of states, each with a name and a list of coordinate tuples. Bins containing these coordinates are mapped to the corresponding macrostate. Example YAML content:  
     ```yaml
     ---
     - name: bound
       bins:
         - [1.0]
         - [1.1]
     - name: unbound
       bins:
         - [2.5, 2.5]
         - [2.6, 2.6]
     ```

  3. **Other options**:  
     Additional options allow control over subsampling, output file naming, and progress coordinate dataset selection.

Macrostates and Labeled Populations
-----------------------------------

When macrostates are defined, the tool labels each trajectory with the macrostate it was most recently in at each timepoint. This labeling enables kinetic analyses that depend on macrostate transitions.

The output includes a `labeled_populations` array with dimensions corresponding to iterations, states, and bins. Summations over this array provide:

- Overall per-bin populations:  
  ```python
  labeled_populations.sum(axis=1)[:, :-1]
  ```
- Overall per-trajectory-ensemble populations for all defined states:  
  ```python
  labeled_populations.sum(axis=2)[:, :-1]
  ```

These populations correspond to the defined macrostates and bins.

Usage Notes
-----------

- The assignment file generated by `w_assign` is essential for subsequent WESTPA analysis tools.
- Ensure that the entire dataset is assigned to maintain consistency.
- Parallel execution is enabled by default to optimize performance but can be configured as needed.

Example
-------

Assign walkers to bins using a progress coordinate dataset and define macrostates from a YAML file:

```bash
w_assign --pcoord-dataset pcoord --states-from-file macrostates.yaml --output assign.h5
```

This command will produce an assignment file `assign.h5` with walker-to-bin assignments and macrostate labels for use in further analysis.
