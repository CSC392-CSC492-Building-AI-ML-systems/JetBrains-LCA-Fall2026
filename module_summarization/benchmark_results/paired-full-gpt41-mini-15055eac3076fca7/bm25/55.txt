Miscellaneous Models
====================

Linear Model with Student-t Distributed Errors
----------------------------------------------

This module implements a linear regression model where the errors are assumed to follow a Student's t-distribution rather than a normal distribution. The Student's t-distribution has heavier tails compared to the normal distribution, making this model more robust to outliers and observations with heavier tails.

The main class provided is `TLinearModel`, which performs maximum likelihood estimation (MLE) of a linear model with t-distributed errors. This approach is useful when the data exhibit deviations from normality, particularly in the presence of outliers or heavy-tailed error distributions.

Key Features
~~~~~~~~~~~~

- **Robustness to Outliers:** The t-distribution's heavier tails allow the model to accommodate outliers more effectively than the standard linear regression model with normally distributed errors.
- **Flexible Degrees of Freedom:** The degrees of freedom parameter (`df`) of the t-distribution can be estimated from the data or fixed by the user, allowing control over the heaviness of the tails.
- **Generic MLE Framework:** The model is implemented using a generic likelihood framework, requiring only the specification of the negative log-likelihood function. Gradients and Hessians are computed numerically.
- **Starting Values:** Starting values for the optimization can be based on ordinary least squares (OLS) estimates, with optional adjustments based on kurtosis to inform the degrees of freedom parameter.
- **Parameter Restrictions:** The model supports fixing certain parameters, such as the degrees of freedom, during estimation.

Usage
~~~~~

The `TLinearModel` class inherits from `GenericLikelihoodModel` and requires the design matrix (`exog`) and response variable (`endog`) as inputs. The model can be initialized with or without fixing the degrees of freedom parameter.

Example:

```python
from statsmodels.miscmodels.tlinear import TLinearModel
import numpy as np

# exog: design matrix, endog: response variable
model = TLinearModel(endog, exog, fix_df=False)
result = model.fit()
print(result.summary())
```
