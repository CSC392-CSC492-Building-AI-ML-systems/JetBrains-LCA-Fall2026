Data Component in an Image HDU
==============================

The `data` attribute of an `ImageHDU` represents the image data contained within the HDU. This data is typically stored as a NumPy array and corresponds to the pixel values of the image.

Key Features
------------

- **Data Storage**: The image data is stored as an array, which can be accessed and manipulated directly through the `data` attribute.
- **Compression Handling**: When the HDU contains compressed image data, the `data` attribute is managed carefully to ensure proper reading and writing. Internally, a temporary backup of the uncompressed data is maintained to facilitate compression and decompression operations.
- **Data Scaling**: The class supports scaling of image data through header keywords, allowing for pseudo-integer scaling and checksum updates based on the data type.
- **Checksum and Data Integrity**: The image data is associated with checksum keywords (`CHECKSUM` and `DATASUM`) in the header to verify data integrity. These are automatically updated when the data changes.
- **Large Data Support**: For very large images (greater than 4 GB uncompressed), special handling is implemented to store compressed data efficiently using the appropriate FITS binary table formats.

Usage Notes
-----------

- When creating an `ImageHDU`, the `data` parameter can be provided as a NumPy array representing the image pixels.
- The `data` attribute can be accessed to read or modify the image pixel values.
- Modifications to the `data` attribute will trigger updates to the header keywords related to scaling and checksums to maintain consistency.
- For compressed images, the `data` attribute may temporarily hold the compressed data during write operations, but users typically interact with the uncompressed image data transparently.

Example
-------

```python
from astropy.io.fits import ImageHDU
import numpy as np

# Create an ImageHDU with a 100x100 array of zeros
image_data = np.zeros((100, 100), dtype=np.uint16)
hdu = ImageHDU(data=image_data)

# Access the image data
pixels = hdu.data

# Modify the image data
pixels[50, 50] = 1234

# The header will be updated automatically to reflect changes in data
print(hdu.header['CHECKSUM'])
```

This design ensures that the `ImageHDU` class provides a robust and flexible interface for working with image data in FITS files, handling both uncompressed and compressed images seamlessly while maintaining data integrity through header keyword management.
