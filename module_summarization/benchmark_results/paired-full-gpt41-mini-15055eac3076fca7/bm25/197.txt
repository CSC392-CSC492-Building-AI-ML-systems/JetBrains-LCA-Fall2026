Naive Bayes Methods
===================

Overview
--------

The `sklearn.naive_bayes` module implements Naive Bayes algorithms, which are supervised learning methods based on applying Bayes' theorem with strong (naive) feature independence assumptions. These algorithms are particularly suited for classification tasks where the dimensionality of the inputs is high.

Naive Bayes classifiers assume that the presence (or absence) of a particular feature of a class is unrelated to the presence (or absence) of any other feature, given the class variable. Despite this naive assumption, Naive Bayes classifiers have worked well in many complex real-world situations.

Available Naive Bayes Classifiers
---------------------------------

- **BernoulliNB**  
  Naive Bayes classifier for multivariate Bernoulli models. It is suitable for binary/boolean features.

- **CategoricalNB**  
  Naive Bayes classifier for categorical features. It models categorical data directly without requiring one-hot encoding.

- **ComplementNB**  
  Complement Naive Bayes classifier, designed to correct the "severe assumptions" made by the standard Multinomial Naive Bayes classifier, particularly useful for imbalanced datasets.

- **GaussianNB**  
  Gaussian Naive Bayes classifier, which assumes that the likelihood of the features is Gaussian (normal distribution). Suitable for continuous data.

- **MultinomialNB**  
  Naive Bayes classifier for multinomial models, typically used for discrete counts such as word counts in text classification.

Common Attributes
-----------------

- `feature_names_in_`  
  Names of features seen during `fit`. Defined only when the input `X` has feature names that are all strings.  
  *(Added in version 1.0)*

- `n_categories_` (CategoricalNB only)  
  Number of categories for each feature. This value is inferred from the data or set by the minimum number of categories.  
  *(Added in version 0.24)*

Usage Examples
--------------

**MultinomialNB Example**

```python
import numpy as np
from sklearn.naive_bayes import MultinomialNB

rng = np.random.RandomState(1)
X = rng.randint(5, size=(6, 100))
y = np.array([1, 2, 3, 4, 5, 6])

clf = MultinomialNB(force_alpha=True)
clf.fit(X, y)
print(clf.predict(X[2:3]))
```

**BernoulliNB Example**

```python
import numpy as np
from sklearn.naive_bayes import BernoulliNB

rng = np.random.RandomState(1)
X = rng.randint(5, size=(6, 100))
Y = np.array([1, 2, 3, 4, 4, 5])

clf = BernoulliNB(force_alpha=True)
clf.fit(X, Y)
print(clf.predict(X[2:3]))
```

**CategoricalNB Example**

```python
import numpy as np
from sklearn.naive_bayes import CategoricalNB

rng = np.random.RandomState(1)
X = rng.randint(5, size=(6, 100))
y = np.array([1, 2, 3, 4, 5, 6])

clf = CategoricalNB(force_alpha=True)
clf.fit(X, y)
print(clf.predict(X[2:3]))
```

Abstract Base Class
-------------------

The module also defines an abstract base class `_BaseNB` which serves as a foundation for all Naive Bayes estimators. It enforces the implementation of key methods such as:

- `_joint_log_likelihood(X)`  
  Computes the unnormalized posterior log probability of the input samples `X`. This corresponds to the log of the joint probability `log P(c) + log P(x|c)` for each class `c`.

- `_check_X(X)`  
  Performs input validation and preprocessing checks on `X`. This method is overridden in subclasses.

These base methods ensure consistency and reliability across different Naive Bayes implementations.

Summary
-------

Naive Bayes classifiers in `sklearn.naive_bayes` provide a variety of models tailored to different types of data and assumptions, from Bernoulli and multinomial models for discrete data to Gaussian models for continuous data. They are efficient, easy to implement, and often perform well on text classification and other high-dimensional problems.
