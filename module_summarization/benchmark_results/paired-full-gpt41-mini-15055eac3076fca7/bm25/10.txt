Using Metadata
==============

When executing queries using the API, it is possible to retrieve not only the records matching the query but also accompanying metadata that provides additional information about the result set.

Query Execution with Metadata
-----------------------------

The method `_query(expression)` executes a query and returns a tuple containing:

- **records**: A list of entities retrieved via the query.
- **metadata**: A dictionary containing supplementary information about the result set.

This metadata can include details such as pagination information, total counts, or other server-provided context that can be useful for handling query results more effectively.

Example Usage
-------------

```python
records, metadata = session._query('select id, name from Task where status is "in progress"')
print('Retrieved records:', records)
print('Metadata:', metadata)
```

In this example, `records` will contain the list of Task entities matching the query, while `metadata` will provide additional information about the query execution.

Benefits of Using Metadata
--------------------------

- **Pagination Support**: Metadata can include information about the total number of results and paging details, enabling efficient handling of large datasets.
- **Query Context**: Additional context about the query execution can be obtained, which may assist in debugging or optimizing queries.
- **Enhanced Client Logic**: Clients can make informed decisions based on metadata, such as whether to fetch more data or display summary information.

Summary
-------

Using metadata alongside query results enhances the ability to interact with the API in a more robust and informed manner. When performing queries, always consider capturing and utilizing the metadata returned to improve your application's data handling and user experience.
