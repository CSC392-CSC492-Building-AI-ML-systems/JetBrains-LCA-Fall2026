Stochastic Gradient Descent (SGD)
==================================

Overview
--------

Stochastic Gradient Descent (SGD) is an iterative optimization algorithm used to minimize an objective function that is typically a sum of differentiable functions. It is particularly well-suited for large-scale and online learning problems.

SGD updates the model parameters incrementally by estimating the gradient of the loss function using one sample (or a small batch of samples) at a time. This allows the model to be updated continuously as new data arrives, making it efficient for large datasets and streaming data.

Key Features
------------

- **Incremental Updates:** The gradient of the loss is estimated for each sample individually, and the model parameters are updated immediately.
- **Learning Rate Schedule:** The step size (learning rate) decreases over time according to a predefined schedule, ensuring convergence.
- **Regularization:** Supports L2 (squared Euclidean norm), L1 (absolute norm), or Elastic Net (a combination of L1 and L2) regularization to prevent overfitting and encourage sparsity.
- **Sparse Models:** When the parameter update crosses zero due to regularization, the update is truncated to zero, enabling online feature selection and sparse solutions.
- **Supports Dense and Sparse Data:** Works with dense numpy arrays and sparse matrices of floating point values.

Implementations
---------------

### SGDRegressor

`SGDRegressor` fits a linear model by minimizing a regularized empirical loss using SGD. It is designed for regression tasks and supports various loss functions and penalties.

**Parameters:**

- `loss` : string, default='squared_error'  
  The loss function to be minimized.

- Other parameters include learning rate, regularization strength, maximum iterations, and options for averaging and early stopping.

### SGDClassifier

`SGDClassifier` implements linear classifiers such as Support Vector Machines (SVM) and logistic regression trained with SGD.

**Features:**

- Supports various loss functions including hinge loss (SVM), log loss (logistic regression), and others.
- Allows minibatch and online learning via the `partial_fit` method.
- Works with dense or sparse input data.
- Regularization options similar to `SGDRegressor`.
- Requires data to be scaled (zero mean and unit variance) for best performance with default learning rate schedules.

### SGDOneClassSVM

`SGDOneClassSVM` solves the linear One-Class SVM problem using SGD. It is intended to be used with kernel approximation techniques (e.g., Nystroem) to approximate nonlinear kernels like the Gaussian kernel.

**Parameters:**

- `nu` : float, default=0.5  
  An upper bound on the fraction of training errors and a lower bound on the fraction of support vectors. Must be in (0, 1].

- `fit_intercept` : bool, default=True  
  Whether to estimate the intercept term.

- `max_iter` : int, default=1000  
  Maximum number of passes over the training data.

- `tol` : float or None, default=1e-3  
  Tolerance for stopping criteria.

Usage Notes
-----------

- For best results, input features should be standardized (zero mean and unit variance).
- The learning rate schedule and regularization parameters significantly affect convergence and model performance.
- SGD supports online learning scenarios where data arrives in streams or batches.
- Sparse solutions can be obtained by using L1 or Elastic Net penalties.
