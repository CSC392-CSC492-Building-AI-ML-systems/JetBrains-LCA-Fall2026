Diophantine Equation Solvers
============================

This module provides functions to solve various types of Diophantine equations, which are polynomial equations where integer solutions are sought.

Functions
---------

diop_linear(eq, param=t)
~~~~~~~~~~~~~~~~~~~~~~~~
Solves linear Diophantine equations of the form:

.. math::

    a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = 0

where :math:`a_i` are integer constants and :math:`x_i` are integer variables.

**Parameters**

- **eq** : Expr  
  A linear Diophantine equation assumed to be zero.

- **param** : Symbol, optional  
  The parameter to be used in the solution (default is an integer symbol `t`).

**Returns**

A tuple representing the parametric solution to the equation.

**Examples**

>>> diop_linear(2*x - 3*y - 5)  
(3*t_0 - 5, 2*t_0 - 5)

Here, :math:`x = 3 t_0 - 5` and :math:`y = 2 t_0 - 5`.

>>> diop_linear(2*x - 3*y - 4*z - 3)  
(t_0, 2*t_0 + 4*t_1 + 3, -t_0 - 3*t_1 - 3)

diophantine(eq, syms=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~
General solver for Diophantine equations. Classifies the equation type and dispatches to the appropriate solver.

**Parameters**

- **eq** : Expr or Eq  
  The Diophantine equation to solve.

- **syms** : list of Symbols, optional  
  Determines the order of the elements in the returned tuple.

**Returns**

A set of tuples representing the integer solutions.

**Examples**

>>> diophantine(x**2 - y**2)  
{(t_0, -t_0), (t_0, t_0)}

>>> diophantine(x*(2*x + 3*y - z))  
{(0, n1, n2), (t_0, t_1, 2*t_0 + 3*t_1)}

>>> diophantine(x**2 + 3*x*y + 4*x)  
{(0, n1), (3*t_0 - 4, -t_0)}

See Also
~~~~~~~~

- diofant.solvers.diophantine.diop_solve


diop_quadratic(eq, param=t)
~~~~~~~~~~~~~~~~~~~~~~~~~~~
Solves quadratic bivariate Diophantine equations of the form:

.. math::

    A x^2 + B x y + C y^2 + D x + E y + F = 0

where :math:`x` and :math:`y` are integer variables.

**Parameters**

- **eq** : Expr  
  A quadratic bivariate expression assumed to be zero.

- **param** : Symbol, optional  
  A parameter to be used in the solution (default is an integer symbol `t`).

**Returns**

A set of integer solutions or parametric solutions.

**Examples**

>>> diop_quadratic(x**2 + y**2 + 2*x + 2*y + 2, t)  
{(-1, -1)}

**References**

- Methods to solve :math:`Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0`,

- Solving the equation :math:`ax^2 + bxy + cy^2 + dx + ey + f = 0`,

Additional Information
----------------------

The module internally classifies Diophantine equations into known types such as linear, binary quadratic, ternary quadratic, and others. It uses helper functions to solve these equations by reducing multivariate problems into simpler bivariate or univariate forms when possible.

The solutions are typically expressed in parametric form using integer parameters (symbols) to represent infinite families of integer solutions.

See the source code for detailed algorithmic implementations and additional solver functions.
