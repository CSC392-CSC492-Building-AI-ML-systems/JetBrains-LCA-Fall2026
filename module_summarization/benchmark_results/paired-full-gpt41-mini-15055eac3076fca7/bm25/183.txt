Feature Selection and Dimensionality Reduction
==============================================

Feature selection and dimensionality reduction are essential techniques in machine learning and data analysis used to improve model performance, reduce overfitting, and enhance interpretability by selecting or transforming input features.

Overview
--------

Feature selection involves selecting a subset of relevant features from the original dataset, while dimensionality reduction transforms the data into a lower-dimensional space, often combining features to capture the most important information.

Scikit-learn provides a comprehensive suite of tools for both feature selection and dimensionality reduction, applicable to various types of data and learning tasks.

Feature Selection
-----------------

Feature selection methods in scikit-learn include univariate statistical tests, model-based selection, and recursive feature elimination.

### Univariate Feature Selection

These methods select features based on univariate statistical tests:

- `chi2`: Chi-squared test for non-negative features, commonly used for classification tasks.
- `f_classif`: ANOVA F-value between label/feature for classification tasks.
- `f_regression`: F-value between label/feature for regression tasks.
- `mutual_info_classif`: Mutual information for a discrete target in classification.
- `mutual_info_regression`: Mutual information for a continuous target in regression.
- `r_regression`: Correlation coefficient for regression tasks.

Example usage:

```python
from sklearn.feature_selection import SelectKBest, chi2
X = [[2, 1, 2], [9, 1, 1], [6, 1, 2], [0, 1, 2]]
y = [0, 1, 2, 2]
selector = SelectKBest(chi2, k=2)
X_new = selector.fit_transform(X, y)
```

### Model-Based Feature Selection

Select features based on importance weights from an estimator:

- `SelectFromModel`: Select features based on importance weights from models like logistic regression or random forests.
- `RFECV`: Recursive feature elimination with cross-validation to select the optimal number of features.
- `SequentialFeatureSelector`: Sequential feature selection using cross-validation without relying on importance weights.

These methods allow for more flexible and often more powerful feature selection strategies, especially when the underlying model can provide meaningful feature importance metrics.

Dimensionality Reduction
------------------------

Dimensionality reduction techniques transform the feature space into a lower-dimensional space, preserving as much information as possible.

### Linear Methods

- `PCA` (Principal Component Analysis): Projects data onto principal components that maximize variance.
- `KernelPCA`: Extends PCA using kernel methods to capture non-linear structures.

### Manifold Learning

- `Isomap`: Non-linear dimensionality reduction preserving geodesic distances.
- `LocallyLinearEmbedding`: Preserves local neighborhood information.
- `SpectralEmbedding`: Uses spectral graph theory for embedding.
- `MDS` (Multidimensional Scaling): Preserves pairwise distances.
- `TSNE` (T-distributed Stochastic Neighbor Embedding): Effective for visualization of high-dimensional data.

Example usage of Isomap:

```python
from sklearn.datasets import load_digits
from sklearn.manifold import Isomap

X, _ = load_digits(return_X_y=True)
isomap = Isomap(n_components=2)
X_transformed = isomap.fit_transform(X)
```

Additional Utilities
--------------------

- `sparse_encode`: Sparse coding for dictionary learning.
- `feature_extraction.grid_to_graph` and `img_to_graph`: Utilities to convert images or grids into graph structures for structured feature extraction.
- `extract_patches_2d` and `reconstruct_from_patches_2d`: Extract and reconstruct image patches useful for image feature extraction.

Notes
-----

- Many feature selection methods support sparse input matrices.
- Some feature selectors allow NaN or infinite values if the underlying estimator supports them.
- Feature names are preserved when input data contains feature names as strings (available from scikit-learn 1.0).

Examples
--------

### Feature Selection with Chi-Squared Test

```python
from sklearn.feature_selection import SelectKBest, chi2

X = [[2, 1, 2], [9, 1, 1], [6, 1, 2], [0, 1, 2]]
y = [0, 1, 2, 2]

selector = SelectKBest(chi2, k=2)
X_new = selector.fit_transform(X, y)
print(X_new)
```

### Dimensionality Reduction with Isomap

```python
from sklearn.datasets import load_digits
from sklearn.manifold import Isomap

X, _ = load_digits(return_X_y=True)
isomap = Isomap(n_components=2)
X_transformed = isomap.fit_transform(X)
print(X_transformed.shape)
```
