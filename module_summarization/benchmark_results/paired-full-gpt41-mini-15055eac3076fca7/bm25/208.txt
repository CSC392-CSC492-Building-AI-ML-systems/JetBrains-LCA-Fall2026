Utilities for Developers
========================

This module provides a collection of utility functions designed to assist developers in handling common tasks such as input validation, dependency checks, and sorting algorithms. These utilities facilitate robust and consistent behavior across various components by standardizing checks and operations.

Dependency Checks
-----------------

Several utilities ensure that optional dependencies are available before proceeding with computations that require them. These checks raise informative errors guiding users to install the necessary packages.

- **check_matplotlib_support(caller_name)**  
  Raises an `ImportError` with a detailed message if `matplotlib` is not installed.  
  This is useful for plotting utilities that lazily import `matplotlib` only when needed.  
  **Parameters:**  
  - `caller_name` (`str`): Name of the function or module requiring `matplotlib`.

- **check_pandas_support(caller_name)**  
  Raises an `ImportError` with a detailed message if `pandas` is not installed, and returns the imported `pandas` package if available.  
  Useful for functions like `fetch_openml` that require `pandas` for data handling.  
  **Parameters:**  
  - `caller_name` (`str`): Name of the function or module requiring `pandas`.  
  **Returns:**  
  - The imported `pandas` package.

Input Validation
----------------

- **check_X_y(X, y, accept_sparse=False, *, accept_large_sparse=True, dtype='numeric', order=None, copy=False, force_all_finite=True, ensure_2d=True, allow_nd=False, multi_output=False, ensure_min_samples=1, ensure_min_features=1, y_numeric=False, estimator=None)**  
  Validates input arrays `X` and `y` for consistency and correctness before fitting estimators.  
  This function checks that `X` and `y` have compatible lengths, enforces dimensionality constraints (`X` as 2D, `y` as 1D by default), and verifies that data contains only finite values unless otherwise specified. It also attempts to convert object dtype arrays to numeric types where applicable.  
  Supports sparse matrices and multi-output targets with configurable parameters.  
  **Parameters:**  
  - `X`: Input features array or matrix.  
  - `y`: Target array.  
  - `accept_sparse` (`bool`): Whether to accept sparse matrix inputs.  
  - `accept_large_sparse` (`bool`): Whether to accept large sparse matrices.  
  - `dtype` (`str` or list): Desired data type(s) for `X`.  
  - `order` (`str`): Memory layout order.  
  - `copy` (`bool`): Whether to copy the input data.  
  - `force_all_finite` (`bool` or 'allow-nan'): Whether to raise an error on infinite or NaN values.  
  - `ensure_2d` (`bool`): Whether to ensure `X` is 2D.  
  - `allow_nd` (`bool`): Whether to allow `X` with more than 2 dimensions.  
  - `multi_output` (`bool`): Whether to allow multi-output targets (`y` with 2D or sparse).  
  - `ensure_min_samples` (`int`): Minimum number of samples required.  
  - `ensure_min_features` (`int`): Minimum number of features required.  
  - `y_numeric` (`bool`): Whether to enforce numeric targets.  
  - `estimator`: The estimator instance calling this validation (optional).  

Sorting Utilities
-----------------

- **simultaneous_sort(values, indices, size)**  
  Implements an in-place sorting algorithm that sorts `values` and simultaneously applies the same swaps to `indices`. This is useful for maintaining correspondence between sorted values and their original indices.  
  The function uses a recursive partitioning approach similar to quicksort.  

Graph Utilities
---------------

Graph-related utilities operate primarily on adjacency matrices, preferably represented as sparse matrices, to efficiently handle graph algorithms and representations.

Extended Math Utilities
-----------------------

This collection includes mathematical helper functions and algorithms contributed by multiple authors, aimed at extending the core mathematical capabilities needed in various modules.

Additional Notes
----------------

- These utilities are designed to be used internally by developers to ensure consistency and reliability across the codebase.  
- Dependency checks are implemented to delay imports of optional packages until they are actually needed, improving startup time and reducing unnecessary dependencies.  
- Input validation functions provide detailed error messages to help users diagnose issues with their data inputs.  
- Sorting and graph utilities provide foundational algorithms optimized for the specific data structures used in the project.
