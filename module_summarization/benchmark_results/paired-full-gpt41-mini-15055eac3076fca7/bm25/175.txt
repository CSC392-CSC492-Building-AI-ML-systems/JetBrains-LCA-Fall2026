Biclustering
============

Spectral Biclustering
---------------------

Spectral biclustering is a clustering technique that simultaneously partitions the rows and columns of a data matrix, assuming that the data exhibits an underlying checkerboard structure. This method is particularly useful in scenarios where both rows and columns can be grouped into meaningful clusters, such as in gene expression data analysis.

For example, if there are two row clusters and three column clusters, each row will belong to three biclusters, and each column will belong to two biclusters. The checkerboard structure is represented by the outer product of the corresponding row and column label vectors.

This approach was introduced by Kluger et al. (2003) and is implemented in the `SpectralBiclustering` class.

Read more in the :ref:`User Guide <spectral_biclustering>`.

Parameters
----------

- **n_clusters** : int or tuple (n_row_clusters, n_column_clusters), default=3  
  The number of row and column clusters in the checkerboard structure.

- **method** : {'bistochastic', 'scale', 'log'}, default='bistochastic'  
  Method of normalizing and converting singular vectors into biclusters.  
  - `'log'` normalization is recommended by the authors but requires the data to be dense (not sparse).  
  - `'bistochastic'` is the default and works well with sparse data.  
  - `'scale'` is another available normalization method.  

  .. warning::  
     If `method='log'`, the input data must not be sparse.

Usage Example
-------------

```python
from sklearn.cluster import SpectralBiclustering
import numpy as np

X = np.array([[1, 1], [2, 1], [1, 0],
              [4, 7], [3, 5], [3, 6]])

clustering = SpectralBiclustering(n_clusters=2, random_state=0).fit(X)

print(clustering.row_labels_)
# Output: array([1, 1, 1, 0, 0, 0], dtype=int32)

print(clustering.column_labels_)
# Output: array([1, 0], dtype=int32)

print(clustering)
# Output: SpectralBiclustering(n_clusters=2, random_state=0)
```

Notes
-----

The algorithm works by normalizing the input data matrix and performing singular value decomposition (SVD) to extract singular vectors. These vectors are then clustered using k-means to identify biclusters. The resulting biclusters correspond to subsets of rows and columns that exhibit coherent patterns.

The `SpectralBiclustering` class supports both dense and sparse input data (in CSR format), with normalization methods adapted accordingly.

The checkerboard structure identified by spectral biclustering can be used to reveal hidden patterns in complex datasets, such as gene expression matrices, recommendation systems, and text mining applications.
