Cross Decomposition
===================

The `cross_decomposition` module in scikit-learn provides tools for Partial Least Squares (PLS) and Canonical Correlation Analysis (CCA), which are methods for modeling relationships between two datasets by decomposing their cross-covariance matrix.

Overview
--------

Cross decomposition methods find latent variables by decomposing the cross-covariance matrix between two datasets `X` and `Y`. These methods are useful when the predictors `X` and responses `Y` are both high-dimensional and possibly collinear.

The module includes the following main classes:

- **PLSCanonical**: Partial Least Squares Canonical mode, which finds components that maximize the correlation between linear combinations of `X` and `Y`.
- **PLSRegression**: Partial Least Squares regression, which models the relationship between `X` and `Y` by projecting both onto a lower-dimensional space.
- **PLSSVD**: Partial Least Squares using Singular Value Decomposition.
- **CCA**: Canonical Correlation Analysis, which finds linear combinations of `X` and `Y` that are maximally correlated.

These transformers and regressors are designed to handle multivariate data and are particularly useful when the number of features is large compared to the number of samples.

Key Attributes
--------------

- `x_weights_` : ndarray  
  The right singular vectors of the SVD of the cross-covariance matrix. Used to project `X` in the `transform` method.

- `n_features_in_` : int  
  Number of features seen during fitting.

- `feature_names_in_` : ndarray of shape (`n_features_in_`,)  
  Names of features seen during fitting. Defined only when `X` has feature names that are all strings.  
  .. versionadded:: 1.0

Parameters (common to PLS classes)
----------------------------------

- `n_components` : int, default=2  
  Number of components to keep. Should be in `[1, min(n_samples, n_features, n_targets)]`.

- `scale` : bool, default=True  
  Whether to scale `X` and `Y` to unit variance before fitting.

- `algorithm` : {'nipals', 'svd'}, default='nipals'  
  The algorithm used to estimate the first singular vectors of the cross-covariance matrix.  
  - `'nipals'` uses the power method (an iterative algorithm).  
  - `'svd'` computes the full Singular Value Decomposition.

- `max_iter` : int, default=500  
  Maximum number of iterations for the power method when `algorithm='nipals'`. Ignored otherwise.

- `tol` : float, default=1e-06  
  Tolerance for convergence in the power method. The algorithm stops when the squared norm of the difference between successive singular vectors is less than `tol`.

- `copy` : bool, default=True  
  Whether to copy `X` and `Y` before fitting.

Usage Example
-------------

```python
import numpy as np
from sklearn.cross_decomposition import PLSSVD

X = np.array([[0., 0., 1.],
              [1., 0., 0.],
              [2., 2., 2.],
              [2., 5., 4.]])
Y = np.array([[0.1, -0.2],
              [0.9, 1.1],
              [6.2, 5.9],
              [11.9, 12.3]])

pls = PLSSVD(n_components=2)
pls.fit(X, Y)

X_scores = pls.transform(X)
print(X_scores)
```
