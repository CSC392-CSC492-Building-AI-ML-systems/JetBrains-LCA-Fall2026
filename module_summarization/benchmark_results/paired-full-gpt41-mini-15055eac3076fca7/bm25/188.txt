Kernel Approximation Functions
==============================

This module provides functions that approximate the feature mappings corresponding to certain kernels. These approximations enable scalable kernel methods by transforming the input data into a feature space where linear methods can be applied efficiently.

Available Feature Map Approximations
------------------------------------

- **AdditiveChi2Sampler**  
  Approximate feature map for the additive chi-squared kernel. Useful for histogram-based features and non-linear classification tasks.

- **PolynomialCountSketch**  
  Polynomial kernel approximation via Tensor Sketch. This method efficiently approximates polynomial kernels by projecting data into a randomized feature space.

- **RBFSampler**  
  Approximate a Radial Basis Function (RBF) kernel feature map using random Fourier features. This technique enables scalable kernel learning by mapping data into a randomized low-dimensional feature space.

- **SkewedChi2Sampler**  
  Approximate feature map for the "skewed chi-squared" kernel. This kernel is a variant of the chi-squared kernel adapted for skewed data distributions.

Additional Resources
--------------------

- **sklearn.metrics.pairwise.kernel_metrics**  
  A list of built-in kernels available in scikit-learn for pairwise computations.

Examples
--------

Approximate an RBF kernel feature map and train a linear classifier:

```python
from sklearn.kernel_approximation import RBFSampler
from sklearn.linear_model import SGDClassifier

X = [[0, 0], [1, 1], [1, 0], [0, 1]]
y = [0, 0, 1, 1]

rbf_feature = RBFSampler(gamma=1, random_state=1)
X_features = rbf_feature.fit_transform(X)

clf = SGDClassifier(max_iter=5, tol=1e-3)
clf.fit(X_features, y)
print(clf.score(X_features, y))
```

Approximate the additive chi-squared kernel feature map:

```python
from sklearn.kernel_approximation import AdditiveChi2Sampler
from sklearn.linear_model import SGDClassifier

X = [[...]]  # your data here
chi2_sampler = AdditiveChi2Sampler()
X_features = chi2_sampler.fit_transform(X)

clf = SGDClassifier()
clf.fit(X_features, y)
```

Approximate the skewed chi-squared kernel feature map:

```python
from sklearn.kernel_approximation import SkewedChi2Sampler
from sklearn.linear_model import SGDClassifier

X = [[0, 0], [1, 1], [1, 0], [0, 1]]
y = [0, 0, 1, 1]

chi2_feature = SkewedChi2Sampler(skewedness=0.01, n_components=10, random_state=0)
X_features = chi2_feature.fit_transform(X, y)

clf = SGDClassifier(max_iter=1000)
clf.fit(X_features, y)
```

Approximate a polynomial kernel using Tensor Sketch:

```python
from sklearn.kernel_approximation import PolynomialCountSketch
from sklearn.linear_model import SGDClassifier

X = [[0, 0], [1, 1], [1, 0], [0, 1]]
y = [0, 0, 1, 1]

ps = PolynomialCountSketch(degree=3, random_state=1)
X_features = ps.fit_transform(X)

clf = SGDClassifier()
clf.fit(X_features, y)
```

Notes
-----

These kernel approximation methods are based on the concept of random feature mappings, which allow kernel methods to scale to large datasets by replacing the kernel function with explicit feature maps. For more details, see the work by Rahimi and Recht on Random Fourier Features and related literature.
