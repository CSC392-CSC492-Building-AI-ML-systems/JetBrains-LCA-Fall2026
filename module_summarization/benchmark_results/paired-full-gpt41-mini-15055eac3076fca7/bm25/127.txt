Convolution Module Built-in Kernels
===================================

The `astropy.convolution` module provides a variety of built-in kernels for use in convolution operations. These kernels represent common smoothing and filtering functions and can be used directly or combined to create custom kernels.

Available Kernels
-----------------

The following kernels are included as built-in classes in the module:

- **Gaussian1DKernel**  
  A one-dimensional Gaussian kernel characterized by its width (standard deviation). Useful for smoothing data with a Gaussian profile.

- **Gaussian2DKernel**  
  A two-dimensional Gaussian kernel, often used for image smoothing and blurring.

- **Box1DKernel**  
  A one-dimensional boxcar (rectangular) kernel. It averages values within a specified width.

- **Box2DKernel**  
  A two-dimensional boxcar kernel, useful for uniform smoothing over a square region.

- **Trapezoid1DKernel**  
  A one-dimensional trapezoidal kernel, which linearly ramps up and down, providing a smoother transition than a boxcar.

- **TrapezoidDisk2DKernel**  
  A two-dimensional kernel shaped like a trapezoidal disk.

- **RickerWavelet1DKernel**  
  A one-dimensional Ricker wavelet (Mexican hat) kernel, useful for edge detection and feature extraction.

- **Tophat2DKernel**  
  A two-dimensional tophat kernel, which is a circular uniform kernel.

- **AiryDisk2DKernel**  
  A two-dimensional Airy disk kernel, modeling the diffraction pattern of a circular aperture.

- **Ring2DKernel**  
  A two-dimensional ring-shaped kernel.

Kernel Parameters
-----------------

Most kernels are parameterized by their size or width, which controls the scale of the smoothing or filtering effect. For example, Gaussian kernels use the standard deviation (width) to define their spread.

Kernel Usage
------------

Kernels can be used with convolution functions such as `convolve` and `convolve_fft` to apply smoothing or filtering to one- or two-dimensional data arrays.

Example usage with a Gaussian kernel:

```python
from astropy.convolution import convolve, Gaussian2DKernel
import numpy as np

data = np.random.rand(100, 100)
gauss_kernel = Gaussian2DKernel(3)
smoothed_data = convolve(data, gauss_kernel)
```

Kernel Arithmetic
-----------------

Kernels support arithmetic operations such as addition and subtraction when combining kernels of the same dimensionality. Multiplication of kernels is defined as convolution of the kernel arrays.

The supported operations are:

- `'add'`: Add two kernels element-wise.
- `'sub'`: Subtract one kernel from another element-wise.
- `'mul'`: Multiply a kernel by a scalar or convolve two kernels.

Note that multiplication of two 1D kernels raises an exception if attempted directly as element-wise multiplication; instead, convolution should be used.

Testing and Validation
----------------------

The built-in kernels have been tested against equivalent functions in SciPy to ensure correctness. For example, the Gaussian kernels have been validated against `scipy.ndimage.gaussian_filter` for both 1D and 2D data.

Test data such as delta pulses and random arrays are used to verify kernel behavior under various conditions and kernel widths.

Kernel Shapes and Widths
------------------------

Kernels support both odd and even sizes, with predefined sets of widths and shapes used for testing and validation:

- Odd widths: 3, 5, 7, 9
- Even widths: 2, 4, 8, 16
- Shapes for 2D kernels include odd sizes like 15x15 and 31x31, and even sizes like 8x8, 16x16, and 32x32.

Boundary Conditions
-------------------

When convolving data with kernels, boundary conditions can be specified, such as `"fill"` to pad with zeros outside the data boundaries.

Summary
-------

The convolution module's built-in kernels provide a comprehensive set of tools for smoothing, filtering, and feature extraction in one- and two-dimensional data. Their integration with Astropy's convolution functions and compatibility with SciPy's filters make them robust and versatile for scientific data analysis.
