Probability Calibration
=======================

Probability calibration, also known as reliability diagram visualization, is a technique used to assess how well the predicted probabilities of a binary classifier reflect the true likelihood of an event. A well-calibrated model outputs probabilities that correspond closely to the actual frequencies of the positive class.

Overview
--------

Calibration curves plot the mean predicted probability in each bin against the true fraction of positives in that bin. This allows visualization of the relationship between predicted probabilities and observed outcomes, helping to identify whether a model is overconfident or underconfident in its predictions.

Key Concepts
------------

- **prob_true**: The proportion of samples whose class is the positive class (fraction of positives) in each bin.
- **prob_pred**: The mean predicted probability for the positive class in each bin.
- **y_prob**: Probability estimates for the positive class for each sample.
- **pos_label**: The positive class label used when computing the calibration curve. By default, the second class in `estimator.classes_` is considered positive.

CalibrationDisplay Class
------------------------

The `CalibrationDisplay` class provides visualization tools for calibration curves. It is recommended to create a `CalibrationDisplay` instance using one of the following class methods:

- `CalibrationDisplay.from_estimator`: Plots the calibration curve using an estimator and data.
- `CalibrationDisplay.from_predictions`: Plots the calibration curve using true labels and predicted probabilities.

All parameters used to create the display are stored as attributes, including:

- `line_`: The matplotlib Artist representing the calibration curve.
- `ax_`: The matplotlib Axes containing the calibration curve.
- `figure_`: The matplotlib Figure containing the plot.

Example Usage
-------------

```python
from sklearn.datasets import make_classification
from sklearn.calibration import CalibrationDisplay
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

X, y = make_classification(n_samples=1000, n_classes=2, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42)

clf = LogisticRegression()
clf.fit(X_train, y_train)
y_prob = clf.predict_proba(X_test)[:, 1]

disp = CalibrationDisplay.from_predictions(y_test, y_prob, n_bins=10, strategy='uniform')
disp.plot()
```

Calibration Methods
-------------------

- **Sigmoid Calibration (Platt Scaling)**: A parametric method that fits a logistic regression model to the classifier's scores to produce calibrated probabilities.
- **Isotonic Regression**: A non-parametric calibration method that fits a piecewise constant non-decreasing function to the predicted probabilities.

These methods help adjust the raw output scores of classifiers to better reflect true probabilities.

Additional Notes
----------------

- Calibration curves are particularly useful when the predicted probabilities are used for decision making or risk assessment.
- The calibration curve can be computed using the `calibration_curve` function, which returns the true fraction of positives and the mean predicted probabilities for each bin.
- When using cross-validation or ensemble methods, multiple calibrated classifiers and calibrators may be combined to improve calibration performance.
