Geometric Image Transformations
===============================

This module provides classes and functions for geometric image transformations, focusing on camera models and their associated operations. It enables the representation and manipulation of pinhole camera models, which are fundamental in computer vision and image processing tasks involving 3D to 2D projections.

Pinhole Camera Model
--------------------

The `PinholeCamera` class represents a pinhole camera model using intrinsic and extrinsic parameters. It supports batch processing to leverage PyTorch's parallelism for efficient computation.

### Initialization

A `PinholeCamera` instance is initialized with the following parameters:

- **intrinsics** (`torch.Tensor`): A tensor of shape `(B, 4, 4)` containing the full 4x4 camera calibration matrices for a batch of cameras.
- **extrinsics** (`torch.Tensor`): A tensor of shape `(B, 4, 4)` containing the full 4x4 rotation-translation matrices representing the camera poses.
- **height** (`torch.Tensor`): A tensor of shape `(B)` containing the image heights.
- **width** (`torch.Tensor`): A tensor of shape `(B)` containing the image widths.

The batch dimension `B` allows simultaneous processing of multiple cameras.

### Scaling the Camera Model

The `scale_` method scales the intrinsic parameters and image dimensions of the camera model in-place:

```python
scale_(scale_factor: torch.Tensor) -> PinholeCamera
```

- **scale_factor**: A tensor broadcastable with the camera parameters, typically of shape `(B)` or `(1)`.
- **Returns**: The scaled `PinholeCamera` instance.

This operation adjusts the focal lengths and principal points in the intrinsic matrix as well as the image height and width according to the provided scale factor.

### Creating a Camera from Parameters

The class method `from_parameters` allows creating a `PinholeCamera` instance from explicit camera parameters such as focal lengths, principal points, translation vectors, and image size. This facilitates easy construction of camera models for synthetic or real data.

Pinhole Cameras List
--------------------

The `PinholeCamerasList` class extends `PinholeCamera` to represent a list of pinhole cameras. It inherits all properties and methods but adds an extra dimension to handle multiple cameras collectively.

- The underlying tensors for intrinsics, extrinsics, height, and width are stacked along the batch dimension.
- This class is useful for scenarios where multiple camera views need to be processed simultaneously.

Notes
-----

- The classes assume batch-form attributes to exploit PyTorch's parallelism capabilities.
- The intrinsic matrix follows the standard pinhole camera calibration format.
- The extrinsic matrix encodes the rotation and translation from world coordinates to camera coordinates.
- Image height and width are stored as tensors to support batch operations and scaling.

These tools provide a flexible and efficient foundation for geometric transformations in image processing pipelines, enabling tasks such as image warping, 3D reconstruction, and multi-view geometry.
