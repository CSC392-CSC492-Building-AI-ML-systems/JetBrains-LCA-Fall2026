Conditions in PyTables
======================

PyTables supports querying tables using conditions, which are expressions that specify criteria for selecting rows. These conditions are passed as strings to methods such as `Table.where()` to filter data efficiently.

Basic Usage
-----------

A condition is a string expression that can reference columns of the table and variables defined in the query environment. For example:

.. code-block:: python

    for row in table.where('age > 30 & weight < 70'):
        print(row['name'], row['age'], row['weight'])

Empty Conditions
----------------

Using an empty condition string is not allowed and will raise a `SyntaxError`:

.. code-block:: python

    table.where('')  # Raises SyntaxError

Syntax Errors
-------------

Conditions must be valid Python expressions using supported operators and column names. Invalid syntax, such as malformed expressions, will raise a `SyntaxError`:

.. code-block:: python

    table.where('foo bar')  # Raises SyntaxError

Unsupported Objects
-------------------

Conditions must only use supported objects and operators. Using unsupported objects or data types in conditions will raise errors.

Condition Compilation and Caching
---------------------------------

When a condition is passed to a query method, PyTables compiles it into an internal representation called a `CompiledCondition`. This compilation process involves:

- Parsing the condition string.
- Extracting referenced column names and variables.
- Validating variable types.
- Optimizing the condition for efficient evaluation.

PyTables maintains a condition cache to avoid recompiling the same condition multiple times. When a condition is reused, the cached compiled condition is retrieved and reused, improving performance.

Index Usage in Conditions
-------------------------

PyTables can optimize queries by using indexes on columns referenced in conditions. During compilation, PyTables identifies indexable expressions and attempts to use indexes to speed up row selection.

If the condition can be satisfied using indexes, PyTables uses an indexed search method, which is much faster than scanning all rows.

Limitations and Notes
---------------------

- The condition syntax is a subset of Python expressions, supporting logical operators (`&`, `|`, `~`), comparison operators (`==`, `!=`, `<`, `>`, `<=`, `>=`), and arithmetic operators.
- Variables used in conditions must have supported data types.
- The condition string must be a valid expression; otherwise, a `SyntaxError` is raised.
- Indexes can only be used if the condition references indexed columns in a supported way.
- The condition compilation process may raise `TypeError` if variables have unsupported data types.

Example
-------

.. code-block:: python

    # Select rows where 'temperature' is above 20 and 'pressure' below 1000
    for row in table.where('temperature > 20 & pressure < 1000'):
        print(row['temperature'], row['pressure'])

Summary
-------

Conditions in PyTables provide a powerful and efficient way to filter table rows using expressive query strings. Proper syntax and supported data types are required to avoid errors, and indexes can be leveraged automatically to optimize queries.
