# FleurXMLModifier

The `FleurXMLModifier` class provides a structured and convenient way to group and organize modifications to a `inp.xml` file used by FLEUR. It leverages various XML setting methods from the modules `masci_tools.util.xml.xml_setters_names` and `masci_tools.util.xml.xml_setters_basic` to apply changes in a controlled manner.

## Overview

`FleurXMLModifier` does not modify the input XML file directly when changes are added. Instead, it collects all modification tasks and applies them in a single operation. This approach allows for easy management of multiple changes, including undoing or reverting modifications before they are applied.

## Basic Usage

```python
from masci_tools.io.fleurxmlmodifier import FleurXMLModifier

# Create an instance of the modifier
fmode = FleurXMLModifier()

# Add changes by calling methods on the modifier instance
# The method names correspond to the XML setter functions available in masci_tools

# Example: Set Kmax to 4.0
fmode.set_inpchanges({'Kmax': 4.0})

# Example: Add 5 to the current value of Gmax
fmode.shift_value({'Gmax': 5.0})

# Example: Set the local orbital configuration on all iron atoms to '3s 3p'
fmode.set_species('all-Fe', {'lo': [{'n': 3, 'l': 's', 'type': 'SCLO'},
                                    {'n': 3, 'l': 'p', 'type': 'SCLO'}]})

# Undo the last change
fmode.undo()

# Undo all changes added so far
fmode.undo(revert_all=True)

# Apply all collected changes to an input XML file
new_xml = fmode.modify_xmlfile(old_xml)
```

## Features

- **Task Collection:** Changes are stored as tasks internally and only applied when explicitly requested.
- **Undo Support:** Undo the last change or revert all changes before applying.
- **Flexible Initialization:** Create an instance from a list of tasks using the `fromList` class method.
- **Validation:** Optionally validate method signatures when adding tasks.
- **Access to Available Actions:** Retrieve the list of allowed modification functions.

## Initialization

```python
fmode = FleurXMLModifier(validate_signatures=True)
```

- `validate_signatures` (bool): If `True`, the class validates the signatures of the setter methods when tasks are added.

## Creating from a List of Tasks

You can instantiate a `FleurXMLModifier` directly from a list of tasks:

```python
task_list = [
    ('set_inpchanges', {'Kmax': 4.0}),
    ('shift_value', {'Gmax': 5.0}),
]

fmode = FleurXMLModifier.fromList(task_list)
```

Each task is a tuple where the first element is the name of the setter method and the second is a dictionary of keyword arguments for that method.

## Methods Summary

- `set_inpchanges(changes: dict)`: Set multiple input parameters at once.
- `shift_value(changes: dict)`: Shift numerical values by a specified amount.
- `set_species(species_label: str, changes: dict)`: Modify species-specific settings.
- `undo(revert_all: bool = False)`: Undo the last change or all changes if `revert_all` is `True`.
- `modify_xmlfile(xmlfile: XMLFileLike) -> etree.ElementTree`: Apply all collected changes to the given XML file.
- `get_avail_actions() -> dict[str, Callable]`: Get a dictionary of all allowed modification functions.

## Notes

- The docstrings for the setter methods are automatically generated from their implementations in the `masci_tools.util.xml` modules.
- This class serves as a low-level utility for modifying FLEUR input files and is conceptually similar to the `FleurinpModifier` in `aiida_fleur`.
- For detailed information on the available setter methods and their parameters, refer to the corresponding modules in `masci_tools.util.xml`.

## Example Workflow

1. Instantiate the modifier.
2. Add desired changes by calling setter methods.
3. Optionally undo changes if needed.
4. Apply all changes to an XML input file.

```python
fmode = FleurXMLModifier()
fmode.set_inpchanges({'Kmax': 4.0})
fmode.shift_value({'Gmax': 5.0})
fmode.set_species('all-Fe', {'lo': [{'n': 3, 'l': 's', 'type': 'SCLO'},
                                    {'n': 3, 'l': 'p', 'type': 'SCLO'}]})

# Apply changes to an existing XML file
new_xml = fmode.modify_xmlfile(old_xml)
```

This class simplifies the process of programmatically modifying FLEUR input XML files by collecting changes and applying them in a robust and manageable way.
