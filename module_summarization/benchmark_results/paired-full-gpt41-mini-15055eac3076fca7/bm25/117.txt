Resources
=========

Support for plugins that provide access to resources such as schemas.

Modules and Classes
-------------------

.. autoclass:: DirectoryResourceMapping
    :members:
    :undoc-members:
    :show-inheritance:

    A resource mapping that reads resource content from a directory or directory tree.

    See :class:`~asdf_standard.resource.DirectoryResourceMapping` for details.


.. autoclass:: ResourceMappingProxy
    :members:
    :undoc-members:

    Wrapper around a resource mapping that carries additional information on the package that provided the mapping.

    Methods
    -------

    .. method:: maybe_wrap(delegate)

        Wraps the given delegate resource mapping in a ResourceMappingProxy if it is not already one.

        :param delegate: The resource mapping to wrap.
        :returns: A ResourceMappingProxy instance wrapping the delegate.


    .. method:: __init__(delegate, package_name=None, package_version=None)

        Initialize the ResourceMappingProxy.

        :param delegate: The resource mapping to wrap. Must implement the Mapping interface.
        :param package_name: Optional name of the package providing the resource mapping.
        :param package_version: Optional version of the package providing the resource mapping.

        :raises TypeError: If the delegate does not implement the Mapping interface.

Imports

- Uses `pkgutil` for package utilities.
- Imports `Mapping` from `collections.abc` to define mapping interfaces.
- Imports `DirectoryResourceMapping` from `asdf_standard` as a base class.
- Imports `get_class_name` from a local utility module.

Summary
-------

This module provides support for resource mappings, particularly for accessing resources such as schemas through plugins. It includes a directory-based resource mapping class and a proxy wrapper class that adds metadata about the package providing the resource mapping.
