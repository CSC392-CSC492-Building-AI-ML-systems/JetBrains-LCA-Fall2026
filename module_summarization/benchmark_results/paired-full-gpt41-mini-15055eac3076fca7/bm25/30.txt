w_pdist — Calculate time-resolved, multi-dimensional probability distributions of WE datasets
===============================================================================================

Description
-----------

The `w_pdist` command calculates time-resolved, multi-dimensional probability distributions from Weighted Ensemble (WE) datasets.

Source data
-----------

Source data is provided either by a user-specified function (`--construct-dataset`) or a list of "data set specifications" (`--dsspecs`). If neither is provided, the progress coordinate dataset `pcoord` is used by default.

- **Custom function**: Specify a function in standard Python `MODULE.FUNCTION` syntax as the argument to `--construct-dataset`. This function will be called as `function(n_iter, iter_group)`, where `n_iter` is the iteration number and `iter_group` is the corresponding group in the main WEST HDF5 file (`west.h5`). The function must return data indexable as `[segment][timepoint][dimension]`.

- **Data set specifications**: Use `--dsspecs` followed by a list of desired datasets (space-separated). These specifications define the datasets from which the distributions will be calculated.

Bin boundaries
--------------

Bins for the histograms can be specified in one of three ways:

1. **Integer**: Number of bins per dimension (default is 100 bins in each dimension).
2. **List of integers**: Number of bins for each dimension.
3. **List of lists of boundaries**: Explicit bin boundaries for each dimension, e.g., `[[a1, a2, ...], [b1, b2, ...], ...]`.

The bin boundaries need not be uniformly spaced. These expressions are evaluated using Python's `eval` with `np` (NumPy) available, allowing specification of bins using functions like `np.arange()`.

Note: The first two forms trigger a scan of all data in each dimension to determine minimum and maximum values, which may be expensive for large datasets. Providing explicit bin boundaries avoids this scan.

These bins are **not** related to the bins used to drive WE sampling.

Output format
-------------

The output file (specified by `-o`/`--output`, defaulting to `pdist.h5`) contains the following datasets:

- **`histograms`**  
  Normalized histograms with the first axis corresponding to iteration number, and subsequent axes corresponding to the dimensions of the input dataset.

- **`/binbounds_0`, `/binbounds_1`, ...**  
  Vectors of bin boundaries for each dimension (index 0 for the first dimension, 1 for the second, etc.).

- **`/midpoints_0`, `/midpoints_1`, ...**  
  Vectors of bin midpoints for each dimension.

- **`n_iter`**  
  Vector of iteration numbers corresponding to the stored histograms (the first axis of the `histograms` dataset).

Subsequent processing
---------------------

The output file generated by this program (default `pdist.h5`) may be plotted using the `plothist` program. For more information, see `plothist --help`.

Parallelization
---------------

`w_pdist` supports parallelized binning, including parallel reading of input data. Parallel processing is enabled by default.

For simple cases (e.g., reading pre-computed input data or modest numbers of segments), serial processing can be enabled with the `--serial` option and may be more efficient.

Command-line options
--------------------

- `-o, --output OUTPUT`  
  Store results in `OUTPUT` (default: `pdist.h5`).

- `-C, --compress`  
  Compress histograms. This may make storage of higher-dimensional histograms more tractable at the possible expense of increased analysis time.

- `--construct-dataset FUNCTION`  
  Specify a custom Python function to extract or calculate data for probability distribution calculation.

- `--dsspecs DATASETS`  
  Specify one or more data set specifications to use as source data.

- `--bins BINS`  
  Specify bin boundaries or number of bins per dimension. Can be an integer, list of integers, or list of lists of bin boundaries.

- `--serial`  
  Disable parallel processing and run in serial mode.

See `w_pdist --help` for a full list of options and usage details.

---

This tool is part of the WESTPA suite and is designed to facilitate detailed analysis of WE simulation data by generating multi-dimensional, time-resolved probability distributions.
