w_states command
================

The `w_states` command is used to display or manipulate basis (initial) or target (recycling) states for a WEST simulation. It provides functionality to view, replace, or append states that define the progress coordinate space for the simulation.

Overview
--------

By default, `w_states` displays the current basis and target states or dumps them to files. The command supports modifying these states for the next iteration of the simulation by either replacing all states or appending new target states.

**Important:** Appending basis states is not permitted due to the complexity of renormalizing basis state probabilities. Instead, users should export the basis states to a file, edit the file manually, and then replace the basis states using the modified file.

Usage
-----

```
w_states [OPTIONS]
```

Options
-------

- `--bstate-file BSTATE_FILE`  
  Read (with `--append` or `--replace`) or write (with `--show`) basis state names, probabilities, and data references from/to the specified file.

- `--bstate LABEL,PROBABILITY[,AUXREF]`  
  Add a basis state specified as a string with the format `'label,probability[,auxref]'` to the list of basis states. Multiple `--bstate` options can be provided to append multiple states in the given order. Note that appending basis states is discouraged; prefer editing a basis state file and replacing.

- `--tstate-file TSTATE_FILE`  
  Read (with `--append` or `--replace`) or write (with `--show`) target state names and representative progress coordinates from/to the specified file.

- `--tstate LABEL,PCOORD0[,PCOORD1[,...]]`  
  Add a target state specified as a string with the format `'label,pcoord0[,pcoord1[,...]]'` to the list of target states. Multiple `--tstate` options can be provided to append multiple states in the given order.

- `--replace`  
  Replace all basis and/or target states with those specified by the provided files or command-line options for the next iteration.

- `--append`  
  Append the specified target states to the existing list of target states for the next iteration. Appending basis states is not supported.

Functionality Details
---------------------

- When displaying states (`--show` mode), the command outputs the current basis and target states, including their labels, probabilities, and progress coordinates.

- When replacing states (`--replace` mode), the command reads the specified basis and/or target states from files or command-line arguments and updates the simulation data accordingly for the next iteration.

- When appending target states (`--append` mode), the command adds the specified target states to the existing list without removing the current ones.

- Basis state probabilities are checked to ensure they sum to unity. If they do not, the probabilities are rescaled proportionally, and a warning is issued.

- Progress coordinates are assigned to basis states as part of the update process.

Examples
--------

1. Show current basis and target states:

   ```
   w_states --show
   ```

2. Replace basis states from a file:

   ```
   w_states --replace --bstate-file bstates.txt
   ```

3. Append new target states from the command line:

   ```
   w_states --append --tstate "state1,0.1,0.2" --tstate "state2,0.3,0.4"
   ```

4. Export basis states to a file for editing:

   ```
   w_states --show --bstate-file bstates.txt
   ```

   Then edit `bstates.txt` as needed and replace the basis states:

   ```
   w_states --replace --bstate-file bstates.txt
   ```

Notes
-----

- The command integrates with WESTPA's runtime configuration and work manager environment, allowing it to operate seamlessly within the WEST simulation framework.

- Target states represent recycling states defined by progress coordinates, while basis states represent initial states with associated probabilities.

- Care should be taken when modifying basis states to maintain proper normalization and consistency within the simulation.

Logging
-------

The command logs warnings if basis state probabilities do not sum to unity and are rescaled. Additional status messages are provided to inform the user about the presence or absence of target states.

---

For more detailed information on the format of basis and target state files, please refer to the WESTPA user guide or the relevant sections of the WESTPA documentation.
