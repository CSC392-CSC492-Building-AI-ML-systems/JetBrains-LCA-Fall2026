Compatibility Policy
====================

This document outlines the compatibility policy for the random number generation API.

Overview
--------

The random number generation API has undergone significant changes to improve functionality, performance, and usability. As a result, some functions from the legacy API have been removed or replaced in the new API. Users are encouraged to migrate to the new API to benefit from these improvements.

Legacy Functions Removed or Deprecated
--------------------------------------

The following functions from the legacy API have been removed or deprecated and are no longer guaranteed to be supported:

- `rand`  
  Generates uniformly distributed values.

- `randn`  
  Generates normally distributed values.

- `ranf`  
  Generates uniformly distributed floating point numbers.

- `random_integers`  
  Generates uniformly distributed integers in a given range.  
  **Deprecated:** Use `integers(..., closed=True)` instead.

- `random_sample`  
  Alias for `random_sample` (legacy naming).

- `randint`  
  Generates uniformly distributed integers in a given range.

- `seed`  
  Seeds the legacy random number generator.

Compatibility Considerations
----------------------------

- The new API introduces a `Generator` class that encapsulates BitGenerators and provides methods for generating random numbers from a wide variety of probability distributions.

- The legacy functions listed above are not guaranteed to be compatible with the new API and may be removed in future releases.

- Users should transition to using the `Generator` class and its methods for random number generation to ensure forward compatibility.

Distribution Functions
----------------------

The new API provides extensive support for univariate, multivariate, and standard distributions, including but not limited to:

- Univariate distributions such as Beta, Binomial, Chi-square, Exponential, Gamma, Normal, Poisson, Uniform, Weibull, and many others.

- Multivariate distributions such as Dirichlet, Multinomial, and Multivariate Normal.

- Standard distributions such as Standard Cauchy, Standard Exponential, Standard Gamma, Standard Normal, and Standard Student's t-distribution.

Internal Functions
------------------

The API also provides internal functions for managing the state of the random number generator:

- `get_state` — Retrieve the internal state of the generator.

- `set_state` — Set the internal state of the generator.

Recommendations
---------------

- Avoid using deprecated or removed legacy functions in new code.

- Use the `Generator` class and its associated methods for all random number generation needs.

- Refer to the official documentation for detailed usage examples and migration guides.

By adhering to this compatibility policy, users can ensure that their code remains functional and maintainable across future versions of the random number generation library.
