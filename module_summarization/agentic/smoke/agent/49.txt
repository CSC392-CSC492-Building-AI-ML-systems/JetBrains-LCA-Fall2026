Duration Module
===============

Overview
--------
This module provides classes and functions for survival analysis using proportional hazards regression models. It supports handling survival times with censoring, stratification, and left truncation, and includes tools for estimating survival functions, cumulative hazard functions, and related statistics.

Key Features
------------
- Representation of survival time data with censoring and stratification.
- Proportional hazards regression modeling.
- Prediction of survival-related quantities such as hazard ratios, survival functions, and cumulative hazard functions.
- Computation of residuals and weighted covariate averages.
- Estimation of baseline cumulative hazard functions.
- Generation of discrete survival distributions for uncensored durations.

Classes
-------

PHSurvivalTime
--------------
Represents a collection of survival times with possible stratification and left truncation.

**Constructor Parameters:**

- `time` : array_like  
  Times at which events (failures) occur or observations are censored.

- `status` : array_like  
  Indicator of event occurrence (1 if event occurred, 0 if censored).

- `exog` : array_like  
  Covariate data matrix (cases as rows, variables as columns).

- `strata` : array_like, optional  
  Grouping variable defining strata. Defaults to a single stratum if None.

- `entry` : array_like, optional  
  Entry (left truncation) times. Observations are not at risk before entry time. Defaults to zero if None.

- `offset` : array_like, optional  
  Optional offset values.

PHRegResults
------------
Encapsulates the results of fitting a proportional hazards regression model.

**Key Methods and Properties:**

- `predict(endog=None, exog=None, strata=None, offset=None, transform=True, pred_type="lhr")`  
  Returns predicted values from the proportional hazards regression model.  
  `pred_type` can be:
  - `'lhr'`: log hazard ratios (with standard errors)
  - `'hr'`: hazard ratios
  - `'surv'`: survival function
  - `'cumhaz'`: cumulative hazard function

- `get_distribution()`  
  Returns a list of `scipy.stats.distributions.rv_discrete` objects representing the estimated discrete survival distributions for uncensored durations within each stratum.

- `weighted_covariate_averages` (property)  
  Average covariate values within the at-risk set at each event time, weighted by hazard.

- `score_residuals` (property)  
  Matrix of score residuals.

- `baseline_cumulative_hazard` (property)  
  List of baseline cumulative hazard functions evaluated at event times for each stratum.

- `baseline_cumulative_hazard_function` (property)  
  List of function objects to compute cumulative hazard functions.

- `schoenfeld_residuals` (property)  
  Matrix of Schoenfeld residuals, with zeros for censored observations.

Usage Notes
-----------
- The module supports stratified survival analysis, allowing different baseline hazards per stratum.
- Left truncation is handled via entry times, excluding observations from risk sets before their entry.
- Prediction methods allow flexible specification of covariates, strata, and prediction types.
- Residuals and weighted averages facilitate model diagnostics and assessment of proportional hazards assumptions.

This module is designed for researchers and practitioners performing survival analysis and proportional hazards modeling, providing a comprehensive toolkit for estimation, prediction, and diagnostics.
