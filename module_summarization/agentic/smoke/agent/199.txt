Neural Network Models (Supervised)
==================================

The `sklearn.neural_network` module provides implementations of supervised neural network models for classification and regression tasks. The primary models included are:

- **MLPClassifier**: Multi-layer Perceptron classifier.
- **MLPRegressor**: Multi-layer Perceptron regressor.

These models are based on feedforward artificial neural networks trained with backpropagation.

Overview
--------

### Multi-layer Perceptron (MLP)

The Multi-layer Perceptron models are fully connected feedforward neural networks that can learn non-linear functions. They consist of one or more hidden layers with configurable sizes and activation functions.

- **MLPClassifier** is used for classification problems.
- **MLPRegressor** is used for regression problems.

Both models support various solvers for weight optimization, including stochastic gradient descent (SGD) and the limited-memory BFGS (LBFGS) algorithm.

Key Features
------------

- Support for multiple hidden layers with customizable sizes.
- Choice of activation functions: `identity`, `logistic` (sigmoid), `tanh`, and `relu`.
- Various optimization solvers: `lbfgs`, `sgd`, and `adam`.
- Early stopping to prevent overfitting.
- Support for mini-batch learning and partial fitting.
- Multi-output regression and multi-label classification support.
- Regularization via L2 penalty (alpha parameter).

Usage Examples
--------------

### Classification Example

```python
from sklearn.neural_network import MLPClassifier
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=1)

mlp = MLPClassifier(hidden_layer_sizes=(50,), max_iter=150, alpha=1e-5,
                    solver='lbfgs', random_state=0, activation='logistic',
                    learning_rate_init=0.2)
mlp.fit(X_train, y_train)
score = mlp.score(X_test, y_test)
print(f"Test set accuracy: {score:.2f}")
```

### Regression Example

```python
from sklearn.neural_network import MLPRegressor
from sklearn.datasets import make_regression
from sklearn.model_selection import train_test_split

X, y = make_regression(n_samples=200, n_targets=5, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=1)

mlp = MLPRegressor(hidden_layer_sizes=(50,), max_iter=200, solver='lbfgs',
                   random_state=1)
mlp.fit(X_train, y_train)
score = mlp.score(X_test, y_test)
print(f"Test set R^2 score: {score:.2f}")
```

Partial fitting is supported for both classifiers and regressors, allowing incremental training on batches of data:

```python
mlp = MLPClassifier(solver='sgd', max_iter=1, warm_start=True, random_state=1)
for _ in range(100):
    mlp.partial_fit(X_train, y_train, classes=np.unique(y_train))
```

Parameters
----------

- `hidden_layer_sizes` : tuple, length = n_layers - 2, default=(100,)
  
  The ith element represents the number of neurons in the ith hidden layer.

- `activation` : {'identity', 'logistic', 'tanh', 'relu'}, default='relu'
  
  Activation function for the hidden layer.

- `solver` : {'lbfgs', 'sgd', 'adam'}, default='adam'
  
  The solver for weight optimization.

- `alpha` : float, default=0.0001
  
  L2 penalty (regularization term) parameter.

- `batch_size` : int, default='auto'
  
  Size of minibatches for stochastic optimizers.

- `learning_rate_init` : float, default=0.001
  
  Initial learning rate used. It controls the step-size in updating the weights.

- `max_iter` : int, default=200
  
  Maximum number of iterations.

- `early_stopping` : bool, default=False
  
  Whether to use early stopping to terminate training when validation score is not improving.

Attributes
----------

- `coefs_` : list of weight matrices, length n_layers - 1
  
  The ith element represents the weight matrix corresponding to layer i.

- `intercepts_` : list of bias vectors, length n_layers - 1
  
  The ith element represents the bias vector corresponding to layer i.

- `n_iter_` : int
  
  The number of iterations the solver has run.

- `loss_` : float
  
  The current loss computed with the loss function.

Notes
-----

- The models are sensitive to feature scaling. It is recommended to scale input features using `StandardScaler` or similar preprocessing.
- The `partial_fit` method allows incremental learning but requires specifying all possible classes for classification.
- Early stopping splits the training data into training and validation sets internally.
