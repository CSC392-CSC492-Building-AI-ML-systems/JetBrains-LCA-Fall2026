Sync Users with LDAP
====================

This module provides functionality to synchronize users with an LDAP directory using a delayed job on the server.

Delayed Job for Syncing LDAP Users
----------------------------------

The synchronization process is executed as a delayed job on the server. This job is represented by a `ftrack.entity.job.Job` instance and is initiated by specifying the job type `"SYNC_USERS_LDAP"`.

### Usage

To execute the synchronization job, use the `delayed_job` method with the job type set to `JOB_SYNC_USERS_LDAP`:

```python
result = session.delayed_job(ftrack_api.symbol.JOB_SYNC_USERS_LDAP)
```

- **job_type**: Must be `JOB_SYNC_USERS_LDAP`. Any other job type will raise a `ValueError`.

The method returns the job data upon successful submission.

Deprecation Notice
------------------

Note that the `Session.delayed_job` method has been deprecated in favor of `session.call`. Please refer to the release notes for more information on migrating to the new API.

Error Handling
--------------

If the server encounters an error while processing the delayed job request, a `ftrack_api.exception.ServerError` will be raised.

Additional Functionality
------------------------

While the primary focus is on syncing users with LDAP, the module also includes other utility methods such as:

- `send_user_invite(user)`: Sends an invitation to a single user.
- `send_user_invites(users)`: Sends invitations to multiple users.

These methods accept `User` instances and handle the invitation process accordingly.

Summary
-------

The LDAP user synchronization is performed asynchronously on the server via a delayed job of type `"SYNC_USERS_LDAP"`. This approach allows for efficient and scalable user management by integrating with LDAP directories seamlessly.
