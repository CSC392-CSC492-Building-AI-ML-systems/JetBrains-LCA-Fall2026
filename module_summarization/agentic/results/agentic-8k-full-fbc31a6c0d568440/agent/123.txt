Implements the preview+confirm+delete workflow
===============================================

This module provides a set of classes to implement a standard preview, confirm, and delete workflow in Django views, particularly suited for use with django-cradmin.

DeleteViewMixin
---------------

`DeleteViewMixin` is a mixin class that adds common functionality for delete views, including previewing the object to be deleted, confirming the deletion, and handling success messages.

Key features:

- **Page Title**: The page title defaults to a translatable string "Confirm delete".
- **Action Label**: The action label defaults to "Delete" and is used as a prefix for the page title and as the default label for the delete button.
- **Button Labels**: Provides default labels for the delete and cancel buttons, which can be overridden.
- **Object Preview**: Displays a preview of the object to be deleted, defaulting to the string representation of the object.
- **Confirm Message**: Shows a confirmation message asking the user if they are sure they want to delete the object, including the object preview.
- **Success URL**: Defines the URL to redirect to after successful deletion, defaulting to the index view of the current app.
- **Success Message**: Provides a success message after deletion, which can be customized.
- **Success Messages Handling**: Adds success messages to the Django messages framework after deletion.
- **Context Data**: Adds relevant context variables for use in templates, such as `model_verbose_name`, `success_url`, `object_preview`, `pagetitle`, `confirm_message`, `delete_button_label`, and `cancel_button_label`.
- **Delete Method**: Overrides the `delete` method to add success messages after the object is deleted.

Usage note: Import this class via `from django_cradmin import viewhelpers` and refer to it as `viewhelpers.formview.DeleteViewMixin`.

WithinRoleDeleteView
--------------------

`WithinRoleDeleteView` is a concrete delete view class designed for use in django-cradmin applications where the view operates within a specific role context.

Features:

- Inherits from `QuerysetForRoleMixin`, `DeleteViewMixin`, Django's generic `DeleteView`, `CommonCradminViewMixin`, and `WithinRoleViewMixin` from the javascript registry.
- Provides the correct context data and uses a sensible base template for delete views scoped to a cradmin role.
- Uses the template `django_cradmin/viewhelpers/formview/within_role_delete_view.django.html`.
- Adds JavaScript component IDs and common view mixin data to the context, along with the delete view mixin context data.

Usage note: Import this class via `from django_cradmin import viewhelpers` and refer to it as `viewhelpers.formview.WithinRoleDeleteView`.

Workflow Summary
----------------

The workflow implemented by these classes follows these steps:

1. **Preview**: The user is shown a preview of the object to be deleted, including a confirmation message.
2. **Confirm**: The user confirms the deletion by clicking the delete button.
3. **Delete**: The object is deleted, and the user is redirected to a success URL.
4. **Feedback**: A success message is displayed to inform the user that the object was deleted.

This workflow ensures a user-friendly and consistent experience for delete operations within django-cradmin applications.
