Migrating to nextcord
=====================

This guide provides important information and notes for migrating your codebase to **nextcord**, a maintained fork of discord.py with additional features and improvements.

Message Replying and Mentions
-----------------------------

When replying to messages, nextcord introduces enhanced control over message references and mentions:

- The `reference` parameter can be a `nextcord.Message`, `nextcord.MessageReference`, or `nextcord.PartialMessage`. This allows you to specify the message you are replying to. You can create a reference using the method `Message.to_reference()` or pass a message object directly.

- The `mention_author` parameter (optional boolean) overrides the `AllowedMentions.replied_user` attribute in `allowed_mentions`. This controls whether the author of the referenced message is mentioned when replying.

These features were added in version 1.6 of nextcord.

Embeds and Stickers in Messages
-------------------------------

nextcord supports sending multiple embeds and stickers with messages:

- `embeds`: A list of up to 10 `nextcord.Embed` objects can be sent with a message.

- `stickers`: A sequence of up to 3 stickers can be sent. Stickers can be either `nextcord.GuildSticker` or `nextcord.StickerItem`.

These capabilities were introduced in version 2.0.

Error Handling
--------------

When sending messages, the following exceptions may be raised:

- `nextcord.HTTPException`: Sending the message failed due to an HTTP error.

- `nextcord.Forbidden`: The bot does not have the required permissions to send the message.

- `nextcord.InvalidArgument`: The provided files list or other arguments are invalid or exceed allowed limits.

Type Converters and Generics
----------------------------

nextcord uses a system of converters to transform input into appropriate Discord objects. The following converters are mapped to their respective types:

- `nextcord.Object` → `ObjectConverter`

- `nextcord.Member` → `MemberConverter`

- `nextcord.User` → `UserConverter`

- `nextcord.Message` → `MessageConverter`

- `nextcord.PartialMessage` → `PartialMessageConverter`

- `nextcord.TextChannel` → `TextChannelConverter`

- `nextcord.Invite` → `InviteConverter`

- `nextcord.Guild` → `GuildConverter`

- `nextcord.Role` → `RoleConverter`

- `nextcord.Game` → `GameConverter`

- `nextcord.Colour` → `ColourConverter`

Additionally, nextcord supports detection of generic types using internal utilities, which may be relevant when working with type hints and converters.

Summary
-------

Migrating to nextcord involves updating your code to utilize the enhanced message replying system, support for multiple embeds and stickers, and handling new exceptions. The converter system remains similar but includes mappings for new or updated types.

For detailed API changes and new features, refer to the official nextcord documentation.
