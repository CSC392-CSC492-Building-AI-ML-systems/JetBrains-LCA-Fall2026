w_red command
=============

Description
-----------

The `w_red` command applies the RED (Rate Estimation from Dynamics) scheme to estimate steady-state Weighted Ensemble (WE) fluxes from shorter trajectories. This method provides an approach to analyze WE simulation data to obtain more accurate flux estimates by leveraging the RED scheme.

Source Data
-----------

The source data for `w_red` is provided as a `w_ipa` scheme, which is typically defined in the `west.cfg` configuration file. For example, if a user wishes to estimate RED fluxes for a scheme named "DEFAULT", this scheme name is provided to `w_red`. The tool then estimates RED fluxes based on the data contained in the `assign.h5` and `direct.h5` files located in the `ANALYSIS/DEFAULT` directory.

Configuration Requirements
--------------------------

The `w_red` command requires specific parameters to be set in the `west.cfg` file under the `[west.analysis.red]` section:

- `scheme`: The name of the scheme to analyze (e.g., "DEFAULT").
- `istate_label`: The label of the initial state.
- `fstate_label`: The label of the final state.
- `nstiter`: Number of steps per iteration.
- `nstrep`: Number of steps per report.

Additionally, the analysis must be configured to use cumulative averaging for kinetics evolution (`[west.analysis.kinetics.evolution]` must be set to `"cumulative"`). Other evolution modes are not supported by `w_red`.

Usage
-----

When executed, `w_red` performs the following steps:

1. Reads and validates the required RED parameters from the `west.cfg` file.
2. Loads the relevant data files (`assign.h5` and `direct.h5`) from the specified analysis directory and scheme.
3. Prints the configuration summary including scheme name, initial and final states, and timing parameters.
4. Estimates the RED fluxes using the `RateCalculator` class, which computes the flux rates iteratively.
5. Saves the computed RED flux evolution data back into the `direct.h5` file under the dataset name `red_flux_evolution`.

If the dataset `red_flux_evolution` already exists in the `direct.h5` file, the user is prompted whether to overwrite it. If the user declines, the flux data is saved as a NumPy `.npy` file in the analysis directory instead.

Output
------

- The primary output is the `red_flux_evolution` dataset saved in the `direct.h5` file within the analysis scheme directory.
- Alternatively, if overwriting is declined, the flux data is saved as `red_flux_evolution.npy` in the same directory.

Example
-------

Assuming the scheme is named "DEFAULT" and the configuration is properly set, running:

```
w_red
```

will estimate the RED fluxes for the "DEFAULT" scheme and save the results in `ANALYSIS/DEFAULT/direct.h5`.

Notes
-----

- The `w_red` command currently supports only cumulative averaging for kinetics evolution.
- Proper configuration in `west.cfg` is essential for successful execution.
- The tool provides progress updates during rate calculation iterations.

For more detailed information on configuring and using the RED scheme, refer to the WESTPA documentation and the `west.cfg` configuration guidelines.
