Iterables Module
================

This module provides a collection of utility functions for working with iterables, including generating subsets, filtering elements, creating infinite streams of symbols, partitioning integers, and more.

Functions
---------

subsets(seq, k=None, repetition=False)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Generate all k-subsets (combinations) from an n-element set, `seq`.

A k-subset of an n-element set is any subset of length exactly k. The number of k-subsets of an n-element set is given by binomial(n, k), whereas there are 2**n subsets altogether. If k is None then all 2**n subsets will be returned from shortest to longest.

Parameters
^^^^^^^^^^

- seq : iterable
  The input sequence from which subsets are generated.
- k : int or None, optional
  The size of each subset. If None, all subsets of all sizes are generated.
- repetition : bool, optional
  If True, combinations with repetition are generated.

Returns
^^^^^^^

- iterator
  An iterator over the generated subsets as tuples.

Examples
^^^^^^^^

>>> list(subsets([1, 2], 2))
[(1, 2)]
>>> list(subsets([1, 2]))
[(), (1,), (2,), (1, 2)]
>>> list(subsets([1, 2, 3], 2))
[(1, 2), (1, 3), (2, 3)]
>>> list(subsets([1, 2], 2, repetition=True))
[(1, 1), (1, 2), (2, 2)]

filter_symbols(iterator, exclude)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Yield elements from `iterator` that do not occur in `exclude`.

Parameters
^^^^^^^^^^

- iterator : iterable
  The iterable to filter.
- exclude : iterable
  Elements to exclude from the output.

Returns
^^^^^^^

- iterator
  An iterator yielding elements from `iterator` not in `exclude`.

numbered_symbols(prefix='x', cls=None, start=0, exclude=[], **assumptions)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Generate an infinite stream of symbols consisting of a prefix and increasing subscripts, excluding any in `exclude`.

Parameters
^^^^^^^^^^

- prefix : str, optional
  The prefix for the symbols (default is 'x').
- cls : class, optional
  The class to instantiate symbols from (default is Symbol).
- start : int, optional
  The starting index for subscripts (default is 0).
- exclude : iterable, optional
  Symbols to exclude from generation.
- **assumptions : keyword arguments
  Additional assumptions to pass to the symbol constructor.

Returns
^^^^^^^

- iterator
  An infinite iterator yielding symbols.

sift(seq, keyfunc)
~~~~~~~~~~~~~~~~~~

Sift the sequence `seq` into a dictionary according to `keyfunc`.

Each element in `seq` is stored in a list keyed to the value of `keyfunc` for that element.

Parameters
^^^^^^^^^^

- seq : iterable
  The sequence to sift.
- keyfunc : callable
  A function that takes an element of `seq` and returns a key.

Returns
^^^^^^^

- defaultdict(list)
  A dictionary mapping keys to lists of elements.

Examples
^^^^^^^^

>>> from collections import defaultdict
>>> sift(range(5), lambda x: x % 2) == defaultdict(list, {0: [0, 2, 4], 1: [1, 3]})
True

partitions(n, m=None, k=None, size=False)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Generate integer partitions of `n`.

Each partition is represented as a dictionary mapping integers to their multiplicities.

Parameters
^^^^^^^^^^

- n : int
  The integer to partition.
- m : int or None, optional
  Maximum number of parts in the partition.
- k : int or None, optional
  Maximum size of parts in the partition.
- size : bool, optional
  If True, yield tuples of (number_of_parts, partition_dict).

Returns
^^^^^^^

- iterator
  An iterator over partitions represented as dictionaries.

Examples
^^^^^^^^

>>> from diofant.utilities.iterables import partitions
>>> for p in partitions(6, k=2):
...     print(p)
{2: 3}
{2: 2, 1: 2}
{2: 1, 1: 4}
{1: 6}

>>> for p in partitions(6, m=2):
...     print(p)
{6: 1}
{5: 1, 1: 1}
{4: 1, 2: 1}
{3: 2}

runs(seq, op=operator.le)
~~~~~~~~~~~~~~~~~~~~~~~~~

Split a sequence into runs where the binary operator `op` holds between consecutive elements.

Parameters
^^^^^^^^^^

- seq : iterable
  The sequence to split.
- op : callable, optional
  A binary operator function (default is operator.le).

Returns
^^^^^^^

- list of lists
  A list of runs (sublists) where the operator holds.

Examples
^^^^^^^^

>>> import operator
>>> runs([0, 1, 2, 2, 1, 4, 3, 2, 2], op=operator.ge)
[[0, 1, 2, 2], [1, 4], [3], [2, 2]]

cantor_product(*args)
~~~~~~~~~~~~~~~~~~~~~

Breadth-first (diagonal) Cartesian product of iterables.

Each iterable is advanced in turn in a round-robin fashion. This approach enumerates tuples in a breadth-first manner.

Parameters
^^^^^^^^^^

- *args : iterables
  The input iterables to form the Cartesian product.

Returns
^^^^^^^

- iterator
  An iterator over tuples representing the Cartesian product.

Examples
^^^^^^^^

>>> from itertools import count, islice
>>> list(islice(cantor_product(count(), count()), 9))
[(0, 0), (0, 1), (1, 0), (1, 1), (0, 2), (1, 2), (2, 0), (2, 1), (2, 2)]

permute_signs(t)
~~~~~~~~~~~~~~~~

Return an iterator over tuples where the signs of non-zero elements of `t` are permuted.

Parameters
^^^^^^^^^^

- t : iterable of numbers
  The input tuple or list.

Returns
^^^^^^^

- iterator
  An iterator over tuples with sign permutations.

Examples
^^^^^^^^

>>> list(permute_signs((0, 1, 2)))
[(0, 1, 2), (0, -1, 2), (0, 1, -2), (0, -1, -2)]

signed_permutations(t)
~~~~~~~~~~~~~~~~~~~~~~

Return an iterator over tuples where the signs of non-zero elements of `t` and the order of the elements are permuted.

Parameters
^^^^^^^^^^

- t : iterable of numbers
  The input tuple or list.

Returns
^^^^^^^

- iterator
  An iterator over tuples with permutations of order and sign.

Examples
^^^^^^^^

>>> list(signed_permutations((0, 1, 2)))
[(0, 1, 2), (0, -1, 2), (0, 1, -2), (0, -1, -2), (0, 2, 1),
 (0, -2, 1), (0, 2, -1), (0, -2, -1), (1, 0, 2), (-1, 0, 2),
 (1, 0, -2), (-1, 0, -2), (1, 2, 0), (-1, 2, 0), (1, -2, 0),
 (-1, -2, 0), (2, 0, 1), (-2, 0, 1), (2, 0, -1), (-2, 0, -1),
 (2, 1, 0), (-2, 1, 0), (2, -1, 0), (-2, -1, 0)]

_internal helper: _nodes(e)
~~~~~~~~~~~~~~~~~~~~~~~~~~

Helper function to count nodes in an expression `e`.

For Basic objects, returns the number of Basic nodes in the expression tree. For other objects, returns 1 unless the object is iterable or a dictionary, in which case it sums the nodes of the contained elements.

Parameters
^^^^^^^^^^

- e : object
  The expression or object to count nodes for.

Returns
^^^^^^^

- int
  The node count.

This module is designed to facilitate common iterable manipulations and combinatorial constructions, providing efficient and flexible tools for symbolic and numeric computations.
