Metrics and Pairwise Functions
==============================

This module provides a collection of functions to compute pairwise distances and kernels between samples in datasets. It supports a variety of distance metrics and kernel functions, optimized for both dense and sparse data representations.

Pairwise Distances and Argmin
-----------------------------

### pairwise_distances_argmin_min

Compute the closest points and minimal distances between two collections of points.

This function computes, for each row in `X`, the index of the row in `Y` which is closest according to the specified distance metric. It also returns the minimal distances. This is equivalent to computing the full pairwise distance matrix and then finding the minimum along the specified axis, but is more memory efficient and faster for large arrays.

**Parameters**

- `X` : array-like or sparse matrix of shape (n_samples_X, n_features)  
  Input array containing points.

- `Y` : array-like or sparse matrix of shape (n_samples_Y, n_features)  
  Input array containing points.

- `axis` : int, default=1  
  Axis along which to compute the argmin and distances.

- `metric` : str or callable, default='euclidean'  
  The distance metric to use. Can be a string representing a valid metric or a callable function.  
  Valid string metrics include those from scikit-learn and `scipy.spatial.distance`, such as:  
  `'cityblock'`, `'cosine'`, `'euclidean'`, `'l1'`, `'l2'`, `'manhattan'`, `'braycurtis'`, `'canberra'`, `'chebyshev'`, `'correlation'`, `'dice'`, `'hamming'`, `'jaccard'`, `'kulsinski'` (deprecated), `'mahalanobis'`, `'minkowski'`, `'rogerstanimoto'`, `'russellrao'`, `'seuclidean'`, `'sokalmichener'`, `'sokalsneath'`, `'sqeuclidean'`, `'yule'`.  
  Note: `'kulsinski'` is deprecated from SciPy 1.9 and will be removed in SciPy 1.11.  
  Note: `'matching'` metric has been removed in SciPy 1.9; use `'hamming'` instead.

- `metric_kwargs` : dict, default=None  
  Additional keyword arguments to pass to the metric function.

**Returns**

- `argmin` : ndarray  
  Indices of the closest points in `Y` for each point in `X`.

- `distances` : ndarray  
  The minimal distances corresponding to the closest points.

**See Also**

- `pairwise_distances` : Compute distances between every pair of samples in `X` and `Y`.
- `pairwise_distances_argmin` : Similar function returning only the indices of closest points.

Paired Distances
----------------

### paired_distances

Compute distances between corresponding pairs of points in two datasets.

Given two collections of points `X` and `Y` of the same length, this function computes the distance between each pair `(X[i], Y[i])` using the specified metric.

**Parameters**

- `X`, `Y` : array-like or sparse matrix  
  Input arrays containing points.

- `metric` : str or callable  
  The distance metric to use. Can be a string key from predefined paired distances or a callable function.

**Returns**

- `distances` : ndarray  
  Array of distances between corresponding pairs.

**Examples**

```python
from sklearn.metrics.pairwise import paired_distances
X = [[0, 1], [1, 1]]
Y = [[0, 1], [2, 1]]
paired_distances(X, Y)
# array([0., 1.])
```

Kernel Functions
----------------

### linear_kernel

Compute the linear kernel between two datasets.

The linear kernel is defined as the inner product between vectors:  
`K(X, Y) = X @ Y.T`

**Parameters**

- `X` : array-like or sparse matrix of shape (n_samples_X, n_features)  
  Input feature array.

- `Y` : array-like or sparse matrix of shape (n_samples_Y, n_features), default=None  
  Optional second feature array. If `None`, uses `Y = X`.

- `dense_output` : bool, default=True  
  Whether to return a dense output matrix even if inputs are sparse.

**Returns**

- Gram matrix : ndarray of shape (n_samples_X, n_samples_Y)  
  The computed linear kernel matrix.

### polynomial_kernel

Compute the polynomial kernel between two datasets.

The polynomial kernel is defined as:  
`K(X, Y) = (gamma * <X, Y> + coef0) ^ degree`

**Parameters**

- `X` : array-like or sparse matrix of shape (n_samples_X, n_features)  
  Input feature array.

- `Y` : array-like or sparse matrix of shape (n_samples_Y, n_features), default=None  
  Optional second feature array. If `None`, uses `Y = X`.

- `degree` : float, default=3  
  Degree of the polynomial kernel.

- `gamma` : float, default=None  
  Coefficient for the inner product term. If `None`, defaults to `1.0 / n_features`.

- `coef0` : float, default=1  
  Independent term added to the kernel.

**Returns**

- Gram matrix : ndarray of shape (n_samples_X, n_samples_Y)  
  The computed polynomial kernel matrix.

Distance Metrics Dictionary
---------------------------

The module maintains a dictionary of valid distance metrics mapped to their corresponding functions:

- `'cityblock'` : Manhattan distances
- `'cosine'` : Cosine distances
- `'euclidean'` : Euclidean distances
- `'haversine'` : Haversine distances
- `'l1'` : Manhattan distances
- `'l2'` : Euclidean distances
- `'manhattan'` : Manhattan distances
- `'nan_euclidean'` : Euclidean distances that handle NaNs

Use the function `distance_metrics()` to retrieve this dictionary and see the valid metrics available.

Parallel and Callable Support
-----------------------------

The module supports parallel computation of pairwise distances using multiple jobs to speed up calculations on large datasets. It also supports user-defined callable metrics for custom distance computations.

Utility Functions
-----------------

- `_dist_wrapper` : Helper to write computed distances into slices of a distance matrix.
- `_parallel_pairwise` : Splits computation into parallel jobs.
- `_pairwise_callable` : Handles pairwise computations when the metric is a callable function.
- `_check_chunk_size` : Validates chunk sizes for parallel computations.

Notes
-----

- Some metrics such as `'kulsinski'` and `'matching'` have been deprecated or removed in recent versions of SciPy.
- When using callable metrics, computations may be less efficient than using built-in string metrics.
- Sparse matrix inputs are supported for many functions, with options to control output density.

For more detailed usage and examples, refer to the User Guide sections on metrics and kernels in the scikit-learn documentation.
