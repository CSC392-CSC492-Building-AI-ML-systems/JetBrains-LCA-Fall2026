Cross Decomposition
===================

The `cross_decomposition` module in scikit-learn provides tools for modeling relationships between two datasets by decomposing their cross-covariance structure. It includes several algorithms such as Partial Least Squares (PLS) and Canonical Correlation Analysis (CCA), which are useful for regression, dimensionality reduction, and feature extraction when dealing with two sets of variables.

Available Classes
-----------------

- **PLSRegression**  
  Partial Least Squares regression. Finds a linear regression model by projecting the predictors and the response variables to a new space.

- **PLSCanonical**  
  Partial Least Squares canonical mode. Finds latent variables that maximize the covariance between two datasets.

- **PLSSVD**  
  Partial Least Squares using Singular Value Decomposition (SVD) of the cross-covariance matrix. This method computes the right singular vectors of the SVD of the cross-covariance matrix and uses them to project the input data.

- **CCA**  
  Canonical Correlation Analysis. Finds linear combinations of variables in two datasets that are maximally correlated.

PLSSVD
-------

The `PLSSVD` class performs Partial Least Squares regression by computing the Singular Value Decomposition (SVD) of the cross-covariance matrix between two datasets `X` and `Y`.

### Parameters

- `n_components` : int, default=2  
  Number of components to keep. Must be at least 1 and at most the minimum of the number of samples, features in `X`, and targets in `Y`.

- `scale` : bool, default=True  
  Whether to scale the data to unit variance before applying the algorithm.

- `copy` : bool, default=True  
  Whether to copy the input data or perform in-place operations.

### Attributes

- `x_weights_` : ndarray of shape (n_features_X, n_components)  
  The weights of `X` variables.

- `y_weights_` : ndarray of shape (n_features_Y, n_components)  
  The weights of `Y` variables.

- `n_features_in_` : int  
  Number of features seen during fit.

- `feature_names_in_` : ndarray of shape (`n_features_in_`,)  
  Names of features seen during fit. Defined only when `X` has feature names that are all strings.

### Methods

- `fit(X, Y)`  
  Fit the model to data `X` and `Y`.

- `transform(X, Y=None)`  
  Apply the dimensionality reduction on `X` (and optionally `Y`).

- `fit_transform(X, Y)`  
  Fit the model and apply the dimensionality reduction on `X` and `Y`.

### Example

```python
>>> import numpy as np
>>> from sklearn.cross_decomposition import PLSSVD
>>> X = np.array([[0., 0., 1.],
...               [1., 0., 0.],
...               [2., 2., 2.],
...               [2., 5., 4.]])
>>> Y = np.array([[0.1, -0.2],
...               [0.9, 1.1],
...               [6.2, 5.9],
...               [11.9, 12.3]])
>>> pls = PLSSVD(n_components=2).fit(X, Y)
>>> X_c, Y_c = pls.transform(X, Y)
>>> X_c.shape, Y_c.shape
((4, 2), (4, 2))
```

Testing and Validation
----------------------

The module includes comprehensive tests to ensure the correctness and stability of the implementations. Tests verify orthogonality of weights and scores, reconstruction of original data from scores and loadings, and consistency of transformations. The `copy` parameter is tested to ensure input data is not modified unexpectedly. Scaling behavior is also validated to ensure numerical stability.

Feature Names Support
---------------------

Estimators in this module support `get_feature_names_out` to retrieve the names of the output features after transformation, facilitating integration with pipelines and feature selection workflows.

---

This module is part of scikit-learn’s decomposition and regression tools, designed to handle multivariate data analysis where relationships between two datasets are of interest.
