Diophantine Equation Solvers
============================

This module provides functions to solve Diophantine equations, which are polynomial equations where integer solutions are sought. The primary function `diophantine` attempts to find all integer solutions to a given polynomial equation, while specialized helper functions handle particular types of Diophantine equations such as linear and quadratic forms.

Functions
---------

diophantine(eq, param=None, syms=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Finds integer solutions to the Diophantine equation `eq == 0`.

Parameters
^^^^^^^^^^
- eq : Expr or Eq
  The polynomial equation to solve. If an equation (`Eq`) is provided, it is converted to an expression by subtracting the right-hand side from the left-hand side.
- param : Symbol, optional
  The parameter symbol to be used in the parametric solutions. If not provided, default symbols are generated.
- syms : list of Symbol, optional
  Specifies the order of variables in the returned solution tuples. If provided, only symbols in `syms` that appear in the equation are considered.

Returns
^^^^^^^
- A set of tuples representing parametric integer solutions to the equation.

Examples
^^^^^^^^
>>> diophantine(x**2 - y**2)
{(t_0, -t_0), (t_0, t_0)}

>>> diophantine(x*(2*x + 3*y - z))
{(0, n1, n2), (t_0, t_1, 2*t_0 + 3*t_1)}

>>> diophantine(x**2 + 3*x*y + 4*x)
{(0, n1), (3*t_0 - 4, -t_0)}

Notes
^^^^^
- The function attempts to factor the polynomial and classify it into known types of Diophantine equations.
- It supports linear, quadratic, ternary quadratic, sum of squares, and other special forms.
- If the equation is not polynomial or cannot be classified, a TypeError is raised.
- Solutions are merged and simplified before being returned.

See Also
^^^^^^^^
- diofant.solvers.diophantine.diop_solve

diop_linear(eq, param=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Solves linear Diophantine equations of the form:

.. math::

   a_0 x_0 + a_1 x_1 + \cdots + a_n x_n = c

Parameters
^^^^^^^^^^
- eq : Expr or Eq
  The linear Diophantine equation to solve.
- param : Symbol, optional
  The parameter symbol to be used in the parametric solution.

Returns
^^^^^^^
- A tuple of parametric expressions representing the general integer solution.

Examples
^^^^^^^^
>>> diop_linear(2*x - 3*y - 5)
(3*t_0 - 5, 2*t_0 - 5)

Here, the solution corresponds to x = 3*t_0 - 5 and y = 2*t_0 - 5.

>>> diop_linear(2*x - 3*y - 4*z - 3)
(t_0, 2*t_0 + 4*t_1 + 3, -t_0 - 3*t_1 - 3)

Notes
^^^^^
- No solution exists if the greatest common divisor of the coefficients does not divide the constant term.
- For multivariate linear equations, the solver reduces the problem to a series of bivariate linear Diophantine equations.
- Parameters are introduced for free variables to express the general solution.

Internal Helper Functions
-------------------------

_diop_linear(var, coeff, param)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Solves linear Diophantine equations given variables and their coefficients.

Parameters
^^^^^^^^^^
- var : list of Symbol
  Variables in the equation.
- coeff : dict
  Dictionary mapping variables to their integer coefficients.
- param : Symbol
  Parameter symbol used for expressing the general solution.

Returns
^^^^^^^
- A tuple representing the parametric solution or None if no solution exists.

Description
^^^^^^^^^^^
- Handles equations of the form a_0*x_0 + a_1*x_1 + ... + a_n*x_n == c.
- Uses the Euclidean algorithm and gcd computations to find solutions.
- Breaks down multivariate linear equations into bivariate equations recursively.
- Introduces parameters for free variables to express infinite families of solutions.

---

Overview
--------

The Diophantine solver module is designed to handle a wide range of polynomial Diophantine equations by classifying the equation type and applying appropriate solving strategies. It supports:

- Linear Diophantine equations with multiple variables.
- Quadratic and ternary quadratic equations.
- Equations representing sums of squares and other special polynomial forms.

The solutions are returned as sets of tuples, where each tuple corresponds to a parametric solution vector. Parameters are symbolic variables representing integer parameters that generate infinite families of solutions.

Error Handling
--------------

- Raises `TypeError` if the input equation is not polynomial or has non-rational coefficients.
- Raises `TypeError` if the `syms` argument is not a sequence.
- Raises `NotImplementedError` if the equation type is not supported.

Examples Summary
----------------

- Solve difference of squares:

  >>> diophantine(x**2 - y**2)
  {(t_0, -t_0), (t_0, t_0)}

- Solve product of linear factors:

  >>> diophantine(x*(2*x + 3*y - z))
  {(0, n1, n2), (t_0, t_1, 2*t_0 + 3*t_1)}

- Solve quadratic with linear terms:

  >>> diophantine(x**2 + 3*x*y + 4*x)
  {(0, n1), (3*t_0 - 4, -t_0)}

- Solve linear equation with two variables:

  >>> diop_linear(2*x - 3*y - 5)
  (3*t_0 - 5, 2*t_0 - 5)

- Solve linear equation with three variables:

  >>> diop_linear(2*x - 3*y - 4*z - 3)
  (t_0, 2*t_0 + 4*t_1 + 3, -t_0 - 3*t_1 - 3)
