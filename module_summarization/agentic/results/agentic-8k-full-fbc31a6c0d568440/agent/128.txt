Miscellaneous Features of `astropy.io.fits`
============================================

This section highlights various miscellaneous features and utilities provided by the `astropy.io.fits` subpackage, which facilitate working with FITS files beyond the core functionality of reading and writing.

Memory Mapping and Data Scaling
-------------------------------

`astropy.io.fits` supports memory mapping of FITS files to allow efficient access to large datasets without loading the entire file into memory. When opening a FITS file with `memmap=True`, the data is accessed via memory mapping. However, if scaling of image data is required (e.g., applying BSCALE and BZERO), memory mapping may not be possible, and attempting to access the data will raise a `ValueError`.

To avoid this issue, the `do_not_scale_image_data=True` option can be used when opening the FITS file. This disables scaling and allows memory mapping to work even if scaling would normally be required.

Example:

```python
from astropy.io import fits

with fits.open('blank.fits', memmap=True) as hdul:
    # This may raise ValueError if scaling is needed
    data = hdul[0].data

with fits.open('blank.fits', memmap=True, do_not_scale_image_data=True) as hdul:
    # This will not raise an error
    data = hdul[0].data
```

Header and Card Utilities
-------------------------

The package provides utilities for working with FITS headers and cards, including:

- Managing comments associated with header keywords.
- Slicing and copying headers while preserving comments.
- Extending headers with new cards and maintaining comment consistency.
- Padding and encoding utilities to ensure FITS compliance.

These utilities help maintain the integrity and readability of FITS headers during manipulation.

Verification and Warning Handling
---------------------------------

`astropy.io.fits` includes verification tools to check FITS file compliance with the FITS standard. When opening or modifying FITS files, warnings such as `VerifyWarning` or `AstropyUserWarning` may be issued to alert users about non-standard cards or potential issues.

The package also provides mechanisms to fix or warn about such issues automatically, for example, by using the `output_verify` parameter when opening files.

FITS Difference Tool (`fitsdiff`)
---------------------------------

The `fitsdiff` script is included as a utility to compare two FITS files and report differences. It supports command-line options such as `-h` for help and `--version` to display the version of the tool.

This tool is useful for regression testing and verifying changes between FITS files.

Handling FITS Standard Compliance
---------------------------------

The package carefully handles FITS standard compliance issues, such as:

- Ensuring equal signs in cards are at the correct column.
- Managing cards that do not conform to the standard.
- Providing warnings and options to fix or ignore such issues.

These features help users maintain FITS files that are compatible with other FITS readers and tools.

Integration with Astropy Utilities
----------------------------------

`astropy.io.fits` integrates with other Astropy utilities, such as:

- `astropy.units` for handling physical units.
- `astropy.time` for time-related FITS columns.
- Exception handling utilities from `astropy.utils.exceptions`.

This integration enhances the functionality and robustness of FITS file handling.

Summary
-------

The miscellaneous features of `astropy.io.fits` provide enhanced control, compliance checking, and utilities that facilitate working with FITS files in a robust and user-friendly manner. These features complement the core FITS I/O capabilities and support a wide range of FITS file manipulation tasks.
