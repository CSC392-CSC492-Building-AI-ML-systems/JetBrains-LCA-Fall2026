Decision Trees
==============

The `sklearn.tree` module provides decision tree-based models for both classification and regression tasks. Decision trees are versatile machine learning algorithms that recursively split the input space to create a model that predicts the target variable by learning simple decision rules inferred from the data features.

Classes
-------

- **BaseDecisionTree**  
  The base class for decision tree estimators.

- **DecisionTreeClassifier**  
  A decision tree classifier. It builds a tree structure where each internal node corresponds to a test on a feature, each branch represents an outcome of the test, and each leaf node represents a class label.

- **DecisionTreeRegressor**  
  A decision tree regressor. Similar to the classifier but used for regression tasks, predicting continuous values.

- **ExtraTreeClassifier**  
  Extremely randomized trees classifier. Similar to `DecisionTreeClassifier` but uses random splits.

- **ExtraTreeRegressor**  
  Extremely randomized trees regressor. Similar to `DecisionTreeRegressor` but uses random splits.

Functions
---------

- **export_text(decision_tree, *, feature_names=None, class_names=None, max_depth=10, spacing=3, decimals=2, show_weights=False)**  
  Generates a text report showing the rules of a decision tree.

  Parameters
  ----------
  - `decision_tree` : estimator instance  
    The decision tree estimator to be exported. Must be an instance of `DecisionTreeClassifier` or `DecisionTreeRegressor`.

  - `feature_names` : array-like of shape (n_features,), default=None  
    Names of each feature. If None, generic names like "feature_0", "feature_1", etc., will be used.

  - `class_names` : array-like of shape (n_classes,), default=None  
    Names of each target class in ascending numerical order. Only relevant for classification. If None, class names are taken from `decision_tree.classes_`.

  - `max_depth` : int, default=10  
    Maximum depth of the tree to export. Branches deeper than this will be truncated and marked with "...".

  - `spacing` : int, default=3  
    Number of spaces between edges in the text output.

  - `decimals` : int, default=2  
    Number of decimal digits to display for numerical values.

  - `show_weights` : bool, default=False  
    If True, the classification weights (number of samples per class) will be shown on each leaf.

  Returns
  -------
  - `report` : str  
    A text summary of all the rules in the decision tree.

  Example
  -------
  ```python
  >>> from sklearn.datasets import load_iris
  >>> from sklearn.tree import DecisionTreeClassifier, export_text
  >>> iris = load_iris()
  >>> X = iris['data']
  >>> y = iris['target']
  >>> decision_tree = DecisionTreeClassifier(random_state=0, max_depth=2)
  >>> decision_tree = decision_tree.fit(X, y)
  >>> r = export_text(decision_tree, feature_names=iris['feature_names'])
  >>> print(r)
  |--- petal width (cm) <= 0.80
  |   |--- class: 0
  |--- petal width (cm) >  0.80
  |   |--- petal width (cm) <= 1.75
  |   |   |--- class: 1
  |   |--- petal width (cm) >  1.75
  |   |   |--- class: 2
  ```

Additional Utilities
--------------------

- **export_graphviz**  
  Export a decision tree in DOT format for visualization with Graphviz.

- **plot_tree**  
  Plot a decision tree using Matplotlib.

Implementation Details
----------------------

The decision tree implementation relies on efficient Cython extensions for performance-critical parts such as impurity calculations and tree traversal. The impurity criteria (e.g., Gini impurity, entropy, mean squared error) are computed internally to evaluate the quality of splits.

The tree structure is stored in a compact format with arrays representing children nodes, feature indices, thresholds, and node values. This allows fast traversal and prediction.
