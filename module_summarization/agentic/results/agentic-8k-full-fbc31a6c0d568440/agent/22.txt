w_fluxanl — Flux Analysis Tool for WEST Simulations
===================================================

Overview
--------

The `w_fluxanl` command extracts fluxes into pre-defined target states from WEST simulation data, performs averaging, and constructs confidence intervals. It employs Monte Carlo bootstrapping to account for correlated and potentially non-Gaussian statistical errors in flux measurements.

This tool is designed to analyze flux data stored in WEST HDF5 files, providing statistically robust estimates of fluxes and their uncertainties.

Key Features
------------

- Extraction of flux values from WEST HDF5 files over specified iteration ranges.
- Calculation of average fluxes and confidence intervals using Monte Carlo Block Bootstrapping.
- Optional autocorrelation analysis of flux data to assess statistical significance.
- Support for time evolution analysis of flux confidence intervals.
- Output of intermediate data and analysis results to an HDF5 file for further inspection.
- Configurable parameters for bootstrapping, confidence levels, and iteration ranges.

Usage
-----

```bash
w_fluxanl [OPTIONS]
```

Options
-------

### Data Input and Iteration Selection

- Arguments to specify the WEST data source and iteration range are supported (inherited from the data reader and iteration range selection modules).

### Output Options

- `-o, --output OUTPUT`  
  Specify the output file to store intermediate data and analysis results.  
  Default: `fluxanl.h5`

### Calculation Options

- `--disable-bootstrap, -db`  
  Disable Monte Carlo Block Bootstrapping (enabled by default).

- `--disable-correl, -dc`  
  Disable correlation analysis (enabled by default).

- `-a, --alpha ALPHA`  
  Set the significance level for confidence intervals on the average flux.  
  Default: `0.05` (corresponding to 95% confidence intervals).

- `--autocorrel-alpha ACALPHA`  
  Set the significance level for autocorrelation analysis of flux data.  
  Default: same as `alpha`.

- `-N, --nsets NSETS`  
  Number of bootstrap samples to use. If not specified, a default based on `alpha` is chosen.

- `--evol`  
  Calculate the time evolution of flux confidence intervals. This option is computationally expensive.

- `--evol-step ESTEP`  
  Calculate time evolution of flux confidence intervals every `ESTEP` iterations.  
  Default: `1`

Details and Notes
-----------------

- The tool assumes that the propagation/resampling period `tau` is unity for all non-graphical output (including terminal and HDF5 outputs). To convert results to physical units, divide all fluxes by the true value of `tau` and multiply all correlation lengths by `tau`.

- Monte Carlo Block Bootstrapping is used to properly account for statistical correlations and non-Gaussian distributions in the flux data.

- Autocorrelation analysis helps determine the effective statistical independence of flux measurements.

- Time evolution analysis (`--evol`) provides confidence intervals as a function of iteration, allowing assessment of convergence behavior.

Output
------

The output is stored in an HDF5 file (default `fluxanl.h5`) containing:

- Extracted flux data for each target state.
- Average fluxes and confidence intervals.
- Autocorrelation analysis results.
- Optional time evolution datasets if `--evol` is enabled.

Deprecation Notice
------------------

**Warning:** The `w_fluxanl` command is deprecated. Users are encouraged to use the `w_assign` and `w_direct` commands for flux and rate analysis in WEST simulations.

Example
-------

```bash
w_fluxanl -o my_flux_analysis.h5 -a 0.01 --evol --evol-step 5
```

This command runs flux analysis with 99% confidence intervals, calculates time evolution of flux confidence intervals every 5 iterations, and stores results in `my_flux_analysis.h5`.

For more detailed information on usage and options, consult the WESTPA documentation or use `w_fluxanl --help`.
