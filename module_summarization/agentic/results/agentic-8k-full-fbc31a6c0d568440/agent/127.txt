Convolution Module Built-in Kernels
===================================

The `convolution` module provides a variety of built-in kernel classes for use in convolution operations. These kernels are designed for smoothing, filtering, and modeling purposes in one or two dimensions. Each kernel class generates a normalized kernel array suitable for convolution with data arrays.

Gaussian Kernels
----------------

### Gaussian1DKernel

1D Gaussian filter kernel.

The Gaussian filter is a filter with excellent smoothing properties. It is isotropic and does not produce artifacts. The generated kernel is normalized so that it integrates to 1.

**Parameters**

- `stddev` : number  
  Standard deviation of the Gaussian kernel.

- `x_size` : int, optional  
  Size of the kernel array. Default is ⌊8 * stddev + 1⌋.

- `mode` : {'center', 'linear_interp', 'oversample', 'integrate'}, optional  
  Discretization mode for the kernel:
  - `'center'` (default): Discretize model by taking the value at the center of the bin.
  - `'linear_interp'`: Discretize model by linearly interpolating between the values at the corners of the bin.
  - `'oversample'`: Discretize model by taking the average on an oversampled grid.
  - `'integrate'`: Discretize model by integrating the model over the bin (very slow).

- `factor` : number, optional  
  Factor of oversampling. Default is 10. Larger factors increase evaluation time.

**See Also**

- `Box1DKernel`
- `Trapezoid1DKernel`
- `RickerWavelet1DKernel`

**Example**

```python
import matplotlib.pyplot as plt
from astropy.convolution import Gaussian1DKernel

gauss_1D_kernel = Gaussian1DKernel(10)
plt.plot(gauss_1D_kernel, drawstyle='steps')
plt.xlabel('x [pixels]')
plt.ylabel('value')
plt.show()
```

### Gaussian2DKernel

2D Gaussian filter kernel.

The Gaussian filter is a filter with excellent smoothing properties. It is isotropic and does not produce artifacts. The generated kernel is normalized so that it integrates to 1.

**Parameters**

- `x_stddev` : float  
  Standard deviation of the Gaussian in x before rotation.

- `y_stddev` : float  
  Standard deviation of the Gaussian in y before rotation.

- `theta` : float or `~astropy.units.Quantity` ['angle']  
  Rotation angle in radians (if float) or as an angle quantity. The rotation angle increases counterclockwise.

- `x_size` : int, optional  
  Size in x direction of the kernel array. Default is ⌊8 * stddev + 1⌋.

- `y_size` : int, optional  
  Size in y direction of the kernel array. Default is ⌊8 * stddev + 1⌋.

- `mode` : {'center', 'linear_interp', 'oversample', 'integrate'}, optional  
  Discretization mode for the kernel (same options as `Gaussian1DKernel`).

Other Built-in Kernels
----------------------

- **Box1DKernel**  
  A 1D boxcar (rectangular) kernel.

- **Box2DKernel**  
  A 2D boxcar (rectangular) kernel.

- **Tophat2DKernel**  
  A 2D tophat kernel, which is a circular flat kernel.

- **Trapezoid1DKernel**  
  A 1D trapezoidal kernel.

- **RickerWavelet1DKernel**  
  A 1D Ricker wavelet kernel (also known as the Mexican hat wavelet).

- **RickerWavelet2DKernel**  
  A 2D Ricker wavelet kernel.

- **AiryDisk2DKernel**  
  A 2D Airy disk kernel, modeling the diffraction pattern of a circular aperture.

- **Moffat2DKernel**  
  A 2D Moffat kernel, often used in astronomy to model point spread functions.

- **Model1DKernel**  
  A 1D kernel generated from an arbitrary 1D model.

- **Model2DKernel**  
  A 2D kernel generated from an arbitrary 2D model.

- **TrapezoidDisk2DKernel**  
  A 2D trapezoidal disk kernel.

- **Ring2DKernel**  
  A 2D ring-shaped kernel.

Kernel Properties and Usage
---------------------------

- All kernels are normalized by default so that their sum equals 1, ensuring that the convolution preserves the overall flux or intensity.

- Kernel sizes are generally odd integers to ensure a well-defined center pixel.

- Kernels support different discretization modes to control how the continuous model is sampled into discrete pixels.

- Attempting to create kernels with even sizes will raise exceptions to enforce odd-sized kernels.

- Kernels can be created from predefined models or custom arrays, but passing an array directly to some kernel constructors is disallowed to prevent misuse.

- Repeated normalization of kernels does not alter their values, ensuring stability in processing pipelines.

- Kernels raise errors if invalid parameters are passed, such as non-integer sizes or unsupported modes.

Testing and Validation
----------------------

The kernel implementations include comprehensive tests to ensure:

- Proper handling of kernel sizes (odd sizes enforced).

- Correct normalization behavior.

- Validation of input parameters.

- Stability of kernel values upon repeated normalization.

- Proper error handling for invalid inputs.

Example Usage
-------------

```python

# Create a 2D Gaussian kernel with standard deviations 3 and 5 in x and y
gauss_2D_kernel = Gaussian2DKernel(x_stddev=3, y_stddev=5)
```

Summary
-------

The built-in kernels in the convolution module provide a robust and flexible set of tools for smoothing and filtering data in one and two dimensions. Their careful design ensures numerical stability, normalization, and ease of use for a wide range of scientific and engineering applications.
