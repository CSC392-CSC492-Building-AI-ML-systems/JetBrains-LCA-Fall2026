Duration Module
===============

Overview
--------
This module provides functionality for survival analysis, specifically focusing on proportional hazards regression models. It includes tools for estimating survival functions, cumulative hazard functions, and related statistics, as well as methods for prediction and residual analysis within the context of survival data.

Key Features
------------
- **Proportional Hazards Regression Model**: Implements the Cox proportional hazards model for analyzing duration (time-to-event) data.
- **Survival Function Estimation**: Non-parametric estimation of survival probabilities and cumulative hazard functions.
- **Prediction Methods**: Generate predicted survival probabilities, hazard rates, and related quantities based on fitted model parameters.
- **Distribution Estimation**: Provides discrete distribution objects representing the estimated survivor functions for uncensored duration values.
- **Residual Analysis**: Computes score residuals and Schoenfeld residuals for model diagnostics.
- **Weighted Covariate Averages**: Calculates average covariate values within the at-risk set at each event time, weighted by hazard.

Detailed Description
--------------------

### Prediction

The `predict` method returns predicted values from the proportional hazards regression model. It supports various prediction types, including survival probabilities and hazard rates.

**Parameters:**

- `exog` : array_like  
  Covariate data used for prediction. If not provided, the covariates from the fitted model are used.
- `endog` : array_like  
  Duration (time-to-event) data.
- `strata` : array_like, optional  
  Stratification variable for grouped data.
- `offset` : array_like, optional  
  Offset values for the linear predictor.
- `transform` : bool, optional  
  Whether to apply transformation to the linear predictor.
- `pred_type` : str, optional  
  Type of prediction to return (e.g., "surv" for survival probabilities).

Returns predicted values corresponding to the specified prediction type.

### Distribution Estimation

The `get_distribution` method returns a list of `scipy.stats.distributions.rv_discrete` objects representing the estimated discrete distributions of uncensored duration values for each case. These distributions are derived from the estimated survivor functions, which place all probability mass on observed failure times within each stratum.

### Residuals and Diagnostics

- **Score Residuals**: A matrix of score residuals useful for assessing model fit.
- **Schoenfeld Residuals**: Residuals used to check the proportional hazards assumption. Residuals for censored observations are set to zero.

### Baseline Hazard Functions

- **Baseline Cumulative Hazard**: Provides the baseline cumulative hazard function evaluated at event times for each stratum.
- **Baseline Cumulative Hazard Function**: Returns function objects that compute the cumulative hazard at arbitrary time points.

### Weighted Covariate Averages

Calculates the average covariate values within the risk set at each event time, weighted by the hazard. This is useful for understanding covariate effects over time.

Usage Notes
-----------
- The module relies on NumPy for numerical operations and SciPy for statistical distributions.
- It supports stratified data, allowing separate baseline hazard functions per stratum.
- Residuals and diagnostic tools facilitate model checking and validation.
- The distribution estimation method currently returns a list of discrete distributions without vectorization support.

Example
-------
```python
# Fit a proportional hazards model and predict survival probabilities
model = PHReg(endog, exog, strata=strata)
results = model.fit()
surv_probs = results.predict(pred_type="surv")
```

This module is intended for researchers and analysts working with survival data who require robust tools for modeling and inference using proportional hazards models.
