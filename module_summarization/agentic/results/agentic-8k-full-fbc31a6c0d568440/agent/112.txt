Generate Documentation for Scan and Spiral Plans
==================================================

This module provides a collection of adaptive tuning and scanning plans designed for experimental control systems. These plans facilitate complex motor movements and data acquisition patterns, including adaptive step tuning and various spiral scanning trajectories.

Functions
---------

tweak(detector, target_field, motor, step, md=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Adaptive tuning plan that iteratively adjusts the motor position to optimize the output of a specified data field from a detector.

**Parameters:**

- **detector** (*Device*): The detector device whose output is monitored.
- **target_field** (*str*): The data field from the detector output that is the focus of adaptive tuning.
- **motor** (*Device*): The motor device to be adjusted.
- **step** (*float*): Initial suggestion for the step size in motor movement.
- **md** (*dict*, optional): Additional metadata to include in the plan.

**Description:**

This plan stages the detector and motor, then enters a loop where it reads the motor position and detector output, prompts the user for a new step size, and moves the motor accordingly. It supports interactive adjustment of the step size and updates metadata with relevant information about detectors, motors, and plan arguments.

spiral_fermat(detectors, x_motor, y_motor, x_start, y_start, x_range, y_range, dr, factor, *, dr_y=None, tilt=0.0, per_step=None, md=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Executes an absolute Fermat spiral scan centered around a specified (x, y) coordinate.

**Parameters:**

- **detectors** (*list*): List of readable detector objects.
- **x_motor** (*object*): Settable object controlling the x-axis position.
- **y_motor** (*object*): Settable object controlling the y-axis position.
- **x_start** (*float*): X-coordinate center of the spiral.
- **y_start** (*float*): Y-coordinate center of the spiral.
- **x_range** (*float*): Width of the spiral along the x-axis.
- **y_range** (*float*): Width of the spiral along the y-axis.
- **dr** (*float*): Radial increment parameter.
- **factor** (*float*): Scaling factor for the spiral.
- **dr_y** (*float*, optional): Radial increment along the y-axis; defaults to None.
- **tilt** (*float*, optional): Tilt angle in radians; default is 0.0.
- **per_step** (*callable*, optional): Hook for customizing actions per step.
- **md** (*dict*, optional): Additional metadata.

**See Also:**

- :func:`bluesky.plans.rel_spiral`
- :func:`bluesky.plans.spiral_fermat`
- :func:`bluesky.plans.rel_spiral_fermat`

rel_spiral(detectors, x_motor, y_motor, x_range, y_range, dr, nth, *, dr_y=None, tilt=0.0, per_step=None, md=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Performs a relative spiral scan with elliptical geometry.

**Parameters:**

- **detectors** (*list*): List of readable detector objects.
- **x_motor** (*object*): Settable object controlling the x-axis.
- **y_motor** (*object*): Settable object controlling the y-axis.
- **x_range** (*float*): Width of the spiral along the x-axis.
- **y_range** (*float*): Width of the spiral along the y-axis.
- **dr** (*float*): Delta radius along the minor axis of the ellipse.
- **dr_y** (*float*, optional): Delta radius along the major axis; defaults to dr if None.
- **nth** (*float*): Number of theta steps.
- **tilt** (*float*, optional): Tilt angle in radians; default is 0.0.
- **per_step** (*callable*, optional): Hook for customizing inner loop actions.
- **md** (*dict*, optional): Additional metadata.

**See Also:**

Metadata
--------

Each plan generates and updates metadata dictionaries (`md`) that include:

- **detectors**: Names or representations of detectors involved.
- **motors**: Names or representations of motors involved.
- **plan_args**: Arguments passed to the plan, with objects replaced by their string representations.
- **plan_name**: Name of the plan.
- **plan_pattern**: Pattern type used in the plan (e.g., 'spiral', 'spiral_square').
- **plan_pattern_args**: Arguments specific to the pattern.
- **extents**: Spatial extents covered by the scan.
- **shape**: Shape of the scan grid (for grid-based scans).
- **hints**: Additional hints such as dimensions and gridding type to assist visualization and analysis tools.

Usage Notes
-----------

- The plans are designed to be used with Bluesky or similar experimental control frameworks.
- The `per_step` callable allows customization of actions performed at each step of the scan.
- Interactive plans like `tweak` support user input to adjust parameters dynamically during execution.
- Metadata is carefully constructed to facilitate downstream data processing and visualization.
