Naive Bayes Methods
===================

Overview
--------

Naive Bayes classifiers are a family of simple probabilistic classifiers based on applying Bayes' theorem with strong (naive) independence assumptions between the features. Despite their simplicity, Naive Bayes classifiers have proven effective in many real-world applications, especially in text classification and natural language processing.

The scikit-learn library provides several implementations of Naive Bayes classifiers tailored for different types of data and assumptions:

- **GaussianNB**: Gaussian Naive Bayes for continuous data assuming Gaussian distribution.
- **MultinomialNB**: Naive Bayes classifier for multinomially distributed data, suitable for discrete counts.
- **ComplementNB**: An adaptation of MultinomialNB designed to handle imbalanced datasets better.
- **BernoulliNB**: Naive Bayes classifier for multivariate Bernoulli models, suitable for binary/boolean features.
- **CategoricalNB**: Naive Bayes classifier for categorical features.

These classifiers share a common interface and can be used for classification tasks where the features are assumed to be conditionally independent given the class label.

Multinomial Naive Bayes (MultinomialNB)
---------------------------------------

The Multinomial Naive Bayes classifier is suitable for classification with discrete features (e.g., word counts for text classification). It models the distribution of features as multinomial distributions conditioned on the class.

**Parameters:**

- `alpha` (float, default=1.0): Additive (Laplace/Lidstone) smoothing parameter.
- `force_alpha` (bool or "warn", default="warn"): Controls whether to force the smoothing parameter alpha to remain unchanged even if it is very close to zero.
- `fit_prior` (bool, default=True): Whether to learn class prior probabilities or not.
- `class_prior` (array-like, default=None): Prior probabilities of the classes.

**Attributes:**

- `class_count_`: Number of samples encountered for each class during fitting.
- `feature_count_`: Number of times each feature appeared in each class.
- `feature_log_prob_`: Empirical log probability of features given a class.
- `class_log_prior_`: Log probability of each class.
- `n_features_in_`: Number of features seen during fit.
- `feature_names_in_`: Names of features seen during fit (if available).

**Example:**

```python
import numpy as np
from sklearn.naive_bayes import MultinomialNB

rng = np.random.RandomState(1)
X = rng.randint(5, size=(6, 100))
y = np.array([1, 2, 3, 4, 5, 6])

clf = MultinomialNB(force_alpha=True)
clf.fit(X, y)
print(clf.predict(X[2:3]))
# Output: [3]
```

Complement Naive Bayes (ComplementNB)
-------------------------------------

Complement Naive Bayes is designed to correct the "severe assumptions" made by the standard Multinomial Naive Bayes classifier. It is particularly suited for imbalanced datasets.

**Parameters:**

- `alpha` (float or array-like, default=1.0): Additive smoothing parameter.
- `force_alpha` (bool or "warn", default="warn"): Controls smoothing parameter behavior.
- `fit_prior` (bool, default=True): Used only in edge cases with a single class.
- `class_prior` (array-like, default=None): Prior probabilities of the classes (not used).
- `norm` (bool, default=False): Whether to perform a second normalization of the weights.

**Attributes:**

- `class_count_`: Number of samples encountered for each class during fitting.
- `feature_count_`: Number of times each feature appeared in each class.
- `feature_all_`: Sum of feature counts across all classes.
- `feature_log_prob_`: Log probabilities of features for complements of classes.
- `class_log_prior_`: Log probability of each class.
- `n_features_in_`: Number of features seen during fit.
- `feature_names_in_`: Names of features seen during fit (if available).

**Example:**

```python
import numpy as np
from sklearn.naive_bayes import ComplementNB

rng = np.random.RandomState(1)
X = rng.randint(5, size=(6, 100))
y = np.array([1, 2, 3, 4, 5, 6])

clf = ComplementNB(force_alpha=True)
clf.fit(X, y)
print(clf.predict(X[2:3]))
# Output: [3]
```

Bernoulli Naive Bayes (BernoulliNB)
-----------------------------------

Bernoulli Naive Bayes is suitable for binary/boolean features. Unlike MultinomialNB which works with occurrence counts, BernoulliNB models binary-valued features.

**Parameters:**

- `alpha` (float or array-like, default=1.0): Additive smoothing parameter.
- `binarize` (float or None, default=0.0): Threshold for binarizing (mapping to booleans) of sample features.
- `fit_prior` (bool, default=True): Whether to learn class prior probabilities.
- `class_prior` (array-like, default=None): Prior probabilities of the classes.

**Attributes:**

- `class_count_`: Number of samples encountered for each class during fitting.
- `feature_count_`: Number of times each feature appeared in each class.
- `feature_log_prob_`: Empirical log probability of features given a class.
- `class_log_prior_`: Log probability of each class.
- `n_features_in_`: Number of features seen during fit.
- `feature_names_in_`: Names of features seen during fit (if available).

Categorical Naive Bayes (CategoricalNB)
---------------------------------------

Categorical Naive Bayes is designed for categorical features where each feature can take on one of a fixed number of categories. It assumes that each feature follows a categorical distribution conditioned on the class.

**Parameters:**

- `alpha` (float or array-like, default=1.0): Additive smoothing parameter.
- `force_alpha` (bool or "warn", default="warn"): Controls smoothing parameter behavior.
- `fit_prior` (bool, default=True): Whether to learn class prior probabilities.
- `class_prior` (array-like, default=None): Prior probabilities of the classes.
- `min_categories` (array-like or None, default=None): Minimum number of categories for each feature.

**Attributes:**

- `class_count_`: Number of samples encountered for each class during fitting.
- `feature_count_`: Number of times each category appeared in each feature per class.
- `feature_log_prob_`: Empirical log probability of categories given a class.
- `class_log_prior_`: Log probability of each class.
- `n_features_in_`: Number of features seen during fit.
- `feature_names_in_`: Names of features seen during fit (if available).
- `n_categories_`: Number of categories for each feature.

**Example:**

```python
import numpy as np
from sklearn.naive_bayes import CategoricalNB

rng = np.random.RandomState(1)
X = rng.randint(5, size=(6, 100))
y = np.array([1, 2, 3, 4, 5, 6])

clf = CategoricalNB(force_alpha=True)
clf.fit(X, y)
print(clf.predict(X[2:3]))
# Output: [3]
```

Examples
--------

Below is a simple example demonstrating the use of MultinomialNB:

```python
import numpy as np
from sklearn.naive_bayes import MultinomialNB

rng = np.random.RandomState(1)
X = rng.randint(5, size=(6, 100))
y = np.array([1, 2, 3, 4, 5, 6])

clf = MultinomialNB(force_alpha=True)
clf.fit(X, y)
print(clf.predict(X[2:3]))
# Output: [3]
```

Similarly, ComplementNB and CategoricalNB can be used in the same manner with their respective imports and parameters.
