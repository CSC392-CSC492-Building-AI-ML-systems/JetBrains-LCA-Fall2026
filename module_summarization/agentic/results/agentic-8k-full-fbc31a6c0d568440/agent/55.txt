Miscellaneous Models
====================

This module provides implementations of statistical models that extend or generalize classical approaches by incorporating alternative error distributions or specialized likelihood functions. The focus is on robust modeling techniques and flexible time series models that can better accommodate real-world data characteristics such as heavy tails, outliers, and overdispersion.

Linear Model with Student-t Distributed Errors
----------------------------------------------

The linear model with Student-t distributed errors is designed to handle data exhibiting heavier tails or outliers more effectively than the traditional Gaussian error assumption. Because the Student-t distribution has fatter tails than the normal distribution, it provides robustness against outliers and yields more reliable parameter estimates in such contexts.

Key features:
- Uses the Student-t distribution for modeling errors, allowing for heavier tails.
- Provides more robust estimators for mean parameters compared to ordinary least squares.
- Includes methods for parameter estimation via maximum likelihood.
- References:
  - Lange, K. L., Little, R. J. A., & Taylor, J. M. G. (1989). Robust Statistical Modeling Using the t Distribution. *Journal of the American Statistical Association*, 84(408), 881-896. [Stable URL](http://www.jstor.org/stable/2290063)

Univariate ARMA Model with t-Distributed Errors (TArma)
--------------------------------------------------------

The `TArma` class extends the classical ARMA time series model by assuming that the innovations (errors) follow a Student-t distribution rather than a normal distribution. This allows the model to better capture heavy-tailed behavior and potential outliers in time series data.

Important notes:
- Inherits most methods from the standard ARMA implementation except for the log-likelihood function, which is adapted for the t-distribution.
- The variance of the error term is given by \( \text{error_variance} = \frac{df}{df-2} \times \text{scale}^2 \), reflecting the properties of the t-distribution.
- The model currently uses the standard t-distribution; future versions may implement a standardized t-distribution where the scale parameter corresponds directly to the variance.

Generic Likelihood-Based Modeling Utilities
-------------------------------------------

The module also includes utilities for generic maximum likelihood estimation (MLE) and numerical differentiation, facilitating the development and fitting of custom models. These tools support:

- Calculation of gradients and Hessians for likelihood functions.
- Handling of parameter covariance matrices.
- Numerical stability improvements and diagnostics for optimization routines.

Known Issues and Development Notes
----------------------------------

- Starting values for parameters can be improved by incorporating ordinary least squares (OLS) estimates.
- Some internal debugging variables and functions (e.g., `store_params`) are currently disabled or under revision.
- Numerical Hessian calculations can be unstable or singular in certain models, such as zero-inflated Poisson (ZIP) models.
- Optimization algorithms like BFGS may be fragile; alternatives like Nelder-Mead are slower but more reliable.
- Further work is needed to implement parameter restrictions and improve scaling in numerical derivatives.

References and Further Reading
------------------------------

This module is intended for users who require robust statistical modeling techniques beyond classical assumptions, particularly in the presence of heavy-tailed data or outliers. It serves as a foundation for further development and experimentation with alternative error distributions and likelihood-based inference methods.
