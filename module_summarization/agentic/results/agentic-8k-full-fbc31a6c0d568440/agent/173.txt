Fitting SESANS Data
===================

This document provides an overview of fitting Spin-Echo Small Angle Neutron Scattering (SESANS) data using the SESANS fitting framework.

Overview
--------

The SESANS fitting framework is designed to handle SESANS data by interpreting the data structure, calculating theoretical models, and evaluating residuals for fitting purposes. It supports lazy evaluation of theoretical predictions and incorporates resolution effects specific to SESANS measurements.

Data Interpretation
-------------------

The fitting process begins by interpreting the input data to determine its type and prepare it for model evaluation. The framework distinguishes SESANS data from other scattering data types by checking the `isSesans` attribute on the data object.

When SESANS data is detected, the framework sets the data type accordingly and prepares the SESANS-specific transform needed for calculations.

SESANS Transform
----------------

A key step in SESANS data fitting is the computation of the Hankel transform matrix, which relates the SESANS correlation function to the scattering intensity. This transform is pre-computed using the following parameters:

- **SElength**: The spin-echo length, converted to Angstroms.
- **zaccept**: The acceptance angle converted to reciprocal Angstroms.
- **Wavelength**: The neutron wavelength(s) used in the experiment.
- **Rmax**: A large cutoff radius for the transform (default is 10,000,000).

The transform is created by calling the `SesansTransform` function with these parameters, enabling efficient calculation of the theoretical SESANS signal.

Model Evaluation
----------------

The theoretical SESANS signal is computed using the model parameters and the SESANS transform. The framework uses lazy evaluation to avoid redundant calculations:

- The `theory()` method returns the current theoretical prediction.
- If the theory has not been computed for the current parameters, it calls `_calc_theory()` with the current model state and caches the result.
- The model state is updated whenever parameters change to ensure consistency.

Residuals and Fitting
---------------------

Residuals are calculated as the difference between the theoretical prediction and the experimental data, normalized by the measurement uncertainties. This is used to guide the fitting process.

Plotting and Visualization
--------------------------

The framework supports plotting SESANS data alongside theoretical predictions and residuals. When SESANS data is detected, a specialized plotting function `_plot_result_sesans` is used to visualize the results, including:

- The experimental data.
- The theoretical model curve.
- Residuals between data and theory.

This visualization aids in assessing the quality of the fit.

Integration with SAS Models
---------------------------

The SESANS fitting framework is integrated with general Small Angle Scattering (SAS) models through a `DataMixin` class, which manages:

- Data interpretation.
- Resolution function evaluation.
- Model parameter handling.

This mixin allows SESANS data to be treated consistently alongside other SAS data types, facilitating combined analyses.

Summary
-------

The SESANS fitting framework provides a robust and efficient approach to fitting SESANS data by:

- Automatically detecting SESANS data.
- Computing the necessary Hankel transforms.
- Evaluating theoretical models with resolution effects.
- Calculating residuals for fitting.
- Providing visualization tools for fit assessment.

This enables researchers to accurately model SESANS experiments and extract meaningful structural information from their data.
