Nonparametric Methods
=====================

Overview
--------

Nonparametric methods provide flexible tools for estimating probability distributions and regression functions without assuming a specific parametric form. These methods are particularly useful when the underlying data structure is complex or unknown, allowing for modeling of continuous, ordered discrete, and unordered discrete variables, as well as mixed data types.

Kernel Density Estimation (KDE)
-------------------------------

Kernel Density Estimation is a fundamental nonparametric technique used to estimate the probability density function of a random variable. The multivariate kernel density estimator extends this concept to multiple variables, accommodating mixed data types including continuous, ordered discrete, and unordered discrete variables.

### KDEMultivariate Class

The `KDEMultivariate` class implements a multivariate kernel density estimator capable of handling univariate and multivariate data with mixed variable types. It supports cross-validated bandwidth selection methods such as least squares and maximum likelihood.

#### Parameters

- **data** : list of ndarrays or 2-D ndarray  
  The training data for the kernel density estimation. If a 2-D array, it should have shape `(num_observations, num_variables)`. Alternatively, a list where each element corresponds to a variable can be provided.

- **var_type** : str  
  Specifies the type of each variable in the data. The string should contain one character per variable:  
  - `'c'` : continuous  
  - `'u'` : unordered discrete  
  - `'o'` : ordered discrete  

  For example, `'ccuo'` indicates four variables with types continuous, continuous, unordered discrete, and ordered discrete respectively.

- **bw** : array_like or str, optional  
  Bandwidth parameter(s) for the kernel. Can be a fixed array or one of the following strings specifying the bandwidth selection method:  
  - `'normal_reference'` : Normal reference rule of thumb (default)  
  - `'cv_ml'` : Cross-validation maximum likelihood  
  - `'cv_ls'` : Cross-validation least squares  

- **defaults** : EstimatorSettings instance, optional  
  Default settings for bandwidth estimation and other parameters.

#### Attributes

- **bw** : array_like  
  The bandwidth parameters used in the kernel density estimation.

#### Example

```python
import numpy as np
import statsmodels.api as sm

nobs = 300
np.random.seed(1234)
c1 = np.random.normal(size=(nobs, 1))
c2 = np.random.normal(2, 1, size=(nobs, 1))

# Estimate a bivariate distribution with continuous variables
dens_u = sm.nonparametric.KDEMultivariate(data=[c1, c2], var_type='cc', bw='normal_reference')
print(dens_u.bw)
```

This example estimates a bivariate distribution for two continuous variables and prints the bandwidth parameters found.

Kernel Functions for Nonparametric Regression
---------------------------------------------

Nonparametric regression methods often utilize kernel functions to weigh observations according to their distance from the target point. One such kernel is the Wang-Ryzin kernel, which is particularly suited for nonparametric regression involving discrete variables.

### Wang-Ryzin Kernel

The Wang-Ryzin kernel is defined as:

```
K_h(X_i, x) = h^{|X_i - x|}
```

where `h` is the bandwidth parameter, `X_i` is the observed value, and `x` is the target point. This kernel is recommended by Li and Racine (2007) for nonparametric regression with mixed data types.

Summary
-------

The nonparametric methods implemented here provide robust tools for density estimation and regression analysis without restrictive assumptions on the data distribution. By accommodating mixed data types and offering data-driven bandwidth selection, these methods enable flexible and accurate modeling in a wide range of applications.
