Discrete Models Module
======================

Overview
--------

This module provides implementations of zero-inflated count models and related discrete outcome models. These models are useful for count data exhibiting excess zeros or overdispersion, extending classical Poisson and Negative Binomial models.

The main classes included are:

- **ZeroInflatedPoisson**: Zero-inflated Poisson regression model.
- **ZeroInflatedGeneralizedPoisson**: Zero-inflated Generalized Poisson regression model.
- **ZeroInflatedNegativeBinomialP**: Zero-inflated Negative Binomial regression model.

These models combine a count data model with a binary inflation model to account for excess zeros.

Key Components
--------------

### GenericZeroInflated

A generic zero-inflated model for count data. It models the count process and the zero-inflation process separately.

Parameters
~~~~~~~~~~

- `endog` : array_like  
  The endogenous response variable (count data).

- `exog` : array_like  
  The exogenous design matrix for the count model.

- `exog_infl` : array_like or None  
  Explanatory variables for the zero-inflation model (binary inflation model). If None, a constant is used.

- `offset` : array_like  
  Offset added to the linear predictor with coefficient fixed at 1.

- `exposure` : array_like  
  Log(exposure) added to the linear predictor with coefficient fixed at 1.

- `inflation` : str, 'logit' or 'probit'  
  Specifies the model for zero inflation. Default is 'logit'.

- `missing` : str  
  Specifies how to handle missing data.

Attributes
~~~~~~~~~~

- `endog` : array  
  Endogenous response variable.

- `exog` : array  
  Exogenous design matrix for the count model.

- `exog_infl` : array  
  Exogenous design matrix for the zero-inflation model.

Methods
~~~~~~~

- `cdf(X)`  
  Cumulative distribution function of the model (to be implemented in subclasses).

- `pdf(X)`  
  Probability mass function of the model (to be implemented in subclasses).

- `summary()`  
  Summarizes the regression results including parameter estimates, standard errors, confidence intervals, and goodness-of-fit statistics.

- `fittedvalues`  
  Linear predictor values (Xβ).

- `resid_response`  
  Response residuals defined as observed minus predicted values.

- `aic`  
  Akaike Information Criterion for model comparison.

### Results Classes

The module also provides result classes for various models, inheriting from base discrete results classes:

- `L1PoissonResults`  
  Results class for L1-penalized Poisson regression.

- `L1NegativeBinomialResults`  
  Results class for L1-penalized Negative Binomial regression.

- `L1GeneralizedPoissonResults`  
  Results class for L1-penalized Generalized Poisson regression.

- `OrderedResults`  
  Results class for ordered discrete data models.

- `BinaryResults`  
  Results class for binary outcome models, including methods such as `pred_table()` to generate prediction tables.

Usage Notes
-----------

- Zero-inflated models are particularly useful when the data exhibit more zeros than expected under standard count models.

- The inflation model can be specified as either a logistic (logit) or probit regression.

- Marginal effects and other post-estimation tools are available through integration with statsmodels discrete margins functionality.

- The module handles missing data according to the specified `missing` parameter.

Warnings
--------

- Convergence warnings may be issued if the maximum likelihood estimation does not converge.

- Perfect separation in the inflation model can cause estimation issues and will raise errors.
