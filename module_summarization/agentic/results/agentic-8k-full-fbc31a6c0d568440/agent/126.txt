Data Component in an Image HDU
==============================

The `ImageHDU` class represents a FITS image extension HDU and contains the image data stored as a NumPy array. This data component is central to the `ImageHDU` and provides access to the pixel values of the image.

Initialization
--------------

When creating an `ImageHDU` instance, the `data` parameter can be provided as a NumPy array representing the image pixels. If no data is provided, the HDU may contain no image data.

```python
hdu = fits.ImageHDU(data=np.arange(100).reshape((10, 10)))
```

Data Scaling and Interpretation
-------------------------------

The image data can be optionally scaled using the FITS header keywords `BSCALE` and `BZERO`. By default, scaling is applied when reading the data, but this behavior can be controlled with the `do_not_scale_image_data` parameter:

- `do_not_scale_image_data=False` (default): The data is scaled according to `BSCALE` and `BZERO`.
- `do_not_scale_image_data=True`: The data is returned without scaling.

Additionally, the `uint` parameter controls whether signed integer data with `BZERO` and `BSCALE` values indicating unsigned integers should be interpreted as unsigned integers. This is enabled by default (`uint=True`).

Data Access and Modification
----------------------------

The image data is accessible via the `.data` attribute of the `ImageHDU` instance. This attribute behaves like a NumPy array and supports standard array operations.

```python
image_data = hdu.data
```

When writing the HDU back to a file, if the data was originally scaled, the `scale_back` parameter determines whether the data should be rescaled back to the original integer representation. This can prevent loss of precision when performing floating point operations on the data.

```python
hdu.writeto('image.fits', overwrite=True)
```

Data Verification
-----------------

The `ImageHDU` class includes verification methods to ensure the integrity of the data and header. For example, it checks that the header contains the correct `XTENSION` keyword with the value `"IMAGE"`, and that the `PCOUNT` and `GCOUNT` header keywords have appropriate values.

Usage Notes
-----------

- The `ImageHDU` class inherits from `_ImageBaseHDU` and `ExtensionHDU`, and is specifically designed to handle image data in FITS files.
- When reading data from a FITS file, if the primary HDU contains no data, the first extension HDU with image data will be used as a fallback.
- The data attribute may be temporarily replaced internally during certain operations (e.g., compression), but this is managed transparently.

Summary
-------

The data component of an `ImageHDU` is a NumPy array representing the image pixels stored in the FITS file. It supports scaling according to FITS conventions, can be accessed and modified directly, and integrates with the FITS header to maintain metadata consistency.
