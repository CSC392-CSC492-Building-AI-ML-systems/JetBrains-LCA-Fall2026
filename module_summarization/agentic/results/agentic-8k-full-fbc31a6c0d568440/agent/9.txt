Using Timers
============

Timers provide a convenient way to schedule the execution of code after a specified interval or repeatedly at fixed intervals. They are useful for performing periodic tasks, delaying execution, or implementing timeouts within your application.

Creating a Timer
----------------

To create a timer, you typically instantiate a timer object with a target function to be called when the timer expires. The timer can be configured to run once after a delay or repeatedly at a fixed interval.

Example:

```python
import threading

def my_task():
    print("Timer executed!")

# Create a timer that runs once after 5 seconds
timer = threading.Timer(5.0, my_task)
timer.start()
```

Starting and Stopping Timers
----------------------------

- **Starting a Timer:** Use the `start()` method to begin the countdown for the timer.
- **Stopping a Timer:** If you need to cancel a timer before it executes, use the `cancel()` method.

Example:

```python
timer = threading.Timer(10.0, my_task)
timer.start()

# Cancel the timer before it executes
timer.cancel()
```

Daemon Timers
-------------

Timers can be set as daemon threads, which means they will not prevent the program from exiting. This is useful for background tasks that should not block program termination.

Example:

```python
timer = threading.Timer(5.0, my_task)
timer.daemon = True
timer.start()
```

Use Cases for Timers
--------------------

- **Auto-connecting or reconnecting services:** For example, automatically connecting to an event hub in the background.
- **Periodic cleanup or maintenance tasks:** Clearing caches or closing unused connections.
- **Timeouts:** Implementing timeouts for network requests or operations.
- **Delayed execution:** Scheduling tasks to run after a delay.

Best Practices
--------------

- Always ensure timers are properly stopped or joined when your application exits to avoid dangling threads.
- Use daemon timers for background tasks that should not block program shutdown.
- Handle exceptions within timer callbacks to prevent silent failures.
- Use weak references or weak methods when registering callbacks to avoid preventing garbage collection of objects.

Example: Auto-Connecting Event Hub with Timer Thread
----------------------------------------------------

```python
import threading

def connect_event_hub():
    # Logic to connect to event hub
    pass

auto_connect_thread = threading.Thread(target=connect_event_hub)
auto_connect_thread.daemon = True
auto_connect_thread.start()
```

This approach allows the event hub to connect automatically in the background without blocking the main application flow.

Summary
-------

Timers are a powerful tool for scheduling and managing timed operations in your application. By leveraging timers, you can implement efficient, non-blocking, and responsive behaviors such as auto-reconnects, periodic maintenance, and delayed execution.
