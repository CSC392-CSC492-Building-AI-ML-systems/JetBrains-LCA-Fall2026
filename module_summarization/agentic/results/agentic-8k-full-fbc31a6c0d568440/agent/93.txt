Basics — Indexing and Structured Arrays
=======================================

This module provides utility functions for working with NumPy structured arrays and record arrays, focusing on indexing, flattening nested data types, and combining multiple arrays with complex dtypes.

Flattening Nested Data Types
----------------------------

Structured arrays in NumPy can have nested fields (fields that themselves have subfields). The function `flatten_descr(ndtype)` recursively flattens such nested dtype descriptions into a simple list of (fieldname, dtype) pairs.

Example:

```python
>>> from numpy.lib import recfunctions as rfn
>>> ndtype = np.dtype([('a', np.int32), ('b', [('ba', np.float64), ('bb', np.int32)])])
>>> rfn.flatten_descr(ndtype)
(('a', dtype('int32')), ('ba', dtype('float64')), ('bb', dtype('int32')))
```

Combining Data Types from Multiple Arrays
-----------------------------------------

The functions `_zip_dtype(seqarrays, flatten=False)` and `_zip_descr(seqarrays, flatten=False)` combine the dtype descriptions of a sequence of arrays into a single dtype description.

- `seqarrays` is a sequence of arrays whose dtypes are to be combined.
- `flatten` indicates whether nested dtype descriptions should be collapsed into a flat structure.

These utilities are useful when merging or concatenating arrays with structured dtypes.

Field Structure Mapping
-----------------------

The function `get_fieldstructure(adtype, lastname=None, parents=None)` returns a dictionary mapping each field name to a list of its parent fields, which helps in simplifying access to nested fields.

Example:

```python
>>> from numpy.lib import recfunctions as rfn
>>> ndtype = np.dtype([('A', int),
...                    ('B', [('BA', int),
...                           ('BB', [('BBA', int), ('BBB', int)])])])
>>> rfn.get_fieldstructure(ndtype)
{'A': [], 'B': [], 'BA': ['B'], 'BB': ['B'], 'BBA': ['B', 'BB'], 'BBB': ['B', 'BB']}
```

Iterators Over Fields and Records
---------------------------------

- `_izip_fields_flat(iterable)` returns an iterator over the concatenated fields of a sequence of arrays, flattening any nested structure.
- `_izip_fields(iterable)` returns an iterator over concatenated fields without necessarily flattening nested structures.
- `_izip_records(seqarrays, fill_value=None, flatten=True)` returns an iterator over concatenated items from a sequence of arrays, optionally flattening nested fields and filling shorter arrays with a specified fill value.

These iterators facilitate iteration over complex structured arrays in a flexible manner.

Summary
-------

This module is designed to assist with advanced indexing and manipulation of structured arrays in NumPy, particularly when dealing with nested fields. It provides tools to flatten nested dtypes, combine dtype descriptions from multiple arrays, map field hierarchies, and iterate over fields and records efficiently.
