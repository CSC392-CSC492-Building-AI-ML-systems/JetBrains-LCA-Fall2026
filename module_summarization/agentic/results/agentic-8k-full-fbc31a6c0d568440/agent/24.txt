w_init — Initialize a New WEST Simulation
==========================================

Synopsis
--------

.. code-block:: console

    w_init [OPTIONS]

Description
-----------

The `w_init` command initializes a new WEST simulation by creating the WEST HDF5 file and preparing the first iteration's segments.

Initial states for the simulation are generated from one or more *basis states*. These basis states can be specified in one of two ways:

- By providing a file containing basis states using the `--bstates-from` (or `--bstate-file`) option.
- By specifying one or more basis states directly on the command line using the `--bstate` option.

If neither `--bstates-from` nor at least one `--bstate` argument is provided, a default basis state will be created with probability one, identified by the state ID zero and labeled `"basis"`. A warning will be printed in this case to remind you of this default behavior.

For (non-equilibrium) steady-state simulations, *target states* can be specified similarly:

- By providing a file containing target states using the `--tstates-from` (or `--tstate-file`) option.
- By specifying one or more target states directly on the command line using the `--tstate` option.

If neither `--tstates-from` nor at least one `--tstate` argument is provided, the simulation will be run as an equilibrium simulation without any sinks.

Options
-------

- `--force`

  Overwrite any existing simulation data.

- `--bstates-from BSTATE_FILE`, `--bstate-file BSTATE_FILE`

  Read basis state names, probabilities, and optionally data references from the specified `BSTATE_FILE`.

- `--bstate 'label,probability[,auxref]'`

  Add a basis state specified as a string with the format `'label,probability[,auxref]'` to the list of basis states. This option may be specified multiple times to add multiple basis states. Basis states specified this way are appended after those read from a file (if any).

- `--tstates-from TSTATE_FILE`, `--tstate-file TSTATE_FILE`

  Read target state names and representative progress coordinates from the specified `TSTATE_FILE`. WESTPA uses the representative progress coordinate of a target state and converts the entire bin containing that progress coordinate into a recycling sink.

- `--tstate 'label,pcoord0[,pcoord1[,...]]'`

  Add a target state specified as a string with the format `'label,pcoord0[,pcoord1[,...]]'` to the list of target states. This option may be specified multiple times to add multiple target states. Target states specified this way are appended after those read from a file (if any).

- `--sstates-from SSTATE_FILE`, `--sstate-file SSTATE_FILE`

  Read start state names, probabilities, and optionally data references from the specified `SSTATE_FILE`.

- `--sstate 'label,probability[,auxref]'`

  Add a start state specified as a string with the format `'label,probability[,auxref]'` to the list of start states. This option may be specified multiple times to add multiple start states. Start states specified this way are appended after those read from a file (if any).

- `--segs-per-state N`

  Specify the number of segments to generate per state (default is 1).

Additional Configuration
------------------------

The command also accepts configuration options from the WESTPA runtime configuration system, which can be added via `westpa.rc.add_args(parser)`.

Examples
--------

Initialize a simulation with a basis state file and target states specified on the command line:

.. code-block:: console

    w_init --bstates-from basis_states.txt --tstate 'sink,1.0' --segs-per-state 5

Initialize a simulation with a single default basis state (warning will be issued):

.. code-block:: console

    w_init

Initialize a simulation with multiple basis states specified directly:

.. code-block:: console

    w_init --bstate 'state1,0.5' --bstate 'state2,0.5'

See Also
--------

- `w_run` — Run a WEST simulation
- `w_postanalysis` — Analyze WEST simulation results

Logging
-------

The `w_init` command logs messages under the logger named `w_init`, which can be configured for verbosity and output destination.

Notes
-----

- The basis states define the initial probability distribution of the system.
- Target states define recycling sinks for steady-state simulations.
- Start states can be used to specify initial conditions distinct from basis states.
- If no target states are specified, the simulation runs as an equilibrium simulation without sinks.

This command is typically the first step in setting up a WEST simulation workflow.
