Naive Bayes Classifiers
=======================

This module implements several variants of the Naive Bayes classifier, a family of simple probabilistic classifiers based on applying Bayes' theorem with strong (naive) independence assumptions between the features.

Overview
--------

Naive Bayes classifiers are particularly suited for high-dimensional data and are widely used in text classification and other applications. The module provides implementations for different types of Naive Bayes models tailored to various data distributions and feature types.

Classes
-------

BernoulliNB
~~~~~~~~~~~

A Naive Bayes classifier for multivariate Bernoulli models. It is suitable for binary/boolean features.

- **Parameters:**
  - `alpha` : float, default=1.0  
    Additive (Laplace/Lidstone) smoothing parameter.
  - `force_alpha` : bool or "warn", default=False  
    Controls behavior when alpha is very small.
  - `fit_prior` : bool, default=True  
    Whether to learn class prior probabilities or not.
  - `class_prior` : array-like of shape (n_classes,), default=None  
    Prior probabilities of the classes.

- **Attributes:**
  - `class_count_` : ndarray of shape (n_classes,)  
    Number of samples encountered for each class during fitting.
  - `feature_count_` : ndarray of shape (n_classes, n_features)  
    Number of times each feature appeared in samples of each class.
  - `feature_log_prob_` : ndarray of shape (n_classes, n_features)  
    Empirical log probability of features given a class, P(x_i|y).
  - `class_log_prior_` : ndarray of shape (n_classes,)  
    Log probability of each class (smoothed).

- **Notes:**
  - Requires input features to be non-negative.
  - Suitable for binary/boolean features.

MultinomialNB
~~~~~~~~~~~~~

A Naive Bayes classifier for multinomial models, typically used for discrete counts such as word counts in text classification.

- **Parameters:**
  - `alpha` : float, default=1.0  
    Additive (Laplace/Lidstone) smoothing parameter.
  - `force_alpha` : bool or "warn", default="warn"  
    Controls behavior when alpha is very small.
  - `fit_prior` : bool, default=True  
    Whether to learn class prior probabilities or not.
  - `class_prior` : array-like of shape (n_classes,), default=None  
    Prior probabilities of the classes.

- **Attributes:**
  - `class_count_` : ndarray of shape (n_classes,)  
    Number of samples encountered for each class during fitting.
  - `feature_count_` : ndarray of shape (n_classes, n_features)  
    Number of times each feature appeared in samples of each class.
  - `feature_log_prob_` : ndarray of shape (n_classes, n_features)  
    Empirical log probability of features given a class, P(x_i|y).
  - `class_log_prior_` : ndarray of shape (n_classes,)  
    Log probability of each class (smoothed).

- **Notes:**
  - Input features must be non-negative.
  - Suitable for count data.

ComplementNB
~~~~~~~~~~~

The Complement Naive Bayes classifier designed to correct the "severe assumptions" made by the standard Multinomial Naive Bayes classifier. It is particularly suited for imbalanced datasets.

- **Parameters:**
  - `alpha` : float or array-like of shape (n_features,), default=1.0  
    Additive (Laplace/Lidstone) smoothing parameter.
  - `force_alpha` : bool, default=False  
    Controls behavior when alpha is very small.
  - `fit_prior` : bool, default=True  
    Only used in edge cases with a single class in the training set.
  - `class_prior` : array-like of shape (n_classes,), default=None  
    Prior probabilities of the classes.
  - `norm` : bool, default=False  
    Whether or not a second normalization of the weights is performed.

- **Attributes:**
  - `class_count_` : ndarray of shape (n_classes,)  
    Number of samples encountered for each class during fitting.
  - `feature_count_` : ndarray of shape (n_classes, n_features)  
    Number of times each feature appeared in samples of each class.
  - `feature_log_prob_` : ndarray of shape (n_classes, n_features)  
    Empirical log probability of features given a class, P(x_i|y).
  - `class_log_prior_` : ndarray of shape (n_classes,)  
    Log probability of each class (smoothed).

CategoricalNB
~~~~~~~~~~~~~

A Naive Bayes classifier for categorical features. Each feature is assumed to be drawn from a categorical distribution.

- **Parameters:**
  - `alpha` : float, default=1.0  
    Additive (Laplace/Lidstone) smoothing parameter.
  - `force_alpha` : bool or "warn", default="warn"  
    Controls behavior when alpha is very small.
  - `fit_prior` : bool, default=True  
    Whether to learn class prior probabilities or not.
  - `class_prior` : array-like of shape (n_classes,), default=None  
    Prior probabilities of the classes.
  - `min_categories` : array-like or None, default=None  
    Minimum number of categories for each feature.

- **Attributes:**
  - `class_count_` : ndarray of shape (n_classes,)  
    Number of samples encountered for each class during fitting.
  - `feature_count_` : ndarray of shape (n_classes, n_features, n_categories)  
    Number of times each category appeared in samples of each class.
  - `feature_log_prob_` : ndarray of shape (n_classes, n_features, n_categories)  
    Empirical log probability of categories given a class.
  - `class_log_prior_` : ndarray of shape (n_classes,)  
    Log probability of each class (smoothed).
  - `n_categories_` : ndarray of shape (n_features,)  
    Number of categories for each feature.

- **Notes:**
  - Input features must be encoded as integers from 0 to n-1 for each feature.
  - Useful for categorical data where features are discrete categories.

Common Methods
--------------

- `fit(X, y, sample_weight=None)`  
  Fit the Naive Bayes classifier according to the training data.

- `partial_fit(X, y, classes=None, sample_weight=None)`  
  Incremental fit on a batch of samples. Useful for online learning or out-of-core learning.

- `predict(X)`  
  Perform classification on an array of test vectors X.

- `predict_log_proba(X)`  
  Return log-probability estimates for the test vector X.

- `predict_proba(X)`  
  Return probability estimates for the test vector X.

Examples
--------

BernoulliNB example:

```python
import numpy as np
from sklearn.naive_bayes import BernoulliNB

rng = np.random.RandomState(1)
X = rng.randint(5, size=(6, 100))
y = np.array([1, 2, 3, 4, 4, 5])

clf = BernoulliNB(force_alpha=True)
clf.fit(X, y)
print(clf.predict(X[2:3]))
```
