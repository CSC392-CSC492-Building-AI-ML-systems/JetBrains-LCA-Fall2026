cubes module
============

This module provides functions and classes to perform various transformations and visualizations on data cubes and their headers, primarily used in astronomical data analysis.

Overview
--------

The module includes utilities for manipulating FITS data cubes, handling World Coordinate System (WCS) information, and plotting maps and spectra interactively. It integrates with libraries such as Astropy, APLpy, and optionally SciPy for advanced interpolation and smoothing.

Key Features
------------

- **Interactive Map Plotting**: The `mapplot` function allows plotting of 2D maps extracted from 3D data cubes. The plots are interactive, supporting mouse and keyboard controls to explore spectra at selected pixels or regions.

- **Baseline Fitting**: The `blfunc_generator` function generates baseline fitting functions using polynomial or spline fits, useful for spectral data processing.

- **WCS Handling**: The module supports reading and flattening FITS headers and creating WCS objects for accurate celestial coordinate transformations.

- **Aperture Spectra Extraction**: Functions to extract and plot spectra from circular apertures within the data cube.

Interactive Map Plotting
------------------------

The `mapplot` method provides an interactive visualization of a map derived from a data cube. It supports:

- Selecting the map plane via the `makeplane` method.
- Interactive mouse controls:
  - **Left-click (Button 1) or '1' key**: Plot the spectrum of the selected pixel in a separate window and mark the pixel.
  - **Middle-click (Button 2) or 'o' key**: Overplot additional spectra on the existing plot.
  - **Right-click (Button 3)**: Disconnect the interactive viewer.
- Click-and-drag with the left mouse button to average spectra over a circular region.
- Keyboard shortcuts to define circular apertures by setting center ('c' key) and radius ('r' key).

Parameters for `mapplot` include:

- `convention`: Projection convention for Galactic data ('calabretta' or 'griesen').
- `colorbar`: Whether to display a colorbar.
- `useaplpy`: Use APLpy for plotting if a FITS header is available.
- `vmin`, `vmax`: Value range for the color scale.
- `cmap`: Colormap to use.
- `plotkwargs`: Additional keyword arguments passed to the plotting functions.

Baseline Fitting Function Generator
-----------------------------------

The `blfunc_generator` function creates a baseline fitting function that can be applied to spectral data arrays. It supports:

- Polynomial fitting of specified order.
- Spline fitting of specified order (requires SciPy).
- Optional downsampling of data before fitting.

Parameters:

- `x`: The x-axis values for the data; defaults to array indices if None.
- `polyorder`: Polynomial order for baseline fitting.
- `splineorder`: Spline order for baseline fitting.
- `sampling`: Sampling rate for downsampling data before fitting.

Usage Example:

```python
blfunc = blfunc_generator(polyorder=3)
baseline_corrected_data = blfunc((data_with_baseline, original_data))
```

Dependencies
------------

- **Astropy**: For FITS file handling and WCS transformations.
- **APLpy** (optional): For advanced FITS image plotting.
- **SciPy** (optional): For spline interpolation.
- **NumPy**: For numerical operations.
- **AG_fft_tools** (optional): For smoothing functions.

Additional Utilities
--------------------

- `copy`: Create a copy of the map plotter instance with uninitialized plotting axes and figures.
- `circle`: Plot the spectrum of a circular aperture defined by center and radius coordinates.

Notes
-----

- The module is designed to work with astronomical data cubes, typically FITS files containing spectral data.
- Interactive plotting requires a graphical backend compatible with Matplotlib and optionally APLpy.
- Some features depend on optional packages and will degrade gracefully if those packages are not installed.
