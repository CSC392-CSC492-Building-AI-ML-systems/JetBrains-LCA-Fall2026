Channel Options
===============

Channel options provide a flexible way to customize the behavior and appearance of channels in your visualizations. These options allow you to specify how data is bound to visual elements, control input elements, and configure rendering settings.

Common Channel Options
----------------------

- **name** (string, optional)  
  By default, the signal name is used to label input elements. This `name` property can be used instead to specify a custom label for the bound signal.

- **options** (array or string)  
  Specifies the set of allowable values for the channel. This can be an array of values or a string indicating the type of input control (e.g., `"radio"`, `"select"`).

- **labels** (array of strings, optional)  
  An array of label strings to represent the `options` values. If unspecified, the `options` values will be coerced to strings and used as labels.

Additional Parameters
---------------------

Additional parameters can be passed as keyword arguments to customize the behavior further. These parameters are also passed to underlying rendering engines such as vega-embed as options.

Examples of such parameters include:

- **renderer**  
  Specifies the renderer to use.

- **theme**  
  Defines the theme for the visualization.

- **actions**  
  Controls the display of action buttons or menus.

Using Channel Options
---------------------

Channel options can be specified directly when enabling plugins or configuring renderers. For example, when enabling a plugin, you can pass the plugin name and additional options as keyword arguments:

```python
plugin_enabler = enable_plugin(name="plugin_name", option1=value1, option2=value2)
```

The returned `PluginEnabler` object can be used as a context manager to temporarily enable the plugin with the specified options:

```python
with enable_plugin(name="plugin_name", option1=value1):
    # code that uses the plugin
```

Accessing the Active Plugin
---------------------------

You can retrieve the name of the currently active plugin using the `active` property:

```python
current_plugin = renderers.active
```

This allows you to query which plugin is currently enabled and adjust your code accordingly.

Summary
-------

Channel options provide a powerful mechanism to control how data channels behave and appear in your visualizations. By specifying options such as `name`, `options`, and `labels`, and by passing additional parameters to rendering engines, you can create highly customized and interactive visualizations.
