w_multi_west Command
====================

Overview
--------
`w_multi_west` is a command-line tool designed to combine multiple WESTPA simulations into a single dataset while properly accounting for reweighting. This tool facilitates the aggregation of simulation data, including auxiliary datasets, and supports options to control reweighting and the inclusion of specific data types.

Features
--------
- Combines multiple WESTPA simulation outputs.
- Supports reweighting of combined data to ensure accurate statistical representation.
- Allows inclusion of additional auxiliary datasets.
- Optionally combines all auxiliary datasets automatically.
- Supports combining of `ibstates` datasets.
- Provides progress indication during execution.

Usage
-----
Run the `w_multi_west` command with the desired options to combine simulation data.

Command-line Options
--------------------

Input/Output Options
~~~~~~~~~~~~~~~~~~~

- `-o`, `--output-file`  
  Specify the name of the output file to store the combined results.  
  Default: `multi.h5`

- `-W`, `--west`, `--WEST_H5FILE`  
  Specify the name of the main `west.h5` file inside each simulation directory.  
  Default: `west.h5`

- `-a`, `--aux`  
  Names of additional auxiliary datasets to be combined. Can be specified multiple times.

- `-aa`, `--auxall`  
  Combine all auxiliary datasets automatically.  
  Default: False

- `-nr`, `--no-reweight`  
  Disable reweighting of the combined data.  
  Default: False

- `-ib`, `--ibstates`  
  Attempt to combine the `ibstates` dataset.  
  Default: False

Progress Indicator
------------------
The tool includes a progress indicator component to provide feedback during long-running operations.

Functionality Details
---------------------
- The tool opens the specified WESTPA simulation files and reads their data.
- It calculates the total number of walkers across all simulations and iterations.
- When combining auxiliary datasets, it can either combine specified datasets or all available auxiliary datasets.
- Reweighting is applied by default to ensure the combined data accurately reflects the underlying statistical ensemble; this can be disabled with the `--no-reweight` option.
- The tool creates a new output file (default `multi.h5`) containing the combined data, including walkers, weights, and auxiliary information.
- Supports handling of iteration precision and metadata stamping for provenance.

Example
-------
Combine multiple WESTPA simulations stored in directories with default `west.h5` files, combining all auxiliary datasets and saving the result to `combined.h5`:

```bash
w_multi_west -o combined.h5 -aa
```

Combine simulations without reweighting and include specific auxiliary datasets `aux1` and `aux2`:

```bash
w_multi_west -o combined.h5 -a aux1 -a aux2 -nr
```

Notes
-----
- The tool assumes that the `istates` dataset is consistent across the combined simulations.
- It is designed to handle differences in the number of walkers between simulations gracefully.
- The output file is stamped with creator metadata for traceability.

For more detailed usage and advanced options, refer to the tool's help message:

```bash
w_multi_west --help
```
