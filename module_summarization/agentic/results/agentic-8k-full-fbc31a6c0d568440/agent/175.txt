Biclustering
============

Spectral Biclustering
---------------------

The Spectral Biclustering algorithm partitions the rows and columns of a data matrix simultaneously, assuming that the data exhibits an underlying checkerboard structure. This means that the data can be divided into biclusters, where each bicluster corresponds to a subset of rows and a subset of columns that exhibit similar behavior or characteristics.

For example, if there are two row partitions and three column partitions, each row will belong to three biclusters, and each column will belong to two biclusters. The checkerboard structure is represented by the outer product of the corresponding row and column label vectors.

This method is particularly useful in applications such as gene expression data analysis, where it is important to identify groups of genes and conditions that exhibit coherent patterns.

More detailed information and usage examples can be found in the :ref:`User Guide <spectral_biclustering>`.

Parameters
----------

- **n_clusters** : int or tuple (n_row_clusters, n_column_clusters), default=3  
  The number of row and column clusters in the checkerboard structure.

- **method** : {'bistochastic', 'scale', 'log'}, default='bistochastic'  
  Method of normalizing and converting singular vectors into biclusters.  
  - 'log' normalization is recommended by the authors but requires dense data (not sparse).  
  - 'bistochastic' is the default and works well with sparse data.  
  - 'scale' is another available option.

  .. warning::  
     If `method='log'`, the input data must not be sparse.

- **n_components** : int, default=6  
  Number of singular vectors to compute and consider.

- **n_best** : int, default=3  
  Number of best singular vectors to which the data is projected for clustering.

- **svd_method** : {'randomized', 'arpack'}, default='randomized'  
  Algorithm used to compute the singular value decomposition (SVD).  
  - 'randomized' uses a faster approximate method suitable for large matrices.  
  - 'arpack' uses a more accurate but potentially slower method.

- **n_svd_vecs** : int, default=None  
  Number of vectors used in the SVD calculation. Corresponds to `ncv` for 'arpack' and `n_oversamples` for 'randomized'.

- **mini_batch** : bool, default=False  
  Whether to use mini-batch k-means for clustering, which is faster but may yield different results.

- **init** : {'k-means++', 'random'} or ndarray of shape (n_clusters, n_features), default='k-means++'  
  Initialization method for the k-means algorithm.

- **n_init** : int, default=10  
  Number of random initializations for the k-means algorithm. The best initialization is selected.

- **random_state** : int, RandomState instance, default=None  
  Controls the randomness of the SVD and k-means initialization for reproducibility.

Attributes
----------

- **rows_** : array-like of shape (n_row_clusters, n_rows)  
  Boolean indicator matrix where `rows_[i, r]` is True if row `r` belongs to cluster `i`. Available after fitting.

- **columns_** : array-like of shape (n_column_clusters, n_columns)  
  Boolean indicator matrix for column clusters, analogous to `rows_`.

- **row_labels_** : array-like of shape (n_rows,)  
  Cluster labels for each row.

- **column_labels_** : array-like of shape (n_columns,)  
  Cluster labels for each column.

- **biclusters_** : tuple of two ndarrays  
  Tuple containing the `rows_` and `columns_` indicator matrices.

- **n_features_in_** : int  
  Number of features seen during fitting.

- **feature_names_in_** : ndarray of shape (n_features_in_,)  
  Names of features seen during fitting, if available.

Examples
--------

>>> from sklearn.cluster import SpectralBiclustering
>>> import numpy as np
>>> X = np.array([[1, 1], [2, 1], [1, 0],
...               [4, 7], [3, 5], [3, 6]])
>>> clustering = SpectralBiclustering(n_clusters=2, random_state=0).fit(X)
>>> clustering.row_labels_
array([1, 1, 1, 0, 0, 0], dtype=int32)
>>> clustering.column_labels_
array([1, 0], dtype=int32)
>>> clustering
SpectralBiclustering(n_clusters=2, random_state=0)
