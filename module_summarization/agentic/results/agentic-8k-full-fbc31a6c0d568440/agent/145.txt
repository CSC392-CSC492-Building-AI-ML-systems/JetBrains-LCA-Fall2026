File Objects
============

File objects represent HDF5 files and provide an interface for creating, accessing, and managing the contents of these files. They serve as the root container for groups, datasets, and other HDF5 objects.

Constants
---------

- `H5F_LIBVER_EARLIEST`  
  Use the earliest possible format for storing objects.

- `H5F_LIBVER_LATEST`  
  Use the latest possible format available for storing objects.

Property Lists
--------------

File objects utilize property lists to control various aspects of file creation and access. These property lists are represented by specialized classes:

- `PropFCID`  
  File creation property list. Used to specify parameters when creating a new file.

- `PropFAID`  
  File access property list. Used to control file access properties such as caching and driver settings.

Property List Classes Hierarchy
-------------------------------

- `PropID`  
  Base class for property lists.

- `PropInstanceID`  
  Represents an instance of a property list class (an actual list that can be passed to API functions).

- `PropCreateID`  
  Base class for all object creation lists, including string character set methods.

- `PropOCID`  
  Object creation property list.

- `PropDCID`  
  Dataset creation property list.

- `PropFCID`  
  File creation property list.

- `PropFAID`  
  File access property list.

- `PropDXID`  
  Dataset transfer property list.

Link Types
----------

File objects support different types of links, which are references to objects within the file:

- `TYPE_HARD`  
  Hard link.

- `TYPE_SOFT`  
  Soft (symbolic) link.

- `TYPE_EXTERNAL`  
  External link.

Link Information
----------------

The `LinkInfo` class provides information about links within the file:

- `type`  
  Integer type code for the link (one of the `TYPE_*` constants).

- `corder_valid`  
  Boolean indicating if the creation order is valid.

Dataspace Constants
-------------------

Dataspaces describe the layout of data in datasets:

- `UNLIMITED`  
  Represents an unlimited dimension size.

Dataspace Classes
-----------------

Dataspace classes define the type of dataspace:

- `NO_CLASS`  
  No dataspace class.

- `SCALAR`  
  Scalar dataspace.

- `SIMPLE`  
  Simple dataspace.

- `NULL`  
  Null dataspace.

Selection Types
---------------

Dataspace selection types specify how data is selected within a dataspace:

- `SEL_ERROR`  
  Selection error.

- `SEL_NONE`  
  No selection.

- `SEL_POINTS`  
  Selection by points.

- `SEL_HYPERSLABS`  
  Selection by hyperslabs.

- `SEL_ALL`  
  Select all elements.

Copying Objects
---------------

File objects support copying with various flags to control the behavior:

- `COPY_EXPAND_SOFT_LINK_FLAG`  
  Expand soft links into new objects.

- `COPY_EXPAND_EXT_LINK_FLAG`  
  Expand external links into new objects.

- `COPY_EXPAND_REFERENCE_FLAG`  
  Copy objects that are pointed to by references.

- `COPY_WITHOUT_ATTR_FLAG`  
  Copy object without copying attributes.

These flags can be set and retrieved using property list methods.

Usage Notes
-----------

- File objects are the entry point for accessing groups, datasets, and other objects within an HDF5 file.

- Property lists allow fine control over file creation and access parameters.

- Link types and link information provide mechanisms to manage references within the file.

- Dataspaces and selection types define how data is organized and accessed.

- Copying flags enable flexible duplication of objects within or between files.

This documentation summarizes the key classes, constants, and concepts related to File Objects in the HDF5 interface.
