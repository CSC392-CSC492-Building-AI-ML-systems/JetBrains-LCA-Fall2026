Compatibility Policy
====================

This document outlines the compatibility policy for the random number generation API.

Overview
--------

The random number generation API has undergone significant changes to improve functionality, performance, and usability. As a result, some functions and interfaces from the legacy API have been removed or replaced in the new API. Users are encouraged to migrate to the new API to benefit from these improvements.

Legacy Functions Removed
------------------------

The following functions from the legacy API have been removed and are no longer supported:

==================== =========================================================
Function             Description
==================== =========================================================
rand                 Uniformly distributed values.
randn                Normally distributed values.
ranf                 Uniformly distributed floating point numbers.
random_integers      Uniformly distributed integers in a given range.
                     (deprecated, use ``integers(..., closed=True)`` instead)
random_sample        Alias for `random_sample`
randint              Uniformly distributed integers in a given range.
seed                 Seed the legacy random number generator.
==================== =========================================================

Users should transition to the new API equivalents, such as the `Generator` class and its methods, which provide more consistent and flexible interfaces.

==================== =========================================================

==================== =========================================================

==================== =========================================================

Compatibility Notes
-------------------

- The new API does not guarantee backward compatibility with the legacy API.
- Users should avoid relying on deprecated functions and migrate to the new `Generator` class and its methods.
- The `Generator` class provides a unified interface for random number generation, supporting various distributions and flexible output shapes.
- Deprecated functions such as `random_integers` have recommended replacements (e.g., `integers(..., closed=True)`).
- Seeding and state management are handled differently in the new API; users should use the `seed` method of the `Generator` class and the `get_state`/`set_state` functions accordingly.
