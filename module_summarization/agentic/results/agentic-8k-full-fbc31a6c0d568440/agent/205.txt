Stochastic Gradient Descent (SGD)
=================================

Overview
--------

Stochastic Gradient Descent (SGD) is an efficient and scalable optimization algorithm commonly used for training linear models such as classifiers and regressors. It is particularly well-suited for large-scale and sparse datasets. SGD updates model parameters incrementally by iterating over training samples and performing gradient updates, which often leads to faster convergence compared to batch gradient descent.

Implemented Estimators
----------------------

The following estimators based on SGD are provided:

- **SGDClassifier**: Linear classifiers (such as SVM, logistic regression) trained with SGD.
- **SparseSGDClassifier**: Sparse variant of SGDClassifier optimized for sparse input data.
- **SGDRegressor**: Linear regression models trained with SGD.
- **SparseSGDRegressor**: Sparse variant of SGDRegressor optimized for sparse input data.
- **SGDOneClassSVM**: One-class SVM trained with SGD for anomaly detection.
- **SparseSGDOneClassSVM**: Sparse variant of SGDOneClassSVM.

These estimators support various loss functions and penalties, allowing flexibility in modeling.

Key Features
------------

- **Incremental Learning**: Supports `partial_fit` method for online learning and handling large datasets in mini-batches.
- **Sparse Data Support**: Efficient handling of sparse input matrices using CSR format.
- **Multiple Learning Rate Schedules**: Supports constant, optimal, inverse scaling, and adaptive learning rates.
- **Warm Start**: Allows reusing previous solution as initialization for further training.
- **Intercept and Offset Initialization**: Supports initializing intercept or offset terms to improve convergence.
- **Multi-class Support**: Implements one-vs-all strategy for multi-class classification.
- **Numerical Stability**: Consistent results across different floating-point precisions (float32 and float64).
- **Verbose Output**: Optional verbosity for monitoring training progress.

Usage Examples
--------------

### Classification

```python
from your_module import SGDClassifier
import numpy as np

X = np.array([[-2, -1], [-1, -1], [-1, -2], [1, 1], [1, 2], [2, 1]])
Y = [1, 1, 1, 2, 2, 2]

clf = SGDClassifier(alpha=0.01, max_iter=1000, tol=1e-3)
clf.fit(X, Y)

predictions = clf.predict(np.array([[0, 0], [1, 1]]))
```

### Regression

```python
from your_module import SGDRegressor
import numpy as np

X = np.array([[0, 0], [1, 1], [2, 2]])
y = np.array([0, 1, 2])

reg = SGDRegressor(max_iter=1000, tol=1e-3)
reg.fit(X, y)

predictions = reg.predict(np.array([[1.5, 1.5]]))
```

### One-Class SVM for Anomaly Detection

```python
from your_module import SGDOneClassSVM
import numpy as np

X = np.array([[0, 0], [1, 1], [2, 2]])

oc_svm = SGDOneClassSVM(max_iter=1000)
oc_svm.fit(X)

scores = oc_svm.decision_function(np.array([[1, 1], [3, 3]]))
```

API Highlights
--------------

- **fit(X, y, \*\*fit_params)**: Fit the model to data matrix `X` and target `y`.
- **partial_fit(X, y, \*\*fit_params)**: Incrementally fit the model on a batch of samples.
- **predict(X)**: Predict target values for samples in `X`.
- **decision_function(X)**: Compute the decision function for samples in `X` (available for classifiers).
- **coef_**: Model coefficients after fitting.
- **intercept_**: Intercept term after fitting.
- **t_**: Number of iterations over the training data.

Parameters
----------

Common parameters across SGD estimators include:

- **alpha**: Regularization term (float, default=0.0001).
- **max_iter**: Maximum number of passes over the training data (int).
- **tol**: Stopping criterion tolerance (float).
- **learning_rate**: Learning rate schedule (`'constant'`, `'optimal'`, `'invscaling'`, `'adaptive'`).
- **early_stopping**: Whether to use early stopping to terminate training when validation score is not improving.
- **shuffle**: Whether to shuffle training data before each epoch.
- **intercept_init / offset_init**: Initial value for intercept or offset.
- **verbose**: Verbosity level.

Notes
-----

- The `partial_fit` method does not support early stopping.
- For multi-class classification, the estimators use a one-vs-all approach.
- The estimators handle both dense and sparse input data efficiently.
- The `predict_proba` and `predict_log_proba` methods are available only for certain loss functions (e.g., logistic loss).
- Proper initialization of intercept or offset can improve convergence speed.
- SGD estimators are tested for numerical consistency across data types and support warm starts.

Testing and Validation
----------------------

The SGD estimators have been extensively tested with various datasets, including:

- Synthetic datasets with multiple classes and features.
- Sparse datasets with redundant feature groups.
- Real-world datasets such as the Iris dataset.
- Different data types (`float32` and `float64`) to ensure numerical stability.
- Various learning rate schedules and warm start scenarios.
