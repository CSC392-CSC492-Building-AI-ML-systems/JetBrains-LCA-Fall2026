Controlling Chunking
====================

When working with large arrays, chunking is a fundamental technique that divides the array into smaller, more manageable pieces called chunks. Proper control over chunking can significantly impact performance, memory usage, and computational efficiency.

This section describes key functions and concepts related to controlling chunking in arrays.

Partitioning and Chunking Utilities
-----------------------------------

### `partition_by_size(sizes, seq)`

Partitions a sequence `seq` into chunks according to specified `sizes`.

**Parameters:**

- `sizes` : list of int  
  Sizes of each chunk.
- `seq` : array-like  
  Sequence to partition.

**Returns:**

- List of arrays, each corresponding to a chunk of the original sequence adjusted by the chunk offset.

**Example:**

```python
>>> partition_by_size([10, 20, 10], [1, 5, 9, 12, 29, 35])
[array([1, 5, 9]), array([ 2, 19]), array([5])]
```

This function is useful for dividing indices or data points into chunks based on predefined chunk sizes.

### `issorted(seq)`

Checks if a sequence is sorted in non-decreasing order.

**Parameters:**

- `seq` : sequence  
  Sequence to check.

**Returns:**

- `True` if sorted, `False` otherwise.

**Example:**

```python
>>> issorted([1, 2, 3])
True
>>> issorted([3, 1, 2])
False
```

### `slicing_plan(chunks, index)`

Constructs a slicing plan to extract data from chunks using a given index.

**Parameters:**

- `chunks` : tuple of int  
  Chunk sizes along one dimension.
- `index` : np.ndarray[int]  
  Indices to slice on that dimension.

**Returns:**

- List of tuples `(chunk_index, sub_index)` where `chunk_index` is the chunk number and `sub_index` is the adjusted index within that chunk.

This function helps map global indices to chunk-local indices, enabling efficient data retrieval from chunked arrays.

Indexing and Data Retrieval
---------------------------

### `getitem(obj, index)`

Retrieves a selection from an array-like object with memory efficiency considerations.

**Parameters:**

- `obj` : ndarray, string, tuple, list  
  Object to index.
- `index` : int, list[int], slice  
  Selection to extract.

**Returns:**

- The selected subset `obj[index]`.

**Details:**

- If the selection is smaller than half the size of the original array, a copy is made to avoid excessive memory usage.
- Raises a `ValueError` if the chunk size or shape is unknown, suggesting the use of `compute_chunk_sizes()`.

Chunk Size Computation and Management
------------------------------------

### `compute_chunk_sizes()`

Some operations require knowledge of chunk sizes. When chunk sizes are unknown, functions may raise errors advising to call `compute_chunk_sizes()` on the array first.

This method computes and caches chunk sizes, enabling subsequent operations like reductions or reshaping to proceed without errors.

Backend and Array Creation Utilities
-----------------------------------

### `to_backend(x, backend=None, **kwargs)`

Moves an array collection `x` to a specified backend.

**Parameters:**

- `x` : Array  
  Input array collection.
- `backend` : str, optional  
  Target backend name. Defaults to the current configuration.

**Returns:**

- A new array collection on the specified backend.

### `empty_like(a, dtype=None, order='C', chunks=None, name=None, shape=None)`

Creates a new empty array with the same shape and type as `a`.

**Parameters:**

- `a` : array_like  
  Reference array.
- `dtype` : data-type, optional  
  Overrides the data type.
- `order` : {'C', 'F'}, optional  
  Memory layout order.
- `chunks` : tuple or dict, optional  
  Chunking specification.
- `name` : str, optional  
  Name for the new array.
- `shape` : tuple, optional  
  Shape of the new array.

Controlling chunking through these utilities allows for efficient manipulation and computation on large arrays by leveraging chunk-wise operations.

Summary
-------

- Chunking divides large arrays into smaller pieces for efficient computation.
- Functions like `partition_by_size` and `slicing_plan` help manage and map indices to chunks.
- `getitem` provides memory-efficient data retrieval from chunked arrays.
- Computing chunk sizes explicitly with `compute_chunk_sizes()` is necessary for some operations.
- Backend utilities facilitate moving arrays between different computational backends.
- Creating arrays with specified chunking is supported via functions like `empty_like`.

Proper control and understanding of chunking mechanisms are essential for optimizing performance and resource usage in array computations.
