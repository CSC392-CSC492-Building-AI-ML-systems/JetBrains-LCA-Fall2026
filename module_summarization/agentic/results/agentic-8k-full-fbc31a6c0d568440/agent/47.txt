Contingency Tables Module
=========================

Overview
--------

This module provides methods for analyzing two-way contingency tables, which are frequency tables for observations cross-classified with respect to two categorical variables. It supports general two-way tables, square tables, 2x2 tables, and collections of 2x2 tables stratified by a third variable.

Main Classes
------------

- **Table**  
  Represents a general two-way contingency table. Provides methods for analysis applicable to any two-way table, including tests of independence and symmetry.

- **SquareTable**  
  Extends `Table` for square contingency tables (same categories for rows and columns). Implements methods specific to square tables, such as tests for symmetry and homogeneity of marginal distributions.

- **Table2x2**  
  Specialized class for 2x2 contingency tables. Implements methods tailored to 2x2 tables, including exact tests like McNemar's test.

- **StratifiedTable**  
  Handles collections of 2x2 contingency tables stratified by a third variable. Implements Cochran-Mantel-Haenszel and Breslow-Day procedures for analyzing stratified 2x2 tables.

Functions
----------

- **McNemar's Test**  
  Conducts McNemar's test for paired nominal data in 2x2 tables.

- **Cochran's Q Test**  
  Performs Cochran's Q test for related samples with binary outcomes.

Key Features and Notes
-----------------------

- The module assumes that observed units are independent and identically distributed unless otherwise specified.

- For tables containing zero counts, an option is available to add 0.5 to all cells to avoid issues with certain statistical calculations.

- The inference procedures rely on sampling models appropriate for categorical data analysis.

- The module includes utility functions such as `_make_df_square` to convert pandas DataFrames into square tables by aligning row and column indices.

- Statistical tests implemented include:
  - Tests of independence for general two-way tables.
  - Symmetry tests for square tables (e.g., Bowker's test).
  - Homogeneity tests comparing row and column marginal distributions.
  - Exact and asymptotic tests for 2x2 tables.
  - Cochran-Mantel-Haenszel test for stratified 2x2 tables.

Usage Examples
--------------

Creating a Table from raw data:

```python
import pandas as pd
from statsmodels.stats.contingency_tables import Table

data = pd.DataFrame({
    'var1': [...],
    'var2': [...],
})

table = Table.from_data(data)
print(table)
```

Performing a symmetry test on a square table:

```python
square_table = SquareTable(your_square_data)
result = square_table.symmetry(method='bowker')
print(f"Statistic: {result.statistic}, p-value: {result.pvalue}")
```

Analyzing stratified 2x2 tables:

```python
stratified = StratifiedTable(list_of_2x2_tables)
cmh_result = stratified.cochran_mantel_haenszel()
print(cmh_result)
```
