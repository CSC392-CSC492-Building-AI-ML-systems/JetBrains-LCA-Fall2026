Polys Module Documentation
==========================

Overview
--------

The `polys` module provides advanced polynomial manipulation and root isolation functionalities over various domains including integers, rationals, and algebraic fields. It includes methods for generating minimal polynomials, isolating real and complex roots of polynomials, and handling polynomial factorization and square-free decomposition.

Key Features
------------

Minimal Polynomial Generation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- The module includes functionality to generate minimal polynomials for algebraic numbers such as roots of trigonometric expressions.
- For example, the roots of the polynomial \( mp(x) \) are given by \(\sin(\pi p/q)\) for \(p = 1, \ldots, q - 1\).
- Special cases are handled, such as when the numerator of a rational number is 1 and the denominator is 9, returning a specific polynomial:
  
  \[
  64x^6 - 96x^4 + 36x^2 - 3
  \]

- For odd degrees \(n\), minimal polynomials are related to Chebyshev polynomials of the first kind, leveraging the identity \(\sin(q a) = 0\).

Polynomial Domain Handling and GCD Computation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- Polynomials are normalized to a specified domain, with denominators cleared to ensure integral coefficients.
- The module supports computation of the greatest common divisor (GCD) of polynomials within the given domain.
- Zero roots are detected and handled appropriately depending on the interval of interest.
- Factorization is performed using square-free decomposition and trial division to extract irreducible factors and their multiplicities.
- Factors are stored in a dictionary mapping each factor to its multiplicities in the input polynomials.

Root Isolation
~~~~~~~~~~~~~~

- The module provides methods to isolate both real and complex roots of polynomials.
- Root isolation supports square-free polynomials as well as non-square-free polynomials, although the latter currently supports only trivial cases.
- Isolation intervals are computed with optional parameters for precision (`eps`), and bounds (`inf`, `sup`).
- The isolation process returns sorted intervals for negative, zero, and positive roots, with zero roots handled distinctly when applicable.
- Complex root isolation complements real root isolation to provide a comprehensive root analysis.

Example usage of root isolation methods:

```python
real_roots, complex_roots = ring._isolate_all_roots_sqf(f, eps=1e-6)
```

Polynomial Decomposition into Real and Imaginary Parts
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- The module includes functionality to decompose a polynomial with complex coefficients into its real and imaginary parts.
- Given a polynomial \( f \), it returns two bivariate polynomials \( f_1 \) and \( f_2 \) such that:

  \[
  f = f_1 + f_2 \cdot i
  \]

- This is useful for symbolic manipulation and analysis of polynomials over complex domains.

Example:

```python
R, x = ring('x', ZZ)
f_real, f_imag = R._real_imag(x**3 + x**2 + x + 1)
```

Error Handling
--------------

- The module raises `DomainError` when operations such as root isolation are attempted over unsupported domains.
- NotImplementedError is raised for unsupported polynomial cases, such as non-trivial non-square-free polynomials in root isolation.

Summary
-------

The `polys` module is a powerful toolkit for polynomial algebra, focusing on root isolation, factorization, and minimal polynomial generation. It supports a variety of algebraic domains and provides robust methods for handling complex polynomial operations essential in symbolic computation and algebraic number theory.
