Sync Users with LDAP
====================

This module provides functionality to synchronize users with an LDAP directory using the Ftrack API. It enables the execution of delayed jobs on the server to perform user synchronization tasks efficiently.

Delayed Job Execution
---------------------

The `delayed_job` method allows you to execute a delayed job on the server. It returns a `ftrack.entity.job.Job` instance representing the job that was started.

**Usage:**

```python
job = session.delayed_job(ftrack_api.symbol.JOB_SYNC_USERS_LDAP)
```

- `job_type` must be one of the predefined job types, specifically `JOB_SYNC_USERS_LDAP` for syncing users with LDAP.
- If an invalid job type is provided, a `ValueError` will be raised.

This method internally calls the server with the action `'delayed_job'` and the specified job type name. If the server returns an error, it will be propagated.

User Invitation
---------------

The module also supports sending invitations to users.

- `send_user_invite(user)`: Sends an invitation to a single user.
- `send_user_invites(users)`: Sends invitations to a list of users.

Both methods expect `user` or `users` to be instances of the User class.

Example:

```python
session.send_user_invite(user)
session.send_user_invites([user1, user2])
```

Additional Features
-------------------

While the primary focus is on LDAP user synchronization, the module also includes other utility methods such as:

- `get_widget_url(name, entity=None, theme=None)`: Returns an authenticated URL for a widget with the specified name and options.
- `encode_media(media, version_id=None, keep_original='auto')`: Creates a job to encode media files for browser compatibility.

These methods support broader integration and customization within the Ftrack environment.

Error Handling
--------------

- If the server does not support the requested action (e.g., `get_widget_url`), a `ServerCompatibilityError` is raised with a message indicating the required server version.
- Server errors during job execution are raised as `ServerError` exceptions.

Summary
-------

This module facilitates the synchronization of users with LDAP through server-side delayed jobs, providing a robust and scalable approach to user management within Ftrack. It also supports user invitation workflows and additional utility functions to enhance integration capabilities.
