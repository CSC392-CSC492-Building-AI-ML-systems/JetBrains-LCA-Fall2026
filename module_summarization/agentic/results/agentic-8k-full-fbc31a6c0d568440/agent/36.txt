w_succ — List Successful (Recycled) Segments
=============================================

Synopsis
--------

.. code-block:: console

    w_succ [OPTIONS]

Description
-----------

The `w_succ` command lists segments from WESTPA simulations that have successfully reached a target state, i.e., segments that were recycled during the simulation. This tool outputs information about these successful segments for each iteration up to the current iteration.

The output includes the iteration number, segment ID, segment weight, and the final progress coordinate values for each successful segment.

Options
-------

- `-o, --output OUTPUT_FILE`  
  Store the output in the specified `OUTPUT_FILE`. By default, the output is written to standard output.

Additional options are available through WESTPA's runtime configuration system and the analysis tool's common arguments.

Output Format
-------------

The output consists of columns with the following information:

- **Column 0:** Iteration number  
- **Column 1:** Segment ID  
- **Column 2:** Segment weight  
- **Columns >2:** Final progress coordinate values for the segment

The output begins with header lines describing the columns:

    # successful (recycled) segments
    # column 0:    iteration
    # column 1:    seg_id
    # column 2:    weight
    # column>2:    final progress coordinate value

Example
-------

To list successful segments and write the output to a file named `success_segments.txt`:

.. code-block:: console

    w_succ -o success_segments.txt

Notes
-----

- The command processes all iterations from 1 up to (but not including) the current iteration.
- Only segments marked as recycled (successful) are included in the output.
- The progress coordinate values are formatted according to their data types for readability.
