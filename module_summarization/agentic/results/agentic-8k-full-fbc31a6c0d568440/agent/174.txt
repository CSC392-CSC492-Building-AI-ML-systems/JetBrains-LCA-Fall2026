Array API Support
=================

This section documents the support for the [Array API standard](https://data-apis.org/array-api/latest/) within the library, including the mechanisms for detecting compliance, wrapping array namespaces, and ensuring compatibility across different array libraries.

Overview
--------

The library provides comprehensive support for the Array API standard, enabling interoperability with array libraries that implement the standard interface, such as `numpy.array_api`, `cupy.array_api`, and others. This support includes:

- Detection of Array API compliance for given arrays.
- Wrapping of array namespaces to provide a consistent API surface.
- Utilities for array creation, type conversion, and operations that respect the Array API.
- Testing and validation to ensure correct behavior with compliant array libraries.

Namespace Detection and Compliance
----------------------------------

The function `get_namespace` is used to retrieve the array namespace for given arrays and to check whether the arrays are compliant with the Array API standard. When called with an Array API-compliant array, it returns a wrapped namespace object and a flag indicating compliance.

Example usage:

```python
xp = pytest.importorskip("numpy.array_api")
X_np = numpy.asarray([[1, 2, 3]])
X_xp = xp.asarray(X_np)

with config_context(array_api_dispatch=True):
    xp_out, is_array_api_compliant = get_namespace(X_xp)
    assert is_array_api_compliant
    assert isinstance(xp_out, _ArrayAPIWrapper)
```

The wrapper `_ArrayAPIWrapper` ensures that the returned namespace behaves consistently with the Array API, even when wrapping namespaces that may have slight variations.

Adjustable Namespace Wrapper
----------------------------

For testing purposes, the class `_AdjustableNameAPITestWrapper` extends `_ArrayAPIWrapper` to allow setting a custom `__name__` attribute on the wrapped namespace. This is useful for simulating different array API namespaces and verifying behavior under various conditions.

Array API Wrapper Features
--------------------------

The `_ArrayAPIWrapper` class provides several key features:

- Supports array creation and type conversion methods such as `asarray` and `astype`.
- Implements array operations like `take` with validation of supported axes and dimensions.
- Ensures that arrays returned from operations carry the `__array_namespace__` attribute, indicating their compliance with the Array API.
- Provides fast paths for known namespaces such as `numpy.array_api` to optimize performance.

Example of type conversion:

```python
numpy_array_api = pytest.importorskip("numpy.array_api")
xp_ = _AdjustableNameAPITestWrapper(numpy_array_api, "wrapped_numpy.array_api")
xp = _ArrayAPIWrapper(xp_)

X = xp.asarray([[1, 2, 3], [3, 4, 5]], dtype=xp.float64)
X_converted = xp.astype(X, xp.float32)
assert X_converted.dtype == xp.float32
```

Array Operations and Validation
-------------------------------

The wrapper supports operations such as `take` with axis validation:

- Only axes 0 and 1 are supported.
- Only arrays with 1 or 2 dimensions are supported.

Invalid usage raises appropriate exceptions:

```python
with pytest.raises(ValueError, match=r"Only axis in \(0, 1\) is supported"):
    xp.take(X, xp.asarray([0]), axis=2)

with pytest.raises(ValueError, match=r"Only X.ndim in \(1, 2\) is supported"):
    xp.take(xp.asarray([[[0]]]), xp.asarray([0]), axis=0)
```

Array Creation with Memory Order
-------------------------------

The utility function `_asarray_with_order` respects the `order` parameter for NumPy arrays, allowing creation of arrays with specified memory layout (C-contiguous or Fortran-contiguous). For generic Array API arrays, the `order` parameter is ignored, as memory layout control is not part of the standard.

Example:

```python
xp = pytest.importorskip("numpy")
X = xp.asarray([1.2, 3.4, 5.1])
X_new = _asarray_with_order(X, order="F", xp=xp)

X_new_np = numpy.asarray(X_new)
assert X_new_np.flags["F_CONTIGUOUS"]
```

For generic Array API arrays:

```python
xp = pytest.importorskip("numpy.array_api")
xp_ = _AdjustableNameAPITestWrapper(xp, "wrapped.array_api")

X = numpy.asarray([[1.2, 3.4, 5.1], [3.4, 5.5, 1.2]], order="C")
X = xp_.asarray(X)

X_new = _asarray_with_order(X, order="F", xp=xp_)

X_new_np = numpy.asarray(X_new)
assert X_new_np.flags["C_CONTIGUOUS"]
assert not X_new_np.flags["F_CONTIGUOUS"]
```

Estimator Compatibility
-----------------------

The library supports converting estimators to work with Array API arrays by converting internal arrays to the target namespace. This ensures that estimators can operate seamlessly with arrays from different compliant libraries.

Example:

```python
X_np = numpy.asarray([[1.3, 4.5]])
est = SimpleEstimator().fit(X_np)

new_est = _estimator_with_converted_arrays(est, lambda array: xp.asarray(array))
assert hasattr(new_est.X_, "__array_namespace__")
```

Reshape Behavior
---------------

The `reshape` method in the NumPy API wrapper respects the `copy` parameter and requires the shape argument to be a tuple. It raises a `TypeError` if the shape is not a tuple.

Example:

```python
xp = _NumPyAPIWrapper()
X = xp.asarray([[1, 2, 3], [3, 4, 5]])

X_no_copy = xp.reshape(X, (-1,), copy=False)
assert X_no_copy.base is X

X_copy = xp.reshape(X, (6, 1), copy=True)
assert X_copy.base is not X.base

with pytest.raises(TypeError, match="shape must be a tuple"):
    xp.reshape(X, -1)
```

Summary
-------

The library's Array API support ensures compatibility and interoperability with multiple array libraries adhering to the Array API standard. Through namespace detection, wrapping, and utility functions, it provides a consistent and robust interface for array operations, facilitating the development of portable and efficient numerical code.
