w_kinetics — Calculate state-to-state kinetics by tracing trajectories
=======================================================================

Description
-----------

The `w_kinetics` command calculates state-to-state rates and transition event durations by tracing trajectories.

A bin assignment file (usually named `assign.h5`) that includes trajectory labeling is required to run this command. For information on generating this file, see the documentation for the `w_assign` tool (`w_assign --help`).

The output generated by `w_kinetics` is intended to be used as input for the `w_kinavg` tool, which converts the flux data into average rates with confidence intervals. For more information, see `w_kinavg trace --help`.

Output Format
-------------

The output file (specified with `-o` or `--output`, default: `kintrace.h5`) contains the following datasets:

- **`/conditional_fluxes`** `[iteration][state][state]`  
  *(Floating-point)* Macrostate-to-macrostate fluxes. These values are **not** normalized by the population of the initial macrostate.

- **`/conditional_arrivals`** `[iteration][stateA][stateB]`  
  *(Integer)* Number of trajectories arriving at state *stateB* in a given iteration, given that they departed from *stateA*.

- **`/total_fluxes`** `[iteration][state]`  
  *(Floating-point)* Total flux into a given macrostate.

- **`/arrivals`** `[iteration][state]`  
  *(Integer)* Number of trajectories arriving at a given state in a given iteration, regardless of their origin.

- **`/duration_count`** `[iteration]`  
  *(Integer)* The number of event durations recorded in each iteration.

- **`/durations`** `[iteration][event duration]`  
  *(Structured dataset)* Event durations for transition events ending during a given iteration. Each entry contains the following fields:

  - `istate`  
    *(Integer)* Initial state of the transition event.

  - `fstate`  
    *(Integer)* Final state of the transition event.

  - `duration`  
    *(Floating-point)* Duration of the transition event, in units of tau.

  - `weight`  
    *(Floating-point)* Weight of the trajectory at the end of the transition, **not** normalized by the initial state population.

Note that the state-to-state fluxes stored in this file are not normalized by the initial macrostate population and therefore cannot be directly interpreted as rates. The `w_kinavg` command should be used to perform this normalization while accounting for statistical fluctuations and correlations. Target fluxes (total flux into a given state) do not require normalization.

Command-line Options
--------------------

Run `w_kinetics --help` to see the full list of available command-line options and usage information.

Deprecation Notice
------------------

The `w_kinetics` command is deprecated. Users are encouraged to use the `w_direct` command instead, which provides equivalent functionality and improved compatibility.

Example Usage
-------------

```bash
w_kinetics -o kintrace.h5 assign.h5
```

This command processes the bin assignment file `assign.h5` and outputs the kinetics trace data to `kintrace.h5`.

See Also
--------

- `w_direct` — Recommended replacement for `w_kinetics`.
- `w_kinavg` — Tool for averaging and calculating confidence intervals from kinetics trace data.
- `w_assign` — Tool for generating bin assignment files required by `w_kinetics`.
