Generate documentation for this module
======================================

This module provides functionality to save and read file contents to and from filenodes inside PyTables files. It allows storing arbitrary files within an HDF5 container managed by PyTables, facilitating the embedding of external file data into HDF5 datasets.

Functions
---------

save_to_filenode(h5file, filename, where, name=None, overwrite=False, title="", filters=None)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Save a file's contents to a filenode inside a PyTables file.

.. versionadded:: 3.2

Parameters
----------
- **h5file** : str or :class:`File`
  The PyTables file to be written to; can be either a string giving the file's location or a :class:`File` object. If a file with name *h5file* already exists, it will be opened in mode ``a``.

- **filename** : str
  Path of the file which shall be stored within the PyTables file.

- **where** : str or :class:`Group`
  Location of the filenode where the data shall be stored.

- **name** : str, optional
  Name of the filenode. If not given, and *where* is either a :class:`Group` object or a string ending on ``/``, the leaf name will be set to the file name of *filename*. The *name* will be sanitized to adhere to Python's naming conventions. The original filename is preserved in the filenode's *_filename* attribute.

- **overwrite** : bool, optional
  Whether or not a possibly existing filenode of the specified name shall be overwritten. Default is False.

- **title** : str, optional
  A description for this node (sets the ``TITLE`` HDF5 attribute on disk).

- **filters** : :class:`Filters`, optional
  An instance of the :class:`Filters` class that provides information about the desired I/O filters to be applied during the life of this object.

Raises
------
- OSError
  If the input file cannot be read, or if the PyTables file is opened read-only, or if the specified node already exists and overwrite is False.

Description
-----------
This function reads the contents of the specified file and writes it into a new filenode inside the given PyTables file at the specified location. It handles name sanitization, file access checks, and optionally overwrites existing nodes.

read_from_filenode(h5file, filename, where, name=None, overwrite=False, create_target=False)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Read a filenode from a PyTables file and write its contents to a file.

.. versionadded:: 3.2

Parameters
----------
- **h5file** : str or :class:`File`
  The PyTables file to be read from; can be either a string giving the file's location or a :class:`File` object.

- **filename** : str
  Path of the file where the contents of the filenode shall be written to. If *filename* points to a directory or ends with a path separator, the filename will be set to the *_filename* attribute (if present; otherwise the *name*) of the read filenode.

- **where** : str or :class:`Group`
  Location of the filenode where the data shall be read from.

- **name** : str, optional
  Name of the filenode to read. If no node with this name can be found at *where*, the first node at *where* whose *_filename* attribute matches *name* will be read.

- **overwrite** : bool, optional
  Whether or not a possibly existing file of the specified *filename* shall be overwritten. Default is False.

- **create_target** : bool, optional
  Whether or not the folder hierarchy needed to accommodate the given target *filename* will be created. Default is False.

Raises
------
- OSError
  If the target file already exists and overwrite is False, or if the target directory is not writable.

- :class:`tb.NoSuchNodeError`
  If the specified filenode cannot be found in the PyTables file.

Description
-----------
This function reads the contents of a filenode stored inside a PyTables file and writes it out to a specified file on disk. It supports automatic filename resolution based on the filenode's stored filename attribute, directory creation, and overwrite protection.

---

Notes
-----
- Both functions support passing either a filename or an open PyTables File object for the *h5file* parameter.
- The filenode's original filename is preserved in the *_filename* attribute for reference.
- Name sanitization ensures compatibility with Python naming conventions for node names.
- These utilities facilitate embedding and extracting arbitrary files within HDF5 containers managed by PyTables, useful for bundling external resources or metadata alongside datasets.
