Quick Start
===========

This module provides a class to represent polynomial paths, which can be used to model joint trajectories or other parametric curves.

Creating a Polynomial Path
--------------------------

To create a polynomial path, initialize the `PolynomialPath` class with the polynomial coefficients and the path interval:

```python
import numpy as np
from your_module import PolynomialPath  # replace with actual import

# Define polynomial coefficients for each degree of freedom (DOF)
# For a single DOF: coeff = [c0, c1, c2, ...]
# For multiple DOFs: coeff = [[c0_0, c0_1, c0_2, ...], [c1_0, c1_1, c1_2, ...], ...]

coeff = np.array([[1, 0, 2], [0, 1, 3]])  # example coefficients for 2 DOFs

# Define the start and end of the path parameter s
s_start = 0.0
s_end = 1.0

# Initialize the polynomial path
path = PolynomialPath(coeff, s_start=s_start, s_end=s_end)
```

Evaluating the Path
-------------------

You can evaluate the polynomial path at given path positions `s` by calling the path object:

```python
s_values = np.linspace(s_start, s_end, 100)

# Evaluate the polynomial path at s_values (order=0 returns position)
positions = path(s_values, order=0)

# Evaluate the first derivative (velocity) at s_values
velocities = path(s_values, order=1)

# Evaluate the second derivative (acceleration) at s_values
accelerations = path(s_values, order=2)
```

Attributes
----------

- `dof`: Returns the number of degrees of freedom (number of polynomial sets).
- `duration`: Returns the duration of the path, i.e., `s_end - s_start`.
- `path_interval`: Returns the interval `[s_start, s_end]` over which the path is defined.

Deprecated Methods
------------------

The following methods are deprecated and replaced by properties:

- `get_path_interval()` → use `path_interval`
- `get_duration()` → use `duration`
- `get_dof()` → use `dof`

Example
-------

```python
import numpy as np

coeff = np.array([1, -2, 3])  # single DOF polynomial coefficients
path = PolynomialPath(coeff, s_start=0, s_end=2)

s = 1.5
pos = path(s, order=0)  # position at s=1.5
vel = path(s, order=1)  # velocity at s=1.5
acc = path(s, order=2)  # acceleration at s=1.5

print(f"Position: {pos}")
print(f"Velocity: {vel}")
print(f"Acceleration: {acc}")
```
