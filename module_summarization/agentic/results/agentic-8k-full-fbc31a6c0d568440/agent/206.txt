Support Vector Machines
=======================

Support Vector Machines (SVMs) are a set of supervised learning methods used for classification, regression, and outliers detection. They are implemented in scikit-learn using the libsvm and liblinear libraries, providing efficient and versatile tools for various machine learning tasks.

Overview
--------

SVMs work by finding the hyperplane that best separates classes in the feature space. For classification, this hyperplane maximizes the margin between different classes. For regression, SVMs try to fit the best line within a threshold margin to the data points.

Key Features
------------

- **Support Vectors**: The data points closest to the decision boundary that influence the position and orientation of the hyperplane.
- **Kernel Trick**: Allows SVMs to perform non-linear classification by implicitly mapping inputs into high-dimensional feature spaces.
- **Platt Scaling**: Used to produce probability estimates from decision values by applying a logistic function. The parameters of this function are learned from the dataset.
- **Multi-class Support**: SVMs handle multi-class classification problems using strategies such as one-vs-one (OVO) or one-vs-rest (OVR).

Attributes
----------

- `support_` : ndarray of shape (n_SV,)
  
  Indices of support vectors.

- `support_vectors_` : ndarray of shape (n_SV, n_features)
  
  The support vectors themselves.

- `n_support_` : ndarray of shape (1,), dtype=int32
  
  Number of support vectors for each class.

- `shape_fit_` : tuple of int
  
  Dimensions of the training data array.

- `n_iter_` : int or ndarray
  
  Number of iterations run by the optimization routine to fit the model. For SVC and NuSVC, this is an ndarray reflecting the number of models optimized; for SVR, NuSVR, and OneClassSVM, it is an integer.

- `feature_names_in_` : ndarray of shape (n_features_in_,)
  
  Names of features seen during fitting. Defined only when the input data has feature names that are all strings.

Probability Estimates
--------------------

When `probability=True`, SVMs use Platt scaling to convert decision function values into calibrated probability estimates. The logistic function used is:

.. math::

    P(y=1 | x) = \frac{1}{1 + \exp(decision\_value \times probA\_ + probB\_)}

where `probA_` and `probB_` are parameters learned from the training data.

If `probability=False`, the probability estimates array is empty.

Kernel Functions
----------------

SVMs support various kernel functions including:

- Linear
- Polynomial
- Radial Basis Function (RBF)
- Sigmoid
- Custom callable kernels

Using a callable kernel requires storing a reference to the training data to compute the kernel matrix during prediction.

Optimization and Convergence
----------------------------

The fitting process involves solving a quadratic optimization problem. The number of iterations (`n_iter_`) reflects the convergence status. If the solver terminates early (e.g., reaching `max_iter`), a warning is issued suggesting data preprocessing such as scaling.

Usage Notes
-----------

- Input data should be finite and may require preprocessing (e.g., scaling) to improve convergence.
- Feature names are preserved if the input data supports them.
- The internal representation of the model should not be altered after fitting to avoid errors during prediction.

See Also
--------

- `SVR` : Support Vector Machine for regression implemented using libsvm.
- `LinearSVC` : Scalable Linear Support Vector Machine for classification implemented using liblinear.
- `NuSVC` : Variant of SVC using a parameter to control the number of support vectors.
- `NuSVR` : Variant of SVR using a parameter to control the number of support vectors.
- `OneClassSVM` : Unsupervised Outlier Detection using SVM.
