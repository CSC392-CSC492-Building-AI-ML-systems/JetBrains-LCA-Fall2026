Plothist Command
================

Overview
--------

The `plothist` command is a versatile tool designed to plot probability density functions (histograms) generated by `w_pdist` or other compatible programs that produce similar output formats. It supports plotting 1-D and 2-D histograms and can visualize data from individual iterations, averages over multiple iterations, or the time evolution of histograms.

The command supports multiple plotting modes, each tailored to different analysis needs:

Modes of Operation
------------------

1. **instant**

   Plot probability distributions for a single weighted ensemble (WE) iteration. The input histogram must correspond to a single iteration and be compatible with the output format of `w_pdist`.

   - Usage: `plothist instant [options]`
   - Description: Plot a probability distribution for a single WE iteration.
   - Options:
     - `--iter N_ITER`  
       Plot the distribution for iteration `N_ITER`. If not specified, the last completed iteration is used by default.

2. **average**

   Plot histograms averaged over several iterations. This mode is useful for smoothing out fluctuations and obtaining a representative distribution over a range of iterations.

   - Usage: `plothist average [options]`
   - Description: Plot averaged 1-D and 2-D histograms over multiple iterations.

3. **evolution**

   Plot the time evolution of 1-D histograms as waterfall or heat map plots, showing how the distribution changes over iterations.

   - Usage: `plothist evolution [options]`
   - Description: Visualize the temporal evolution of histograms across iterations.

Input Data
----------

The input to `plothist` is typically the output from `w_pdist`, which contains histogram data for weighted ensemble simulations. The input data must include histogram counts, bin midpoints, and dimension labels. The tool supports both 1-D and 2-D histograms.

Plotting Features
-----------------

- **Plot scales:**

  The command supports different scales for plotting histograms:

  - `energy` scale: plots the negative logarithm of the probability, \(-\ln P(x)\), useful for free energy landscapes.
  - `log10` scale: plots the base-10 logarithm of the probability, \(\log_{10} P(x)\).
  - Default: plots the raw probability \(P(x)\).

- **Plot ranges:**

  Users can specify plot ranges for both x and y axes to focus on regions of interest.

- **Labels and titles:**

  Axis labels are automatically derived from the dimension metadata. Users can specify custom plot titles.

- **Post-processing:**

  A user-defined post-processing function can be applied to the histogram data before plotting.

- **Output formats:**

  Plots are saved to files in any format supported by Matplotlib (e.g., PNG, PDF).

- **2-D plotting:**

  For 2-D histograms, the tool uses `NonUniformImage` to accurately represent non-uniform binning. Colorbars indicate the scale of the plotted quantity. Optional contour lines can be added to enhance visualization.

- **Evolution plots:**

  Time evolution plots display histograms as heat maps with iteration number on one axis and bin midpoints on the other.

Examples
--------

- Plot the histogram for iteration 10 on an energy scale:

  ```
  plothist instant --iter 10 --plotscale energy -o hist_iter10.png input_data.h5
  ```

- Plot the average histogram over iterations 5 to 15 with logarithmic scale:

  ```
  plothist average --start 5 --stop 15 --plotscale log10 -o avg_hist.png input_data.h5
  ```

- Plot the evolution of histograms over all iterations:

  ```
  plothist evolution -o evolution.png input_data.h5
  ```

Dependencies
------------

- Python packages: `matplotlib`, `numpy`, `h5py`
- Input data compatible with `w_pdist` output format

Command-line Options
--------------------

Run `plothist --help` or `plothist <mode> --help` for detailed command-line options and usage instructions for each mode.

Summary
-------

`plothist` is a powerful and flexible plotting tool for weighted ensemble histogram data, supporting multiple visualization modes and scales. It facilitates detailed analysis of probability distributions from simulation data, enabling insights into system behavior across iterations or over time.
