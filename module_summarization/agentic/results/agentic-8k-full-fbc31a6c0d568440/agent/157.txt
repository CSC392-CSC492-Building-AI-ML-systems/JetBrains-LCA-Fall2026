nextcord
=======

nextcord is an easy-to-use, feature-rich Python library designed for interacting with the Discord API. It allows developers to create Discord bots and applications with a simple and intuitive interface, supporting a wide range of Discord features including messages, embeds, stickers, reactions, and more.

Key Features
------------

- **Message Handling**  
  nextcord provides comprehensive support for sending and managing messages. You can reply to messages using references created via `Message.to_reference()` or by passing a `Message` object directly. The library also allows control over whether the author of the referenced message is mentioned through the `AllowedMentions.replied_user` attribute or the `mention_author` parameter.

- **Embeds and Stickers**  
  You can enhance your messages by attaching up to 10 embeds and up to 3 stickers per message, enabling rich content delivery and interactive experiences.

- **Robust Conversion System**  
  nextcord includes a powerful and extensible converter system that automatically converts command arguments into appropriate Discord objects such as `Member`, `User`, `Message`, `TextChannel`, `Guild`, `Role`, and many others. This system supports custom converters and handles complex types including unions and generics, ensuring smooth command parsing and error handling.

- **Command Framework**  
  The library offers a flexible command framework that allows you to define commands and groups easily using decorators. Commands automatically inherit help descriptions from their docstrings, and you can customize command behavior and checks seamlessly.

- **Cog Support**  
  nextcord supports cogs, which are classes that group commands and listeners together. Cogs can have their own names and descriptions, and they provide a clean way to organize your bot’s functionality.

Error Handling
--------------

nextcord raises specific exceptions to help you handle errors gracefully:

- `HTTPException`: Raised when sending a message or performing an HTTP request fails.
- `Forbidden`: Raised when the bot lacks the necessary permissions to perform an action.
- `InvalidArgument`: Raised when invalid arguments are passed, such as an incorrect number of files.

Getting Started
---------------

To get started with nextcord, install it via pip:

```bash
pip install nextcord
```

Then, create a bot instance and start adding commands and event listeners. The library’s extensive documentation and type annotations make it easy to explore available features and build powerful Discord bots.

Versioning Notes
----------------

- Features like message references and mention control were introduced in version 1.6.
- Support for embeds and stickers in message sending was added in version 2.0.
- The converter system and command framework have been enhanced progressively to support more complex use cases and improve developer experience.

nextcord is actively maintained and continuously improved to keep up with Discord’s evolving API, making it a reliable choice for Python developers building Discord bots.
