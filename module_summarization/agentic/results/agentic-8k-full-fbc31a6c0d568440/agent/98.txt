Contracts
=========

This module provides functionality to interact with Ethereum smart contracts using a Web3 connector. It defines a base `Contract` class and a factory function to create contract proxy classes from compiled Solidity contract definitions.

Contract Class
--------------

The `Contract` class serves as a base proxy class for interacting with smart contracts on the blockchain.

### Overview

- The `Contract` class is designed to be subclassed by contract proxy classes created via the `construct_contract_factory` function.
- It allows interaction with deployed smart contracts by their address.
- It also supports deploying new smart contracts to the blockchain.

### Initialization

```python
Contract(abi=None, address=None, code=None, code_runtime=None, source=None)
```

Creates a new contract proxy instance.

- `abi` (optional): The contract ABI (Application Binary Interface). Overrides the class-level ABI.
- `address` (optional): The deployed contract's address as a hex string (with `0x` prefix).
- `code` (optional): The contract bytecode. Overrides the class-level code.
- `code_runtime` (optional): The runtime bytecode of the contract. Overrides the class-level runtime code.
- `source` (optional): The contract source code. Overrides the class-level source.

Raises an `AttributeError` if the `Contract` class has not been properly initialized with a Web3 connection.

### Properties

- `abi`: Returns the contract ABI. Raises `AttributeError` if not specified.
- `code`: Returns the contract bytecode. Raises `AttributeError` if not specified.
- `code_runtime`: Returns the runtime bytecode. Raises `AttributeError` if not specified.
- `source`: Returns the contract source code. Raises `AttributeError` if not specified.

### Methods

#### deploy

```python
@classmethod
deploy(transaction=None, args=None, kwargs=None)
```

Deploys the contract to the blockchain.

- `transaction` (optional): A dictionary specifying transaction parameters such as `from` address and `value`.
- `args` (optional): Tuple of positional arguments to pass to the contract constructor.
- `kwargs` (optional): Dictionary of keyword arguments to pass to the contract constructor.

Returns the address of the deployed contract as a hex string.

Example:

```python
MyContract.deploy(
    transaction={
        'from': web3.eth.accounts[1],
        'value': 12345,
    },
    args=('DGD', 18),
)
```

Contract Factory Function
-------------------------

```python
construct_contract_factory(
    web3,
    abi=None,
    code=None,
    code_runtime=None,
    source=None,
    contract_name='Contract',
    base_contract_factory_class=Contract
)
```

Creates a new contract proxy class for a specific smart contract.

- `web3`: A Web3 connection instance.
- `abi`: The contract ABI as generated by the Solidity compiler (`solc`).
- `code`: The contract bytecode.
- `code_runtime`: The runtime bytecode.
- `source`: The contract source code.
- `contract_name`: The name of the generated contract class (default: `'Contract'`).
- `base_contract_factory_class`: The base class to inherit from (default: `Contract`).

Returns a new Python class that can be used to interact with or deploy the specified smart contract.

### Usage Example

```python
# Contract data as compiled by solc or Populus framework
token_contract_data = {
    'abi': [...],
    'code': '0x...',
    'code_runtime': '0x...',
    'source': 'contract Token { ... }',
}

# Create a contract factory class
token_contract_factory = construct_contract_factory(
    web3=web3,
    abi=token_contract_data["abi"],
    code=token_contract_data["code"],
    code_runtime=token_contract_data["code_runtime"],
    source=token_contract_data["source"],
)

# Create an instance of the contract proxy for a deployed contract
token_contract = token_contract_factory(
    address='0x1234567890abcdef...',
    abi=token_contract_data["abi"],
    code=token_contract_data["code"],
    code_runtime=token_contract_data["code_runtime"],
    source=token_contract_data["source"],
)
```

This instance can then be used to call contract functions or send transactions.

Summary
-------

This module abstracts the complexity of interacting with Ethereum smart contracts by providing:

- A base `Contract` class for proxying contract interactions.
- A factory function to generate contract proxy classes from compiled contract data.
- Support for deploying contracts and interacting with deployed contracts via their address.
- Properties to access contract ABI, bytecode, runtime code, and source code.

It relies on the Web3.py library and related utilities for encoding, decoding, and event handling.
