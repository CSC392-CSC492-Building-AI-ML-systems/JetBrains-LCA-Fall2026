Novelty and Outlier Detection
=============================

Outlier detection and novelty detection are important tasks in unsupervised learning, aimed at identifying rare items, events, or observations which raise suspicions by differing significantly from the majority of the data.

Overview
--------

- **Outlier Detection** refers to identifying unusual data points in a dataset, typically during the training phase. The model is trained on the entire dataset, including outliers, and attempts to detect anomalies within it.
- **Novelty Detection** focuses on identifying new or unseen anomalies in data that was not present during training. The model is trained only on "normal" data and then used to detect outliers in new, unseen data.

Local Outlier Factor (LOF)
--------------------------

The Local Outlier Factor (LOF) algorithm is an unsupervised method for outlier detection that measures the local deviation of a given data point with respect to its neighbors. It assigns an anomaly score called the LOF score, where a higher score indicates a higher likelihood of being an outlier.

Key points about LOF:

- The `fit_predict` method fits the model to the training data and returns labels indicating inliers (1) and outliers (-1). This method is **not available for novelty detection** (i.e., when `novelty=True`).
- The `fit` method fits the LOF detector to the training dataset.
- The number of neighbors used (`n_neighbors`) is automatically adjusted if it exceeds the number of samples.
- The negative outlier factor is computed as the mean of local reachability density ratios.
- The decision threshold (`offset_`) is set based on the contamination parameter or automatically if contamination is set to `"auto"`.

Example usage:

```python
from sklearn.neighbors import LocalOutlierFactor

clf = LocalOutlierFactor(n_neighbors=20, contamination=0.1)
y_pred = clf.fit_predict(X_train)
```

Isolation Forest
----------------

Isolation Forest is an ensemble-based method for anomaly detection that isolates observations by randomly selecting a feature and then randomly selecting a split value between the maximum and minimum values of the selected feature. The number of splits required to isolate a sample is equivalent to the path length from the root node to the terminating node.

Key features:

- Based on an ensemble of randomized trees (ExtraTreeRegressor).
- The maximum depth of each tree is set to `ceil(log_2(n))`, where `n` is the number of samples.
- The contamination parameter controls the proportion of outliers in the data.
- Supports various parameters such as `n_estimators`, `max_samples`, `max_features`, and `bootstrap`.
- Does not support out-of-bag (OOB) score estimation.

Example usage:

```python
from sklearn.ensemble import IsolationForest

clf = IsolationForest(random_state=0)
clf.fit(X_train)
y_pred = clf.predict(X_test)
```

One-Class SVM
-------------

The One-Class SVM is an unsupervised novelty detection method that estimates the support of a high-dimensional distribution. It is based on the Support Vector Machine (SVM) algorithm and implemented using libsvm.

Key parameters:

- `kernel`: Specifies the kernel type (`'linear'`, `'poly'`, `'rbf'`, `'sigmoid'`, or `'precomputed'`).
- `degree`: Degree of the polynomial kernel function (used only if `kernel='poly'`).
- `gamma`: Kernel coefficient for `'rbf'`, `'poly'`, and `'sigmoid'`.
- `nu`: An upper bound on the fraction of training errors and a lower bound on the fraction of support vectors.
- `shrinking`: Whether to use the shrinking heuristic.
- `cache_size`: Size of the kernel cache in MB.
- `max_iter`: Hard limit on iterations within the solver.

Attributes include:

- `coef_`: Weights assigned to features (only for linear kernel).
- `dual_coef_`: Coefficients of the support vectors.
- `intercept_`: Constant in the decision function.
- `fit_status_`: Status of the fitting process.

Example usage:

```python
from sklearn.svm import OneClassSVM

clf = OneClassSVM(kernel='rbf', gamma='scale', nu=0.5)
clf.fit(X_train)
y_pred = clf.predict(X_test)
```

Notes
-----

- The `fit_predict` method is only available for outlier detection (when `novelty=False`) because novelty detection requires a separate training and prediction phase.
- The contamination parameter is crucial for setting the threshold to distinguish between inliers and outliers.
- Local Outlier Factor is sensitive to the choice of `n_neighbors`.
- Isolation Forest is efficient for high-dimensional datasets and large sample sizes.
- One-Class SVM is effective for novelty detection when the training data contains only normal observations.
