Generate Documentation for Alembic Commands Module
====================================================

This module provides a set of command functions used to interact with Alembic's database migration environment. These commands facilitate operations such as displaying the current revision, stamping the database with a specific revision, editing revision scripts, and ensuring the Alembic version table exists.

Commands
--------

current(config: Config, verbose: bool = False) -> None
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Display the current revision(s) for a database.

:param config: A :class:`.Config` instance representing the Alembic configuration.
:param verbose: If True, outputs detailed information about the current revision(s).

This command retrieves and prints the current revision(s) applied to the database. When run in verbose mode, additional details about each revision are included.

stamp(config: Config, revision: str, sql: bool = False, tag: Optional[str] = None, purge: bool = False) -> None
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Stamp the revision table with the given revision without running any migrations.

:param config: A :class:`.Config` instance representing the Alembic configuration.
:param revision: Target revision or list of revisions to stamp. May be a list to indicate stamping of multiple branch heads.
    .. note:: This parameter is called "revisions" in the command line interface.
:param sql: If True, generate SQL script output instead of applying changes directly.
:param tag: An arbitrary tag string that can be intercepted by custom `env.py` scripts via the :class:`.EnvironmentContext.get_tag_argument` method.
:param purge: If True, delete all entries in the version table before stamping.

This command updates the Alembic version table to the specified revision(s) without performing any migration operations. It supports stamping multiple branch heads and can operate in SQL script generation mode.

edit(config: Config, rev: str) -> None
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Edit revision script(s) using the system's default editor.

:param config: A :class:`.Config` instance representing the Alembic configuration.
:param rev: Target revision identifier to edit. The special value "current" edits the current revision script(s).

This command opens the specified revision script(s) in the editor defined by the environment variable `$EDITOR`. If the revision is "current", it edits the script(s) corresponding to the current revision(s).

ensure_version(config: Config, sql: bool = False) -> None
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Create the Alembic version table if it does not already exist.

:param config: A :class:`.Config` instance representing the Alembic configuration.
:param sql: If True, generate SQL script output instead of applying changes directly.

.. versionadded:: 1.7.6

This command ensures that the Alembic version table is present in the database, creating it if necessary. It can operate in SQL script generation mode.

Internal Functions
------------------

The module also contains internal helper functions used to support the above commands, such as displaying history with current revisions and formatting output. These are not intended for direct use outside the module.

Usage Context
-------------

All commands operate within an Alembic `EnvironmentContext`, which manages the migration environment and database connection. Commands typically instantiate a `ScriptDirectory` from the provided configuration to access migration scripts and metadata.

Summary
-------

This module is essential for managing Alembic migrations programmatically, providing commands to inspect, modify, and maintain the migration state of a database. It supports both direct database operations and SQL script generation for offline review or execution.
