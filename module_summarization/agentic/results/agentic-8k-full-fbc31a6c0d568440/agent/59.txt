Regression Module
=================

This module provides classes and methods for various regression techniques, including quantile regression and dimension reduction regression methods.

Quantile Regression
-------------------

The `QuantReg` class implements quantile regression, which estimates the conditional quantiles of a response variable given explanatory variables. It uses an iterative reweighted least squares algorithm to fit the model.

Key Features:
- Supports estimation of any quantile between 0 and 1.
- The Least Absolute Deviation (LAD) estimator is a special case with quantile set to 0.5.
- Provides robust and heteroskedasticity-consistent covariance matrix estimators.
- Supports kernel density estimation for asymptotic covariance matrix calculation with various kernel and bandwidth options.

Parameters:
- `endog`: Endogenous or response variable (array or DataFrame).
- `exog`: Exogenous or explanatory variables (array or DataFrame).

Fit Method Parameters:
- `q`: Quantile to estimate (float between 0 and 1).
- `vcov`: Method for variance-covariance matrix estimation (`robust` or `iid`).
- `kernel`: Kernel type for density estimation (`epa`, `cos`, `gau`, `par`).
- `bandwidth`: Bandwidth selection method (`hsheather`, `bofinger`, `chamberlain`).
- `max_iter`, `p_tol`: Control iterative fitting convergence.

References:
- Birkes and Dodge (1993), Alternative Methods of Regression.
- Greene (2008), Econometric Analysis.
- Koenker (2005), Quantile Regression.
- LeSage (1999), Applied Econometrics Using MATLAB.
- Additional references for kernels and bandwidth selection methods are provided in the class docstring.

Dimension Reduction Regression
------------------------------

This module also includes base and specific classes for dimension reduction regression techniques, which aim to reduce the dimensionality of explanatory variables while preserving the relationship with the response variable.

Base Class:
- `_DimReductionRegression`: Provides common functionality such as data whitening and slicing for dimension reduction methods.

Specific Methods:

1. Sliced Inverse Regression (SIR)
   - Class: `SlicedInverseReg`
   - Estimates effective dimension reduction (EDR) space by slicing the data according to the response variable.
   - Parameters:
     - `endog`: Dependent variable (1D array).
     - `exog`: Covariates (2D array).
     - `slice_n`: Number of observations per slice (optional).
   - Reference: Li (1991), "Sliced inverse regression for dimension reduction", JASA.

2. Principal Hessian Directions (PHD)
   - Class: `PrincipalHessianDirections`
   - Estimates EDR space using second-order derivative information.
   - Parameters:
     - `endog`: Dependent variable (1D array).
     - `exog`: Covariates (2D array).
     - `resid`: Boolean flag to remove linear effects before PHD (optional).
   - Reference: Li (1992), "On Principal Hessian Directions for Data Visualization and Dimension Reduction", JASA.

These dimension reduction methods facilitate visualization and interpretation of high-dimensional regression problems by identifying lower-dimensional structures that capture the essential relationships between variables.

Summary
-------

The regression module offers robust and flexible tools for regression analysis, including advanced quantile regression techniques and dimension reduction methods. These tools are suitable for econometric analysis, robust estimation, and exploratory data analysis in high-dimensional settings.
