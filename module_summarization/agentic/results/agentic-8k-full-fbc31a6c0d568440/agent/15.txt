Ploterr Command
===============

The `ploterrs` command is a versatile tool designed to plot error ranges for weighted ensemble datasets. It supports multiple input formats and subcommands tailored to different types of data generated by weighted ensemble simulations and analyses.

Overview
--------

`ploterrs` reads data from HDF5 files and generates plots illustrating expectation values and confidence intervals, state-to-state rates, flux evolutions, and population probabilities. The output plots are saved to files in formats determined by the filename extensions.

Subcommands
-----------

The tool provides several subcommands, each targeting specific data types and formats:

### generic

Plots generic expectation and confidence interval (CI) data from arbitrary HDF5 files.

- **Input:** A dataset specified as `FILENAME/PATH[SLICE]`, where:
  - `FILENAME` is the HDF5 file.
  - `PATH` is the internal HDF5 path to the dataset.
  - `SLICE` (optional) is a NumPy-style slice selecting a vector of data.

- **Requirements:** The dataset must be one-dimensional and contain the following fields:
  - `iter_start`
  - `iter_stop`
  - `expected`
  - `ci_lbound`
  - `ci_ubound`

- **Usage example:**

  ```
  ploterrs generic kinavg.h5/rate_evolution[:,0,1] -o output.pdf
  ```

- **Description:**  
  This subcommand is useful for plotting arbitrary expectation and confidence interval data extracted from HDF5 datasets, including sliced views of multidimensional datasets.

### d.kinetics

Plots the evolution of state-to-state rates and total flux into states as generated by `w_direct kinetics` (when used with the `--evolution-mode` option).

- **Input filename:** `direct.h5`

- **Output files:**  
  - Flux evolution plots: `flux_evolution_d_{state_label}.pdf`  
  - Rate evolution plots: `rate_evolution_d_{istate_label}_{fstate_label}.pdf`

- **Substitution variables for output filenames, plot titles, and axis labels:**

  - `istate_label`, `fstate_label`: String labels of initial and final states.
  - `istate_index`, `fstate_index`: Integer indices of initial and final states.
  - `state_label`: String label of a state (for fluxes).
  - `state_index`: Index of a state.

- **Description:**  
  Generates plots for all rates and fluxes calculated by `w_direct kinetics`.

### rw.kinetics

Plots kinetics data generated by `w_reweight kinetics`.

- **Input filename:** `reweight.h5`

- **Output files:**  
  - Flux evolution plots: `flux_evolution_rw_{state_label}.pdf`  
  - Rate evolution plots: `rate_evolution_rw_{istate_label}_{fstate_label}.pdf`

- **Description:**  
  Similar to `d.kinetics`, but for data produced by the `w_reweight kinetics` tool.

### Additional Subcommands

- `DirectStateprobs` and `ReweightStateprobs` (not fully detailed here) handle plotting of state probability evolutions and color evolutions from respective input files.

Command-Line Options
--------------------

Each subcommand supports specific command-line arguments. Common options include:

- `-o, --output OUTPUT`  
  Specify the output filename for the plot. The file format is inferred from the extension. Default is typically `errbars.pdf`.

- `dsspec` (positional argument for `generic` subcommand)  
  Specifies the dataset location in the form `FILENAME/PATH[SLICE]`.

Usage
-----

To use the `ploterrs` command, invoke it with the desired subcommand and appropriate arguments. For example:

```
ploterrs generic data.h5/dataset[10:20] -o myplot.pdf
```

This command will plot the expectation and confidence interval data from the specified slice of the dataset and save the plot to `myplot.pdf`.

Entry Point
-----------

The command-line interface is provided by the `PloterrsTool` class, which manages subcommands and argument parsing. The main entry point is:

```bash
ploterrs [subcommand] [options]
```

Examples
--------

- Plot generic expectation and CI data:

  ```
  ploterrs generic kinavg.h5/rate_evolution[:,0,1] -o rate_plot.pdf
  ```

- Plot direct kinetics flux evolution for a specific state:

  ```
  ploterrs d.kinetics -o flux_evolution_d_stateA.pdf
  ```

- Plot reweight kinetics rate evolution between two states:

  ```
  ploterrs rw.kinetics -o rate_evolution_rw_stateA_stateB.pdf
  ```

Summary
-------

`ploterrs` is a flexible plotting tool for visualizing error bars, kinetics, and probability evolutions from weighted ensemble simulation data stored in HDF5 files. Its modular subcommand structure allows it to handle diverse data formats and plotting needs efficiently.
