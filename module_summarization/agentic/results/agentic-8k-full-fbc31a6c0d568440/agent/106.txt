Hyperexpand
===========

The `hyperexpand` module provides functionality to find and generate expanded expressions for hypergeometric functions and related special functions. It attempts to rewrite hypergeometric functions in terms of simpler or more explicit expressions, often involving elementary functions or other special functions with known expansions.

Classes
-------

### Formula

The `Formula` class represents hypergeometric formulae and encapsulates the data and methods related to these expressions.

**Attributes:**

- `z` : The argument of the hypergeometric function.
- `closed_form` : The closed form expression of the formula, if known.
- `symbols` : The free symbols (parameters) involved in the formula.
- `func` : The hypergeometric function object.
- `B`, `C`, `M` : Internal data structures computed by the `_compute_basis` method, representing a basis of functions and transformation matrices related to the formula.

**Example:**

```python
func = Hyper_Function((a/2, a/3 + b, (1+a)/2), (a, b, (a+b)/7))
f = Formula(func, z, None, [a, b])
```

Functions
---------

### _hyperexpand(func, z, ops0=[], z0=Dummy('z0'), premult=1, prem=0, rewrite='default')

Attempts to find an expanded expression for the hypergeometric function `func` evaluated at `z`.

- The result is expressed in terms of a dummy variable `z0`.
- The result is then multiplied by `premult`, which must be of the form `a*z**prem` for some `a` independent of `z`.
- The list of operations `ops0` is applied to the result.
- The `rewrite` parameter controls the rewriting strategy used.

This function is the core engine behind the expansion process, recursively applying transformations and expansions to simplify or rewrite hypergeometric functions.

### hyperexpand(f, rewrite='default', allow_hyper=True, place=0)

Expands hypergeometric functions and Meijer G-functions appearing in the expression `f`.

- `f` : The expression to expand, typically containing hypergeometric or Meijer G-functions.
- `rewrite` : Specifies the rewriting strategy.
- `allow_hyper` : If `True`, allows expansions that still contain hypergeometric functions.
- `place` : Indicates the preferred expansion point for G-functions that have expansions at both zero and infinity. Can be set to `0` or `zoo`.

**Behavior:**

- Hypergeometric functions are replaced by their expanded forms when possible.
- Non-hypergeometric parts of the expression and hypergeometric expressions that are not recognized remain unchanged.

**Examples:**

```python
>>> hyperexpand(hyper([], [], z))
E**z

>>> hyperexpand(1 + hyper([1, 1, 1], [], z))
hyper((1, 1, 1), (), z) + 1
```

Internal Details
----------------

- The module uses dummy variables and symbolic manipulation to handle expansions.
- It relies on gamma functions, factorials, and other special function identities to compute coefficients and transformations.
- The expansion process may involve polar lifting and careful handling of branch cuts and singularities.
- The `_compute_basis` method in the `Formula` class computes a set of basis functions and transformation matrices used internally for expansions.

Notes
-----

- The module currently contains a limited set of formulae and expansions; further algorithms and formulae may be added.
- The expansions aim to express hypergeometric functions in terms of simpler or more explicit functions whenever possible.
- Some expansions may still contain hypergeometric functions if no simpler closed form is found.

This module is useful for symbolic computation systems that require manipulation and simplification of hypergeometric functions and related special functions.
