# Supporting Data to Plotting Functions in Multiple Ways

This document describes how data can be supported and normalized for use in plotting functions, enabling flexible and consistent handling of various data formats.

## Overview

The plotting functions support data input in multiple forms, including dictionaries, lists, numpy arrays, and pandas Series. The data can be provided as single datasets or multiple datasets grouped together. The system normalizes these inputs to ensure compatibility with plotting routines.

## PlotData and Iteration Modes

The `PlotDataIterator` class provides iteration behavior over the `PlotData` class, supporting three modes of iteration:

- **keys**: Returns the keys corresponding to the data entries.
- **values**: Returns the data values for each entry.
- **items**: Returns tuples of keys and corresponding data sources.

The keys and values are returned as named tuples with fields corresponding to the defined data keys. This allows for structured access to the data components during plotting.

## Data Normalization

The function `normalize_list_or_array` is responsible for normalizing input data that may be provided as lists, numpy arrays, or pandas Series. It processes the data according to the following rules:

- If the input data is a multidimensional array (e.g., list of lists or multidimensional numpy array) and splitting is not forbidden, the first dimension is iterated over and interpreted as separate entries. This allows multiple datasets to be handled simultaneously.
- If the input data is one-dimensional and its length differs from the number of existing data sets, the data is added to all existing entries.
- If the input data is one-dimensional and matches the length of existing data sets, each data entry is added to the corresponding dataset.

### Parameters

- `data`: The array-like data to be normalized.
- `key`: The key under which the new data will be stored.
- `out_data`: A dictionary or list of dictionaries containing previously normalized data.
- `flatten_np`: If `True`, multidimensional numpy arrays are flattened before processing.
- `forbid_split_up`: If `True`, multidimensional arrays are not split into separate entries.

### Return Value

The function returns either a dictionary or a list of dictionaries containing the normalized data, ready for use in plotting.

## Handling of Column Data Sources

When iterating over plot data, if the data source is a Bokeh `ColumnDataSource` and wrapping is enabled, the data is wrapped using a `ColumnDataSourceWrapper`. This ensures compatibility with Bokeh plotting functions and allows seamless integration of data sources.

## Summary

The plotting system supports flexible data input formats and provides mechanisms to normalize and iterate over data in a structured way. This flexibility allows users to supply data in various forms while ensuring consistent behavior in plotting functions.

By supporting multiple data input styles and providing robust normalization, the plotting functions can handle complex datasets and multiple data sources efficiently and transparently.
