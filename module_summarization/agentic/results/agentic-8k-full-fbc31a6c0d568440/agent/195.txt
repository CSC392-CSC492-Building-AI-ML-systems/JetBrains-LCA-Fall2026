Learn Gaussian Mixture Models
==============================

Overview
--------

The `sklearn.mixture` module provides implementations of mixture modeling algorithms, including the Gaussian Mixture Model (GMM) and Bayesian Gaussian Mixture Model. These models are powerful tools for clustering and density estimation by representing data as a mixture of multiple Gaussian distributions.

Gaussian Mixture Model
----------------------

A Gaussian Mixture Model is a probabilistic model that assumes all data points are generated from a mixture of a finite number of Gaussian distributions with unknown parameters. It is widely used for clustering, anomaly detection, and density estimation.

Key Classes
-----------

- **GaussianMixture**  
  Implements the standard Gaussian Mixture Model using the Expectation-Maximization (EM) algorithm. It supports different covariance types (`full`, `tied`, `diag`, `spherical`) to model the shape of the Gaussian components.

- **BayesianGaussianMixture**  
  Extends the Gaussian Mixture Model by incorporating Bayesian priors, allowing automatic determination of the number of components and providing more robust clustering.

Parameters and Validation
-------------------------

- **Weights**  
  The mixture proportions for each component must be non-negative, normalized to sum to 1, and have shape `(n_components,)`.

- **Means**  
  The centers of each Gaussian component, with shape `(n_components, n_features)`.

- **Precisions**  
  The precision matrices (inverse of covariance matrices) must be positive definite. Depending on the covariance type, precisions can have different shapes:
  
  - `full`: `(n_components, n_features, n_features)`
  - `tied`: `(n_features, n_features)`
  - `diag`: `(n_components, n_features)`
  - `spherical`: `(n_components,)`

The module includes rigorous checks to ensure these parameters are valid, symmetric (where applicable), and positive definite.

Covariance Types
----------------

- **Full**: Each component has its own general covariance matrix.
- **Tied**: All components share the same general covariance matrix.
- **Diagonal**: Each component has its own diagonal covariance matrix.
- **Spherical**: Each component has its own single variance (isotropic covariance).

Usage Example
-------------

```python
from sklearn.mixture import GaussianMixture
import numpy as np

# Generate sample data
X = np.vstack([
    np.random.multivariate_normal(mean=[0, 0], cov=np.eye(2), size=100),
    np.random.multivariate_normal(mean=[5, 5], cov=np.eye(2), size=100)
])

# Fit a Gaussian Mixture Model with 2 components
gmm = GaussianMixture(n_components=2, covariance_type='full', random_state=42)
gmm.fit(X)

# Predict cluster labels
labels = gmm.predict(X)

# Predict posterior probabilities for each component
probs = gmm.predict_proba(X)
```

Advanced Features
-----------------

- Initialization with user-provided parameters (`weights_init`, `means_init`, `precisions_init`) to control the starting point of the EM algorithm.
- Support for different covariance structures to balance model complexity and computational efficiency.
- Methods to compute log-likelihood, sample new data points, and evaluate model convergence.
- Integration with scikit-learn utilities for parameter validation and numerical stability.

Testing and Validation
----------------------

The implementation includes comprehensive tests to ensure:

- Correct handling of parameter shapes and values.
- Stability when fitting models with a single component or small datasets.
- Proper error handling when the number of components exceeds the number of samples.
- Consistency of precision matrix computations across covariance types.
- Correct iteration counts and convergence behavior.
