distutils module
================

The `distutils` module provides utilities and classes to facilitate the building, installation, and configuration of Python packages, particularly those involving compiled extensions. It includes support for managing build jobs, handling package information, and working with temporary directories during the build process.

Key Components
--------------

- **InstallableLib**  
  A container class that holds information about an installable library, including its name, build information, and target installation directory.

- **get_num_build_jobs()**  
  Determines the number of parallel build jobs to run, based on command-line arguments, environment variables, or system CPU count, with a maximum limit to prevent system overload.

- **get_cmd(cmdname)**  
  Retrieves a cached command object from the distutils distribution instance, raising an error if the distribution is not initialized.

- **get_numpy_include_dirs()**  
  Returns a list of include directories for NumPy headers, either from the current configuration or by importing NumPy directly.

- **get_npy_pkg_dir()**  
  Returns the path to the `npy-pkg-config` directory, which contains configuration files for NumPy packages. This path can be overridden by the `NPY_PKG_CONFIG_PATH` environment variable, useful for cross-compilation scenarios.

- **get_pkg_info(pkgname, dirs=None)**  
  Retrieves build information for a specified package by reading its `.ini` configuration files from the `npy-pkg-config` directories.

- **get_info(pkgname, dirs=None)**  
  Returns a dictionary of build options for a given C library package, suitable for use in extension building. It parses compiler and linker flags from the package configuration.

- **is_bootstrapping()**  
  Checks if the current environment is in the process of bootstrapping NumPy, by detecting a special built-in attribute.

- **default_config_dict(name=None, parent_name=None, local_path=None)**  
  Returns a configuration dictionary for use in setup scripts. This function is deprecated in favor of using the `Configuration` class directly.

- **dict_append(d, **kws)**  
  Utility function to append values to lists in a dictionary or set new keys if they do not exist.

- **appendpath(prefix, path)**  
  Joins two filesystem paths, handling platform-specific path separators and drive letters.

Temporary Directory Management
------------------------------

The module manages temporary directories created during build processes, ensuring that each thread creates only one temporary directory and that all temporary directories are cleaned up upon program exit.

Color Terminal Utilities
------------------------

Functions such as `red_text`, `green_text`, `yellow_text`, `blue_text`, and `cyan_text` provide colored text output in terminals that support colors, enhancing the readability of build logs.

Usage Notes
-----------

- The module integrates closely with NumPy's build system, providing utilities to locate NumPy headers and libraries.
- It supports parallel builds, respecting user-specified parallelism levels or environment variables.
- The package configuration system allows for flexible inclusion of external libraries and packages through `.ini` configuration files.
- Deprecated functions and warnings guide users towards preferred modern interfaces.

See Also
--------

- `Configuration` class for managing build configurations.
- `numpy.distutils.npy_pkg_config` for handling NumPy package configuration files.
- `distutils.core` for core distutils functionality.
- `distutils.errors.DistutilsError` for error handling within distutils.

This module is essential for developers extending Python with compiled code, especially when integrating with NumPy and other scientific computing libraries.
