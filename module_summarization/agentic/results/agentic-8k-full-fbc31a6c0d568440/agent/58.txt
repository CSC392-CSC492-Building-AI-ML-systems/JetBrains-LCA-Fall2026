Optimization Module
===================

This module provides a collection of general-purpose optimization functions and classes designed to be used for fitting statistical models. The functions are designed to be independent of any specific model class, allowing for flexible reuse across different model fitting scenarios.

Overview
--------

The core functionality revolves around fitting models by minimizing or maximizing objective functions, typically log-likelihood functions, using a variety of optimization algorithms. The module supports multiple optimization methods, including Newton-Raphson, BFGS, L-BFGS-B, Nelder-Mead, Powell, conjugate gradient, Newton-conjugate gradient, and global basin-hopping solvers.

Key Components
--------------

### Optimizer Class

The `Optimizer` class encapsulates the fitting process with a generic `_fit` method that can handle different optimization methods. It accepts an objective function, its gradient, starting parameters, and various options controlling the optimization process.

#### `_fit` Method

- **Parameters:**
  - `objective`: The function to minimize or maximize.
  - `gradient`: The gradient (score) of the objective function.
  - `start_params`: Initial guess for the parameters.
  - `fargs`: Additional arguments passed to the objective function.
  - `kwargs`: Additional keyword arguments for the optimizer.
  - `hessian`: Optional Hessian function.
  - `method`: Optimization method to use (e.g., 'newton', 'bfgs', 'nm', 'powell', 'cg', 'ncg', 'basinhopping', 'minimize').
  - `maxiter`: Maximum number of iterations.
  - `full_output`: Whether to return detailed output.
  - `disp`: Whether to display convergence messages.
  - `callback`: Function called after each iteration.
  - `retall`: Whether to return all intermediate solutions.

- **Returns:**
  - `xopt`: Optimized parameters.
  - `retvals`: Dictionary of solver-specific output if `full_output` is True, otherwise None.
  - `optim_settings`: Dictionary of optimization settings used.

- **Notes:**
  - The 'basinhopping' method ignores some arguments like `maxiter`, `retall`, and `full_output`.
  - Each solver supports different optional arguments; refer to the solver-specific documentation for details.

### Standalone Fit Functions

The module also provides standalone functions implementing specific optimization algorithms:

- `_fit_bfgs`: Uses the Broyden-Fletcher-Goldfarb-Shanno (BFGS) algorithm.
- `_fit_lbfgs`: Uses the Limited-memory BFGS (L-BFGS-B) algorithm, supporting bound constraints.
- `_fit_nm`: Uses the Nelder-Mead simplex algorithm.

These functions accept the objective function, its gradient, starting parameters, and various options, returning optimized parameters and detailed solver output when requested.

### Method Validation

The helper function `_check_method` validates that the specified optimization method is among the supported methods, raising a `ValueError` if not.

Usage Notes
-----------

- The optimization functions expect the objective function to return the negative log-likelihood (or a similar scalar objective to minimize).
- Gradients (scores) should correspond to the objective function and are used when available to improve optimization efficiency.
- The module supports callbacks to monitor or modify the optimization process at each iteration.
- Detailed solver outputs include convergence status, number of iterations, function evaluations, and other diagnostic information.
- Constraints support is noted as a TODO and is not currently implemented.

Supported Optimization Methods
------------------------------

- **newton**: Newton-Raphson method using objective, gradient, and optionally Hessian.
- **bfgs**: Quasi-Newton method using BFGS update.
- **lbfgs**: Limited-memory BFGS with optional bounds.
- **nm**: Nelder-Mead simplex algorithm.
- **powell**: Powell’s conjugate direction method.
- **cg**: Conjugate gradient method.
- **ncg**: Newton-conjugate gradient method.
- **basinhopping**: Global optimization using basin-hopping algorithm.
- **minimize**: Wrapper for `scipy.optimize.minimize` allowing flexible method selection.
