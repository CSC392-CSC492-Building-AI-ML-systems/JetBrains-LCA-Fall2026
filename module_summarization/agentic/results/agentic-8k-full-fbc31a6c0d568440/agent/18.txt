w_bins Command
==============

Overview
--------
The `w_bins` command is a versatile tool for displaying information and statistics about binning in a WEST simulation, as well as modifying the binning for the current iteration of a WEST simulation.

This command provides two main subcommands:

- `info`: Display information about the current binning.
- `rebin`: Rebuild the current iteration with new binning.

Usage
-----

```
w_bins <subcommand> [options]
```

Subcommands
-----------

### info

Display information about binning for a specified iteration.

**Options:**

- `-n`, `--n-iter` *N_ITER*  
  Consider initial points of segment *N_ITER*. Defaults to the current iteration if not specified.

- `--detail`  
  Display detailed per-bin information in addition to summary information.

- Binning options inherited from the binning component (e.g., bin definitions).

**Description:**

The `info` subcommand prints bin information for the specified iteration, including bin counts and weights. It uses the initial progress coordinates of the iteration's segments to assign bins and then summarizes the binning statistics. When the `--detail` flag is provided, detailed per-bin information is also displayed.

---

### rebin

Rebuild the current iteration with new binning.

**Options:**

- `--confirm`  
  Commit the revised iteration to the HDF5 file. Without this option, the effects of the new binning are only calculated and printed, but not saved.

- `--detail`  
  Display detailed per-bin information in addition to summary information.

- `-n`, `--n-iter` *N_ITER*  
  Consider initial points of segment *N_ITER*. Defaults to the current iteration if not specified.

- Binning options inherited from the binning component, except `--bins-from-file` is suppressed.

- Target count options for specifying desired counts per bin.

**Description:**

The `rebin` subcommand allows rebuilding the current iteration's binning scheme according to new bin definitions and target counts. It operates on the initial points of the specified iteration's segments and recalculates bin assignments and weights accordingly.

**Important Notes:**

- Rebinning is **not supported** for the first iteration. Attempting to rebin iteration 1 will result in an error message advising to reinitialize with `w_init` instead.

- Without the `--confirm` flag, changes are only simulated and printed; the HDF5 data is not modified.

---

General Behavior
----------------

- The command reads WEST simulation data using the `WESTDataReader` and manages binning through the `BinMappingComponent`.

- The iteration number defaults to the current iteration if not explicitly provided.

- Detailed bin information includes per-bin counts, weights, and assignments.

- The tool integrates with WESTPA's data management and driver components to ensure consistency when rebinding.

Examples
--------

Display binning information for the current iteration with detailed output:

```
w_bins info --detail
```

Display binning information for iteration 5:

```
w_bins info -n 5
```

Simulate rebinning for the current iteration with detailed output (without committing changes):

```
w_bins rebin --detail
```

Rebin the current iteration and commit changes to the HDF5 file:

```
w_bins rebin --confirm
```

Rebin iteration 10 with new bin definitions and target counts (assuming appropriate binning options are provided):

```
w_bins rebin -n 10 --confirm [binning options] [target count options]
```

Logging
-------

The `w_bins` command uses the logger named `w_bins` for diagnostic and error messages.

---

For more detailed information on binning options and target counts, refer to the documentation of the binning component used by WESTPA.
