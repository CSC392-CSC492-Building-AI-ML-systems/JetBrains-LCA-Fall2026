# General Plotting Routines

This document provides an overview of the general plotting routines available for creating various types of plots using interactive and static plotting libraries. These routines are designed to handle common plotting tasks with flexibility and customization options.

---

## bokeh_line

Creates an interactive line plot using Bokeh with support for multiple plot types including line, scatter, and area plots.

### Parameters
- `plot_data`: Data to be plotted, typically a dictionary or similar structure containing x and y values.
- `title`: Title of the plot.
- `xlabel`: Label for the x-axis.
- `ylabel`: Label for the y-axis.
- `figure`: Optional Bokeh figure object to plot on.
- `plot_points`: Boolean indicating whether to plot scatter points on top of the line.
- `area_curve`: Optional parameter to specify area plot curves.
- `**kwargs`: Additional keyword arguments passed to the plotting functions.

### Features
- Supports horizontal and vertical area plots.
- Automatically sets color palettes based on the number of plots.
- Adds tooltips for interactive data inspection.
- Supports multiple levels for layering plots.
- Draws straight lines, sets axis limits, legends, and saves the plot.

---

## bokeh_dos

Creates an interactive Density of States (DOS) plot using Bokeh, supporting both horizontal and vertical orientations.

### Parameters
- `energy_grid`: Array-like or key data for the energy grid.
- `dos_data`: Array-like or key data for the DOS.
- `data`: Optional data source (e.g., pandas DataFrame).
- `energy_label`: Label for the energy axis (default: '$$E-E_F [eV]$$').
- `dos_label`: Label for the DOS axis (default: 'DOS [1/eV]').
- `title`: Title of the figure.
- `xyswitch`: Boolean to switch energy axis orientation.
- `e_fermi`: Float indicating the Fermi energy line position.
- `saveas`: Filename for saving the plot.
- `copy_data`: Boolean indicating whether to copy the data.
- `**kwargs`: Additional keyword arguments passed to the underlying `bokeh_line()` function.

### Features
- Supports deprecated usage with warnings.
- Automatically determines DOS data columns if not provided.
- Provides interactive visualization of DOS with customizable labels and title.

---

## waterfall_plot

Creates a standard 3D waterfall plot using Matplotlib.

### Parameters
- `xdata`: Array-like data for the x coordinate.
- `ydata`: Array-like data for the y coordinate.
- `zdata`: Array-like data for the z coordinate.
- `data`: Optional data source (e.g., pandas DataFrame).
- `xlabel`: Label for the x-axis.
- `ylabel`: Label for the y-axis.
- `zlabel`: Label for the z-axis.
- `title`: Title of the figure.
- `axis`: Optional Matplotlib Axes object to plot on.
- `saveas`: Filename for saving the plot.
- `copy_data`: Boolean indicating whether to copy the data.
- `**kwargs`: Additional keyword arguments passed to the Matplotlib scatter3D function or plotter.

### Features
- Supports 3D scatter and surface plotting.
- Automatically sets color limits based on z-data.
- Configurable markersize, linewidth, and color maps.
- Supports saving the plot to file.

---

## multiplot_moved

Plots multiple scatter plots stacked vertically by adding an offset to the y-data.

### Parameters
- `xdata`: Array-like data for the x coordinate.
- `ydata`: Array-like data for the y coordinate.
- `data`: Optional data source (e.g., pandas DataFrame).
- `xlabel`: Label for the x-axis.
- `ylabel`: Label for the y-axis.
- `title`: Title of the figure.
- `scale_move`: Float scaling factor for the vertical offset.
- `min_add`: Minimum vertical offset added.
- `saveas`: Filename for saving the plot.
- `copy_data`: Boolean indicating whether to copy the data.
- `**kwargs`: Additional keyword arguments passed to the underlying `multiple_scatterplots()` function.

### Features
- Automatically calculates vertical shifts to separate plots.
- Clears y-axis ticks and labels by default to avoid clutter.
- Useful for visualizing multiple datasets stacked vertically.

---

## histogram

Creates a histogram plot with various customization options.

### Parameters
- `xdata`: Data for the histogram.
- `density`: Boolean indicating whether to plot a density histogram.
- `histtype`: Type of histogram (e.g., 'bar').
- `align`: Alignment of the bars.
- `orientation`: Orientation of the histogram ('vertical' or 'horizontal').
- `log`: Boolean to use logarithmic scale.
- `**kwargs`: Additional keyword arguments passed to the plotting function.

---

# Notes

- All plotting functions support passing a `data` argument, which can be a pandas DataFrame or similar structure, allowing flexible data input.
- Most functions support a `saveas` parameter to save the generated plot to a file.
- The plotting routines handle setting axis labels, titles, legends, colorbars, and limits automatically or via parameters.
- Interactive plots use Bokeh, while static plots use Matplotlib.
- The plotting routines include error handling and consistency checks to ensure robustness.

---

This set of general plotting routines provides a comprehensive toolkit for creating interactive and static visualizations tailored to scientific and data analysis needs.
