Working with User Security Roles
================================

User security roles in ftrack define the permissions and access levels assigned to users within the system. Managing these roles effectively is crucial for maintaining secure and organized project workflows.

Overview
--------

Security roles determine what actions a user can perform and what data they can access. Assigning appropriate roles ensures that users have the necessary privileges without exposing sensitive information or administrative capabilities unnecessarily.

Assigning Security Roles
------------------------

Users can be assigned one or more security roles to tailor their access rights. This assignment is typically managed through the ftrack API or the user interface.

Example: Assigning a Role to a User
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

```python
# Assuming 'session' is an authenticated ftrack Session instance
user = session.query('User where username is "jdoe"').one()
role = session.query('SecurityRole where name is "Artist"').one()

# Assign the role to the user
user['security_roles'].append(role)
session.commit()
```

Retrieving User Roles
---------------------

To check which security roles are assigned to a user, you can query the user's `security_roles` attribute.

```python
user = session.query('User where username is "jdoe"').one()
for role in user['security_roles']:
    print(role['name'])
```

Creating and Managing Security Roles
------------------------------------

Security roles can be created and customized to fit the needs of your organization. This includes defining specific permissions and access scopes.

Example: Creating a New Security Role
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

```python
new_role = session.create('SecurityRole', {
    'name': 'NewRoleName',
    'description': 'Description of the new role'
})
session.commit()
```

Best Practices
--------------

- Assign the least privilege necessary for users to perform their tasks.
- Regularly review and update security roles to reflect changes in project requirements.
- Use descriptive names and documentation for roles to clarify their purpose.

Summary
-------

Managing user security roles is a fundamental part of maintaining a secure and efficient ftrack environment. By properly assigning and managing these roles, you ensure that users have appropriate access aligned with their responsibilities.
