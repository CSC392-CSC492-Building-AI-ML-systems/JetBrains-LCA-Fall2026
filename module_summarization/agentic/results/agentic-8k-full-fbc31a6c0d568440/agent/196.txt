Multiclass and Multioutput Algorithms
=====================================

Overview
--------

Multiclass and multioutput algorithms extend traditional binary classification and regression methods to handle multiple classes or multiple outputs simultaneously. These algorithms are essential for solving complex problems where the target variable can take on more than two categories (multiclass) or where multiple target variables need to be predicted at once (multioutput).

Multiclass Classification
-------------------------

Multiclass classification involves predicting one label from three or more possible classes. Unlike binary classification, which distinguishes between two classes, multiclass classifiers assign each input sample to one of several classes.

Key Points:
- Multiclass targets can be represented as 1-dimensional arrays of integer labels or as 2-dimensional arrays with shape `(n_samples, 1)`.
- Stratified cross-validation techniques, such as `StratifiedKFold`, are used to maintain the distribution of classes across folds.
- Classifiers should be tested on both binary and multiclass datasets to ensure compatibility.
- Label encoding can be used to convert string labels to numeric form for classifier compatibility.

Example:
```python
y_multiclass = np.array([0, 1, 0, 1, 2, 1, 2, 0, 2])
cv = check_cv(3, y_multiclass, classifier=True)
np.testing.assert_equal(
    list(StratifiedKFold(3).split(X, y_multiclass)), list(cv.split(X, y_multiclass))
)
```

Multioutput Classification and Regression
-----------------------------------------

Multioutput algorithms predict multiple target variables simultaneously. This can apply to classification problems where each sample has multiple labels (multiclass-multioutput) or regression problems with multiple continuous outputs (continuous-multioutput).

Key Points:
- Multioutput targets are typically represented as 2-dimensional arrays with shape `(n_samples, n_outputs)`.
- Multioutput regression can handle multiple continuous outputs, while multioutput classification handles multiple discrete outputs.
- Evaluation metrics and cross-validation strategies must account for multiple outputs.
- Multioutput support is tested by fitting estimators on datasets with multiple outputs and verifying consistent predictions.

Example:
```python
y_multioutput = np.vstack([y, 2 * y + rnd.randint(2, size=len(y))]).T
regressor.fit(X, y_multioutput)
predictions = regressor.predict(X)
```

Handling Labels and Targets
---------------------------

- Labels for multiclass problems can be integers, strings, or other categorical types.
- It is important to ensure that labels are consistent and correctly encoded before training.
- Functions like `_choose_check_classifiers_labels` help in selecting appropriate label formats for testing classifiers.
- For multioutput problems, the shape and consistency of `y_true` and `y_pred` must be verified to avoid errors.

Cross-Validation and Testing
----------------------------

- Cross-validation strategies such as `StratifiedKFold` are adapted for multiclass classification to preserve class proportions.
- Tests ensure that classifiers and regressors handle multiclass and multioutput data correctly.
- Estimators are cloned and tested with different random states to verify reproducibility.
- Error handling is implemented to catch malformed inputs or inconsistent target shapes.

Evaluation Metrics
------------------

- Metrics like mean absolute error (MAE) support multioutput evaluation by averaging errors across outputs.
- The `multioutput` parameter controls how errors are aggregated, with options such as `"raw_values"`, `"uniform_average"`, and `"variance_weighted"`.
- Consistent length and shape checks are performed on true and predicted targets before metric computation.

Summary
-------

Multiclass and multioutput algorithms provide powerful tools for handling complex prediction tasks involving multiple classes or multiple target variables. Proper handling of labels, target shapes, cross-validation, and evaluation metrics is crucial for developing robust and reliable models in these settings.
