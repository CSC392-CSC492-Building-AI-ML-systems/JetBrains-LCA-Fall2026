w_states command
================

Overview
--------

The `w_states` command is used to display or manipulate basis (initial) or target (recycling) states for a WEST simulation. By default, it displays the current states or dumps them to files. It also supports replacing or appending states for the next iteration of the simulation.

Modes of Operation
------------------

The command supports three mutually exclusive modes of operation:

- **--show** (default):  
  Display the current basis and target states or dump them to specified files.

- **--replace**:  
  Replace the current basis or target states with those specified by the user for the next iteration.

- **--append**:  
  Append the given target states to those currently in use for the next iteration.  
  *Note:* Appending basis states is not permitted due to the complexity of renormalizing probabilities. Instead, use the `--show` mode to export basis states, edit them externally, and then use `--replace` to update.

Arguments
---------

- **--bstate-file BSTATE_FILE**  
  Read (with `--append` or `--replace`) or write (with `--show`) basis state names, probabilities, and data references from or to the specified file.

- **--bstate 'label,probability[,auxref]'**  
  Add a basis state specified as a string with the format `'label,probability[,auxref]'`. Multiple `--bstate` options can be provided to add multiple states. These states are appended after those specified in `--bstate-file`, if any.

- **--tstate-file TSTATE_FILE**  
  Read (with `--append` or `--replace`) or write (with `--show`) target state names and representative progress coordinates from or to the specified file.

- **--tstate 'label,pcoord0[,pcoord1[,...]]'**  
  Add a target state specified as a string with the format `'label,pcoord0[,pcoord1[,...]]'`. Multiple `--tstate` options can be provided to add multiple states. These states are appended after those specified in `--tstate-file`, if any.

Additional Options
------------------

- WESTPA runtime configuration options can be passed to customize the environment and simulation parameters.

- Work manager arguments can be specified to control parallel execution and resource management.

Usage Notes
-----------

- When replacing basis states, the probabilities are checked and rescaled if they do not sum to unity, with a warning issued.

- Basis states are assigned progress coordinates automatically by the simulation manager.

- Target states can be appended only; appending basis states is disallowed to avoid errors in probability normalization.

- If the current iteration has completed segments, new states are applied to the next iteration.

Examples
--------

1. Display current basis and target states:

   ```
   w_states --show
   ```

2. Dump basis states to a file:

   ```
   w_states --show --bstate-file bstates.txt
   ```

3. Replace basis states from a file:

   ```
   w_states --replace --bstate-file bstates.txt
   ```

4. Append target states from command line:

   ```
   w_states --append --tstate 'state1,0.1,0.2' --tstate 'state2,0.3,0.4'
   ```

5. Replace target states from a file and add additional states:

   ```
   w_states --replace --tstate-file tstates.txt --tstate 'state3,0.5,0.6'
   ```

Error Handling
--------------

- Attempting to append basis states will result in an error message and termination. Use the recommended workflow of exporting, editing, and replacing basis states instead.

- If no target states are specified when required, a status message is printed indicating the absence of target states.

Logging and Output
------------------

- The command logs warnings if basis state probabilities do not sum to unity and rescales them accordingly.

- Reports of basis and target states are printed to standard output or saved to specified files.

- Progress and status messages are provided to inform the user of actions taken, such as applying new states to the next iteration.

Summary
-------

The `w_states` command is a versatile tool for managing the initial and recycling states in WEST simulations, providing capabilities to inspect, replace, and append states with careful handling of probabilities and iteration management.
