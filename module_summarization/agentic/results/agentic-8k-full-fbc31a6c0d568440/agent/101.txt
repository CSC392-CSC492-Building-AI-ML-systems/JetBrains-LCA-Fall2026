Miner
=====

The `Miner` class provides an interface to interact with the Ethereum miner through the Web3.py library. It allows you to query mining-related information and control the mining process by sending requests to the Ethereum node.

Initialization
--------------

`Miner(web3)`

- **web3**: An instance of the Web3 class used to communicate with the Ethereum node.

Properties
----------

hashrate
~~~~~~~~

- **Type:** int

Returns the current mining hashrate of the node.

Example:

```python
current_hashrate = miner.hashrate
```

Methods
-------

makeDAG(number)
~~~~~~~~~~~~~~

Generate a DAG (Directed Acyclic Graph) for the specified epoch number.

- **number** (`int`): The epoch number for which to generate the DAG.

Returns the result of the `miner_makeDag` RPC call.

Example:

```python
miner.makeDAG(42)
```

setExtra(extra)
~~~~~~~~~~~~~~

Set the extra data field for the miner.

- **extra** (`str`): The extra data to set.

Returns the result of the `miner_setExtra` RPC call.

Example:

```python
miner.setExtra("0x1234abcd")
```

setEtherBase(etherbase)
~~~~~~~~~~~~~~~~~~~~~~

Set the etherbase (coinbase) address for the miner. This is the address that will receive mining rewards.

- **etherbase** (`str`): The Ethereum address to set as the etherbase.

Returns the result of the `miner_setEtherbase` RPC call.

Example:

```python
miner.setEtherBase("0xabc123...")
```

setGasPrice(gas_price)
~~~~~~~~~~~~~~~~~~~~~~

Set the gas price for the miner.

- **gas_price** (`int`): The gas price in wei.

Returns the result of the `miner_setGasPrice` RPC call.

Example:

```python
miner.setGasPrice(20000000000)
```

start(num_threads)
~~~~~~~~~~~~~~~~~~

Start the miner with the specified number of threads.

- **num_threads** (`int`): Number of CPU threads to use for mining.

Returns the result of the `miner_start` RPC call.

Example:

```python
miner.start(4)
```

stop()
~~~~~~

Stop the miner.

Returns the result of the `miner_stop` RPC call.

Example:

```python
miner.stop()
```

startAutoDAG()
~~~~~~~~~~~~~

Start automatic DAG generation.

Returns the result of the `miner_startAutoDag` RPC call.

Example:

```python
miner.startAutoDAG()
```

stopAutoDAG()
~~~~~~~~~~~~

Stop automatic DAG generation.

Returns the result of the `miner_stopAutoDag` RPC call.

Example:

```python
miner.stopAutoDAG()
```
