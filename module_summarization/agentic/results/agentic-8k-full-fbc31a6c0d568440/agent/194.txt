Pairwise Metrics, Affinities and Kernels
========================================

This section documents the available pairwise metrics, affinities, and kernels that can be used to compute distances or similarities between samples in datasets. These functions are fundamental in many machine learning algorithms, including clustering, classification, and dimensionality reduction.

Pairwise Distance Metrics
-------------------------

Pairwise distance metrics compute the distance between pairs of samples. The following distance metrics are supported:

+------------------+---------------------------------------------------------+
| Metric           | Function                                                |
+==================+=========================================================+
| 'cityblock'      | :func:`metrics.pairwise.manhattan_distances`           |
| 'cosine'         | :func:`metrics.pairwise.cosine_distances`              |
| 'euclidean'      | :func:`metrics.pairwise.euclidean_distances`           |
| 'haversine'      | :func:`metrics.pairwise.haversine_distances`           |
| 'l1'             | :func:`metrics.pairwise.manhattan_distances`           |
| 'l2'             | :func:`metrics.pairwise.euclidean_distances`           |
| 'manhattan'      | :func:`metrics.pairwise.manhattan_distances`           |
| 'nan_euclidean'  | :func:`metrics.pairwise.nan_euclidean_distances`       |
| 'precomputed'    | Use a precomputed distance matrix (no function called) |
+------------------+---------------------------------------------------------+

These metrics can be accessed programmatically via the function ``distance_metrics()``, which returns a dictionary mapping metric names to their corresponding functions.

Note
~~~~
- The 'precomputed' metric assumes that the input is already a distance matrix and does not perform any computation.
- The 'l1' and 'manhattan' metrics are aliases for 'cityblock'.
- The 'l2' metric is an alias for 'euclidean'.

For more details, see the :ref:`User Guide <metrics>`.

Pairwise Kernels
----------------

Kernels compute similarity measures between samples and are widely used in kernel methods such as Support Vector Machines and Kernel PCA.

The following kernels are supported:

+-------------------+--------------------------------------------------------------+
| Kernel            | Function                                                     |
+===================+==============================================================+
| 'additive_chi2'   | :func:`sklearn.pairwise.additive_chi2_kernel`               |
| 'chi2'            | :func:`sklearn.pairwise.chi2_kernel`                        |
| 'linear'          | :func:`sklearn.pairwise.linear_kernel`                      |
| 'poly'            | :func:`sklearn.pairwise.polynomial_kernel`                  |
| 'polynomial'      | :func:`sklearn.pairwise.polynomial_kernel`                  |
| 'rbf'             | :func:`sklearn.pairwise.rbf_kernel`                         |
| 'laplacian'       | :func:`sklearn.pairwise.laplacian_kernel`                   |
| 'sigmoid'         | :func:`sklearn.pairwise.sigmoid_kernel`                     |
| 'cosine'          | :func:`sklearn.pairwise.cosine_similarity`                  |
| 'precomputed'     | Use a precomputed kernel matrix (no function called)        |
+-------------------+--------------------------------------------------------------+

These kernels can be accessed programmatically via the function ``kernel_metrics()``, which returns a dictionary mapping kernel names to their corresponding functions.

Kernel Parameters
~~~~~~~~~~~~~~~~~

Some kernels accept additional parameters to control their behavior:

- **additive_chi2**: No parameters.
- **chi2**: accepts parameter `gamma`.
- **cosine**: No parameters.
- **linear**: No parameters.
- **poly** / **polynomial**: accepts parameters `gamma`, `degree`, and `coef0`.
- **rbf**: accepts parameter `gamma`.
- **laplacian**: accepts parameter `gamma`.
- **sigmoid**: accepts parameters `gamma` and `coef0`.

These parameters can be passed as keyword arguments when calling kernel functions.

Using Pairwise Kernels
~~~~~~~~~~~~~~~~~~~~~~

The function ``pairwise_kernels`` computes the kernel matrix between arrays `X` and optionally `Y`. It supports all the kernels listed above and also accepts custom callable metrics.

Parameters
~~~~~~~~~~

- **X** : array-like or sparse matrix of shape (n_samples_X, n_features) or (n_samples_X, n_samples_X)
  
  Input data or kernel matrix. If `metric='precomputed'`, `X` is assumed to be a kernel matrix.

- **Y** : array-like or sparse matrix of shape (n_samples_Y, n_features), default=None
  
  Optional second input data array. If provided, computes the kernel between `X` and `Y`.

- **metric** : str or callable, default='linear'
  
  The kernel to use. Must be one of the supported kernel names or a callable function. If 'precomputed', `X` is assumed to be a kernel matrix.

- **filter_params** : bool, default=False
  
  Whether to filter out invalid parameters for the kernel function.

- **n_jobs** : int or None, default=None
  
  The number of jobs to run in parallel for kernel computation.

- **\*\*kwds** : additional keyword arguments
  
  Additional parameters to pass to the kernel function.

Returns
~~~~~~~

- **K** : ndarray of shape (n_samples_X, n_samples_Y)
  
  Kernel matrix computed between samples in `X` and `Y`.

Notes
~~~~~

- If `Y` is None, the kernel matrix between `X` and itself is computed.
- If `metric` is a callable, it should take two 1-D arrays and return a scalar.
- The function supports parallel computation to speed up kernel matrix calculation.

For more information, see the :ref:`User Guide <metrics>`.

Helper Functions and Utilities
------------------------------

- **_parallel_pairwise**: Computes pairwise metrics or kernels in parallel by splitting the computation into slices.
- **_pairwise_callable**: Handles the case when the metric or kernel is a callable function.
- **_dist_wrapper**: Helper to write computed distances into a slice of the output matrix.
- **_check_chunk_size**: Validates the size of chunks when reducing results in parallel computations.

Summary
-------

This module provides a comprehensive set of pairwise distance metrics and kernels, along with utilities to compute them efficiently, including support for parallel computation and callable custom metrics. These tools enable flexible and efficient computation of similarities and distances essential for many machine learning algorithms.
