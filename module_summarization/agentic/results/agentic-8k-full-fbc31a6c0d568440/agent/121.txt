Create Cradmin menu system
==========================

The Cradmin menu system provides a flexible and extensible way to create menus in your Django applications using renderable components. This documentation describes the core classes and methods used to build and customize menus with Cradmin.

AbstractMenuRenderable
----------------------

`AbstractMenuRenderable` is the base class for creating menu renderables. It manages a list of renderable items and provides methods to create and manipulate menu components such as links, buttons, and separators.

### Initialization

```python
def __init__(self, request, cradmin_instance=None):
```

- `request`: The current HTTP request.
- `cradmin_instance`: Optional Cradmin instance associated with the menu.

### Managing Renderables

- `iter_renderables()`: Returns an iterator over the renderable items in the menu.
- `insert(index, renderable_object)`: Inserts a renderable object at the specified index.
- `prepend(renderable_object)`: Prepends a renderable object to the beginning of the menu.
- `append(renderable_object)`: Appends a renderable object to the end of the menu.
- `extend(renderable_iterable)`: Extends the menu with an iterable of renderable objects.

### Renderable Classes

The class provides methods to get the renderable classes for different menu components. These methods raise a `ValueError` if the corresponding class is not defined.

- `get_link_renderable_class()`: Returns the class used for link renderables.
- `get_separator_renderable_class()`: Returns the class used for separator renderables.
- `get_button_renderable_class()`: Returns the class used for button renderables.

### Creating Renderables

- `make_child_renderable_kwargs(**kwargs)`: Prepares keyword arguments for child renderables, adding the `parent_bem_block` key by default.
- `make_link_renderable(**kwargs)`: Creates a link renderable instance.
- `make_separator_renderable(**kwargs)`: Creates a separator renderable instance.
- `make_button_renderable(**kwargs)`: Creates a button renderable instance.

### BEM Block Handling

- `get_child_renderable_parent_bem_block()`: Must be implemented by subclasses to return the BEM block name for child renderables.

DefaultMainMenuRenderable
-------------------------

`DefaultMainMenuRenderable` is the default renderable for large screen (desktop) menus.

### Attributes

- `template_name`: Template used for rendering the main menu (`django_cradmin/crmenu/menu/default-main.django.html`).
- `menutoggle_renderable_class`: Class used for the menu toggle item.
- `link_renderable_class`: Class used for navigation link items.
- `button_renderable_class`: Class used for navigation link buttons.

### Methods

- `get_wrapper_htmltag_id()`: Returns the HTML id attribute for the menu wrapper (`id_django_cradmin_menu_main`).
- `get_menutoggle_renderable()`: Returns an instance of the menu toggle renderable.
- `cached_menutoggle_renderable`: Cached property for the menu toggle renderable.
- `expandable_menu_renderable`: Returns the expandable menu renderable associated with the Cradmin instance or the default one.
- `has_expandable_menu_renderable()`: Returns `True` if an expandable menu renderable is available.
- `should_render_menutoggle()`: Returns `True` if the menu toggle should be rendered.
- `get_child_renderable_parent_bem_block()`: Returns the BEM block name for child renderables (`adminui-page-header`).
- `get_bem_block_or_element()`: Returns the BEM block or element name for the menu (`adminui-page-header__nav`).
- `__bool__()`: Returns `True` if the menu has renderables or an expandable menu.

DefaultExpandableMenuRenderable
-------------------------------

`DefaultExpandableMenuRenderable` is the default renderable for small screen (mobile) expandable menus.

### Attributes

- `template_name`: Template used for rendering the expandable menu (`django_cradmin/crmenu/menu/default-expandable.django.html`).
- `link_renderable_class`: Class used for expandable menu items.
- `separator_renderable_class`: Class used for expandable menu separators.
- `button_renderable_class`: Not used (set to `None`).

### Methods

- `get_wrapper_htmltag_id()`: Returns the HTML id attribute for the expandable menu wrapper (`id_django_cradmin_menu_expandable`).
- `get_bem_block_or_element()`: Returns the BEM block or element name for the expandable menu (`expandable-menu`).
- `get_child_renderable_parent_bem_block()`: Returns the BEM block name for child renderables (same as `get_bem_block_or_element()`).

Usage Overview
--------------

To create a Cradmin menu, subclass `AbstractMenuRenderable` or use one of the provided default renderables (`DefaultMainMenuRenderable` for desktop and `DefaultExpandableMenuRenderable` for mobile). Add renderable items such as links, buttons, and separators to the menu using the provided methods (`append`, `prepend`, `insert`, `extend`).

Customize the appearance and behavior by overriding methods to specify renderable classes, templates, and BEM block names.

The menu system supports responsive design by providing separate renderables for large and small screens, with toggle functionality to switch between them.

This modular approach allows you to build complex, accessible, and maintainable menus tailored to your application's needs.
