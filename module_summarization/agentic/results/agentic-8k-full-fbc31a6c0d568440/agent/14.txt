Querying
========

The querying functionality allows you to retrieve entities from the server using query expressions. Queries can be executed with or without specifying projections, and the results are returned as query result objects or as lists of entities along with accompanying metadata.

Basic Querying
--------------

To perform a query, you can use an expression string that specifies the entities and conditions you want to retrieve. If no projections are specified in the query expression (i.e., the expression does not start with `select`), sensible default projections will be added automatically based on the entity type's default projections.

Example:

```python
# Query with default projections
query_result = session.query('Task where status is "in progress"', page_size=100)
```

Here, `page_size` specifies the maximum number of results per page that the returned query result object should be configured with.

Query Result Object
-------------------

The query returns a `QueryResult` object which can be iterated over to access the entities matching the query. This object handles paging transparently.

Executing Queries and Retrieving Records
----------------------------------------

The internal `_query` method executes a query expression and returns a tuple `(records, metadata)`:

- `records`: A list of entities retrieved by the query.
- `metadata`: A dictionary containing additional information about the result set.

Example:

```python
records, metadata = session._query('select id, name from Task where status is "done"')
```

Merging Entities into Session
-----------------------------

When query results are returned, entities are merged into the local session cache to maintain consistency and avoid duplication. The `merge` method can be used to merge a value (entity, collection, or mapped collection) into the session and return the merged value.

```python
merged_entity = session.merge(entity)
```

The merging process handles:

- Single entities (`Entity` instances)
- Collections (`Collection` instances)
- Mapped collection proxies (`MappedCollectionProxy` instances)
- Other values are returned as-is

Recursive Merging
-----------------

The `_merge_recursive` method merges an entity and all its attributes recursively into the session. This ensures that all related entities and their attributes are properly merged and synchronized with the session cache.

Logging
-------

Debug logging is available throughout the querying and merging process to trace the operations performed on entities and collections.
