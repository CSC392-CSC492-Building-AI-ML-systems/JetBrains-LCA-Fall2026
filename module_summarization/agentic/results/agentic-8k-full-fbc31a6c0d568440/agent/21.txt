w_eddist — Calculate time-resolved transition-event duration distributions
=============================================================================

Description
-----------

The `w_eddist` tool calculates time-resolved transition-event duration distributions from kinetics results generated by weighted ensemble simulations. It processes data collected from the output of the `w_kinetics trace` command and produces histograms representing the distribution of event durations over time.

Source Data
-----------

The source data for `w_eddist` is obtained from the results of the `w_kinetics trace` command. This dataset contains information about transition events, including their durations and associated weights. For more information on generating this dataset, see the documentation for `w_kinetics trace`.

Histogram Binning
-----------------

By default, histograms are constructed with 100 bins in each dimension. This default can be overridden using the `-b` or `--bins` option, which accepts several types of arguments:

- **Single integer N**:  
  Use N uniformly spaced bins in each dimension.

- **Sequence of integers N1,N2,... (comma-separated)**:  
  Use N1 bins for the first dimension, N2 for the second, and so on.

- **List of lists [[B11, B12, ...], [B21, B22, ...], ...]**:  
  Specify explicit bin boundaries for each dimension. These boundaries need not be uniformly spaced. The bin boundaries are evaluated as Python expressions with `np` (NumPy) available, allowing use of functions like `np.arange()`.

Note that the first two forms (integer or list of integers) require scanning all data to determine minimum and maximum values for each dimension, which may be computationally expensive for large datasets. Providing explicit bin boundaries avoids this overhead.

**Important:** These bins are unrelated to the bins used to drive weighted ensemble sampling.

Output Format
-------------

The output is stored in an HDF5 file (default: `eddist.h5`), which can be used with the `plothist` tool for visualization or further analysis. The output file contains the following datasets:

- **`histograms`**:  
  Normalized histograms of event durations. The first axis corresponds to iteration number, and subsequent axes correspond to the dimensions of the input dataset.

- **`binbounds_0`, `binbounds_1`, ...**:  
  Arrays of bin boundaries for each dimension.

- **`midpoints_0`, `midpoints_1`, ...**:  
  Arrays of bin midpoints for each dimension.

- **`n_iter`**:  
  Vector of iteration numbers corresponding to the histograms.

Additionally, the `histograms` dataset includes attributes `iter_start` and `iter_stop` indicating the iteration range analyzed.

Subsequent Processing
---------------------

The output file generated by `w_eddist` can be visualized using the `plothist` program. Refer to `plothist --help` for details on plotting and further processing.

Parallelization
---------------

`w_eddist` supports parallelized binning and input data reading. Parallel processing is enabled by default to improve performance on large datasets. For simpler cases or smaller datasets, serial processing can be enabled with the `--serial` option.

Command-Line Options
--------------------

The following are key command-line options available for `w_eddist`:

- `-k`, `--kinetics`  
  Specify the kinetics input file containing populations and transition rates (default: `kintrace.h5`).

- `-o`, `--output`  
  Specify the output file to store results (default: `eddist.h5`).

- `--istate`  
  Initial state index for selecting transition events.

- `--fstate`  
  Final state index for selecting transition events.

- `--iter-start`  
  Iteration number to start analysis (default is 1).

- `--last-iter`  
  Iteration number to end analysis.

- `-b`, `--bins`  
  Specify histogram binning as described above.

- `--ignore-out-of-range`  
  Ignore data points outside the specified bin ranges.

- `--compress`  
  Compress the output HDF5 file.

- `--serial`  
  Disable parallel processing and run in serial mode.

- Progress indicator options are also available to monitor the progress of the computation.

Example Usage
-------------

```bash
w_eddist --istate 1 --fstate 2 -k kintrace.h5 -o eddist.h5 -b 50
```

This command computes the transition-event duration distribution from state 1 to state 2 using 50 bins per dimension, reading data from `kintrace.h5` and writing results to `eddist.h5`.
