GILDAS CLASS File Reader
=======================

Overview
--------

This module provides functionality to read GILDAS CLASS files into Python objects, specifically into instances of `pyspeckit.spectrum.ObsBlock`. CLASS files are a data format used primarily in radio astronomy for spectral data storage.

The module supports multiple versions and types of CLASS files, including single and multiple spectra files with different byte orders and formats.

Key Features
------------

- Reading CLASS files of various versions (v1, v2) and formats (IEEE, VAX, EEEI).
- Parsing file headers and data blocks according to the CLASS file specification.
- Handling different telescope and observation metadata embedded in the files.
- Utilities for interpreting binary data structures and converting them into usable Python data types.
- Timing decorator to measure and log the execution time of functions that read CLASS files.
- Compatibility with both Python 2 and 3 using the `six` library.
- Integration with Astropy for logging and unit handling.

Constants and Dictionaries
--------------------------

- `filetype_dict`: Maps CLASS file type codes to descriptive strings indicating the file format and byte order.
- `fileversion_dict`: Maps file type codes to CLASS file version identifiers.
- `record_lengths`: Defines the length in bytes of records for different CLASS file versions.
- `header_id_numbers`: Maps header ID numbers to their descriptive names, indicating the type of metadata contained.
- `header_id_lengths`: Specifies the expected length of various header sections.
- `filedescv2_nw1`: A constant related to the CLASS file version 2 descriptor length.

Functions
---------

- `print_timing(func)`: A decorator that logs the execution time of the decorated function. Useful for monitoring the performance of file reading operations.
- `ensure_bytes(string)`: Ensures that a given string is converted to bytes, compatible with both Python 2 and 3.
- `_find_index(entry_number, file_description, return_position=False)`: Computes the position of an entry index within the CLASS file based on the entry number and file description.
- `_read_index(f, filetype='v1', DEBUG=False, clic=False, position=None, entry_number=None, file_description=None)`: Reads an index entry from the CLASS file, returning metadata about a specific observation or data block.

Data Structures
---------------

The module defines several data structures and mappings to interpret the binary layout of CLASS files, including observation metadata fields such as observation number, version, telescope name, observation date, coordinates, and system temperature.

Usage
-----

The primary use case is to load CLASS files into Python for further analysis or visualization. The module reads the binary data, interprets the headers and data blocks, and constructs Python objects representing the observations.

Example (conceptual):

```python
from classfile_reader import read_class_file

obs_block = read_class_file('example.class')
print(obs_block)
```

Dependencies
------------

- `pyspeckit`: For spectrum data structures.
- `astropy`: For logging, units, and FITS file handling.
- `numpy`: For numerical operations.
- `six`: For Python 2 and 3 compatibility.

Notes
-----

- The module includes partial support for progress indication during file reading, with a fallback to no progress bar if `astropy.utils.console.ProgressBar` is unavailable.
- Some parts of the CLASS file format, especially private or less common header sections, are marked as "private" or "untested".
- The module is designed to handle large CLASS files efficiently, with indexing and record length calculations to optimize file access.

References
----------

- CLASS file format specification: http://iram.fr/IRAMFR/GILDAS/doc/html/class-html/node58.html
- GILDAS CLASS software documentation.

This module is essential for astronomers and researchers working with spectral data stored in CLASS files, enabling seamless integration of CLASS data into Python-based analysis workflows.
