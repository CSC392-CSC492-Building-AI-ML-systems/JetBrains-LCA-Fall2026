Using Review Sessions
=====================

Overview
--------

Review sessions provide a collaborative environment where users can share and review content efficiently. This documentation covers how to manage review sessions, including sending invites to participants.

Sending Invites to Review Sessions
----------------------------------

You can send invitations to users to join a review session using the provided methods. Invites are represented by instances of the `ReviewSessionInvitee` class.

### Sending a Single Invite

To send an invite to a single invitee, use the method:

```python
send_review_session_invite(invitee)
```

- **Parameters:**
  - `invitee`: An instance of `ReviewSessionInvitee` representing the user to invite.
  
- **Notes:**
  - The `invitee` must be committed before sending the invite.
  
- **Example:**

```python
review_session.send_review_session_invite(invitee)
```

### Sending Multiple Invites

To send invites to multiple invitees at once, use the method:

```python
send_review_session_invites(invitees)
```

- **Parameters:**
  - `invitees`: A list of `ReviewSessionInvitee` instances.
  
- **Notes:**
  - All invitees must be committed before sending the invites.
  
- **Example:**

```python
review_session.send_review_session_invites([invitee1, invitee2, invitee3])
```

Error Handling
--------------

When sending invites, the system communicates with the server to perform the action. If the server does not support the `send_review_session_invite` action, a `ServerCompatibilityError` will be raised with a message indicating that the server version should be updated.

Example error handling:

```python
try:
    review_session.send_review_session_invite(invitee)
except ServerCompatibilityError as error:
    print(error)
```

Context Managers for Session Behavior
-------------------------------------

Two context managers are provided to temporarily modify session behavior during operations:

### AutoPopulatingContext

Temporarily changes the session's `auto_populate` setting.

```python
with AutoPopulatingContext(session, auto_populate=True):
    # Operations with auto_populate enabled
```

- **Parameters:**
  - `session`: The session object.
  - `auto_populate`: Boolean to enable or disable auto population.

### OperationRecordingContext

Temporarily changes the session's `record_operations` setting.

```python
with OperationRecordingContext(session, record_operations=True):
    # Operations with recording enabled
```

- **Parameters:**
  - `session`: The session object.
  - `record_operations`: Boolean to enable or disable operation recording.

Operation Payload Representation
--------------------------------

The `OperationPayload` class represents the payload of an operation as a mutable mapping (dictionary-like object). It allows easy manipulation of operation data.

Example usage:

```python
payload = OperationPayload()
payload['action'] = 'send_review_session_invite'
payload['review_session_invitee_id'] = invitee['id']
```

This class supports standard dictionary operations such as getting, setting, deleting items, and iteration.

Summary
-------

Using review sessions involves creating and managing invites to participants, handling server compatibility, and optionally adjusting session behavior with context managers. The provided methods and classes facilitate these tasks in a structured and error-resilient manner.
