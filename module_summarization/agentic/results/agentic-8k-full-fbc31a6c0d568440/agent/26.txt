w_kinavg command
================

Overview
--------

The `w_kinavg` command calculates average rates and associated confidence intervals (CIs) from weighted ensemble data. It is designed for path-tracing kinetics analysis and produces statistical summaries of state-to-state rates and fluxes based on previously generated bin assignments and kinetics data files.

Input Requirements
------------------

Before running `w_kinavg`, the following data files must be generated:

- Bin assignments file (usually `assignments.h5`)
- Kinetics data file (usually `kintrace.h5` or `kinmat.h5`)

Refer to the commands `w_assign` and `w_kinetics` for information on generating these files.

Modes of Operation
------------------

The primary mode of `w_kinavg` is the **trace** mode, which performs averaging and confidence interval calculations for path-tracing kinetics analysis.

Output
------

The output file (specified with `-o` or `--output`, default is `kinavg.h5`) contains datasets with the following structure:

- `/avg_rates` [state,state]  
  Structured dataset containing state-to-state rates averaged over the selected iteration window.

Additional datasets generated in trace mode:

- `/avg_total_fluxes` [state]  
  Total fluxes into each state averaged over the selected iteration window.

- `/avg_conditional_fluxes` [state,state]  
  State-to-state fluxes averaged over the selected iteration window.

If the `--evolution-mode` option is specified, additional datasets are available:

- `/rate_evolution` [window][state][state]  
  State-to-state rates calculated over windows of iterations of varying width.  
  - If `--evolution-mode=cumulative`, windows start at `--start-iter` and grow by `--step-iter`.  
  - If `--evolution-mode=blocked`, windows have fixed width `--step-iter` (except possibly the last), starting at `--start-iter`.

In trace mode with `--evolution-mode`, the following datasets are also generated:

- `/target_flux_evolution` [window,state]  
  Total flux into each macro state over iteration windows.

- `/conditional_flux_evolution` [window,state,state]  
  State-to-state fluxes over iteration windows.

Dataset Structure
-----------------

Each dataset contains the following fields:

- `iter_start`  
  Integer indicating the inclusive start iteration of the averaging window.

- `iter_stop`  
  Integer indicating the exclusive end iteration of the averaging window.

- `expected`  
  Floating-point expected (mean) value of the rate or flux within the window, in units of inverse tau.

- `ci_lbound`  
  Floating-point lower bound of the confidence interval within the window, in units of inverse tau.

- `ci_ubound`  
  Floating-point upper bound of the confidence interval within the window, in units of inverse tau.

- `corr_len`  
  Integer correlation length of the rate or flux within the window, in units of tau.

Dataset Attributes
------------------

Each dataset is annotated with the following attributes:

- `mcbs_alpha`  
  Floating-point alpha value used for confidence intervals (e.g., 0.05 corresponds to a 95% confidence interval).

- `mcbs_nsets`  
  Integer number of bootstrap data sets used to generate confidence intervals.

- `mcbs_acalpha`  
  Floating-point alpha value used for determining correlation lengths.

Command-line Options
--------------------

Run `w_kinavg trace --help` to see detailed command-line options and usage information.

Deprecation Notice
------------------

The `w_kinavg` command is deprecated. Users are encouraged to use the `w_direct` command instead for direct kinetics analysis.
