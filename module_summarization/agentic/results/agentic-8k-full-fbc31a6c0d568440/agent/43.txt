Config Usage
============

The `Config` object provides access to the configuration of the ASAB application. It is an instance of a specialized configuration parser that supports interpolation and loading configuration data from various sources and formats.

Accessing Configuration Values
------------------------------

Configuration values can be accessed using dictionary-like syntax:

```python
my_conf_value = asab.Config['section_name']['key']
```

This allows straightforward retrieval of configuration parameters organized by sections.

Configurable Objects
--------------------

The `Configurable` class is a base class designed for objects whose attributes can be loaded and initialized from configuration data. It supports default values and merging of configuration from multiple sources.

### Defining a Configurable Object

To create a configurable object, subclass `Configurable` and define a `ConfigDefaults` dictionary containing default configuration values:

```python
class ConfigurableObject(asab.Configurable):

    ConfigDefaults = {
        'foo': 'bar',
    }

    def __init__(self, config_section_name, config=None):
        super().__init__(config_section_name=config_section_name, config=config)

        config_foo = self.Config.get('foo')
```

### Initialization

When initializing, the `Configurable` class:

- Merges default configuration values from all base classes.
- Loads configuration values from the global `Config` object if the specified section exists.
- Updates the configuration with any additional dictionary passed during initialization.

This allows flexible and hierarchical configuration management.

ConfigurableDict
----------------

The `ConfigurableDict` class is a specialized dictionary used internally by `Configurable` to store configuration key-value pairs. It extends the standard dictionary interface with additional methods to conveniently retrieve typed values:

- `getboolean(key)`: Returns the value as a boolean.
- `getseconds(key)`: Converts the value to a number of seconds (float).
- `getint(key)`: Returns the value as an integer.
- `getfloat(key)`: Returns the value as a float.
- `geturl(key, scheme)`: Parses and validates the value as a URL with the specified scheme.

Example usage:

```python
value_bool = config_dict.getboolean('enabled')
timeout = config_dict.getseconds('timeout')
count = config_dict.getint('max_retries')
ratio = config_dict.getfloat('scale_factor')
url = config_dict.geturl('endpoint', scheme='http')
```

This makes it easier to work with configuration values in their expected types without manual conversion.

Summary
-------

- Use the global `Config` object to access application-wide configuration.
- Subclass `Configurable` to create objects that automatically load and merge configuration.
- Use `ConfigurableDict` methods to conveniently retrieve typed configuration values.

This design promotes clean, maintainable, and type-safe configuration handling within ASAB applications.
