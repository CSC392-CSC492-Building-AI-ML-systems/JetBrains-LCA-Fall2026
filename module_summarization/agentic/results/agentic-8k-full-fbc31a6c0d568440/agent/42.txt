How to Generate Schema
======================

This module provides functionality to generate and apply SQL schemas for a given database client.

Functions
---------

get_schema_sql(client: BaseDBAsyncClient, safe: bool) -> str
    Generates the SQL schema for the specified database client.

    Parameters:
    
    - client: The database client instance for which the schema SQL will be generated.
    - safe: If set to True, the generated SQL will include checks to create tables only if they do not already exist.

    Returns:
    
    - A string containing the SQL commands to create the schema.

generate_schema_for_client(client: BaseDBAsyncClient, safe: bool) -> None
    Asynchronously generates and applies the SQL schema directly to the specified database client.

    Parameters:
    
    - client: The database client instance to which the schema will be applied.
    - safe: If set to True, the schema creation will be performed safely by creating tables only if they do not already exist.

    Behavior:
    
    - Generates the schema SQL using `get_schema_sql`.
    - Logs the generated schema at the debug level.
    - If the schema SQL is not empty, applies it to the database client asynchronously.

Usage Notes
-----------

- The `safe` parameter is useful to avoid errors when tables already exist in the database.
- The functions expect a client that implements the `BaseDBAsyncClient` interface and provides a `schema_generator` method.
- Logging is performed using the "tortoise" logger to help trace schema generation steps.

Example
-------

```python
from tortoise.backends.base.client import BaseDBAsyncClient

async def setup_schema(client: BaseDBAsyncClient):
    await generate_schema_for_client(client, safe=True)
```

This will generate and apply the schema safely, creating tables only if they do not exist.
