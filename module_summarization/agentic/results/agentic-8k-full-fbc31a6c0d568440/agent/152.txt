Executing Notebooks
===================

The `ExecutePreprocessor` class provides functionality to execute all the code cells in a Jupyter notebook, updating the outputs accordingly. This is useful for running notebooks programmatically as part of a conversion or processing pipeline.

Overview
--------

The `ExecutePreprocessor` inherits from both `Preprocessor` and `NotebookClient` to combine notebook preprocessing capabilities with notebook execution management. It executes each code cell in the notebook in order, capturing outputs and updating the notebook metadata with execution information.

Usage
-----

To execute a notebook, instantiate the `ExecutePreprocessor` and call its `preprocess` method with the notebook object and optional resources:

```python
from nbconvert.preprocessors import ExecutePreprocessor
import nbformat

# Load the notebook
with open("notebook.ipynb") as f:
    nb = nbformat.read(f, as_version=4)

# Create the preprocessor
ep = ExecutePreprocessor(timeout=600, kernel_name='python3')

# Execute the notebook
nb, resources = ep.preprocess(nb, resources={'metadata': {'path': './'}})
```

Parameters
----------

- `nb` (`NotebookNode`): The notebook object to be executed. This notebook is modified in-place.
- `resources` (optional, `dict`): Additional resources used during processing. For example, passing `{'metadata': {'path': run_path}}` sets the execution path to `run_path`.
- `km` (optional, `KernelManager`): An optional kernel manager instance. If not provided, a new kernel manager will be created internally.

Methods
-------

### `preprocess(nb, resources=None, km=None)`

Executes all code cells in the notebook.

- Initializes the execution environment and kernel.
- Executes each code cell sequentially.
- Updates the notebook metadata with language information and execution results.
- Returns the executed notebook and updated resources.

### `preprocess_cell(cell, resources, index)`

Executes a single cell. This method can be overridden to customize cell execution behavior.

Returns the modified cell and resources.

Deprecation Notice
------------------

The function `executenb` is deprecated and has been moved to the `nbclient.execute` module. It is recommended to import and use `nbclient.execute` directly for executing notebooks.

Example:

```python
from nbclient import execute

execute.executenb(nb, kernel_name='python3')
```

Notes
-----

- The `ExecutePreprocessor` resets its internal state on each call to `preprocess` to ensure a clean execution environment.
- Execution errors in cells raise `CellExecutionError` exceptions.
- The notebook's metadata is updated with the kernel's language information after execution.
- The execution path can be controlled via the `resources` dictionary by specifying the `metadata.path` key.
