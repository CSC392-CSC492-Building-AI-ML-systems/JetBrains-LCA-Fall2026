w_ipa Command
=============

Overview
--------
`w_ipa` (WESTPA Interactive Python Analysis) is an interactive command-line tool designed for analyzing WESTPA simulation data. It provides a stateful environment where users can explore trajectories, weights, progress coordinates, and other relevant data from the current analysis scheme and iteration. The tool is intended to facilitate detailed inspection and analysis of WESTPA simulation results in an intuitive and flexible manner.

Key Features
------------
- Access and manipulate data from the current analysis scheme and iteration.
- Inspect walkers, weights, progress coordinates, states, bins, and auxiliary data.
- Trace the history of individual trajectory segments.
- Switch between different analysis schemes and iterations.
- Plot data using matplotlib or terminal-based plotting.
- Supports parallel execution and progress indication.
- Provides raw access to underlying HDF5 files associated with the current scheme.

Getting Started
---------------
To launch the interactive analysis environment, run the `w_ipa` command from your terminal within a WESTPA simulation directory.

Upon startup, `w_ipa` will:
- Load the current analysis scheme and iteration (default iteration is 1).
- Display a welcome message and basic usage hints.
- Open necessary data files and prepare the analysis environment.

Basic Usage
-----------

### Accessing Iterations and Schemes

- View the current iteration:
  ```python
  w.iteration
  # or
  west.iteration
  ```

- Set the current iteration:
  ```python
  w.iteration = 100
  ```

- List available analysis schemes:
  ```python
  w.list_schemes
  ```

- Change the current analysis scheme:
  ```python
  w.scheme = <scheme_name>
  ```

### Exploring States and Bins

- View states defined in the current scheme:
  ```python
  w.states
  ```

- View bin labels:
  ```python
  w.bin_labels
  ```

### Accessing Data for the Current Iteration

All information about the current iteration is accessible via the `current` property:

```python
w.current
```

This object contains data such as:
- Walkers
- Summary statistics
- States
- Segment IDs
- Weights
- Parent segments
- Kinetic averages
- Progress coordinates
- Bin assignments
- Populations
- Auxiliary data (if available)

### Tracing Segment Histories

To trace the history of a specific trajectory segment by its segment ID:

```python
trace_data = w.trace(seg_id)
```

This returns a dictionary containing all pertinent information about the segment's lineage and history. Since tracing can be computationally expensive, it is recommended to store the result for repeated use.

### Accessing Past and Future Data

In addition to `current`, the tool provides access to `past` and `future` datasets, which represent data from previous and upcoming iterations, respectively.

```python
w.past
w.future
```

These datasets are keyed differently and provide different views of the simulation data.

### Raw Access to HDF5 Files

For advanced users, raw access to the HDF5 files associated with the current scheme is available via:

```python
w.west
w.assign
w.direct
w.reweight
```

These objects allow direct inspection and manipulation of the underlying data files.

Runtime Options
---------------
`w_ipa` supports several command-line options to customize its behavior:

- `--analysis-only`, `-ao`  
  Run the analysis and return to the terminal without launching the interactive environment.

- `--reanalyze`, `-ra`  
  Delete existing analysis files and reanalyze from scratch.

- `--ignore-hash`, `-ih`  
  Ignore file hashes and do not regenerate analysis files.

- `--debug`, `-d`  
  Enable debug output for development purposes.

- `--terminal`, `-t`  
  Plot output directly in the terminal.

Additional options related to progress indication and data reading can be viewed by running:

```bash
w_ipa --help
```

Interactive Environment
-----------------------
If launched without the `--analysis-only` flag, `w_ipa` opens an IPython interactive shell with tab completion enabled for convenient exploration of data objects.

Help and Documentation
----------------------
Within the interactive environment, you can access help and introductory information:

- Display a brief introduction and overview of available properties and methods:

  ```python
  w.introduction
  ```

- Get detailed help on the `w` object and its methods:

  ```python
  w.help
  ```

- Use Python's built-in `help()` function on any attribute or method for more information.

Example Session
---------------
```python
>>> w.iteration
1
>>> w.list_schemes
['scheme1', 'scheme2']
>>> w.scheme = 'scheme1'
>>> w.states
['state1', 'state2', 'state3']
>>> w.current.weights.plot()
>>> trace = w.trace(42)
>>> print(trace['parents'])
```
