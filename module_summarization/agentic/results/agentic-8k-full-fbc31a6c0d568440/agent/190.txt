Linear and Quadratic Discriminant Analysis
===========================================

Linear Discriminant Analysis (LDA)
----------------------------------

Linear Discriminant Analysis is a classification method that finds a linear combination of features which characterizes or separates two or more classes of objects or events. The resulting combination may be used as a linear classifier or, more commonly, for dimensionality reduction before later classification.

**Parameters**

- **solver** : {'svd', 'lsqr', 'eigen'}, default='svd'  
  Solver to use, possible values are:  
  - 'svd': Singular Value Decomposition solver. Does not compute the covariance matrix explicitly and works well for data with many features.  
  - 'lsqr': Least squares solver. Can be used with shrinkage.  
  - 'eigen': Eigenvalue decomposition solver. Can be used with shrinkage.

- **shrinkage** : 'auto', float or None, default=None  
  Shrinkage parameter for covariance estimation. Possible values:  
  - None: no shrinkage.  
  - 'auto': automatic shrinkage using the Ledoit-Wolf lemma.  
  - float between 0 and 1: fixed shrinkage parameter.  
  Ignored if `covariance_estimator` is not None.

- **priors** : array-like of shape (n_classes,), default=None  
  Class priors. If specified, the priors are used instead of empirical class frequencies.

- **n_components** : int or None, default=None  
  Number of components (< n_classes - 1) for dimensionality reduction. If None, no dimensionality reduction is performed.

- **store_covariance** : bool, default=False  
  If True, the covariance matrices are computed and stored.

- **tol** : float, default=1e-4  
  Threshold used for rank estimation in the 'svd' solver.

- **covariance_estimator** : estimator or None, default=None  
  If not None, used to estimate the covariance matrices instead of the empirical covariance estimator. The estimator should have a `fit` method and a `covariance_` attribute.

**Attributes**

- **classes_** : ndarray of shape (n_classes,)  
  Class labels known to the classifier.

- **priors_** : ndarray of shape (n_classes,)  
  Class priors.

- **means_** : ndarray of shape (n_classes, n_features)  
  Class means.

- **covariance_** : ndarray of shape (n_features, n_features) or list of such arrays  
  Covariance matrix or matrices for each class (if `store_covariance=True`).

**Example**

```python
>>> import numpy as np
>>> from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
>>> X = np.array([[-1, -1], [-2, -1], [-3, -2], [1, 1], [2, 1], [3, 2]])
>>> y = np.array([1, 1, 1, 2, 2, 2])
>>> clf = LinearDiscriminantAnalysis()
>>> clf.fit(X, y)
LinearDiscriminantAnalysis()
>>> print(clf.predict([[-0.8, -1]]))
[1]
```

Quadratic Discriminant Analysis (QDA)
-------------------------------------

Quadratic Discriminant Analysis is a classification algorithm that assumes each class has its own covariance matrix, allowing for quadratic decision boundaries. It is a generalization of Linear Discriminant Analysis which assumes identical covariance matrices for all classes.

**Parameters**

- **priors** : array-like of shape (n_classes,), default=None  
  Class priors. If specified, the priors are used instead of empirical class frequencies.

- **reg_param** : float, default=0.0  
  Regularization parameter between 0 and 1. This shrinks the covariance estimates towards the identity matrix, improving stability when the number of features is large or the number of samples is small.

- **store_covariance** : bool, default=False  
  If True, the covariance matrices are computed and stored.

- **tol** : float, default=1e-4  
  Threshold used for rank estimation.

**Attributes**

- **classes_** : ndarray of shape (n_classes,)  
  Class labels known to the classifier.

- **priors_** : ndarray of shape (n_classes,)  
  Class priors.

- **means_** : ndarray of shape (n_classes, n_features)  
  Class means.

- **covariances_** : list of ndarray of shape (n_features, n_features)  
  Covariance matrices for each class (if `store_covariance=True`).

**Example**

```python
>>> import numpy as np
>>> from sklearn.discriminant_analysis import QuadraticDiscriminantAnalysis
>>> X = np.array([[-1, -1], [-2, -1], [-3, -2], [1, 1], [2, 1], [3, 2]])
>>> y = np.array([1, 1, 1, 2, 2, 2])
>>> clf = QuadraticDiscriminantAnalysis()
>>> clf.fit(X, y)
QuadraticDiscriminantAnalysis()
>>> print(clf.predict([[-0.8, -1]]))
[1]
```

---

Notes
-----

- Linear Discriminant Analysis assumes that different classes share the same covariance matrix, leading to linear decision boundaries.
- Quadratic Discriminant Analysis allows each class to have its own covariance matrix, resulting in quadratic decision boundaries.
- Shrinkage and regularization parameters help improve the stability of covariance estimation, especially in high-dimensional settings or with limited data.
- Both methods support specifying class priors to incorporate prior knowledge about class distributions.
