w_run command
=============

Overview
--------
The `w_run` command is used to start or continue a WEST simulation. It manages the execution of the simulation by coordinating the simulation manager, system driver, data manager, weighted ensemble (WE) driver, and propagator components. The command supports running simulations in parallel using different work managers and handles graceful shutdown on interruptions or errors.

Usage
-----
```
w_run [OPTIONS]
```

Options
-------
- `--oneseg`  
  Only propagate one segment. This option is primarily useful for debugging propagators by limiting the simulation to a single segment.

- Additional options are available through WESTPA configuration and the selected work manager environment. These can be viewed by running `w_run --help`.

Functionality
-------------
When executed, `w_run` performs the following steps:

1. **Argument Parsing and Configuration**  
   Parses command-line arguments, including WESTPA runtime configuration options and work manager-specific arguments. Processes these arguments to configure the simulation environment.

2. **Work Manager Initialization**  
   Creates and initializes a work manager instance responsible for managing parallel execution and task distribution.

3. **Simulation Component Setup**  
   Loads and configures the simulation manager, system driver, data manager, WE driver, and propagator. These components are interconnected to ensure proper data flow and control during the simulation.

4. **Simulation Execution**  
   - If running as the master process, installs signal handlers for graceful interruption, loads simulation plugins, prepares the simulation run, executes the simulation, and finalizes the run upon completion.
   - If running as a worker process, executes assigned tasks as directed by the work manager.

5. **Error Handling and Logging**  
   Captures keyboard interrupts and other exceptions to ensure the simulation shuts down cleanly. Logs detailed error messages and stack traces for troubleshooting.

Examples
--------
To start or continue a simulation with default settings:
```
w_run
```

To run the simulation propagating only one segment (useful for debugging):
```
w_run --oneseg
```

Logging
-------
The command logs detailed debug information under the logger named `w_run`. This includes preparation steps, run progress, and error details if exceptions occur.

Notes
-----
- The `w_run` command relies on the WESTPA runtime configuration (`westpa.rc`) to manage simulation settings and component instantiation.
- Work manager environments may provide additional command-line options to customize parallel execution behavior.
- Proper handling of interrupts and exceptions ensures that simulation data is preserved and resources are cleaned up appropriately.
