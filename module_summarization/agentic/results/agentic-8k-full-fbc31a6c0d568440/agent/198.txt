Nearest Neighbors
=================

The Nearest Neighbors methods provide functionality for unsupervised and supervised learning based on the concept of proximity in feature space. These methods are widely used for classification, regression, and clustering tasks, relying on the idea that points close to each other in the feature space are likely to have similar properties.

Overview
--------

Nearest Neighbors algorithms find the closest points in the training data to a given query point according to a specified distance metric. The two primary types of queries are:

- **k-nearest neighbors**: Find the *k* closest points.
- **radius neighbors**: Find all points within a fixed radius.

These neighbors can be used for various tasks such as classification, regression, or constructing graphs representing neighborhood relationships.

Key Classes and Mixins
----------------------

- **NearestNeighbors**: Provides unsupervised nearest neighbors learning. It supports both k-nearest neighbors and radius neighbors queries, returning either distances or connectivity graphs.

- **RadiusNeighborsMixin**: Mixin class for radius-based neighbors searches. It supports querying neighbors within a specified radius.

- **KNeighborsRegressor**: Implements regression based on k-nearest neighbors. The prediction is made by local interpolation of the targets associated with the nearest neighbors.

Parameters
----------

Common parameters across nearest neighbors estimators include:

- `n_neighbors` (int, default=5): Number of neighbors to use for k-nearest neighbors queries.
- `radius` (float, default=1.0): Radius within which to search for neighbors.
- `algorithm` (str, default='auto'): Algorithm used to compute the nearest neighbors. Options include 'auto', 'ball_tree', 'kd_tree', and 'brute'.
- `leaf_size` (int, default=30): Leaf size passed to BallTree or KDTree. This can affect the speed of the construction and query.
- `metric` (str or callable, default='minkowski'): The distance metric to use for the tree.
- `p` (int, default=2): Parameter for the Minkowski metric.
- `metric_params` (dict, default=None): Additional keyword arguments for the metric function.
- `n_jobs` (int, default=None): The number of parallel jobs to run for neighbors search.

Usage Examples
--------------

### k-Nearest Neighbors Graph

```python
X = [[0], [3], [1]]
from sklearn.neighbors import NearestNeighbors
neigh = NearestNeighbors(n_neighbors=2)
neigh.fit(X)
A = neigh.kneighbors_graph(X)
print(A.toarray())
# Output:
# array([[1., 0., 1.],
#        [0., 1., 1.],
#        [1., 0., 1.]])
```

This example fits a nearest neighbors model on a small dataset and computes the k-nearest neighbors graph, which is returned as a sparse matrix.

### Radius Neighbors Graph

```python
X = [[0], [3], [1]]
from sklearn.neighbors import NearestNeighbors
neigh = NearestNeighbors(radius=1.5)
neigh.fit(X)
A = neigh.radius_neighbors_graph(X)
print(A.toarray())
# Output:
# array([[1., 0., 1.],
#        [0., 1., 0.],
#        [1., 0., 1.]])
```

This example computes the radius neighbors graph, connecting points within a radius of 1.5.

### k-Nearest Neighbors Regression

```python
import numpy as np
from sklearn.neighbors import KNeighborsRegressor

samples = [[0, 0, 2], [1, 0, 0], [0, 0, 1]]
neigh = KNeighborsRegressor(n_neighbors=2, weights='uniform')
neigh.fit(samples, [1, 2, 3])
prediction = neigh.predict([[0, 0, 1.3]])
print(prediction)
```

This example demonstrates regression using k-nearest neighbors, where the prediction is based on the average target values of the nearest neighbors.

Details
-------

- The `kneighbors_graph` method returns a sparse matrix representing the neighborhood connectivity or distances.
- The `radius_neighbors_graph` method returns a sparse matrix indicating neighbors within a specified radius.
- The `kneighbors` and `radius_neighbors` methods return the indices and optionally distances of neighbors.
- Weighting schemes such as uniform or distance-based weights can be used in regression to influence the contribution of neighbors.
