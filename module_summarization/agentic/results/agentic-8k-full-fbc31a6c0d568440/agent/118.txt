Configuration Module
====================

Overview
--------
The Configuration module provides classes and methods to manage configuration settings for designs within the application. It enables exporting and importing configuration options, facilitating the application of these settings to new or existing designs. This module supports handling variables, materials, coordinate systems, native components, monitors, and other design-related configurations.

Classes
-------

Configurations
--------------

The `Configurations` class is the core configuration handler. It allows importing configuration settings from JSON files and applying them to the current design environment. It also manages the results of import operations and the options specifying which configuration sections to import.

### Initialization

```python
Configurations(app)
```

- **app**: The application instance to which the configurations will be applied.

### Attributes

- `options` : Instance of `ConfigurationsOptions` that defines which configuration sections to import/export.
- `results` : Instance of `ImportResults` that stores the results of import operations.

### Methods

#### import_config(config_file, *args)

Imports configuration settings from a JSON file and applies them to the current design. The sections to be applied are controlled by the `options` attribute. The results of the import operation are saved in the `results` attribute.

```python
import_config(config_file, *args)
```

- **Parameters:**
  - `config_file` (str): Full path to the JSON configuration file.
  - `*args` (optional): A set of object names to exclude from monitor assignment.

- **Returns:**
  - `dict, bool`: The configuration dictionary and a boolean indicating success.

- **Description:**
  This method reads the configuration JSON file and applies various settings such as model units, variables, postprocessing variables, materials, datasets, coordinate systems, native components, and monitors. It handles errors gracefully and updates the import results accordingly.

Internal Helper Methods
-----------------------

- `_map_dict_value(dict_out, key, value)`

  Maps an object key to a value within the general object mapping dictionary.

- `_map_object(props, dict_out)`

  Maps objects, faces, or edges from the properties dictionary to the output dictionary using the application modeler.

- `_convert_objects(props, mapping)`

  Converts object identifiers in the properties dictionary to their mapped names or positions based on the provided mapping.

- `_monitor_assignment_finder(dict_in, monitor_obj, exclude_set)`

  Finds and assigns monitors based on the imported configuration, excluding specified objects.

Properties
----------

- `global_import_success`

  Returns `True` if all imports were successful; otherwise, returns `False`.

  ```python
  @property
  def global_import_success(self) -> bool
  ```

Usage Example
-------------

```python
from configuration import Configurations

# Initialize configuration handler with application instance
config = Configurations(app)

# Import configuration from JSON file
config_dict, success = config.import_config("path/to/config.json")

if success:
    print("Configuration imported successfully.")
else:
    print("Some configuration sections failed to import.")
```

Notes
-----

- The import process respects the options set in `config.options` to determine which sections to import.
- Import results are stored in `config.results` for inspection after the import operation.
- The module supports importing complex design elements including variables, materials, coordinate systems, native components, and monitors.
- Error handling is implemented to ensure robustness during import operations.

This module is essential for automating the setup and replication of design configurations, improving workflow efficiency and consistency across projects.
