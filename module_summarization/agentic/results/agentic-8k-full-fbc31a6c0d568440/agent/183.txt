Feature Selection and Dimensionality Reduction
==============================================

Feature selection and dimensionality reduction are essential techniques in machine learning and data preprocessing that aim to reduce the number of input variables to a manageable size, improving model performance, reducing overfitting, and enhancing interpretability.

Overview
--------

Feature selection methods identify and select a subset of relevant features from the original dataset, while dimensionality reduction techniques transform the data into a lower-dimensional space. This documentation focuses on feature selection methods applicable to sample sets, including recursive feature elimination, model-based selection, and sequential feature selection.

Key Attributes in Feature Selection Estimators
----------------------------------------------

- **feature_names_in_** : ndarray of shape (`n_features_in_`,)  
  Names of features seen during :term:`fit`. Defined only when `X` has feature names that are all strings.  
  .. versionadded:: 1.0

- **ranking_** : ndarray of shape (n_features,)  
  The feature ranking, where ``ranking_[i]`` corresponds to the ranking position of the i-th feature. Selected (i.e., estimated best) features are assigned rank 1.

- **support_** : ndarray of shape (n_features,)  
  The mask of selected features, indicating which features are retained.

Core Feature Selection Methods
------------------------------

### Recursive Feature Elimination (RFE)

RFE recursively removes features and builds a model on those features that remain. It uses the model’s importance weights to rank features and eliminate the least important ones step-by-step.

**Example:**

```python
from sklearn.datasets import make_friedman1
from sklearn.feature_selection import RFE
from sklearn.svm import SVR

X, y = make_friedman1(n_samples=50, n_features=10, random_state=0)
estimator = SVR(kernel="linear")
selector = RFE(estimator, n_features_to_select=5, step=1)
selector = selector.fit(X, y)

print(selector.support_)
# array([ True,  True,  True,  True,  True, False, False, False, False, False])

print(selector.ranking_)
# array([1, 1, 1, 1, 1, 6, 4, 3, 2, 5])
```

### SelectFromModel

SelectFromModel selects features based on importance weights from a fitted estimator. It supports thresholds to determine which features to keep.

**Example:**

```python
from sklearn.feature_selection import SelectFromModel
from sklearn.linear_model import LogisticRegression

X = [[ 0.87, -1.34,  0.31],
     [-2.79, -0.02, -0.85],
     [-1.34, -0.48, -2.55],
     [ 1.92,  1.48,  0.65]]
y = [0, 1, 0, 1]

selector = SelectFromModel(estimator=LogisticRegression()).fit(X, y)
print(selector.estimator_.coef_)
# array([[-0.3252302 ,  0.83462377,  0.49750423]])

print(selector.threshold_)
# 0.55245...

print(selector.get_support())
# array([False,  True, False])

print(selector.transform(X))
# array([[-1.34],
#        [-0.02],
#        [-0.48],
#        [ 1.48]])
```

SelectFromModel also supports using a callable to dynamically determine the maximum number of features to select.

### Sequential Feature Selector

SequentialFeatureSelector performs feature selection by sequentially adding or removing features based on cross-validation performance. Unlike RFE or SelectFromModel, it does not rely on importance weights.

Related Classes and Functions
-----------------------------

- **RFECV**: Recursive feature elimination with built-in cross-validated selection of the best number of features.
- **SelectFromModel**: Feature selection based on thresholds of importance weights.
- **SequentialFeatureSelector**: Sequential cross-validation based feature selection.

Handling Missing Values
-----------------------

Feature selection methods generally allow `NaN` or `Inf` values in the input if the underlying estimator supports them. This flexibility enables working with real-world datasets that may contain missing or infinite values.

References
----------

.. [1] Guyon, I., Weston, J., Barnhill, S., & Vapnik, V., "Gene selection for cancer classification using support vector machines", *Machine Learning*, 46(1-3), 389–422, 2002.

Notes
-----

- Feature selection can significantly improve model interpretability and reduce computational cost.
- The choice of feature selection method depends on the estimator used and the problem context.
- Recursive and sequential methods are iterative and may be computationally intensive for large feature sets.
- Model-based methods require the estimator to provide feature importance or coefficients.

Examples
--------

Retrieve the 5 most informative features in the Friedman #1 dataset using RFE:

```python
from sklearn.datasets import make_friedman1
from sklearn.feature_selection import RFE
from sklearn.svm import SVR

X, y = make_friedman1(n_samples=50, n_features=10, random_state=0)
estimator = SVR(kernel="linear")
selector = RFE(estimator, n_features_to_select=5, step=1)
selector = selector.fit(X, y)

print(selector.support_)
print(selector.ranking_)
```

Select features based on logistic regression coefficients:

```python
from sklearn.feature_selection import SelectFromModel
from sklearn.linear_model import LogisticRegression

X = [[ 0.87, -1.34,  0.31],
     [-2.79, -0.02, -0.85],
     [-1.34, -0.48, -2.55],
     [ 1.92,  1.48,  0.65]]
y = [0, 1, 0, 1]

selector = SelectFromModel(LogisticRegression()).fit(X, y)
print(selector.get_support())
print(selector.transform(X))
```

Summary
-------

Feature selection and dimensionality reduction are powerful tools to enhance machine learning workflows by focusing on the most relevant features. Scikit-learn provides a variety of methods such as RFE, SelectFromModel, and SequentialFeatureSelector to facilitate these tasks with flexibility and ease of use.
