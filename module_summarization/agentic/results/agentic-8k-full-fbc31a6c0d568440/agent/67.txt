Feature Extraction Module
=========================

The `feature_extraction` module in scikit-learn provides utilities and classes to extract features from various types of data, including text and images. This module is essential for preprocessing raw data into a format suitable for machine learning algorithms.

Text Feature Extraction
-----------------------

### CountVectorizer

Transforms a collection of text documents to a matrix of token counts.

**Key Features:**

- Converts text documents into a sparse matrix of token counts.
- Supports tokenization, stop word removal, n-gram extraction, and more.
- Parameters include `input`, `encoding`, `decode_error`, `strip_accents`, `lowercase`, `preprocessor`, `tokenizer`, `stop_words`, `token_pattern`, `ngram_range`, `analyzer`, `max_df`, `min_df`, `max_features`, `vocabulary`, `binary`, and `dtype`.

**Example:**

```python
from sklearn.feature_extraction.text import CountVectorizer

corpus = [
    'This is the first document.',
    'This document is the second document.',
    'And this is the third one.',
    'Is this the first document?',
]

vectorizer = CountVectorizer()
X = vectorizer.fit_transform(corpus)
print(vectorizer.get_feature_names_out())
print(X.toarray())
```

This will output the feature names and the corresponding count matrix.

You can also extract n-grams by setting the `ngram_range` parameter:

```python
vectorizer2 = CountVectorizer(analyzer='word', ngram_range=(2, 2))
X2 = vectorizer2.fit_transform(corpus)
print(vectorizer2.get_feature_names_out())
print(X2.toarray())
```

### TfidfTransformer

Transforms a count matrix to a normalized tf or tf-idf representation.

**Key Features:**

- Learns the inverse document frequency (idf) vector.
- Supports normalization (`l1` or `l2`), use of idf weighting, smoothing of idf weights, and sublinear tf scaling.

**Example:**

```python
from sklearn.feature_extraction.text import TfidfTransformer
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.pipeline import Pipeline

corpus = [
    'this is the first document',
    'this document is the second document',
    'and this is the third one',
    'is this the first document'
]

vocabulary = ['this', 'document', 'first', 'is', 'second', 'the', 'and', 'one']

pipe = Pipeline([
    ('count', CountVectorizer(vocabulary=vocabulary)),
    ('tfid', TfidfTransformer())
]).fit(corpus)

print(pipe['count'].transform(corpus).toarray())
print(pipe['tfid'].idf_)
print(pipe.transform(corpus).shape)
```

Image Feature Extraction
------------------------

The `feature_extraction.image` submodule provides utilities to extract features from images, including patch extraction and graph construction from image grids.

### PatchExtractor and extract_patches_2d

Utilities to extract patches from images for further processing.

### Graph Construction from Images

Functions such as `grid_to_graph` and `img_to_graph` convert image grids into graph representations, useful for graph-based machine learning methods.

**Internal Utilities:**

- `_make_edges_3d`: Generates edges for a 3D image grid.
- `_compute_gradient_3d`: Computes gradients along edges in a 3D image.
- `_mask_edges_weights`: Applies masks to edges and their weights.
- `_to_graph`: Auxiliary function to create graph representations from image data.

These functions support building adjacency graphs where nodes correspond to pixels or patches, and edges represent spatial relationships weighted by image gradients.

Summary
-------

The `feature_extraction` module is a comprehensive toolkit for converting raw data into meaningful features:

- For text data, it provides vectorizers and transformers to convert documents into numerical feature matrices.
- For image data, it offers tools to extract patches and represent images as graphs for advanced analysis.

These tools are foundational for preparing data for machine learning pipelines in scikit-learn.
