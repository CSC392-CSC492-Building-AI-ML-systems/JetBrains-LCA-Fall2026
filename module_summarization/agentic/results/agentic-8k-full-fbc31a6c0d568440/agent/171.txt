Calculator Interface
====================

The Calculator Interface provides a set of tools and functions to create and use model calculators for various shapes and scattering models. These calculators are used to compute scattering intensities based on model parameters and experimental data.

Functions
---------

eval_opencl(model_info, data, dtype='single', cutoff=0.)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Return a model calculator using the OpenCL calculation engine.

Parameters:
- **model_info**: ModelInfo  
  Information about the model to be used.
- **data**: Data  
  Experimental or simulated data to be used in the calculation.
- **dtype**: str, optional  
  Data type for calculations (default is 'single').
- **cutoff**: float, optional  
  Cutoff value for the calculation (default is 0.0).

Returns:
- Calculator  
  A calculator object configured to use the OpenCL engine.

eval_ctypes(model_info, data, dtype='double', cutoff=0.)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Return a model calculator using the DLL calculation engine.

Parameters:
- **model_info**: ModelInfo  
  Information about the model to be used.
- **data**: Data  
  Experimental or simulated data to be used in the calculation.
- **dtype**: str, optional  
  Data type for calculations (default is 'double').
- **cutoff**: float, optional  
  Cutoff value for the calculation (default is 0.0).

Returns:
- Calculator  
  A calculator object configured to use the DLL engine.

make_engine(model_info, data, dtype, cutoff, ngauss=0)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Create a calculation engine for the given model and data.

Parameters:
- **model_info**: ModelInfo  
  Information about the model.
- **data**: Data  
  Data to be used in the calculation.
- **dtype**: str  
  Data type for calculations.
- **cutoff**: float  
  Cutoff value for the calculation.
- **ngauss**: int, optional  
  Number of Gaussian points (default is 0).

Returns:
- Calculator  
  A calculator object configured with the specified engine and parameters.

select_calculator(model_name, n=150, size=(10, 40, 100))
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Create a model calculator for the given shape.

Parameters:
- **model_name**: str  
  Name of the model shape. Supported shapes include:
  - 'sphere'
  - 'cylinder'
  - 'ellipsoid'
  - 'triaxial_ellipsoid'
  - 'parallelepiped'
  - 'bcc_paracrystal'
  - 'fcc_paracrystal'
  - 'sc_paracrystal'
- **n**: int, optional  
  Number of points to use in the q range (default is 150).
- **size**: tuple of three floats, optional  
  Tuple (a, b, c) giving minor and major equatorial axes and polar axis respectively (default is (10, 40, 100)).

Returns:
- tuple  
  A tuple containing:
  - **calculator**: Calculator  
    The model calculator object.
  - **size**: tuple  
    The adjusted size parameters (a, b, c) used for the model.

Notes:
- The function automatically adjusts parameters such as nearest neighbor distance and radius for paracrystal models.
- The q range and other parameters are chosen based on the model to provide meaningful scattering patterns.

Supported Shapes
----------------
The following shapes are supported by the calculator interface:

- parallelepiped
- sphere
- ellipsoid
- triaxial_ellipsoid
- cylinder
- fcc_paracrystal
- bcc_paracrystal
- sc_paracrystal

Drawing Functions
-----------------
Some shapes have associated drawing functions for visualization:

- fcc_paracrystal: `draw_fcc`
- bcc_paracrystal: `draw_bcc`
- sc_paracrystal: `draw_sc`

These can be used to generate graphical representations of the respective crystal structures.

Usage Example
-------------
Here is an example of how to create a calculator for a sphere model:

.. code-block:: python

    calculator, size = select_calculator('sphere', n=200, size=(20, 20, 20))
    intensity = calculator(theta=0, phi=0, psi=0, **calculator.pars)

This will create a calculator for a sphere with radius 20 and compute the scattering intensity at specified angles.

Summary
-------
The Calculator Interface provides flexible and efficient tools to build and use scattering model calculators for a variety of shapes and crystal structures. It supports multiple calculation engines including OpenCL and DLL, and allows customization of parameters such as data type, cutoff, and q range.
