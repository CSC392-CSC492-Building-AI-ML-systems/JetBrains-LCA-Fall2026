AutoAugment Module
==================

Overview
--------
This module provides implementations of the AutoAugment data augmentation technique as described in the paper "AutoAugment: Learning Augmentation Policies from Data" (https://arxiv.org/abs/1805.09501). AutoAugment applies a learned policy of image transformations to batches of samples to improve the robustness and generalization of machine learning models.

Functions
---------

auto_augment_image_net(data, shape=None, fill_value=128, interp_type=None, max_translate_abs=None, max_translate_rel=None, seed=None) → _DataNode
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Applies the ImageNet AutoAugment policy to a batch of samples.

This function is equivalent to calling `auto_augment` with the policy name set to `'image_net'`.

Parameters:
- **data** (_DataNode_): Batch of samples to be augmented.
- **shape** (Optional[Union[_DataNode, Tuple[int, int]]]): Target shape for the output images.
- **fill_value** (Optional[int]): Pixel fill value used for padding or filling areas after transformations. Default is 128.
- **interp_type** (Optional[types.DALIInterpType]): Interpolation type used for image transformations.
- **max_translate_abs** (Optional[int]): Maximum absolute translation in pixels.
- **max_translate_rel** (Optional[float]): Maximum relative translation as a fraction of image size.
- **seed** (Optional[int]): Random seed for reproducibility.

Returns:
- _DataNode_: Batch of augmented samples.

apply_auto_augment(policy, data, seed=None, **kwargs) → _DataNode
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Applies a given AutoAugment policy to a batch of samples.

This function executes the augmentation sequences defined in the provided `policy` on the input data.

Parameters:
- **policy** (Policy): A set of augmentation sub-policies to apply.
- **data** (_DataNode_): Batch of samples to be processed.
- **seed** (Optional[int]): Seed for random operations and magnitude negations.
- **kwargs**: Additional keyword arguments passed to augmentations, such as `shape`, `fill_value`, and `interp_type`.

Returns:
- _DataNode_: Batch of transformed samples.

Raises:
- Exception: If the provided policy contains no sub-policies.

get_image_net_policy(use_shape=False, max_translate_abs=None, max_translate_rel=None) → Policy
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Creates the AutoAugment policy tuned for ImageNet dataset.

Parameters:
- **use_shape** (bool): Whether to use image shape information in augmentations.
- **max_translate_abs** (Optional[int]): Maximum absolute translation allowed.
- **max_translate_rel** (Optional[float]): Maximum relative translation allowed.

Returns:
- Policy: The ImageNet AutoAugment policy.

get_svhn_policy(use_shape=False, max_translate_abs=None, max_translate_rel=None) → Policy
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Creates the AutoAugment policy tuned for the SVHN dataset.

Parameters:
- **use_shape** (bool): Whether to use image shape information in augmentations.
- **max_translate_abs** (Optional[int]): Maximum absolute translation allowed.
- **max_translate_rel** (Optional[float]): Maximum relative translation allowed.

Returns:
- Policy: The SVHN AutoAugment policy.

get_reduced_image_net_policy() → Policy
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Creates the reduced ImageNet AutoAugment policy.

This policy is a simplified version of the ImageNet policy designed for faster experimentation while maintaining effectiveness.

Returns:
- Policy: The reduced ImageNet AutoAugment policy.

Classes and Types
-----------------
- **Policy**: Represents a collection of augmentation sub-policies and associated parameters such as the number of magnitude bins.
- **_DataNode**: Represents a batch of data samples to be augmented.
- **types.DALIInterpType**: Enumeration of interpolation types used in image transformations.

Usage Notes
-----------
- The module supports passing additional keyword arguments to augmentations via `apply_auto_augment`. These arguments are matched by name to augmentation parameters and passed accordingly.
- Random seeds can be specified to ensure reproducibility of augmentation sequences.
- The module includes predefined policies for popular datasets such as ImageNet and SVHN, as well as a reduced ImageNet policy for quicker experimentation.

References
----------
- AutoAugment Paper: https://arxiv.org/abs/1805.09501

This module is part of the NVIDIA DALI library's auto augmentation utilities and is designed to facilitate easy integration of AutoAugment policies into data preprocessing pipelines.
